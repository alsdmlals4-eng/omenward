# 아트

- Skill ID: `discipline.art`
- Category: `disciplines`
- Registry: `docs/base/SKILL_REGISTRY.json`
- Shared contract: `skills/SHARED_EXECUTION_CONTRACT.md`

## 사용 조건
- 아트 방향·캐릭터·환경
- 아이콘·픽셀 아트·시각 자료

## 사용하지 않는 조건
- 게임 규칙 변경

## 고유 책임
- 시각 언어
- 실루엣·팔레트
- 자산 승인 상태

## 입력
- 아트 가이드
- 시각 참고
- 실제 화면

## 절차
1. 참고·금지 요소를 분리한다.
2. 실루엣과 정보성을 검토한다.
3. 출처와 승인 상태를 기록한다.

## 출력
- 아트 브리프
- 자산 상태
- 시각 검수

## 고유 검수
- 참고 이미지를 그대로 복제하지 않는가.
- 화면 목적과 승인 상태가 명확한가.
