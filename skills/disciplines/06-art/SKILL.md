# Omenward Art

- Skill ID: `discipline.art`
- 공통 계약: `skills/SHARED_EXECUTION_CONTRACT.md`

## 사용 조건

아트 방향·캐릭터·환경·아이콘·픽셀아트·이미지 프롬프트·기법 카드를 설계·감사할 때.

## 사용하지 않는 조건

시각 영향 없는 시스템 로직 작업.

## 고유 책임

승인 시각 방향과 베일종·루메른 진영의 차이를 유지하고, 생성 전 프롬프트와 구현 후 자산 감사를 분리한다.

## 입력

- 승인 아트 방향·참고 이미지
- Asset Registry·출처·권한
- 목표 화면·용도·규격
- 채택·비채택 시각 요소

## 절차

- Modes: `art-direction → art-prompt → technique-card → asset-audit → visual-consistency`
- 기존 승인 이미지와 채택 요소를 먼저 확인한다.
- 프롬프트에 주제·구도·재질·팔레트·광원·금지 요소를 명시한다.
- 기법 카드는 재현 가능한 단계·도구·검수로 작성한다.
- 결과 자산은 픽셀·관절·무기·문자·광원·권한을 검사한다.
- 승인 전 임의 교체하지 않는다.

## 출력

- 아트 방향 결정
- 이미지 생성·편집 프롬프트
- 기법 카드
- 자산 finding·승인 상태

## 고유 검수

- 기존 승인 이미지가 있으면 무단 새 시안을 만들지 않는다.
- 참고 게임의 고유 디자인을 복제하지 않는다.
- 권한·출처 미확인 자산을 최종 자산으로 사용하지 않는다.
