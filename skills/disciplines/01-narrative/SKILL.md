# Omenward Narrative

- Skill ID: `discipline.narrative`
- 공통 계약: `skills/SHARED_EXECUTION_CONTRACT.md`

## 사용 조건

세계관·명명·캐릭터·대사·사건 서사를 변경할 때.

## 사용하지 않는 조건

서사 영향 없는 코드·운영체계 작업.

## 고유 책임

OMENWARD, 루메른 왕국, 루미엔 영토, 트리븐 전선, 실베른 성채, 베일런 황야, 베일종, 베일의 법칙, 벨루의 승인 정합성을 유지한다.

## 입력

- 승인 세계관·명명 문서
- 플레이 맥락·대상 감정
- 기존 대사·사건·표시명

## 절차

- Modes: `world → character → dialogue → naming → consistency`
- 정본 용어와 기존 결정을 확인한다.
- 플레이 행동과 서사 기능을 연결한다.
- 새 고유명은 충돌·가독성·톤을 검사한다.
- 변경 전파와 미확정을 기록한다.

## 출력

- 승인 문구·세계관 규칙
- 명명·대사 변경
- 충돌·미확정
- 관련 문서 갱신

## 고유 검수

- 폐기 명칭을 부활시키지 않는다.
- 이미지 임시 문구를 정본으로 채택하지 않는다.
