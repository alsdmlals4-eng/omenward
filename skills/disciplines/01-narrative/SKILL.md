# 설정·내러티브

- Skill ID: `discipline.narrative`
- Category: `disciplines`
- Registry: `docs/base/SKILL_REGISTRY.json`
- Shared contract: `skills/SHARED_EXECUTION_CONTRACT.md`

## 사용 조건
- 세계관·서사·캐릭터
- 대사·명명·용어

## 사용하지 않는 조건
- 밸런스 수치 결정

## 고유 책임
- 세계관·명명·서사 규칙

## 입력
- GDD
- 승인 내러티브 문서
- 최신 사용자 지시

## 절차
1. 정본과 충돌하는 설정을 찾는다.
2. 플레이 경험에 필요한 정보만 갱신한다.
3. 용어와 톤을 통일한다.

## 출력
- 내러티브 변경안
- 확정 문구
- 충돌 목록

## 고유 검수
- 승인 용어·세계관과 일치하는가.
