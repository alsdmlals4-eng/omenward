# 테크니컬 아트·콘텐츠 파이프라인

- Skill ID: `discipline.technical-art`
- Category: `disciplines`
- Registry: `docs/base/SKILL_REGISTRY.json`
- Shared contract: `skills/SHARED_EXECUTION_CONTRACT.md`

## 사용 조건
- 리소스 파이프라인·임포트
- 스프라이트 규격·애니메이션 계약

## 사용하지 않는 조건
- 아트 방향 자체의 승인

## 고유 책임
- 자산 규격
- 임포트·빌드
- 콘텐츠 검증

## 입력
- 아트 계약
- 엔진 제약
- 자산 목록

## 절차
1. 원본→가공→엔진 경로를 명세한다.
2. 자동 검증 가능한 규격을 만든다.
3. 누락·파생·교체 상태를 기록한다.

## 출력
- 파이프라인 계약
- 검증 도구
- 누락표

## 고유 검수
- 원본과 파생본의 추적성이 있는가.
