# Omenward Core UX and Playtests

Skill ID: `discipline.omenward-core-ux`

`skills/SHARED_EXECUTION_CONTRACT.md`를 따른다.

## 사용 조건
10~15분 핵심 플레이테스트, HUD·가독성, 실패 원인 이해, 1920×1080·1280×720 화면 검증, 선택 피드백을 평가할 때 사용한다.

## 사용하지 않는 조건
플레이어가 보지 않는 내부 코드 정리나 순수 에셋 제작에는 주 Skill로 사용하지 않는다.

## 고유 책임
플레이어가 위협 예고를 읽고, 건설 선택이 룰렛 확률에 미친 영향과 보상을 이해하고, 레인 배치 결과와 실패 원인을 다음 선택에 활용할 수 있는지 검증한다.

## 입력
실행 빌드, 캡처·영상, 플레이테스트 관찰 기록, UI 정본, C1~C4 게이트, 대상 해상도.

## 절차
1. 관찰 질문과 성공 기준을 행동 단위로 정의한다.
2. 핵심 루프의 각 선택에서 정보 인지·결정·피드백 시간을 기록한다.
3. 해상도별 잘림, 대비, 우선순위, 상태 구분을 확인한다.
4. 문제를 규칙·UI·연출·밸런스 원인으로 분리하고 증거를 연결한다.

## 출력
관찰 로그, 재현 가능한 UX 결함, 우선순위, 승인·보류 판단, 다음 플레이테스트 질문.

## 고유 검수
자동화 통과를 인간 이해 증거로 대체하거나, 플레이 영상 없이 C4를 완료 처리하거나, 해상도별 증거가 없으면 실패다.
