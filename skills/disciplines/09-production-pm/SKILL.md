# 프로덕션·PM

- Skill ID: `discipline.production-pm`
- Category: `disciplines`
- Registry: `docs/base/SKILL_REGISTRY.json`
- Shared contract: `skills/SHARED_EXECUTION_CONTRACT.md`

## 사용 조건
- 일정·우선순위·마일스톤
- 의존성·위험·작업 분해

## 사용하지 않는 조건
- 세부 구현을 대신 수행

## 고유 책임
- 범위·순서·의존성
- 완료 게이트

## 입력
- Roadmap·Issue
- 팀 용량
- 위험과 선행 조건

## 절차
1. 작업을 검증 가능한 단위로 나눈다.
2. 선행 조건과 병렬 가능성을 표시한다.
3. 완료 기준에 검증을 연결한다.

## 출력
- 계획·우선순위
- 위험표
- Handoff

## 고유 검수
- 완료 정의가 산출물만 있고 검증은 없는가.
