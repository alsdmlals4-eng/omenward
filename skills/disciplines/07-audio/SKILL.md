# Omenward Audio

- Skill ID: `discipline.audio`
- 공통 계약: `skills/SHARED_EXECUTION_CONTRACT.md`

## 사용 조건

음악·효과음·음성·믹싱·오디오 피드백을 설계·검수할 때.

## 사용하지 않는 조건

오디오 영향 없는 작업.

## 고유 책임

공세 예고·룰렛·전투·점령·벨루의 핵심 정보를 시각 채널과 중복 가능한 오디오 피드백으로 전달한다.

## 입력

- 게임 이벤트·우선순위
- 아트·서사 톤
- 플랫폼·믹싱·접근성 요구
- 기존 자산·권한

## 절차

- Modes: `direction → event-map → asset-spec → mix → accessibility → review`
- 플레이 이벤트와 청취 목적을 연결한다.
- 중요도·동시 재생·ducking을 정의한다.
- 자산 규격·루프·변형·권한을 기록한다.
- 실제 게임 장면에서 명료성·피로·대체 시각 신호를 검수한다.

## 출력

- 오디오 방향·이벤트 맵
- 자산 규격
- 믹싱·접근성 규칙
- 실제 장면 검수

## 고유 검수

- 오디오만으로 필수 정보를 전달하지 않는다.
- 권한 미확인 자산을 사용하지 않는다.
- 실제 재생 없이 믹싱 완료를 주장하지 않는다.
