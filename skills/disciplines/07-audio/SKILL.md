# 사운드

- Skill ID: `discipline.audio`
- Category: `disciplines`
- Registry: `docs/base/SKILL_REGISTRY.json`
- Shared contract: `skills/SHARED_EXECUTION_CONTRACT.md`

## 사용 조건
- 사운드·음악·효과음
- 음성·믹싱

## 사용하지 않는 조건
- 전투 수치 변경

## 고유 책임
- 오디오 큐
- 우선순위·믹스
- 청각 접근성

## 입력
- 게임 이벤트
- 연출 계약
- 플랫폼 제약

## 절차
1. 이벤트와 소리를 매핑한다.
2. 중요도와 중첩 규칙을 정한다.
3. 무음·반복 피로·과밀을 검토한다.

## 출력
- 오디오 이벤트 표
- 제작 브리프
- 검수 결과

## 고유 검수
- 핵심 피드백이 다른 소리에 묻히는가.
