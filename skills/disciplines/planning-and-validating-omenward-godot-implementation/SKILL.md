# Omenward Godot Implementation

Skill ID: `discipline.omenward-godot`

`skills/SHARED_EXECUTION_CONTRACT.md`를 따른다.

## 사용 조건
Godot, GDScript, 결정론, 공유 데이터, 자동전투, 저장·로드, 검증기, 엔진 경계 변경에 사용한다.

## 사용하지 않는 조건
규칙만 논의하거나 시각 기획만 하는 작업에는 주 Skill로 사용하지 않는다.

## 고유 책임
승인된 코어 규칙을 Godot 구조와 데이터 계약으로 변환하고, 실행 경로·결정론·실패 경계·정본 데이터의 일치를 검증한다.

## 입력
승인 규칙, 실제 `.gd`·`.tscn`·리소스 파일, 테스트·validator, Godot 버전과 실행 로그.

## 절차
1. 승인 사양과 실제 파일의 차이를 먼저 기록한다.
2. 입력·출력·상태 전이·결정론·오류 경계를 정의한다.
3. 테스트를 먼저 추가하고 실패를 확인한 뒤 최소 구현을 계획한다.
4. 헤드리스·통합·회귀 검증과 수동 확인 항목을 분리한다.

## 출력
파일 단위 구현 계약, 테스트 증거, 엔진 제약, 데이터 마이그레이션 및 롤백 기준.

## 고유 검수
승인되지 않은 규칙을 코드가 새 정본으로 만들거나, 동일 입력의 결과가 비결정적이거나, 공유 데이터 정의가 중복되면 실패다.
