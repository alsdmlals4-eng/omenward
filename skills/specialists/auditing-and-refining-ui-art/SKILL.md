# UI·아트 시각 감사와 개선

- Skill ID: `specialist.ui-art-audit`
- Category: `specialists`
- Registry: `docs/base/SKILL_REGISTRY.json`
- Shared contract: `skills/SHARED_EXECUTION_CONTRACT.md`

## 사용 조건
- UI 아트 검수·시각 감사
- 화면 가독성·Visual Audit

## 사용하지 않는 조건
- 실제 화면이나 명확한 레이아웃 근거가 없는 경우

## 고유 책임
- 정보 위계·대비·일관성
- 화면 밀도·시각 회귀

## 입력
- 스크린샷·Scene
- UI 계약
- 아트 가이드
- 대상 해상도

## 절차
1. 핵심 시선 경로를 표시한다.
2. 가독성·대비·정렬·밀도를 공격한다.
3. 게임 상태와 표현의 불일치를 찾는다.
4. 수정 우선순위를 제시한다.
5. 수정 후 같은 기준으로 재평가한다.

## 출력
- 시각 감사 결과
- 수정안
- 사람 QA 체크리스트

## 고유 검수
- 문자열 검사만으로 시각 통과를 주장하는가.
- 실제 해상도 증거가 있는가.
