# 수직 슬라이스 설계

- Skill ID: `specialist.vertical-slice`
- Category: `specialists`
- Registry: `docs/base/SKILL_REGISTRY.json`
- Shared contract: `skills/SHARED_EXECUTION_CONTRACT.md`

## 사용 조건
- 수직 슬라이스·Vertical Slice
- MVP·PoC 범위

## 사용하지 않는 조건
- 전체 제품 로드맵만 요청된 경우

## 고유 책임
- 핵심 경험 증명 범위
- 대표 콘텐츠
- 완료·실패 게이트

## 입력
- 핵심 루프
- 위험 가설
- 팀·엔진 제약

## 절차
1. 증명할 경험을 하나로 고정한다.
2. 필수 시스템과 가짜·생략 가능 요소를 분리한다.
3. 대표 시나리오와 실패 조건을 만든다.
4. 자동·수동 검증을 연결한다.

## 출력
- 슬라이스 범위
- 작업 순서
- 검증 시나리오
- 제외 목록

## 고유 검수
- MVP가 전체 게임 축소판이 되었는가.
- 핵심 가설을 실제로 검증하는가.
