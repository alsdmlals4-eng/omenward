# 게임 콘셉트 분석과 정제

- Skill ID: `specialist.game-concept`
- Category: `specialists`
- Registry: `docs/base/SKILL_REGISTRY.json`
- Shared contract: `skills/SHARED_EXECUTION_CONTRACT.md`

## 사용 조건
- 게임 아이디어·콘셉트
- 핵심 재미·차별점

## 사용하지 않는 조건
- 세부 구현만 요청된 경우

## 고유 책임
- 핵심 루프
- 플레이어 약속
- 차별점과 삭제 기준

## 입력
- 초기 아이디어
- 타깃 경험
- 유사 사례

## 절차
1. 핵심 동사를 추출한다.
2. 보상·긴장·반복 루프를 연결한다.
3. 차별점과 모순을 공격한다.
4. 불필요한 기능을 제거한다.
5. 검증 가능한 콘셉트 문장으로 정제한다.

## 출력
- 콘셉트 문장
- 핵심 루프
- 가설·검증 질문

## 고유 검수
- 기능 목록이 핵심 경험을 가리는가.
- 차별점이 실제 플레이 행동으로 나타나는가.
