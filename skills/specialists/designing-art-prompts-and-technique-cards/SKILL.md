# 아트 프롬프트와 제작 기법 카드

- Skill ID: `specialist.art-prompts`
- Category: `specialists`
- Registry: `docs/base/SKILL_REGISTRY.json`
- Shared contract: `skills/SHARED_EXECUTION_CONTRACT.md`

## 사용 조건
- 아트 프롬프트
- 이미지 생성 지시
- 기법 카드

## 사용하지 않는 조건
- 최종 자산 승인을 프롬프트만으로 대체하려는 경우

## 고유 책임
- 시각 목표·금지 요소
- 제작 단계·검수 기준

## 입력
- 아트 가이드
- 참고 이미지 해석
- 자산 규격

## 절차
1. 목표·구도·형태·재질·광원을 분리한다.
2. 복제 금지 요소를 명시한다.
3. 생성 후 수작업 정리 단계를 정의한다.
4. 실패 예와 검수 기준을 붙인다.

## 출력
- 프롬프트
- Negative 기준
- 제작·검수 카드

## 고유 검수
- 고유 IP를 복제하도록 지시하는가.
- 엔진 규격과 실제 화면 목적이 포함됐는가.
