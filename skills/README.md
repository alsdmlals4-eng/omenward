# Omenward Skills

- 공통 계약: `skills/SHARED_EXECUTION_CONTRACT.md`
- Registry: `docs/base/SKILL_REGISTRY.json`
- Base coverage: `docs/base/BASE_CAPABILITY_COVERAGE.json`
- Alias: `skills/LEGACY_SKILL_ALIASES.json`
- Router: `tools/route_skills.py`
- Validator: `tools/validate_skill_system.py`

구조는 Foundation 12개와 Omenward Discipline 11개다. 별도 Specialist 디렉터리는 사용하지 않으며 전문 기능은 해당 분야의 명시적 mode로 통합한다.

새 Skill은 기존 mode로 해결할 수 없고 독립 입력·산출물·권한·검증 경계가 있을 때만 추가한다.
