# 프로젝트 요청 접수와 작업 계약

- Skill ID: `foundation.project-intake`
- Category: `foundation`
- Registry: `docs/base/SKILL_REGISTRY.json`
- Shared contract: `skills/SHARED_EXECUTION_CONTRACT.md`

## 사용 조건
- 요청
- 작업
- 변경
- 구현
- 검토
- 기획

## 사용하지 않는 조건
- 단순 사실 질의
- 프로젝트와 무관한 대화

## 고유 책임
- 작업 목표
- 범위와 제외 범위
- 승인 상태
- 완료 기준과 검증 계획

## 입력
- 사용자 최신 지시
- 현재 Issue·Goal·PR
- `AGENTS.md`
- 책임 원본

## 절차
1. 요청을 한 문장 목표로 정규화한다.
2. PLAN·BUILD·REVIEW 모드를 결정한다.
3. 포함·제외·보호 경로를 잠근다.
4. Registry로 필요한 Skill을 선택한다.
5. 미확정 사항과 중단 조건을 기록한다.

## 출력
- 작업 계약
- Work Mode와 Skill 목록
- 변경·검증 계획

## 고유 검수
- 승인되지 않은 BUILD가 없는가.
- 범위 밖 변경이 없는가.
- 최신 사용자 지시가 최우선인가.
