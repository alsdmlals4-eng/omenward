## 2. 전장·중간거점·성문·암살자

구조와 초기값 확정:

- 좌우 대칭 독립 상·중·하 3라인.
- `본진 → 성문 → 중간거점 → 중앙 접전지 → 적 중간거점 → 적 성문 → 적 본진`.
- 각 중간거점 전방 2·후방 1 건설 노드.
- 중간거점 점령 시 건설권·생산권 이전.
- 미니맵 없음.
- 암살자 직접 후방 배치 금지, 같은 라인의 안개 우회로 사용.

중간거점 초기값:

- 중립화 10초 + 점령 10초 at 점령력 1.0.
- 최대 유효 점령력 2.0.
- 진행 유지 3초, 복귀 초당 10%.
- 안정화 5초.
- 소유 거점 금화 +2/30초.
- 점령 중 생산·건설·업그레이드 정지.
- 중립화 시 건물 비활성, 점령 완료 시 폐허화·환불 없음.

성문 초기값:

- HP 5,000, 방어 80, 마법저항 80.
- 일반 구조물 피해 40%, 공성 200%, 고정 피해 50%.
- 붕괴 2초.
- 수직 슬라이스에서 수리·재건 없음.

암살자 초기값:

- 진입 준비 1초, 이동 9초.
- 도착 2.5초 전 경고, 출현 준비 0.6초.
- 적 중간거점 뒤 120 units, 160×120 도착 영역.
- 막힘 보정 80 units.
- 점령력 0, 우회 중 전투·피격·버프 없음.

플레이테스트 조정 대상:

- [ ] 10+10초 점령 시간이 실제 전선 속도에 적절한지.
- [ ] 병종별 점령력과 2.0 상한.
- [ ] 거점 +2/30초가 시장·기본·접전지 수입과 만드는 경제 속도.
- [ ] 성문 HP·방어·공성 배율이 목표 공성 시간에 맞는지.
- [ ] 암살자 9초 이동·2.5초 경고가 공격성과 대응성을 모두 만족하는지.
- [ ] 주 도로 200~240, 거점·성문 전방 240~320 units 최종 폭.
- [ ] 라인별 실제 이동 거리 보정.

후속 범위:

- [ ] 암살자 탐지 전용 건물 또는 정찰 대응 체계 채택 여부.
- [ ] 정식 캠페인에서 성문 수리·재건을 추가할지 여부.

- Tier와 등급 분리.

## 6. 경제·룰렛

```text

식량 12
기본 수입 +5 / 20초
중앙 접전지 +4 / 60초 / 소유 지점
중간거점 +2 / 30초 / 소유 지점

```

- 적 처치·웨이브 클리어 고정 금화 없음.

검증 대상:

- [ ] 룰렛 최소 100,000시드 분포.
- [ ] 기본 X·금화·이동권 가중치.

- [ ] 금화 장기 평균 지급이 회전비 30% 이하인지.
- [ ] 시장·접전지·거점·기본 수입의 시간축 밸런스.
- [ ] 이동권 가격·보유 상한·상점 출현률.
