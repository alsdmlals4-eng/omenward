# 오멘워드 미확정 결정 목록

Codex는 아래 항목을 사용자 승인 없이 임의 확정하지 않는다.

## 공식 명칭 — 확정

- [x] 게임명: **오멘워드 / OMENWARD**
- [x] 첫 캠페인 부제 가안: **오멘워드: 실베른 성채**
- [x] 국가: **루메른 왕국**
- [x] 인간 생활권: **루미엔 영토**
- [x] 전선: **트리븐 전선**
- [x] 첫 요새: **실베른 성채**
- [x] 괴물 영역: **베일런 황야**
- [x] 경계 현상: **베일**
- [x] 기존 `경계의 율`: **베일의 법칙**
- [x] 기존 `율비`: **벨루**
- [x] 적 공식 분류: **베일종**
- [x] 신규 UI·대사·기획에는 레거시 명칭을 사용하지 않음
- [x] 저장소명·내부 코드명 `roulettebound-prototype`은 구현 마이그레이션 승인 전까지 유지

## 제품·기술 — 확정

- [x] Godot + GDScript
- [x] Windows PC / 마우스·키보드
- [x] 싱글플레이 PvE
- [x] 코드 작업 전 Codex Plan Mode 제안서와 사용자 승인 필수
- [x] 정규 스테이지 활성 전투 시간 약 15분
- [x] 활성 전투 시간 기준 60초마다 공세 충돌
- [x] 표준 클리어 목표 15웨이브
- [x] 20웨이브는 신화 최종보스가 출격하는 소프트 패배 시한
- [x] 수직 슬라이스 10~15분
- [x] 첫 공개 프로토타입 약 3시간
- [x] 단일 수동 튜토리얼 뒤 결정론적 절차 생성 스테이지

## Dopamine Driven Design — 확정

- [x] 핵심 재미: 건물로 확률을 만들고 예고된 위기를 뒤집음
- [x] 새 시스템 기본 습득 목표 10~30초
- [x] 한 문장 설명 → 한 번 행동 → 즉시 결과
- [x] 첫 10분 안에 핵심 루프 두 번
- [x] 첫 룰렛은 일반 검사, 두 번째 룰렛은 이동권으로 엘리트
- [x] 첫 10분 안에 방패병·대검병·광전사 중 하나 체험

## 벨루 — 확정

- [x] 세계관 설명·적 보고·튜토리얼·전술 선택지·감정 반응 통합
- [x] 정찰관·부관 기능성 안내 NPC 제외
- [x] 최신 요정형 시안 사용
- [x] 상태 반응은 0.5~2초 경고등 방식 뒤 기본형 복귀
- [x] 지속 상태는 HUD 아이콘·타이머가 표시
- [x] 오른쪽 하단 48~64px 도크, 최대 두 줄 말풍선

미확정:

- [ ] 벨루 공식 영문 철자
- [ ] 성우 캐스팅 방향과 샘플
- [ ] 표정 8종 최종 원화
- [ ] 상태별 애니메이션 정확한 프레임
- [ ] 캠페인에서 벨루의 성장·기억 회복 여부

## 룰렛·플레이어 등급 — 확정

- [x] 중앙 가로줄 기본 판정
- [x] 같은 비-X 심벌 3개일 때만 보상
- [x] 1/2/3~7/8줄 → 일반/엘리트/영웅/전설
- [x] 플레이어 등급은 일반·엘리트·영웅·전설 4단계 유지
- [x] 신화급은 플레이어 룰렛 결과에 추가하지 않음
- [x] 전설은 한 판당 1회, 이후 9칸 동일은 영웅 2명
- [x] 상위 등급은 룰렛으로만 생성
- [x] 합성·처치 경험치·건물 Tier 승급 없음
- [x] 금화 1/2/3줄 이상 → 75%/200%/500%
- [x] 럭키 찬스 12%, 실패당 +8%p, 6회 실패 뒤 확정
- [x] 자연 이동과 여러 이동권 동시 사용 가능

미확정:

- [ ] 판정줄 변경 아이템
- [ ] 행운 아이템 증가량·중첩 상한
- [ ] 이동권 보유 상한·가격·출현 빈도
- [ ] 결과 보관함과 대기칸 최종 UI
- [ ] 등급별 정확한 능력치 배율

## 적군 등급 이정표 — 확정

- [x] 1~4웨이브 일반 중심
- [x] 5웨이브 엘리트 유닛 공세
- [x] 10웨이브 영웅 유닛 공세
- [x] 15웨이브 전설 유닛 보스 공세
- [x] 16~19웨이브 엘리트·영웅 비중 급증
- [x] 20웨이브 적군 전용 신화 최종보스 공세
- [x] 15웨이브 전설 보스 처치가 표준 승리
- [x] 15웨이브 이전 적 본진 파괴는 공격적 조기 승리

미확정:

- [ ] 적 전사 계보 최종 이름과 정확한 수치
- [ ] 웨이브별 정확한 Threat Budget
- [ ] 난이도별 등급 비중

## 진영 대칭형 유닛·건물 — 확정

- [x] 아군·적군은 병종 계열·Tier·전투 태그·능력치 필드·패시브·스킬 구조를 공유
- [x] 같은 병종 계열·같은 Tier·같은 등급은 비슷한 기본 전투 예산 사용
- [x] 기본 전투 예산은 초기 ±10% 범위에서 시작
- [x] 큰 성능 차이는 숨은 능력치가 아니라 공개 태그·스킬·AI·진영 수정자로 설명
- [x] 같은 기능 계열·Tier의 아군·적군 건물은 기본 HP·사거리·생산 주기 예산이 유사
- [x] 적군은 룰렛을 사용하지 않고 적 건물·공세 시간표로 등급과 병력을 생성
- [x] 적 생산 건물 파괴는 대응 병종 공세 감소와 연결

미확정:

- [ ] 같은 계열·Tier·등급의 최종 허용 편차
- [ ] 아군·적군 공통 RankProfile 배율
- [ ] 적군 병종 공식 이름·외형·능력표
- [ ] 적군 건물 공식 이름·전문화·Tier 수치
- [ ] 난이도 프로필과 진영 수정자의 적용 순서

## 병영·유닛 성장 — 확정

- [x] 같은 병종 계열은 Tier가 달라도 토큰 공유
- [x] T1 검사와 T2 이상 전사 계열은 전사 토큰 공유
- [x] T2 전사: 방패병·대검병·광전사
- [x] 깃발병은 기본 병영의 Tier 2 전문화
- [x] 깃발병 전문화 중에는 검사 생산·전사 토큰 유지
- [x] 전문화 완료 뒤 생산 진행률을 보존하고 일반 깃발병 자동생산으로 전환
- [x] 진행 중 룰렛은 유지하고 다음 회전부터 독립 군기 토큰으로 교체
- [x] 별도 지휘소 건물은 사용하지 않음
- [x] 일반 깃발병은 Tier 2 패시브 구조에서 시작
- [x] T3 기병: 중기병·충격기병
- [x] T3 궁병: 석궁병·대공궁병·연사궁병
- [x] 일반은 출처 병영의 실제 병종
- [x] 엘리트·영웅·전설은 계열별 고정 유닛
- [x] T1 패시브 1, T2 패시브 1 강화+2 생성, T3 패시브 1 추가 강화+2 강화+3 생성
- [x] 일반 1스킬, 엘리트 1 강화, 영웅 2 생성, 전설 2 강화+3 생성

미확정:

- [ ] 전사 Tier 3 세부 병종
- [ ] 창병 Tier 3 세부 병종
- [ ] 깃발병 Tier 3 심화 병종·교리
- [ ] Tier 후보 가중치 1/2/3 최종 승인
- [ ] 고정 엘리트·영웅·전설 전사 능력표
- [ ] 엘리트·영웅·전설 깃발병 이름·외형·최종 수치
- [ ] 기병·궁병 세부 병종 패시브·스킬 수치
