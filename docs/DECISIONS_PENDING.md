## 2. 전장·중간거점·성문·암살자

### 승인 구조

- 좌우 대칭 독립 상·중·하 3라인.
- `본진 → 성문 → 중간거점 → 중앙 접전지 → 적 중간거점 → 적 성문 → 적 본진`.
- 라인별 성문 3개.
- 중간거점 전방 2·후방 1 건설 노드.
- 점령 시 건설권·기본 생산권 이전.
- 중앙 접전지 건설 불가와 라인 독립.
- 미니맵 없음.
- 암살자 후방 직접 생성 금지, 같은 라인의 안개 우회로 사용.

### 승인된 PoC 초기값

중간거점:

```text
중립화 10초 + 점령 10초 at 점령력 1.0
최대 유효 점령력 2.0
진행 유지 3초
복귀 초당 10%
안정화 5초
금화 +2 / 30초
```

- 점령 시도 중 생산·건설·업그레이드 정지.
- 중립화 시 기존 건물 비활성.
- 점령 완료 시 기존 건물 폐허화, 환불 없음.

성문:

```text
HP 5000
방어·마법저항 80
일반 구조물 피해 40%
공성 200%
고정 피해 50%
붕괴 2초
```

암살자:

```text
진입 1초
이동 9초
도착 경고 2.5초 전
출현 준비 0.6초
적 중간거점 뒤 120 units
도착 영역 160 × 120
막힘 보정 80 units
점령력 0
```

### 플레이테스트 조정

- [ ] 10+10초 점령 시간이 실제 전선 속도에 적절한가.
- [ ] 병종별 점령력과 2.0 상한.
- [ ] 거점 +2/30초가 기본·시장·접전지 수입과 만드는 경제 속도.
- [ ] 성문 HP·방어·공성 배율과 목표 공성 시간.
- [ ] 암살자 9초 이동과 2.5초 경고의 공격성·대응성.
- [ ] 주 도로 200~240, 거점·성문 전방 240~320 units.
- [ ] 라인별 이동 거리 보정.

### 장기 확장

- [ ] 암살자 탐지 건물 또는 정찰 대응 체계.
- [ ] 정식 캠페인의 성문 수리·재건.

## 3. 공용 10병종 데이터

### 승인 구조

```text
UnitArchetypeProfile × 10
+ TierProfile
+ RankProfile
+ owner_team_id
+ FactionVisualProfile
```

- 아군·적군 별도 전투 데이터 세트를 만들지 않는다.
- HP·공격·스킬·패시브·타기팅·점령·구조물 피해·AnimationContract를 공유한다.
- 차이는 소유 팀, 출격 방식, 스프라이트·초상화·아이콘·팔레트·표시명이다.
- 별도 `EnemyUnitProfile`과 적군 전용 스탯·스킬·모션 타이밍 금지.
- 일반 적 웨이브는 공용 `archetype_id`에 Tier·Rank·수량·라인·출격 시간·enemy 팀·veil Visual Set을 지정한다.
- 보스는 공용 base archetype에 BossBehaviorPackage·BossPhaseProfile·전용 Visual Set을 추가한다.

### 구현 전 결정

- [ ] UnitArchetypeProfile의 실제 Godot Resource 필드와 경로.
- [ ] TierProfile·RankProfile 적용 순서와 캐시 방식.
- [ ] FactionVisualProfile과 AnimationContract의 실제 Resource 구조.
- [ ] 공용 Unit Scene에 프로필을 주입하는 방식.
- [ ] 아군·적군 Visual Set의 프레임·피벗·이벤트 호환 자동 검사.
- [ ] 첫 PoC에서 VFX·오디오를 완전 공유할지 최소 팀 마커만 분리할지.

### 검증 뒤 결정

- [ ] 체형 차이가 큰 Visual Set에 제한적 피벗 override가 필요한가.
- [ ] 진영 판독을 위해 VFX·효과음 음색 override가 필요한가.
- [ ] 보스가 기존 base archetype으로 충분한가, 보스 전용 base archetype이 필요한가.

공용 데이터 분리는 마지막 수단이며 사용자 승인 대상이다.

## 9. 애니메이션·전투 연출

### 승인 구조

- 공용 아키타입마다 AnimationContract 하나.
- 아군·적군 Visual Set은 같은 상태, 프레임 수, 배열, 피벗과 이벤트 프레임.
- 공격은 준비→판정→회복.
- 판정과 접촉·발사 이벤트 오차 한 프레임 이내.
- 이동 위치는 코드가 소유하고 루트 모션 사용 안 함.
- 적군 전용 모션 상태 머신과 별도 타이밍 데이터 없음.
- 개별 처치 승리 모션 없음, 스테이지 승리 2.5~4초.

### 구현 전·PoC 결정

- [ ] 기준 애니메이션 FPS.
- [ ] 2방향 미러링 또는 추가 방향 수.
- [ ] AnimatedSprite2D·AnimationPlayer 조합.
- [ ] 프레임 이름, 아틀라스, 피벗 프로필.
- [ ] 공격속도 변화 재생 상·하한.
- [ ] 히트 스톱과 화면 흔들림 정확한 수치.
- [ ] 공용 이벤트와 Visual Set 호환 검사.
- [ ] 대표 아키타입 3~5종 제작 순서.
