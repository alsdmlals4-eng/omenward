## 3. 전장·중간거점·성문·암살자

### 승인 구조

- 좌우 대칭 독립 상·중·하 3라인.
- `본진 → 성문 → 중간거점 → 중앙 접전지 → 적 중간거점 → 적 성문 → 적 본진`.
- 양 진영 라인별 성문 총 6개.
- 중간거점 전방 2·후방 1 건설 노드.
- 점령 시 건설권·기본 생산권 이전.
- 중앙 접전지 건설 불가와 라인 독립.
- 미니맵 없음.
- 암살자 후방 직접 생성 금지, 같은 라인의 안개 우회로 사용.

### 승인된 PoC 초기값

중간거점:

```text
중립화 10초 + 점령 10초 at 점령력 1.0
최대 유효 점령력 2.0
진행 유지 3초
복귀 초당 10%
안정화 5초
금화 +2 / 30초
```

성문:

```text
HP 5000
방어·마법저항 80
일반 구조물 피해 40%
공성 200%
고정 피해 50%
붕괴 2초
```

암살자:

```text
진입 1초
이동 9초
도착 경고 2.5초 전
출현 준비 0.6초
적 중간거점 뒤 120 units
도착 영역 160 × 120
막힘 보정 80 units
점령력 0
```

### 플레이테스트 조정

- [ ] 10+10초 점령 시간이 실제 전선 속도에 적절한가.
- [ ] 병종별 점령력과 2.0 상한.
- [ ] 거점 +2/30초의 전체 경제 영향.
- [ ] 성문 HP·방어·공성 배율과 목표 공성 시간.
- [ ] 암살자 9초 이동과 2.5초 경고의 대응성.
- [ ] 주 도로와 거점·성문 전방 거리.
