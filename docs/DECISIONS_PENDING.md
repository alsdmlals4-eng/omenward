- [x] 개발 엔진: **Godot**
- [x] 기본 스크립트 언어: **GDScript**

## Phase 0에서 즉시 결정 필요

- [ ] Godot 정확한 minor 버전: urban-legend와 동일한 4.7 stable 사용 여부
- [ ] 목표 플랫폼: Windows PC 우선 여부
- [ ] 2D 픽셀아트, 2.5D 또는 로우폴리 방향
- [ ] 싱글플레이 전용 MVP 여부
- [ ] 목표 한 판 길이
- [ ] 기본 해상도와 화면 비율
- [ ] 첫 프로토타입의 최대 동시 유닛 수 목표
- [ ] 자동 테스트 도구와 headless 실행 명령

## 룰렛

- [ ] 서로 다른 3개 심벌이 나온 경우 각각 1성 보상을 모두 주는지
- [ ] 한 회전에 여러 병종을 동시에 획득할 때 식량·대기칸 밸런스
- [ ] 기준 줄을 회전 전 선택하는지, 회전 후 선택하는지
- [ ] 럭키 찬스 발생 확률과 이동권 가격
- [ ] 전설·신화 등급의 정확한 빙고 조건
- [ ] 금화 토큰 기대값과 연속 회전 비용

## 건물

- [ ] 최대 티어와 티어별 선택형/고정형 업그레이드
- [ ] 전방 시설 파괴 후 폐허 유지 시간
- [ ] 시설 수리 기능의 MVP 포함 여부
- [ ] 고티어 포탑이 접전지에 닿는 정확한 업그레이드 단계
- [ ] 포탑 종류와 시설 우선 타기팅 규칙

## 전투

- [ ] 유닛 충돌과 라인 폭
- [ ] 맵 단위, 기본 사거리와 이동 단위
- [ ] 유닛이 건물을 공격하는 우선순위
- [ ] 후퇴 또는 라인 변경 가능 여부
- [ ] 영웅과 별 단계의 능력치 결합 방식

- [ ] 적의 건설 및 티어 상승 규칙을 실제로 시뮬레이션할지 스크립트화할지
