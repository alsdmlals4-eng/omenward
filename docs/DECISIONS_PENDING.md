# 오멘워드 미확정 결정 목록

Codex는 아래 항목을 사용자 승인 없이 임의 확정하지 않는다.

## 공식 명칭 — 확정

- [x] 게임명: **오멘워드 / OMENWARD**
- [x] 첫 캠페인 부제 가안: **오멘워드: 실베른 성채**
- [x] 국가: **루메른 왕국**
- [x] 인간 생활권: **루미엔 영토**
- [x] 전선: **트리븐 전선**
- [x] 첫 요새: **실베른 성채**
- [x] 괴물 영역: **베일런 황야**
- [x] 경계 현상: **베일**
- [x] 기존 `경계의 율`: **베일의 법칙**
- [x] 기존 `율비`: **벨루**
- [x] 적 공식 분류: **베일종**
- [x] 신규 UI·대사·기획에는 레거시 명칭을 사용하지 않음
- [x] 저장소명·내부 코드명 `roulettebound-prototype`은 구현 마이그레이션 승인 전까지 유지

## 제품·기술 — 확정

- [x] Godot + GDScript
- [x] Windows PC / 마우스·키보드
- [x] 싱글플레이 PvE
- [x] 코드 작업 전 Codex Plan Mode 제안서와 사용자 승인 필수
- [x] 정규 스테이지 25~35분
- [x] 수직 슬라이스 10~15분
- [x] 첫 공개 프로토타입 약 3시간
- [x] 단일 수동 튜토리얼 뒤 결정론적 절차 생성 스테이지

## Dopamine Driven Design — 확정

- [x] 핵심 재미: 건물로 확률을 만들고 예고된 위기를 뒤집음
- [x] 새 시스템 기본 습득 목표 10~30초
- [x] 한 문장 설명 → 한 번 행동 → 즉시 결과
- [x] 첫 10분 안에 핵심 루프 두 번
- [x] 첫 룰렛은 일반 검사, 두 번째 룰렛은 이동권으로 엘리트
- [x] 첫 10분 안에 방패병·대검병·광전사 중 하나 체험

## 벨루 — 확정

- [x] 세계관 설명·적 보고·튜토리얼·전술 선택지·감정 반응 통합
- [x] 정찰관·부관 기능성 안내 NPC 제외
- [x] 최신 요정형 시안 사용
- [x] 상태 반응은 0.5~2초 경고등 방식 뒤 기본형 복귀
- [x] 지속 상태는 HUD 아이콘·타이머가 표시
- [x] 오른쪽 하단 48~64px 도크, 최대 두 줄 말풍선

미확정:

- [ ] 벨루 공식 영문 철자
- [ ] 성우 캐스팅 방향과 샘플
- [ ] 표정 8종 최종 원화
- [ ] 상태별 애니메이션 정확한 프레임
- [ ] 캠페인에서 벨루의 성장·기억 회복 여부

## 룰렛·등급 — 확정

- [x] 중앙 가로줄 기본 판정
- [x] 같은 비-X 심벌 3개일 때만 보상
- [x] 1/2/3~7/8줄 → 일반/엘리트/영웅/전설
- [x] 전설은 한 판당 1회, 이후 9칸 동일은 영웅 2명
- [x] 상위 등급은 룰렛으로만 생성
- [x] 합성·처치 경험치·건물 Tier 승급 없음
- [x] 금화 1/2/3줄 이상 → 75%/200%/500%
- [x] 럭키 찬스 12%, 실패당 +8%p, 6회 실패 뒤 확정
- [x] 자연 이동과 여러 이동권 동시 사용 가능

미확정:

- [ ] 판정줄 변경 아이템
- [ ] 행운 아이템 증가량·중첩 상한
- [ ] 이동권 보유 상한·가격·출현 빈도
- [ ] 결과 보관함과 대기칸 최종 UI
- [ ] 등급별 정확한 능력치 배율

## 병영·유닛 성장 — 확정

- [x] 같은 병종 계열은 Tier가 달라도 토큰 공유
- [x] T1 검사와 T2 이상 전사 계열은 전사 토큰 공유
- [x] T2 전사: 방패병·대검병·광전사
- [x] T3 기병: 중기병·충격기병
- [x] T3 궁병: 석궁병·대공궁병·연사궁병
- [x] 일반은 출처 병영의 실제 병종
- [x] 엘리트·영웅·전설은 계열별 고정 유닛
- [x] T1 패시브 1, T2 패시브 1 강화+2 생성, T3 패시브 1 추가 강화+2 강화+3 생성
- [x] 일반 1스킬, 엘리트 1 강화, 영웅 2 생성, 전설 2 강화+3 생성

미확정:

- [ ] 전사 Tier 3 세부 병종
- [ ] 창병 Tier 3 세부 병종
- [ ] Tier 후보 가중치 1/2/3 최종 승인
- [ ] 고정 엘리트·영웅·전설 전사 능력표
- [ ] 기병·궁병 세부 병종 패시브·스킬 수치

## 건설·경제 — 확정

- [x] 적이 있어도 건설·업그레이드 진행
- [x] 건설 중 피격과 완공 전 파괴 가능
- [x] Tier 1 공통 → Tier 2 전문화 → Tier 3 세부 병종·교리
- [x] 생산시설 버프는 등급과 분리
- [x] 시장+포탑+용병 정식 전략

미확정:

- [ ] 건설 시작 체력과 진행도별 체력 곡선 최종값
- [ ] 철거·취소 환불률
- [ ] 농장·시장 전문화 정확한 수치
- [ ] 포탑 전문화 정확한 수치
- [ ] 병영 Tier 3 교리 수치
- [ ] 용병 병종·가격·재고와 일반 등급 고정 여부

## 전투 — 확정

- [x] 물리·마법·고정 피해
- [x] 기본 치명타 5%, 피해 150%
- [x] 후방 판정 120도
- [x] 창병 돌진 저지 내부 쿨타임 5초 초기값
- [x] 지상·비행 레이어와 대공 태그
- [x] 비행은 지상 유닛·바리케이드·지상 함정 우회
- [x] 비행은 기본적으로 접전지 점령 미기여

미확정:

- [ ] 유닛 충돌과 라인 폭
- [ ] 타깃 변경과 적 통과
- [ ] 치명타·후방·돌진 세부 수치 최종 승인
- [ ] 경직·기절·넘어짐·밀쳐내기 공통 지속시간
- [ ] 출혈·독·화상 중첩 규칙 최종값
- [ ] 보스 군중 제어 저항
- [ ] 첫 비행 베일종과 대공 대응 세트

## 전술 명령·보스 — 확정

- [x] 바리케이드·화살비·역병·강화지대
- [x] 발동마다 금화 지불
- [x] 전역 쿨다운 없음, 명령별 개별 쿨다운
- [x] 일시정지 중 정상 사용·확정, 시간 진행은 정지
- [x] 보스 가로축 직선 돌파와 세로축 크게 베기
- [x] 전조 뒤 공격 범위는 목표를 계속 추적하지 않음

미확정:

- [ ] 명령별 비용·개별 쿨다운 최종값
- [ ] 바리케이드 체력·지속시간
- [ ] 화살비·역병·강화지대 수치
- [ ] 보스 패턴 피해·범위·시전시간·쿨다운
