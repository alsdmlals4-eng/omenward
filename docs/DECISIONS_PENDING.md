# 미확정 결정 목록

Codex는 아래 항목을 승인 없이 임의 확정하지 않는다.

## 확정됨

- [x] 개발 엔진: **Godot**
- [x] 기본 스크립트 언어: **GDScript**
- [x] 공용 작업 규칙 참고: `alsdmlals4-eng/Base`
- [x] Godot 프로젝트 구조 참고: `alsdmlals4-eng/urban-legend`
- [x] 코드 작업 전 Codex Plan Mode 제안서와 사용자 승인 필수
- [x] 우선 플랫폼과 입력: **Windows PC, 마우스·키보드**
- [x] 첫 프로토타입 기본 모드: **싱글플레이 PvE**
- [x] 정규 스테이지 목표 시간: 평균 **25~35분**
- [x] 핵심 수직 슬라이스 목표 시간: **10~15분**
- [x] 첫 공개 프로토타입 총 플레이 분량: 여러 스테이지로 구성된 **약 3시간**
- [x] 시작 상태, 첫 60초, 일시정지·2배속, 승패·재도전 기본 계약: `docs/design/APPROVED_MATCH_STRUCTURE.md`
- [x] 첫 프로토타입에 **절차적 스테이지 생성기** 포함
- [x] 튜토리얼은 절차적으로 생성하지 않는 **10~15분짜리 단일 수동 설계 스테이지**
- [x] 정규 스테이지는 난이도 증가, 맵 변형, 특수 적 순차 등장으로 구성
- [x] 튜토리얼 완료 후 플레이어 선택형 **제약 시스템** 해금
- [x] 제약은 숨은 동적 난이도가 아니라 시작 전에 효과가 공개되는 선택형 규칙
- [x] 수직 슬라이스 필수 UX: 확률 미리보기, 토큰 장부, 3단계 전조, 상성·사거리 오버레이, 라인별 원인 보고, 건설 비교 UI
- [x] MVP 건물 티어: **고정형 3티어 성장**
- [x] 일반 난이도 적 웨이브: 라인·병종·**정확한 수량 공개**
- [x] 전방 생산시설 보상: 추가 생산 보너스 없이 짧은 전선 합류 거리만 제공

### 승인된 룰렛 핵심

- [x] 기본 판정 줄은 **가운데 가로줄**로 고정하며 아이템 효과로만 변경
- [x] 판정 줄의 세 칸이 동일한 비-X 심벌일 때만 보상
- [x] 혼합 심벌과 동일 심벌 1~2개는 보상 없음
- [x] 판정 심벌 완성 줄 1개는 1성 병사, 2개는 엘리트, 3~7개는 영웅
- [x] 유닛 심벌 9칸 전체 동일은 전설
- [x] 전설은 한 스테이지/한 판 전체에서 병종과 관계없이 1회만 소환
- [x] 전설 사용 뒤 9칸 동일 결과는 해당 병종 영웅 2명으로 변환
- [x] 금화 완성 줄 1개 75%, 2개 200%, 3개 이상 500% 환급
- [x] 럭키 찬스: 12% 시작, 실패당 +8%p, 6회 실패 뒤 다음 회전 확정
- [x] `행운` 아이템이 럭키 찬스 초기 확률을 상승
- [x] 자연 럭키 찬스와 이동권 동시 사용 가능
- [x] 회전당 이동 횟수 제한 없음. 보유 이동권 수로만 제한

## Phase 0에서 즉시 결정 필요

- [ ] Godot 정확한 stable 버전
- [ ] 2D 픽셀아트, 2.5D 또는 로우폴리 방향
- [ ] 기본 해상도와 화면 비율
- [ ] 첫 프로토타입의 최대 동시 유닛 수 목표
- [ ] 자동 테스트 도구와 headless 실행 명령

## 프로토타입 캠페인과 절차적 생성기

- [x] 약 3시간을 짧은 수동 설계 튜토리얼 1개와 정규 스테이지 여러 개로 구성
- [x] 튜토리얼은 10~15분 안에 핵심 기능을 한 번씩 소개하고 생성기 대상에서 제외
- [x] 정규 스테이지는 난이도, 맵, 특수 적을 점차 확장
- [x] 플레이 기록에 따른 숨은 동적 난이도 제외
- [ ] 정규 스테이지 정확한 개수와 목표 시간 배분
- [ ] 정적·시드 기반 결정론적 생성 방식 최종 승인
- [ ] 쉬움·보통·어려움 3단계 Difficulty Profile
- [ ] Map Template 변형 가능 범위
- [ ] Stage Archetype, Enemy Build Archetype, Wave Pattern Card 구성
- [ ] Threat Budget 계산과 축별 상한
- [ ] StageManifest 데이터 계약
- [ ] 자동 Validator와 안전 스테이지 대체 규칙
- [ ] 같은 시드·새 시드 재도전 방식
- [ ] 생성기 개발자 확인 화면의 프로토타입 포함 여부

## 제약 시스템

- [x] 제약은 튜토리얼 완료 후 정규 스테이지에서 선택
- [x] 제약 효과와 보상은 시작 전에 공개
- [x] 기본 난이도와 제약은 별도 축으로 관리
- [ ] 정규 스테이지 첫 도전의 최대 제약 점수
- [ ] 첫 클리어·어려움 클리어 후 제약 점수 상한 확장 방식
- [ ] 초기 제약 수량과 카테고리별 목록
- [ ] 정보 숨김, 일시정지 금지, 철인 모드의 프로토타입 제외 여부
- [ ] 점수·메달·기록 중심 보상과 영구 전투력 보상 제외 여부
- [ ] 불공정 조합 선택 차단과 이유 표시 방식
- [ ] 제약 효과를 포함한 StageManifest와 Validator 계약

## 룰렛 세부

- [ ] 판정 줄 변경 아이템의 형태·지속시간·소비 여부
- [ ] 행운 아이템 1개당 초기 확률 증가량과 중첩 상한
- [ ] 대기칸 기본 용량과 결과 보관함 최종 UI
- [ ] 수동·자동 유닛 합성의 프로토타입 포함 여부
- [ ] 이동권 보유 상한, 가격과 상점 출현 빈도
- [ ] 전설 유닛의 영웅 대비 전투력과 스킬 관계
- [ ] 금화 200%·500%를 유지하면서 무한 회전을 막을 안전장치

### 금화 안전장치 후보

- [ ] 금화와 별개의 시간 기반 회전 충전
- [ ] 금화 고배율 보상 재사용 대기시간 또는 웨이브당 횟수 제한
- [ ] 금화 보상 기준액과 실제 회전 비용 분리
- [ ] 동일 금화 연속 보상 감쇠

현재 추천은 **시간 기반 회전 충전 + 금화 비용**이다.
