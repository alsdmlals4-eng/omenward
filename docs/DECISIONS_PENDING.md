- [x] 개발 엔진: **Godot**
- [x] 기본 스크립트 언어: **GDScript**
- [x] 공용 작업 규칙 참고: `alsdmlals4-eng/Base`

- [x] 우선 플랫폼과 입력: **Windows PC, 마우스·키보드**
- [x] 첫 프로토타입 기본 모드: **싱글플레이 PvE**
- [x] 정규 스테이지 목표 시간: 평균 **25~35분**
- [x] 핵심 수직 슬라이스 목표 시간: **10~15분**
- [x] 첫 공개 프로토타입 총 플레이 분량: 여러 스테이지로 구성된 **약 3시간**
- [x] 첫 프로토타입에 **절차적 스테이지 생성기** 포함
- [x] 튜토리얼은 절차적으로 생성하지 않는 **10~15분짜리 단일 수동 설계 스테이지**
- [x] 정규 스테이지는 난이도 증가, 맵 변형, 특수 적 순차 등장으로 구성
- [x] 튜토리얼 완료 후 플레이어 선택형 **제약 시스템** 해금
- [x] 제약은 시작 전에 효과가 공개되는 선택형 규칙
- [x] 수직 슬라이스 필수 UX 6개
- [x] 일반 난이도 적 웨이브: 라인·병종·정확한 수량 공개
- [x] 전방 생산시설 보상: 추가 생산 보너스 없이 짧은 전선 합류 거리만 제공

### 승인된 룰렛 핵심

- [x] 기본 판정 줄은 가운데 가로줄이며 아이템으로만 변경
- [x] 판정 줄의 세 칸이 동일한 비-X 심벌일 때만 보상
- [x] 혼합 심벌과 동일 심벌 1~2개는 보상 없음
- [x] 완성 줄 1/2/3~7/8개는 각각 1성 병사/엘리트/영웅/전설
- [x] 전설은 한 판당 1회이며 이후 9칸 동일은 해당 병종 영웅 2명
- [x] 금화 완성 줄 1/2/3개 이상은 회전 비용의 75%/200%/500%
- [x] 시장 특화의 고배율 금화 보상을 유지
- [x] 시간 기반 회전 충전, 웨이브당 제한, 연속 감쇠는 사용하지 않음
- [x] 럭키 찬스 12% 시작, 실패당 +8%p, 6회 실패 뒤 다음 회전 확정
- [x] 행운 아이템이 럭키 찬스 초기 확률을 상승
- [x] 자연 럭키 찬스와 이동권 동시 사용 가능
- [x] 회전당 이동 횟수 제한 없음

### 승인된 경제·장기전 방향

- [x] 시장 다수 건설은 정식 빌드
- [x] 시장+포탑+상점 용병 조합을 정식 전략으로 허용
- [x] 용병 구매는 룰렛 토큰을 추가하지 않고 출전 시 식량 사용
- [x] 강제 시간패 대신 공개된 결전 웨이브 타이머 사용
- [x] 기본 초기 가설은 35분에 초강력 결전 웨이브 출격
- [x] 결전 웨이브 전에 적 생산시설을 파괴하면 해당 증원량 감소
- [x] 결전 웨이브 방어 뒤에도 적 본진이 남으면 강화 웨이브 반복 가능

### 승인된 건물·전문화 방향

- [x] 적이 건설 노드 주변에 있어도 새 건설·업그레이드 시작 가능
- [x] 피격 중에도 건설·업그레이드 진행도 유지
- [x] 건설 중 구조물은 공격받고 완공 전에 파괴될 수 있음
- [x] 3티어 유지: Tier 1 공통 기능 → Tier 2 전문화 → Tier 3 심화·교리
- [x] 기존 완전 고정형 3티어 결정은 선택형 전문화 구조로 대체
- [x] 토큰 증폭은 대응 토큰 1개를 결정론적으로 선택된 릴 하나에만 추가
- [x] 토큰 증폭 대상 릴은 건물 수명 동안 고정되고 UI에 공개
- [x] 생산시설은 해당 시설에서 생산되는 유닛에 버프를 부여하는 전문화 가능
- [x] 기본 병영 Tier 1은 검사 생산·검사 토큰
- [x] 기본 병영 Tier 2는 기병·창병·궁병 중 하나를 선택
- [x] 병영 전문화 완료 시 생산 병종과 세 릴 기본 토큰이 선택 병종으로 변경
- [x] 기존 생산 유닛은 병영 전문화로 소급 변경되지 않음
- [x] 포탑은 제압형·요새형·장거리형 전문화 방향을 가질 수 있음

### 승인된 전술 명령 방향

## 건물 Tier·생명주기·전문화

상위 제안은 `docs/design/proposals/0005-building-tiers-lifecycle-and-economy.md`, 현재 세부 추천은 `docs/design/notes/0005a-construction-durability-and-doctrine-recommendation.md`에서 검토한다.

현재 추천:

- 건설 시작 체력: 완공 최대 체력의 25%
- 진행도 증가로 추가되는 최대 체력을 현재 체력에도 더하고 누적 피해 절대값 보존
- 동일 틱 처리: 건설·완공 → 기능 활성화 → 공격 피해
- 일반 건물은 라인 하드 길막 없음, 바리케이드만 적 이동 차단
- 같은 Tier 전문화는 동일 비용·동일 시간
- 포탑·시장·농장은 Tier 2 방향을 Tier 3에서 고정 심화
- 병영은 Tier 2 병종 선택 뒤 Tier 3 대량생산·정예훈련·토큰 증폭 중 선택
- 시장 추천: 금고시장·군수시장·행운시장
- 농장 추천: 대농장·보급소·비축창고

미확정:

- [ ] 건설 중 시작 체력과 진행도별 체력 곡선 최종 승인
- [ ] 건설 중 구조물의 길막·충돌 규칙 최종 승인
- [ ] 후방 안전 노드의 포탑 건설 금지 여부
- [ ] 업그레이드 중 이전 Tier 기능과 룰렛 토큰 유지 최종 승인
- [ ] Tier 2 전문화 동일 비용·시간 승인
- [ ] Tier 3의 고정 심화와 병영 교리 예외 구조
- [ ] 병영 Tier 3 대량생산 -25%, 정예훈련 체력 +15%·피해 +10%, 토큰 +1 초기값
- [ ] 금고·군수·행운시장 효과와 군수시장 할인 상한 24%
- [ ] 대농장·보급소·비축창고 효과
- [ ] 제압·요새·장거리 포탑 초기 수치
- [ ] 건설 취소 70%, 업그레이드 취소 50% 환불
- [ ] 완공 건물 철거: 5초, 기본 건설비 40% 환불
- [ ] 전방 시설 파괴 후 폐허 기본 15초

- [ ] Tier 1 비용과 Tier 2·3 비용 곡선
