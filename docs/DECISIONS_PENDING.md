# 미확정 결정 목록

Codex는 아래 항목을 승인 없이 임의 확정하지 않는다.

## 확정됨

- [x] 개발 엔진: **Godot**
- [x] 기본 스크립트 언어: **GDScript**
- [x] 공용 작업 규칙 참고: `alsdmlals4-eng/Base`
- [x] Godot 프로젝트 구조 참고: `alsdmlals4-eng/urban-legend`
- [x] 코드 작업 전 Codex Plan Mode 제안서와 사용자 승인 필수
- [x] 우선 플랫폼과 입력: **Windows PC, 마우스·키보드**
- [x] 첫 프로토타입 기본 모드: **싱글플레이 PvE**
- [x] 정규 스테이지 목표 시간: 평균 **25~35분**
- [x] 핵심 수직 슬라이스 목표 시간: **10~15분**
- [x] 첫 공개 프로토타입 총 플레이 분량: 여러 스테이지로 구성된 **약 3시간**
- [x] 시작 상태, 첫 60초, 일시정지·2배속, 승패·재도전 기본 계약: `docs/design/APPROVED_MATCH_STRUCTURE.md`
- [x] 첫 프로토타입에 **절차적 스테이지 생성기** 포함
- [x] 수직 슬라이스 필수 UX: 확률 미리보기, 토큰 장부, 3단계 전조, 상성·사거리 오버레이, 라인별 원인 보고, 건설 비교 UI
- [x] MVP 건물 티어: **고정형 3티어 성장**. 선택형 분기는 후속 실험
- [x] 일반 난이도 적 웨이브: 라인·병종·**정확한 수량 공개**
- [x] 럭키 찬스 구조: 기본 확률 + 실패 누적 보정
- [x] 전방 생산시설 보상: 추가 생산 보너스 없이 짧은 전선 합류 거리만 제공

상세 근거:

- `docs/design/APPROVED_MATCH_STRUCTURE.md`
- `docs/design/APPROVED_BENCHMARK_DECISIONS.md`

## Phase 0에서 즉시 결정 필요

- [ ] Godot 정확한 minor 버전: urban-legend와 동일한 4.7 stable 사용 여부
- [ ] 2D 픽셀아트, 2.5D 또는 로우폴리 방향
- [ ] 기본 해상도와 화면 비율
- [ ] 첫 프로토타입의 최대 동시 유닛 수 목표
- [ ] 자동 테스트 도구와 headless 실행 명령

## 프로토타입 캠페인과 절차적 스테이지 생성기

방향은 확정됐지만 세부 계약은 `docs/design/proposals/0002-prototype-campaign-and-stage-generator.md`에서 검토한다.

- [ ] 약 3시간을 6개 안팎의 선형 스테이지로 구성할지
- [ ] 정적·시드 기반 결정론적 생성 방식 승인
- [ ] 쉬움·보통·어려움 3단계 Difficulty Profile
- [ ] Map Template의 변형 가능 범위
- [ ] Stage Archetype, Enemy Build Archetype, Wave Pattern Card 구성
- [ ] Threat Budget 계산과 축별 상한
- [ ] StageManifest 데이터 계약
- [ ] 자동 Validator와 안전 스테이지 대체 규칙
- [ ] 같은 시드·새 시드 재도전 방식
- [ ] 플레이 기록에 따른 숨은 동적 난이도 제외 여부
- [ ] 생성기 개발자 확인 화면의 프로토타입 포함 여부

## 룰렛

- [ ] 서로 다른 3개 심벌이 나온 경우 각각 1성 보상을 모두 주는지
- [ ] 한 회전에 여러 병종을 동시에 획득할 때 식량·대기칸 밸런스
- [ ] 기준 줄을 회전 전 선택하는지, 회전 후 선택하는지
- [ ] 럭키 찬스의 기본 확률, 실패당 증가량, 확정 상한과 이동권 가격
- [ ] 전설·신화 등급의 정확한 빙고 조건
- [ ] 금화 토큰 기대값과 연속 회전 비용
- [ ] 대기칸이 가득 찼을 때 보상 처리

## 건물

- [ ] 건물별 Tier 1~3의 정확한 기능과 비용 곡선
- [ ] 전방 시설 파괴 후 폐허 유지 시간
- [ ] 시설 수리 기능의 MVP 포함 여부
- [ ] 철거 가능 여부와 환불률
- [ ] 고티어 포탑이 접전지에 닿는 정확한 업그레이드 단계
- [ ] 포탑 종류와 시설 우선 타기팅 규칙

## 전투

- [ ] 유닛 충돌과 라인 폭
- [ ] 맵 단위, 기본 사거리와 이동 단위
- [ ] 유닛이 건물을 공격하는 우선순위
- [ ] 후퇴 또는 라인 변경 가능 여부
- [ ] 영웅과 별 단계의 능력치 결합 방식
- [ ] 타깃 변경, 적 통과와 밀집 처리

## 접전지와 경제

- [ ] 점령·중립화 시간
- [ ] 접전 중 기존 소유자의 금화 수입 정지 여부 최종 승인
- [ ] 접전지 수입의 시장 대비 목표 비율
- [ ] 뒤처진 플레이어의 복구 수단과 스노우볼 안전장치

## 적 웨이브

- [ ] 정규 웨이브 간격
- [ ] T-10초 구성 확정안 승인
- [ ] 접전지 소유가 웨이브에 추가 전투 보너스를 주는지
- [ ] 적의 건설 및 티어 상승 규칙을 실제로 시뮬레이션할지 데이터 스케줄로 처리할지
- [ ] 확정 전 적 건물 파괴가 현재 웨이브를 줄이는 정확한 계산
