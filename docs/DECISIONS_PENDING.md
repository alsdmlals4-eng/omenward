- 안내자 벨루.

## 2. 전장·점령·암살자 우회로

구조 확정:

- 좌우 대칭의 독립 상·중·하 3라인.
- 라인별 순서: `본진 → 성문 → 중간거점 → 중앙 접전지 → 적 중간거점 → 적 성문 → 적 본진`.
- 라인 간 횡단로와 기본 라인 변경 없음.
- 중앙 접전지는 해당 라인의 앞뒤 길에만 연결하며 건설 불가.
- 각 중간거점은 전방 노드 2개와 후방 노드 1개를 보유.
- 중간거점 점령 시 건설권과 거점 기본 생산권이 점령 진영으로 이전.
- 암살자는 적 후방에 직접 배치하지 않고 같은 라인의 우회로로 침투.
- 우회로는 평상시 안개로 가리고 암살자 선택·배치 중에만 표시.
- 전장 전체를 기본 화면에서 조망하므로 별도 미니맵 사용 안 함.
- 건물은 도로를 막지 않으며 성문과 중간거점 전방 길을 넓게 확보.

첫 PoC 가설로 조정 가능:

- [ ] 중간거점 점령 시간과 병종별 점령 가중치.
- [ ] 중간거점 기본 자원 생산량과 생산 주기.
- [ ] 점령 시 기존 건물의 정지·파괴·회수·소유권 처리.
- [ ] 성문 HP·방어·공성 배율·재건 가능 여부.
- [ ] 암살자 우회 이동 시간과 도착 범위.
- [ ] 적 암살자 탐지·경고·대응 시설 규칙.
- [ ] 우회 중 피격·중단·후퇴 가능 여부.
- [ ] 주 도로 200~240, 중간거점·성문 전방 240~320 world units 최종 폭.
- [ ] 라인별 실제 이동 거리와 상·하단 보정.

## 3. 공통 전투·등급

구조 확정:

- 물리·마법·고정 피해.
- 방어·저항·치명타·후방·범위 감쇠 계산 순서.
- 일반·엘리트·영웅·전설 4등급과 적군 전용 신화.
- 보스 제어 감소·연속 제어 면역.
- Tier와 등급 분리.

첫 PoC 가설로 조정 가능:

- [ ] 방어 공식과 75% 감소 상한.
- [ ] 기본 치명타 5%, 피해 150%, 후방 +25%.
- [ ] 공격속도·이동속도 버프/감소 상한.
- [ ] 일반/엘리트/영웅/전설 HP·피해·Threat 배율.
- [ ] 상태이상 지속시간과 보스 적용률.
- [ ] 타깃 변경 임계값과 재탐색 주기.

## 4. 플레이어 10병종

확정:

```text
기본 병영 6종
방패병 / 대검전사 / 암살자 / 창병 / 궁병 / 기병

특수병단 4종
사제 / 마법사 / 비행병 / 거인
```

- 암살자는 같은 라인의 우회로 침투 병종.
- 기본 병영과 특수병단 모두 Tier 2부터 선택 병종 토큰·일반 자동생산 제공.
- 특수병단 Tier 1은 준비 할인 시설.
- 플레이어 신화급 없음.

첫 PoC 가설로 조정 가능:

- [ ] 10병종 절대 HP·공격·방어·사거리·이동·쿨다운.
- [ ] 기본 병영 생산시간 115~150초 구간.
- [ ] 특수병단 생산시간: 사제 180, 마법사 210, 비행병 240, 거인 300초.
- [ ] 식량: 기본 보병 2, 기병·사제·마법사 3, 비행 4, 거인 6.
- [ ] Tier 3 최종 이름과 역할 수치.
- [ ] 계열별 엘리트·영웅·전설 최종 이름·외형·능력.
- [ ] 대량생산·정예훈련·토큰 증폭 최종 수치.

## 5. 특수병단·건물

확정:

- Tier 1 특수병단 금화 40, 건설 25초 첫 기준.
- 완공 뒤 30초마다 Tier 2 비용 -10%, 150초에 최대 -50%.
- 사제단·마도단·비행단·거인단.
- Tier 2 완료부터 특수 토큰과 일반 자동생산.
- 자동생산은 일반 등급만 생성.
- 중간거점 건설 노드는 전방 2·후방 1 배치.

첫 PoC 가설로 조정 가능:

- [ ] 특수병단 Tier 2 비용 60/70/80/100과 시간 30/35/40/45초.
- [ ] 특수병단 Tier 3 비용·시간과 분기.
- [ ] 준비도·할인·자동생산 최종 UI.
- [ ] 기본 병영 Tier 3 비용 75/90과 시간 40/50초.
- [ ] 농장·시장·포탑 Tier 2·3 효과·비용.
- [ ] 건설 중 체력 곡선과 폐허 처리.
- [ ] 거점 점령 중 건물 작동 제한.

## 6. 경제·룰렛

확정 구조:

- 정규 시작 금화 160, 식량 12 첫 기준.
- 기본 수입 20초마다 +5.
- 중앙 접전지 한 곳당 60초마다 +4.
- 중간거점 소유 진영에 기본 생산 제공, 점령 시 생산권 이전.
- 적 처치·웨이브 클리어 고정 금화 없음.
- 기본 룰렛 비용 20.
- 금화 1/2/3줄 이상은 75%/200%/500%.
- 럭키 12%, 실패당 +8%p, 6회 실패 뒤 확정.
- 전설 1회 제한.

첫 PoC 가설로 조정 가능:

- [ ] 중간거점 기본 생산과 중앙 접전지 수입의 비중.
- [ ] 릴 기본 X·금화·이동권 가중치.
- [ ] 기본 병영 +3, 특수병단 +2 토큰 가중치.
- [ ] 자연 일반·엘리트·영웅·전설 목표 확률.
- [ ] 금화 장기 평균 지급 회전비 30% 이하 검증.
- [ ] 이동권 가격·보유 상한·상점 출현률.
- [ ] 결과 보관함 3칸 최종 UX.
- [ ] 시장 수입과 다중 시장 비용 증가.
- [ ] 난이도별 시작 금화·수입 배율.

## 7. 적군·웨이브·보스

확정:

- 아군 10병종과 대응하는 적군 10병종 구조.
- 같은 계열·Tier·등급 예산 ±10%에서 시작.
- 60초 충돌 시계.
- 5 엘리트, 10 영웅, 15 전설 보스, 20 신화 보스.
- 15 보스 처치 표준 승리, 적 본진 조기 승리.
- 16~19 초과 공세.

첫 PoC 가설로 조정 가능:

- [ ] W1~15 Threat 6~85 곡선.
- [ ] W16~20 Threat 100~250 곡선.
- [ ] 웨이브별 실제 병종 수량·라인 배분.
- [ ] 적 생산시설 파괴 시 현재 -30%, 다음 -50%, 이후 -20% 감소 규칙.

- [ ] 20 신화 보스 Threat 55와 2페이즈 수치.
- [ ] 적군 10병종 최종 AI·스킬·외형.
