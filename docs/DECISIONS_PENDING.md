# 미확정 결정 목록

Codex는 아래 항목을 승인 없이 임의 확정하지 않는다.

## 확정됨

- [x] 개발 엔진: **Godot**
- [x] 기본 스크립트 언어: **GDScript**
- [x] 공용 작업 규칙 참고: `alsdmlals4-eng/Base`
- [x] Godot 프로젝트 구조 참고: `alsdmlals4-eng/urban-legend`
- [x] 코드 작업 전 Codex Plan Mode 제안서와 사용자 승인 필수
- [x] 우선 플랫폼과 입력: **Windows PC, 마우스·키보드**
- [x] 첫 프로토타입 기본 모드: **싱글플레이 PvE**
- [x] 정규 스테이지 목표 시간: 평균 **25~35분**
- [x] 핵심 수직 슬라이스 목표 시간: **10~15분**
- [x] 첫 공개 프로토타입 총 플레이 분량: 여러 스테이지로 구성된 **약 3시간**
- [x] 첫 프로토타입에 **절차적 스테이지 생성기** 포함
- [x] 튜토리얼은 절차적으로 생성하지 않는 **10~15분짜리 단일 수동 설계 스테이지**
- [x] 첫 10분은 시스템당 10~30초 학습 단위로 구성
- [x] 첫 10분에 약 8개의 핵심 시스템을 순차적으로 학습 가능
- [x] 플레이어는 괴물 군단을 막는 최전선 지휘관
- [x] 적은 정체불명의 `경계의 율`에 따라 웨이브로 경계를 넘음
- [x] 공세 전 징조와 전장 조건에 따른 축복·저주가 존재
- [x] 경계의 율 기원과 목적은 초반에 암시만 하고 직접 설명하지 않음
- [x] 룰렛·토큰은 물리적 마법 소환 장치로 강제 설명하지 않음
- [x] 플레이어 UI의 룰렛·토큰을 세계관에서는 전술판·증원 경로 정도로 가볍게 번역

### 승인된 룰렛 핵심

- [x] 기본 판정 줄은 가운데 가로줄이며 아이템으로만 변경
- [x] 판정 줄의 세 칸이 동일한 비-X 심벌일 때만 보상
- [x] 혼합 심벌과 동일 심벌 1~2개는 보상 없음
- [x] 완성 줄 1/2/3~7/8개는 각각 일반 병사/엘리트/영웅/전설
- [x] 유닛 등급은 룰렛 결과 확정 시점에 직접 생성
- [x] 수동 합성·처치 경험치·건물 Tier로 유닛 등급 상승 없음
- [x] 병영 자동 생산은 기본적으로 일반 등급
- [x] 병영 정예훈련은 상위 등급 생성이 아닌 생산 유닛 영구 능력치 버프
- [x] 상점의 상위 등급 용병 직접 판매는 현재 승인 범위에서 제외
- [x] 전설은 한 판당 1회이며 이후 9칸 동일은 해당 병종 영웅 2명
- [x] 금화 완성 줄 1/2/3개 이상은 회전 비용의 75%/200%/500%
- [x] 시장 특화의 고배율 금화 보상을 유지
- [x] 시간 기반 회전 충전, 웨이브당 제한, 연속 감쇠는 사용하지 않음
- [x] 럭키 찬스 12% 시작, 실패당 +8%p, 6회 실패 뒤 다음 회전 확정
- [x] 행운 아이템이 럭키 찬스 초기 확률을 상승
- [x] 자연 럭키 찬스와 이동권 동시 사용 가능
- [x] 회전당 이동 횟수 제한 없음

### 승인된 유닛 능력 성장

- [x] 병영 Tier 1: 패시브 1 기본형
- [x] 병영 Tier 2: 패시브 1 강화 + 패시브 2 생성
- [x] 병영 Tier 3: 패시브 1 추가 강화 + 패시브 2 강화 + 패시브 3 생성
- [x] 일반: 1스킬 기본형
- [x] 엘리트: 1스킬 강화
- [x] 영웅: 강화된 1스킬 + 2스킬 생성
- [x] 전설: 영웅 효과 + 2스킬 강화 + 3스킬 생성
- [x] 생산시설 능력치 버프는 유닛 등급과 분리

### 승인된 전사 계열

- [x] Tier 1 검사와 Tier 2 이상 전사 계열은 전사 토큰 공유
- [x] Tier 2 전사 병종: 방패병·대검병·광전사
- [x] 방패병: 수비 숙련·방패 방어·방패 밀치기
- [x] 대검병: 중량 무기 숙련·파갑·대회전 베기
- [x] 광전사: 광전 본능·피의 갈증·광란 연격
- [x] Tier 2 일반 병종 고유 1스킬은 상위 등급 고정 전사에게 자동 승계되지 않음

### 승인된 건물·전문화 방향

- [x] 적이 건설 노드 주변에 있어도 새 건설·업그레이드 시작 가능
- [x] 피격 중에도 건설·업그레이드 진행도 유지
- [x] 건설 중 구조물은 공격받고 완공 전에 파괴될 수 있음
- [x] Tier 1 공통 기능 → Tier 2 전문화 → Tier 3 심화·교리
- [x] Tier 3 병영은 상위 세부 병종 1개와 운영 교리 1개 선택
- [x] 기병 Tier 3: 중기병·충격기병
- [x] 궁병 Tier 3: 석궁병·대공궁병·연사궁병
- [x] 같은 계열 Tier 2·3 병영은 같은 룰렛 토큰 공유
- [x] 토큰 원장은 출처 병영·Tier·실제 병종·패시브 단계를 보존
- [x] 생산시설 강화는 유닛 등급을 바꾸지 않음

### 승인된 전술 명령·일시정지 방향

- [x] 금화를 소비하는 바리케이드·화살비·역병·강화지대
- [x] 해금된 명령은 HUD에서 사용하고 발동마다 금화 직접 결제
- [x] 전역 쿨다운 없음
- [x] 명령별 개별 쿨다운 유지
- [x] 일시정지는 전투 시간만 멈추는 계획 모드
- [x] 일시정지 중 룰렛·건설·전술 명령·유닛 배치·상점 조작 가능
- [x] 일시정지 중 이동·공격·생산·건설·시전·지속시간·쿨다운·웨이브 타이머 정지

### 승인된 전투·비행 방향

- [x] 물리·마법·고정 피해, 치명타, 후방, 돌진과 군중 제어 공통 규칙
- [x] 모든 유닛은 지상 또는 비행 레이어 보유
- [x] 비행은 지상 충돌·바리케이드·지상 함정을 우회
- [x] 비행은 기본적으로 접전지 점령에 기여하지 않음
- [x] 공격은 `target_layers` 명시
- [x] 대공·급강하·지상화 태그 사용
