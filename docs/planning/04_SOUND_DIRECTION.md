## 0. 10분 콜드 스타트 요약

오멘워드의 사운드는 밝은 왕국 판타지와 다가오는 공세의 불안을 동시에 전달한다. 음악은 웨이브가 임박할수록 층이 더해지고, SFX는 화면을 보지 않아도 룰렛 결과·건설·공격 전조·거점 변화의 우선순위를 구분하게 해야 한다. 벨루는 명랑하지만 과잉 수다스럽지 않은 길잡이다.

| 구분 | 현재 상태 |
|---|---|
| BGM 단계 구조 | 확정 |
| 이벤트별 SFX 역할 | 확정 |
| 벨루 음성 성격·반복 규칙 | 확정 |
| 최종 음원 파일·길이·BPM·라우드니스 | 미정 |

## 1. 사운드 약속

- 전장 상태를 먼저 알리고 장식은 그다음에 둔다.
- 아군은 맑은 금속·목재·빛 계열, 베일 세력은 둔탁한 금속·왜곡·저역 계열로 구분하되 같은 병종의 규칙을 바꾸지 않는다.
- 전조음과 실제 판정음의 순서를 유지해 회피·대응 가능성을 보장한다.
- 장시간 반복되는 기본 공격음은 변형 샘플과 미세 피치·볼륨 변화를 사용한다.
- 확정되지 않은 BPM, 음량 수치, 제작비와 성우 비용을 임의로 만들지 않는다.

## 2. BGM 구조

| 구간 | 음악 역할 | 필수 신호 |
|---|---|---|
| 건설·준비 | 낮은 현악·가벼운 타악·맑은 종으로 판단 여백 제공 | 다음 공세 예고를 가리지 않음 |
| 공세 30초 전 | 리듬 또는 저역 층을 한 단계 추가 | 긴장 상승을 즉시 인식 |
| 공세 5초 전 | 짧고 분명한 종·맥박 신호 | 벨루 경고와 충돌하지 않음 |
| 일반 전투 | 주력군 충돌을 받치되 기본 공격 SFX를 덮지 않음 | 위협 전조가 항상 우선 |
| W5·W10·W15·W20 | 단계별 밀도·악기층 상승 | 같은 곡의 단순 볼륨 증가로 처리하지 않음 |
| 승리·패배 | 결과를 짧고 명료하게 확정 | UI 결과 표시와 동기화 |

곡 수, BPM, 조성, 루프 길이는 실제 플레이 시간과 제작 여건을 확인한 뒤 확정한다.

## 3. 룰렛·UI SFX

- 룰렛 시작은 가볍고 빠른 기계·마법 회전음으로 기대를 만든다.
- 칸 통과음은 연속 재생 시 피로하지 않아야 하며 속도 변화가 느껴져야 한다.
- 정지 전 감속을 소리로 예고하고 결과 등급별로 명료한 도착음을 둔다.
- 일반·고급 결과는 짧고 절제하며, 희귀·영웅·전설은 화음·잔향·상승음을 단계적으로 추가한다.
- 구매 가능, 자원 부족, 잘못된 배치, 잠금 상태는 서로 다른 짧은 피드백을 사용한다.
- 버튼 hover보다 선택·확정·취소의 행동 피드백을 우선한다.

## 4. 전투·병종 SFX

| 범주 | 방향 | 검증 포인트 |
|---|---|---|
| 근접 | 무기 재질과 타격 무게를 짧게 구분 | 다수 교전에서 뭉개지지 않음 |
| 원거리 | 발사와 명중을 분리 | 투사체 시간과 일치 |
| 마법·지원 | 맑은 에너지·종·숨결 계열 | 공격·회복·강화가 구분됨 |
| 거대·공성 | 준비 저역 뒤 강한 충격 | 판정 전에 전조가 들림 |
| 암살자 | 진입·위험·출현을 별도 신호화 | 후열 침투를 소리만으로도 인지 |
| 비행 | 가벼운 바람·날개 움직임 | 지상 발소리와 혼동하지 않음 |

아군과 적군은 음색을 달리할 수 있지만, 동일 아키타입의 공격 타이밍과 의미를 바꾸는 별도 규칙을 만들지 않는다.

## 5. 건물·거점·성문 SFX

- 건설 시작·진행 완료·생산 완료·업그레이드·파괴를 구분한다.
- 배치 불가와 자원 부족은 실패 원인을 혼동하지 않게 다르게 만든다.
- 중간거점의 중립화·점령·소유권 이전은 전장 전체에서 알아들을 수 있는 서명음을 사용한다.
- 성문 피해는 일반 건물 피해보다 무겁게, 위험 단계 상승은 반복 피로 없이 명료하게 알린다.
- 후방 건물 공격은 화면 밖에서도 대응할 수 있도록 경고 우선순위를 높인다.

## 6. 벨루 음성·보이스 가이드

- 공식 명칭은 **벨루/Bellu**다. `율비/Yulbi`는 외형 참고 이미지에 남은 폐기 표기이며 음성·대사에서 사용하지 않는다.
- 목소리는 맑고 따뜻한 중성적 요정 톤으로, 어린아이를 과장해 흉내 내지 않는다.
- 중요한 안내 앞에는 짧은 두 음의 종 서명을 사용한다.
- 화면에 정확한 수치가 있을 때 음성은 의미를 설명하고, 숫자 낭독은 꼭 필요한 경우에만 사용한다.
- 동일 문장을 60초 안에 반복하지 않는다. 연속 경고는 짧은 변형 또는 비언어 신호로 대체한다.
- 위험 경고, 튜토리얼, 축하, 생각, 걱정의 감정이 캐릭터 시트 표정과 일치해야 한다.

## 7. 이벤트 연결 계약

| 게임 이벤트 | 오디오 이벤트 | 우선순위 |
|---|---|---:|
| wave_warning_30 | BGM 레이어 상승 + 선택적 벨루 안내 | 높음 |
| wave_warning_5 | 종 서명 + 짧은 경고 | 매우 높음 |
| roulette_spin/start/stop/result | 회전·감속·결과 SFX | 중간~높음 |
| building_place/complete/destroy | 배치·완료·파괴 SFX | 높음 |
| outpost_neutral/captured | 거점 상태 서명음 | 매우 높음 |
| gate_damaged/critical | 성문 피해·위기 경고 | 매우 높음 |
| assassin_warning/appear | 침투 경고·출현 | 매우 높음 |
| attack_telegraph/contact/projectile | 전조·접촉·발사 | 전조 우선 |

실제 이벤트 이름은 구현 파일과 일치하게 확정하며, 사운드 코드가 전투 규칙을 중복 판정하지 않는다.

## 8. 믹싱·반복 방지·접근성

- 위험 경고와 벨루 핵심 안내가 BGM·기본 공격보다 우선하도록 덕킹한다.
- 동일 SFX의 동시 재생 수를 제한하고 가까운 사건과 높은 위협을 우선한다.
- BGM, SFX, 음성은 별도 볼륨 조절을 제공하는 것을 릴리스 게이트로 둔다.
- 청각 신호만으로 필수 정보를 독점하지 않고 시각 경고와 쌍으로 제공한다.
- 음성 자막과 핵심 환경음·위협 알림의 텍스트 대체를 검토한다.
- 최종 라우드니스와 포맷 수치는 실제 자산·플랫폼 테스트 전까지 `미정`이다.

## 9. 제작 상태와 다음 게이트

1. 이벤트 목록을 실제 Godot 신호·상태와 대조한다.
2. 임시 SFX로 우선순위와 동시 재생 정책을 검증한다.
3. BGM 단계 전환과 벨루 반복 방지 로그를 확인한다.
4. 최종 자산을 제작·권리 확인 후 안정 경로에 연결한다.
5. 자동 이벤트 검증과 수동 청취 QA를 [QA·PM 본책](05_QA_PM_PLAN.md)에 기록한다.

## 11. 완료 기준

- 모든 핵심 이벤트가 고유하고 일관된 청각 피드백을 가진다.
- 전조·판정·결과 순서가 실제 시뮬레이션과 일치한다.
- 장시간 교전에서 반복 피로와 동시 재생 과부하가 허용 범위에 있다.
- BGM·SFX·음성 볼륨, 자막·시각 대체 신호가 실제 빌드에서 검증된다.
- 최종 파일의 출처·권리·교체 상태가 문서화된다.
