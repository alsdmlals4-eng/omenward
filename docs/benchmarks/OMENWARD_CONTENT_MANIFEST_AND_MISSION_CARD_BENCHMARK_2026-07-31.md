## 1. 조사 질문

1. 30~40분 전략 런에서 미션이 핵심 루프를 방해하지 않고 선택을 강화하려면 어떻게 구성해야 하는가?
2. 버티컬 슬라이스가 모든 주요 시스템을 연결하면서도 콘텐츠 제작량을 통제하려면 무엇을 재사용해야 하는가?
3. 목표·보상·위험 정보는 언제, 어느 정도 공개해야 하는가?

## 2. 비교 대상

### 2.1 Into the Breach

- 공식 Steam 설명은 적 공격을 사전에 전조하고 대응을 분석하는 구조를 핵심으로 제시한다.
- 추가 콘텐츠 역시 적·보스뿐 아니라 `mission objectives`를 통해 상황 문제를 변형한다.

추출 원칙:

- 목표는 예고된 위협 정보와 충돌하지 않아야 한다.
- 미션은 숨은 함정이 아니라 공개된 전술적 기회비용이어야 한다.
- 목표 달성 여부가 전장에서 명확히 판독되어야 한다.

오멘워드 적용:

- 미션 카드에 대상 전선, 판정 시점, 실패 조건, 보상을 모두 표시한다.
- 미션 때문에 베일의 징조가 거짓이 되거나 숨은 적이 추가되지 않는다.

공식 자료:
- https://store.steampowered.com/app/590380/

### 2.2 Against the Storm

- 공식 Wiki의 Orders는 일정 구간마다 여러 후보 중 하나를 선택하고, 완료 시 평판·자원·주민·Perk 등을 보상한다.
- 일반 Orders와 고위험 Timed Orders는 구분되며, 튜토리얼에서는 Orders가 새 개념의 도입 순서를 안내한다.

추출 원칙:

- 목표 선택은 빌드 적응을 유도하되 강제 정답이 되어서는 안 된다.
- 후보와 보상을 비교한 뒤 커밋하게 한다.
- 시간 압박형 목표는 일반 목표와 별도 슬롯·규칙으로 분리해야 한다.
- 튜토리얼 목표는 시스템 학습을 요약하는 데 사용할 수 있다.

오멘워드 적용:

- 한 막에 한 번, 서로 다른 유형의 카드 2개를 제시하고 1개 선택 또는 거절을 허용한다.
- 첫 버티컬 슬라이스에서는 별도 초 단위 Timed Mission을 사용하지 않는다.
- 보상은 전부 사전 공개한다.

공식 자료:
- https://wiki.hoodedhorse.com/Against_the_Storm/Orders
- https://wiki.hoodedhorse.com/Against_the_Storm/Tutorial_Walkthrough

### 2.3 Thronefall

- 공식 Steam 설명은 낮의 건설·경제와 밤의 방어를 단순한 세션 구조로 결합한다.
- 여러 맵의 차이는 지형·날씨·적·건물·도전 변형으로 만들며, Perk와 선택적 Mutator가 반복성을 보강한다.

추출 원칙:

- 짧은 전략 세션은 화면과 규칙을 단순하게 유지하되 상황 조합으로 깊이를 만든다.
- 콘텐츠 폭은 독립 시스템을 계속 추가하는 방식보다 기존 요소의 조합과 변형으로 확보한다.
- 선택적 난이도 요소는 기본 경험과 분리한다.

오멘워드 적용:

- 한 개 전장을 4막 상태 변화로 재사용한다.
- 20개 스테이지는 20개의 독립 제작물이 아니라 재사용 가능한 공세·라인·위협 패키지 조합으로 구성한다.

공식 자료:
- https://store.steampowered.com/app/2239150/

### 2.4 Luck be a Landlord

- 공식 Steam 설명은 런마다 달라지는 심볼과 아이템, 그리고 심볼 간 상호작용을 빌드 전략의 핵심으로 제시한다.

추출 원칙:

- 확률 기반 게임의 콘텐츠 가치는 단순 항목 수보다 상호작용 가능한 풀의 질에서 나온다.
- 각 항목은 다른 항목과 조합될 때 새로운 판단을 만들어야 한다.

오멘워드 적용:

- 건물·TokenSource·릴 이동·병종·전선의 조합 가능성을 콘텐츠 Manifest의 핵심으로 삼는다.
- 미션 전용 화폐·별도 미니게임·평행 성장 시스템을 새로 만들지 않는다.

공식 자료:
- https://store.steampowered.com/app/1404850/

## 3. 비교 결론

### 유지할 원칙

1. 미션 선택과 보상 전체 사전 공개.
2. 선택 또는 거절 가능.
3. 한 번에 활성 미션 하나.
4. 미션은 핵심 루프 행동을 변주하며 별도 미니게임을 만들지 않음.
5. 콘텐츠는 공용 아키타입·규칙·상태 변형을 재사용.
6. 위험·시간 압박은 기본 미션과 구분.
7. 미션 실패의 기본 손실은 보상 상실뿐.
8. 스테이지 목표와 적 공세 정보가 서로 모순되지 않음.

### 피할 위험

- 카드 수를 채우기 위한 동의어 목표 양산.
- 보상에 숨은 무작위 결과 사용.
- 미션 때문에 비합리적인 플레이를 강요.
- 첫 10분에 미션 선택까지 추가해 정보 과밀 유발.
- 모든 스테이지에 고유 적·배경·규칙을 제작.
- 미션 전용 재화·전용 상점·전용 성장 트리 추가.
- 실패 시 직접 디버프나 본진 피해를 부과.

## 4. 오멘워드 설계에 미치는 영향

다음 설계안은 이 벤치마킹을 바탕으로 작성한다.

- 미션 선택은 1막 온보딩 종료 후 Stage 6·11·16 준비 단계에만 제시.
- 각 선택 시 서로 다른 카테고리 2장 중 1장 선택 또는 거절.
- 최소 풀은 `전선 / 설계 / 제약` 3카테고리로 구성.
- 보상은 기존 런 자원과 행동만 사용: 골드, 식량, 추가 무료 회전.
- 20스테이지는 공용 적 10병종, 공세 패턴, 라인 배분, Rank, 보스 패키지를 조합.
- 하나의 전장을 4막 시각·상태 변화로 재사용.
- 모든 시스템은 기능적으로 연결하되, 대표 구간과 대표 자산에 표현 품질을 집중.
