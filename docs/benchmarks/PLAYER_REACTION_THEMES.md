# 플레이어 반응 테마 요약

## 반복적으로 호평받은 요소

- 짧고 이해하기 쉬운 기본 규칙
- 조합과 대응에서 발생하는 깊이
- 적 행동과 전투 결과의 명확한 인과관계
- 제한된 공간이 만드는 경제·방어 타협
- 짧은 세션과 빠른 재시도
- 무작위 결과를 직접 설계하거나 보정할 수 있는 수단

## 반복적으로 불만이 발생한 요소

- 장르 혼합으로 인한 UI·규칙 과부하
- 원하는 빌드를 막는 통제 불가능한 RNG
- 강한 조합 완성 후 판단이 사라지는 반복 플레이
- 화려한 전투에서 패배 원인을 알 수 없는 문제
- 메타 성장이나 해금이 기본 재미를 늦게 여는 문제
- 확률과 슬롯 외형에서 발생하는 도박 이미지 및 등급 정책 위험

## Roulettebound 검증 질문

- 플레이어가 건물과 룰렛 확률의 연결을 즉시 이해하는가?
- 다음 웨이브를 보고 실제로 다른 건물·병종·라인 선택을 하는가?
- 포탑과 경제시설의 노드 경쟁이 의미 있는 고민을 만드는가?
- 패배 후 원인을 한 문장으로 설명할 수 있는가?
- 운이 나빴다고 느끼더라도 다음에 바꿀 수 있는 선택이 보이는가?
