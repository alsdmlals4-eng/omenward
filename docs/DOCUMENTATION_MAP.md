## 4. Decision 9 핵심

```text
BOTTOM_FUNCTIONS = ROULETTE / STORAGE / BUILD / TACTICAL_SKILL / BELU
SHOP_BUTTON = REMOVED
MAIN_HUD_RESOURCES = GOLD / MANA_STONE / DEPLOYED_TROOP_CAPACITY
MOVE_TICKET_DISPLAY = ROULETTE_PANEL_ONLY
MERCHANT = AFTER_STAGE_MAINTENANCE_ONLY
```

- 벨루는 우측 하단 초상과 상황 대사로만 사용한다.
- 이동권은 `보관 이동권 n/3`과 럭키 무료 이동으로 룰렛 안에서 표시한다.
- 토큰은 초당 공급되지 않으며 완공·활성 TokenSource가 릴에 결속한다.
- 보상 등급은 독립 확률표가 아니라 완성선 수로 판정한다.
- 룰렛 이동은 릴 또는 행 선택→미리보기→실행 순서다.

기본 건물:

```text
금고 / 농장 / 병영 / 방어탑 / 지휘소 / 마력탑
```

- 건물별 지속 유지비는 없다.
- 농장은 병력 한도를 확장한다.
- 지휘소는 현재 MapRun 전체 아군 병력 오라다.
- 마력탑은 전술스킬 자원인 마석의 수급·보유량을 강화한다.
