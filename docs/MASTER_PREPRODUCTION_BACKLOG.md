## 우선순위 원칙

1. 다른 시스템의 기준이 되는 경제·공통 전투 규칙을 먼저 고정한다.
2. 유닛 계보를 고정한 뒤 적군 대칭표와 웨이브를 만든다.
3. 웨이브와 경제가 고정된 뒤 캠페인·절차 생성·난이도를 만든다.
4. 아트는 역할·크기·전조 계약을 먼저 만들고 최종 시안은 수치와 화면 밀도 검증 뒤 확정한다.
5. 구현 가능성 검수는 매 패킷에서 수행하지만 구현은 전체 수직 슬라이스 Plan Mode 승인 뒤 시작한다.

# 트랙 A — 핵심 기획

## A01. 전체 경제 기준표

- 상태: `[~] CHATGPT_DRAFT`
- 목적: 시작 금화, 기본 수입, 룰렛 회전비, 일반 건물 비용, 업그레이드, 시장, 농장, 전술 명령, 환불률을 하나의 곡선으로 통합.
- 의존: 특수병단 V5 비용표, 60초 공세 시계.
- 산출물:
  - 0~15분 금화 유입·지출 표.
  - 빠른 병영·포탑·시장·특수병단 빌드 비교.
  - 최소 운·평균 운·높은 운 시나리오.
  - 투자 회수시간과 파괴 리스크.
- Codex 핵심 검수:
  - 특수병단 최대 할인 대기가 항상 최적인가.
  - 시장+포탑 빌드와 병영 빌드가 모두 성립하는가.
  - 금화 룰렛이 무한 회전 또는 파산 루프를 만드는가.
