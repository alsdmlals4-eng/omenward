## 2. 이미지별 채택·제외 범위

### VR-001 — 룰렛·벨루 UI

채택:

- 전장 또는 준비 화면과 함께 읽히는 룰렛·건설·스킬 카드의 정보 위계.
- 어두운 남청색 패널, 절제된 금속 금장, 큰 핵심 선택 카드.
- 작은 인게임 벨루의 표정과 대화·추천 정보 분리.

제외:

- 화면 안 가격, 자원, 문장, 아이콘 배열과 임시 명칭.
- 이미지가 암시하는 구체 기능을 승인 없이 구현하는 것.

### VR-003 — 전장 인게임 기준

채택:

- 좌우 본진 사이 상·중·하 독립 3라인을 한 화면에서 읽는 구성.
- 각 라인의 성문·중간거점·접전지와 길 바깥 건설 노드의 가독성.
- 상단 1·중단 2·하단 1 우회로와 중앙 교차 교전의 방향 표현.
- 밝은 왕국 판타지와 적 진영의 대비, 전략 지도형 전체 조망.

제외:

- 이미지 속 라벨, 수치, 장식물 위치를 데이터로 복사하는 것.
- 수채화 렌더링을 최종 인게임 픽셀 자산으로 간주하는 것.
- `APPROVED_BATTLEFIELD_TOPOLOGY_AND_SCALE_V1.md`와 다른 연결을 채택하는 것.

### VR-004 — 벨루 캐릭터

채택:

- 청백색 반투명 정령, 꽃, 초승달형 촉수와 등불, 종 장식.
- 둥근 2~3등신, 연청·백색·금색 팔레트, 8종 표정 폭.

제외:

- `율비/Yulbi` 이름과 해당 이름을 전제로 한 설정·대사.
- 시트의 임시 UI 문구·수치·색상 코드를 검증 없이 최종값으로 사용하는 것.

## 3. 부분 참고·이전 자료

### VR-002 — 10병종 × 등급 전개 도감표

- 상태: **SUPERSEDED_FOR_SPRITE_FORMAT / PARTIAL_REFERENCE / MIGRATION_PENDING**
- 계속 참고: 공용 10병종 구분, 일반→엘리트→영웅→전설 위계 비교.
- 제외: 큰 전신 도감 렌더링을 실제 월드 스프라이트 형식으로 사용하는 것.
- 현재 월드 스프라이트 형식은 `../design/APPROVED_UNIT_VISUAL_FORMAT_AND_REFERENCE_USE_V1.md`가 책임진다.

기타 `.staging/` 자료는 이전 유입·분할 흔적이며 공식 최신 이미지가 아니다. 미분류 외부 탐색 자료는 출처·채택/제외·권리를 기록하기 전 제작 근거로 사용하지 않는다.

## 4. 유입·교체 규칙

1. 저장 가능한 원본 또는 변환본을 저장소에 배치한다.
2. ID, 출처, 승인일, 상태, 용도, 권리·교체 필요 여부를 기록한다.
3. 채택할 요소와 제외할 요소를 분리한다.
4. 아트 본책과 관련 게임·프로그래밍·QA 본책을 갱신한다.
5. 공식 이미지 교체는 같은 안정 경로를 사용하고 이전 버전은 Git 이력으로 보존한다.
6. 바이너리 배치가 끝나지 않았으면 `MIGRATION_PENDING`으로 표시한다.

## 5. 검수 질문

- 현재 공식 최신 이미지 3종이 모두 안정 경로에 존재하는가.
- 이미지의 임시 명칭·수치·토폴로지를 규칙으로 오인하지 않았는가.
- 벨루 외형 참고에서 폐기 명칭 `율비/Yulbi`를 제거했는가.
- 실제 1920×1080·1280×720 엔진 화면에서 가독성을 검증했는가.
- 최종 자산의 출처·사용 권리·후처리 상태가 기록됐는가.
