## 고정 토폴로지

```text
아군 본진
→ 아군 라인 성문
→ 아군 중간거점
→ 중앙 접전지
→ 적 중간거점
→ 적 라인 성문
→ 적 본진
```

- 좌우 대칭, 상·중·하 독립 3라인.
- 일반 횡단로와 기본 라인 변경 없음.
- 중앙 접전지는 해당 라인의 앞뒤 길에만 연결하며 건설 불가.
- 각 중간거점은 전방 2·후방 1 건설 노드를 사용.
- 별도 미니맵 없이 실제 전장 위에서 성문·거점·접전지 상태 표시.

## 중간거점 초기값

- 적 소유 거점을 완전히 빼앗는 데 `중립화 10초 + 점령 10초`.
- 유효 점령력 최대 2.0배, 최소 완전 점령 시간 10초.
- 방패·수호형 1.25, 일반 근접·기병 1.0, 원거리·지원·거인 0.5.
- 암살자·비행·순수 공성 병기는 점령력 0.
- 교착 시 게이지 정지.
- 점령 병력이 사라지면 3초 유지 뒤 이전 안정 상태로 초당 10% 복귀.
- 점령 시도 시작부터 신규 건설·업그레이드와 거점 생산 정지.
- 중립화 시 기존 건물 기능 정지.
- 점령 완료 시 기존 건물은 폐허 처리되며 환불 없음.
- 5초 안정화 후 노드와 기본 생산 활성.
- 소유 중간거점 한 곳당 금화 `+2 / 30초`.

## 성문 초기값

- 라인별 독립 성문 최대 HP 5,000.
- 방어 80, 마법저항 80.
- 일반 피해는 구조물에 40%, 공성 태그 피해는 200% 적용.
- 고정 피해는 구조물에 50% 적용.
- 군중제어·밀치기·비율 피해 면역.
- 아군은 통과하고 적군은 파괴 전까지 차단.
- 0 HP에서 2초 붕괴 연출 뒤 통로 개방.
- 폐허는 이동을 막지 않음.
- 수직 슬라이스에서는 자동 수리·재건 없음.
- 중간거점 점령 여부와 무관하게 실제 도달한 적은 공격 가능.

## 암살자 우회로 초기값

- 진입 준비 1초, 우회 이동 9초.
- 진입 확정 뒤 취소·후퇴 불가.
- 우회 중 전투·점령·버프·피격이 없으며 전장 밖 이동 상태로 처리.
- 도착 구역은 적 중간거점 기준 본진 방향 120 units 뒤의 160×120 영역.
- 막힌 경우 반경 80 units 안의 가장 가까운 유효 지점에 배치.
- 도착 2.5초 전 수비 측에 안개 파동 경고.
- 출현 후 0.6초 준비 뒤 공격 시작.
- 암살자는 전 구간 점령력 0.
- 우선순위: 지원·원거리 → 후방 자원·지원 시설 → 공성 → 가장 가까운 일반 병력.
- 우회 종료 후에는 일반 유닛처럼 해당 라인에서 계속 전투.
- 탐지 전용 건물과 추가 경고 증폭은 수직 슬라이스 제외.

## 길·스케일 초기 가설

```text
플레이 영역: 2,880 × 1,280 world units
일반 보행속도: 60 units/sec
기본 포탑 사거리: 270
주 도로: 200~240
중간거점 전방: 240~300
성문 전방: 260~320
```

## 다음 단계

- 위 초기값을 데이터 상수로 분리한 수직 슬라이스 Plan Mode 제안서 준비.
- 실제 블록아웃에서 점령 시간, 성문 공성 시간, 암살자 대응 시간을 계측.
- 구조 변경 없이 수치만 플레이테스트로 조정.

별도 Codex Plan Mode 제안서와 사용자 승인 전에는 Godot Scene·Navigation·Camera2D·UI·전투 구현을 시작하지 않는다.
