# Issue #2: [Approved][Benchmark] 핵심 게임 반응 및 적용 후보

## Issue body
## 현재 상태

**제안서 검토 대기 / 승인 전 게임 기획 확정 및 구현 금지**

## 목표

Slotbound, Luck be a Landlord, Commander Quest, Mechabellum, Thronefall, Into the Breach, The King is Watching, 9 Kings의 시스템과 반응을 비교해 Roulettebound 수직 슬라이스에 적용할 요소와 제외할 요소를 확정한다.

## 책임 문서

- `docs/benchmarks/0001-core-game-benchmark-proposal.md`
- `docs/benchmarks/SOURCE_SNAPSHOT_2026-07-14.md`
- `docs/benchmarks/PLAYER_REACTION_THEMES.md`
- `docs/benchmarks/APPLICATION_CANDIDATES.md`
- `docs/benchmarks/REVIEW_CHECKLIST.md`

## 주요 조사 결론

- 높은 반응을 얻은 비교작은 단순한 기본 규칙, 깊은 조합, 명확한 인과관계, 제한된 건설 공간, 빠른 재시도를 공통적으로 가진다.
- 반복된 위험은 장르 혼합 과부하, 통제 불가능한 RNG, 전투 결과 불명확, 경제 스노우볼, UI 과밀이다.
- Roulettebound의 차별점은 `건물이 룰렛 토큰 풀을 구성하고, 예고된 적 웨이브에 3라인으로 대응한다`는 연결로 유지한다.

## 검토할 핵심 결정

1. 수직 슬라이스 필수 UX 6개 채택 여부
2. 건물 티어 고정 성장 또는 선택형 2갈래 분기
3. 적 웨이브 수량 정확 공개 또는 범위 공개
4. 럭키 찬스 순수 확률 또는 실패 누적 보정
5. 전방 생산시설 추가 생산 보너스 여부

## 승인 후 작업

- 승인된 후보만 `GAME_DESIGN.md`, `ROADMAP.md`, `DECISIONS_PENDING.md`에 반영
- 구현 전 별도 Codex Plan Mode 제안서 작성
- 승인되지 않은 후보는 아이디어 백로그에만 유지

## 승인 게이트

사용자가 제안서의 항목별 채택 여부를 명시적으로 결정하기 전에는 게임 기획서와 Godot 구현에 반영하지 않는다.
