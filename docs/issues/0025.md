# Issue #25: [Obsolete][Enemy Data] 베일 전사 별도 계보·데이터 초안

## Issue body
## 종료 상태

이 Issue는 아군·적군을 별도 전투 데이터와 능력 계보로 관리하던 초기 안이다. 현재는 **공용 UnitArchetype 10개 + 진영별 Visual Set** 구조로 대체되어 사용하지 않는다.

현재 책임 원본:

- `docs/design/APPROVED_SHARED_UNIT_ARCHETYPE_AND_FACTION_VISUAL_DATA_V1.md`
- `docs/design/APPROVED_SHARED_ARCHETYPE_WAVE_1_20_POC_V1.md`
- `docs/design/APPROVED_PLAYER_TEN_UNIT_LINEAGES_POC_V1.md`
- `docs/design/APPROVED_COMMON_COMBAT_AND_RANK_BUDGET_POC_V1.md`
- `docs/design/APPROVED_UNIT_ANIMATION_AND_BATTLE_PRESENTATION_GUIDE_V1.md`
- Issue #30·#33

현재 규칙:

```text
공용 UnitArchetypeProfile
+ TierProfile
+ RankProfile
+ owner_team_id
+ FactionVisualProfile
```

- 같은 병종·Tier·Rank의 아군과 적군은 능력치·스킬·타기팅·AnimationContract를 공유한다.
- 베일 전사 이름과 이미지는 적군 Visual Set과 표시명이다.
- W5·W10은 공용 아키타입의 엘리트·영웅 Rank 조합이다.
- W15·W20 보스는 공용 base archetype에 BossBehaviorPackage·BossPhaseProfile과 전용 Visual Set을 추가한다.
- 별도 적군 UnitProfile·스킬 계보·모션 상태 머신은 만들지 않는다.

이전 별도 계보 초안은 GitHub 변경 이력에서만 확인한다.
