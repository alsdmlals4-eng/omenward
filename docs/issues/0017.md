# Issue #17: [Approved Mascot][UX] 벨루 최종 시안·단일 안내·일시 상태 반응

## Issue body
## 현재 상태

**벨루 명칭·최종 시안·단일 안내자·일시 상태 반응 승인 / 실제 원화·애니메이션·성우 제작 대기 / 구현 금지**

## 공식 이름과 기원

기존 `율비` 명칭은 `벨루`로 교체됐다.

벨루는 실베른 성채의 오래된 경계종 울림에서 태어난 작은 감시 정령이다.

## 역할

- 세계관 설명
- 적 라인·병종·수량·시간 보고
- 시스템 튜토리얼
- 전술 선택지 요약
- 베일의 법칙 암시
- 룰렛·역전 감정 반응

정찰관·부관 별도 안내 UI와 음성은 사용하지 않는다.

## 최종 시안

- 작고 둥근 요정형 비인간 캐릭터
- 큰 눈과 작은 입
- 부드럽게 늘어진 긴 귀형 장식
- 반투명 요정 날개
- 청백색·옅은 금색 파스텔 팔레트
- 중앙 베일 문양
- 머리 위 빛 신호 기관
- 몸 아래 작은 경계종

## 일시 상태 반응

```text
기본형
→ 짧은 색·문양·표정·사운드 반응
→ 정보 전달
→ 잔광
→ 기본형 복귀
```

- 반응은 약 0.5~2초
- 기본형 복귀는 약 0.2~0.4초
- 지속 상태와 수치는 HUD 아이콘·타이머가 표시

## UI·오디오

- 오른쪽 하단 48~64px 도크
- 말풍선 최대 두 줄
- 맑고 작은 중성적 음색
- 두 음의 종 모티프
- 같은 대사 60초, 같은 카테고리 15초 반복 제한

## 남은 제작물

1. 최종 회전도와 구조 분해도
2. 표정 8종
3. 상태별 0.5~2초 애니메이션
4. 48px·64px 식별 테스트
5. 발화 모드별 보이스 샘플
6. 두 음 종 모티프
7. 벨루 영문 표기 최종 결정

별도 Plan Mode 승인 전에는 Godot 애니메이션·오디오·UI 구현을 시작하지 않는다.
