- 아군·적군은 스탯·스킬·타기팅·점령·구조물 피해·AnimationContract를 공유한다.
- 별도 `EnemyUnitProfile`, 적군용 Unit Scene, 전투 데이터·모션 타이밍 복사본은 금지한다.

- 일반 적 웨이브는 공용 `archetype_id`를 Tier·Rank·수량·라인·출격 시간으로 조합한다.
- W15·W20 보스는 공용 base archetype에 BossBehaviorPackage·BossPhaseProfile과 전용 Visual Set을 추가한다.

## 전장 기준

- 좌우 대칭 독립 상·중·하 3라인.
- `본진 → 성문 → 중간거점 → 중앙 접전지 → 적 중간거점 → 적 성문 → 적 본진`.
- 중간거점 전방 2·후방 1 건설 노드.
- 점령 시 건설권·기본 생산권 이전.
- 중앙 접전지 건설 불가·라인 독립.
- 암살자는 같은 라인의 안개 우회로 사용, 후방 직접 생성 금지.
- 기본 화면 전체 전장 조망, 미니맵 없음.

## 승인된 초기값

```text
중간거점: 중립화 10초 + 점령 10초, 최대 점령력 2.0
거점 생산: 금화 +2 / 30초, 안정화 5초
성문: HP 5000, 방어·마저 80, 일반 40%, 공성 200%, 붕괴 2초
암살자: 진입 1초, 이동 9초, 경고 2.5초, 출현 준비 0.6초
```

## 애니메이션·연출

- 공용 archetype마다 AnimationContract 하나.
- 양 진영 Visual Set은 같은 상태·프레임·피벗·판정 이벤트를 사용한다.
- 공격은 준비→판정→회복.
- 판정과 접촉·투사체 이벤트 오차 한 프레임 이내.
- 적군 전용 모션 상태 머신 제작 없음.
- 스테이지 승리는 2.5~4초 병종별 승리 시퀀스 뒤 결과 UI.

## 완료된 프리프로덕션 범위

1. 핵심 루프·첫 10분.
2. 세계관·벨루.
3. 전장·점령·성문·우회로.
4. 공용 10병종 Tier·Rank·능력 계보.
5. 룰렛·경제·건물·전술·용병.
6. 공용 아키타입 기반 W1~20·보스.
7. 튜토리얼·약 3시간 캠페인·절차 생성.
8. HUD·아트·애니메이션·오디오.
9. 성능·데이터·테스트·Plan Mode 기준.
