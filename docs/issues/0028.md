# Issue #28: [Approved Unit][Special Corps] 공용 거인 아키타입·공성·300초 생산

## Issue body
## 현재 상태

**공용 거인 아키타입의 대형·범위·공성 역할, 특수병단 할인, 거인 토큰과 일반 300초 자동생산 승인 / 절대 수치·Rank 능력은 PoC 조정 / 구현 금지**

## 데이터 구조

거인은 아군·적군 별도 병종이 아니라 공용 `giant` archetype 하나를 사용한다.

```text
UnitArchetypeProfile: giant
+ TierProfile
+ RankProfile
+ owner_team_id
+ FactionVisualProfile
```

- 아군 거인과 적군 파성거체 이미지는 같은 능력치·스킬·타기팅·AnimationContract를 사용한다.
- 적군 차이는 enemy 팀, 웨이브 출격과 베일종 Visual Set이다.
- 별도 적군 GiantProfile·AreaAttackProfile·AnimationContract를 만들지 않는다.

## 획득과 경제

```text
Tier 1 특수병단
금화 40 / 건설 25초

→ 준비도 축적
30초마다 -10%
150초에 -50% 최대

→ Tier 2 거인단
원가 100 / 최대 할인 50 / 업그레이드 45초

→ 거인 토큰 활성
→ 일반 거인 300초 자동생산
```

- 즉시 총금화 140, 최대 할인 총금화 90.
- 첫 자동생산도 300초 전체 시간이 필요하다.
- 자동생산은 Normal Rank만 생성한다.
- 룰렛은 Normal·Elite·Hero·Legendary Rank를 생성한다.
- 플레이어 Mythic Rank는 없다.

## 전투 정체성

```text
대형
넓은 지상 범위 공격
매우 높은 체력·물리 방어
매우 느린 이동
긴 공격 준비·회복
높은 구조물 압박
비행 공격 불가
```

첫 수치 후보:

```text
move_speed = 30
attack_interval = 2.8초
attack_windup = 1.1초
attack_target_cap = 6
food_cost = 6
auto_production_interval = 300초
structure_damage_multiplier = 1.35
barricade_damage_multiplier = 1.50
```

## 생산 경계

- 거인단 완공 순간 생산 진행 0%.
- active combat time에만 진행.
- 식량 부족 시 한 기 완성 대기, 다음 생산 중단.
- 거인단 파괴 시 진행 중 생산과 건물 안 완성 대기 유닛 소멸.
- 이미 인도된 UnitInstance는 유지.
- 다음 룰렛부터 거인 archetype 토큰 제거.

## 기본 공격·연출

- 전방 넓은 범위 내려찍기.
- 최대 6기 지상 대상.
- 중심 100%, 외곽 감쇠.
- 소형 대상 경직·약한 밀쳐내기.
- 준비 뒤 범위가 대상을 계속 추적하지 않는다.
- `structure_attack`은 들어올리기→충돌→긴 회복을 구분한다.
- 아군·적군 Visual Set은 같은 프레임 수·피벗·충돌 이벤트를 사용한다.

## 약점

- 느린 전진과 라인 변경 불가.
- 긴 준비와 빗나감 위험.
- 큰 피격 판정.
- 창병의 대형 보너스.
- 마법 피해·방어 파쇄·독·출혈·최대 체력 비례 피해.
- 비행 대응 불가.

## 남은 검증

1. 공용 거인 절대 HP·방어·공격력.
2. 내려찍기 범위와 공격 이벤트 프레임.
3. Elite·Hero·Legendary 능력과 이름.
4. 식량 6·300초 생산 간격.
5. 아군 거인과 적군 파성거체 Visual Set의 프레임·피벗 호환.
6. 성문 HP 5,000과 공성 배율에서 목표 파괴 시간.

별도 Plan Mode 승인 전에는 UnitArchetypeProfile·ProductionQueue·AnimationContract·SiegeModifier를 구현하지 않는다.
