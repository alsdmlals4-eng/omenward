# Issue #10: [Archived][Boss Patterns] 바리케이드 대응 패턴 초안

## Issue body
## 종료 상태

바리케이드 길 뚫기와 축 방향 범위 공격은 현재 공용 아키타입 기반 웨이브·보스 패키지와 전술 명령 기준으로 통합되어 이 Issue를 종료 상태로 유지한다.

현재 책임 원본:

- `docs/design/APPROVED_SHARED_ARCHETYPE_WAVE_1_20_POC_V1.md`
- `docs/design/APPROVED_COMMON_COMBAT_AND_RANK_BUDGET_POC_V1.md`

- `docs/OMENWARD_GAME_DESIGN.md`

유지되는 핵심:

- 보스는 공용 base archetype에 BossBehaviorPackage를 추가한다.
- 직선 돌파로 바리케이드·전열·구조물을 압박한다.
- 대단절은 고정 전조 범위로 밀집 진형을 압박한다.
- 바리케이드는 영구 완전 봉쇄 수단이 아니다.
- 보스 패턴과 일반 병종의 전투 데이터를 별도 적군 계보로 복제하지 않는다.

세부 피해·범위·쿨다운은 PoC 조정 대상으로 관리한다.
