## 공세 시계

```text
활성 전투 시간 기준 매 60초 충돌
W1   1:00
W5   5:00  — 엘리트
W10 10:00  — 영웅
W15 15:00  — 전설 보스
W20 20:00  — 신화 보스
```

- 일시정지는 공세 시계를 멈춘다.
- 이전 공세가 남아 있어도 다음 공세는 예정대로 진입한다.
- 일반 공세는 T-30/T-15/T-5로 경고한다.
- W15 보스는 T-60부터 예고한다.

## 공용 병종 사용

일반 적 웨이브는 별도 적군 UnitProfile을 사용하지 않는다.

```text
공용 archetype_id
+ Tier
+ Rank
+ count
+ lane_id
+ spawn_time
+ owner_team_id = enemy
+ visual_faction_id = veil
```

- W5 대표 위협은 공용 아키타입의 Elite Rank.
- W10 대표 위협은 공용 아키타입의 Hero Rank.
- 적군 이미지와 표시명은 FactionVisualProfile이 소유한다.
- 같은 archetype·Tier·Rank는 아군과 적군이 같은 전투 데이터와 AnimationContract를 사용한다.

## 보스

W15·W20은 일반 적군 데이터 복사본이 아니다.

```text
공용 base_archetype_id
+ BossBehaviorPackage
+ BossPhaseProfile
+ 전용 Visual Set
```

- W15 전설 보스 처치: 표준 승리.
- W15 이전 적 본진 파괴: 공격적 조기 승리.
- W16~19: 엘리트·영웅·전설 비중이 증가하는 초과 공세.
- W20: 신화 보스 패키지와 전설·영웅 호위.
- 플레이어 Rank는 일반·엘리트·영웅·전설만 유지한다.

## 검증 목표

- 공세 충돌 간격 60초 유지.
- W5·W10의 Rank 상승이 전투와 징조에서 명확히 읽힘.
- W15 전설 보스 전투 30~60초 첫 목표.
- W16~19가 파밍이 아니라 실패 압박으로 작동.
- W20 일반 승률은 매우 낮지만 강제 0%가 아님.
- 모든 일반 spawn entry가 공용 10개 archetype만 참조.
- 적군 전용 스탯·스킬·AnimationContract 복사본이 없음.

## 남은 검증

1. W5 첫 Elite archetype과 호위.
2. W10 첫 Hero archetype과 호위.
3. W15 base archetype과 전설 BossBehaviorPackage.
4. W20 신화 패키지와 2페이즈.
5. 웨이브별 Threat·수량·라인 편성.
6. 징조 UI와 보스 경고.

별도 Plan Mode 승인 전에는 WaveService·StageManifest·Boss Resource를 구현하지 않는다.
