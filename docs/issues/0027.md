# Issue #27: [Approved Progression][Buildings] 기본 병영 6종·특수병단 4종 V5

## Issue body
## 현재 상태

**기본 병영 6종·특수병단 4종 / 특수병단 Tier 1 최대 50% 준비 할인 / Tier 1·2 비용·시간 / Tier 2 특수 토큰·장기 자동생산 승인 / 특수병단 Tier 3은 후속 조정 / 구현 금지**

## 책임 문서

- `docs/design/APPROVED_BARRACKS_AND_SPECIAL_CORPS_UNIT_TREE_V5.md`
- `docs/design/APPROVED_SPECIAL_CORPS_BUILDING_AND_GIANT_CLASS_V3.md`
- `docs/design/APPROVED_UNIT_GRADE_AND_ABILITY_GROWTH.md`

V1~V4 병영·특수병단 트리는 기록용 레거시다.

## 기본 병영

```text
Tier 1
검사 자동생산 + 전사 토큰

Tier 2
방패병 / 대검전사 / 암살자 / 창병 / 궁병 / 기병
```

- 비교적 빠른 일반 병력 자동생산과 토큰 제공.
- 자동생산은 일반 등급만 생성.

## 특수병단 Tier 1

```text
금화 40
건설 25초
토큰 없음
자동생산 없음
준비도 축적
```

준비 할인:

```text
30초  -10%
60초  -20%
90초  -30%
120초 -40%
150초 -50% 최대
```

- 활성 전투 시간만 축적.
- 일시정지 중 정지.
- 업그레이드 시작 순간 할인 고정.
- 파괴·철거·재건 시 준비도 초기화.
- 할인은 Tier 2 금화 비용에만 적용.

## Tier 2 전문화 경제

| 전문화 | 원가 | 최대 할인 | 업그레이드 | 일반 자동생산 | 식량 |
|---|---:|---:|---:|---:|---:|
| 사제단 | 60 | 30 | 30초 | 180초 | 3 |
| 마도단 | 70 | 35 | 35초 | 210초 | 3 |
| 비행단 | 80 | 40 | 40초 | 240초 | 4 |
| 거인단 | 100 | 50 | 45초 | 300초 | 6 |

Tier 1을 포함한 총금화:

| 전문화 | 즉시 총금화 | 최대 할인 총금화 |
|---|---:|---:|
| 사제단 | 100 | 70 |
| 마도단 | 110 | 75 |
| 비행단 | 120 | 80 |
| 거인단 | 140 | 90 |

## Tier 2 효과

```text
사제단 → 사제 토큰 + 일반 사제 자동생산
마도단 → 마법사 토큰 + 일반 마법사 자동생산
비행단 → 비행 토큰 + 일반 비행병 자동생산
거인단 → 거인 토큰 + 일반 거인 자동생산
```

- 다음 룰렛부터 선택 토큰 적용.
- 자동생산은 일반 등급만 생성.
- 엘리트·영웅·전설은 룰렛 전용.
- 식량 부족 시 한 기 완성 대기, 다음 생산 정지.
- 건물 파괴 시 진행 중 생산과 건물 안 완성 대기 유닛 소멸.
- 이미 인도된 유닛과 확정 룰렛 결과는 유지.

## 전략적 의미

```text
즉시 전문화
→ 비싸지만 토큰과 자동생산을 150초 빠르게 시작

최대 할인 전문화
→ 전력 도입은 늦지만 Tier 2 비용 50% 절감
```

## 남은 작업

1. 시작 금화·기본 수입·시장 수입과 비용표 통합
2. 기본 병영·농장·시장·포탑 절대 비용
3. 마법사·비행병·사제·거인 등급별 능력 계보
4. 특수 토큰 최종 릴 확률
5. 특수병단 Tier 3 도입 여부
6. 캠페인 해금 순서와 1~15웨이브 편성

별도 Plan Mode 승인 전에는 BuildingProfile·PreparationDiscount·ProductionQueue·TokenPool 구현을 시작하지 않는다.
