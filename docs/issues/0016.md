## 공식 전제

플레이어는 루메른 왕국 트리븐 전선의 실베른 성채에 부임한 지휘관이다. 베일런 황야의 괴물 군단이 루미엔 영토로 넘어가지 못하게 세 전선을 지휘한다.

## 베일의 법칙

기존 `경계의 율` 명칭은 `베일의 법칙`으로 교체됐다.

- 괴물의 공세 시간·통로·규모에 영향을 줌
- 공세 전에는 `베일의 징조`가 나타남
- 축복·저주·스테이지 제약과 연결 가능
- 인간과 괴물 모두 전체 원리를 알지 못함
- 원인과 목적은 암시하되 게임 효과와 수치는 HUD에 공개

## 공식 명칭

```text
루메른 왕국
루미엔 영토
트리븐 전선
실베른 성채
베일런 황야
루메른 경계군
실베른 수비대
베일종
```

## 첫 장면

> 벨루: 지휘관, 실베른 성채의 베일이 울려요.

> 벨루: 베일런 쪽에서 전사형 넷. 상단으로 와요.

## 남은 작업

1. 루메른 왕국의 정치·군사 구조 최소 설정
2. 실베른 성채의 과거와 지휘관 부임 이유
3. 베일런 황야의 시각 테마
4. 베일종 명명 규칙
5. 첫 캠페인 사건과 엔딩 암시

별도 Plan Mode 승인 전에는 서사 Scene·대사 데이터 구현을 시작하지 않는다.
