# Issue #58: [CI] GitHub Actions 월간 사용량 소진 — 초기화 후 재검증

## Issue body
## 확정 원인

GitHub Actions의 이번 월간 포함 실행 시간이 모두 소진되어 GitHub-hosted runner가 첫 step 전에 차단되고 있다.

저장소 Actions 권한과 workflow trigger는 정상이며, 외부 Action을 사용하지 않은 shell-only 진단도 같은 방식으로 실패했다. 따라서 workflow 코드나 Action 허용 정책이 원인이 아니다.

## 운영 결정

- 월간 사용량 초기화 전에는 실패 workflow를 재실행하지 않는다.
- 초기화 후 PR #61을 먼저 검증하고 squash merge한다.
- 그 다음 PR #57을 최신 main으로 업데이트해 재검증한다.
