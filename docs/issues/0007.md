## 종료 상태

- W15 전설 보스 처치가 표준 승리.

- W16~19 초과 공세.
- W20 신화 보스 패키지.
- 일반 적 웨이브는 공용 10병종 archetype을 Tier·Rank·수량·라인·출격 시간으로 조합.
