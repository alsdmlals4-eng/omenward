## 현재 적용 규칙

- 공세 충돌은 활성 전투 시간 기준 60초 간격.
- 일시정지 중 공세 시계 정지.
- 첫 Tier 2 선택은 `방패병·대검전사·암살자`.
- 전장은 라인별 성문, 점령 가능한 중간거점, 독립 중앙 접전지를 사용.
- 암살자 선택 시 안개 우회로 학습을 포함할 수 있음.
- 미니맵은 사용하지 않음.

## 첫 4공세 학습 목적

1. 첫 배치와 기본 교전.
2. 포탑 또는 바리케이드로 첫 역전.
3. 룰렛 상위 등급의 강함 체감.
4. 세 라인 분배와 Tier 2 선택.

## 초기 수치 가설

```text
일반 검사: HP 280 / 공격 32 / 1.20초
소형 근접 베일종: HP 65 / 공격 10 / 1.40초 / 이동 60
소형 원거리 베일종: HP 48 / 공격 12 / 1.80초 / 사거리 200
Tier 1 포탑: HP 500 / 공격 18 / 1.00초 / 사거리 270 / 건설 22초
바리케이드: HP 350 / 시전 1.5초 / 지속 18초 / 비용 12 / 쿨다운 30초
```

정확한 병영 생산 간격과 공세 수량은 최신 경제·웨이브 표 계산 뒤 조정한다.

## 다음 검증

1. 60초 충돌 주기에 맞춘 생산·건설 타이밍.
2. 첫 네 공세 StageManifest.
3. 중간거점·성문·우회로 튜토리얼 도입 시점.
4. 포탑 완공과 첫 역전 타이밍.
5. 세 Tier 2 선택의 방어 성공률.
6. 시작 금화·병영·포탑·룰렛 비용 정합성.

별도 Codex Plan Mode 제안서와 사용자 승인 전에는 Unit·Wave·Building Resource와 전투 코드를 구현하지 않는다.
