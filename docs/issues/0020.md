# Issue #20: [Approved][Brand] 게임명 오멘워드 확정

## Issue body
## 승인 완료

공식 게임명을 다음으로 확정했다.

```text
오멘워드
OMENWARD
```

첫 캠페인·프로토타입 부제:

```text
오멘워드: 실베른 성채
OMENWARD: Silvern Citadel
```

태그라인:

```text
확률을 설계하고, 최전선을 지켜라.
Build the odds. Hold the frontier.
```
