# Issue #235: Replace progress-bar minimaps with a three-front strategic map

## Issue body
## Goal
Replace the three per-front progress-bar minimaps with one readable strategic map matching the approved three-lane structure direction.

## Design intent
The Run Command screen should show a single map with left/right faction network connections, three main fronts, forward bases, central clash nodes, and upper/lower bypass routes. It is contextual presentation only; it must not become a second battle simulator.

## Scope
- Replace `Fronts/Top|Middle|Bottom` progress-bar cards with a `StrategicMap` Control in the existing upper HUD area.
- Draw the static route/network hierarchy and update only markers/count labels from existing run state.
- Preserve current battlefield backdrop as the primary terrain image; the map stays translucent.
- Keep roulette, battle, deployment, probability, and balance rules unchanged.

## Acceptance criteria
- Map exposes exactly three primary routes, 3 friendly and 3 Veil forward-base markers, 3 clash nodes, connection links, and two bypass routes.
- The old progress-bar minimap nodes are gone from the player screen.
- Existing Run Command and roulette contracts still pass; a new UI contract test proves the strategic-map structure.
- Hera technical capture at 960×540 shows the network legibly with clean runtime diagnostics.
- Docs/Notion distinguish map presentation evidence from human readability evidence.
