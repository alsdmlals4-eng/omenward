# Issue #33: [Approved Presentation] 공용 병종 AnimationContract·진영 Visual Set V1

## Issue body
## 현재 상태

**공용 10병종의 이동·공격·피격·사망·승리 연출 승인 / 아군·적군은 같은 상태·타이밍 계약과 다른 이미지 세트 사용 / 구현 전**

- `docs/design/APPROVED_SHARED_UNIT_ARCHETYPE_AND_FACTION_VISUAL_DATA_V1.md`

## 핵심 데이터 구조

```text
공용 UnitArchetypeProfile × 10
+ 공용 AnimationContract × 10
+ 아군 FactionVisualProfile
+ 적군 FactionVisualProfile
```

- 적군 10병종을 별도 모션 기획·상태 머신·타이밍 데이터로 제작하지 않는다.
- 같은 archetype의 양 진영 이미지 시트는 상태, 프레임 수, 배열, 피벗과 판정 이벤트 프레임을 공유한다.
- 이미지·초상화·아이콘·팔레트·표시명만 다르다.
- `visual_faction_id`는 공격속도·피해·쿨다운과 이벤트 시간을 바꾸지 않는다.

## 필수 상태

```text
deploy
idle
move
attack_basic
skill_1
hit_light
death
victory
```

역할별 추가:

- 점령 가능 병종: `capture`.
- 암살자: `bypass_enter`, `bypass_exit`.
- 기병: `charge`, `turn_recover`.
- 비행병: 상승·순항·급강하·회복.
- 거인: `structure_attack`, `heavy_stagger`.

## 공격 계약

```text
준비
→ 판정
→ 회복
```

- 접촉·투사체 발사와 실제 판정 오차 한 프레임 이내.
- 이동 위치는 코드가 소유하고 루트 모션 사용 안 함.
- 가벼운 연속 피격은 플래시·미세 반동.
- 일반 공격마다 큰 화면 흔들림·히트 스톱 금지.

## 첫 프레임 가설

```text
idle 4~6
move 6~8
attack_basic 6~10
skill_1 8~14
hit_light 2~3
death 6~10
victory 8~14
```

## 승리 연출

- 개별 처치: 없음.
- 웨이브 정리: 0.4~0.8초 무기 정리.
- 거점 점령: 참여 유닛 0.6~1.0초 확인 동작.
- 성문 파괴: 0.5초 이내 반응.
- 스테이지 승리: 2.5~4.0초 병종별 승리→벨루→결과 UI.

## 수직 슬라이스 우선 검증

- 대표 공용 archetype 3~5종.
- 각 archetype의 아군·적군 이미지 세트.
- 전열, 원거리, 암살자 또는 공성 역할 포함.
- 같은 Unit Scene과 전투 데이터로 양 진영 생성.
- 상태·프레임·피벗·접촉·투사체 이벤트 호환 검사.

## 완료 기준

- 전략 줌 0.85배에서 대표 역할과 진영을 구분한다.
- 같은 archetype·Tier·Rank의 양 진영 판정 시간이 동일하다.
- `visual_faction_id`만 바꿔 이미지가 교체된다.
- 양 진영 시트의 상태·프레임·피벗·이벤트가 일치한다.
- 적군 전용 Unit Scene·AnimationContract·전투 데이터가 없다.
- 가벼운 피격으로 공격이 계속 끊기지 않는다.
- 암살자 우회가 순간이동으로 보이지 않는다.
- 성문 붕괴와 승리 연출이 승인 시간 안에 끝난다.

Issue #1 Phase 0과 Issue #32 수직 슬라이스 Plan Mode 승인 전에는 실제 자산·Scene·Resource·코드를 구현하지 않는다.
