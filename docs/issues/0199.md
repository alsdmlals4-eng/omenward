# Issue #199: Reconcile reopened v4.7 canon with legacy C1/C2/C3 documentation validators

## Issue body
## Problem
Current Omenward `main` uses the reopened 2026-08-20 v4.7 planning/current-state documents, while several legacy validators still require July Vertical Slice and C1/C2/C3 proof strings in active current documents.

This is a pre-existing baseline inconsistency. PR #198 changes only:
- `docs/base-reuse-adoption.json`
- `tests/headless/p0_candidate_draft_reuse_test.gd`
- `tests/test_base_v9_adoption.py`
- `vendor/base-reuse/candidate_draft_weight_engine.gd`
- `vendor/base-reuse/omenward_candidate_draft_adapter.gd`

None of the failing canon documents or legacy validators are changed by that rollout.

## Observed failing surfaces
- `tools/validate_c1_roulette.py` requires historical C1 proof strings in `CURRENT_IMPLEMENTATION_STATUS.md` and `OMENWARD_ROADMAP.md`.
- `tools/validate_c2_battle_objective.py` requires legacy V2/C2 strings and exact run `29938742864` in current docs.
- `tools/validate_project_core_docs.py` still routes `APPROVED_VERTICAL_SLICE_SYSTEM_CONTRACT_2026-07-27.md` and old Evidence Pilot/review surfaces as current authority.
- `tests/python/test_bca_visual_sheet_adoption.py` requires exact historical C1 head/run inside the current implementation status.
- C3 validation is expected to have the same current-vs-historical authority risk after C1/C2 are cleared.

## Required resolution
1. Read current `AGENTS.md`, `ACTIVE_CONTEXT.md`, `CURRENT_CONFIRMED_DECISIONS.md`, `CURRENT_IMPLEMENTATION_STATUS.md`, current GDD/Project Core and documentation map.
2. Preserve exact historical proof in dedicated evidence/audit sources.
3. Require current docs to label historical proof as historical and keep `CURRENT_*_RUNTIME = NOT_RUN` where applicable.
4. Update validators/tests rather than restoring obsolete current-authority claims.
5. Run C1, C2, C3, Project Core Documentation, GDD Sheet Adoption and full Python/Godot regressions.
6. Do not change roulette, battle, economy, save, data, scenes, balance or player-facing runtime behavior.

## Acceptance criteria
- All current documentation/contract workflows pass on exact head.
- Historical proof remains verifiable by exact SHA/run.
- Current runtime and human evidence are not promoted from `NOT_RUN`.
- No deprecated Google Sheet/legacy surface is restored as current planning authority.
- Five full adversarial review loops and zero unresolved review threads before merge.

## Evidence boundary
`BASELINE_VALIDATOR_DRIFT != PR198_ADAPTER_FAILURE`
`HISTORICAL_REMOTE_PROOF != CURRENT_RUNTIME_PASS`
