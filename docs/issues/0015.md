# Issue #15: [Approved Principle][UX] 벨루 단일 안내·첫 10분 도파민 루프

## Issue body
## 현재 상태

**10~30초 학습 원칙과 첫 10분 흐름 승인 / 실제 HUD·수치·연출 조정 대기 / 구현 금지**

- `docs/design/APPROVED_DOPAMINE_DRIVEN_DESIGN_AND_FIRST_10_MINUTES.md`
- `docs/design/APPROVED_BELLU_SINGLE_GUIDE_AND_FIRST_10_MINUTE_FLOW.md`

- `docs/design/APPROVED_OMENWARD_WORLD_AND_NAMING.md`

## 공식 명칭

```text
게임: 오멘워드
안내자: 벨루
첫 요새: 실베른 성채
전선: 트리븐 전선
괴물 영역: 베일런 황야
세계 규칙: 베일의 법칙
전조: 베일의 징조
```

## 첫 10분

| 시간 | 경험 |
|---|---|
| 0:00~0:15 | 실베른 성채·첫 베일의 징조 |
| 0:15~0:35 | 일시정지 계획 모드 |
| 0:35~1:05 | 첫 병영·전사 토큰 |
| 1:05~1:45 | 1줄 일반 검사 |
| 1:45~2:15 | 상단 배치 |
| 2:15~3:10 | 첫 경계 공세 |
| 3:10~5:15 | 포탑·바리케이드 역전 |
| 5:15~5:45 | 이동권으로 2줄 엘리트 |
| 5:45~7:20 | 엘리트 강화 |
| 7:20~8:10 | Tier 2 전사 선택 |
| 8:10~10:00 | 선택 병종 체험과 다음 성장 예고 |

## 학습 원칙

```text
한 문장 설명
→ 한 번의 직접 행동
→ 즉시 결과
→ 다음 목표
```

각 시스템의 최초 습득은 10~30초를 목표로 한다. 시스템 수가 아니라 동시에 요구하는 새 개념 수를 제한한다.

## 벨루

세계관 설명, 적 보고, 시스템 안내와 전술 선택지 요약은 모두 벨루가 담당한다. 정확한 수치와 지속 상태는 HUD가 담당한다.

## PoC 목표

- 첫 병영 1분 10초
- 첫 룰렛 1분 45초
- 첫 배치 2분 15초
- 첫 역전 5분 15초
- 첫 엘리트 5분 45초
- Tier 2 선택 8분 10초
- 핵심 루프 두 번 10분 이내

별도 Plan Mode 승인 전에는 튜토리얼 Scene·UI·데이터 구현을 시작하지 않는다.
