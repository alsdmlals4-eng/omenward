# Issue #41: [Infrastructure] Base PR #18 기반 단일 정본 전수 최신화

## Issue body
## 목표
Base PR #18(`d2457e7`)의 11개 독립 본책·1:1 스킬 운영 구조를 유지한 채, Omenward 이주 작업본을 Git/문서/발행/검증이 가능한 단일 정본으로 최신화한다.

## 범위
- 안전한 Git worktree 전환 및 기존 이주 작업본 보존
- 내부 `omenward/` 미커밋 전장 시안·아트 문서·Godot 설정의 검증 후 회수
- 11개 본책, 허브, Registry·Manifest·PDF·Skill Map, QA/통합검수 문서 갱신
- GitHub Actions 발행 SHA를 현재 빌드 SHA로 전환
- Godot editor import, headless 6종, runtime smoke, 문서 발행 검증

## 제외
- 게임 규칙·콘텐츠·전투 로직 확장
- 내부 보존 작업본 삭제 또는 강제 정리

## 완료 기준
- 정본 worktree에서 Git 상태·origin·브랜치가 정상이며 원본은 보존된다.
- Asset Registry SHA와 승인 전장 시안이 일치하고, `.import`·캐시·`.superpowers`는 활성 산출물에 포함되지 않는다.
- 13개 Publication Manifest/PDF와 Skill Map이 생성기로 최신화된다.
- 검증 결과와 미실행 사람 플레이 QA가 문서에 사실대로 기록된다.
