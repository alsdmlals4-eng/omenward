# Issue #256: Phase 2: implement approved storybook SD unit runtime assets

## Issue body
## Goal
Bring the current runtime unit presentation into the user-approved storybook watercolor SD tactical direction without changing battle rules, unit data, or animation timing.

## Scope
- Produce original, provenance-recorded idle candidates for the existing runtime archetype/faction consumers.
- Start with the current early-stage readability pair: Lumern/Veil Shield Guard and Lumern/Veil Archer.
- Preserve the existing 512×512 runtime cell, pivot, source-facing, UnitView binding, and deterministic battle behavior.
- Keep terrain, fixed towers, units, and ownership state as separate render layers.

## Non-goals
- No battle balance, attack timing, frame-count, or new animation-state change.
- No replacement of a user-approved source without candidate provenance, exact approval, and consumer verification.
- No baked character/tower content in the strategic terrain backdrop.

## Acceptance
- Every changed runtime texture has an original-generation provenance record, SHA-256, and a non-overwrite path.
- Existing geometry/gallery and battle contracts remain green.
- Godot scene import resolves the new textures and runtime visual capture is taken separately from machine checks.
- Human readability remains not-run until actually reviewed.
