# AI 공동 작업 흐름 요약

```text
사용자 의견
→ 기획 AI가 의도와 플레이어 경험 구체화
→ GAME_DESIGN 또는 Issue 갱신
→ 실행 가능한 Codex Goal 작성
→ Codex가 작업 전 범위·위험·검증 계획 요약
→ 별도 브랜치에서 최소 구현
→ 테스트와 실행 검증
→ Pull Request
→ 사용자 검수
→ Compound 교훈 기록
```

## Goal 필수 항목

- 목표와 사용자 가치
- 먼저 읽을 문서
- 포함 범위
- 제외 범위
- 예상 변경 파일
- 데이터·UI 영향
- 완료 기준
- 검증 명령과 수동 확인
- 결과 보고 형식

## 완료 판단

기능 이름이 아니라 실제로 관찰 가능한 조건과 테스트 결과로 판단한다. 실행하지 못한 검증은 미검증으로 보고한다.
