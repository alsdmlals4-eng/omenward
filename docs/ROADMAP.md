# 개발 로드맵

모든 단계는 이전 단계의 관찰 가능한 완료 기준을 통과한 뒤 진행한다.

## Phase 0 — 기술 기반 결정

- 엔진 후보 비교 및 선택
- 목표 플랫폼과 입력 방식 결정
- 2D/2.5D 카메라와 아트 파이프라인 결정
- 데이터 정의, 테스트, 빌드 명령 확정
- 최소 빈 프로젝트와 자동 검증 구성

완료 기준:

- 새 개발자가 문서의 명령만으로 프로젝트를 실행할 수 있다.
- 자동 테스트 또는 헤드리스 검증의 최소 루프가 동작한다.
- 맵 단위와 사거리 기준이 수치로 정의된다.

## Phase 1 — 3라인 전장 시뮬레이션

- 본진, 전방 거점, 접전지, 이동 구간 배치
- 검사 더미 유닛의 자동 이동과 교전
- 라인별 전투 분리
- 기본 승패 판정
- 디버그 오버레이로 좌표, 라인, 사거리 확인

## Phase 2 — 건설과 경제

- 후방 6개, 라인별 전방 3개 노드
- 농장, 시장, 훈련소, 포탑
- 금화·식량
- 건물 완공, 파괴, 폐허, 재건설
- 티어 상승 및 생산 타이머
- 기본 포탑이 접전지에 닿지 않는 거리 검증

## Phase 3 — 룰렛과 배치

- 건물 기반 릴별 토큰 풀
- X 토큰 자동 충전·제거
- 3×3 회전과 선택 줄 판정
- 유닛 대기칸
- 원하는 라인으로 출전
- 토큰 확률 UI

## Phase 4 — 상성과 접전지

- 검사, 기병, 창병, 궁병
- 상성 배율 데이터
- 라인별 접전지 점령
- 점령 수입과 접전 중 정지
- 1대1 및 소규모 자동 밸런스 테스트

## Phase 5 — 적 웨이브

- 적 건물 기반 웨이브 생성
- 30초 전조 UI
- 라인·병종·수량 공개
- 웨이브 확정 시점
- 적 건물 파괴가 현재/다음 웨이브에 미치는 영향

## Phase 6 — 런 빌드와 특수 병종

- 상점
- 스킬북과 장비
- 럭키 찬스
- 사제, 마법사, 도적
- 영웅 스킬

## Phase 7 — 콘텐츠와 폴리시

- 맵 변형
- 특수 웨이브
- 난이도와 튜토리얼
- 아트·사운드 교체
- 성능 최적화
- 저장 및 설정
