# 개발 로드맵

모든 단계는 이전 단계의 관찰 가능한 완료 기준을 통과한 뒤 진행한다. 실제 구현은 각 단계마다 Codex Plan Mode 제안서와 사용자 승인을 거친다.

## Phase P — 프리프로덕션 디자인 프리즈

- 한 판 구조, 시작 상태, 승패와 결전 웨이브 계약 확정
- 약 3시간 캠페인과 10~15분 단일 튜토리얼 범위 확정
- 절차적 생성기의 시드, StageManifest, DifficultyProfile, Threat Budget, Validator 확정
- 플레이어 선택형 제약의 점수, 충돌 규칙, 보상과 검증 계약 확정
- 룰렛 판정, 금화, 럭키 찬스, 이동권, 대기칸과 아이템 계약 확정
- 룰렛 완성 줄에 따른 일반·엘리트·영웅·전설 등급 생성 계약 확정
- 수동 합성·경험치·건물 Tier가 등급을 올리지 않는 생성 경계 확정
- 시장·병영·혼합 빌드, 포탑과 용병 상점의 경제 계약 확정
- 적이 있어도 진행되는 건설·업그레이드와 건설 중 피격 계약 확정
- Tier 1 공통 → Tier 2 전문화 → Tier 3 심화·교리 계약 확정
- 병영 병종 전환, 한 릴 토큰 증폭, 생산 버프와 포탑 전문화 확정
- 병영 자동 생산은 일반 등급, 정예훈련은 등급 변경 없는 생산 버프 계약 확정
- 금화 소모형 전술 명령의 비용·범위·개별 쿨다운·중첩 계약 확정
- 전술 명령 전역 쿨다운·별도 일시정지 예약 객체를 사용하지 않는 실행 계약 확정
- 일시정지 중 룰렛·건설·배치·상점·전술 명령을 정상 확정하고 시간 진행만 멈추는 계약 확정
- 바리케이드 대응 보스의 가로축 직선 돌파·세로축 크게 베기 계약 확정
- 일반 병사의 핵심 패시브 1개·핵심 스킬 1개와 등급별 신규 핵심 능력·기존 능력 강화 계약 확정
- 파괴·폐허·철거·Ready 슬롯과 수리 범위 확정
- 유닛 상태, 타기팅, 상성, 전투 키워드, 접전지와 웨이브 규칙 확정
- 특수 적과 결전 웨이브의 역할·전조·공격 우선순위 확정
- Godot 데이터 스키마, 상태 소유, 성능 예산과 검증 시나리오 확정

완료 기준:

- Codex가 주요 규칙과 상태 전이를 임의 해석할 필요가 없다.
- MVP와 첫 공개 프로토타입의 포함·제외 범위가 명시돼 있다.
- 경계·실패 상황의 기대 동작이 정리돼 있다.
- 밸런스 수치는 코드 상수가 아니라 데이터 조정 대상으로 분리돼 있다.
- 생성기·제약·결전 웨이브가 재현 가능한 데이터 계약으로 정의돼 있다.
- 전문화·전술 명령·보스 패턴·유닛 능력 성장 결과가 데이터와 UI에서 재현 가능하다.

## Phase 0 — Godot 기술 기반 구축

- Godot 정확한 stable 버전 확정
- GDScript 기반 최소 프로젝트 생성
- `scenes/`, `scripts/`, `data/`, `resources/`, `tests/` 기본 구조
- 2D/2.5D 카메라와 아트 파이프라인 결정
- 기준 해상도와 stretch 정책
- Godot headless 파싱·실행 검증
- 난수 시드, 결정론적 시간 서비스와 테스트 seam
- 맵 단위, 사거리와 최대 동시 유닛 목표

완료 기준:

- README 명령만으로 프로젝트를 열고 실행할 수 있다.
- 빈 메인 Scene이 오류 없이 실행된다.
- headless 검증의 최소 루프가 동작한다.
- 같은 시드를 테스트에 전달할 수 있다.

## Phase 1 — 3라인 전장 시뮬레이션

- 본진, 전방 거점, 접전지와 이동 구간
- 검사 더미 유닛의 자동 이동과 교전
- 라인별 전투 분리
- 기본 승패 판정
- 좌표·라인·사거리 디버그 오버레이
- 기본 포탑 위치에서 접전지까지 거리 검증

## Phase 2 — 건설, 경제와 전문화

- 후방 6개, 라인별 전방 3개 노드와 건물 허용 규칙
- 농장, 시장, 기본 병영, 단일 대상 포탑
- 금화·식량과 생산 타이머
- `Empty → Constructing → Active → Upgrading/Demolishing → Ruins` 상태 전이
- 적이 있어도 건설·업그레이드 시작 및 진행
- 건설 중 구조물 피격, 체력 증가와 완공 직전 파괴 처리
- 건설 중 길막 악용 방지 충돌 규칙
- 건설·업그레이드 취소와 철거 환불
- 완공, 파괴, 폐허와 재건설
- Tier 1 공통 기능과 Tier 2·3 전문화 선택 구조
- 업그레이드 중 이전 Tier 기능과 토큰 유지
- 기본 병영 Tier 1 검사 생산
- Tier 2 기병·창병·궁병 전문화와 생산·토큰 교체
- Tier 3 대량생산·정예훈련·토큰 증폭 교리 데이터
- 정예훈련은 등급 생성이 아닌 생산 유닛 버프 데이터
- 생산시설 유닛 버프 데이터
- 포탑 제압형·요새형·장거리형 전문화
- 훈련시설 Ready 슬롯과 생산 공간 부족 처리
- 농장 파괴 후 식량 초과 처리
- 건설 선택·전문화 비교와 예상 룰렛 변화 UI
- 시장·병영·혼합 빌드의 데이터 기반 경제 비교

완료 기준:

- 적이 있어도 건설 진행도가 승인 계약대로 유지된다.
- 건설 중 구조물이 파괴되거나 완공되는 경계가 결정론적으로 처리된다.
- 병영 전문화 완료 전후 생산 병종과 토큰 전환 시점이 일치한다.
- 병영 생산과 정예훈련이 상위 등급 유닛을 생성하지 않는다.
- 전문화 선택은 비용·효과·토큰 변화 미리보기와 일치한다.
- 파괴가 수입·식량·생산·토큰에 정해진 시점에 반영된다.
- 공간 부족으로 완성 유닛이 조용히 사라지지 않는다.
- 농장 파괴로 식량을 초과해도 기존 출전 유닛을 제거하지 않는다.
- 모든 맵 템플릿에서 포탑 사거리 계약이 유지된다.

## Phase 3 — 룰렛과 배치

- 건물 기반 릴별 토큰 풀과 X 토큰
- 기본 중앙 가로줄 판정
- 완성 줄 1/2/3~7/8개 등급 판정
- 룰렛 판정 시점에 일반·엘리트·영웅·전설 등급 직접 생성
- 수동 합성·경험치·건물 Tier 등급 상승 경로 없음 검증
- 금화 75%/200%/500% 지급
- 전설 한 판당 1회와 이후 영웅 2명 변환
- 결과 보관함과 유닛 대기칸
- 원하는 라인 출전
- 토큰 장부와 건설 전 확률 변화 UI
- 전문화로 한 릴에만 추가되는 보너스 토큰
- 같은 시드·건물 인스턴스의 보너스 릴 결정론 검증
- 럭키 찬스 실패 누적과 행운 아이템 데이터
- 자연 이동과 여러 이동권의 다중 이동·되돌리기
- 룰렛 결과 화면의 병종·등급·신규 능력·기존 능력 강화 표시

완료 기준:

- 같은 최종 룰렛 보드와 판정 줄은 같은 병종·등급 보상을 만든다.
- 병영 생산 버프와 룰렛 등급이 데이터에서 분리된다.
- 일시정지 중에도 룰렛 회전·이동 계획·결과 확정이 정상 작동하고 시간은 진행되지 않는다.

## Phase 4 — 상성, 능력과 접전지

- 검사, 방패병, 기병, 창병, 궁병, 암살자
- 상성 배율 데이터
- 병종별 기본 핵심 패시브 1개와 기본 핵심 스킬 1개
- 엘리트·영웅·전설 단계별 신규 핵심 패시브 또는 스킬 1개 추가
- 등급 상승 시 기존 병종 능력 강화 데이터
- 엘리트 신규 스킬과 기존 기본 스킬 강화의 분리
- 돌진, 후방, 원거리, 기병, 경직, 밀쳐내기, 치명타 등 공통 키워드
- 라인별 접전지 점령과 금화 수입
- 접전 중 수입 처리
- 상성·사거리·타기팅·스킬 준비 상태 오버레이
- 1대1 및 소규모 자동 밸런스 테스트

완료 기준:

- 일반/엘리트/영웅/전설은 각각 2/3/4/5개의 핵심 능력을 가진다.
- 상위 등급은 하위 등급 능력을 유지하고 신규 능력과 기존 능력 강화를 모두 적용한다.
- 창병의 대기병·돌진 취소, 기병 돌진, 궁병 조건부 치명타, 암살자 후방 판정이 재현된다.
- 상성상 유리한 하위 등급이 불리한 상위 등급을 조건에 따라 이길 수 있다.

## Phase 5 — 적 웨이브, 보스와 결전

- 적 건물 기반 웨이브 생성
- T-30, T-15, T-5 전조와 정확한 구성 공개
- T-10 병력 구성 확정
- 적 건물 파괴가 현재·다음 웨이브에 미치는 영향
- 결전 웨이브 상시 타이머와 5분 전 경보
- 기본 35분 결전 웨이브 데이터 가설
- 세 라인 공성·지원·지휘관형 결전 구성
- 결전 전 적 시설 파괴에 따른 증원 감소
- 방어 후 2~3분 간격 강화 웨이브 데이터 구조
- 바리케이드 감지와 길 뚫기 보스 우선순위
- 가로축 직선 돌파의 전조·고정 범위·바리케이드 피해
- 세로축 크게 베기의 전조·밀집 기준·현재 라인 범위
- 보스 패턴 최소 반복 간격과 개별 쿨다운
- 보스 돌진과 창병 돌진 저지의 약화 규칙
- 웨이브 종료 후 라인별 원인 보고

완료 기준:

- 전조 정보와 실제 출격이 일치한다.
- 강제 시간패 없이 결전 웨이브가 공격 전환을 유도한다.
- 결전 웨이브는 강하지만 검증된 빌드로 방어 가능하다.
- 적 시설 파괴가 결전 증원량에 재현 가능하게 반영된다.
- 바리케이드가 일반 적을 지연하지만 길 뚫기 보스를 영구 봉쇄하지 않는다.
- 보스 범위는 전조 뒤 플레이어 유닛을 계속 추적하지 않는다.
- 세로축 크게 베기는 기본적으로 인접 라인을 공격하지 않는다.

## Phase 6 — 절차적 스테이지 생성기

- 튜토리얼을 생성 대상에서 제외
- 결정론적 시드와 생성 규칙 버전
- `StageArchetype`, `MapTemplate`, `EnemyBuildArchetype`, `WavePatternCard`
- `DifficultyProfile`과 Threat Budget
- 생성 결과를 고정하는 `StageManifest`
- 결전 시간·패턴·반복 강화 필드
- 전문화·보너스 릴·전술 명령 해금 필드
- Command Power와 보스 패턴 ID·위력·초기 사용 지연 필드
- 유닛 능력 해금·적 병종 태그·키워드 허용 범위 필드
- 맵 거리·포탑 사거리·해금·전조 일치 Validator
- 생성 실패 시 검증된 안전 스테이지 대체
- 같은 시드와 새 시드 재도전
- 개발자용 시드·예산·웨이브 타임라인 화면
- 다수 시드 headless 일괄 생성 검증

## Phase 7 — 상점, 용병, 전술 명령과 특수 적

- 상점 재고와 새로고침
- 포탑·용병 중심 경제 빌드
- 용병 병종·가격·재고와 식량 사용
- 상위 등급 용병 직접 판매는 별도 승인 전 제외
- 스킬북, 장비, 이동권, 행운과 줄 변경 아이템
- 금화 소모형 전술 명령 패널
- 일시정지 중에도 명령 목표 지정·금화 차감·사용 확정
- 일시정지 중 시전시간·지속시간·개별 쿨다운은 정지
- 전역 쿨다운 없이 준비된 서로 다른 명령 연속 사용
- 명령별 개별 쿨다운과 금화 차감
- 바리케이드 지정 지점 설치와 파괴
- 화살비 범위 피해와 건물 피해 제외
- 역병 지속 피해·치유 감소·중첩 규칙
- 강화지대 아군 버프·중첩 규칙
- 사제, 마법사, 도적과 등급별 능력
- 공성병, 돌격형, 지원형, 침투형, 지휘관형 특수 적
- 특수 적 아이콘, 목표와 대응 수단 전조
- 특수·공성·침투·보스·결전 Wave Pattern Card

완료 기준:

- 전술 명령은 금화·범위·개별 쿨다운 계약과 일치한다.
- 한 명령 사용이 다른 명령을 전역적으로 잠그지 않는다.
- 일시정지 중 전술 명령이 정상 확정되고 별도 예약 객체·예약 금액은 발생하지 않는다.
- 일시정지 중 명령 시전시간·지속시간·쿨다운은 진행되지 않는다.
- 같은 효과의 무한 중첩은 차단된다.
- 전술 명령만으로 적 본진·생산시설을 제거할 수 없다.
- 시장 빌드는 금화를 즉각 대응력으로 전환할 수 있지만 병력·포탑을 완전히 대체하지 않는다.

## Phase 8 — 단일 튜토리얼 스테이지

- 절차적으로 생성하지 않는 10~15분 고정 스테이지
- 한 전투 흐름에서 카메라, 건설, 룰렛, 배치, 상성, 전조, 접전지와 Tier를 짧게 소개
- 일시정지 중 룰렛·건설·유닛 배치를 천천히 수행하는 계획 모드 소개
- 적이 접근하는 동안 포탑이 완공되는 짧은 건설 장면
- 병영 Tier 2 전문화 한 번 체험
- 바리케이드 전술 명령 하나만 짧게 소개
- 설명은 1~2문장, 기능마다 필수 행동 1회
- 실수 시 즉시 패배 대신 짧은 안내와 보충 자원
- 안내 건너뛰기와 다시 보기
- 2~3분 종합 웨이브
- 완료 후 제약 시스템 해금

완료 기준:

- 첫 플레이어가 10~15분 안에 핵심 연결을 한 번씩 경험한다.
- 빠른 조작이 어려운 플레이어도 일시정지로 핵심 선택을 완료할 수 있다.
- 튜토리얼이 장시간 숙련 과정으로 변하지 않는다.
- 고급 전문화·특수 적·나머지 전술 명령은 정규 스테이지에서 짧게 소개한다.

## Phase 9 — 플레이어 선택형 제약 시스템

- 제약 데이터 스키마와 위험도 점수
- 경제·보급·룰렛·전장·적 강화 카테고리
- 튜토리얼 완료 후 준비 화면에서 선택
- 난이도·시드·제약을 포함한 StageManifest
- 충돌 태그와 선택 차단 이유
- 제약 적용 후 Validator 재실행
- 결전 조기 출격·강화 제약
- 전술 명령 비용·개별 쿨다운 제약
- 보스 패턴 강화·조기 사용 제약
- 점수 배율, 메달과 최고 제약 점수 기록
- 영구 전투력 보상 제외

## Phase 10 — 약 3시간 프로토타입 캠페인

- 단일 튜토리얼 1개
- 난이도·맵·특수 적이 단계적으로 증가하는 정규 스테이지 여러 개
- 맵 골격, 적 건물 성향, 웨이브 패턴, 보스 패턴, 결전 패턴과 수정자 콘텐츠
- 쉬움·보통·어려움 Difficulty Profile
- 건물 전문화와 전술 명령의 단계적 해금
- 병종과 등급별 핵심 능력의 단계적 소개
- 제약 선택, 결과 화면과 재도전
- 스테이지별 검증된 안전 시드
- 목표 총 플레이 분량 165~195분 조정
- 시장·병영·혼합 빌드, 전문화와 제약 조합 플레이테스트
- 아트·사운드 교체와 성능 최적화
- 설정, 캠페인 진행과 최고 제약 기록 저장

- 추가 맵 테마와 진영
- 정보 제한, 철인 모드 같은 고급 제약
