# 개발 로드맵

모든 단계는 이전 단계의 관찰 가능한 완료 기준을 통과한 뒤 진행한다. 실제 구현은 각 단계마다 Codex Plan Mode 제안서와 사용자 승인을 거친다.

## Phase P — 프리프로덕션 디자인 프리즈

- Dopamine Driven Design과 `건물로 확률을 만들고 예고된 위기를 뒤집는다`는 핵심 재미 확정
- 새 시스템의 기본 사용법을 10~30초 안에 습득시키는 UI·튜토리얼 계약 확정
- 첫 10분 안에 핵심 루프를 약 2회 경험하는 화면 단위 플로우 확정
- 최전선 지휘관, 세 전선, 괴물 군단과 경계의 율 세계관 전제 확정
- 웨이브 전조를 경계의 징조로 표현하고 축복·저주를 Stage Modifier와 연결하는 계약 확정
- 룰렛·토큰은 플레이어 UI로 유지하고 세계관에서는 전술판·증원 경로로 가볍게 번역하는 경계 확정
- 한 판 구조, 시작 상태, 승패와 결전 웨이브 계약 확정
- 약 3시간 캠페인과 10~15분 단일 튜토리얼 범위 확정
- 절차적 생성기의 시드, StageManifest, DifficultyProfile, Threat Budget, Validator 확정
- 플레이어 선택형 제약의 점수, 충돌 규칙, 보상과 검증 계약 확정
- 룰렛 판정, 금화, 럭키 찬스, 이동권, 대기칸과 아이템 계약 확정
- 룰렛 완성 줄에 따른 일반·엘리트·영웅·전설 등급 생성 계약 확정
- 수동 합성·경험치·건물 Tier가 등급을 올리지 않는 생성 경계 확정
- 시장·병영·혼합 빌드, 포탑과 용병 상점의 경제 계약 확정
- 적이 있어도 진행되는 건설·업그레이드와 건설 중 피격 계약 확정
- Tier 1 공통 → Tier 2 전문화 → Tier 3 심화·교리 계약 확정
- 전사·기병·창병·궁병 공유 토큰과 병영 출처 후보 가중치 계약 확정
- 병영 Tier별 패시브 생성·강화와 룰렛 등급별 스킬 생성·강화 계약 확정
- 병영 자동 생산은 일반 등급, 정예훈련은 등급 변경 없는 생산 버프 계약 확정
- 금화 소모형 전술 명령의 비용·범위·개별 쿨다운·중첩 계약 확정
- 전술 명령 전역 쿨다운·별도 일시정지 예약 객체를 사용하지 않는 실행 계약 확정
- 일시정지 중 룰렛·건설·배치·상점·전술 명령을 정상 확정하고 시간 진행만 멈추는 계약 확정
- 바리케이드 대응 보스의 가로축 직선 돌파·세로축 크게 베기 계약 확정
- 지상·비행, 대공·지상화와 전투 키워드 계약 확정
- 파괴·폐허·철거·Ready 슬롯과 수리 범위 확정
- 유닛 상태, 타기팅, 상성, 접전지와 웨이브 규칙 확정
- 특수 적과 결전 웨이브의 역할·전조·공격 우선순위 확정
- Godot 데이터 스키마, 상태 소유, 성능 예산과 검증 시나리오 확정

완료 기준:

- 플레이어가 첫 30초 안에 최전선 지휘관과 방어 목표를 이해한다.
- 각 신규 핵심 시스템은 한 문장·한 행동·즉시 피드백으로 10~30초 안에 기본 사용법을 습득할 수 있다.
- 첫 10분 PoC가 건설·토큰·룰렛·배치·웨이브 대응·첫 역전을 연속 제공한다.
- Codex가 주요 규칙과 상태 전이를 임의 해석할 필요가 없다.
- MVP와 첫 공개 프로토타입의 포함·제외 범위가 명시돼 있다.
- 경계·실패 상황의 기대 동작이 정리돼 있다.
- 밸런스 수치는 코드 상수가 아니라 데이터 조정 대상으로 분리돼 있다.
- 생성기·제약·결전 웨이브가 재현 가능한 데이터 계약으로 정의돼 있다.
- 전문화·전술 명령·보스 패턴·유닛 능력 성장 결과가 데이터와 UI에서 재현 가능하다.

## Phase 0 — Godot 기술 기반 구축

- Godot 정확한 stable 버전 확정
- GDScript 기반 최소 프로젝트 생성
- `scenes/`, `scripts/`, `data/`, `resources/`, `tests/` 기본 구조
- 2D/2.5D 카메라와 아트 파이프라인 결정
- 기준 해상도와 stretch 정책
- Godot headless 파싱·실행 검증
- 난수 시드, 결정론적 시간 서비스와 테스트 seam
- 맵 단위, 사거리와 최대 동시 유닛 목표

완료 기준:

- README 명령만으로 프로젝트를 열고 실행할 수 있다.
- 빈 메인 Scene이 오류 없이 실행된다.
- headless 검증의 최소 루프가 동작한다.
- 같은 시드를 테스트에 전달할 수 있다.

## Phase 1 — 첫 10분 PoC와 3라인 전장

- 최전선 요새, 세 경계 통로와 후방 방어선
- 경계종·라인 점등·정찰관 보고를 사용한 첫 웨이브 징조
- 10~30초 시스템 학습 카드 프레임
- 일시정지 최초 학습
- 검사 더미 유닛의 자동 이동·교전·횡베기
- 라인별 전투 분리
- 기본 승패 판정
- 좌표·라인·사거리 디버그 오버레이
- 첫 10분 타임라인 계측

완료 기준:

- 첫 30초 안에 역할과 위험 라인을 이해한다.
- 일시정지 학습이 10~20초 안에 끝난다.
- 첫 병력 배치 뒤 3분 30초 이내 교전을 확인한다.
- 경계의 율은 암시되지만 긴 설정 설명은 발생하지 않는다.

## Phase 2 — 건설, 경제와 전문화

- 후방 6개, 라인별 전방 3개 노드와 건물 허용 규칙
- 농장, 시장, 기본 병영, 단일 대상 포탑
- 금화·식량과 생산 타이머
- `Empty → Constructing → Active → Upgrading/Demolishing → Ruins` 상태 전이
- 적이 있어도 건설·업그레이드 시작 및 진행
- 건설 중 구조물 피격, 체력 증가와 완공 직전 파괴 처리
- 건설 중 길막 악용 방지 충돌 규칙
- 건설·업그레이드 취소와 철거 환불
- 완공, 파괴, 폐허와 재건설
- Tier 1 공통 기능과 Tier 2·3 전문화 선택 구조
- 업그레이드 중 이전 Tier 기능과 토큰 유지
- 기본 병영 Tier 1 검사 생산과 전사 토큰
- Tier 2 방패병·대검병·광전사·기병·창병·궁병 전문화
- Tier 3 세부 병종과 대량생산·정예훈련·토큰 증폭 교리
- 정예훈련은 등급 생성이 아닌 생산 유닛 버프 데이터
- 생산시설 유닛 버프 데이터
- 포탑 제압형·요새형·장거리형 전문화
- 훈련시설 Ready 슬롯과 생산 공간 부족 처리
- 농장 파괴 후 식량 초과 처리
- 건설 선택·전문화 비교와 예상 룰렛 변화 UI
- 시장·병영·혼합 빌드의 데이터 기반 경제 비교

완료 기준:

- 첫 병영 건설과 토큰 연결 학습이 각각 10~30초 안에 끝난다.
- 적이 있어도 건설 진행도가 승인 계약대로 유지된다.
- 건설 중 구조물이 파괴되거나 완공되는 경계가 결정론적으로 처리된다.
- 병영 전문화 완료 전후 생산 병종과 토큰 전환 시점이 일치한다.
- 병영 생산과 정예훈련이 상위 등급 유닛을 생성하지 않는다.
- 전문화 선택은 비용·효과·토큰 변화 미리보기와 일치한다.
- 파괴가 수입·식량·생산·토큰에 정해진 시점에 반영된다.
- 공간 부족으로 완성 유닛이 조용히 사라지지 않는다.

## Phase 3 — 룰렛과 배치

- 건물 기반 릴별 토큰 풀과 X 토큰
- 기본 중앙 가로줄 판정
- 완성 줄 1/2/3~7/8개 일반·엘리트·영웅·전설 판정
- 공유 토큰의 병영 출처 후보 가중치 추첨
- 일반은 실제 세부 병종, 상위 등급은 계열별 고정 유닛 생성
- 수동 합성·경험치·건물 Tier 등급 상승 경로 없음 검증
- 금화 75%/200%/500% 지급
- 전설 한 판당 1회와 이후 영웅 2명 변환
- 결과 보관함과 유닛 대기칸
- 원하는 라인 출전
- 토큰 장부와 건설 전 확률 변화 UI
- 전문화로 한 릴에만 추가되는 보너스 토큰
- 럭키 찬스 실패 누적과 행·열 이동권
- 첫 회전 결정론적 일반 보상과 두 번째 회전 엘리트 체험 데이터
- 룰렛 결과 화면의 병종·등급·패시브·스킬 강화 표시

완료 기준:

- 첫 룰렛 기본 학습이 20~30초 안에 끝난다.
- 건물 건설 뒤 토큰과 확률 변화가 즉시 이해된다.
- 같은 최종 보드와 판정 줄은 같은 병종·등급 보상을 만든다.
- 병영 생산 버프와 룰렛 등급이 데이터에서 분리된다.

## Phase 4 — 상성, 능력과 접전지

- 검사, 방패병, 대검병, 광전사, 기병, 창병, 궁병, 암살자
- 상성 배율 데이터
- 병영 Tier별 핵심 패시브 1·2·3과 강화 단계
- 룰렛 등급별 1·2·3스킬과 강화 단계
- 엘리트·영웅·전설 계열별 고정 유닛
- 돌진, 후방, 원거리, 기병, 경직, 밀쳐내기, 치명타 등 공통 키워드
- 지상·비행·대공·지상화
- 라인별 접전지 점령과 금화 수입
- 상성·사거리·타기팅·스킬 준비 상태 오버레이
- 1대1 및 소규모 자동 밸런스 테스트

완료 기준:

- 패시브와 스킬의 신규 해금·강화가 UI에서 구분된다.
- 엘리트는 1스킬 강화, 영웅은 2스킬 생성, 전설은 2스킬 강화·3스킬 생성을 적용한다.
- 상성상 유리한 하위 등급이 불리한 상위 등급을 조건에 따라 이길 수 있다.

## Phase 5 — 적 웨이브, 보스와 결전

- 적 건물 기반 웨이브 생성
- 경계의 징조로 표현하는 T-30, T-15, T-5 전조
- T-10 병력 구성 확정
- 적 건물 파괴가 현재·다음 웨이브에 미치는 영향
- 결전 웨이브 상시 타이머와 5분 전 경보
- 세 라인 공성·지원·지휘관형 결전 구성
- 결전 전 적 시설 파괴에 따른 증원 감소
- 바리케이드 감지와 길 뚫기 보스 우선순위
- 가로축 직선 돌파와 세로축 크게 베기
- 웨이브 종료 후 라인별 원인 보고

완료 기준:

- 전조 정보와 실제 출격이 일치한다.
- 플레이어가 웨이브 전조 기본 사용법을 10~30초 안에 이해한다.
- 경계의 율은 공세의 미스터리를 만들지만 실제 규칙은 명확히 공개한다.
- 바리케이드가 일반 적을 지연하지만 보스를 영구 봉쇄하지 않는다.

## Phase 6 — 절차적 스테이지 생성기

- 튜토리얼을 생성 대상에서 제외
- 결정론적 시드와 생성 규칙 버전
- `StageArchetype`, `MapTemplate`, `EnemyBuildArchetype`, `WavePatternCard`
- `DifficultyProfile`과 Threat Budget
- 생성 결과를 고정하는 `StageManifest`
- 결전 시간·패턴·반복 강화 필드
- Command Power와 보스 패턴 필드
- 비행 위협·대공 해금 필드
- 경계의 율 축복·저주·선언 Modifier 필드
- 맵 거리·포탑 사거리·해금·전조 일치 Validator
- 생성 실패 시 검증된 안전 스테이지 대체
- 다수 시드 headless 일괄 생성 검증

## Phase 7 — 상점, 용병, 전술 명령과 특수 적

- 상점 재고와 새로고침
- 포탑·용병 중심 경제 빌드
- 용병 병종·가격·재고와 식량 사용
- 스킬북, 장비, 이동권, 행운과 줄 변경 아이템
- 금화 소모형 전술 명령 패널
- 일시정지 중 명령 목표 지정·금화 차감·사용 확정
- 전역 쿨다운 없이 준비된 서로 다른 명령 연속 사용
- 바리케이드·화살비·역병·강화지대
- 사제, 마법사, 도적과 등급별 능력
- 공성병, 돌격형, 지원형, 침투형, 지휘관형 특수 적
- 특수 적 아이콘, 목표와 대응 수단 전조

## Phase 8 — 단일 튜토리얼 스테이지

- 절차적으로 생성하지 않는 10~15분 고정 스테이지
- 첫 30초 최전선 지휘관·경계 징조 제시
- 각 시스템 10~30초 학습 모듈
- 첫 룰렛 2분 10초 이내
- 첫 교전 3분 30초 이내
- 첫 전선 역전 5분 30초 이내
- 첫 10분에 핵심 루프 약 2회
- 일시정지, 건설, 토큰 연결, 룰렛, 배치, 전조, 포탑·바리케이드, 이동권, 엘리트 체험
- Tier 2 전사 병종 예고
- 설명 건너뛰기와 다시 보기
- 10분 이후 짧은 종합 웨이브와 스테이지 종료

완료 기준:

- 처음 플레이한 사용자가 각 기능을 10~30초 안에 기본 조작한다.
- 사용자가 최전선 지휘관·건물-토큰 연결·웨이브 대응을 자신의 말로 설명한다.
- 설명을 읽는 시간보다 직접 조작과 결과를 보는 시간이 길다.
- 첫 10분 종료 시 다음 Tier·고등급·새 병종을 기대한다.
