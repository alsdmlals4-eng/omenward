## 핵심 정체성

- 장르: 실시간 3라인 전략 오토배틀 + 건물 기반 3×3 룰렛 빌드.
- 핵심 루프: `베일의 징조 → 건물·토큰 선택 → 룰렛 → 라인 배치 → 상성과 전술로 역전`.
- 플랫폼: Windows PC / 마우스·키보드 / 싱글플레이 PvE.
- 엔진: Godot + GDScript. 정확한 stable 버전은 Issue #1 Plan Mode에서 고정한다.
- 새 시스템은 10~30초 안에 기본 사용법을 익히고 첫 10분 안에 핵심 루프를 두 번 체험한다.

## 세계관·명칭

- 루메른 왕국, 루미엔 영토, 트리븐 전선, 실베른 성채, 베일런 황야.
- 베일의 법칙, 베일의 징조, 베일종.
- 벨루가 세계관·적 보고·튜토리얼·전술 요약·감정 반응을 담당한다.
- 레거시 명칭은 신규 기획·UI·대사에서 사용하지 않는다.

## 전장 구조

```text
아군 본진
→ 아군 성문
→ 아군 중간거점
→ 중앙 접전지
→ 적 중간거점
→ 적 성문
→ 적 본진
```

- 좌우 대칭, 상·중·하 독립 3라인.
- 라인 간 일반 횡단로와 기본 라인 변경 없음.
- 중앙 접전지는 해당 라인의 앞뒤 길에만 연결하며 건설 불가.
- 각 본진에 라인별 성문 3개.
- 각 중간거점에 전방 건설 노드 2개와 후방 노드 1개.
- 전장 전체를 기본 전략 화면에서 보며 미니맵은 사용하지 않는다.
- 암살자는 적 후방에 직접 배치하지 않고 같은 라인의 안개 우회로를 사용한다.

## 승인된 중간거점 초기값

```text
중립화 10초 + 점령 10초 at 점령력 1.0
최대 유효 점령력 2.0
최소 완전 점령 시간 10초
진행 유지 3초
복귀 속도 초당 10%
안정화 5초
소유 수입 금화 +2 / 30초
```

점령력:

- 방패·수호형 1.25.
- 일반 근접·기병 1.0.
- 원거리·지원·거인 0.5.
- 암살자·비행·순수 공성 병기 0.

처리:

- 점령 시도 시작부터 거점 생산·신규 건설·업그레이드 정지.
- 중립화 시 기존 건물 비활성.
- 점령 완료 시 기존 건물 폐허화, 환불 없음.
- 5초 안정화 후 새 소유자의 노드와 생산 활성.

## 승인된 성문 초기값

```text
HP 5000
방어 80
마법저항 80
일반 구조물 피해 40%
공성 태그 구조물 피해 200%
고정 피해 50%
붕괴 2초
```

- 아군은 통과하고 적은 파괴 전까지 차단.
- 군중제어·밀치기·비율 피해 면역.
- 폐허는 이동을 막지 않음.
- 수직 슬라이스에서는 자동 수리·재건 없음.
- 성문 세 개는 독립 상태.

## 승인된 암살자 우회로 초기값

```text
진입 준비 1초
우회 이동 9초
수비 측 도착 경고 2.5초 전
출현 준비 0.6초
도착 위치: 적 중간거점에서 본진 방향 120 units
도착 영역: 160 × 120 units
막힘 보정 반경: 80 units
점령력 0
```

- 진입 확정 후 취소·후퇴 불가.
- 우회 중 전투·점령·피격·버프 없음.
- 우회 경로는 선택·배치 중에만 표시.
- 탐지 전용 건물은 수직 슬라이스 제외.
- 공격 우선순위는 지원·원거리 → 후방 시설 → 공성 → 주변 일반 병력.

## 플레이어 병종

기본 병영 6종:

- 방패병, 대검전사, 암살자, 창병, 궁병, 기병.

특수병단 4종:

- 사제, 마법사, 비행병, 거인.

- 플레이어 등급은 일반·엘리트·영웅·전설.
- 플레이어 신화급은 없다.
- 자동생산은 일반 등급만 생성한다.

## 승인된 병종 애니메이션·전투 연출

### 필수 상태

```text
deploy
idle
move
attack_basic
skill_1
hit_light
death
victory
```

- 점령 가능 병종은 `capture`를 가진다.
- 암살자는 `bypass_enter`, `bypass_exit`를 가진다.
- 기병은 `charge`, 비행병은 상승·순항·급강하, 거인은 `structure_attack`을 별도 상태로 가진다.
- 공격은 준비→판정→회복의 세 구간을 구분하고 실제 피해·투사체 발사와 판정 프레임을 맞춘다.
- 가벼운 피격은 큰 경직을 반복하지 않고 짧은 플래시·미세 반동으로 처리한다.
- 이동은 코드가 위치를 소유하며 애니메이션 루트 모션으로 전투 위치를 결정하지 않는다.

### 병종별 움직임 핵심

- 방패병: 낮은 중심, 방패를 전방에 유지.
- 대검전사: 큰 준비와 긴 회복으로 무게 표현.
- 암살자: 낮고 빠른 보폭, 우회 진입·출현 전용 모션.
- 창병: 창끝과 진행·공격 방향 일치.
- 궁병: 화살 꺼내기·당기기·발사 순서 명확.
- 기병: 보행·속보·돌진과 충돌·방향 회복 분리.
- 사제: 치유와 격려의 지팡이 방향 구분.
- 마법사: 시전 문양·방출 프레임 분리.
- 비행병: 상승·순항·급강하·회복 분리.
- 거인: 준비·충돌·회복과 구조물 공격 분리.

### 승리 연출

- 개별 처치에는 승리 모션 없음.
- 웨이브 정리에는 0.4~0.8초 무기 정리·호흡만 사용.
- 중간거점 점령은 참여 유닛의 0.6~1.0초 짧은 확인 동작.
- 성문 파괴는 0.5초 이내 반응만 허용하고 공성 흐름을 멈추지 않는다.
- 스테이지 승리 확정 뒤 2.5~4.0초 병종별 승리 시퀀스를 사용한다.
- 같은 병종 다수의 승리 시작은 0~0.35초 결정론적 오프셋으로 복제 느낌을 줄인다.

## 경제·룰렛

```text
시작 금화 160
시작 식량 12
기본 수입 +5 / 20초
중앙 접전지 +4 / 60초 / 소유 지점
중간거점 +2 / 30초 / 소유 지점
기본 룰렛 비용 20
```

- 적 처치·웨이브 클리어 고정 금화 없음.
- 시장 +4/20초, 다중 시장 비용 증가.
- 룰렛은 3×3, 같은 비-X 심벌 완성 줄 판정.
- 1/2/3~7/8줄은 일반/엘리트/영웅/전설.
- 럭키 12%, 실패당 +8%p, 6회 실패 후 확정.
- 전설은 스테이지당 1회.

## 공세·캠페인

- 활성 전투 시간 기준 60초마다 공세 충돌.
- W5 엘리트, W10 영웅, W15 전설 보스, W20 적군 전용 신화 보스.
- W15 보스 처치 표준 승리, W15 이전 적 본진 파괴는 조기 승리.
- 수동 튜토리얼 1 + 정규 9, 총 10스테이지 약 3시간 초안.

## UI·아트·성능

- 1920×1080, 내부 960×540 정수 확대 후보.
- 룰렛 좌하단, 건설·용병·전술 하단, 벨루 우하단.
- 성문·거점·접전지 상태는 실제 전장 위에 표시.
- 일반 인간형 첫 프레임 가설: 대기 4~6, 이동 6~8, 기본 공격 6~10, 핵심 스킬 8~14, 사망 6~10, 승리 8~14.
- 정상 목표: 지상 120, 비행 24, 투사체 160, VFX 80.
- 하드 상한: 지상 180, 비행 40, 투사체 260, VFX 140.
