## 핵심 정체성

- 장르: 실시간 3라인 전략 오토배틀 + 건물 기반 3×3 룰렛 빌드.
- 핵심 재미: `베일의 징조 → 건물·토큰 선택 → 룰렛 기대와 결과 → 라인 배치 → 상성과 전술로 역전`.
- Dopamine Driven Design: 새 시스템은 10~30초 안에 기본 사용법을 익히고 첫 10분 안에 핵심 루프를 두 번 체험한다.
- 플랫폼: Windows PC / 마우스·키보드 / 싱글플레이 PvE.
- 엔진: Godot + GDScript. 정확한 stable 버전은 구현 Plan Mode에서 고정한다.

## 세계관·명칭

- 루메른 왕국, 루미엔 영토, 트리븐 전선, 실베른 성채, 베일런 황야.
- 세계 규칙 `베일의 법칙`, 공세 전조 `베일의 징조`, 괴물 분류 `베일종`.
- 플레이어 조직: 루메른 경계군·실베른 수비대.
- 벨루는 세계관·적 보고·튜토리얼·전술 요약·감정 반응을 모두 담당한다.
- 룰렛은 UI 용어이며 세계관에서는 전술판·전력 표식·증원 경로로 번역한다.
- 레거시 명칭 `Roulettebound`, `율비`, `경계의 율`, `은종성채`, `무명야`는 신규 기획·UI·대사에서 사용하지 않는다.

## 전장·공세

### 전장 구조

- 좌측 아군과 우측 적군은 기능상 대칭인 상·중·하 3라인 구조다.
- 라인별 순서: `아군 본진 → 아군 성문 → 아군 중간거점 → 중앙 접전지 → 적 중간거점 → 적 성문 → 적 본진`.
- 각 본진 입구에는 상·중·하 라인별 성문이 하나씩 있다.
- 라인 간 횡단로와 기본 라인 변경은 없다.
- 각 중앙 접전지는 해당 라인의 앞뒤 도로에만 연결한다.
- 중앙 접전지는 점령 가능하지만 건설할 수 없다.

### 중간거점

- 각 라인의 중간거점은 접전지처럼 점령 가능하다.
- 각 중간거점에는 전방 건설 노드 2개와 후방 건설 노드 1개가 있다.
- 점령 진영이 해당 거점의 건설권과 기본 자원 생산을 획득한다.
- 빼앗긴 진영은 신규 건설권과 거점 생산을 잃는다.
- 점령 시 기존 건물 처리 방식과 정확한 생산량·점령 시간은 구현 전 확정한다.

### 암살자 우회로

- 우회로는 각 라인의 중간거점보다 조금 앞에서 시작해 같은 라인의 적 후열로 이어진다.
- 암살자는 적 후방에 직접 배치하지 않고 아군 측에 배치한 뒤 우회로로 침투한다.
- 우회로는 평상시 안개·연무로 가린다.
- 암살자를 선택하고 라인을 지정할 때만 출발점·경로 방향·도착 구역을 표시한다.
- 다른 병종 선택 중에는 우회로가 보이지 않는다.
- 우회로는 다른 라인이나 중앙 접전지로 연결되지 않는다.

### 카메라·길

- 기본 전략 줌에서 양측 본진과 세 라인 전체를 확인한다.
- 전장이 한눈에 보이므로 별도 미니맵은 사용하지 않는다.
- 주 도로 폭은 200~240, 중간거점·성문 전방은 240~320 world units 초기 가설이다.
- 건설 노드는 도로 바깥에 두며 대형 건물도 통행로를 막지 않는다.
- PoC 맵 2,880×1,280 world units, 일반 이동속도 기준 60, 포탑 사거리 270.

### 공세

- 활성 전투 시간 기준 매 60초 공세 충돌.
- W5 엘리트, W10 영웅, W15 전설 보스, W20 적군 전용 신화 보스.
- W15 보스 처치가 표준 승리, W15 이전 적 본진 파괴는 조기 승리.
- W16~19는 초과 공세, W20은 즉시 패배가 아닌 사실상 절멸 공세.

## 플레이어 10병종

### 기본 병영 6종

- 방패병: 범용 전열·원거리 대응.
- 대검전사: 정면 범위·파쇄·격노.
- 암살자: 같은 라인의 안개 우회로를 통해 적 후열·후방 시설 침투.
- 창병: 돌진·대형 저지.
- 궁병: 지속 원거리·대공.
- 기병: 기동·돌진·후열 압박.

### 특수병단 4종

- 사제: 치유·버프.
- 마법사: 광역 마법·제어.
- 비행병: 지상 전열 우회·후열 압박.
- 거인: 높은 범위 공격·체력·방어·공성.

- 플레이어 등급은 일반·엘리트·영웅·전설 4단계다.
- 플레이어 신화급은 없다.
- 자동생산은 일반 등급만 생성한다.
- 엘리트·영웅·전설은 계열별 룰렛 고정 템플릿이다.

## 기본 병영

- Tier 1: 검사 자동생산 + 전사 토큰.
- Tier 2: 방패병·대검전사·암살자·창병·궁병·기병 중 하나.
- 방패병·대검전사는 전사 토큰 공유.
- 암살자·창병·궁병·기병은 독립 토큰.
- Tier 3: 상위 병종 1개 + 대량생산·정예훈련·토큰 증폭 중 교리 1개.
- T2 생산시간 첫 가설: 방패 120, 대검 120, 암살 125, 창 115, 궁 120, 기병 150초.

## 특수병단

- Tier 1: 금화 40, 건설 25초, 토큰·생산 없음.
- 완공 뒤 활성 전투 시간 30초마다 Tier 2 금화 비용 -10%, 150초에 최대 -50%.
- Tier 2 원가/시간: 사제 60/30초, 마법사 70/35초, 비행 80/40초, 거인 100/45초.
- Tier 2 완료부터 선택 특수 토큰과 일반 자동생산 제공.
- 생산시간·식량: 사제 180초·3, 마법사 210초·3, 비행 240초·4, 거인 300초·6.
- Tier 3 초안: 치유/전쟁사제, 원소/주술, 천공창/폭풍익, 파성거인/고대거신.

## 경제

- 정규 시작 금화 160, 식량 한도 12.
- 기본 수입 20초마다 +5.
- 중앙 접전지 한 곳당 60초마다 +4.
- 중간거점은 소유 진영에 기본 자원 생산을 제공하며 점령 시 생산권이 이전된다.
- 중간거점 생산량과 주기는 아직 미확정이다.
- 적 처치·웨이브 클리어 고정 금화 없음.
- 기본 건물: 병영 40, 특수병단 40, 농장 35, 시장 50, 포탑 35.
- 시장은 20초마다 +4, 다중 시장 비용은 `50 + 25 × 기존 시장 수`.
- 기본 룰렛 비용 20.
- 취소·환불: 건설 70%, 업그레이드 50%, 완공 철거 40%, 적 파괴 0%.
- 일시정지 중 기본·시장·점령 수입, 생산, 건설, 준비 할인, 웨이브 시계가 정지한다.

## 룰렛

- 3×3, 중앙 가로줄 기본 판정, 같은 비-X 심벌 3개가 완성된 줄만 보상.
- 1/2/3~7/8줄은 일반/엘리트/영웅/전설.
- 9칸 동일은 첫 전설 전에는 전설, 이후 영웅 2기.
- 전설은 스테이지당 1회.
- 럭키 12%, 실패당 +8%p, 6회 실패 뒤 확정.
- 기본 릴 가중치 첫 가설: X 6, 금화 2, 이동권 1, 기본 병영 토큰 +3, 특수병단 +2.
- 결과 보관함 3칸, 이동권 보유 상한 5개 첫 가설.
- 금화 1/2/3줄 이상은 15/40/100, 장기 평균 지급 목표는 회전비 30% 이하.

## 공통 전투·등급

- 물리·마법·고정 피해.
- 방어·저항 공식 `100/(100+defense)`, 피해 감소 상한 75% 첫 가설.
- 기본 치명타 5%, 피해 150%, 후방 120도·+25%.
- 일반/엘리트/영웅/전설 Threat 1/2.2/5/10.
- 보스 전설 Threat 24, 신화 보스 55 첫 가설.
- 상태이상 연속 감소·면역, 보스 지속시간 보정.
- 지상·비행·대공·대형 태그.
- 거인: HP 900·방어 80·공격 120·2.8초·이동 30 첫 가설, 최대 6기 범위, 비행 공격 불가.

## 적군·웨이브

- 아군 10병종에 대응하는 적군 10병종 구조.
- 작업명: 베일 갑각수, 균열도살자, 그림자갈퀴, 가시창병, 침사수, 균열기수, 베일 표식자, 공허주술사, 베일익수, 파성거체.
- 같은 병종·Tier·등급 기본 전투 예산 ±10%에서 시작.
- W1~15 Threat 첫 곡선 6→85.
- W16~20 Threat 첫 곡선 100→250.
- 적 생산시설 파괴 첫 가설: 미출격 현재 -30%, 다음 -50%, 이후 -20%.
- W15 전설 보스 패턴: 직선 돌파, 대단절, 진군.
- W20 신화 보스: 끝나지 않는 진군, 2페이즈.

## 건물·전술·용병

- 농장 T2 곡물창고, T3 대형 곡물창고/야전 취사장.
- 시장 T2 교역소/군수상회, T3 왕립 거래소/전선 보급소.
- 포탑 T2 연발포탑/노포탑, T3 폭풍연발포/파성노포.
- 전술 명령 첫 가설: 바리케이드 12/30초, 화살비 25/35초, 강화지대 25/40초, 역병 30/45초.
- 용병 상점은 일반·엘리트만 판매하고 토큰을 추가하지 않는다.

## 튜토리얼·캠페인·절차 생성

- 수동 튜토리얼 1 + 정규 9, 총 10스테이지 약 3시간 초안.
- 해금: 방패·대검·암살 → 창 → 궁 → 사제 → 기병 → 마법사 → 비행 → 거인 → 전체 T3.
- 튜토리얼 첫 회전 일반 검사, 두 번째 이동권 엘리트.
- 첫 Tier 2 선택은 방패병·대검전사·암살자.
- 정규 스테이지는 결정론적 StageManifest·WavePatternCard·DifficultyProfile·Validator 사용.
- 생성 실패 시 안전 Manifest 대체.

## UI·아트·오디오

- 1920×1080, 내부 960×540 정수 확대 후보.
- 좌하단 룰렛, 하단 건설·용병·전술, 우하단 벨루.
- 미니맵은 사용하지 않는다. 성문·거점·접전지 상태는 실제 전장 위에서 표시한다.
- 암살자 선택·배치 중에만 안개 속 우회로를 임시 표시한다.
- 아군 형태: 수직선·아치·방패·종·천 배너.
- 적 형태: 비대칭 균열·갑각·가시·공허.
- 10병종은 무기·자세·크기 실루엣으로 구분.
- 등급은 부속·문양·프레임·짧은 VFX로 표현.
- 벨루 작업 영문 철자 `Bellu`, 표정 8종 초안, 맑은 두 음 종 모티프.
