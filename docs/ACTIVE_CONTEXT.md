# Active Context

- Goal: 기술 스택을 결정하고 3라인 전장·건설·룰렛의 수직 슬라이스를 만들 준비를 완료한다.
- User value: 건설 조합이 룰렛 확률과 전선 운영으로 직접 연결되는 핵심 재미를 빠르게 검증한다.
- Decisions: 3라인, 후방 6노드, 라인별 전방 3노드, 중앙 접전지, 건물 기반 토큰, 적 30초 전조 웨이브.
- Scope: 현재는 기획과 저장소 준비. 엔진 코드 구현 전.
- Excluded: 멀티플레이, 영구 성장, 완성형 아트, 전설·신화 최종 규칙.
- Files: `docs/GAME_DESIGN.md`, `docs/DECISIONS_PENDING.md`, `docs/ROADMAP.md`.
- Risks: 엔진 미확정, 룰렛 경제 기대값, 접전지 스노우볼, 전방 시설 파괴 연쇄 효과.
- Next verification: 엔진과 목표 플랫폼 승인 후 Phase 0 Goal 수행.
