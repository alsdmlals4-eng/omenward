## 승인된 경계

- 첫 플레이는 별도 연습장이 아닌 실제 MapRun이다.
- Stage 1은 예고→첫 건설 선택→룰렛→병력 결과→비가역 배치→실전 전투→복기→첫 상인의 핵심 인과를 완성한다.
- Stage 2는 이동권·행/열 조작을 다전선 판단에 연결한다.
- Stage 3은 마력탑·연구·첫 T1 전술·수동 시전을 한 인과로 가르친다.
- Stage 4 Danger와 Stage 5 Boss는 새 시스템을 추가하지 않고 통합·숙련을 시험한다.
- 첫 상인은 Stage 1 정비시간에 등장하며 선택 사항과 골드 기회비용만 가르친다.
- 실제 경제·전투 결과 규칙을 사용하고 벨루는 플레이어 결정을 대신하지 않는다.
