- 첫 판 1스테이지에서 여섯 T1을 각각 한 개씩 직접 설치한다.
- 지급 골드는 필수 T1 세트의 실제 비용을 감당할 수 있어야 한다.
- T1 설명은 이름·한 문장·아이콘 수준으로 제한한다.
- T1 설치는 분기 선택이 아닌 기초 세팅이다.

- 첫 건물 전략 판단은 Stage 2의 T2 업그레이드다.
