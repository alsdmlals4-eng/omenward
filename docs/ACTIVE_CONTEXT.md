## 승인된 경계

- Stage 1은 실제 골드로 금고·농장·일반병 병영·방어탑·지휘소·마력탑 T1을 각각 한 개씩 직접 설치한다.
- 특수병 병영은 Stage 1 의무 건물이 아니다.
- 일반병 병영 T1은 기본 보병 자동생산과 TokenSource를 함께 제공한다.
- 일반병 병영 T2는 방패·대검·창·궁병·기병 중 하나로 전문화해 선택 병종 자동생산과 TokenSource를 제공한다.
- Stage 2 첫 후보는 Stage 1 일반병 병영의 방패병·궁병 두 분기로 고정한다.
- 방패병은 전선 유지·지연, 궁병은 지속 원거리 화력·비행 우선 대응을 맡는다.
- 두 후보는 같은 비용 등급이고 지급 실제 골드는 정확히 하나의 후보만 살 수 있다.
- 선택 전 후보 외 소비를 차단하고 첫 T2 비용을 예약한다.
- 기존 골드는 보존하며 선택 뒤 정상 지갑으로 사용한다.
- 선택한 병영의 분기는 확인 뒤 무료 변경할 수 없지만 미선택 분기는 전역 잠금하지 않는다.
- 다음 전투는 두 경로가 모두 유효한 혼합 지상 압력이며 한 경로만 요구하는 하드 카운터를 금지한다.
- 특수병 병영 T1은 특수병 5종 중 하나를 무작위 자동생산하지만 TokenSource를 제공하지 않는다.
- 특수병 병영 T2는 마도사·사제·암살자·비행병·거인 중 하나로 전문화해 선택 병종 자동생산과 TokenSource를 제공한다.
- 특수병은 일반병보다 기능이 강하지만 자동생산 시간이 더 길다.
- 방어탑 T2는 포격·방어 강화·저격 세 역할이다.
- 금고·농장·지휘소·마력탑은 분기 없이 기존 기능을 강화한다.
- 세팅 확인 전에는 허용된 안전 노드 사이의 무료 이동·교환을 허용한다.
- 세팅 확인 뒤에는 무료 이동을 종료하고 표준 Run 규칙을 사용한다.
- 아직 설치하지 않은 필수 T1의 실제 비용 합계를 지갑에 예약한다.
- 필수 세트 완료 전 비필수 소비를 차단한다.
- 잘못된 건설 거래는 생성·노드 점유·골드 차감을 원자적으로 취소하고 전액 복구한다.
- 여섯 T1과 세팅 확인 전에는 첫 룰렛을 열지 않는다.
