# OMENWARD GPT 이미지 생성·검수 Workflow

```text
현재 확정 결정 확인
→ planning-visualization
→ 브리프·구도·금지 요소 검토
→ final-visual-candidate
→ 실제 화면·권리·오류·일관성 검수
→ visual-qa-and-approval
→ PROJECT_ASSET_APPROVED
→ Godot 적용·런타임 확인 뒤 APPLIED_AND_RUNTIME_VERIFIED
```

생성 결과는 자동 최종 자산이 아니며, 전장·릴·HUD 이미지는 1920×1080과 1280×720 가독성을 별도로 확인한다.
