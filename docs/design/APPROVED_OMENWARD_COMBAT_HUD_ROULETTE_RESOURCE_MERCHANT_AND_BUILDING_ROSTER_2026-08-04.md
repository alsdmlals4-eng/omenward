## 1. 결정 목적

이 문서는 OMENWARD의 다음 플레이어 경험을 함께 소유한다.

- 평상시 전투 HUD에 항상 보이는 자원과 하단 기능.
- 룰렛을 열었을 때만 보이는 이동권과 릴 정보.
- 세로·가로 이동의 선택→미리보기→실행 흐름.
- Stage 종료 뒤 정비시간에 방문하는 상인.
- 버티컬 슬라이스 기본 건물 6종과 각 건물의 기획 역할.
- 우측 하단에서 상황 설명과 간단한 조언을 제공하는 벨루.

이 결정은 구현 자료구조·좌표·애니메이션·입력 장치·성능 방식은 소유하지 않는다. Codex는 아래의 플레이어 경험과 콘텐츠 역할을 보존하는 범위에서 구현 방식을 결정한다.

## 2. 핵심 재미와의 관계

> **건물로 룰렛을 만들고, 룰렛으로 전선을 지휘한다.**

HUD는 기능을 많이 노출하는 것이 아니라 다음 인과를 플레이어가 추적하게 해야 한다.

```text
전황과 자원 확인
→ 건물 선택
→ TokenSource가 바꾼 릴 구조 확인
→ SpinSnapshot에서 이동권 사용
→ 결과 확정
→ 보관·판매·배치
→ 전투 결과 확인
→ 다음 건설과 릴 편집 수정
```

## 3. 평상시 하단 HUD

평상시 하단의 큰 기능 영역은 왼쪽부터 다음 순서를 사용한다.

```text
[룰렛] [보관함] [건설] [전술스킬] [벨루]
```

- 상시 `[상점]` 버튼은 제거한다.
- `[벨루]`는 목록형 메뉴가 아니라 우측 하단 초상·대사 영역이다.
- 룰렛 이동권 수량은 평상시 HUD에 별도 원형 게이지로 표시하지 않는다.
- 룰렛 버튼은 열린 SpinSession, 미처리 PendingReward, 회전 가능 여부 같은 상태 배지만 표시할 수 있다.

## 4. 평상시 자원 표시

평상시 HUD가 상시 표시하는 핵심 자원은 다음 세 가지다.

| 자원 | 플레이어가 이해해야 할 용도 |
|---|---|
| 골드 | 건설·업그레이드·수리·룰렛 회전·상인 거래 |
| 마석 | 전술스킬 사용 자원 |
| 배치 병력 / 병력 한도 | 신규 병력 배치 가능 여부 |

### 4.1 골드

- 건물별 지속 유지비는 없다.
- 건설·업그레이드 비용과 수리 비용은 존재할 수 있다.
- 룰렛 회전과 Stage 종료 상인 거래에도 골드를 사용한다.

### 4.2 마석

- 마석은 MapRun 전용 전술 자원이다.
- 전술스킬을 사용할 때 마석을 소비한다.
- 마석은 골드·룰렛 이동권·병력 한도를 대체하지 않는다.
- MapRun은 기본적으로 느린 마석 축적 수단을 가진다.
- 마력탑은 마석 수급 또는 최대 보유량을 강화하는 건물이다.
- 정확한 수급량, 최대치와 전술스킬 비용은 별도 밸런스 결정 대상이다.

### 4.3 병력 한도

- 별도 나뭇잎 아이콘과 중복 인구 카운터를 사용하지 않는다.
- 플레이어 표시는 `배치 병력 / 병력 한도`로 통일한다.
- 농장은 병력 한도를 확장한다.
- 한도 감소가 이미 배치된 병력을 제거하거나 약화하지 않으며 신규 배치만 차단한다.

## 5. 이동권 표시와 획득

이동권은 룰렛 전용 자원이므로 **룰렛 정보 패널 안에서만 주요 수치로 표시**한다.

```text
보관 이동권 2 / 3
럭키 무료 이동 1회
```

- 평상시 전투 HUD에서 `7/10` 형태의 원형 이동권 게이지를 사용하지 않는다.
- 보관형 이동권 상한은 3개다.
- 세로 이동과 가로 이동은 같은 보관형 이동권 또는 현재 SpinSession의 럭키 무료 이동을 사용한다.
- 럭키 무료 이동을 먼저 소비한다.
- 이동 실행은 즉시 소비·확정되며 전체 되돌리기와 초기화는 없다.

획득 경로:

1. 럭키가 제공하는 현재 세션 전용 무료 이동.
2. 확정 무보상 누적 보정.
3. Stage 종료 정비시간의 상인 판매.
4. 미션·이벤트 보상.

전투 중 상시 상점에서 이동권을 반복 구매하는 규칙은 폐기한다.

## 6. 룰렛 정보 패널

룰렛 화면은 `초당 토큰 공급 대시보드`가 아니라 **현재 세 릴의 실제 구성과 조작 결과를 확인하는 작업대**다.

### 6.1 왼쪽 — 현재 토큰 출처

- 완공·활성 상태의 금고와 병영을 출처별로 표시한다.
- 각 출처가 세 릴에 결속한 토큰 계열과 현재 Tier를 표시한다.
- `개/초`, `공급 진행 중`과 같은 시간당 공급 표현은 사용하지 않는다.
- 건물 건설·업그레이드·BLOCKED·철거가 다음 live 릴에 미치는 영향을 설명한다.

예시:

```text
금고 A · T2
→ 금화 토큰 3개 결속

병영 B · 궁병 T2
→ 궁병 계열 토큰 3개 결속
```

### 6.2 가운데 — 세 원형 릴

- 왼쪽 릴, 중앙 릴, 오른쪽 릴을 하나의 통합 룰렛으로 표시한다.
- 세 릴은 상·중·하 전선에 직접 대응하지 않는다.
- 기본 화면은 현재 노출 3×3 보드를 보여준다.
- 특정 릴을 선택하면 해당 원형 배열의 전체 토큰 순서와 숨은 위·아래 인접 토큰을 확인할 수 있다.
- 토큰은 심벌, 출처 건물, Tier, `NORMAL_X`, `SOURCE_BOUND_X`를 구분할 수 있어야 한다.

### 6.3 오른쪽 — 릴 정보·Tier·보상 등급

**세로 릴 정보**

- 릴별 전체 토큰 수.
- 현재 노출 구간.
- 선택 릴의 위·아래 인접 토큰.
- 출처별 토큰 분포.

**병종 Tier**

```text
T1 = 기본 병종
T2 = 병종 분기
T3 = 선택 병종 전문화
```

**보상 등급**

```text
동일 심벌 완성선 1줄 = 일반
2줄 = 엘리트
3~7줄 = 영웅
8줄·9칸 전체 동일 = 전설 또는 위험 주기 변환
```

보상 등급은 `일반 45% / 고급 30% / 희귀 15%` 같은 독립 희귀도 추첨표로 표시하지 않는다. 최종 확정 보드의 동일 심벌 완성선 수로 결정한다.

## 7. 룰렛 이동 UX

### 7.1 세로 이동

```text
릴 선택
→ 선택 릴 전체 강조
→ 위 또는 아래 이동 미리보기
→ 실행
→ 이동권 소비
```

- 선택한 한 릴의 전체 원형 배열을 위 또는 아래로 한 칸 회전한다.
- 숨은 인접 토큰이 새로 노출된다.
- 다른 릴과 릴 소속은 바뀌지 않는다.

### 7.2 가로 이동

```text
노출 행 선택
→ 선택 행 세 토큰 강조
→ 왼쪽 또는 오른쪽 순환 미리보기
→ 실행
→ 이동권 소비
```

- 선택한 노출 행의 세 TokenInstance를 릴 사이에서 원형 순환 교환한다.
- 토큰 심벌, 출처와 보상 데이터가 함께 이동한다.
- 변경된 live 릴 배열은 이후 회전에도 영구 유지된다.

## 8. Stage 종료 상인

상인은 평상시 HUD에 상시 존재하지 않는다.

```text
Stage 종료
→ Stage 결과 정산·checkpoint
→ 정비시간
→ 상인 방문·거래
→ 미션·선택지 처리
→ 다음 Stage 시작 확정
```

- 상인은 각 Stage 종료 뒤 정비시간에 방문한다.
- 최소 핵심 판매품에 보관형 이동권이 포함된다.
- 상인 재고는 방문별 유한 재고를 사용하며 무한 반복 구매를 허용하지 않는다.
- 정확한 재고 수, 가격, 갱신과 추가 상품군은 별도 콘텐츠·경제 결정 대상이다.
- 최종 Stage 뒤에는 다음 Stage 상인이 아니라 MapRun 최종 정산 흐름을 우선한다.

## 9. 버티컬 슬라이스 기본 건물 6종

건물별 지속 유지비는 없다.

| 건물 | 핵심 역할 | 룰렛 영향 |
|---|---|---|
| 금고 | 골드 수입 | 금화 TokenSource |
| 농장 | 병력 한도 확장 | 없음 |
| 병영 | 병종 선택·Tier 성장 | 병종 TokenSource |
| 방어탑 | 전선 직접 방어 | 없음 |
| 지휘소 | 현재 MapRun 전체 아군 병력 오라 | 없음 |
| 마력탑 | 마석 수급·최대 보유량 강화 | 없음 |

### 9.1 금고

- 골드 수입을 제공한다.
- 세 릴에 금화 토큰 하나씩을 결속한다.
- 금고 Tier는 금화 당첨 배율을 이중 강화하지 않는다.

### 9.2 농장

- 배치 병력 한도를 확장한다.
- 별도 유지비·초당 식량 소비 UI는 사용하지 않는다.
- 기존 병력을 강제 제거하지 않고 신규 배치 가능 여부만 바꾼다.

### 9.3 병영

- 병종 토큰을 공급하는 TokenSource다.
- T1은 공통 기본 병종, T2는 병종 분기, T3는 선택 병종의 전문화다.
- 병력을 시간당 직접 생산하거나 당첨을 보장하지 않는다.

### 9.4 방어탑

- 기본 건물 중 직접 공격 가능한 방어 건물이다.
- T2에서 연사 계열과 포격 계열로 분기할 수 있다.
- 전선 역할과 공격 대상 차이는 유지하되 정확 수치는 별도 밸런스 대상이다.

### 9.5 지휘소

지휘소는 주변 반경 오라가 아니라 **현재 MapRun의 모든 아군 배치 병력에 적용되는 전역 군단 오라**다.

- 상단·중단·하단 전선의 모든 아군 전투 병력에 적용한다.
- 건물이 활성·아군 소유일 때만 오라가 유효하다.
- T2 돌격 계열과 수비 계열의 역할 구분은 유지한다.
- 같은 계열 지휘소는 중첩하지 않고 가장 높은 Tier 하나만 적용한다.
- 돌격 계열과 수비 계열은 함께 활성화할 수 있다.
- 정확한 오라 효과와 수치는 별도 콘텐츠·밸런스 결정 대상이다.

### 9.6 마력탑

- MapRun의 마석 수급 또는 최대 보유량을 강화한다.
- 전술스킬 운용을 지원하지만 스킬 자체를 자동 사용하지 않는다.
- 기본적으로 룰렛 토큰을 공급하지 않는다.
- 마석 수급형과 저장형 업그레이드 분기는 별도 콘텐츠 결정 대상이다.

## 10. 벨루

- 벨루 목록·전용 관리 화면은 사용하지 않는다.
- 벨루는 우측 하단 초상과 말풍선으로 등장한다.
- 위험한 전선, 보스 예고, 병력 한도, 마석 충전, TokenSource 변경, 미처리 보상을 설명한다.
- 플레이어 대신 전선·건물·룰렛 결과를 자동 결정하지 않는다.
- 우선순위가 낮은 반복 대사로 전장을 가리지 않는다.

예시:

```text
“마석이 충분해요. 전술스킬을 사용할 수 있어요!”
“궁병 병영이 완성돼서 다음 회전부터 토큰이 활성화돼요!”
“하단 전선이 밀리고 있어요. 보관함 병력을 확인해 보세요!”
```
