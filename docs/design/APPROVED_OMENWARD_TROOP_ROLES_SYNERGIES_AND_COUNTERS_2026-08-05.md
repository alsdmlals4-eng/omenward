## 1. 결정 요약

```text
ROSTER_BASELINE: 10
ROSTER_COUNT_IS_NOT_SACRED
ROSTER_MIN_MAX: NOT_PRESET
```

현행 열 종은 첫 정본 기준선이며 불변 수량이 아니다. 병종 수는 역할 공백·중복·룰렛 학습량·보관함 복잡도·아트 제작비를 근거로 별도 승인하여 늘리거나 줄일 수 있다.

```text
ADD_UNIT_ONLY_IF
= 기존 병종으로 표현할 수 없는 압력 대응·전선 판단·Route 판단을 만든다.

REMOVE_OR_REPLACE_IF
= 다른 병종과 역할·표적·배치 판단·포기 비용이 실질적으로 같다.
```

단순 콘텐츠 증량, 외형만 다른 중복, 한 Stage를 여는 열쇠 역할만 수행하는 병종은 추가하지 않는다.

## 2. 핵심 재미 연결

```text
예고된 압력
→ 병영·건물로 병종 결과의 방향 설계
→ 룰렛에서 T1/T2 병종 획득
→ 보관·판매·한 전선 비가역 배치
→ 역할·시너지·카운터 결과 복기
```

병종은 단순 수치 차이가 아니라 다음을 바꾼다.

- 어떤 압력·표적·Layer를 우선 처리하는가.
- 어느 전선·Route에 커밋할 가치가 있는가.
- 어떤 병종이 역할 수행 시간을 만들어 주는가.
- 무엇을 얻는 대신 어떤 역할을 포기하는가.

## 3. 열 종 기준선

| 병종 | 전장 역할 | 주 대응 압력 | 명확한 포기 비용 |
|---|---|---|---|
| 방패수호병 | 전선 고정·후열 보호 | MASS·INFILTRATION | 낮은 처치력·기동성 |
| 대검병 | 근접 광역·밀집 해체 | MASS | 낮은 방어·대공 불가 |
| 창병 | 대형·돌진·공성 차단 | SIEGE·ARMORED | 다수 소형 처리 취약 |
| 궁수 | 공중 억제·원거리 견제 | FLYING | 장갑 대상·근접 취약 |
| 마도사 | 장갑 약화·제한 광역 | ARMORED·MASS | 낮은 생존력·느린 템포 |
| 사제 | 유지력·보호·회복 | 장기 복합 압력 | 직접 처치력 부족 |
| 암살자 | 우회 Route 추적·후열 제거 | INFILTRATION·SIEGE | 전선 유지·점령 취약 |
| 기병 | 공개 Route 신속 대응 | INFILTRATION·SIEGE | 장기 교전·대공 취약 |
| 비행병 | 공중 우세·후방 급습 | FLYING·SIEGE | 점령 불가·대공에 취약 |
| 거인 | 장갑 돌파·승리 전선 구조물 파괴 | ARMORED·SIEGE | 느림·다전선 대응 불가 |

기존 프로토타입의 이름과 외형 계보는 가능한 한 유지한다. 다만 암살자·기병·비행병은 각각 `우회 추적 / 공개 Route 대응 / 공중 우세`로 역할을 분리한다.

## 4. 다섯 압력 대응

```text
압력별 최소 두 병종 대응 경로
단일 하드키 병종 금지
```

| 압력 | 주 대응 병종 | 보조 대응 | 금지되는 단일 정답 |
|---|---|---|---|
| MASS | 대검병·마도사 | 방패수호병 | 광역 병종 하나로 자동 해결 |
| ARMORED | 마도사·창병 | 거인 | 방어 무시 하나로 모든 장갑·Boss 해결 |
| FLYING | 궁수·비행병 | 후속 전술스킬 | 궁수 미보유 시 통과 불가 |
| INFILTRATION | 암살자·기병 | 후방 방패수호병 | 숨은 우회 Route로 특정 병종 강제 |
| SIEGE | 창병·기병 또는 암살자 | 거인의 역공 | 공성 저지와 구조물 파괴를 한 병종이 모두 최적 수행 |

병종 대응은 건물·전술 대응을 대체하지 않는다. 다섯 압력 각각은 병종 경로 두 개 이상과 건물·전술·룰렛 준비 경로를 함께 가져야 한다.

## 5. 행동 기반 시너지

```text
행동 기반 시너지
단순 세트 보너스: FORBIDDEN
```

시너지는 보유 수량에 따른 숨은 수치 보너스가 아니라 전장에서 관찰되는 행동 연결이다.

```text
방패수호병이 적을 고정
→ 대검병·마도사가 밀집을 처리

마도사가 장갑을 약화
→ 창병·거인이 핵심 표적을 마무리

암살자가 우회 Route를 추적·표시
→ 기병·궁수가 공개된 목표를 차단

사제가 비가역 배치 전선을 유지
→ 전문 병종이 역할을 수행할 시간 확보

궁수·비행병이 공중을 통제
→ 거인과 전열 병력이 지상 목표에 집중
```

가드레일:

- 각 병종은 단독으로도 최소 역할을 수행한다.
- 특정 짝이 없으면 기능하지 않는 의존형 설계 금지.
- 하나의 고정 조합이 모든 Stage의 최적해가 되면 Stop-ship.
- 시너지 원인과 결과를 전장·결과 로그·복기에서 설명할 수 있어야 한다.

## 6. 병영 전문화 연결

```text
전열 병영 가중 계열
= 방패수호병 / 대검병 / 창병 / 거인

기동 병영 가중 계열
= 궁수 / 암살자 / 기병 / 비행병

공통 지원 계열
= 마도사 / 사제

반대 계열 영구 삭제: FORBIDDEN
```

병영 분기는 반대 계열을 삭제하거나 하드 잠금하지 않는다. 다음 결과의 방향만 조정한다.

- TokenSource 등장 가중.
- 보상 후보 역할 분포.
- 해당 계열 승급 기회.
- Stage 예고에 맞춘 결과 예측 가능성.

공통 지원 계열은 어느 한 분기의 독점물이 아니다. 정확한 가중치·등장 확률·승급 비용은 시뮬레이션 후 확정한다.

## 7. Tier·룰렛·자산 계약

```text
T1 병종 토큰 = 실제 T1 인게임 이미지
T2 병종 토큰 = 실제 T2 인게임 이미지
T3 병종 토큰 = FORBIDDEN
결과 Preview = 실제 지급 병종 이미지
```

- T1은 역할을 처음 읽히는 기본형이다.
- T2는 같은 역할을 안정화하거나 특정 압력에 전문화한다.
- T3는 표적 우선순위·Route 대응·Layer 상호작용·전선 유지 방식 중 하나를 바꾼다.
- T3는 결과 Preview·보관함·배치 카드·전장 실제 병종에서 표현한다.
- 룰렛용 별도 T3 토큰은 만들지 않는다.

## 8. 전선·Route·Layer 규칙

```text
FREE_RECALL: FORBIDDEN
FREE_CROSS_LANE_MOVE: FORBIDDEN
HIDDEN_ROUTE_REACTION: FORBIDDEN
LAYER_UI_MISMATCH: FORBIDDEN
```

- 일반 병력은 배치 뒤 자유 전선 이동·회수·판매가 불가능하다.
- 기병의 신속 대응은 배치 전 선택과 공개 Route 안의 행동이며 자유 전선 횡단이 아니다.
- 암살자의 추적은 Stage 시작 전에 공개된 우회 Route와 목표에만 반응한다.
- 궁수와 비행병의 공격 가능 Layer는 UI·시각·실제 판정이 일치해야 한다.
- 비행병의 이동은 점령·구조물 상호작용을 자동 허용하지 않는다.
- 거인은 느린 결정 전선 병종이며 세 전선을 동시에 해결하지 않는다.

## 9. 정보 공개·UX

병종 카드·보관함·배치 Preview에는 다음을 표시한다.

```text
핵심 역할
공격 가능 Layer
우선 표적
유리한 압력
명확한 약점
배치 뒤 이동 가능 여부
현재 Tier와 T3 역할 변화
```

한 화면에서 전체 상성표를 강제하지 않는다. 현재 후보와 예고 압력의 관계를 우선 표시하며, 역할 아이콘과 실제 행동이 다르면 Stop-ship이다.

## 10. 로스터 증감 Gate

```text
1. 역할 공백 또는 중복 증거 제시
2. 기존 병종 역할 수술로 해결 가능한지 검토
3. 이름·외형 계보 보존 가능성 검토
4. 룰렛·보관함·학습량·아트 비용 영향 검토
5. 적대적 검토와 시뮬레이션 Gate
6. 별도 정본 변경 승인
```

현재 기준선은 10종이다. 고정 수량에 맞추기 위해 역할을 억지로 합치거나 쪼개지 않는다.

## 11. 벤치마킹 적용

채택:

- 다수 유닛을 빠르게 구분하는 명확한 역할 분류.
- 읽을 수 있는 강점·약점·카운터 관계.
- 특정 조합에 조기 고정되지 않는 유연한 구성.

비채택:

- 타 게임의 피해 배율·비용·생산 체계 직접 복제.
- 단일 가위바위보로 모든 교전을 결정.
- 강한 세트 보너스로 고정 조합 강제.
- 병종별 별도 자원·미니게임·독립 메뉴.

공식 근거는 설계 Spec의 링크를 따른다.
