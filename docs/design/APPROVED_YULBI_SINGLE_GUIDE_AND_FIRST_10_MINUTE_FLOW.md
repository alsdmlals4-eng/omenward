- 상태: **핵심 흐름 승인됨 / 적 수치·연출 타이밍 플레이테스트 대기**
- 승인일: 2026-07-14
- 우선 적용 문서:
  - `docs/design/APPROVED_YULBI_FINAL_VISUAL_AND_TRANSIENT_STATE_RULE.md`
  - `docs/design/APPROVED_YULBI_MASCOT_CHARACTER_AND_UI_AUDIO_GUIDE.md`
  - `docs/design/APPROVED_DOPAMINE_DRIVEN_DESIGN_AND_FIRST_10_MINUTES.md`

이 문서는 첫 10분의 실제 플레이 순서, HUD 공개 순서, 결정론적 룰렛 결과, 초기 웨이브와 실패 복구를 정의한다. 정찰관·부관 등 별도 안내 인물에 관한 이전 문구와 충돌할 경우 이 문서가 우선한다.

## 1. 율비 단일 안내자 원칙

프로토타입과 첫 캠페인에서 다음 기능은 모두 율비가 담당한다.

1. 세계관 기본 설명
2. 적 웨이브의 라인·병종·수량·도착 시간 보고
3. 튜토리얼 조작 안내
4. 현재 전술적 위험과 선택지 요약
5. 룰렛·토큰·건물의 세계관식 번역
6. 축복·저주·경계의 율에 관한 암시
7. 룰렛 등급·방어 성공·패배의 감정 반응

정찰관·부관은 기능성 안내 NPC로 두지 않는다.

- 별도의 정찰관 초상·음성·말풍선 없음
- 별도의 부관 조언 패널 없음
- 일반 병사와 장교는 배경 인물·캠페인 사건 인물로 등장할 수 있지만 시스템 설명을 분담하지 않음
- 플레이어가 받아야 하는 필수 정보는 `율비 + HUD` 두 경로로 통일

장점:

- 플레이어가 누구의 말을 들어야 하는지 즉시 이해
- 설명 캐릭터가 늘어나는 복잡도 방지
- 마스코트 인지도와 애착 강화
- 음성 제작량과 UI 초상 공간 감소
- 위험 보고·세계관 암시·보상 반응이 한 캐릭터의 감정 흐름으로 연결

위험:

- 율비 대사가 과도하게 많아질 수 있음
- 군사 보고와 귀여운 감정 반응의 톤이 충돌할 수 있음

대응:

- 숫자 정보는 HUD 카드가 주체, 율비는 핵심 한 문장만 말함
- 보고 대사는 짧고 단정하게, 감정 대사는 위험 해소 뒤에만 사용
- 같은 상황 반복 시 음성 없이 문양 점멸과 아이콘만 사용

## 2. 율비 발화 모드

율비는 역할마다 다른 인물처럼 말하지 않고 같은 성격 안에서 발화 목적만 바꾼다.

| 모드 | 목적 | 말투 |
|---|---|---|
| 감지 | 새로운 징조·보스·축복·저주 발견 | 짧고 즉각적 |
| 보고 | 라인·병종·수량·시간 전달 | 숫자를 정확히, 단정하게 |
| 안내 | 새 시스템 최초 조작 | 한 행동만 요청 |
| 조언 | 위험과 가능한 대응 요약 | 명령하지 않고 선택지 제시 |
| 암시 | 경계의 율과 과거 사건 표현 | 짧고 불완전하게 |
| 반응 | 당첨·역전·패배 감정 전달 | 상황 종료 뒤 짧게 |

예시:

```text
감지: 지휘관, 상단 경계가 울려요.
보고: 전사형 넷. 도달까지 30초.
안내: 병영을 지으면 전사 증원이 늘어요.
조언: 포탑을 세우거나 바리케이드로 시간을 벌 수 있어요.
암시: 징조는 틀리지 않아요. 선택이 달라질 뿐이에요.
반응: 좋아요! 지휘관의 선택이 통했어요.
```

한 이벤트에서 율비가 연속으로 여러 문장을 길게 말하지 않는다. 감지·보고는 한 말풍선으로 합쳐 최대 두 줄로 표시할 수 있다.

## 3. 첫 10분 전체 목표

첫 10분 종료 시 플레이어가 다음을 직접 경험해야 한다.

- 자신이 괴물 군단을 막는 최전선 지휘관임을 이해
- 일시정지 상태에서 모든 핵심 명령을 내릴 수 있음을 이해
- 병영이 전사 토큰과 증원 확률을 높이는 것을 확인
- 룰렛 한 줄 완성과 일반 병력 획득
- 유닛을 원하는 라인에 배치해 첫 웨이브 방어
- 포탑 또는 바리케이드로 위험한 웨이브 역전
- 행·열 이동으로 일반 결과를 엘리트 결과로 개선
- 병영 Tier 2에서 방패병·대검병·광전사 중 하나를 선택
- 첫 10분 동안 핵심 루프를 최소 두 번 반복

```text
징조 확인
→ 준비 수단 선택
→ 건설·룰렛
→ 병력 획득
→ 라인 배치
→ 방어 결과 확인
→ 다음 성장 선택
```

## 4. 기본 HUD 공개 원칙

첫 화면에서 핵심 HUD를 모두 숨기지는 않는다. 전체 구조는 보여주되 현재 필요한 기능만 강조한다.

### 항상 표시

- 상·중·하 세 라인
- 플레이어 본진 체력
- 금화와 식량
- 현재 게임 속도·일시정지
- 다음 웨이브 카드
- 율비 도크

### 순차 활성화

| 시점 | 활성 기능 |
|---|---|
| 시작 | 일시정지, 웨이브 카드 |
| 첫 건설 | 건설 메뉴, 병영 |
| 병영 완공 | 룰렛, 토큰 간단 표시 |
| 첫 병력 획득 | 대기칸, 라인 배치 |
| 두 번째 웨이브 | 포탑, 바리케이드 |
| 두 번째 룰렛 | 행·열 이동, 되돌리기, 확정 |
| 첫 역전 뒤 | 병영 Tier 2 업그레이드 |

상점 전체, Tier 3, 상태이상 상세, 제약, 결전 웨이브 정보는 첫 10분에 비활성 또는 접힌 상태로 둔다.

## 5. 0:00~10:00 화면 단위 흐름

### 0:00~0:15 — 전장과 역할

화면:

- 카메라가 최전선 요새에서 세 라인을 짧게 훑음
- 상단 경계 문양만 주황색으로 점등
- HUD는 본진 체력·금화·식량·속도·웨이브 카드만 표시
- 율비가 기본형에서 짧게 경고색으로 반응

율비:

> 지휘관, 경계가 울려요.

> 상단에 전사형 넷. 도달까지 30초예요.

학습 목표:

- 플레이어 역할
- 공격 예정 라인
- 30초 준비 시간

### 0:15~0:35 — 일시정지

화면:

- 일시정지 버튼과 단축키만 강조
- 버튼을 누르면 전장 유닛·웨이브 타이머가 멈춤
- 금화·건설 버튼은 조작 가능 상태 유지

율비:

> 잠깐 멈춰도 괜찮아요. 명령은 계속 내릴 수 있어요.

완료 조건:

- 플레이어가 일시정지 1회 사용

실패 복구:

- 5초 동안 누르지 않으면 게임이 자동 일시정지되고 버튼 위치를 다시 점등

### 0:35~1:05 — 첫 병영 건설

화면:

- 후방 빈 노드 하나 강조
- 건설 메뉴에서 병영만 활성 강조
- 비용과 완공 시간을 짧게 표시
- 건설 후 진행도와 현재 체력 표시

율비:

> 병영을 지으면 전사 증원이 늘어요.

완공 반응:

- 병영에서 전사 표식 세 개가 각 릴로 이동
- 토큰 장부는 `전사 +1`만 간단 표시

율비:

> 전술판에 전사 표식이 연결됐어요.

학습 목표:

- 건물과 룰렛 확률의 연결

### 1:05~1:45 — 첫 룰렛

화면:

- 룰렛 버튼 강조
- 회전 비용 표시
- 첫 회전은 튜토리얼 결정론적 결과 사용

최종 보드:

```text
X     전사   X
전사  전사   전사
X     X      X
```

판정:

- 중앙 가로 1줄 완성
- 일반 검사 1명 생성

연출:

- 중앙줄 점등
- `1줄 → 일반` 텍스트
- 검사 카드와 1스킬 `횡베기` 아이콘 1초 노출
- 율비는 일반 당첨 반응 후 기본형 복귀

율비:

> 검사 증원 확보! 상단에 보낼 수 있어요.

학습 목표:

- 같은 심벌 3개
- 완성 줄과 일반 등급
- 룰렛 결과가 실제 병력으로 이어짐

### 1:45~2:15 — 첫 배치

화면:

- 대기칸 검사 카드 강조
- 상단 라인 배치 영역 점등
- 중단·하단도 보이지만 위험 라인은 상단으로 명확히 표시

율비:

> 상단을 선택하면 바로 전선으로 갑니다.

완료 조건:

- 검사를 상단에 배치

실패 복구:

- 교전 전에는 무료로 라인 재배치 가능
- 다른 라인에 놓으면 `상단 공세 예정` 아이콘을 보여주되 강제 취소하지 않음

### 2:15~3:10 — 첫 웨이브

웨이브 1:

```text
라인: 상단
구성: 소형 근접 괴물 4기
전조: 30초
목적: 검사 1명만으로 방어 가능
```

전투 목표:

- 배치 뒤 10초 안에 첫 교전
- 검사가 `횡베기`를 최소 한 번 사용
- 전투 종료 시 검사 체력 30~60% 남는 초기 밸런스

율비 교전 직전:

> 곧 부딪혀요. 검사의 횡베기를 봐주세요.

방어 성공:

> 첫 공세를 막았어요. 다음 징조가 벌써 움직여요.

### 3:10~3:35 — 두 번째 징조

웨이브 카드:

```text
상단: 소형 근접 6기
중단: 소형 근접 3기
도달: 30초
```

화면:

- 상단 위험도 높음
- 포탑 건설과 바리케이드 전술 명령 동시 해금
- 두 대응 모두 가능한 선택지로 표시

율비:

> 이번엔 두 라인이에요. 상단이 더 위험해요.

> 포탑을 세우거나 바리케이드로 시간을 벌 수 있어요.

### 3:35~4:15 — 첫 전술 선택

선택 A — 포탑:

- 상단 전방 노드에 포탑 건설
- 적이 접근하는 동안 건설 진행
- 완공 시 즉시 공격 시작

선택 B — 바리케이드:

- 상단 전술 지점에 설치
- 적을 지연해 검사와 후속 병력이 합류할 시간 확보

선택하지 않은 수단은 이후에도 사용 가능하지만 강제 학습하지 않는다.

율비 포탑 선택:

> 완공될 때까지 버티면 전선이 달라져요.

율비 바리케이드 선택:

> 여기에 세우면 적을 잠깐 막을 수 있어요.

### 4:15~5:15 — 첫 역전 웨이브

웨이브 2:

- 상단 6기, 중단 3기
- 상단 적은 포탑 또는 바리케이드가 없으면 본진에 일부 피해를 줄 수 있음
- 선택한 수단을 사용하면 안정적으로 방어
- 중단 3기는 튜토리얼 임시 수비대 또는 본진 방어 사격으로 버티되, 이후 병력 배치 필요성을 보여줌

핵심 연출:

- 포탑은 적 선두 도착 직전 완공되도록 초기 시간 조정
- 바리케이드는 파괴 직전 마지막 적을 저지
- 성공 원인을 화면에 `포탑 완공`, `바리케이드 지연`으로 짧게 표시

율비:

> 좋아요! 지휘관의 선택이 통했어요.

### 5:15~5:45 — 두 번째 룰렛과 이동권

보상:

- 이동권 1장 지급
- 룰렛 결과 미리보기와 `되돌리기`, `확정` 활성

이동 전 보드:

```text
X     전사   X
전사  전사   전사
X     X      전사
```

이동 전 판정:

- 중앙 가로 1줄
- 일반 전사 결과

율비:

> 지금도 한 줄이에요. 위쪽 줄을 왼쪽으로 움직여 보세요.

이동 후 보드:

```text
전사  X      X
전사  전사   전사
X     X      전사
```

이동 후 판정:

- 중앙 가로 1줄
- 왼쪽 위에서 오른쪽 아래 대각선 1줄
- 총 2줄 → 엘리트 전사 1명

율비:

> 두 줄이에요! 엘리트 증원으로 바뀌었어요.

학습 목표:

- 결과 조작
- 미리보기
- 이동권은 확정 시 소비
- 2줄은 엘리트

실패 복구:

- 확정 전 이동 횟수 제한 없이 되돌리기 가능
- 20초 이상 막히면 목표 행에 방향 화살표 표시

### 5:45~6:20 — 엘리트 배치

화면:

- 엘리트 전사 카드에 `강화된 1스킬` 강조
- 중단 라인 점등

율비:

> 엘리트는 첫 기술이 강화돼요. 중단을 맡겨볼까요?

플레이어는 다른 라인에 배치할 수 있지만 중단이 권장된다.

### 6:20~7:20 — 두 번째 핵심 루프

웨이브 3:

```text
상단: 소형 근접 4기
중단: 소형 근접 6기
하단: 없음
```

목표:

- 기존 검사·포탑 또는 바리케이드가 상단 방어
- 엘리트가 중단에서 강화된 1스킬을 사용
- 일반과 엘리트의 전투 차이를 즉시 보여줌

율비:

> 중단의 반응이 강해졌어요. 강화된 기술이에요.

### 7:20~8:10 — 병영 Tier 2 선택

보상:

- 병영 Tier 2 업그레이드 비용 지급
- 방패병·대검병·광전사 선택 카드 표시

카드의 최초 설명은 한 줄로 제한한다.

| 병종 | 최초 한 줄 설명 |
|---|---|
| 방패병 | 원거리 공격을 견디며 전선을 지킵니다. |
| 대검병 | 넓게 베고 적 방어를 낮춥니다. |
| 광전사 | 다칠수록 빨라지고 스스로 회복합니다. |

세부 수치와 전체 패시브 설명은 `상세 보기`에서만 표시한다.

율비:

> 병영을 강화하면 전사의 역할을 고를 수 있어요.

선택 후:

- 병영 외형 변경
- 패시브 1 강화 + 패시브 2 생성 표시
- 전사 공유 토큰은 유지됨을 `토큰 유지`로 짧게 표시

율비:

> 전사 표식은 그대로예요. 이제 선택한 병종도 함께 올 수 있어요.

### 8:10~9:20 — 선택 병종 체험 웨이브

병영 자동 생산으로 선택한 일반 병종 1명을 즉시 준비 완료 상태로 제공한다.

웨이브 4는 같은 구성으로 시작하되 선택 병종마다 다른 강점이 보이도록 설계한다.

```text
라인: 상단·중단 분산
구성: 소형 근접 다수 + 원거리 적 2기
```

- 방패병: 원거리 피해 감소와 밀치기 체감
- 대검병: 밀집 적 범위 피해와 파갑 체감
- 광전사: 체력이 낮아질수록 공격속도·회복 체감

어느 선택도 실패 정답이 되지 않게 구성한다.

율비는 선택 병종에 따라 한 문장만 말한다.

- 방패병: `화살을 잘 버텨요. 앞줄을 맡기기 좋아요.`
- 대검병: `적이 뭉쳤어요. 넓은 베기가 잘 들어가요.`
- 광전사: `다칠수록 빨라져요. 체력이 너무 낮아지는지만 봐주세요.`

### 9:20~10:00 — 마무리와 다음 목표

화면:

- 네 번째 웨이브 방어 성공
- 세 라인 카메라 줌아웃
- 적 전방 시설과 먼 적 본진 실루엣 공개
- 다음 해금 예고: 기병·창병·궁병 계열, 영웅·전설 등급

율비:

> 이곳은 막아냈어요. 하지만 경계 너머의 징조는 더 커지고 있어요.

> 다음 공세부터는 지휘관이 직접 전선을 키워야 해요.

적 병종 이름·외형은 세계관 명칭 작업에서 확정한다. 이 문서는 역할과 수량 구조만 승인한다.

## 7. 튜토리얼 결정론 계약

- 튜토리얼은 절차적 생성 대상에서 제외
- 첫 룰렛 보드는 항상 일반 검사 1줄
- 두 번째 룰렛은 이동 전 1줄, 지정 이동 후 2줄
- 룰렛 애니메이션은 무작위처럼 보일 수 있으나 최종 보드는 고정
- 플레이어가 확정 전 다른 이동을 실험하는 것은 허용
- 두 번째 결과는 최종적으로 엘리트 전사 획득이 가능하도록 복구 안내 제공
- 첫 포탑 완공 시점과 적 선두 도착 시점은 간발의 차이 연출을 위해 고정 범위로 조정
- Tier 2 세 병종 중 어느 것을 선택해도 웨이브 4 방어 가능

## 8. 실패 복구 계약

### 건설 실수

- 잘못된 노드는 비용 차감 전 차단
- 이유를 한 문장으로 표시
- 첫 병영 건설 중 취소는 전액 환불

### 룰렛 이해 실패

- 첫 회전 결과는 자동으로 보관함에 들어감
- 배치 전까지 다음 단계가 진행되지 않음
- 두 번째 이동은 확정 전 무제한 되돌리기

### 배치 실수

- 첫 교전 전 무료 라인 변경
- 첫 웨이브 실패 시 본진 피해 상한 적용
- 대기 중 비상 검사 1명을 한 번 제공

### 포탑·바리케이드 미사용

- 웨이브 2에서 본진이 파괴되지 않게 피해 상한 적용
- 율비가 남은 수단 하나를 다시 강조
- 필요 시 비상 바리케이드 1회 무료 제공

### Tier 2 선택 지연

- 전투 시간 자동 일시정지
- 선택 카드에는 역할 한 줄만 표시
- `추천 없음`, 세 선택 모두 유효함을 명시

## 9. 율비 대사 빈도 계약

첫 10분에는 설명이 집중되므로 일반 전투보다 발화가 많을 수 있다.

- 같은 화면에서 음성 대사 최대 2개
- 연속 대사 사이 최소 0.6초
- 필수 조작 대사는 행동 완료 시 즉시 종료
- HUD 숫자 전체를 읽지 않고 핵심 라인·병종·수량·시간만 발화
- 경고 중 룰렛 보상 감정 반응은 축소 가능
- 플레이어가 빠르게 행동하면 남은 안내 음성을 취소
- 튜토리얼 재플레이 시 `전체 안내`, `핵심 안내`, `안내 없음` 선택 가능
