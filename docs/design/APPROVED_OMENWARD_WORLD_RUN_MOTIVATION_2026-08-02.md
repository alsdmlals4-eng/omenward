## 1. 결정 요약

하나의 20 Stage MapRun은 **베일의 징조로 사전에 감지된, 서로 다른 실제 경계 공세를 막는 하나의 방어 작전**이다.

```text
OMEN_DETECTED
→ FORWARD_DEFENSE_OPERATION
→ FOUR_ACTS / TWENTY_STAGES
→ BREACH_SEALED_OR_FRONT_EVACUATED
→ RECORDS_AND_DOCTRINE_RETURN_TO_PROFILE
```

징조는 시간 반복이나 가상 시뮬레이션이 아니다. 실제로 다가올 공세의 전선·적 구성·치명적 행동을 제한적으로 예고하는 관측 현상이다. 전투와 피해는 현실이며, 승리와 패배도 실제 세계의 결과로 남는다.

## 2. MapRun의 세계관 의미

### 2.1 시작

- 베일에서 발생한 이상 징조가 새로운 침공 가능성을 알린다.
- 지휘관과 벨루는 징조를 해석해 방어가 필요한 전선과 예상 공세를 확인한다.
- 플레이어는 해당 지역의 전진 방어선을 맡아 제한된 건물·병력·릴 구조로 작전을 준비한다.
- 각 MapRun은 같은 하루의 반복이 아니라 별개의 지역·시점·공세 조합을 가진 실제 작전이다.

### 2.2 진행

- 20 Stage와 4막은 하나의 공세가 정찰·돌파·공성·경계파쇄 단계로 고조되는 구조다.
- Stage 5·10·15·20은 공세의 전환점이며 단순한 난이도 숫자가 아니라 적이 침공 방식을 바꾸는 사건이다.
- 플레이어가 읽는 공세 정보는 징조와 정찰·전선 보고가 합쳐진 결과다.
- 징조는 확정 미래가 아니라 다가오는 위협의 구조를 보여준다. 플레이어의 건설·릴 설계·배치에 따라 실제 결과는 달라진다.

### 2.3 승리

- Stage 20 승리는 해당 공세의 핵심 경계파쇄자를 격퇴하고 하나의 균열 또는 침공로를 봉쇄한 결과다.
- 한 작전의 승리는 실제 영토와 생존자를 지키지만, 세계의 모든 베일과 전쟁을 끝내지는 않는다.
- 새로운 징조와 다른 침공로가 존재하므로 다음 MapRun이 성립한다.

### 2.4 패배

- 본진 HP 0은 해당 전진 방어선의 붕괴와 작전 실패를 뜻한다.
- 패배는 시간 되감기나 없었던 사건으로 처리하지 않는다.
- 생존 인원·벨루의 관측·회수된 작전 기록·정산된 자원은 후방으로 돌아갈 수 있지만, 잃은 거점과 피해는 세계의 역사로 남는다.
- 제품 paid Retry는 세계 전체를 되감는 능력이 아니라, 같은 공세에서 확보한 비상 예비 전력으로 실패 Stage 준비 지점부터 한 번 재투입하는 작전적 조치다.

## 3. 반복 플레이와 Profile 성장

Profile은 한 지휘관의 무한 능력치가 아니라 여러 실제 작전에서 축적된 **전술 교리·보급망·기록·준비 체계**다.

- 수평 해금: 과거 작전에서 검증된 대체 교리·건물/TokenSource 선택지·미션·분석 기록.
- 제한된 편의: 작전 계획안·복기 기록·제한된 시작 보관 체계.
- 준비 보정: 누적된 조직적 준비 수준에서 한 MapRun에 하나 선택하는 유한한 초기 지원.
- paid Retry: 정산된 Profile 자원을 소모하는 비상 재투입.

Profile 성장은 전쟁이 지속되며 방어 조직이 학습하는 결과다. 노가다로 세계의 법칙을 무시하는 초월적 능력 누적이 아니다.

## 4. 벨루의 역할

- 벨루는 시간 루프의 유일한 기억자가 아니다.
- 서로 다른 실제 공세를 관측하고, 징조와 전선 결과를 기록하며, 다음 작전에 사용할 인과를 설명하는 안내자다.
- 벨루의 기록은 Profile의 분석·도감·복기 계보와 연결될 수 있다.
- 벨루는 미래를 완전히 아는 예언자나 자동 지휘자가 아니다.
- 징조가 보여주지 않은 결과와 플레이어 선택의 책임을 대신하지 않는다.
