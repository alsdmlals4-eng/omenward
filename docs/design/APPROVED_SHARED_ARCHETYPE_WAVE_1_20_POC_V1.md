## 1. 웨이브 데이터 원칙

적 웨이브는 별도 적군 병종 데이터를 만들지 않는다.

```text
공용 archetype_id
+ Tier
+ Rank
+ 수량
+ 라인
+ 출격 시점
+ enemy owner/team
+ veil visual set
```

- 아군과 적군은 같은 10병종 전투 데이터와 애니메이션 타이밍을 사용한다.
- 적군 표시명과 이미지만 베일종 형태로 교체한다.
- 적 위협 차이는 수량, Tier, 등급, 라인 편성, 출격 시점과 보스 패키지로 만든다.
- 일반 적군 전용 스탯·스킬·타기팅 복사본을 만들지 않는다.

## 2. 공용 병종의 적군 표시

| 공용 archetype | 적군 표시명 후보 | 베일의 징조 태그 |
|---|---|---|
| 방패병 | 베일 갑각수 | `[방어]` |
| 대검전사 | 균열도살자 | `[파쇄]` |
| 암살자 | 그림자갈퀴 | `[암살]` |
| 창병 | 가시창병 | `[대형저지]` |
| 궁병 | 침사수 | `[원거리]`, `[대공]` |
| 기병 | 균열기수 | `[돌진]` |
| 사제 | 베일 표식자 | `[지원]` |
| 마법사 | 공허주술사 | `[마법]`, `[제어]` |
| 비행병 | 베일익수 | `[비행]` |
| 거인 | 파성거체 | `[대형]`, `[공성]` |

표시명은 로컬라이징·세계관 별칭이며 새 전투 데이터 ID가 아니다.

## 5. 라인 배분

- W1~4: 주력 60%, 보조 40%, 세 번째 라인은 비우거나 소수.
- W5~9: 주력 50%, 보조 30%, 견제 20%.
- W10~14: 주력 45%, 보조 35%, 견제 20%.
- W15: 보스 주력 65%, 나머지 두 라인 각 17.5%.
- 같은 특수 위협을 세 라인에 동시에 배치하지 않는다.
- 비행·암살·지원 중 두 종류 이상을 같은 라인에 넣으면 T-30 징조에 모두 공개한다.

## 6. 적 생산시설 파괴

적 생산시설은 공용 `archetype_id`의 예약 출격분을 약화한다.

```text
시설 파괴 시
- 아직 출격하지 않은 현재 웨이브 해당 archetype 수량 -30%
- 다음 웨이브 해당 archetype Threat -50%
- 이후 웨이브는 StageManifest의 예비 시설 여부에 따라 -20%
```

- 이미 전장에 나온 유닛은 제거하지 않는다.
- 보스 본체는 일반 생산시설 파괴로 제거·약화되지 않는다.
- 보스 호위는 감소할 수 있다.
- 감소 결과가 1기 미만이면 일반 유닛 1기는 유지할 수 있다.

## 7. W15 전설 보스

작업명 `경계파쇄자`.

```text
base_archetype_id = greatsword_warrior 또는 giant 후보
+ legendary BossBehaviorPackage
+ boss Visual Set
```

- Threat 24.
- 목표 전투시간 30~60초.
- `직선 돌파`: 긴 전조, 바리케이드·전열·건물 우선.
- `대단절`: 세로축 크게 베기, 밀집 병력 대응.
- `진군`: 처치·건물 타격 시 공개 중첩.
- 체력 60%에서 패턴 간격 감소.
- 보스 사망 시 표준 승리.

보스 전용 행동은 일반 적군 아키타입 데이터를 복제하지 않고 패키지로 추가한다.

- W20은 즉시 패배 판정이 아니라 사실상 절멸 공세다.

## 9. W20 신화 보스

작업명 `절멸체 경계파쇄자`.

```text
base_archetype_id
+ mythic BossBehaviorPackage
+ BossPhaseProfile
+ mythic Visual Set
```

### 신화 특성 `끝나지 않는 진군`

- 15초마다 공개 중첩 1.
- 중첩당 이동속도·제어저항·구조물 피해 증가.
- 5중첩 상한.

### 2페이즈

- 1페이즈: 전설 보스 패턴 강화.
- 2페이즈 50% HP: 직선 돌파 뒤 충격파, 호위 재집결 1회.
- 무조건 제어 면역이 아니라 보스 보정과 연속 제어 면역을 사용한다.

## 11. 검증 기준

- 모든 일반 적 웨이브가 공용 10개 `archetype_id`만 참조한다.
- 같은 아키타입·Tier·등급은 아군과 적군의 전투 결과가 동일하다.
- 적군 이미지 세트가 공용 애니메이션 이벤트 계약을 지킨다.
- W5·W10·W15·W20의 등급 차이가 수량·Rank·보스 패키지로 설명된다.
- W14 종료 시 W15 보스 주력 라인과 호위 태그를 알 수 있다.
- 비행이 등장하기 최소 30초 전에 대응 태그를 공개한다.
- 건강한 빌드는 다음 충돌 전 현재 웨이브 Threat의 70% 이상을 제거하는 것을 첫 목표로 한다.
- 최대 동시 객체 예산을 넘으면 군집 표현을 조정하되 공용 병종 데이터를 복제하지 않는다.

## 12. 금지 사항

- 웨이브 파일에 적군 전용 스탯·스킬 복사본 작성.
- 난이도 조정을 위해 같은 archetype에 숨은 적군 보너스를 적용.
- 표시명이나 적군 이미지 이름을 별도 전투 데이터 ID로 사용.
- 일반 적군마다 별도 AI·애니메이션 상태 머신 제작.
- 보스 패키지를 일반 병종 데이터에 직접 덮어써 공용성을 파괴.
