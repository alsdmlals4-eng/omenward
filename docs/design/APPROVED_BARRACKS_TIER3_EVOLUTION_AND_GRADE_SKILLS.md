## 1. 세 개의 독립 성장 축

유닛 성장은 다음 세 축으로 분리한다.

1. **병영 Tier와 병종 진화**
   - 상위 Tier 병영은 더 전문화된 일반 병종을 생산한다.
2. **병영 Tier와 핵심 패시브 성장**
   - Tier가 높을수록 패시브가 추가되고 기존 패시브도 강화된다.
3. **룰렛 등급과 일반 스킬 성장**
   - 일반 / 엘리트 / 영웅 / 전설 등급이 스킬 강화와 신규 스킬 해금을 결정한다.

병영 Tier는 룰렛 등급을 올리지 않는다. 룰렛 등급은 병영의 병종 전문화 선택을 바꾸지 않는다.

## 2. 병영 Tier 구조

### Tier 1 — 전사 기반 병영

- 기본 생산 유닛: 검사
- 공유 심벌: `전사 토큰`
- 각 릴에 전사 토큰 1개 제공
- 자동 생산은 일반 등급 검사
- 핵심 패시브 1개를 기본형으로 제공

검사는 `[전사]` 계열의 기본 유닛이며, 이후 전사 계열 Tier 2 병종과 같은 전사 토큰을 공유한다.

### Tier 2 — 기본 전문 병종

Tier 2에서는 다음 계열 또는 병종 전문화를 선택할 수 있다.

- 전사 계열 Tier 2 병종
- 기병
- 창병
- 궁병

#### 전사 계열 Tier 2 초기 후보

- 방패병: 전열 방어와 원거리 대응
- 대검병: 느린 공격과 전방 범위·장갑 파괴
- 광전사: 생존을 대가로 높은 근접 지속 화력

전사 계열 세부 이름과 수치는 후속 조정할 수 있지만, **Tier 1 검사와 Tier 2 전사 병종이 전사 토큰을 공유한다**는 구조는 승인한다.

Tier 2 병영은:

- 선택한 병종의 일반 유닛을 자동 생산한다.
- 선택 계열의 공유 토큰을 각 릴에 1개씩 제공한다.
- 핵심 패시브 2개를 적용한다.
- 패시브 1을 Tier 2 단계로 강화하고 패시브 2를 새로 해금한다.

### Tier 3 — 상위 세부 병종 + 운영 교리

Tier 3 업그레이드에서는 다음 두 결정을 함께 가진다.

1. 상위 세부 병종 1개 선택
2. 운영 교리 1개 선택

운영 교리:

- 대량생산
- 정예훈련
- 토큰 증폭

Tier 3 병영은:

- 선택한 상위 세부 병종의 일반 유닛을 자동 생산한다.
- 기본 계열 공유 토큰을 유지한다.
- 핵심 패시브 3개를 적용한다.
- 패시브 1을 Tier 3 단계로 강화한다.
- 패시브 2를 Tier 3 단계로 강화한다.
- 패시브 3을 새로 해금한다.

정예훈련은 유닛 등급을 올리지 않는다.

## 3. 병영 Tier별 핵심 패시브 성장

| 선택된 훈련 출처 | 패시브 구성 |
|---|---|
| Tier 1 | 패시브 1 기본형 |
| Tier 2 | 패시브 1 강화 + 패시브 2 생성 |
| Tier 3 | 패시브 1 추가 강화 + 패시브 2 강화 + 패시브 3 생성 |

이 규칙은 일반·엘리트·영웅·전설 모두에 적용한다.

예시:

```text
Tier 1 궁병 계열
- 패시브 1: 원거리 사격

Tier 2 궁병 출처
- 패시브 1 강화: 사거리 또는 명중 안정성 향상
- 패시브 2 생성: 후열 전투 특성

Tier 3 대공궁병 출처
- 패시브 1 추가 강화
- 패시브 2 강화
- 패시브 3 생성: 대공 사격
```

- 상위 Tier에서 새 패시브만 추가하는 것이 아니라 기존 패시브도 함께 강화한다.
- 병영이 파괴돼도 이미 생성된 유닛의 패시브와 강화 단계는 유지한다.
- 자동 생산 유닛도 생산 병영 Tier에 맞는 패시브 구성과 강화 단계를 가진다.

### 고정 상위 등급 유닛의 패시브

엘리트·영웅·전설 유닛은 계열별 고정 템플릿을 사용하지만, 선택된 훈련 출처 Tier에 따라 패시브 구성은 달라진다.

- Tier 1 출처: 패시브 1 기본형
- Tier 2 출처: 패시브 1 강화 + 패시브 2
- Tier 3 출처: 패시브 1 추가 강화 + 패시브 2 강화 + 패시브 3

고정 상위 등급 유닛의 Tier 3 패시브 3은 기본 병종 계열에 정의된 고정 패시브를 사용하며, 중기병·충격기병 같은 일반 세부 분기의 패시브를 그대로 복사하지 않는다.

## 4. 초기 Tier 3 세부 병종

### 기병 계열

#### 중기병

- 높은 체력·방어력
- 전열 유지와 원거리 병력 압박
- 일반 기병보다 낮은 이동속도 또는 긴 돌진 준비시간
- 돌진 뒤에도 오래 싸우는 지속 전투형

#### 충격기병

- 높은 돌진 피해와 돌파력
- 첫 충돌의 밀쳐내기·경직 강화
- 돌진 종료 뒤 생존력은 중기병보다 낮음
- 후열을 빠르게 무너뜨리는 순간 화력형

### 궁병 계열

#### 석궁병

- 낮은 공격속도
- 높은 단발 피해
- 방어력 관통 또는 중장갑 대상 보너스

#### 대공궁병

- `[대공]` 태그
- 비행 유닛 우선 타기팅
- 비행 대상 추가 피해 또는 지상화 보조
- 지상 대상 화력은 다른 궁병보다 낮게 조정 가능

#### 연사궁병

- 높은 공격속도
- 낮은 1발 피해
- 경장갑·소형 다수 대응
- 공격 횟수 조건형 스킬과 높은 시너지

### 창병 계열

Tier 3 세부 병종은 후속 설계에서 확정한다.

### 전사 계열

Tier 3 세부 병종은 Tier 2 전사 병종 목록 확정 뒤 설계한다. 전사 계열은 Tier 1부터 같은 전사 토큰을 공유한다.

## 5. 계열별 공유 토큰

같은 기본 병종 계열은 Tier와 세부 병종이 달라도 동일 룰렛 심벌을 사용한다.

### 전사 토큰

- Tier 1 검사
- Tier 2 방패병·대검병·광전사 후보
- 향후 Tier 3 전사 계열 세부 병종

### 기병 토큰

- Tier 2 기병
- Tier 3 중기병
- Tier 3 충격기병

### 궁병 토큰

- Tier 2 궁병
- Tier 3 석궁병
- Tier 3 대공궁병
- Tier 3 연사궁병

### 창병 토큰

- Tier 2 창병
- 향후 Tier 3 창병 세부 병종

병영 한 동은 기본적으로 각 릴에 공유 토큰 1개를 제공한다.

예시:

```text
Tier 2 기병 병영 1개
Tier 3 중기병 병영 1개
→ 각 릴 기병 토큰 2개
```

```text
Tier 1 검사 병영 1개
Tier 2 방패병 병영 1개
→ 각 릴 전사 토큰 2개
```

토큰 외형은 공유하지만 내부 토큰 원장은 다음 정보를 보존한다.

```text
source_building_id
source_building_tier
base_unit_family
produced_unit_variant
variant_weight
passive_progression_id
```

건물 완공·파괴·업그레이드는 다음 룰렛 회전 스냅샷부터 반영한다.

## 6. 병종 후보 확률 추첨

같은 심벌이 당첨되면 현재 스냅샷에 포함된 해당 계열 병영들로 후보 풀을 만든다.

핵심 원칙:

- 높은 Tier 병영에서 나오는 일반 병종의 후보 가중치가 더 높다.
- 낮은 Tier 병영이 남아 있으면 낮은 Tier 병종도 계속 등장할 수 있다.
- 정확한 가중치는 데이터로 조정한다.

초기 추천:

| 출처 | 추천 가중치 |
|---|---:|
| Tier 1 | 1 |
| Tier 2 | 2 |
| Tier 3 | 3 |

기병·궁병·창병처럼 Tier 1 후보가 없는 계열은 Tier 2와 Tier 3만 비교한다. 기존 1:2 비율을 사용할 수도 있으며 최종 수치는 플레이테스트로 결정한다.

## 7. 룰렛 보상 판정 순서

```text
1. 최종 룰렛 보드 확정
2. 동일 심벌 완성 줄 수로 등급 확정
3. 당첨 계열의 병영 출처 후보 풀 생성
4. 가중치 기반으로 실제 훈련 출처 선택
5. 일반이면 선택 출처의 실제 병종 생성
6. 엘리트·영웅·전설이면 계열별 고정 등급 유닛 생성
7. 출처 Tier에 따른 패시브 생성·강화 적용
8. 룰렛 등급에 따른 스킬 생성·강화 적용
```

같은 시드, 회전 스냅샷과 최종 보드는 같은 결과를 만든다.

## 8. 일반 등급과 병종 진화

일반 등급은 선택된 출처 병영의 실제 병종을 생성한다.

- Tier 1 전사 출처: 일반 검사
- Tier 2 전사 출처: 선택한 일반 전사 병종
- Tier 2 기병 출처: 일반 기병
- Tier 3 중기병 출처: 일반 중기병
- Tier 3 대공궁병 출처: 일반 대공궁병

서로 다른 세부 병종은 별도 능력치·AI·패시브 세트를 가진다.

## 9. 엘리트·영웅·전설 유닛은 고정

엘리트·영웅·전설은 기본 병종 계열별 고정 템플릿을 사용한다.

- 전사 계열 엘리트·영웅·전설은 전사 계열 고정 템플릿
- 기병 계열 엘리트·영웅·전설은 기병 계열 고정 템플릿
- 궁병 계열 엘리트·영웅·전설은 궁병 계열 고정 템플릿
- 창병 계열 엘리트·영웅·전설은 창병 계열 고정 템플릿

Tier 3 세부 병종 선택은 고정 상위 등급 유닛의 정체성·외형·기본 스킬 세트를 바꾸지 않는다. 다만 선택된 출처 Tier는 패시브 수와 강화 단계를 결정한다.

## 10. 일반 스킬 성장은 룰렛 등급이 결정

### 일반

- 1스킬 기본형 보유

### 엘리트

- 1스킬 강화
- 계열별 고정 엘리트 능력치·외형·AI 프로필 적용

### 영웅

- 엘리트의 1스킬 강화 유지
- 2스킬 생성

### 전설

- 영웅 단계의 모든 효과 유지
- 2스킬 강화
- 3스킬 생성

```text
일반: 1스킬
엘리트: 강화된 1스킬
영웅: 강화된 1스킬 + 신규 2스킬
전설: 강화된 1스킬 + 강화된 2스킬 + 신규 3스킬
```

신규 스킬 생성과 기존 스킬 강화는 별도 데이터 ID로 관리한다.

## 11. 전설 등급

| 완성 줄 | 등급 |
|---:|---|
| 1줄 | 일반 |
| 2줄 | 엘리트 |
| 3~7줄 | 영웅 |
| 8줄·9칸 동일 | 전설 |

- `신화` 명칭은 사용하지 않고 기존 `전설` 명칭을 유지한다.
- 전설은 한 스테이지 전체에서 병종과 관계없이 1회만 생성한다.
- 전설 생성 뒤 다시 9칸 동일이 나오면 해당 계열 영웅 2명으로 변환한다.

## 12. 자동 생산

병영 자동 생산은 항상 일반 등급 유닛을 생산한다.

- Tier 1: 일반 검사
- Tier 2: 선택한 일반 전문 병종
- Tier 3: 선택한 일반 상위 세부 병종

자동 생산에는 룰렛 등급 판정을 적용하지 않는다. 운영 교리는 자동 생산 유닛에 적용할 수 있지만 등급을 엘리트·영웅·전설로 바꾸지 않는다.

- 선택될 훈련 출처 Tier 확률

- 적용된 패시브 목록과 강화 단계

### 병영 업그레이드 화면

- 전문 병종 역할 비교
- 자동 생산 병종 변화
- 공유 토큰 유지 또는 변경
- 일반 룰렛 후보 확률 변화
- 새 패시브와 기존 패시브 강화 내용
- 운영 교리 효과

## 15. 검증 계약

- Tier 1 검사와 Tier 2 이상 전사 병종은 전사 토큰을 공유한다.
- 같은 계열의 Tier 2·Tier 3 병종은 같은 토큰을 공유한다.
- 높은 Tier 일반 병종 후보가 낮은 Tier보다 높은 가중치를 가진다.
- 일반 등급은 선택 출처의 실제 병종을 생성한다.
- 엘리트·영웅·전설은 계열별 고정 유닛을 생성한다.
- Tier 1은 패시브 1 기본형을 가진다.
- Tier 2는 패시브 1 강화와 패시브 2 생성을 모두 적용한다.
- Tier 3은 패시브 1 추가 강화, 패시브 2 강화와 패시브 3 생성을 모두 적용한다.
- 엘리트는 1스킬을 강화한다.
- 영웅은 강화된 1스킬을 유지하고 2스킬을 생성한다.
- 전설은 영웅 효과를 유지하고 2스킬을 강화하며 3스킬을 생성한다.
- 병영 Tier는 룰렛 등급을 올리지 않는다.
- 자동 생산은 상위 룰렛 등급을 생성하지 않는다.
- 건물 파괴 뒤에도 생성된 유닛의 병종·등급·패시브·스킬 구성은 유지된다.
