# 승인된 병영 Tier 3 병종 진화·공유 토큰·등급 스킬 성장 규칙

- 상태: **핵심 구조 승인됨 / 확률 가중치·개별 병종 수치 조정 대기**

## 1. 세 개의 독립 성장 축

유닛 성장은 다음 세 축으로 분리한다.

1. **병영 Tier와 일반 병종 진화**
   - Tier 2: 기본 전문 병종
   - Tier 3: 상위 세부 병종
2. **룰렛 등급**
   - 일반 / 엘리트 / 영웅 / 신화
3. **능력 구성**
   - 핵심 패시브 수는 병영 Tier 출처가 결정
   - 일반 스킬의 생성·강화는 룰렛 등급이 결정

병영 Tier는 룰렛 등급을 올리지 않는다. 룰렛 등급은 병영의 Tier 3 세부 병종 선택을 바꾸지 않는다.

## 2. 병영 Tier 구조

### Tier 1

- 검사 생산
- 검사 토큰 제공
- 자동 생산은 일반 등급 검사

### Tier 2

다음 기본 전문 병종 중 하나를 선택한다.

- 기병
- 창병
- 궁병

Tier 2 병영은 선택 병종의 기본 유닛을 자동 생산하며, 세 릴에 해당 병종 토큰을 1개씩 제공한다.

### Tier 3

Tier 3 업그레이드에서는 다음 두 결정을 함께 가진다.

1. **상위 세부 병종 1개 선택**
2. **운영 교리 1개 선택**

기존 운영 교리 후보:

- 대량생산
- 정예훈련
- 토큰 증폭

상위 세부 병종 선택은 자동 생산 유닛의 종류와 룰렛 일반 등급 유닛 후보를 바꾼다. 운영 교리는 생산속도·능력치·토큰 수 등 운영 성능을 바꾼다.

정예훈련은 유닛 등급을 올리지 않는다.

## 3. 초기 Tier 3 세부 병종

### 기병 계열

#### 중기병

역할:

- 높은 체력·방어력
- 전열 유지와 원거리 병력 압박
- 일반 기병보다 낮은 이동속도 또는 긴 돌진 준비시간
- 돌진 이후에도 전선에 오래 남는 지속 전투형

#### 충격기병

역할:

- 강한 돌진 피해와 돌파력
- 밀쳐내기·경직 등 첫 충돌 효과 강화
- 돌진 종료 뒤 장기 생존력은 중기병보다 낮음
- 후열을 빠르게 무너뜨리는 순간 화력형

### 궁병 계열

#### 석궁병

역할:

- 낮은 공격속도
- 높은 단발 피해
- 방어력 관통 또는 중장갑 대상 보너스
- 지상 중장갑 유닛 대응

#### 대공궁병

역할:

- `[대공]` 태그
- 비행 유닛 우선 타기팅
- 비행 대상 추가 피해 또는 지상화 보조
- 지상 대상 일반 화력은 다른 궁병보다 낮게 조정 가능

#### 연사궁병

역할:

- 높은 공격속도
- 낮은 1발 피해
- 다수의 경장갑·소형 적 대응
- 공격 횟수 조건형 스킬과 높은 시너지

### 창병 계열

Tier 3 세부 병종은 후속 설계에서 확정한다. 확정 전에는 임의 병종을 구현하지 않는다.

## 4. Tier 2와 Tier 3의 토큰 공유

같은 기본 병종 계열의 Tier 2와 Tier 3 병영은 **동일한 룰렛 심벌**을 사용한다.

예시:

- 기병
- 중기병
- 충격기병

위 세 병종은 모두 룰렛에서 `기병 토큰`으로 표시한다.

- Tier 2 기병 병영 1개는 각 릴에 기병 토큰 1개 추가
- Tier 3 중기병 병영 1개도 각 릴에 기병 토큰 1개 추가
- Tier 3 충격기병 병영 1개도 각 릴에 기병 토큰 1개 추가

따라서 Tier 2 기병 병영 1개와 Tier 3 중기병 병영 1개가 있으면 각 릴의 기병 토큰은 총 2개다.

토큰 외형은 공유하지만 내부 토큰 원장에는 다음 출처 정보를 보존한다.

```text
source_building_id
source_building_tier
base_unit_family
advanced_unit_variant
variant_weight
```

건물 완공·파괴·업그레이드 결과는 기존 규칙과 같이 다음 룰렛 회전 스냅샷부터 반영한다.

## 5. 병종 후보 확률 추첨

기병·궁병 등 같은 심벌이 당첨되면 현재 회전 스냅샷에 포함된 해당 계열 병영들로 `병종 후보 풀`을 만든다.

초기 가중치 추천:

| 출처 | 후보 | 가중치 |
|---|---|---:|
| Tier 2 병영 | 기본 전문 병종 | 1 |
| Tier 3 병영 | 선택한 상위 세부 병종 | 2 |

높은 Tier 병영의 유닛이 더 높은 확률로 생성되지만, Tier 2 병영이 존재하면 기본 병종도 계속 등장할 수 있다.

### 예시 1

```text
Tier 2 기병 병영 ×1
Tier 3 중기병 병영 ×1
```

일반 등급 기병 계열 보상:

- 기병: 1 / 3 = 33.3%
- 중기병: 2 / 3 = 66.7%

### 예시 2

```text
Tier 2 기병 병영 ×1
Tier 3 중기병 병영 ×1
Tier 3 충격기병 병영 ×1
```

일반 등급 기병 계열 보상:

- 기병: 1 / 5 = 20%
- 중기병: 2 / 5 = 40%
- 충격기병: 2 / 5 = 40%

정확한 Tier 2:Tier 3 가중치는 데이터로 조정한다. 핵심 계약은 Tier 3 후보가 Tier 2 후보보다 높은 가중치를 가진다는 점이다.

## 6. 룰렛 등급 판정 순서

유닛 보상은 다음 순서로 결정한다.

```text
1. 최종 룰렛 보드 확정
2. 동일 심벌 완성 줄 수로 등급 확정
3. 당첨된 기본 병종 계열의 출처 후보 풀 생성
4. 가중치 기반으로 훈련 출처 Tier 선택
5. 등급에 따라 일반 병종 후보 또는 고정 등급 유닛 생성
6. 출처 Tier에 따른 핵심 패시브 수 적용
7. 등급에 따른 일반 스킬 생성·강화 적용
```

같은 시드, 같은 회전 스냅샷과 같은 최종 보드는 같은 결과를 만들어야 한다.

## 7. 일반 등급과 세부 병종

완성 줄 1줄로 일반 등급이 결정된 경우:

- Tier 2 출처가 선택되면 기본 전문 병종 생성
- Tier 3 출처가 선택되면 해당 병영이 선택한 상위 세부 병종 생성

예시:

```text
기병 심벌 1줄 당첨
→ Tier 3 중기병 출처 선택
→ 일반 중기병 생성
```

일반 중기병과 일반 충격기병은 서로 다른 유닛 데이터·능력치·핵심 패시브를 가진다.

## 8. 엘리트·영웅·신화 유닛은 고정

엘리트·영웅·신화 유닛은 기본 병종 계열별로 미리 정의된 고정 유닛이다.

- Tier 3 중기병·충격기병 선택에 따라 영웅의 정체성이 바뀌지 않는다.
- 같은 기병 계열이라면 엘리트 기병, 영웅 기병, 신화 기병은 각각 고정된 유닛 템플릿을 사용한다.
- 궁병 계열도 엘리트 궁병, 영웅 궁병, 신화 궁병을 고정 템플릿으로 사용한다.
- 상위 등급 유닛은 Tier 3 세부 병종의 외형·능력 세트를 그대로 복사하지 않는다.

다만 병종 후보 추첨에서 선택된 훈련 출처 Tier는 유지한다. 이 Tier는 해당 고정 등급 유닛이 보유할 핵심 패시브 수를 결정한다.

## 9. 핵심 패시브 수는 병영 Tier 출처가 결정

| 선택된 훈련 출처 | 핵심 패시브 수 |
|---|---:|
| Tier 2 병영 | 2개 |
| Tier 3 병영 | 3개 |

- Tier 3 출처 유닛은 Tier 2 출처 유닛보다 핵심 패시브를 1개 더 가진다.
- 이 규칙은 일반·엘리트·영웅·신화 등급 모두에 적용한다.
- 핵심 패시브 수는 룰렛 완성 줄 수로 증가하지 않는다.
- 병영이 파괴돼도 이미 생성된 유닛의 핵심 패시브는 유지한다.

일반 Tier 3 세부 병종의 세 번째 패시브는 해당 세부 병종의 정체성을 나타낸다.

예시:

- 중기병: 중장갑·전열 유지 패시브
- 충격기병: 돌진 충격·돌파 패시브
- 대공궁병: 대공 추가 피해·비행 우선 타기팅 패시브

고정 엘리트·영웅·신화 유닛이 Tier 3 출처를 받았을 때의 세 번째 패시브는 **기본 병종 계열의 고정 Tier 3 패시브**를 사용한다. 중기병·충격기병 등 세부 분기에는 의존하지 않는다.

## 10. 일반 스킬 성장은 룰렛 등급이 결정

핵심 패시브와 별도로 일반 스킬은 등급에 따라 생성·강화한다.

### 일반

- 1스킬 기본형 보유

### 엘리트

- 병종별로 고정된 엘리트 능력치·외형·AI 프로필 적용
- 기본적으로 신규 스킬 슬롯은 생성하지 않음
- 1스킬은 일반과 같은 기능 구조를 유지하되 엘리트 능력치의 영향을 받음

### 영웅

- 1스킬 강화
- 2스킬 생성

### 신화

- 영웅 단계의 모든 효과 유지
- 2스킬 강화
- 3스킬 생성

```text
일반: 1스킬
엘리트: 1스킬 + 고정 엘리트 능력치 프로필
영웅: 강화된 1스킬 + 신규 2스킬
신화: 강화된 1스킬 + 강화된 2스킬 + 신규 3스킬
```

신규 스킬 생성과 기존 스킬 강화는 별도 데이터 ID로 관리한다.

## 11. 신화 명칭

기존 `전설` 등급 명칭은 `신화`로 교체한다.

| 완성 줄 | 등급 |
|---:|---|
| 1줄 | 일반 |
| 2줄 | 엘리트 |
| 3~7줄 | 영웅 |
| 8줄·9칸 동일 | 신화 |

신화 생성 제한은 기존 전설 제한을 그대로 계승한다.

- 한 스테이지 전체에서 병종과 관계없이 1회
- 이미 신화를 생성한 뒤 다시 9칸 동일이 나오면 해당 병종 영웅 2명으로 변환

## 12. 자동 생산

병영 자동 생산은 항상 일반 등급 유닛을 생산한다.

- Tier 2 병영: 일반 기본 전문 병종 생산
- Tier 3 병영: 일반 상위 세부 병종 생산

자동 생산에는 룰렛 등급 추첨을 적용하지 않는다.

운영 교리는 자동 생산 유닛에 적용할 수 있지만 등급을 엘리트·영웅·신화로 바꾸지 않는다.

## 13. UI 계약

### 룰렛 토큰 장부

같은 심벌 안에서 다음 내용을 표시한다.

- Tier 2·Tier 3 병영 수
- 각 릴의 총 토큰 수
- 일반 등급 결과의 세부 병종별 확률
- Tier 2·Tier 3 훈련 출처 확률
- Tier에 따른 핵심 패시브 수

예시:

```text
기병 토큰: 릴마다 3개
기병 20%
중기병 40%
충격기병 40%
Tier 2 출처 20% / Tier 3 출처 80%
```

### 룰렛 결과 화면

- 기본 병종 계열
- 완성 줄 수
- 생성 등급
- 일반 등급일 경우 실제 세부 병종
- 선택된 훈련 출처 Tier
- 보유 핵심 패시브 수
- 등급으로 생성·강화된 스킬

### 병영 업그레이드 화면

Tier 3 선택 전에 다음을 표시한다.

- 상위 세부 병종 역할 비교
- 자동 생산 유닛 변경
- 일반 룰렛 보상의 후보 확률 변화
- 공유 토큰 수는 유지된다는 설명
- 세 번째 핵심 패시브
- 운영 교리 효과

## 15. 검증 계약

- Tier 2와 Tier 3의 같은 계열 병영은 같은 토큰 심벌을 제공한다.
- 병영 한 동은 기본적으로 릴마다 토큰 1개를 제공한다.
- Tier 3 후보 가중치는 Tier 2 후보보다 높다.
- 일반 등급에서는 선택된 출처 병영의 실제 기본·상위 세부 병종을 생성한다.
- 엘리트·영웅·신화에서는 세부 병종과 관계없이 계열별 고정 유닛을 생성한다.
- 상위 등급에서도 선택된 출처 Tier는 핵심 패시브 수를 결정한다.
- Tier 2 출처는 패시브 2개, Tier 3 출처는 패시브 3개를 가진다.
- 영웅은 1스킬 강화와 2스킬 생성을 모두 받는다.
- 신화는 영웅 효과를 유지하고 2스킬 강화와 3스킬 생성을 받는다.
- 병영 Tier는 룰렛 등급을 올리지 않는다.
- 병영 자동 생산은 엘리트·영웅·신화를 생산하지 않는다.
- 건물 파괴 뒤에도 이미 생성된 유닛의 병종·등급·패시브·스킬 구성은 변하지 않는다.
- 같은 시드와 회전 스냅샷은 같은 병종 후보·훈련 Tier·등급 결과를 만든다.

- Tier 2:T3 정확한 가중치
