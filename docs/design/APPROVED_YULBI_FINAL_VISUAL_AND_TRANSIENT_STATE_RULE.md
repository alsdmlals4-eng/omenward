# 승인된 율비 최종 시안과 일시 상태 표현 규칙

- 상태: **최종 시안 승인됨 / 실제 원화 정리·애니메이션 제작 대기**
- 승인일: 2026-07-14
- 우선 문서:
  - `docs/design/APPROVED_YULBI_MASCOT_CHARACTER_AND_UI_AUDIO_GUIDE.md`
  - `docs/design/APPROVED_YULBI_SINGLE_GUIDE_AND_FIRST_10_MINUTE_FLOW.md`

이 문서는 율비의 최종 외형 방향과 상태별 표현 지속 규칙을 확정한다. 기존 가이드와 충돌할 경우 이 문서의 외형·상태 지속 규칙이 우선한다.

## 1. 최종 외형 방향

율비는 최신 요정형 시안을 최종 기준으로 사용한다.

핵심 특징:

- 작고 둥근 요정형 비인간 캐릭터
- 큰 타원형 눈과 작은 입
- 부드럽게 아래로 늘어진 긴 귀·날개형 장식
- 반투명한 요정 날개
- 밝은 청백색과 옅은 금색 중심의 파스텔 팔레트
- 몸 중앙의 단일 경계 문양
- 머리 위의 짧은 빛 고리·신호 기관
- 몸 아래에는 작은 경계종 또는 방울 장식
- 꽃·빛가루·이슬 같은 자연 정령 요소
- 전체 인상은 부드럽고 친근하지만 전장 경고와 정확한 보고를 전달할 만큼 표정이 명확함

실루엣 목표:

```text
둥근 얼굴과 몸
+ 아래로 늘어진 긴 귀·날개형 장식
+ 투명 요정 날개
+ 머리 위 빛 고리
+ 몸 아래 작은 종
```

작은 HUD 초상에서도 `긴 귀형 실루엣`, `큰 눈`, `머리 위 신호`, `중앙 문양`이 구분되어야 한다.

## 2. 독창성 경계

부드러운 파스텔 색감, 둥근 얼굴, 긴 귀형 실루엣과 친근한 감정 표현은 참고할 수 있다. 다만 특정 기존 캐릭터의 다음 요소를 그대로 복제하지 않는다.

- 동일한 얼굴 비율과 눈·입 배치
- 동일한 귀 길이·끝 모양·자세
- 동일한 의상·소품·색 배치
- 대표 포즈와 상징 행동
- 기존 캐릭터로 오인될 수 있는 전체 실루엣

율비의 고유 식별 요소는 `반투명 요정 날개`, `경계 문양`, `빛 신호 기관`, `경계종`, `전장 상태 반응`, `지휘관에게 전황을 보고하는 역할`이다.

## 3. 기본 모습 유지 원칙

율비는 대부분의 시간 동안 하나의 `기본형`을 유지한다.

기본형:

- 청백색 몸체
- 옅은 금색 문양
- 은은한 문양 호흡 발광
- 느린 공중 부유
- 기본 또는 현재 대화에 맞는 가벼운 표정

축복·저주·위험·보스 등의 상태는 영구 외형 변경이 아니다. **경고등처럼 짧게 표시한 뒤 기본형으로 돌아온다.**

## 4. 상태 반응 흐름

```text
기본형
→ 상태 감지
→ 짧은 색·문양·표정·사운드 반응
→ 필요한 정보 전달
→ 짧은 잔광
→ 기본형 복귀
```

상태가 지속 중이어도 율비 전체가 계속 다른 색으로 남아 있지 않는다. 지속 정보는 별도 HUD 아이콘·타이머·웨이브 카드가 담당한다.

율비가 세계관 설명이나 전술 보고를 길게 이어가더라도 상태색을 유지하지 않는다. 순간 반응 뒤 기본형으로 돌아온 상태에서 대화할 수 있다.

## 5. 상태별 일시 표현

| 상태 | 순간 표현 | 권장 반응 시간 | 지속 중 표시 |
|---|---|---:|---|
| 일반 웨이브 | 신호 기관·문양 주황 점등, 위험 방향을 봄 | 0.8~1.5초 | 초상 테두리의 작은 라인 아이콘 |
| 웨이브 임박 | 주황 점멸 2회, 경고 표정 | 0.8~1.2초 | 웨이브 타이머가 담당 |
| 본진 치명 위험 | 붉은 문양 점멸, 움직임 정지, 짧은 경보 | 1.0~1.8초 | 작은 붉은 경고 배지 |
| 보스·결전 | 자주빛·적색 파동, 날개 수축, 진지한 표정 | 1.2~2.0초 | 보스 카드·패턴 UI가 담당 |
| 축복 | 금색·연두빛 확장, 꽃·빛가루 | 1.0~1.8초 | 축복 아이콘과 남은 시간 |
| 저주 | 보랏빛·탁한 적색 그림자, 문양 왜곡 | 1.0~1.8초 | 저주 아이콘과 남은 시간 |
| 일반 당첨 | 짧게 위로 뜀, 작은 금빛 고리 | 0.5~0.9초 | 없음 |
| 엘리트 | 두 번 뜀, 별빛 2회 | 0.8~1.2초 | 결과 카드가 담당 |
| 영웅 | 한 바퀴 회전, 큰 빛 고리 | 1.0~1.5초 | 결과 카드가 담당 |
| 전설 | 짧은 정적, 문양 폭발, 날개 개방, 환호 | 1.2~1.8초 | 전설 결과 연출이 담당 |
| 일시정지 | 푸른 원형 파동, 안정된 생각 표정 | 0.5~0.8초 | 초상 주변 작은 정지 링 |
| 실패·꽝 | 귀형 장식과 날개가 잠깐 처짐 | 0.4~0.7초 | 없음 |
| 승리 | 금빛 빛가루와 안도 표정 | 1.2~2.0초 | 승리 화면 전환 |
| 세계관 기억 반응 | 기본 금빛 문양이 잠깐 불규칙 점등, 먼 곳을 봄 | 0.8~1.5초 | 대화 기록 아이콘 |

정확한 시간은 플레이테스트로 조정하되 상태 반응이 전투 정보와 입력을 오래 가리지 않게 한다.

## 6. 상태 중복 우선순위

```text
본진 치명 위험
> 보스·결전
> 웨이브 임박
> 필수 튜토리얼
> 축복·저주 발동
> 룰렛 등급 반응
> 세계관 기억 반응
> 일반 감정 반응
```

- 높은 우선순위 상태가 오면 낮은 상태 반응을 즉시 취소한다.
- 같은 상태가 반복되면 전체 변신을 다시 재생하지 않고 짧은 문양 점멸만 사용한다.
- 전설 획득 중 본진 치명 경보가 발생하면 전설 반응을 축소하고 경보를 우선한다.
- 세계관 암시 대화 중 웨이브가 임박하면 대화를 중단하고 경고를 우선한다.
- 상태 반응이 끝나면 별도 해제 애니메이션 없이 0.2~0.4초의 부드러운 색상 복귀로 기본형으로 돌아간다.

## 7. UI 계약

- 율비의 상태색은 알림을 처음 인지시키는 보조 수단이다.
- 상태의 실제 지속 여부와 수치는 반드시 별도 아이콘·타이머·텍스트에서 확인 가능해야 한다.
- 율비가 기본형으로 돌아왔다고 상태 효과가 종료된 것으로 오해되지 않게 한다.
- 말풍선과 음성이 없어도 상태 정보가 전달되어야 한다.
- 애니메이션 감소 옵션에서는 색 점등·문양 변화만 남기고 회전·도약·날개 확장을 줄인다.
- 율비가 적 수량·시간을 보고하는 동안 웨이브 카드의 숫자와 항상 일치해야 한다.

## 8. 제작 산출물 수정

기존 제작 목록에 다음을 추가한다.

- 최종 기본형 정면·측면·후면과 3/4 회전도
- 긴 귀형 장식과 요정 날개의 구조 분해도
- 기본형 ↔ 상태색 전환 팔레트
- 각 상태의 1~2초 반응 애니메이션
- 기본형 복귀 0.2~0.4초 블렌드
- 48px·64px에서 상태 문양·표정 식별 테스트
- 상태 중복 우선순위 프로토타입
- 애니메이션 감소 버전
- 감지·보고·안내·암시 모드별 기본 포즈

## 9. 검증 기준

- 대부분의 플레이 시간에 율비는 동일한 기본형으로 보인다.
- 위험·축복·저주·보상 상태는 짧게 표현되고 기본형으로 복귀한다.
- 율비가 기본형으로 돌아와도 지속 효과의 상태는 HUD에서 명확히 남는다.
- 48px 초상에서도 일반·위험·보스·축복·저주의 순간 반응이 구분된다.
- 상태 반응이 룰렛 판정, 웨이브 정보와 전술 명령 버튼을 가리지 않는다.
- 같은 경고가 반복될 때 전체 애니메이션이 과도하게 반복되지 않는다.
- 높은 우선순위 경보가 보상·감정·세계관 반응보다 먼저 전달된다.
- 율비의 보고와 HUD의 라인·병종·수량·시간 정보가 일치한다.
