# 승인된 Dopamine Driven Design 원칙과 첫 10분 구조

- 상태: **기획 원칙 승인됨 / 첫 10분 세부 연출·수치 조정 대기**
- 승인일: 2026-07-14
- 적용 범위: 게임 전체 기획, 튜토리얼, 수직 슬라이스, UI, 연출, 콘텐츠 추가 검수
- 연결 세계관: `docs/design/APPROVED_FRONTIER_COMMANDER_AND_BOUNDARY_LAW_WORLD_PREMISE.md`
- 우선순위: 이후 추가되는 기능은 단순성·첫 10분·뾰족한 재미 기준을 통과해야 한다.

## 1. 핵심 기획 원칙

Roulettebound는 시스템 수가 많은 게임이지만 플레이어가 처음 느껴야 하는 것은 복잡함이 아니라 다음 한 문장이다.

> 건물을 지어 룰렛 확률을 바꾸고, 당첨된 병력으로 예고된 위기를 뒤집는다.

기획은 기능 목록보다 다음 순서로 작성한다.

```text
의도
→ 플레이어에게 주고 싶은 감정과 경험
→ 플레이어 행동
→ 작동 규칙
→ 보상과 피드백
→ 다음 목표
```

새 기능은 `왜 필요한가`, `어떤 감정을 만드는가`, `핵심 루프에 어떻게 연결되는가`를 설명하지 못하면 추가하지 않는다.

## 2. 단순성의 정의

단순성은 첫 10분에 기능을 거의 보여주지 않는 것이 아니다.

단순성은 다음을 의미한다.

- 한 기능을 한 문장으로 설명할 수 있다.
- 한 번에 한 행동만 요구한다.
- 입력 직후 결과가 화면에서 보인다.
- 비슷한 규칙은 같은 UI와 용어로 처리한다.
- 기능을 처음 배울 때 전체 예외·수치·고급 활용을 모두 설명하지 않는다.
- 플레이어가 10~30초 안에 기본 사용법을 이해하고 바로 행동할 수 있다.

따라서 첫 10분에는 여러 시스템을 빠르게 소개할 수 있다. 단, 동시에 설명하지 않고 `설명 → 한 번 사용 → 즉시 피드백` 단위로 연속 배치한다.

## 3. 시스템당 습득 시간

### 기본 목표

새 시스템의 최초 습득 시간은 넉넉하게 잡아도 10~30초를 목표로 한다.

```text
짧은 설명 3~7초
→ 강조된 버튼·대상 확인 2~5초
→ 플레이어 입력 2~10초
→ 즉시 결과 확인 3~8초
```

### 습득과 숙련의 구분

- `습득`: 무엇을 누르면 어떤 결과가 나오는지 이해
- `활용`: 어떤 상황에 사용하는지 이해
- `숙련`: 다른 시스템과 조합하고 예외를 판단

첫 10분에는 습득을 빠르게 완료시킨다. 활용과 숙련은 이후 웨이브와 스테이지에서 반복적으로 익히게 한다.

### 10~30초 학습 계약

각 시스템은 처음 등장할 때 다음 형식을 사용한다.

1. 목적을 한 문장으로 표시
2. 사용할 버튼·노드·라인 하나만 강조
3. 플레이어가 한 번 직접 실행
4. 결과를 전장과 UI에 즉시 표시
5. 다음 행동으로 바로 연결

예시:

```text
병영을 지으면 전사 토큰이 늘어납니다.
→ 빈 노드 하나 강조
→ 병영 건설
→ 전사 토큰이 릴로 이동
→ 룰렛 버튼 강조
```

이 과정은 약 15~25초 안에 끝내는 것을 목표로 한다.

## 4. 뾰족한 핵심 재미

이 게임의 핵심 재미는 단순한 룰렛 당첨이나 자동전투가 아니다.

```text
적의 위협을 미리 읽음
→ 건물과 토큰 구성을 선택함
→ 룰렛 결과를 기대함
→ 원하는 병력 또는 예상 밖의 고등급 병력을 얻음
→ 필요한 라인에 배치함
→ 상성과 전술로 전선을 뒤집음
```

핵심 감정 순서:

1. **긴장** — 어느 라인이 위험한지 보인다.
2. **판단** — 어떤 건물·병종·소비가 필요한지 고른다.
3. **기대** — 룰렛이 멈추기 전 결과를 기다린다.
4. **폭발적 보상** — 줄 완성·등급·유닛 등장 연출을 받는다.
5. **통제감** — 자신의 건물 구성과 이동 선택이 결과에 영향을 줬음을 이해한다.
6. **역전** — 새 병력·포탑·전술 명령이 실제 전선을 바꾼다.
7. **성장 기대** — 다음 Tier·세부 병종·더 높은 등급을 목표로 한다.

## 5. 대표 세일즈 포인트

### 5.1 확률을 건설하는 룰렛 전략

- 건물이 생산뿐 아니라 룰렛 토큰과 확률을 바꾼다.
- 플레이어는 확률을 설계하고 이동권으로 마지막 결과를 조정한다.
- 룰렛은 전투와 분리된 미니게임이 아니라 전선 대응의 핵심이다.

### 5.2 30초 뒤 위기를 보고 준비하는 전략

- 적 웨이브의 라인·병종·수량을 미리 보여준다.
- 플레이어는 정보 부족이 아니라 대응 판단으로 승패가 갈린다.
- 일시정지 계획 모드가 빠른 손보다 판단을 우선하게 한다.

### 5.3 희귀 병력이 전선을 바꾸는 즉시 체감

- 일반·엘리트·영웅·전설은 단순 능력치 색상 차이가 아니다.
- 높은 등급은 강화된 스킬과 신규 스킬로 전투 장면을 바꾼다.
- 높은 Tier 병영은 일반 병종의 외형·역할·패시브를 바꾼다.

### 5.4 간발의 차이로 완성되는 전장 건설

- 적이 접근하고 건물을 공격해도 건설은 계속된다.
- 포탑이나 병영이 파괴 직전에 완공되어 전선을 구할 수 있다.
- 건설 진행도·체력·완공 연출을 강하게 보여준다.

### 5.5 최전선 지휘관 판타지

- 플레이어는 직접 싸우는 영웅보다 전선을 살리는 지휘관이다.
- 세 라인의 위험을 읽고 제한된 전력을 배분한다.
- 정체불명의 `경계의 율`이 공세·징조·축복·저주를 묶는다.

## 6. 첫 10분 목표

첫 10분은 시스템을 천천히 하나씩 설명하는 시간이 아니다.

목표:

- 자신이 괴물 군단을 막는 최전선 지휘관임을 이해
- 경계의 징조가 다음 웨이브 정보를 준다는 사실 이해
- 건물이 룰렛 토큰과 확률을 바꾼다는 사실 체험
- 첫 룰렛 당첨과 병력 등장 체험
- 첫 라인 배치와 자동전투 체험
- 포탑 또는 전술 명령으로 첫 역전 체험
- 이동권 또는 럭키 찬스로 결과를 직접 개선
- 다음 Tier·병종·고등급 유닛에 대한 기대 형성

첫 10분 종료 시 플레이어가 다음 문장을 설명할 수 있어야 한다.

> 나는 최전선 지휘관이고, 적이 올 라인을 본 뒤 건물과 룰렛으로 병력을 준비해 막는다.

## 7. 첫 10분 권장 흐름

세부 시간은 플레이테스트로 조정하지만 각 시스템의 최초 설명은 10~30초 안에 끝낸다.

### 0:00~0:30 — 역할과 위기

- 경계종과 함께 한 라인의 징조 표시
- 대사: `지휘관, 상단 경계가 열립니다. 도달까지 30초.`
- 대사: `저 선을 넘기면 후방은 끝입니다.`
- 플레이어 역할과 방어 목표를 즉시 이해시킨다.

### 0:30~0:50 — 일시정지

- 전투 시간이 흐르기 전에 일시정지 버튼을 강조
- 한 번 눌러 시간이 멈추는 것을 확인
- `멈춘 상태에서도 모든 명령을 내릴 수 있습니다.` 한 문장 표시

학습 목표 시간: 10~20초

### 0:50~1:20 — 첫 건설

- 빈 노드와 병영 버튼 강조
- 병영 건설 한 번 실행
- 시작 자원은 실패하지 않을 만큼 충분히 제공

학습 목표 시간: 15~30초

### 1:20~1:40 — 건물과 토큰 연결

- 병영 완공과 동시에 전사 토큰이 릴로 이동
- `전사 토큰 +1`만 크게 표시
- 상세 확률표는 열지 않음

학습 목표 시간: 10~20초

### 1:40~2:10 — 첫 룰렛

- 룰렛 버튼 강조
- 첫 회전은 최소 일반 유닛이 확정되는 결정론적 결과
- 심벌 정지 → 줄 완성 → 등급 공개 → 유닛 등장

학습 목표 시간: 20~30초

### 2:10~2:35 — 첫 병력 배치

- 위험 라인만 강조
- 획득한 검사를 해당 라인에 배치
- 다른 라인과 고급 명령은 잠시 비강조

학습 목표 시간: 15~25초

### 2:35~3:30 — 첫 교전

- 병력이 긴 이동만 하지 않고 빠르게 적과 충돌
- 횡베기·상성·피해 결과를 눈에 보이게 표시
- 첫 적 소규모 부대를 쓰러뜨리게 한다.

### 3:30~3:55 — 웨이브 전조 읽기

- 두 번째 공세 카드 표시
- 라인·병종·수량 세 정보만 읽게 한다.
- 대응할 라인을 플레이어가 직접 선택하게 한다.

학습 목표 시간: 10~25초

### 3:55~4:25 — 포탑 또는 바리케이드

- 적이 접근하는 동안 포탑 건설 또는 바리케이드 사용
- 범위와 결과를 한 번 미리 보여준다.
- 버튼 하나와 목표 지점 하나만 강조한다.

학습 목표 시간: 15~30초

### 4:25~5:30 — 첫 역전

- 포탑 완공 또는 바리케이드 발동 직후 전선이 안정
- `방어 성공`과 전선 변화 표시
- 플레이어 선택이 실제 결과를 바꿨음을 강조

### 5:30~5:55 — 두 번째 건설 또는 업그레이드

- 플레이어가 병영 추가, 시장 또는 포탑 중 하나를 선택
- 각 선택은 한 줄 역할 설명만 제공
- 이 선택이 다음 룰렛 또는 전선에 미치는 변화 즉시 표시

학습 목표 시간: 15~25초

### 5:55~6:25 — 통제 가능한 행운

- 두 번째 룰렛에서 이동권 또는 럭키 찬스 하나 소개
- 플레이어가 행·열을 한 번 움직여 줄을 완성

학습 목표 시간: 20~30초

### 6:25~6:50 — 첫 엘리트

- 가능하면 첫 엘리트 결과를 보장 또는 높은 확률로 제공
- 강화된 1스킬을 한 줄로 설명
- 일반과 다른 외형·이펙트를 즉시 보여준다.

### 6:50~8:20 — 두 번째 웨이브 종합 대응

- 두 라인 중 하나를 선택하게 하거나 병력 분산을 요구
- 건설·룰렛·배치·전조를 한 번 스스로 연결
- 도움말은 막혔을 때만 짧게 표시

### 8:20~8:50 — 병영 Tier 2 예고

- 방패병·대검병·광전사 카드 표시
- 역할을 아이콘과 한 문장으로 전달
- 모든 패시브와 수치는 설명하지 않는다.

학습 목표 시간: 20~30초

### 8:50~10:00 — 미니 위기와 마무리

- 강한 적 한 기 또는 작은 특수 웨이브 등장
- 지금까지 배운 시스템으로 방어
- 전선 안정, 보상, 다음 성장 목표 표시
- `첫 번째 율을 견뎌냈다.`는 짧은 문장으로 세계관 미스터리 예고

## 8. 첫 10분 학습 밀도

첫 10분에 적극적으로 습득시키는 시스템은 약 8개까지 허용한다.

1. 방어 목표와 위험 라인
2. 일시정지 계획 모드
3. 건설
4. 건물과 토큰 연결
5. 룰렛 회전과 한 줄 보상
6. 유닛 배치와 자동전투
7. 웨이브 전조
8. 포탑 또는 바리케이드
9. 이동권 또는 럭키 찬스는 상황에 따라 같은 10분 안에 추가 가능

제한하는 것은 시스템 수가 아니라 `동시 인지 부담`이다.

- 한 번에 새 개념 하나만 강조
- 한 화면의 주요 강조 버튼은 1~3개
- 설명 문장은 기본 한 문장, 최대 두 문장
- 고급 예외와 정확한 수치는 상세 패널로 이동
- 이전 개념을 한 번 사용한 뒤 다음 개념 공개
- 이미 이해한 플레이어는 안내를 즉시 넘길 수 있음

## 9. 빠른 학습 UI 계약

### 설명 카드

- 25자 안팎의 한 문장 목표
- 행동 버튼 또는 전장 대상과 직접 연결
- 확인 버튼을 따로 누르게 하지 않고 행동하면 자동 종료

### 강조 방식

- 필요한 버튼·노드·라인만 밝게 표시
- 불필요한 UI를 완전히 숨기기보다 비강조 상태로 유지
- 플레이어가 다른 올바른 선택을 해도 진행 가능하게 설계

### 실패 처리

- 잘못된 노드를 선택하면 금지 이유를 즉시 표시
- 자원이 부족하면 필요한 금액과 현재 금액 표시
- 잘못된 라인에 배치해도 즉시 패배시키지 않고 재배치 기회 제공
- 설명 중 연타·중복 입력은 한 번만 처리
- 대상이 사라지거나 상태가 바뀌면 자원을 차감하지 않고 다시 선택

## 10. 도파민 피드백 계약

핵심 행동은 시각·음향·수치 피드백을 함께 가진다.

### 건설

- 노드 선택 시 완성 외형과 룰렛 변화 미리보기
- 진행 중 명확한 체력·진행도
- 완공 시 충격파, 가동음, 토큰이 룰렛으로 이동하는 연출

### 룰렛

- 릴마다 개별 정지감과 짧은 타격음
- 완성 가능성이 생기면 긴장음 강화
- 줄 완성 시 연결선과 심벌 확대
- 등급 공개는 짧고 강하게, 조작을 오래 막지 않음

### 유닛 등장

- 병종 실루엣 → 등급 색 → 이름·핵심 능력 공개
- 새 패시브·강화 스킬은 한 줄 요약
- 즉시 출전 가능한 라인 강조

### 전투 역전

- 상성, 돌진 저지, 파갑, 대공 등 핵심 상호작용을 아이콘과 짧은 텍스트로 표시
- 다수 적 처치 시 화면 흔들림·타격음·전선 변화로 결과 증폭
- 포탑 완공이나 전술 명령으로 위기를 막으면 별도 `방어 성공` 피드백

### 성장

- Tier 상승 전후 외형 차이를 명확히 표시
- 신규 패시브 해금과 기존 패시브 강화를 분리 표시
- 높은 등급은 애니메이션·이펙트·행동 패턴으로 체감

## 11. 세계관 전달 원칙

세계관은 설명량이 아니라 게임 규칙을 납득시키고 기억하게 만드는 역할을 한다.

첫 10분에 필요한 정보:

1. 플레이어는 괴물 군단을 막는 최전선 지휘관
2. 세 전선 뒤에는 지켜야 할 후방 지역이 있음
3. 괴물은 `경계의 율`에 따라 웨이브로 넘어옴
4. 웨이브 전에 정확한 징조가 나타남
5. 축복과 저주의 원리는 아직 알 수 없음

룰렛·토큰은 반드시 세계관 속 마법 장치로 설명하지 않는다.

- 플레이어에게는 룰렛과 토큰으로 표시
- 세계관 인물은 전술판·증원 경로 정도로 표현
- 병영 건설이 특정 병종의 증원 가능성을 높인다는 사실만 자연스럽게 전달

## 12. 기능 추가 검수 질문

### 필요성

- 이 기능이 없으면 핵심 경험에 어떤 문제가 생기는가?
- 이미 있는 시스템으로 해결할 수 없는가?

### 감정과 행동

- 어떤 행동을 유도하는가?
- 긴장·성취·전략·몰입·수집 중 어떤 감정을 만드는가?
- 결과가 전장에서 바로 보이는가?

### 핵심 루프 연결

- 건설·룰렛·배치·웨이브 대응 어디에 연결되는가?
- 행동 → 보상 → 성장 → 다음 목표 흐름이 있는가?

### 단순성

- 기본 사용법을 10~30초 안에 습득할 수 있는가?
- 한 문장과 한 번의 행동으로 가르칠 수 있는가?
- 별도 버튼·재화·패널을 추가할 가치가 있는가?

### 차별성

- 룰렛 확률 설계와 실시간 전장 대응을 강화하는가?
- 다른 게임의 기능을 그대로 복제하지 않고 원리를 변형했는가?

### 리스크

- 정보 과부하, 필수 선택 고착, 반복 피로, 운 의존 증가 위험은 없는가?
- 실패·중복 입력·자원 부족·상태 불일치 때 자연스럽게 이어지는가?

## 13. PoC 검증 목표

첫 수직 슬라이스는 콘텐츠 양보다 다음을 검증한다.

- 첫 룰렛 회전까지 2분 이내
- 첫 유닛 교전까지 3분 30초 이내
- 첫 건설 또는 전술 선택에 의한 눈에 보이는 역전까지 5분 30초 이내
- 첫 10분 안에 핵심 루프 2회 경험
- 각 신규 시스템의 기본 습득에 10~30초
- 플레이어가 건물이 룰렛 확률을 바꾼다는 사실을 설명 가능
- 다음 웨이브 정보를 보고 병종·건물·라인 중 하나를 바꾸는 행동 수행
- 첫 10분 종료 시 다음 Tier·고등급·새 병종에 대한 기대 형성

관찰 항목:

- 각 설명 카드 노출부터 올바른 행동까지 걸린 시간
- 30초가 넘게 막힌 시스템과 원인
- 룰렛 결과를 이해하지 못한 횟수
- UI에서 다음 행동을 찾는 데 걸린 시간
- 첫 10분 중 조작하지 않고 설명만 읽은 시간
- 가장 강하게 기억한 순간
- 다시 플레이하고 싶은 이유

## 14. 문서와 개발 방식

기획 문서 순서:

1. 개요·기획 의도·기대 효과
2. 플레이어 경험과 핵심 흐름
3. 상세 규칙
4. 예외·실패 처리
5. 데이터 계약
6. UI·피드백 계약
7. 검증 기준

개발 순서:

```text
핵심 컨셉
→ 제약 확인
→ 뾰족한 재미 정의
→ PoC
→ 피드백 기반 재조정
→ 프로덕션
```

- 전체 콘텐츠를 만들기 전에 핵심 기능과 첫 10분을 먼저 검증한다.
- 컨셉 이미지와 와이어프레임으로 기획·AI·개발 이해 차이를 조기에 찾는다.
- 일·주·월 체크리스트는 플레이 가능한 결과를 기준으로 작성한다.
- 예상 개발 기간에는 시행착오 여유를 포함한다.

## 15. 금지 원칙

- 세계관 설명을 긴 텍스트로 먼저 제시하지 않는다.
- 시스템당 학습 시간을 과도하게 늘려 플레이 흐름을 끊지 않는다.
- 단순성을 이유로 핵심 시스템 노출을 불필요하게 늦추지 않는다.
- 첫 10분에 모든 예외·수치·고급 활용을 설명하지 않는다.
- 단순 수치 증가만으로 높은 등급과 Tier를 표현하지 않는다.
- 핵심 루프와 연결되지 않는 별도 미니게임·재화·패널을 쉽게 추가하지 않는다.
- 도파민을 보상 팝업과 희귀도 색상만으로 해결하지 않는다.
- 운으로 좋은 결과가 나왔다는 감정만 남기지 않고 플레이어 선택의 영향을 보여준다.
- 설명을 줄인다는 이유로 중요한 판정·비용·실패 결과를 숨기지 않는다.

이 문서는 앞으로의 기획 검수 기준이다. 이미 승인된 기능도 10~30초 습득, 첫 10분 속도감과 핵심 재미를 해칠 경우 노출 시점·UI·설명 방식을 재조정한다.
