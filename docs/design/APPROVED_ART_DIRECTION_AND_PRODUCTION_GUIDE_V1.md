## 1. 최종 그림체 방향

오멘워드의 기본 아트 스타일은 다음 조합을 사용한다.

```text
A. 클린 전술 픽셀
+
B. 미니어처 치비 픽셀의 친근한 비율
+
고해상도 픽셀의 재질·조명 완성도
```

### 핵심 정의

- 전략 줌에서 빠르게 읽히는 명확한 실루엣.
- 약 2.5~3등신의 경량화된 비율.
- 작은 화면에서도 무기·자세·몸통 덩어리로 병종 식별.
- 픽셀 단위는 일관되게 유지하되 확대 콘셉트에서는 재질과 표정을 충분히 표현.
- 환경 조명과 영웅·전설 연출에만 제한적으로 고급 조명 사용.
- 장식이 역할을 가리지 않도록 기본형은 절제하고 상위 등급에서 단계적으로 증가.

### 지향하는 인상

```text
가볍고 접근하기 쉬움
+ 전술 정보가 즉시 읽힘
+ 인디 픽셀 특유의 수공예 감각
+ 상위 등급에서 프리미엄 판타지 연출
```

### 피해야 할 인상

- 모바일 양산형 성채 게임의 과도한 금장·문장·판금 장식.
- 모든 유닛이 처음부터 영웅처럼 보이는 디자인.
- 픽셀 위에 매끈한 생성형 일러스트 명암만 얹은 형태.
- 실루엣보다 미세 장식과 발광이 먼저 보이는 구성.
- 유명 게임·기존 IP 캐릭터를 직접 연상시키는 복제형 디자인.

## 2. 제작 해상도와 화면 기준

### 실제 게임 출력

- 기준 출력: 1920×1080, 16:9.
- 저사양·UI 검증 기준: 1280×720.
- 내부 픽셀 해상도 후보: 960×540, 정수 2배 확대.
- 기본 전략 줌에서 양측 본진과 세 라인을 함께 본다.

### 월드 표시 크기

| 대상 | 기본 화면 높이 |
|---|---:|
| 일반 인간형 병사 | 34~40px |
| 엘리트 | 38~44px |
| 영웅 | 42~50px |
| 전설 | 46~56px |
| 특수 인간형 | 42~56px |
| 거인 | 72~96px |
| 기본 병영 | 약 100~128px |
| 특수병단 | 약 120~150px |
| 중간요새 | 100~130px |
| 본진 | 150~180px |

상위 등급은 크기만 키우지 않는다. 실루엣 부속, 무기, 망토, 문양, 짧은 VFX로 위계를 표현한다.

## 3. 공통 픽셀 제작 규칙

### 팔레트

- 기본 유닛 1종당 핵심 색상 6~10색.
- 피부·머리·금속을 포함해 최대 18~24색을 첫 제작 상한으로 둔다.
- 동일 재질은 유닛마다 다른 명암법을 사용하지 않는다.
- 아군 기본색은 회청·남색·상아색·따뜻한 금속 포인트.
- 적군 기본색은 흑자색·암적색·갑각 회색·균열 발광색.

### 외곽선

- 기본 1px 외곽선.
- 가장 바깥 실루엣은 어두운 중성색.
- 내부 경계는 바깥선보다 한 단계 밝게 사용 가능.
- 밝은 배경과 어두운 배경 모두에서 읽히도록 선택적 밝은 림을 허용한다.

### 명암

- 캐릭터 본체는 2~4단 명암.
- 금속·마법 핵심부만 제한적으로 1단 하이라이트 추가.
- 광원은 기본적으로 화면 좌상단 하나를 기준으로 한다.
- 상시 강한 발광 금지. 스킬 전조·영웅·전설 순간 연출에만 사용한다.

### 픽셀 일관성

- 같은 시트에서 픽셀 크기 혼용 금지.
- 자동 안티앨리어싱 금지.
- 확대 시 최근접 보간 사용.
- 생성형 원본은 최종 자산이 아니라 형태 탐색용으로만 사용하고, 실제 자산은 픽셀 그리드 위에서 재정리한다.

## 4. 아군 진영 형태 언어

### 루메른 왕국·실베른 수비대

- 수직선, 아치, 방패, 종, 천 배너.
- 실용적인 판금과 천 갑옷.
- 밝은 회색 금속, 남색 천, 상아색 의복.
- 금색은 계급·성물·전설 연출의 포인트로만 사용.
- 무기와 장비가 병종의 기능을 과장해 보여준다.

### 공통 금지

- 모든 병종에 동일한 왕관·날개·금빛 후광 사용.
- 장식이 무기 실루엣을 가리는 구성.
- 일반 등급부터 긴 망토와 대형 보석을 과도하게 사용.
- 얼굴이 병종 식별의 유일한 단서가 되는 디자인.

## 5. 아군 10병종 디자인 계약

| 병종 | 핵심 실루엣 | 얼굴·복장 방향 | 무기 규칙 |
|---|---|---|---|
| 방패병 | 몸 높이의 큰 방패, 낮은 중심 | 투구와 짧은 외투 | 방패가 몸보다 먼저 읽혀야 함 |
| 대검전사 | 넓은 어깨, 몸보다 긴 대검 | 수염 없이 젊거나 중년, 상위 단계에서 흉터 추가 | 검날 방향과 손잡이 위치가 항상 명확 |

| 마법사 | 큰 소매, 지팡이·촉매 | 일반은 젊은 마도사, 등급이 오를수록 백발·수염·노마법사 느낌 강화 | 지팡이와 마법 구체의 시선 흐름 일치 |

| 거인 | 인간형의 약 2배, 큰 팔과 무기 | 단순한 얼굴, 중량 갑주 | 망치·철퇴의 무게 중심과 손 위치가 자연스러워야 함 |

### 최근 피드백 고정 사항

1. 대검전사는 수염으로 경험을 표현하지 않는다.
2. 대검전사의 경험 표현은 얼굴 흉터, 손상된 어깨 장비, 검날의 사용 흔적으로 나타낸다.
3. 창병은 일반·엘리트·영웅·전설 모두 창끝이 적 방향을 향해야 한다.
4. 창병의 손은 창의 무게중심을 기준으로 앞손과 뒷손 위치가 자연스러워야 한다.
5. 궁병은 두건을 벗고 엘프 캐릭터의 귀·머리카락 실루엣을 사용한다.
6. 마법사는 등급이 오를수록 백발·수염·자세 변화로 노마법사의 권위를 강화한다.

## 6. 창병 무기 방향 세부 계약

창병은 최근 시안에서 무기 방향 오류가 반복되었으므로 별도 검수 항목으로 관리한다.

### 기본 방향

```text
캐릭터 진행 방향: 오른쪽
창끝: 오른쪽
자루 끝·장식: 왼쪽
앞손: 창끝에 가까운 중간 지점
뒷손: 자루 끝에 가까운 지점
```

### 자세

- 대기: 창끝이 전방 상단 5~15도.
- 이동: 창끝이 전방 수평 또는 약간 상향.
- 기본 공격 준비: 창끝을 뒤로 당기되 방향은 뒤집지 않는다.
- 찌르기: 전방 수평으로 뻗는다.
- 창벽: 여러 창끝이 모두 적 진행 방향을 향한다.
- 사망·피격 프레임 외에는 창끝이 뒤를 향하지 않는다.

### 무기 구조

- 창끝은 금속 날, 소켓, 자루 순서가 명확해야 한다.
- 반대쪽 끝은 작은 금속 슈 또는 장식으로 표현한다.
- 양 끝이 모두 동일한 날처럼 보이지 않게 한다.
- 영웅·전설의 추가 장식은 창날 바로 뒤쪽에 두되 창끝보다 커지지 않는다.

### 체크리스트

- [ ] 창날과 자루 끝의 형태가 구분되는가.
- [ ] 손의 위치가 창날과 자루 끝 사이에 있는가.
- [ ] 창끝이 캐릭터의 시선·진행 방향과 같은가.
- [ ] 등급이 올라가도 기본 방향이 유지되는가.
- [ ] 좌우 미러링 시 문양·손잡이·창날이 비정상적으로 뒤집히지 않는가.

## 7. 등급별 시각 성장

| 등급 | 캐릭터 변화 | 무기 변화 | VFX |
|---|---|---|---|
| 일반 | 가장 단순한 실루엣과 장비 | 기능이 즉시 읽히는 기본형 | 없음 또는 피격·공격 최소 효과 |
| 엘리트 | 어깨·투구·천 장식 1개 추가 | 날·가드·성물의 품질 상승 | 짧은 스킬 잔광 |
| 영웅 | 실루엣 부속 2개, 망토·머리·자세 변화 | 고유 형태와 기능성 장식 | 비전투 중 매우 짧은 잔광 |
| 전설 | 고유 부속, 명확한 초상 실루엣 | 계열을 대표하는 상징 무기 | 출격·스킬 순간 후광·바닥 문양 |
| 적 신화 | 페이즈마다 실루엣·코어 변화 | 비대칭 성장·균열 증식 | 전용 보스 전조와 화면 반응 |

### 공통 원칙

- 상위 등급은 일반형의 역할을 유지한다.
- 전설도 다른 병종의 핵심 실루엣을 침범하지 않는다.
- 색상 변경만으로 등급을 표현하지 않는다.
- 일반형을 확대하고 금색을 추가하는 방식만으로 끝내지 않는다.

## 9. 건물 디자인 계약

### 공통 상태

모든 건물은 다음 상태를 가진다.

```text
건설 예정
건설 중
활성
업그레이드 중
파손
폐허
```

### 기본 병영

- 돌·목재 혼합의 낮고 넓은 실루엣.
- 출입구, 훈련장, 허수아비, 무기 거치대로 기능 표현.
- Tier 1은 전문화 장비를 과도하게 노출하지 않는다.
- Tier 2는 지붕·입구·외부 무기 거치대로 6전문화를 구분한다.
- Tier 3은 수직 크기보다 부속 시설과 훈련 공간 확장으로 성장한다.

### 특수병단

- 기본 병영보다 높고 의식·연구·대형 출입 구조가 보인다.
- Tier 1은 비어 있는 4개 준비 단상과 준비도 표시 장치를 가진다.
- 사제단: 성물·종·밝은 천.
- 마도단: 원형 관측부·룬 촉매·청색 조명.
- 비행단: 높은 탑·착륙대·깃발 방향 표시.
- 거인단: 매우 큰 문·보강재·중량 사슬.

### 농장

- 밭·곡물창고·풍차 또는 물레의 조합.
- 식량 저장량 증가가 창고 크기로 보인다.

### 시장

- 천막·진열대·수레·교역 표식.
- 수입 강화는 점포 수와 물류 공간 증가로 표현한다.

### 포탑

- 사거리·연사·공성 역할이 포신 길이와 수, 상부 구조로 읽혀야 한다.
- 공격 방향과 포신 방향이 항상 일치한다.

### 요새

- 본진·중간요새는 별도 크기 체계를 사용한다.
- 일반 생산 건물이 요새처럼 보이지 않도록 탑과 성벽 높이를 제한한다.

## 10. 애니메이션 제작 규격

### 일반 인간형

| 상태 | 프레임 가설 |
|---|---:|
| 대기 | 4~6 |
| 이동 | 6~8 |
| 기본 공격 | 6~10 |
| 스킬 1 | 8~12 |
| 피격 | 2~3 |
| 사망 | 6~10 |

### 특수·거인·보스

- 핵심 스킬당 8~16프레임.
- 거인 공격은 준비·충돌·회복 키포즈를 분리한다.
- 비행병은 상승·순항·급강하·착지 또는 회복을 분리한다.
- 보스 패턴은 전조 프레임과 실제 공격 프레임이 명확히 달라야 한다.

### 좌우 방향

- 좌우 미러링을 기본으로 사용한다.
- 창, 활, 방패 문양, 비대칭 어깨 장비는 미러링 검수 후 보정한다.
- 글자나 숫자를 장비 표면에 넣지 않는다.

## 11. VFX·조명 계약

- 캐릭터 본체는 클린 픽셀을 유지한다.
- 소프트 라이팅은 환경, 마법, 영웅·전설 순간 연출에 제한적으로 사용한다.
- 일반 스킬 전조: 0.25~0.6초.
- 영웅 스킬 전조: 0.6~1.0초.
- 전설·보스 전조: 1.0~1.5초.
- 실제 판정과 전조 범위는 일치한다.
- 적 위험 범위는 외곽선 중심.
- 아군 강화 범위는 내부 문양 중심.
- 지속 장판 최대 불투명도 목표 45%.
- 비행 고도는 지상 그림자와 얇은 수직 연결선으로 표시한다.

## 12. 실제 게임 삽입 검증

### 필수 테스트 해상도

- 1920×1080 기본 HUD.
- 1280×720 축소 HUD.
- 전략 최소 줌 0.85배.

### 유닛 검증

1. 일반 인간형을 40px 높이로 축소한다.
2. 같은 병종 5기를 24px 간격으로 일부 겹치게 배치한다.
3. 회색 석재 길, 저채도 풀, 적 VFX 위에서 확인한다.
4. 흑백으로 변환해 실루엣을 확인한다.
5. 1초 안에 병종·진영·등급 중 최소 두 항목을 인지하는지 측정한다.

### 건물 검증

1. 기본 병영을 128px 이하로 축소한다.
2. 농장·시장·특수병단·포탑과 나란히 배치한다.
3. 지붕, 입구, 부속 시설만으로 기능을 구분한다.
4. 파손·업그레이드 상태에서도 원래 건물 계열이 유지되는지 본다.

### 등급 검증

- 색상 제거 후 일반·엘리트·영웅·전설 중 최소 3단계를 구분.
- 전설 VFX를 제거해도 고유 실루엣이 남아야 함.
- 상위 등급 5인 편대가 과도한 잔광으로 하나의 덩어리가 되지 않아야 함.

## 14. 생성형 콘셉트 사용 규칙

생성형 이미지는 탐색과 비교에 사용하되 최종 스프라이트로 직접 사용하지 않는다.

### 허용

- 전체 스타일 후보 비교.
- 병종 실루엣과 장비 아이디어.
- 건물 Tier 변화와 전문화 구조 탐색.
- 색상·조명·재질 무드보드.

### 필수 후처리

- 픽셀 그리드 재작성.
- 손·무기·관절·방향 검수.
- 가짜 문자 제거.
- 팔레트 통합.
- 외곽선과 광원 통일.
- 실제 게임 크기 축소 테스트.

### 금지

- 생성 이미지를 수정 없이 최종 게임 자산으로 사용.
- 무기 구조와 손 위치를 검수하지 않은 채 채택.
- 확대 시에는 그럴듯하지만 40px에서 무너지는 디자인 채택.

## 16. 승인된 기준과 후속 결정

### 승인

- 클린 전술 픽셀 + 미니어처 치비 비율 + 고해상도 픽셀 완성도.
- 실제 축소 가독성을 콘셉트 확대 이미지보다 우선.
- 아군 10병종·적군 10병종·4등급 시각 성장.
- 대검전사 수염 제거와 흉터 중심 성장.
- 창병 무기 방향 계약.
- 궁병 두건 제거와 엘프형 실루엣.
- 마법사의 등급별 노마법사 성장.
- 생성형 이미지는 탐색용이며 최종 자산은 재정리.

### 후속 결정

- 최종 공통 팔레트와 색상 코드.
- 실제 스프라이트 캔버스 크기.
- 8방향 또는 좌우 2방향 제작 범위.
- 각 병종 성별·얼굴 다양성.
- 적군 발광색 최종값.
- 스프라이트 제작 도구와 파일 규칙.
- 최종 로고·폰트·아이콘 세트.

이 문서는 아트 제작 기준이며 Godot 자산 생성·임포트·애니메이션 구현 승인을 뜻하지 않는다. 실제 프로젝트 반영은 별도 Codex Plan Mode 제안서와 사용자 승인을 거친다.
