## 1. 최종 그림체 방향

```text
클린 전술 픽셀
+
미니어처 치비 픽셀의 친근한 비율
+
고해상도 픽셀의 재질·조명 완성도
```

### 핵심 정의

- 전략 줌에서 빠르게 읽히는 실루엣.
- 인간형 약 2.5~3등신의 경량화된 비율.
- 작은 화면에서도 무기, 자세와 몸통 덩어리로 병종 식별.
- 픽셀 단위를 일관되게 유지.
- 환경·마법·영웅·전설 순간 연출에만 제한적으로 고급 조명 사용.
- 기본 등급은 절제하고 상위 등급에서 실루엣과 기능 장식을 단계적으로 확장.

### 지향하는 인상

```text
가볍고 접근하기 쉬움
+ 전술 정보가 즉시 읽힘
+ 인디 픽셀의 수공예 감각
+ 상위 등급의 프리미엄 판타지 연출
```

### 피해야 할 인상

- 모바일 양산형 성채 게임의 과도한 금장과 장식.
- 모든 유닛이 처음부터 영웅처럼 보이는 디자인.
- 픽셀 위에 매끈한 생성형 명암만 얹은 형태.
- 실루엣보다 미세 장식과 발광이 먼저 보이는 구성.
- 기존 IP의 캐릭터·무기·문장을 직접 연상시키는 복제.

## 2. 공용 아키타입과 진영 이미지 제작

오멘워드는 공용 10병종 데이터와 AnimationContract를 사용한다.

```text
UnitArchetypeProfile
+ AnimationContract
+ FactionVisualProfile
```

이미지 제작 원칙:

- 공용 병종 하나당 아군 Visual Set과 적군 Visual Set을 만든다.
- 20개의 독립 병종 디자인·모션 데이터로 취급하지 않는다.
- 같은 아키타입의 양 진영 이미지 시트는 상태 목록, 프레임 수, 배열, 피벗과 공격 이벤트 프레임이 같다.
- 아군과 적군은 실루엣·소재·팔레트·초상화·아이콘이 다르다.
- 전투 능력과 판정 타이밍은 이미지가 소유하지 않는다.
- 적군 디자인이 공용 프레임 계약을 지키지 못하면 이미지 체형과 공격 기관을 먼저 수정한다.

### FactionVisualProfile 후보

```text
visual_faction_id
archetype_id
sprite_atlas_id
portrait_id
icon_id
palette_or_material_id
pivot_profile_id
```

금지:

- 적군 이미지를 위해 별도 Unit Scene·스탯·스킬·AnimationContract 제작.
- 표시명 차이를 새 전투 데이터 ID로 사용.
- 양 진영 시트의 프레임 수와 이벤트 위치가 다름.

## 3. 제작 해상도와 화면 기준

### 출력

- 기준: 1920×1080, 16:9.
- 축소 검증: 1280×720.
- 내부 픽셀 해상도 후보: 960×540, 정수 2배 확대.
- 기본 전략 줌에서 양측 본진과 세 라인을 함께 본다.
- 미니맵은 사용하지 않는다.

### 월드 표시 크기

| 대상 | 기본 화면 높이 |
|---|---:|
| 일반 인간형 | 34~40px |
| 엘리트 | 38~44px |
| 영웅 | 42~50px |
| 전설 | 46~56px |
| 특수 인간형 | 42~56px |
| 거인 | 72~96px |
| 기본 병영 | 100~128px |
| 특수병단 | 120~150px |
| 중간거점 핵심 구조 | 100~130px |
| 본진 | 150~180px |

- 상위 등급은 크기만 키우지 않는다.
- 실루엣 부속, 무기, 자세, 문양과 짧은 VFX로 위계를 표현한다.
- 전설이 거인 아키타입의 크기 의미를 침범하지 않는다.

## 4. 공통 픽셀 제작 규칙

### 팔레트

- 기본 유닛 Visual Set 하나당 핵심 색상 6~10색.
- 피부·머리·금속·갑각을 포함한 첫 제작 상한 18~24색.
- 동일 재질은 자산마다 다른 명암법을 사용하지 않는다.
- 아군 기본색: 회청, 남색, 상아색, 따뜻한 금속 포인트.
- 적군 기본색: 흑자색, 암적색, 갑각 회색, 제한된 균열 발광.

### 외곽선

- 기본 1px 외곽선.
- 바깥 실루엣은 어두운 중성색.
- 내부 경계는 한 단계 밝게 사용 가능.
- 밝고 어두운 배경 모두에서 읽히는 선택적 밝은 림 허용.

### 명암과 광원

- 본체 2~4단 명암.
- 금속·마법·균열 핵심부에 제한적 하이라이트 1단.
- 기본 광원은 화면 좌상단 하나.
- 상시 강한 발광 금지.
- 스킬 전조, 영웅·전설·보스 순간에만 발광 강조.

### 픽셀 일관성

- 한 시트에서 픽셀 크기 혼용 금지.
- 자동 안티앨리어싱 금지.
- 확대는 최근접 보간.
- 생성형 원본은 형태 탐색용이며 최종 자산은 픽셀 그리드 위에서 다시 정리한다.

## 5. 진영 형태 언어

### 루메른·실베른 Visual Set

- 수직선, 아치, 방패, 종, 천 배너.
- 실용적인 판금과 천 갑옷.
- 밝은 회색 금속, 남색 천, 상아색 의복.
- 금색은 계급·성물·전설의 제한된 포인트.
- 무기와 장비가 공용 아키타입의 기능을 과장해 보여준다.
- 훈련된 정렬과 비교적 대칭적인 구조.

### 베일런·베일종 Visual Set

- 비대칭 균열, 갑각, 가시, 공허 구멍.
- 검은 외곽과 내부에서 새는 제한된 빛.
- 인간 장비의 단순 어두운 복제가 아니라 기능을 생물 구조로 번역.
- 공용 아키타입의 무기 길이, 자세와 타격 방향은 유지.
- 역할을 읽을 수 있는 큰 기관·갑각·가시를 사용.

### 공통 금지

- 진영을 색상만으로 구분.
- 장식이 무기·기관 실루엣을 가림.
- 일반 등급부터 긴 망토·왕관·대형 보석·후광 사용.
- 얼굴이 병종 식별의 유일한 단서.
- 베일종에 무작위 가시를 추가해 공격 방향이 흐려짐.

## 6. 공용 10병종 Visual Set 계약

| 공용 병종 | 역할 실루엣 | 아군 Visual Set | 적군 Visual Set |
|---|---|---|---|
| 방패병 | 큰 전방 방어면, 낮은 중심 | 몸 높이 방패, 투구·짧은 외투 | 넓은 전방 갑각판, 접힌 방어 다리 |
| 대검전사 | 넓은 어깨, 몸보다 긴 공격 구조 | 대검, 사용 흔적과 손상 장비 | 성장한 절단 골격·균열 칼날 |
| 암살자 | 낮은 전방 자세, 양손 짧은 무기 | 쌍단검·짧은 망토 | 긴 갈퀴·낮은 비대칭 갑각 |
| 창병 | 가장 긴 수평 무기 | 장창·단단한 보병 장비 | 몸에서 뻗은 전방 가시창 |
| 궁병 | 큰 원거리 발사 구조와 탄약 | 활·화살통·엘프 귀·긴 머리 | 침 발사기관·탄낭 |
| 기병 | 탈것 포함 긴 전후 길이 | 기수와 말, 창·검 | 변이 야수와 탑승 기관의 일체형 |
| 사제 | 직립 지원 자세와 상단 성물 | 밝은 천·지팡이·성물 | 주변 개체와 연결되는 표식기관 |
| 마법사 | 촉매와 시전 중심 | 큰 소매·지팡이·마법 구체 | 공허 코어·촉수·지면 오염 기관 |
| 비행병 | 날개, 고도, 지상 그림자 | 가벼운 갑주·날개 장비·창 | 비대칭 날개·급강하 발톱 |
| 거인 | 일반의 약 2배, 큰 팔·공성 무기 | 중량 갑주·망치·철퇴 | 거대 갑각 팔·충격 구조 |

### 고정 피드백

- 대검전사는 수염으로 경험을 표현하지 않는다. 흉터, 손상 장비와 검날 사용 흔적을 사용한다.
- 창병의 창끝은 모든 등급·진영 Visual Set에서 적 방향을 향한다.
- 창병의 앞손·뒷손은 무게중심에 맞춘다.
- 궁병 아군 Visual Set은 두건보다 귀와 머리카락 실루엣을 사용한다.
- 마법사 아군 Visual Set은 등급 상승에 따라 백발, 수염과 자세로 권위를 높일 수 있다.
- 적군 Visual Set은 같은 AnimationContract를 지키는 범위에서 생물 구조로 변환한다.

## 7. 창병 방향 세부 계약

오른쪽 진행 기준:

```text
진행 방향: 오른쪽
창끝: 오른쪽
자루 끝·장식: 왼쪽
앞손: 창끝에 가까운 중간 지점
뒷손: 자루 끝에 가까운 지점
```

### 자세

- 대기: 창끝 전방 상단 5~15도.
- 이동: 전방 수평 또는 약간 상향.
- 공격 준비: 창끝을 뒤로 당겨도 방향을 뒤집지 않는다.
- 찌르기: 전방 수평.
- 창벽: 모든 창끝이 적 진행 방향.
- 사망·강한 피격 외에는 창끝이 뒤를 향하지 않는다.

### 적군 Visual Set

- 가시창의 끝과 몸쪽 연결부를 명확히 구분한다.
- 양 끝이 동일한 날처럼 보이지 않는다.
- 공용 접촉 이벤트 프레임에 가시 끝이 목표 위치에 도달해야 한다.

### 검수

- 창날과 자루·몸 연결부가 구분되는가.
- 손·관절 또는 생체 연결부 위치가 자연스러운가.
- 창끝과 시선·진행·공격 방향이 같은가.
- 등급과 진영이 바뀌어도 방향이 유지되는가.
- 좌우 미러링에서 문양·손잡이·창끝이 비정상적으로 뒤집히지 않는가.

## 8. 등급별 시각 성장

| 등급 | 캐릭터·개체 변화 | 무기·기관 변화 | VFX |
|---|---|---|---|
| 일반 | 가장 단순한 역할 실루엣 | 기능이 바로 읽히는 기본형 | 최소 공격·피격 효과 |
| 엘리트 | 어깨·투구·갑각 부속 1개 | 날·가드·기관 품질 상승 | 짧은 스킬 잔광 |
| 영웅 | 실루엣 부속 2개, 자세 변화 | 고유 형태와 기능성 장식 | 짧은 비전투 문양 |
| 전설 | 고유 부속·초상 실루엣 | 계열을 대표하는 상징 구조 | 출격·스킬·승리 순간 연출 |
| 신화 보스 | 페이즈별 실루엣·코어 변화 | 비대칭 증식·공성 구조 | 전용 보스 전조와 화면 반응 |

- 상위 등급은 일반형의 역할을 유지한다.
- 색상과 크기만으로 등급을 표현하지 않는다.
- 공용 RankProfile과 visual_grade_id가 양 진영 Visual Set에 동일하게 적용된다.
- 전설 VFX를 꺼도 고유 실루엣이 남아야 한다.

## 9. 건물 디자인 계약

### 상태

```text
건설 예정
건설 중
활성
업그레이드 중
비활성
파손
폐허
```

### 기본 병영

- 낮고 넓은 돌·목재 실루엣.
- 출입구, 훈련장, 허수아비와 무기 거치대로 기능 표현.
- T1은 전문화 장비를 과도하게 노출하지 않는다.
- T2는 지붕·입구·외부 장비로 6전문화를 구분한다.
- T3는 수직 크기보다 부속 시설과 훈련 공간을 확장한다.

### 특수병단

- 기본 병영보다 높고 의식·연구·대형 출입 구조가 보인다.
- T1은 비어 있는 준비 단상과 할인 축적 표시.
- 사제단: 성물, 종, 밝은 천.
- 마도단: 원형 관측부, 촉매, 청색 조명.
- 비행단: 높은 탑, 착륙대, 바람 방향 깃발.
- 거인단: 큰 문, 보강재, 중량 사슬.

### 농장·시장·포탑

- 농장: 밭, 창고, 풍차·물레. 식량 증가는 저장 구조 확장으로 표현.
- 시장: 천막, 진열대, 수레. 수입 증가는 물류와 점포 수로 표현.
- 포탑: 포신 길이·수와 상부 구조로 연사·사거리·대공 역할을 표시.

### 거점 노드와 폐허

- 전방 2·후방 1 배치를 유지한다.
- 노드 UI가 도로와 유닛을 가리지 않는다.
- 중립화 시 기능이 꺼진 비활성 상태를 표시한다.
- 적 점령 완료 시 원래 계열이 보이는 폐허로 전환한다.
- 폐허는 이동로를 막지 않는다.

## 10. 애니메이션 제작 규격

세부 상태와 타이밍은 `APPROVED_UNIT_ANIMATION_AND_BATTLE_PRESENTATION_GUIDE_V1.md`가 책임진다.

### 첫 프레임 가설

### 공용 계약

- 같은 아키타입의 아군·적군 시트가 프레임 수와 배열을 공유한다.
- 무기 접촉·투사체 생성 이벤트가 같은 프레임에 발생한다.
- 피벗, 지면선과 그림자 기준을 공유한다.
- 좌우 미러링을 기본으로 하되 비대칭 문양·무기·갑각을 검수한다.
- 장비 표면에 글자와 숫자를 넣지 않는다.

## 11. VFX·조명 계약

- 캐릭터 본체는 클린 픽셀을 유지한다.
- 소프트 라이팅은 환경, 마법과 상위 등급 순간에 제한한다.
- 일반 스킬 전조 0.25~0.6초.
- 영웅 0.6~1.0초.
- 전설·보스 1.0~1.5초.
- 실제 판정과 전조 범위를 일치시킨다.
- 적 위험은 외곽선, 아군 강화는 내부 문양.
- 지속 장판 최대 불투명도 목표 45%.
- 비행 고도는 그림자와 얇은 수직 연결선.
- 우회로 연무는 공격 위험 전조와 다른 회색·청회색 언어.
- 일반 공격에 상시 잔광·화면 흔들림을 붙이지 않는다.

첫 PoC에서는 진영별 VFX·오디오를 대량 분리하지 않는다. 이미지와 팀 마커만으로 판독이 부족하다는 테스트 근거가 있을 때 제한적 override를 검토한다.

## 12. 제작 우선순위

```text
1. 공용 역할의 흑백 키포즈
2. 아군 Visual Set 기본형
3. 동일 프레임 계약의 적군 Visual Set
4. 대기·이동·기본 공격
5. 피격·사망
6. 핵심 스킬
7. 등급 부속
8. 점령·우회·공성 상태
9. 승리 모션
10. VFX·오디오
11. 실제 HUD·배경·다수 유닛 검증
```

수직 슬라이스에서는 10개 전체가 아니라 대표 아키타입 3~5종의 양 진영 호환을 먼저 검증한다.

## 13. 실제 게임 삽입 검증

### 해상도

- 1920×1080 기본 HUD.
- 1280×720 축소 HUD.
- 전략 최소 줌 0.85배.

### 유닛

1. 일반 인간형을 40px 높이로 축소.
2. 같은 병종 5기를 일부 겹침.
3. 아군·적군 이미지를 혼합 배치.
4. 회색 돌길, 저채도 풀, 위험 VFX 위 확인.
5. 흑백 변환 후 병종·진영·등급을 판독.
6. 이동·공격·피격 상태를 실제 속도로 확인.

### Visual Set 호환

- 같은 archetype의 양 진영 시트 상태 수 일치.
- 상태별 프레임 수와 순서 일치.
- 피벗·지면선·그림자 위치 일치.
- 공격 접촉·투사체 생성 이벤트 일치.
- `visual_faction_id` 교체만으로 같은 Unit Scene에서 표시.

### 건물

1. 기본 병영을 128px 이하로 축소.
2. 농장·시장·특수병단·포탑과 비교.
3. 지붕, 입구와 부속만으로 기능 구분.
4. 비활성·파손·폐허에서도 원래 계열 유지.
5. 노드·도로·유닛과 겹침 확인.

### 등급

- 색 제거 후 최소 3단계 구분.
- 전설 VFX를 제거해도 고유 실루엣 유지.
- 상위 등급 5인 편대가 잔광으로 한 덩어리가 되지 않음.
