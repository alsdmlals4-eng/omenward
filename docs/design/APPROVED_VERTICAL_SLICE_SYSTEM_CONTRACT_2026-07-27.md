- 상태: `USER_APPROVED_PLAN / PLANNING_ONLY_PROFILE / PRODUCT_CODE_NOT_AUTHORIZED`

## 1. 제품 목표와 버티컬 슬라이스 범위

오멘워드는 건물로 세 원형 릴의 토큰 구조를 만들고, 룰렛 결과를 보관·판매·배치하여 세 전선의 공세에 대응하는 실시간 전략 오토배틀 게임이다.

버티컬 슬라이스는 작은 PoC가 아니라 다음 시스템을 실제로 연결하는 축소형 완성 경험이다.

- 세 가변 원형 릴, 영구 가로 이동, SpinSnapshot, SpinSession.
- 금화·병종 토큰, 보관·판매·식량.
- Tier 1~3 병종 성장과 건물 Tier 성장.
- 상·중·하 3라인 전장.
- 본진, 양측 중간 거점, 중앙 경합 지역.
- 건설, 점령, 파괴, 철거, 업그레이드, 수리.
- Map → Stage → Wave의 20스테이지 런.
- 미션, 메타 성장, 저장, UI, 아트, 오디오.
- 벨루 조언과 수동 팁.

콘텐츠 종류와 변형 수는 최소화할 수 있지만, 위 시스템의 연결 자체는 제외하지 않는다.

## 2. 전장 토폴로지

각 라인은 다음 순서를 가진다.

```text
아군 본진
→ 아군 중간 거점
→ 중앙 경합 지역
→ 적 중간 거점
→ 적 본진
```

전체 전장 수량:

| 항목 | 수량 |
|---|---:|
| 라인 | 3 |
| 본진 건설 노드 | 진영당 6 |
| 중간 거점 | 전체 6 |
| 중간 거점 건설 노드 | 거점당 3 |
| 중앙 경합 지역 | 3 |
| 전체 건설 노드 | 30 |

- 일반 병력은 라인 사이를 자유롭게 횡단하지 않는다.
- 호위병의 보호 오라는 실제 거리만 사용하므로 라인 경계를 넘을 수 있다.
- 후방 거점을 잃어도 이미 전진한 병력은 후퇴·약화·소멸하지 않는다.
- 신규 증원은 후방 경로를 다시 확보해야 전진할 수 있다.

## 3. 중앙 경합 지역

- 적 병력을 제거한 뒤 고정 시간 동안 점령한다.
- 점령속도는 유닛 수, 등급, Tier에 영향받지 않는다.
- 적이 점령 구역에 들어오면 점령은 일시정지한다.
- 점령 부대가 사라지면 유예시간 뒤 진행도가 합법 소유 상태 쪽으로 회복된다.
- 중립 지역은 진행도가 0으로 회복된다.
- 즉시 초기화하지 않는다.
- 점령 완료 전까지 기존 소유자와 골드/초 보너스는 유지된다.
- 점령 완료 순간 소유권과 골드/초 보너스가 원자적으로 이전된다.
- 소유권은 주둔 병력이 없어도 유지되며 수입도 계속 발생한다.
- 수동 중립화는 없고, 적이 명시적으로 재점령해야 한다.
- 같은 시각에 점령 완료와 적 진입이 발생하면 점령 거래를 먼저 완료한 뒤 `CONTESTED`로 전환한다.
- 점령 완료 전에는 해당 라인의 적 중간 거점으로 진격하지 않는다.
- 소유권은 같은 MapRun의 스테이지 사이에 유지된다.

초기 점령시간 기준은 8초다. 유예시간과 회복속도는 밸런스 데이터로 남긴다.

## 4. 중간 거점

- 각 라인에는 아군 중간 거점과 적 중간 거점이 하나씩 있다.
- 적 중간 거점을 점령하려면 해당 라인의 중앙 경합 지역을 소유하고 수비 병력을 제거해야 한다.
- 적 중간 거점 점령 완료 전에는 적 본진으로 진격하지 않는다.
- 고정 시간 점령이며 유닛 수와 등급은 점령속도에 영향받지 않는다.
- 소유권은 주둔 병력이 없어도 유지된다.
- 점령 완료 순간 소유권, 건설 권리, 건물 상태를 하나의 원자 거래로 처리한다.

### 4.1 점령 시 건물 처리

- 호환 건물은 새 소유자에게 이전한다.
- 비호환·진영 제한·사용 불가·병영 건물은 `BLOCKED`가 된다.
- 자동 파괴하지 않는다.
- 이전 가능한 건물은 HP와 Tier를 보존한다.
- `BLOCKED` 건물은 노드를 점유하며 모든 효과가 중지된다.

### 4.2 진행 중 작업

- 호환 건설: 진행도, HP, 지불 비용을 보존하고 계속한다.
- 비호환 건설: `BLOCKED`, 진행도와 HP를 보존하고 정지한다.
- 호환 업그레이드: 현재 Tier와 진행도를 보존하고 계속한다.
- 비호환 업그레이드: `BLOCKED`로 정지한다.
- 철거: 점령 시 일시정지하며 새 소유자가 재개하거나 취소한다. 완료 환불은 새 소유자가 받는다.
- 수리: 이미 회복한 HP는 보존하고 수리 작업은 종료한다. 실시간 과금이므로 예약금 반환은 없다.

### 4.3 점령 거래 순서

```text
1. 해당 시각의 건설·업그레이드 진행 반영
2. 해당 시각의 수리 회복·비용 정산
3. 건물 생존·파괴 상태 확정
4. 중간 거점 소유권 이전
5. 건물 호환성 분류
6. 호환 건물·프로젝트 이전 또는 BLOCKED 처리
7. 철거 일시정지
8. 수리 작업 종료
9. 건물 효과·타기팅·토큰 공급 재계산
10. 적 본진 진격 경로 개방
```

거래 중 일부만 적용할 수 없으며 실패하면 전체 롤백한다.

## 5. 건물 구성

버티컬 슬라이스의 기본 건물은 5종이다.

| 건물 | 핵심 기능 | 직접 공격 가능 | Tier 구조 |
|---|---|---:|---|
| 금고 | 골드/초 + `[금화]` 토큰 | 아니요 | 선형 T1→T3 |
| 농장 | 식량 생산·식량 한도 | 아니요 | 선형 T1→T3 |
| 타워 | 방어 공격 | 예 | T2 분기, T3 계열 강화 |
| 병영 | 병종 토큰 | 아니요 | T2 병종 분기, T3 전문화 |
| 지휘소 | 범위형 전장 버프 | 아니요 | T2 분기, T3 계열 강화 |

보관함과 판매는 별도 건물이 아니라 플레이어 공통 UI·런 시스템으로 유지한다.

### 5.1 금고

- 전역 골드/초를 제공한다.
- 각 릴의 해당 물리 노드 결속 슬롯에 `[금화]` 토큰 하나씩, 총 세 개를 공급한다.
- 금고 Tier는 지속 골드/초만 선형 강화한다.
- 금화 토큰의 보상 공식은 금고 Tier와 독립한다.
- 금화 당첨 보상은 기존 승인 규칙인 실제 회전 비용 기준 75% / 200% / 500%를 유지한다.
- 무료 회전의 기준 회전 비용은 미확정 데이터다.
- 금고가 파괴·철거 완료·교체·소유권 상실되면 플레이어 릴의 결속 금화 토큰은 같은 자리의 `SOURCE_BOUND_X`로 복구된다.
- 금고를 재점령하면 현재 금고가 다시 플레이어 소유가 된 시각에 금화 토큰이 같은 슬롯에서 재활성화된다.

금고 Tier가 금화 보상액과 변형 선택 확률을 동시에 올리는 이중 증폭은 금지한다.

### 5.2 농장

- 식량 생산과 최대 식량 한도를 제공한다.
- Tier가 오르면 두 값이 선형 강화된다.
- 식량 한도가 감소해도 기존 배치 병력을 제거하거나 약화하지 않는다.
- 신규 배치만 차단한다.

### 5.3 타워

Tier 1은 공통 기본 타워다.

Tier 2에서 두 계열 중 하나를 선택한다.

1. **연사탑 계열**
   - 빠른 단일 대상 공격.
   - 지상과 비행 모두 공격 가능.
   - 낮은 단발 피해와 빠른 표적 전환.
   - Tier 3은 같은 공격 모델의 공격속도·사거리·내구도를 선형 강화한다.

2. **포격탑 계열**
   - 느린 지상 광역 공격.
   - 비행 유닛 공격 불가.
   - 높은 단발 피해와 제한된 공격속도.
   - Tier 3은 같은 공격 모델의 피해·광역 반경·내구도를 선형 강화한다.

타워는 건설 시작 순간부터 직접 공격 가능한 구조물이 되지만, 완공 전에는 공격 기능이 비활성화된다.

### 5.4 병영

병영은 병종 토큰을 공급하는 TokenSource다.

- Tier 1: 공통 보병.
- Tier 2: 10개 병종 중 하나를 선택.
- Tier 3: 선택한 Tier 2 병종의 두 전문화 중 하나를 선택.
- 업그레이드 진행 중에는 현재 Tier 토큰과 현재 효과를 유지한다.
- 완료 순간 세 결속 토큰의 이름·외형·페이로드를 원자적으로 교체한다.
- 적이 중간 거점을 점령하면 병영은 `BLOCKED`가 되고 플레이어 릴의 토큰은 즉시 `SOURCE_BOUND_X`로 복구된다.

### 5.5 지휘소

지휘소는 자신을 중심으로 하는 범위형 오라 건물이다. 전역 버프를 기본으로 사용하지 않는다.

Tier 2에서 두 계열 중 하나를 선택한다.

1. **돌격 지휘소 계열**
   - 범위 내 아군 전투 유닛의 공격속도와 이동속도를 강화한다.
   - Tier 3은 같은 오라의 강도와 범위를 선형 강화한다.

2. **수비 지휘소 계열**
   - 범위 내 아군 전투 유닛의 방어력과 강제 이동 저항을 강화한다.
   - Tier 3은 같은 오라의 강도와 범위를 선형 강화한다.

중첩 규칙:

- 같은 계열 오라는 가장 높은 Tier 하나만 적용한다.
- 돌격과 수비 계열은 동시에 적용할 수 있다.
- 점령 완료 순간 현재 소유자 진영으로 오라 대상을 원자적으로 재결속한다.

## 6. 건물 공통 생명주기

### 6.1 공격 가능성

- 타워와 기타 명시적 전투 건물만 점령 전 직접 공격 가능하다.
- 금고, 농장, 병영, 지휘소는 점령 전 직접 공격할 수 없다.
- 비전투 건물은 별도 명시 규칙이 없는 한 광역·관통·환경·아군 피해도 받지 않는다.
- 전투 건물은 건설 시작 순간부터 노드와 footprint를 점유하고 공격 대상이 된다.
- 건설 중 공격·버프·디버프·점령 차단 효과는 비활성화된다.
- 업그레이드 중에는 기존 Tier 기능을 유지한다.

### 6.2 HP와 진행도

- HP와 건설·업그레이드 진행도는 별도 값이다.
- 피해는 진행도를 감소시키지 않는다.
- 진행도 증가는 HP를 회복하지 않는다.
- 손상된 상태로 완공될 수 있으며 완공 시 HP를 채우지 않는다.
- 건설 중 HP가 0이 되면 파괴된다.

### 6.3 파괴

- HP 0에서 건물 인스턴스를 완전히 제거한다.
- 잔해와 재건 명령은 없다.
- 노드는 즉시 `EMPTY`가 되고 새 건설을 시작할 수 있다.
- 건물 종류, Tier, 진행도, HP, 쿨다운, 생산, 이전 소유자를 보존하지 않는다.
- 이미 소비된 건설·업그레이드 비용은 환불하지 않는다.
- 미소비 프로젝트 에스크로만 원래 자금 제공자에게 반환한다.
- 파괴는 철거가 아니며 철거 환불을 제공하지 않는다.

## 7. 수리

별도 수리공방, 작업자, 작업 슬롯, 임금 곡선은 사용하지 않는다.

- 손상된 각 건물에 수리 작업 하나를 부착할 수 있다.
- 서로 다른 여러 건물을 동시에 수리할 수 있다.
- 같은 건물에 수리 작업을 중첩할 수 없다.
- 수리는 초당 HP를 회복하고 실제 회복 HP에 비례해 골드를 실시간 차감한다.
- 지갑은 음수가 될 수 없다.
- 골드가 부족하면 감당 가능한 HP만 회복한 뒤 자동 일시정지한다.
- 최대 HP에서 자동 종료한다.
- 파괴·`BLOCKED`·적 소유 건물에는 수리 작업을 시작할 수 없다.

동일 시각 처리 순서:

```text
1. 직접·광역·지속·환경 피해 계산
2. 건물 HP 반영
3. HP 0 이하 건물 파괴 확정
4. 생존한 건물에만 수리 적용
5. 실제 회복 HP 기준 골드 차감
6. 최대 HP 도달 시 수리 종료
7. 점령 거래 처리
```

수리 속도와 HP당 골드 비용은 룰렛 기대수익 재산정 뒤 고정한다.

## 8. 물리 릴과 결속 토큰

- 세 개의 가변 길이 원형 릴을 사용한다.
- 각 물리 건설 노드는 릴마다 결속 슬롯 하나를 가진다.
- 같은 노드가 같은 릴에 결속 슬롯을 중복 보유할 수 없다.
- 비활성 상태는 `SOURCE_BOUND_X`다.
- 금고 완공 시 세 결속 X가 금화 토큰으로 바뀐다.
- 병영 완공 시 세 결속 X가 해당 병종 토큰으로 바뀐다.
- 농장·타워·지휘소는 결속 X를 바꾸지 않는다.
- 파괴, 철거 완료, 교체, `BLOCKED`, 강제 제거 시 활성 토큰은 같은 자리의 X로 돌아간다.
- 릴 길이, 순서, cursor는 유지한다.
- 이미 생성된 SpinSnapshot은 변경하지 않는다.
- 이미 확정된 보상과 PendingReward는 변경하지 않는다.
- 비활성화 거래는 `physical_node_id + source_lifecycle_id` 기준으로 멱등적이다.

금화는 Tier 변형 선택을 사용하지 않는다. 병종 보상 변형은 동일 `infantry_root` 계열 매칭 뒤 다음 가중치로 결정한다.

```text
정확한 병종 변형 후보 가중치
= 해당 현재 변형을 공급하는 물리 병영 수 × Tier 가중치
```

| Tier | 가중치 |
|---:|---:|
| 1 | 1 |
| 2 | 2 |
| 3 | 3 |

동일 건물은 세 릴을 공급해도 후보 풀에서 한 번만 센다. SpinSnapshot 이후의 live 변경은 해당 보상 선택에 영향주지 않는다.

UI는 다음 5개 전술 그룹으로 정리하지만 모든 병종은 항상 선택 가능하다.

- 전열군: 방패병 / 대검전사

- 마법사: 원소술사 / 주술사

## 10. 업그레이드 경제 계약

- 건물 하나당 건설·업그레이드·철거 프로젝트는 최대 하나다.
- 작업자, 작업 슬롯, 노동력, 임금은 사용하지 않는다.
- 자원과 건물이 있으면 여러 업그레이드를 병렬 진행할 수 있다.
- 업그레이드 확정 시 전체 골드를 즉시 지갑에서 차감한다.
- 내부 프로젝트 에스크로는 소비분과 미소비분을 분리한다.
- 소비 비용은 정규화 진행도에 비례해 결정론적 누적 목표로 처리한다.
- 취소 시 미소비 에스크로 100%, 소비 비용 50%를 반환한다.
- 파괴 시 소비 비용은 소멸하고 미소비 에스크로만 반환한다.
- 호환 점령으로 프로젝트 제어권이 이전되어도 원래 자금 제공자를 보존한다.
- 취소·파괴 반환금은 원래 자금 제공자에게 돌아간다.
- 비용은 5골드 단위, 시간은 1초 단위 half-up 반올림한다.

기존 제안의 `100 / 140 / 180골드`, `24 / 29 / 35초`는 금화 토큰 기대수익을 포함하지 않았으므로 **초기 시뮬레이션 입력값**일 뿐 최종 정본 수치가 아니다.

## 11. 전투 기준

표준 공간 단위 `D`는 Tier 1 보병 충돌 지름이다.

```yaml
standard_infantry_collision_diameter: 1.0D
standard_infantry_collision_radius: 0.5D
standard_melee_edge_reach: 0.35D
standard_infantry_movement_speed: 1.0D_per_second
```

초기 기준 능력치:

| 병종 | HP | 공격력 | 공격간격 | 방어력 | 이동속도 |
|---|---:|---:|---:|---:|---:|
| Tier 1 보병 | 100 | 10 | 1.20초 | 0 | 1.00D/s |
| Tier 2 방패병 | 160 | 9 | 1.25초 | 20 | 0.85D/s |
| Tier 3 철벽수호병 | 220 | 11 | 1.40초 | 30 | 0.75D/s |
| Tier 3 호위병 | 190 | 10 | 1.30초 | 22 | 0.85D/s |

방어 계산 초기식:

```text
방어 후 피해 = 원시 피해 × 100 ÷ (100 + 방어력)
```

철벽 피해 감소는 방어 계산 뒤 곱연산한다. 최소 직접 피해는 면역이 아닌 한 1이다. 내부 계산은 결정론적 고정소수점을 사용한다.

## 12. 기본 표적 AI

일반 적은 점수가 낮은 대상을 선호한다.

```text
총 표적 점수
= 병종 가중치
+ 예상 교전 도달시간 ÷ 2초
+ 가장 강한 전문 프로필 보정 하나
+ 기타 전술 보정
```

병종 가중치:

| 계열 | 값 |
|---|---:|
| 방패병 계열 | 1.0 |
| 기타 근거리 | 1.4 |
| 원거리 | 1.8 |

예상 교전 도달시간:

```text
필요 접근거리 = max(0, 경로거리 - 유효 공격사거리)
예상 교전 도달시간 = 필요 접근거리 ÷ 현재 유효 이동속도
```

- 현재 공격 준비·실행·회복 주기가 끝난 뒤 재평가한다.
- 새 표적 총점이 현재 표적의 80% 이하일 때만 정상 전환한다.
- 사망, 무효, 도달 불가 대상은 즉시 재평가한다.
- 공격 주기 중에는 점수 스냅샷을 바꾸지 않는다.

전문 프로필 보정:

| 프로필 | 선호 대상 | 보정 |
|---|---|---:|
| 암살 | 원거리·지원 | -1.0 |
| 대공 | 비행 | -1.0 |
| 공성 | 전투 건물·기지 | -1.0 |
| 방패 파괴 | 방패병·`HIGH_DEFENSE` | -0.4 |
| 보스 | 패턴 정의 | 공통값 없음 |

공통 보정 등급은 `-0.4 / -0.8 / -1.0`이다. 여러 조건이 겹쳐도 가장 강한 하나만 적용한다. 최종 점수 하한은 0.25다.

`HIGH_DEFENSE`는 런타임 방어력에서 추론하지 않고 콘텐츠 태그로 명시한다. 방패병 계열은 자동 보유하며, 태그가 있는 직접 공격 가능한 전투 건물도 포함한다.

## 13. 방패병 Tier 3

### 13.1 호위병

- 호위병 중심의 원형 근거리 범위.
- 초기 반경은 표준 보병 충돌 지름의 2.5배.
- 라인 제한 없음.
- 보호 대상의 방어 계산 후 감소 예정 HP 중 25%를 호위병이 대신 잃는다.
- 호위병 방어력은 분담 피해에 다시 적용하지 않는다.
- 직접 피해와 광역 피해를 분담한다.
- 지속 피해와 환경 피해는 분담하지 않는다.
- 가장 가까운 유효 호위병 한 명만 선택한다.
- 호위병 계열 자신과 다른 호위병은 보호 대상에서 제외한다.
- 이미 전달된 피해는 다시 전달하지 않는다.
- 동일 틱의 보호자 배정은 틱 시작에 고정하고, 배정된 분담 피해를 모두 처리한 뒤 호위병 사망을 확정한다.
- 호위병이 같은 광역 공격에 직접 맞으면 자신의 방어 후 피해와 주변 아군 분담 피해를 모두 받는다.
- 이동·공격·둔화·속박·침묵·무장해제 중에는 보호를 유지한다.
- 기절·수면·빙결·넉다운·추방·사망 중에는 중단한다.

표현:

- 발밑 방패 문양으로 활성 상태를 표시한다.
- 전체 범위는 선택·마우스오버·전술 오버레이 때만 선명하게 표시한다.
- 피해 분담 순간 0.25초 맥동과 방패 아이콘 피해 숫자를 표시한다.
- 색상만으로 상태를 구분하지 않는다.

### 13.2 철벽수호병

정지한 시간이 길수록 0~3단계 철벽 상태를 쌓는다.

| 단계 | 정지시간 | 직접·광역 피해 감소 | 일반 강제 이동 거리 감소 |
|---:|---:|---:|---:|
| 0 | 0초 | 0% | 0% |
| 1 | 2초 | 10% | 25% |
| 2 | 5초 | 20% | 50% |
| 3 | 10초 | 40% | 100% |

- 지속 피해와 환경 피해에는 철벽 피해 감소를 적용하지 않는다.
- 공격 중 실제 위치가 변하지 않으면 정지시간을 계속 쌓는다.
- 미세 충돌 보정은 이동으로 보지 않는다.
- 실제 이동 누적 1초마다 철벽이 한 단계 하락한다.
- 1초 미만 이동시간은 정지 중에도 보존된다.
- 3단계는 일반 밀치기·끌어당김·띄우기·전투 충돌 이동에 면역이다.
- 순간이동, 위치 교환, 보스 재배치, 스테이지 이동, 안전 복구 등 예외 재배치가 성공하면 원인과 관계없이 즉시 0단계로 초기화한다.

추적:

| 단계 | 자율 추적 |
|---:|---|
| 0 | 일반 근접 추적 |
| 1 | 정착 기준점 반경 2.5D |
| 2 | 정착 기준점 반경 1.25D |
| 3 | 자율 추적 없음, 사거리 안의 적만 공격 |

플레이어 또는 상위 전선 AI의 명시적 이동은 허용하고 실제 이동에 따라 단계를 해제한다.

## 14. 벨루 조언

### 벨루의 조언

- 자동으로 표시되는 짧은 상황 문장.
- 한 문장, 비상호작용, 입력 차단과 자동 일시정지 없음.
- 이벤트 기반 후보 생성, 중요도 우선 큐, 동일 주제 병합, 오래된 항목 폐기.
- 한 번에 한 문장만 표시한다.
- 기본 빈도 `표준`, 옵션 `낮음`, `끔`.
- 긴급 본진 위험은 기존 음성을 짧게 중단할 수 있다.

### 벨루 팁

- 벨루 초상을 눌러 여는 비모달 패널.
- 현재 상황, 추천 병종 최대 2개, 이유와 단점을 표시한다.
- 자동 선택, 숨은 선택지, 비용·능력치·룰렛 보너스는 없다.
- 패널을 연 시점의 RecommendationSnapshot을 유지한다.
- 관련 사건이 발생하면 오래됨 표시만 하고 수동 새로고침 또는 재개방 때 갱신한다.
- 오래된 추천이어도 선택을 차단하지 않으며 실제 명령 합법성만 재검증한다.

추천은 결정론적 규칙 기반이다.

```text
직접 카운터
+ 전투 기능 공백
+ 라인 긴급도
+ 경제 실행 가능성
+ 장기 효용
- 중복
- 완공 위험
- 명확한 불리함
```

최근 조언은 현재 스테이지 최대 5개, 최신순으로 보존한다. 해결된 항목은 낮은 우선순위로 남고 재발은 새 생명주기로 기록한다.

## 15. 맵런·시간·저장

- 표준 MapRun은 20스테이지다.
- 일반 스테이지 3웨이브, 위험 스테이지 4웨이브, 최종 스테이지 5웨이브.
- 매 5번째 스테이지는 위험 스테이지다.
- 일반 전투의 전술계획 정지는 전투, 점령, 회복, 수리, 경제를 모두 정지한다.
- 위험 전투는 전술계획 정지를 허용하지 않는다.
- 준비 화면은 안전하고 시간 제한이 없다.
- 접전지와 중간 거점 소유권, 건물, 병력, HP, 자원, 릴, 보관함 상태는 MapRun 안에서 스테이지 사이에 유지된다.

### 15.1 저장

기존 `첫 슬라이스 mid-run save 미지원` 규칙은 이번 전체 시스템 버티컬 슬라이스 목표로 대체한다.

- 활성 전투 중 임의 프레임 저장은 지원하지 않는다.
- 스테이지 준비 진입과 스테이지 정산 완료 시 versioned checkpoint를 원자적으로 저장한다.
- checkpoint에는 MapRun 상태, 건물·소유권·프로젝트, 병력·HP·식량, 릴 배열·cursor·결속 슬롯, 보관함, 미션, 메타 런 보상 임시 상태를 포함한다.
- 불완전 저장은 이전 정상 checkpoint를 대체하지 않는다.
- 저장 스키마 버전과 migration 정책은 구현 계획 전 별도 고정한다.

## 16. 경제 기준과 잠정값

- 기준 일반 웨이브 길이: 60초.
- 웨이브 사이 기본 간격: 10초.
- 본진 보장 수입 초기값: 1.5골드/초.
- Tier 1 금고 지속 수입 초기값: 1.0골드/초.
- 중앙 경합 지역 초기 보너스: 지역당 0.25골드/초, 최대 0.75골드/초.

금화 토큰의 기대수익이 전체 경제에 추가되므로 다음은 최종 고정 전 반드시 100,000시드 시뮬레이션으로 재산정한다.

- 유료 회전 비용.
- 무료 회전의 기준 회전 비용.
- 금화 당첨 기대수익.
- 건물 건설·업그레이드 비용.
- 병영 전문화 비용과 시간.
- 수리 HP당 비용.
- 판매가와 보관 압력.

경제 잠정값을 승인 정본 수치로 오인하지 않는다.
