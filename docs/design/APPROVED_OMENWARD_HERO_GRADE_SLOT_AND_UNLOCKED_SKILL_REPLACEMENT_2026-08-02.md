# [보류] 영웅 이상 등급 슬롯·해금 고유 스킬 교체

```yaml
status: HELD_FOR_CURRENT_CONTENT_RECONCILIATION
held_at: 2026-08-04
implementation_authority: NONE
```

전장 전체의 고등급 병력 수를 제한해 희소성과 판독성을 보존하고, 해금 영웅이 기본 병종 계보를 유지해야 한다는 방향은 후보로 보존한다.

그러나 영웅·전설의 실제 역할·획득 빈도·Stage 압력·병종 카운터·전선 커밋 경험이 아직 최신 콘텐츠 정본으로 확정되지 않았다. 과거 단일 슬롯·스킬 교체·반복 결과 처리 규칙을 그대로 구현하면 룰렛 보상 기대와 전선 전략을 왜곡할 수 있다.

재개 조건:

```text
Stage 압력 매트릭스
→ 병종 역할·Tier 시너지
→ 첫 10~15분 기본 루프
→ Hero·Legendary family 통합 적대적 검토
```

그 전까지 획득·배치·슬롯·스킬 교체의 구현 입력으로 사용하지 않는다.
