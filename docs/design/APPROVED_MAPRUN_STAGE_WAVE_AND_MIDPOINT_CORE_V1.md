# 승인된 MapRun·스테이지·웨이브·접전지 코어

- 작성일: 2026-07-24
- 상태: `V2_SPEC_APPROVED / V2_IMPLEMENTATION_NOT_STARTED`
- 기존 구현: `LEGACY_C2_C3_PROVEN / MIGRATION_REQUIRED`
- 승인 근거: 2026-07-24 사용자 확정
- 상위 책임: `docs/PROJECT_CORE.md`

이 문서는 맵런 수명주기, 준비·일반·위험 시간 규칙, 웨이브 묶음 출현, 병력 보관·배치·식량과 중간 접전지 규칙을 소유한다.

## 1. 진행 계층

```text
MapRun
└─ Stage
   └─ Wave
      └─ Spawn Batch
```

- 맵런은 한 전장의 전체 플레이 세션이다.
- 스테이지는 준비와 전투가 반복되는 성장 단위다.
- 웨이브는 하나의 적 편성이다.
- 출현 묶음은 실제 출현 최소 단위다.

표준 맵은 20스테이지다. 약 15·25스테이지 변형은 콘텐츠 확장 단계로 보류한다.

- 일반 스테이지: 3웨이브.
- 위험 스테이지: 4웨이브.
- 최종 스테이지: 5웨이브.
- 매 5번째 스테이지는 위험이다.
- 20스테이지는 위험과 최종 속성을 함께 가진다.

## 2. MapRun 유지 상태

맵런 동안 다음을 유지한다.

- 건물·업그레이드·파괴·노드 상태.
- 생존 병력, 라인, 현재 HP와 사망 손실.
- 본진·건물 HP.
- 금화, 식량 수용량, 이동 아이템, 무료 회전권.
- 세 릴 전체 배열, cursor, 토큰 출처와 가로 이동 결과.
- 럭키 실패 상태.
- 결과 보관함과 결과 대기.
- 전설 위험 주기 사용 상태.
- 접전지 소유권과 양방향 게이지.

새 맵런 시작 시 위 런 상태를 초기화하고 영구 해금·설정·기록만 유지한다.

## 3. mid-run save

코어 PoC와 첫 수직 슬라이스에서는 mid-run save를 지원하지 않는다.

```text
실행 중 MapRun → 세션 메모리에서만 유지
게임 종료·런 포기 → 런 상태 소멸
영구 해금·설정·기록 → 저장
```

정식 20스테이지 맵을 콘텐츠 기준으로 잠그기 전에 스테이지 준비 화면 전용 `versioned checkpoint save`를 별도 승인·구현한다. 전투 중 임의 저장은 현재 범위에서 제외한다.

## 4. StageFlow 상태

```text
PREPARATION
NORMAL_COMBAT
TACTICAL_PLANNING
DANGER_COMBAT
SYSTEM_PAUSE
STAGE_CLEAR
RUN_COMPLETE
DEFEAT
```

각 상태는 전투, 웨이브, 생산, 회복, 수리, 쿨다운, 점령과 룰렛 쿨다운의 진행 여부를 명시적으로 소유한다.

## 5. 스테이지 준비

스테이지 진입 시 전투를 완전히 정지한다.

```text
준비 진입
→ 무료 회전권 +1
→ 첫 웨이브 전체 예고
→ 미션 선택·거부
→ 건설·업그레이드·룰렛·배치·수리
→ [스테이지 시작]
→ 첫 출현 묶음 즉시 등장
```

- 준비 시간은 무제한이다.
- 준비 시간은 클리어 시간 평가에서 제외한다.
- 준비 중 건설·업그레이드·룰렛·배치·유료 수리는 즉시 적용한다.
- 병력과 건물은 준비 시간이 길다는 이유로 자연 회복하지 않는다.
- 위험 스테이지도 안전한 전용 준비 화면을 제공한다.

## 6. 무료 회전권

- 스테이지 준비 진입 시 무료 회전권 1개를 즉시 지급한다.
- 웨이브별이 아니라 스테이지별이다.
- 준비 화면에서 사용할 수 있다.
- 사용하지 않은 회전권은 같은 맵런 안에서 제한 없이 이월한다.
- 위험 스테이지의 추가 웨이브는 추가 회전권을 주지 않는다.

## 7. 일반 전술계획

일반 전투에서 핵심 계획 UI를 열면 `TACTICAL_PLANNING`으로 전환한다.

정지 대상:

- 유닛 이동·공격.
- 웨이브 타이머.
- 생산·치유·수리.
- 쿨다운.
- 접전지 진행.
- 룰렛 쿨다운.

건설·업그레이드·병력 배치·전술 스킬은 예약한다. 예약은 `[전투 재개]` 전 무료 수정·취소가 가능하다.

룰렛 이동은 예외다.

- 이동은 즉시 실행한다.
- 자원을 즉시 소비한다.
- 되돌릴 수 없다.

`[전투 재개]` 시 예약 명령을 검증하고 비용을 일괄 차감한 뒤 동시에 적용한다. 패널을 닫는 것만으로 전투를 재개하지 않는다.

## 8. 위험 스테이지

위험 준비 화면에서 `[위험 스테이지 시작]`을 누른 뒤 스테이지 종료까지 전술계획 정지를 사용할 수 없다.

- 모든 패널을 실시간으로 조작한다.
- 룰렛 회전·판독·이동·확정·보관·판매·배치 중에도 전투가 진행된다.
- 건설·스킬·배치는 즉시 실행하고 비용도 즉시 차감한다.
- 공세 정보는 일반 스테이지와 같은 정확도로 공개한다.
- 시스템 ESC 정지는 허용하지만 그 상태에서 전장 명령과 핵심 UI 조작은 금지한다.

위험의 난이도는 숨은 정보가 아니라 실제 실행 시간과 주의 비용에서 나온다.

## 9. 웨이브 예고와 출현

공세 예고는 다음을 공개한다.

- 라인.
- 병종.
- 라인·병종별 정확한 총수량.
- 특수 능력과 위협.
- 난이도·변형을 적용한 최종 출현 간격.

숨기는 정보:

- 각 3기 묶음의 내부 조합.
- 묶음의 세부 출현 순서.

출현 규칙:

- 기본 묶음 크기는 라인당 최대 3기다.
- 마지막 묶음은 1~2기일 수 있다.
- 다중 라인 웨이브는 같은 시점에 라인별 최대 3기까지 출현할 수 있다.
- 웨이브는 마지막 예약 묶음이 출현한 순간 편성 종료로 판정한다.
- 살아 있는 이전 웨이브 적은 제거하지 않는다.

## 10. 웨이브 전환 시간

```text
t = 0초  현재 웨이브 마지막 묶음 출현
t = 10초 다음 웨이브 전체 예고 공개
t = 20초 다음 웨이브 첫 묶음 출현
```

- 일반 전술계획 중에는 이 타이머가 정지한다.
- 위험 전투에서는 계속 진행한다.
- 첫 웨이브는 준비 화면에서 이미 공개되며 스테이지 시작과 동시에 첫 묶음이 출현한다.

난이도별 기본 출현 간격:

| 난이도 | 간격 |
|---|---:|
| 노말 | 3.0초 |
| 베테랑 | 2.5초 |
| 나이트메어 | 2.0초 |
| 헬 | 1.5초 |

변형 규칙을 합산한 최종 하한은 1.0초다.

## 11. 스테이지 종료

최종 웨이브의 마지막 묶음이 출현하고, 전장에 남은 모든 적과 적 소환물을 제거하면 스테이지를 클리어한다.

- 투사체·일시 효과·비전투 구조물은 클리어를 막지 않는다.
- 마지막 적 사망 즉시 전투를 멈춘다.
- 미션·성과를 정산한다.
- 다음 스테이지 준비로 이동하고 무료 회전권을 지급한다.
- 클리어 후 자유 회복 시간을 제공하지 않는다.

본진 HP가 0이면 즉시 패배한다.

## 12. 결과 보관함

병력은 결과 대기, 보관함, 전선 배치의 세 상태 중 하나에 있다.

기본 보관함:

- 4칸.
- 한 칸에 병력 한 기.
- 중첩 없음.
- 보관 중 식량 0.
- 맵런 동안 유지.

복수 병력 결과가 빈 슬롯보다 크면 전체 결과를 안전한 결과 대기에 유지한다.

- 병력 손실 없음.
- 다음 룰렛 회전 차단.
- 개별 즉시 배치 또는 판매 가능.
- 남은 병력 전부가 들어갈 공간이 생겼을 때만 보관함으로 일괄 이동.
- 일부를 판매한 뒤 나머지를 보관할 수 있다.

보관함이 4/4이고 처리 중 결과가 없으면 새 유닛 결과를 받을 수 없으므로 회전을 차단한다. 차단 시 회전권과 금화를 소비하지 않는다.

## 13. 배치와 식량

- 병력 배치 시 라인을 선택한다.
- 성공한 배치는 식량 수용량을 즉시 점유한다.
- 배치 후 라인 변경, 회수, 판매가 불가능하다.
- 생존 병력과 현재 HP는 다음 스테이지로 유지한다.
- 병력 사망 시 점유 식량을 즉시 반환한다.

식량은 유지비가 아니라 배치 수용량이다.

- 결과 대기·보관 병력은 식량 0.
- 수용량이 현재 사용량 아래로 감소해도 기존 병력을 제거·약화하지 않는다.
- 사용량이 다시 최대치 이하가 될 때까지 신규 배치만 차단한다.

## 14. 판매

- 결과 대기 또는 보관함 병력만 판매할 수 있다.
- 배치 병력은 판매할 수 없다.
- 판매는 즉시 확정하고 되돌릴 수 없다.
- 특수 병종은 같은 등급 일반 병종의 정확히 2배를 기본 계약으로 한다.
- 정확한 등급별 판매가는 경제 시뮬레이션에서 확정한다.
- 전설 판매는 위험 주기 한도를 복구하지 않는다.

## 15. 중간 접전지

각 라인에는 하나의 고정 중간 접전지가 있다.

영역:

- **전투 반경**: 적 존재를 확인하고 교전하는 넓은 범위.
- **점령 구역**: 점령 게이지를 움직이는 좁은 범위.

점령 조건:

1. 한 진영 병력이 점령 구역에 최소 한 기 존재한다.
2. 반대 진영 병력이 전투 반경에 한 기도 없다.
3. 양 진영이 동시에 점령 구역을 점유하지 않는다.

- 병력 수·등급·점령력 수치가 속도를 바꾸지 않는다.
- 한쪽 끝에서 반대쪽 끝까지 고정 8초다.
- 게이지는 양방향 하나를 사용한다.
- 소유권은 반대쪽 끝에 완전히 도달할 때만 바뀐다.
- 중간을 지났다고 중립이 되지 않는다.
- 교전·공백·일시정지 시 게이지와 소유권을 보존한다.

중립·적 접전지에 도착한 병력은 멈추고 전투 반경 안의 적을 일반 AI로 공격한다. 반경 밖까지 추격하지 않는다. 적이 사라지면 점령 구역으로 돌아와 점령한다.

이미 접전지를 지나 전진한 병력은 후방 접전지를 잃어도 후퇴·약화하지 않는다. 신규 증원만 해당 접전지에서 멈춰 재점령한다.

## 16. 체력·회복·수리

- 생존 병력, 건물과 본진의 현재 HP는 스테이지 사이 유지한다.
- 자동 회복·자동 수리는 없다.
- 사망 병력은 부활하지 않는다.
- 파괴 건물은 일반 수리로 복구하지 않는다.
- 병력 회복은 전투 중 명시적 효과만 허용한다.
- 건물·본진은 전투 수리와 준비 화면 유료 수리를 허용한다.
- 준비 화면 유료 수리는 `실제 회복 HP × 공통 체력당 수리 단가`를 사용하며 정확한 단가는 PoC 변수다.

최종 웨이브 마지막 묶음 출현 뒤 `잔존 적 처리` 상태에서는 전투 중 병력 회복과 건물·본진 수리의 최종량에 0.5를 곱한다. 준비 화면 유료 수리는 이 감소를 받지 않는다.

## 17. 맵 종료와 무한 방어

20스테이지 최종 클리어 보상은 즉시 확정한다. 이후 런 종료 또는 무한 방어를 선택할 수 있다.

무한 방어는 후속 구현 범위다.

- 기존 런 상태 유지.
- 매 5번째 스테이지 위험.
- 준비 화면에서만 자진 종료.
- 자진 종료는 패배가 아님.
- 직접 보상은 기록·업적·칭호·장식으로 제한.

## 18. 기존 구현 강등

다음 구현은 V2 현재 규칙이 아니다.

- 60초마다 전체 웨이브를 한 번에 출현시키는 흐름.
- T-30/T-15/T-5 단계 공개.
- 유닛별 `capture_power` 합산과 최대 점령력 2.0.
- 중간거점의 10초 중립화+10초 점령 상태기를 중앙 접전지에 재사용.
- 단일 StageRun이 맵런 영속 상태를 모두 소유하는 구조.
- 웨이브당 또는 구형 방식의 무료 회전 지급.

기존 C2·C3 실행 증거는 보존하지만 위 규칙은 `LEGACY_IMPLEMENTED / MIGRATION_REQUIRED`다.

## 19. 검증 계약

- 상태별 시간 진행 행렬.
- 준비 진입 무료 회전권 정확히 1회.
- 일반 명령 예약·수정·취소·동시 적용.
- 룰렛 이동 즉시 소비 예외.
- 위험 전투 중 타이머·전투 지속.
- 1·2기 나머지 묶음과 다중 라인 동시 출현.
- t+10 예고·t+20 시작.
- 이전 웨이브 잔존 적 누적.
- 최종 예약 출현과 전멸을 모두 요구하는 클리어.
- 2영웅 결과·빈 슬롯 1칸의 무손실 처리.
- 사망 식량 반환과 수용량 감소 후 기존 병력 유지.
- 접전지 고정 8초, 적 전투 반경 진입 정지, 빈 상태 보존.
- mid-run save 호출이 코어 MVP에서 명시적으로 거부됨.
