# 승인된 진영 대칭형 유닛·건물 구조와 적군 등급 이정표 1차안

- 작성일: 2026-07-15
- 적용 범위: 아군·적군 유닛, 병종·Tier·등급 비교, 적 건물, 웨이브 5·10·15·20 이정표, 데이터·UI·밸런스 계약
- 연결 문서:
  - `docs/design/APPROVED_15_WAVE_STAGE_CLOCK_AND_OVERTIME_V1.md`
  - `docs/design/APPROVED_UNIT_GRADE_AND_ABILITY_GROWTH.md`

이 문서는 아군과 베일종이 서로 다른 외형·진영·생산 방식으로 싸우더라도, 플레이어가 병종·Tier·등급만 보고 대략적인 위협을 가늠할 수 있도록 공통 제작·밸런스 문법을 정의한다.

---

## 1. 핵심 원칙

```text
같은 병종 계열
+ 같은 Tier
+ 같은 전투 등급
= 비슷한 기본 전투 예산
```

예시:

```text
아군 Tier 2 전사 일반
↔ 적군 Tier 2 전사 일반

아군 Tier 2 전사 엘리트
↔ 적군 Tier 2 전사 엘리트
```

두 유닛은 외형과 세부 능력이 달라도 다음 값의 총합이 유사해야 한다.

- 생존력
- 지속 피해량
- 사거리와 이동성
- 범위 공격 가치
- 상태이상과 전술 가치
- 구조물 대응력
- AI·타기팅의 효율

같은 계열·Tier·등급의 기본 전투 예산은 원칙적으로 ±10% 안에서 시작한다. 더 큰 차이가 필요하면 숨은 능력치가 아니라 공개 태그·능력·약점으로 설명한다.

---

## 2. 진영 차이와 대칭의 경계

### 공통으로 사용하는 것

- 병종 계열
- Tier 1~3
- 일반·엘리트·영웅·전설의 전투 단계
- 물리·마법·고정 피해
- 지상·비행 레이어
- 근접·원거리·돌진·급강하·공성 등 행동 태그
- 치명타·후방·경직·밀쳐내기·상태이상 규칙
- 기본 능력치 필드
- 패시브·스킬 슬롯 구조
- 건물 Tier와 전문화 구조

### 진영별로 달라지는 것

- 외형·애니메이션·음향
- 스킬의 실제 명칭과 연출
- 세부 타기팅과 AI
- 진영 고유 상태이상·편성 보너스
- 획득·생산 방식
- 경제 비용과 웨이브 Threat Cost

아군은 건물·생산·용병·룰렛으로 병력을 확보한다. 적군은 룰렛을 사용하지 않고 적 건물과 `StageManifest`의 시간표에 따라 정해진 병력과 등급을 출격시킨다.

## 3. 병종 대응 구조

초기 병종은 양 진영에서 같은 역할 축을 공유한다.

| 공통 계열 | 아군 예시 | 적군 예시 | 비교 기준 |
|---|---|---|---|
| 전사 | 검사·방패병·대검병·광전사 | 베일 검병·갑각 수호병·분쇄자·혈전사 | 전열·근접 지속전 |
| 창병 | 창병·상위 장병기 | 가시창병·돌진 저지형 | 기병·돌진 대응 |
| 궁병 | 궁병·석궁·대공·연사 | 침사수·뼈궁수·공중 사냥꾼 | 후열·대공 |
| 기병 | 기병·중기병·충격기병 | 야수기수·갑각 돌격수 | 기동·돌진 |
| 암살자 | 도적·암살자 | 베일 잠복자 | 후방 침투 |
| 공성 | 공성병·공성 지원 | 파괴자·운반수 | 구조물 압박 |
| 비행 | 비행 아군 후보 | 비행 베일종 | 지상 우회·대공 요구 |

이름과 실루엣은 완전히 달라도 HUD의 공통 계열 아이콘과 태그를 사용해 역할을 즉시 비교할 수 있게 한다.

## 4. Tier 대칭 계약

| Tier | 공통 의미 |
|---:|---|
| 1 | 계열의 기본 역할과 패시브 1 |
| 2 | 역할 전문화, 패시브 1 강화와 패시브 2 |
| 3 | 세부 병종 심화, 패시브 1·2 강화와 패시브 3 |

적군 Tier는 웨이브가 진행됐다는 이유만으로 자동 상승하지 않는다. 실제 출격 유닛과 생산 건물에 Tier가 명시된다.

```text
적 전사 Tier 1 일반 다수
≠ 적 전사 Tier 3 일반 소수
```

두 편성은 총 Threat Budget이 같을 수 있지만, 개별 유닛의 역할·상성·처치 우선순위는 다르게 읽혀야 한다.

## 5. 공통 등급 구조

### 일반

- 기본 능력치 프로필
- 1스킬 기본형
- 계열과 Tier의 패시브 적용

### 엘리트

- 일반보다 높은 공통 등급 예산
- 강화된 1스킬
- 즉시 식별 가능한 무기·장식·자세

### 영웅

- 엘리트 단계의 강화 1스킬
- 신규 2스킬
- 고유 실루엣과 전장 역할

### 전설

- 영웅 단계 유지
- 강화된 2스킬
- 신규 3스킬
- 보스가 아닌 전설 유닛도 존재 가능

플레이어의 등급은 룰렛 결과로만 결정된다. 적군 등급은 웨이브 시간표와 적 건물이 결정하며 룰렛을 사용하지 않는다.

---

## 6. 적군 전용 신화급

`신화`는 플레이어 룰렛에 추가되는 다섯 번째 등급이 아니다.

```text
플레이어 획득 등급
일반 → 엘리트 → 영웅 → 전설

적군 절멸 위협
전설 → 신화급
```

신화급은 20웨이브 최종보스 같은 적군 전용 절멸 위계다.

신화급 기본 구조:

- 전설 단계의 패시브·1·2·3스킬 구조 유지
- `신화 특성` 1개 추가
- 최소 2개 전투 페이즈
- 페이즈 전환 시 패턴·타기팅·이동 규칙 변화
- 높은 군중제어 저항과 구조물 압박
- 약점과 대응법을 베일의 징조에 공개

신화급은 단순한 체력 배율이 아니라 전설 보스의 규칙 위에 새로운 페이즈 규칙을 추가한 적군 전용 보스 패키지다.

## 7. 웨이브 등급 이정표

정규 스테이지의 주요 이정표는 다음으로 고정한다.

| 웨이브 | 대표 위계 | 기본 구성 |
|---:|---|---|
| 1~4 | 일반 | 일반 병종 중심, Tier·라인 학습 |
| 5 | 엘리트 | 엘리트 핵심 유닛 + 일반 호위 |
| 6~9 | 일반·엘리트 혼합 | 엘리트 비중과 복수 병종 증가 |
| 10 | 영웅 | 영웅 핵심 유닛 + 엘리트·일반 호위 |
| 11~14 | 영웅·엘리트 혼합 | 상위 Tier·공성·비행 포함 |
| 15 | 전설 | 전설 보스 + 영웅·엘리트 호위 |
| 16~19 | 강화 초과전 | 엘리트·영웅 비중 급증, 전설 잔존 가능 |
| 20 | 신화급 | 신화 최종보스 + 전설·영웅 호위 |

### 5웨이브 엘리트 공세

- 엘리트 유닛의 강화 1스킬을 처음 명확히 보여준다.
- 일반 호위는 엘리트의 역할을 가리지 않는 편성으로 둔다.
- 외형·크기·징조 카드에서 엘리트를 즉시 식별하게 한다.

### 10웨이브 영웅 공세

- 영웅의 2스킬을 공세 핵심 패턴으로 사용한다.
- 한 라인만 보는 플레이를 벌하기 위해 다른 라인에 엘리트 압박을 함께 둔다.
- 10웨이브는 빌드가 최종 결전까지 갈 수 있는지 검사하는 중간 보스 역할이다.

### 15웨이브 전설 보스 공세

- 전설 보스 1기가 주 라인의 결전 핵심이다.
- 강화 1스킬·강화 2스킬·3스킬을 모두 사용한다.
- 보스 태그와 페이즈·돌파 패턴은 등급 스킬 구조와 별개인 보스 행동 패키지로 관리한다.
- 나머지 라인에는 영웅 또는 엘리트 지휘관을 배치한다.

### 20웨이브 신화 최종보스 공세

- 신화급 보스 1기와 전설·영웅 호위를 사용한다.
- 기존 15웨이브 전설 보스가 살아 있으면 함께 남는다.
- 신화 특성과 페이즈 전환으로 장기 교착을 끝낸다.
- 즉시 패배는 아니지만 일반적인 기대 결과는 빠른 패배다.

## 8. 동일 병종·Tier·등급 비교 규칙

예시:

```text
아군 Tier 2 방패 전사 엘리트
↔ 적군 Tier 2 갑각 전사 엘리트
```

두 유닛의 기본 생존·피해 예산은 비슷하게 시작한다.

차이는 다음처럼 만든다.

- 아군: 원거리 피해 감소와 아군 보호
- 적군: 밀쳐내기 저항과 건물 접근 압박

적군이 더 강해야 하는 스테이지라면 유닛 자체에 숨은 30% 보너스를 넣지 않는다. 대신 다음 중 하나를 공개한다.

- `강화 공세` 수정자
- 적 건물 Tier·교리
- 베일의 축복·저주
- 영웅·전설 지휘 오라
- 난이도 프로필 배율

동일 조건의 단독 결투 결과는 완전한 50:50을 강제하지 않지만, 별도 상성 없이 한쪽이 일방적으로 압도해서는 안 된다.

## 9. 건물 대칭 계약

아군과 적군 건물도 같은 기능 계열·Tier 문법을 공유한다.

| 공통 기능 | 아군 예시 | 적군 예시 |
|---|---|---|
| 근접 병력 생산 | 병영 | 베일 둥지·전투 소굴 |
| 원거리 병력 생산 | 궁병 훈련소 | 침사수 둥지 |
| 기동 병력 생산 | 기병 훈련소 | 야수 우리 |
| 방어 사격 | 포탑 | 베일 첨탑 |
| 경제·보급 | 시장·농장 | 군락 저장고·영양 기관 |
| 특수 지원 | 신전·아카데미 | 의식핵·변이실 |

공통 원칙:

- 같은 기능 계열·Tier 건물은 기본 HP·사거리·생산 주기 예산이 유사하다.
- 아군과 적군 건물의 기본 전투 예산은 원칙적으로 ±10% 안에서 시작한다.
- 건물 전문화는 Tier 2, 심화·교리는 Tier 3에서 적용한다.
- 적 건물은 플레이어처럼 UI로 자원을 지불하지 않지만 StageManifest의 생산 예산과 공세 시간표를 소비한다.
- 적 생산 건물 파괴는 대응 병종의 현재 또는 다음 공세 수량을 감소시킨다.
- 적 방어 건물의 사거리·대상·Tier·전문화는 공격 전에 공개한다.

적 본진이나 보스 시설이 특별히 강하면 일반 건물 데이터에 숨은 배율을 넣지 않고 `본진`, `보스 시설`, `강화 건물` 태그로 분리한다.

## 11. UI·징조 계약

베일의 징조 카드에는 다음을 표시한다.

- 병종 계열 아이콘
- Tier
- 일반·엘리트·영웅·전설·신화급 표식
- 지상·비행
- 핵심 역할 태그
- 보스·공성·돌파·지원 같은 특수 태그
- 공개된 주요 스킬과 약점

예시:

```text
중단 / 전사 / Tier 2 / 영웅
태그: 전열·범위·지휘
주요 능력: 5초마다 전방 베기 / 체력 50%에서 지원병 호출
약점: 원거리 집중 공격
```

등급 표식만 보고 정확한 능력치까지 알 수는 없지만, 같은 병종·Tier·등급의 아군 전력을 떠올려 대략적인 위협을 가늠할 수 있어야 한다.

## 12. 검증 계약

1. 5웨이브의 핵심 위협은 엘리트로 명확히 인식된다.
2. 10웨이브의 핵심 위협은 영웅이며 2스킬이 공세 패턴에 사용된다.
3. 15웨이브의 표준 승리 목표는 전설 보스다.
4. 20웨이브의 절멸급 최종보스는 적군 전용 신화급이다.
5. 신화급은 플레이어 룰렛 결과와 유닛 등급에 추가되지 않는다.
6. 같은 병종·Tier·등급의 아군·적군은 비슷한 기본 전투 예산을 사용한다.
7. 유닛·건물의 큰 성능 차이는 공개 태그·능력·수정자로 설명된다.
8. 적군은 플레이어와 같은 전투 데이터 구조를 사용하지만 룰렛과 플레이어 경제는 사용하지 않는다.
9. 동일 병종의 진영별 외형이 달라도 공통 계열 아이콘과 태그로 비교할 수 있다.
10. 적 생산 건물의 Tier·생산 병종·전문화가 공세 예측과 파괴 우선순위에 연결된다.
