## 1. 최종 비전

> **오멘워드는 픽셀의 명료한 실루엣과 일러스트의 동화적 깊이를 결합한다. 전장에서는 멀리서 읽히고, 보상·도감·벨루에서는 가까이서 아름답게 보인다.**

전체 인상은 `멋지고 따뜻한 동화풍 성전 판타지`다. 아군은 희망적이고 우아하며, Veil은 같은 동화책을 찢고 침식한 듯한 고딕 공포로 대비한다.

이 결정은 순수 픽셀 아트, 순수 수채화 일러스트, 반실사 3D를 선택하지 않는다. 픽셀풍 가독성과 일러스트풍 재질·빛·장식의 장점을 한 체계로 묶는다.

## 2. 표현 계층

### 전장 플레이 계층

- 2D 스프라이트·컷아웃을 중심으로 2.5D 깊이감을 표현한다.
- 외곽선과 큰 명암 덩어리는 픽셀풍처럼 명확하게 유지한다.
- 갑주·천·빛·마법 효과에는 일러스트풍 색 번짐과 섬세한 재질감을 제한적으로 사용한다.
- 고각도 3/4 시점과 먼 카메라에서도 병종·진영·진행 방향을 읽을 수 있어야 한다.
- 세부 장식보다 실루엣, 대표 무기, 자세, 이동 방식이 우선한다.

### 근접 정보 계층

보상 카드, 보관함, 도감, 영웅 소개, 벨루 대사는 일러스트 비중을 높인다.

- 얼굴·재질·문양·감정 표현을 전장 스프라이트보다 풍부하게 보여준다.
- 같은 병종이 전장과 카드에서 다른 캐릭터처럼 보이면 안 된다.
- 전장용과 카드용은 동일한 디자인 계보와 색·무기·실루엣을 공유한다.

## 3. 아군 병종 문법

### 공통 정체성

```text
주색 = 상아색·백색 갑주
보조색 = 청색·남청색 천
강조색 = 절제된 금색
마법광 = 청백색·금백색
```

- SD 비율과 작은 체구를 유지하되 장난감처럼 가볍게 보이지 않는다.
- 머리보다 방패·활·창·지팡이·날개·망토 같은 역할 표식을 크게 읽히게 한다.
- 둥근 동화적 형태와 날카로운 성전 장비를 함께 사용한다.
- 병종마다 하나 이상의 독점 실루엣 요소를 가진다.

### Tier 성장

```text
T1 = 가장 단순한 갑주와 대표 무기, 역할의 원형
T2 = 병종 분기를 명확히 보여주는 장비·자세·천 실루엣
T3 = 전문화의 전투 방식과 판타지를 극대화한 확장 실루엣
```

- Tier 상승은 단순 색 변경이나 몸집 확대가 아니다.
- 같은 계열임을 알아볼 수 있도록 얼굴·갑주 핵심 형태·대표 무기를 유지한다.
- T3는 전장 실루엣과 VFX가 가장 강하지만 룰렛 병종 토큰에는 사용하지 않는다.

### 등급 성장

```text
일반 = 기본 자세와 최소 장식
엘리트 = 장비 강화·문양·망토 또는 보조 장비
영웅 = 고유 머리장식·자세·빛의 궤적·개인 문장
전설 = 역할 판타지를 완성하는 대형 실루엣·후광·날개·고유 연출
```

등급 표현은 Tier 역할을 덮어서는 안 된다. 전설이라도 어떤 병종에서 성장했는지 즉시 알아볼 수 있어야 한다.

## 4. 룰렛·보상 자산 재사용

```text
금화 토큰 = 인게임 금화 이미지
병종 토큰 = 인게임 T1·T2 병종 이미지
T3 병종 이미지 = 룰렛 병종 토큰에 사용하지 않음
결과 보상 = 실제 지급 병종의 인게임 이미지
```

- 룰렛 전용 금화·병종 상징 아이콘 세트를 새로 제작하지 않는다.
- T1·T2 병종 이미지는 크롭·축소·여백 정리·프레임 적용만 허용한다.
- 결과 카드, 보관함, 배치 카드, 전장 병종은 동일한 자산 계보를 사용한다.
- 공백 X와 시스템 특수 표시는 기존 UI 표시를 사용하며 병종 자산처럼 보이지 않게 한다.

## 5. 영웅·전설 표현

- 영웅·전설도 기본 병종의 디자인 언어에서 출발한다.
- 고유 자세, 얼굴 노출, 개인 문장, 상징 장비, 전용 VFX로 이름 있는 존재임을 표현한다.
- 역할상 거대 병종이 아닌 경우 몸집만 키워 희소성을 표현하지 않는다.
- 화면을 가리는 지속형 후광·거대 이펙트는 금지한다.
- 보상·도감에서는 일러스트 비중을 높이고, 전장에서는 실루엣과 공격 예고가 우선한다.

## 6. Veil 병력·건물 문법

### 병력

```text
주색 = 흑색·목탄색
보조색 = 심자색·보라색
발광 = 적자색·진홍색
형태 = 가시·갈고리·찢어진 천·비대칭·유기체성
```

- 아군 모델을 검게 칠한 단순 색상 변형으로 만들지 않는다.
- 같은 역할이라도 아군의 정돈된 성전 형태와 반대되는 비대칭·침식 형태를 사용한다.
- 작은 적도 무기 방향과 공격 방식이 읽혀야 한다.

### 건물

- 고딕 첨탑, 갈비뼈형 아치, 가시 외피, 붉게 빛나는 내부를 공통 언어로 사용한다.
- 건물 종류는 중앙 실루엣과 입구·상단 장치로 구분한다.
- 적 본진에서 중앙으로 갈수록 지형의 색과 식생이 점진적으로 오염된다.

## 7. 아군 기본 건물 6종

| 건물 | 실루엣·표현 핵심 |
|---|---|
| 금고 | 낮고 단단한 석조·돔·인게임 금화 문양 |
| 농장 | 넓은 수평 형태·성스러운 정원·저장고·깃발 |
| 병영 | 방패형 정면·훈련장·병종 깃발 |
| 방어탑 | 높고 좁은 공격 실루엣·상단 무장 방향 |
| 지휘소 | 대형 군기·왕관형 지붕·전역 명령의 빛 신호 |
| 마력탑 | 수정·구체·초승달·수직 마석 흐름 |

- 색만으로 건물을 구분하지 않는다.
- 건물의 역할을 대표하는 상단 장치와 바닥 형태를 함께 사용한다.
- 지휘소는 주변 범위 건물처럼 원형 범위 VFX를 지속 표시하지 않는다. MapRun 전체 오라는 HUD·전역 신호로 표현한다.

## 8. 전장·노드·카메라

- 아군 본진부터 적 본진까지 상·중·하 세 전선 전체가 한 화면에 남는다.
- 룰렛 작업대를 열어도 전장 전체 구도를 유지한다.
- 전장은 회화적인 자연 지형 위에 픽셀풍으로 명확한 길·거점·노드를 얹는다.
- 아군 지역은 밝은 석재·푸른 지붕·수목·수로, 중앙은 중립 석재·초지, 적 지역은 Veil 균열·흑자색 식생으로 변한다.
- 전선 구분은 색뿐 아니라 높이·수로·절벽·식생·랜드마크로 보조한다.

노드 상태:

```text
빈 노드 = 밝은 원형 석판 + 중앙 건설 문양
설치 가능 = 금색 외곽선 + 약한 맥동
선택 = 예상 건물 실루엣 + 설치 범위
사용 중 = 건물 바닥 문양
설치 불가 = 잠금·금지 아이콘
점령권 상실 = 적 문양 + 오염된 외곽선
```

## 9. UI·룰렛 시각 문법

```text
기본 프레임 = 짙은 남청색·목탄색
테두리 = 얇고 절제된 고색 금속
정보 면 = 상아색·양피지색
상호작용 강조 = 청색·금색
위험 강조 = 적색 + 형태·아이콘·맥동
```

- UI는 일러스트풍 장식과 픽셀풍 정렬·명료성을 결합한다.
- 장식이 텍스트·토큰·전장을 가리면 실패다.
- 룰렛 작업대는 세로로 낮고 가로로 길게 유지한다.
- 좌측은 이동권·럭키·Tier·완성선 등급, 중앙은 큰 3×3 룰렛과 방향 화살표, 우측은 회전 비용·돌리기·결과·확정·벨루다.
- 결과 카드에는 실제 지급 병종 이미지와 이름·Tier·보상 등급·핵심 역할을 표시한다.

## 10. 벨루

- 벨루는 일러스트 우선 SD 캐릭터로 유지하며 억지로 저해상도 픽셀화하지 않는다.
- 우측 하단에서 상반신 또는 작은 전신 컷아웃으로 등장한다.
- 기본·기쁨·경고·걱정·생각·위험·축복 표정을 사용한다.
- 말풍선은 1~2문장이고 위험 전황이 장식 대사보다 우선한다.
- 벨루의 빛·날개·꽃 장식은 아군의 청백금 문법과 연결한다.

## 11. VFX·애니메이션 방향

- 핵심 타격·이동·스킬 예고는 픽셀풍으로 또렷한 시작점과 끝점을 가진다.
- 빛의 궤적·마법 연기·천의 잔상에는 일러스트풍 부드러움을 사용한다.
- 아군 VFX는 청백·금백, Veil VFX는 심자·적자색을 기본으로 한다.
- 장시간 화면을 덮는 안개·후광·입자 폭풍은 금지한다.
- 전선·노드·병종 실루엣을 가리는 연출은 품질이 높아도 실패다.

## 12. 자산 제작 우선순위

```text
1. T1·T2 핵심 병종 전장 이미지와 토큰 재사용 검증
2. 세 전선·노드·아군/적 본진 전장 타일·랜드마크
3. 기본 건물 6종과 Veil 대응 건물
4. T3 전문화·영웅·전설 전장 이미지
5. 결과·보관함·도감용 확대 이미지
6. 벨루 표정·대사 컷아웃
7. 전술스킬·타격·점령·위험 VFX
```

실제 제작 착수와 이미지 생성은 별도 사용자 지시 전까지 중단 상태를 유지한다.

## 13. 실패 조건

- 순수 픽셀로 축소되어 사용자가 승인한 동화적 재질과 멋이 사라짐.
- 순수 일러스트로 치우쳐 먼 카메라에서 병종·전선·노드를 읽지 못함.
- T1·T2 토큰을 위해 별도 병종 아이콘을 제작함.
- T3 병종을 룰렛 병종 토큰으로 사용함.
- Tier 상승을 색 변경·몸집 확대만으로 표현함.
- Veil을 아군 자산의 보라색 재도색으로 처리함.
- 건물 역할이 색이나 텍스트 없이는 구분되지 않음.
- UI 장식·VFX·벨루가 전장 정보를 가림.
- 룰렛·결과·보관함·전장에서 같은 병종의 외형이 달라짐.
- 생성된 비교 시안을 최종 인게임 자산으로 간주함.
