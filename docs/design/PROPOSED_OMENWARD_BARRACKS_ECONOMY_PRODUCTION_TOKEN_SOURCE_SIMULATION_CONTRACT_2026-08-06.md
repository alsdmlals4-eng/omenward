## 1. 목적

일반병 병영과 특수병 병영의 건설비·자동생산 간격·TokenSource 공급량·가중치를 함께 탐색해, 특수병의 기능적 우위가 선택 가치는 가지되 모든 상황의 필수 정답이 되지 않도록 한다.

```text
SIMULATION_RESULTS = NOT_RUN
THRESHOLDS = POC_HYPOTHESES_REQUIRING_USER_APPROVAL
ABSOLUTE_ECONOMY_VALUES = NOT_AVAILABLE
MISSING_REQUIRED_INPUT = BLOCK_SIMULATION
NO_BALANCE_APPROVAL_FROM_STATIC_MARKER_TESTS
PRODUCT_CODE = UNCHANGED
LOCAL_GODOT_PROJECT = UNCHANGED
```

정적 계약 테스트는 문서 구조와 금지 규칙만 검증한다. 실제 밸런스 판정은 입력 출처가 고정된 시뮬레이션 결과와 사용자 승인 뒤에만 가능하다.

## 2. 보존해야 할 현행 정본

```text
GENERAL_T1_AUTO_PRODUCTION = BASIC_INFANTRY
GENERAL_T1_TOKEN_SOURCE = BASIC_INFANTRY
GENERAL_T2_AUTO_PRODUCTION = SELECTED_GENERAL_UNIT
GENERAL_T2_TOKEN_SOURCE = SELECTED_GENERAL_UNIT

SPECIAL_T1_SELECTION_TRIGGER = SUCCESSFUL_CONSTRUCTION_COMMIT
SPECIAL_T1_SELECTED_UNIT_PERSISTENCE = FIXED_WHILE_BUILDING_REMAINS_T1
SPECIAL_T1_AUTO_PRODUCTION = SELECTED_RANDOM_SPECIAL_UNIT
SPECIAL_T1_TOKEN_SOURCE = SELECTED_RANDOM_SPECIAL_UNIT
SPECIAL_T1_AUTO_PRODUCTION_AND_TOKEN_SOURCE = SAME_SELECTED_UNIT_SEPARATE_ACQUISITION_PATHS
SPECIAL_T1_SAVE_RELOAD_RESELECT = FORBIDDEN
SPECIAL_T1_FREE_REROLL = FORBIDDEN
SPECIAL_T2_AUTO_PRODUCTION = SELECTED_SPECIAL_UNIT
SPECIAL_T2_TOKEN_SOURCE = SELECTED_SPECIAL_UNIT
```

자동생산과 TokenSource는 같은 병종 정체성을 공유하지만 서로 다른 획득 경로다. 시뮬레이션은 두 경로의 수치 기여를 분리해 측정하며, 결과를 이유로 병종 정체성을 분리하거나 무료 재추첨을 도입하지 않는다.

## 3. 필수 입력 사전조건

첫 실행 전 다음 입력은 출처·버전·단위를 가진 데이터로 제공되어야 한다.

```text
GENERAL_BARRACKS_COST_INDEX
SPECIAL_BARRACKS_COST_MULTIPLIER
GENERAL_PRODUCTION_INTERVAL_INDEX
SPECIAL_PRODUCTION_INTERVAL_MULTIPLIER
GENERAL_TOKEN_SOURCE_WEIGHT_INDEX

TOKEN_SOURCE_COUNT_PER_EVENT

UNIT_FUNCTIONAL_VALUE_INDEX
FOOD_SLOT_AND_NODE_OPPORTUNITY_COST
ENEMY_PRESSURE_TIMELINE

```

실제 골드 비용·초 단위 간격·룰렛 주기·압력 타임라인 중 하나라도 없으면 절대값 결과를 만들지 않는다. 이 계약의 지수는 탐색 공간을 정의하기 위한 무차원 PoC 가설이다.

```text
GENERAL_BARRACKS_COST_INDEX = 1.00
SPECIAL_BARRACKS_COST_MULTIPLIER = 1.25 / 1.50 / 1.75 / 2.00

GENERAL_PRODUCTION_INTERVAL_INDEX = 1.00
SPECIAL_PRODUCTION_INTERVAL_MULTIPLIER = 1.45 / 1.70 / 1.95 / 2.20

GENERAL_TOKEN_SOURCE_WEIGHT_INDEX = 1.00
SPECIAL_TOKEN_SOURCE_WEIGHT_MULTIPLIER = 0.35 / 0.50 / 0.65 / 0.80

GENERAL_UNIT_FUNCTIONAL_VALUE_INDEX = 1.00
```

`2_STRESS_ONLY`는 TokenSource 폭증 내성을 확인하기 위한 실패 유도 조건이며 권장 기본값이 아니다.

## 5. 시나리오 행렬

모든 조합을 동일한 시드 묶음으로 비교한다.

```text
BUILD_PLAN = GENERAL_ONLY / SPECIAL_ONLY / GENERAL_AND_SPECIAL / MULTI_SPECIAL
STAGE2_PATH = SHIELD_PATH / ARCHER_PATH
SPECIAL_ACCESS = NO_SPECIAL_PATH / ONE_SPECIAL / TWO_SPECIAL
SPECIAL_RESULT = FIXED_EACH_OF_FIVE_SPECIAL_RESULTS / RANDOM_WEIGHTED_RESULT
GOLD_SURPLUS = LOW / STANDARD / HIGH_SURPLUS
PRESSURE = MASS / ARMORED / FLYING / INFILTRATION / SIEGE
TOKEN_POOL = SMALL / STANDARD / DILUTED
SAVE_RECOVERY = FRESH_RUN / SAVE_RELOAD_SAME_RESULT
```

최소 경로인 `SHIELD_PATH + NO_SPECIAL_PATH`, `ARCHER_PATH + NO_SPECIAL_PATH`는 모든 표준 압력에서 별도 추적한다. 특수병 5종은 평균만 보지 않고 각 고정 결과별 하위 지표를 낸다.

## 6. KPI와 제안 통과선

| KPI | 방향 | PoC 제안선 | 판정 이유 |
|---|---:|---:|---|
| `SPECIAL_OPTION_DOMINANCE_RATE` | 낮을수록 좋음 | `<= 0.60` | 특수병이 대부분 조합의 단일 정답이 되는 것을 방지 |
| `GENERAL_PATH_VALIDITY_RATE` | 높을수록 좋음 | `>= 0.95` | 일반병 기초 투자와 무특수 최소 경로 보존 |
| `EACH_SPECIAL_OUTCOME_PATH_VALIDITY_RATE` | 높을수록 좋음 | `>= 0.85` | 5개 결과 중 죽은 결과 방지 |
| `WORST_SPECIAL_REGRET_RATE` | 낮을수록 좋음 | `<= 0.15` | 최악 결과가 중앙값 대비 과도한 손해가 되지 않게 함 |
| `SPECIAL_TOKEN_SHARE_10_MIN` | 낮을수록 좋음 | `<= 0.35` | 룰렛 풀 독점 방지 |
| `SPECIAL_TOKEN_SHARE_BURST_MAX` | 낮을수록 좋음 | `<= 0.45` | 짧은 구간 폭증 방지 |
| `MULTI_SPECIAL_DOMINANCE_RATE` | 낮을수록 좋음 | `<= 0.55` | 복수 특수병 스노우볼 방지 |
| `SECOND_SPECIAL_MARGINAL_VALUE_RATIO` | 낮을수록 좋음 | `<= 0.80` | 두 번째 특수병의 한계가치 체감 |
| `REROLL_EXPECTED_VALUE_GAIN` | 0 고정 | `= 0` | 저장·철거·취소 기반 재추첨 이득 금지 |

계약 marker:

```text
SPECIAL_OPTION_DOMINANCE_RATE <= 0.60
GENERAL_PATH_VALIDITY_RATE >= 0.95
EACH_SPECIAL_OUTCOME_PATH_VALIDITY_RATE >= 0.85
WORST_SPECIAL_REGRET_RATE <= 0.15
SPECIAL_TOKEN_SHARE_10_MIN <= 0.35
SPECIAL_TOKEN_SHARE_BURST_MAX <= 0.45
MULTI_SPECIAL_DOMINANCE_RATE <= 0.55
SECOND_SPECIAL_MARGINAL_VALUE_RATIO <= 0.80
REROLL_EXPECTED_VALUE_GAIN = 0
```

보조 진단 지표:

```text
FIRST_UNIT_ARRIVAL_TIME
FIRST_MEANINGFUL_POWER_SPIKE_TIME
UNIT_EQUIVALENT_VALUE_BY_MINUTE
CONSTRUCTION_PAYBACK_TIME
ROULETTE_HIT_RATE_BY_UNIT
UNSPENT_AND_RESERVED_GOLD
PRESSURE_CLEAR_MARGIN
BUILD_NODE_OPPORTUNITY_COST
```

PoC 목표 구간은 일반 병영 투자 회수 3~5분, 특수 병영 5~8분이다. 특수병의 우위는 유리한 압력에서 10분 기준 +5~20% 범위만 허용하며 모든 압력의 전역 우위를 허용하지 않는다.

## 7. 판정 규칙

```text
IF_SPECIAL_DOMINANCE_HIGH = INCREASE_SPECIAL_COST_OR_INTERVAL_BEFORE_CHANGING_IDENTITY
IF_TOKEN_MONOPOLY_HIGH = REDUCE_SPECIAL_TOKEN_WEIGHT_BEFORE_WEAKENING_AUTO_PRODUCTION
IF_LOW_ROLL_DEAD = ADJUST_UNIT_VALUE_OR_SELECTION_WEIGHT_WITHOUT_FREE_REROLL
IF_MULTI_SPECIAL_COMPOUNDING_HIGH = APPLY_COST_AND_MARGINAL_VALUE_PRESSURE
IF_GENERAL_PATH_INVALID = STOP_SHIP
IF_REROLL_EV_POSITIVE = STOP_SHIP
IF_INPUT_PROVENANCE_MISSING = INVALID_RESULT
```

비용·생산 간격·TokenSource 가중치는 독립적으로 한 개씩 최적화하지 않는다. 최소 2차 교호작용을 포함해 공동 탐색한다.
