## 2. 현행 용어와 자원 역할

현행 전술 자원 명칭은 **마력**이다. 마력은 현재 MapRun 전용이며 실제 전술스킬 시전에만 사용한다.

- 골드·룰렛 이동권·병력 한도를 대체하지 않는다.
- 연구 비용에는 마력을 사용하지 않는다.
- Stage 전환으로 초기화하지 않는다.
- 새 MapRun 시작 시 보유 마력을 초기화한다.
- 정확한 초당 수급량·보유 상한은 `PENDING_SIMULATION`이다.

```text
RESEARCH_USES_MANA = FORBIDDEN
STAGE_TRANSITION_RESET = FALSE
RESET_SCOPE = NEW_MAPRUN
```

## 3. 마력탑 단일 선형 성장

```text
마력탑 T1
→ 기본 초당 마력 수급
→ T1 전술 연구 가능

마력탑 T2
→ 초당 마력 수급 증가
→ T2 전술 연구 가능

마력탑 T3
→ 초당 마력 수급 추가 증가
→ T3 전술 연구 가능
```

운영 규칙:

- 한 MapRun에서 동시에 활성 가능한 마력탑은 하나다.
- 마력탑은 분기하지 않는다.
- 마력탑 미건설·파괴·비활성 상태에서는 마력 수급과 신규 연구가 중단된다.
- 파괴 뒤 재건할 수 있으며 완료 연구·해금 전술은 현재 MapRun 동안 유지된다.
- 연구 중 비활성화되면 진행 시간을 정지하고 진행도는 유지한다.
- 마력탑 업그레이드와 전술 연구는 동시에 진행하지 않는다.
- 재건으로 연구 비용·해금 상태·마력을 복제하거나 초기화하지 않는다.
