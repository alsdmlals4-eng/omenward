# 승인된 전투 중 건설, 건물 전문화, 전술 명령과 보스 대응 방향

- 상태: **핵심 구조 승인됨 / 세부 수치와 개별 효과 조정 대기**
- 승인일: 2026-07-14
- 관련 제안서:
  - `docs/design/proposals/0005-building-tiers-lifecycle-and-economy.md`
  - `docs/design/proposals/0006-tactical-commands.md`

이 문서는 `docs/GAME_DESIGN.md`의 건물 전문화·전술 명령·특수 적 관련 내용보다 우선한다. 특히 전술 명령의 전역 쿨다운과 일시정지 예약에 관한 이전 문구는 이 문서로 대체한다.

## 1. 적이 있어도 건설과 업그레이드는 계속된다

적 유닛이 건설 노드 주변에 있거나 구조물을 공격하고 있어도 건설·업그레이드 진행도를 멈추지 않는다.

```text
적 웨이브 접근
→ 포탑 건설 시작
→ 건설 중 구조물 피격
→ 파괴되기 전에 완공
→ 포탑 즉시 가동
→ 아슬아슬한 방어 성공 가능
```

계약:

- 적 존재는 새 건설·업그레이드 명령을 차단하지 않는다.
- 피격 중에도 진행도는 계속 증가한다.
- 건설 중 구조물은 공격받아 완공 전에 파괴될 수 있다.
- 건설 중에는 생산·수입·식량·룰렛 토큰·포탑 공격 기능이 없다.
- 완공되는 시뮬레이션 틱부터 정상 기능이 활성화된다.
- 완공 전에 체력 0이면 건설 실패, 환불 없음, 폐허 상태로 전환한다.
- 건설 중 체력 곡선과 충돌 범위는 별도 데이터로 조정한다.

## 2. 선택형 3티어 전문화

기존 완전 고정형 3티어는 다음 구조로 대체한다.

```text
Tier 1: 공통 기본 기능
→ Tier 2: 역할 또는 병종 전문화
→ Tier 3: 선택 방향 심화 또는 건물 전용 교리
```

원칙:

- Tier 2 선택은 해당 건물이 파괴·철거될 때까지 유지한다.
- 한 건물에서 서로 다른 Tier 2 방향을 동시에 섞지 않는다.
- 전문화 변경은 철거 후 재건설을 기본 방식으로 한다.
- 업그레이드 중에는 이전 Tier 기능과 기존 룰렛 토큰을 유지한다.
- 완료 순간 전문화 효과와 변경된 토큰을 적용한다.
- 선택 전에 비용·시간·기능·토큰·확률 변화를 표시한다.

## 3. 토큰 증폭

기본 토큰 제공 건물 1동은 세 릴 각각에 대응 토큰 1개를 제공한다.

토큰 증폭 전문화:

- 대응 토큰 1개를 세 릴 중 정확히 한 릴에만 추가한다.
- 추가 릴은 스테이지 시드와 건물 인스턴스로 결정론적으로 선택한다.
- 선택 릴은 건물 수명 동안 고정되고 UI에 공개된다.
- 매 회전마다 다시 추첨하지 않는다.
- 파괴·철거 시 다음 회전부터 제거한다.
- 업그레이드 선택 화면에서 릴별 확률 변화를 미리 보여준다.

## 4. 생산 유닛 강화

생산시설은 생산속도뿐 아니라 해당 시설에서 생산되는 유닛 자체를 강화할 수 있다.

- 전문화 완료 뒤 새로 생산되는 유닛에만 적용한다.
- 이미 생산된 유닛과 상점 용병에는 소급 적용하지 않는다.
- 유닛 데이터에 출처 건물과 강화 ID를 기록한다.
- 생산시설이 파괴돼도 이미 생산된 유닛의 강화는 유지한다.
- 공격력·체력·방어·이동속도 수치는 데이터로 조정한다.

## 5. 기본 병영의 병종 전문화

### Tier 1

- 검사 생산
- 세 릴에 검사 토큰 1개씩 제공

### Tier 2

다음 중 하나를 선택한다.

1. 기병 전문화
2. 창병 전문화
3. 궁병 전문화

업그레이드 완료 시:

- 이후 생산 병종이 선택 병종으로 바뀐다.
- 세 릴의 검사 토큰이 선택 병종 토큰으로 교체된다.
- 이미 생산된 검사와 출전 유닛은 변경되지 않는다.
- 생산 진행률은 보존하고 완료 뒤 처음 완성되는 유닛부터 새 병종을 적용한다.
- 진행 중인 룰렛은 유지하고 다음 회전부터 새 토큰을 적용한다.

### Tier 3 교리 후보

- 대량생산: 생산 간격 감소
- 정예훈련: 생산 유닛 강화 또는 일정 주기 엘리트 생산
- 토큰 증폭: 선택 병종 토큰을 결정된 릴 하나에 추가

정확한 수치는 후속 승인 대상이다.

## 6. 포탑 전문화

포탑 Tier 2 방향:

- 제압형: 작은 범위 또는 추가 대상 공격
- 요새형: 체력·방어·피격 저항 강화
- 장거리형: 사거리 증가

Tier 3은 선택 방향을 심화한다.

- 장거리형이 아닌 포탑은 접전지에 닿지 않는다.
- 장거리형 Tier 3도 접전지 전체와 적 진영 깊숙한 곳을 공격하지 않는다.
- 제압형은 밀집 대응용이며 시설 철거 수단이 아니다.
- 요새형은 시간을 벌지만 공격 병력을 대체하는 영구 봉쇄 수단이 아니다.
- 전문화별 외형·아이콘·범위 오버레이를 구분한다.

## 7. 금화 소모형 전술 명령

첫 프로토타입 후보:

1. 바리케이드
2. 화살비
3. 역병
4. 강화지대

공통 계약:

- 해금된 기본 명령은 HUD에 항상 표시한다.
- 상점 무작위 1회권 대신 사용할 때마다 금화를 직접 지불한다.
- 식량·건설 노드·룰렛 토큰을 사용하지 않는다.
- 적 본진·생산시설을 직접 파괴하는 주력 수단으로 만들지 않는다.
- 효과 범위·지속시간·예상 효과·비용을 실행 전에 표시한다.
- 시장 빌드가 금화를 전장 대응력으로 바꾸는 주요 소비처다.

### 전역 쿨다운 없음

- 전술 명령 전체를 잠그는 전역 쿨다운을 사용하지 않는다.
- 명령별 개별 쿨다운은 유지한다.
- 금화가 충분하고 각 명령이 준비됐다면 서로 다른 명령을 연속 사용할 수 있다.
- 사용 횟수 하드 제한과 반복 사용 가격 상승을 기본 규칙에 넣지 않는다.

### 일시정지 예약 없음

- `PendingCommand`와 예약 금액을 사용하지 않는다.
- 일시정지 중에는 설명과 범위 미리보기만 허용한다.
- 실행 확정·금화 차감·쿨다운 시작은 게임이 진행 중일 때만 발생한다.

## 8. 바리케이드 기본 역할

- 지정된 전술 지점에 설치한다.
- 아군은 통과하고 적은 차단된다.
- 라인당 동시에 하나만 활성화한다.
- 체력 0 또는 지속시간 종료 시 사라진다.
- 공격 기능이 없다.
- 포탑 완공과 증원 도착까지 시간을 버는 수단이다.
- 일반 적에게는 강한 지연 효과를 주지만 보스를 영구 봉쇄하지 않는다.

## 9. 보스의 바리케이드 대응과 축 방향 공격

바리케이드 악용을 전술 명령 전역 제한으로 막지 않고 보스·지휘관형 적의 전투 패턴으로 대응한다.

### 가로축 직선 돌파

- 라인 진행 방향으로 긴 직선 범위를 공격한다.
- 바리케이드와 임시 구조물에 높은 피해를 준다.
- 바리케이드 뒤의 전열도 함께 공격할 수 있다.
- 경로를 열고 보스가 다시 전진하게 한다.

### 세로축 크게 베기

- 현재 라인의 폭 방향으로 넓은 범위를 공격한다.
- 바리케이드 뒤에 밀집한 다수 유닛을 견제한다.
- 기본적으로 인접한 다른 라인까지 공격하지 않는다.

공통 계약:

- 두 패턴 모두 명확한 범위·동작·음향 전조를 사용한다.
- 전조가 시작되면 공격 범위를 유닛에게 계속 추적시키지 않는다.
- 직접 유닛을 세밀하게 조작하지 않는 게임이므로 예고 없는 즉사 패턴으로 만들지 않는다.
- 바리케이드는 패턴 준비 시간만큼 여전히 유의미한 시간을 번다.
- 보스가 바리케이드를 감지했다고 쿨다운을 무시하거나 즉시 파괴하지 않는다.

## 11. UI 계약

- 적이 있어도 남은 건설·업그레이드 시간 표시
- 건설 중 현재 체력과 완공 예상 시점 표시
- 전문화 선택지의 비용·기능·생산·토큰 변화 비교
- 토큰 증폭 대상 릴 표시
- 포탑 전문화별 범위·사거리·내구도 표시
- 전술 명령 비용·범위·효과·개별 쿨다운 표시
- 전역 쿨다운·예약 금액·예약 상태는 표시하지 않음
- 보스의 가로축·세로축 공격 범위를 서로 다른 형태로 표시
- 위협 카드에 `장애물 파괴`, `밀집 공격` 태그 표시

## 12. 검증 계약

- 피격 중 건설·업그레이드가 계속된다.
- 완공 전 파괴와 완공 후 기능 활성화 경계가 결정론적이다.
- 병영 전문화 완료 전후 생산 병종·토큰 전환 시점이 일치한다.
- 보너스 릴은 건물 수명 동안 고정된다.
- 금화가 충분하면 준비된 서로 다른 전술 명령을 연속 사용할 수 있다.
- 한 명령이 다른 명령을 전역 쿨다운으로 잠그지 않는다.
- 일시정지 중 명령 실행·예약·금화 차감이 발생하지 않는다.
- 바리케이드는 일반 적을 지연하지만 길 뚫기 보스를 영구 봉쇄하지 않는다.
- 직선 돌파와 크게 베기는 전조 뒤 고정된 범위에 적용된다.
- 같은 시드·StageManifest에서 전문화·명령 위력·보스 패턴 구성이 재현된다.

## 13. 아직 미확정인 세부

- 건설 중 시작 체력과 진행도별 체력 곡선
- 일반 건물의 충돌·길막 범위
- 농장과 시장의 정확한 전문화 목록
- 병영 Tier 3 교리 수치
- 포탑 전문화 수치
- 전술 명령별 비용·지속시간·개별 쿨다운
- 바리케이드 체력과 배치 지점
- 보스 직선 돌파·크게 베기의 피해·범위·시전시간·쿨다운
- 패턴을 가진 첫 보스와 등장 스테이지

이 문서는 핵심 방향을 승인하지만 세부 수치를 구현 승인으로 간주하지 않는다. Godot 구현은 별도의 Codex Plan Mode 제안서와 사용자 승인을 거쳐야 한다.
