# 승인된 유닛 등급·핵심 패시브·일반 스킬 성장 규칙

- 상태: **핵심 구조 승인됨 / 병종별 세부 능력과 수치 조정 대기**
- 승인일: 2026-07-14
- 연결 문서:
  - `docs/design/APPROVED_ROULETTE_CORE_RULES.md`
  - `docs/design/APPROVED_BARRACKS_TIER3_EVOLUTION_AND_GRADE_SKILLS.md`

이 문서는 룰렛 등급과 능력 성장 구조를 정의한다. 병영 Tier 3 세부 병종과 공유 토큰 규칙은 `APPROVED_BARRACKS_TIER3_EVOLUTION_AND_GRADE_SKILLS.md`가 우선한다.

## 1. 등급은 룰렛로만 결정한다

| 동일 심벌 완성 줄 | 생성 등급 |
|---:|---|
| 1줄 | 일반 |
| 2줄 | 엘리트 |
| 3~7줄 | 영웅 |
| 8줄·9칸 전체 동일 | 신화 |

- 수동 합성, 처치 경험치와 건물 Tier로 등급이 상승하지 않는다.
- 병영 자동 생산은 항상 일반 등급이다.
- 상점의 상위 등급 용병 직접 판매는 현재 승인 범위에서 제외한다.
- 신화는 한 스테이지 전체에서 병종과 관계없이 1회만 생성한다.
- 이미 신화를 생성한 뒤 다시 9칸 동일 결과가 나오면 해당 병종 영웅 2명으로 변환한다.

기존 `전설` 명칭은 `신화`로 교체한다.

## 2. 병영 Tier와 룰렛 등급은 독립 축이다

병영 Tier는 다음을 결정한다.

- 일반 등급의 실제 기본·상위 세부 병종
- 핵심 패시브 수
- 자동 생산 병종

룰렛 등급은 다음을 결정한다.

- 일반·엘리트·영웅·신화 고정 등급
- 일반 스킬의 생성과 강화 단계
- 고정 등급 유닛 템플릿

병영 Tier 3이라고 엘리트·영웅·신화 확률이 증가하지 않는다.

## 3. 핵심 패시브 수

핵심 패시브 수는 룰렛 등급이 아니라 선택된 훈련 출처 병영 Tier가 결정한다.

| 훈련 출처 | 핵심 패시브 수 |
|---|---:|
| Tier 2 병영 | 2개 |
| Tier 3 병영 | 3개 |

이 규칙은 일반·엘리트·영웅·신화 모두에 적용한다.

- Tier 3 일반 세부 병종의 세 번째 패시브는 세부 병종 정체성을 나타낸다.
- Tier 3 출처의 고정 엘리트·영웅·신화 유닛은 기본 병종 계열별 고정 세 번째 패시브를 가진다.
- 건물이 파괴돼도 이미 생성된 유닛의 패시브는 유지한다.

## 4. 등급별 일반 스킬 성장

핵심 패시브와 별도로 일반 스킬은 등급에 따라 성장한다.

### 일반

- 1스킬 기본형

### 엘리트

- 병종별 고정 엘리트 유닛 템플릿
- 고정 능력치·외형·AI 프로필 적용
- 기본적으로 신규 스킬 슬롯 없음
- 1스킬의 기능 구조는 일반과 동일

### 영웅

- 1스킬 강화
- 2스킬 생성

### 신화

- 영웅 단계의 모든 효과 유지
- 2스킬 강화
- 3스킬 생성

```text
일반: 1스킬
엘리트: 1스킬 + 엘리트 고정 능력치 프로필
영웅: 강화된 1스킬 + 신규 2스킬
신화: 강화된 1스킬 + 강화된 2스킬 + 신규 3스킬
```

## 5. 고정 상위 등급 유닛

엘리트·영웅·신화 유닛은 기본 병종 계열별 고정 템플릿이다.

- 기병 계열의 엘리트·영웅·신화 유닛은 중기병·충격기병 선택으로 정체성이 바뀌지 않는다.
- 궁병 계열의 엘리트·영웅·신화 유닛은 석궁병·대공궁병·연사궁병 선택으로 정체성이 바뀌지 않는다.
- Tier 3 세부 병종 선택은 일반 등급 유닛 후보와 자동 생산에 적용한다.
- 상위 등급 고정 유닛은 선택된 훈련 출처 Tier에 따라 패시브 2개 또는 3개를 받는다.

## 6. 일반 등급 세부 병종

일반 등급은 병영 출처 후보 풀에서 실제 병종을 확률로 선택한다.

예시:

- Tier 2 기병 출처 → 일반 기병
- Tier 3 중기병 출처 → 일반 중기병
- Tier 3 충격기병 출처 → 일반 충격기병

Tier 3 후보는 Tier 2 후보보다 높은 가중치를 가진다.

## 7. 초기 병종 능력 예시

### 방패병

- 핵심 패시브 후보: 원거리 공격 피해 50% 감소
- 1스킬 후보: 방패 밀치기

### 창병

- 핵심 패시브 후보: `[기병]` 추가 피해 +50%, 일반 `[돌진]` 저지
- 1스킬: 쓰러스트

### 기병

- 핵심 패시브 후보: 이동력 증가
- 1스킬: 돌진

### 궁병

- 핵심 패시브 후보: 원거리 사격
- 1스킬: 성공한 기본 공격 3회 뒤 다음 공격 확정 치명타

### 암살자

- 핵심 패시브 후보: 후방 공격 시 치명타 확률 +50%p
- 1스킬 후보: 그림자 이동

정확한 각 병종의 패시브 1·2·3과 스킬 1·2·3은 별도 병종 능력표에서 확정한다.

## 9. UI 계약

룰렛 결과 화면:

- 기본 병종 계열
- 실제 생성 유닛
- 생성 등급
- 선택된 훈련 출처 Tier
- 핵심 패시브 수와 목록
- 새로 생성되거나 강화된 스킬

유닛 정보창:

1. 기본 병종 계열·실제 세부 병종·등급
2. 훈련 출처 Tier
3. 병종 태그·상성·이동 레이어
4. 핵심 패시브 2개 또는 3개
5. 1·2·3스킬과 강화 상태
6. 내부 쿨타임·발동 조건·대상 레이어

## 10. 검증 계약

- 1/2/3~7/8줄은 일반/엘리트/영웅/신화로 정확히 매핑된다.
- 병영 Tier가 등급 결과를 바꾸지 않는다.
- Tier 2 출처는 패시브 2개, Tier 3 출처는 패시브 3개를 부여한다.
- 엘리트·영웅·신화 유닛의 정체성은 Tier 3 세부 병종 선택과 무관하게 고정된다.
- 영웅은 1스킬 강화와 2스킬 생성을 모두 받는다.
- 신화는 영웅 효과를 유지하고 2스킬 강화와 3스킬 생성을 받는다.
- 자동 생산은 항상 일반 등급이다.
- 이미 생성된 유닛은 출처 병영이 파괴돼도 병종·등급·패시브·스킬을 유지한다.

## 11. 미확정 세부

- 엘리트 고정 능력치 배율
- 계열별 엘리트·영웅·신화 고정 유닛
- 병종별 패시브 1·2·3
- 병종별 스킬 1·2·3과 강화 효과
- Tier 3 출처 상위 등급 유닛의 세 번째 패시브
- Tier 2:T3 세부 병종 추첨 가중치

이 문서는 핵심 구조를 승인하지만 개별 수치를 구현 승인으로 간주하지 않는다. Godot 구현은 별도의 Codex Plan Mode 제안서와 사용자 승인을 거쳐야 한다.
