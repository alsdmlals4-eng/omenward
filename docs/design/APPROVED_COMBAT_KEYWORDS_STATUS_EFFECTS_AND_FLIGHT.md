- 상태: **핵심 구조 승인됨 / 개별 병종 수치와 비행 카운터 밸런스 조정 대기**

- 원본 제안서:
  - `docs/design/proposals/0008-combat-keywords-status-effects-and-interrupts.md`
- 연결 문서:
  - `docs/design/APPROVED_UNIT_GRADE_AND_ABILITY_GROWTH.md`

이 문서는 병종별 패시브와 스킬이 공통으로 사용하는 태그, 치명타, 후방, 돌진, 중단, 군중 제어, 상태이상과 비행 이동·타기팅 레이어를 정의한다. 이 문서가 이전의 미확정 전투 키워드 문구보다 우선한다.

## 1. 전투 능력 표기

모든 유닛·공격·스킬·상태이상은 다음 정보를 분리해 가진다.

1. 대상 태그: 병종·등급·크기·구조물 종류
2. 이동 레이어: 지상 또는 비행
3. 행동 태그: 공격·이동·범위 형태
4. 효과 태그: 피해·제어·상태이상
5. 유효 대상 레이어: 지상, 비행 또는 양쪽

능력 설명에 없는 숨은 예외를 만들지 않는다. 보스 면역, 구조물 제외, 비행 미적용과 중첩 불가는 데이터와 UI에 표시한다.

## 2. 핵심 대상 태그

병종·역할 태그:

- `[보병]`
- `[방패병]`
- `[창병]`
- `[기병]`
- `[원거리병]`
- `[지원병]`
- `[마법사]`
- `[암살자]`
- `[공성병]`

등급·크기 태그:

- `[일반]`
- `[엘리트]`
- `[영웅]`
- `[전설]`
- `[소형]`
- `[대형]`
- `[지휘관]`
- `[보스]`

구조물 태그:

- `[건물]`
- `[포탑]`
- `[생산시설]`
- `[경제시설]`
- `[본진]`
- `[임시구조물]`
- `[바리케이드]`

한 유닛은 여러 병종 태그를 가질 수 있다. 예를 들어 기마궁수는 `[기병] [원거리병]`이므로 창병의 기병 추가 피해를 받는다.

## 3. 지상과 비행 이동 레이어

모든 유닛은 기본적으로 다음 중 하나의 이동 레이어를 가진다.

- `[지상]`
- `[비행]`

둘은 기본적으로 상호 배타적이다. `지상화`, `이륙`, `착륙`처럼 상태가 명시적으로 바뀔 때만 레이어를 전환한다.

`[비행]`은 병종 역할 태그가 아니라 이동·충돌·타기팅 레이어다.

예시:

```text
비행 궁수: [비행] [원거리병]
비행 근접 괴수: [비행] [대형]
기마궁수: [지상] [기병] [원거리병]
```

비행이라고 자동으로 원거리 공격을 하는 것은 아니며, 원거리병이라고 자동으로 비행인 것도 아니다.

## 4. 비행 이동과 충돌

비행 유닛은:

- 지상 유닛의 충돌과 대형을 넘어 이동한다.
- 바리케이드에 이동이 막히지 않는다.
- 지상에 설치된 함정과 지면 위험 구역을 기본적으로 무시한다.
- 지상 유닛과 같은 전장 좌표에 존재할 수 있으며 공중 점유를 별도로 사용한다.
- 건물과 포탑의 지상 충돌 범위를 넘어갈 수 있다.

그러나 비행 유닛도:

- 지정된 상·중·하 라인을 벗어나지 않는다.
- 전장 경계와 출격 경계를 넘지 않는다.
- `공중 차단` 태그가 있는 지형·결계·구조물을 통과하지 못한다.
- 순간이동하지 않고 자신의 이동속도로 경로를 이동한다.
- 목표와 공격 우선순위 규칙을 무시하지 않는다.

따라서 비행은 바리케이드와 전열을 우회하는 장점이 있지만, 라인을 무시해 본진으로 즉시 이동하는 기능은 아니다.

## 5. 비행 유닛의 점령

비행 상태의 유닛은 기본적으로 중앙 접전지 점령 수에 포함되지 않는다.

이유:

- 지상 전열의 전략적 가치를 유지한다.
- 소수의 빠른 비행 유닛이 전투를 무시하고 접전지를 계속 탈취하는 것을 방지한다.

예외:

- `[점령 가능 비행]`
- 착륙 스킬로 `[지상]` 상태가 된 유닛

비행 유닛은 점령에 기여하지 않더라도 접전지 안의 적을 공격하고 아군을 지원할 수 있다.

## 6. 유효 대상 레이어

모든 공격과 스킬은 다음 중 하나를 명시한다.

```text
target_layers = ground
target_layers = air
target_layers = ground_and_air
```

초기 기본값:

- 지상 근접 기본 공격: 지상 전용
- 활·투척·직접 투사체 원거리 공격: 지상·비행
- 직접 대상 마법 광선·마법 투사체: 지상·비행
- 지면 장판·지상 폭발·발밑 함정: 지상 전용
- 바리케이드: 지상 유닛만 차단
- 비행 유닛의 공격: 능력별 유효 대상 레이어를 따름

`[원거리]` 태그만으로 대공 가능 여부를 추론하지 않는다. 실제 데이터의 `target_layers`를 사용한다.

## 7. 대공 태그

비행 유닛을 전문적으로 상대하는 공격은 `[대공]` 태그를 가진다.

대공 공격은 다음 효과 중 일부를 가질 수 있다.

- 비행 대상 추가 피해
- 비행 대상 우선 타기팅
- 비행 대상 사거리 증가
- `지상화` 또는 이동속도 감소
- 급강하·비행 돌진 저지

대공 태그가 없더라도 `target_layers = ground_and_air`인 공격은 비행 유닛을 공격할 수 있다. `[대공]`은 타격 가능 여부가 아니라 **비행 카운터에 특화된 능력**임을 뜻한다.

궁병과 일부 기본 포탑은 비행 유닛을 공격할 수 있지만, 대공 전문 병종·포탑보다 효율이 낮게 조정할 수 있다.

## 8. 범위 공격과 비행

범위 공격은 범위 형태와 함께 적용 레이어를 가진다.

- 지상 원·부채꼴·직선: 기본적으로 지상 전용
- 공중 폭발·구형 범위: 비행 또는 양쪽
- 투사체가 직접 폭발하는 범위: 능력 데이터에 따라 양쪽 가능
- 지면에 남는 지속 구역: 지상 전용

전술 명령 초기 방향:

- 바리케이드: 지상 전용
- 화살비: 지상 전용 추천
- 역병: 지상·비행 적용 가능 추천
- 강화지대: 범위 안의 지상·비행 아군에게 적용 추천

전술 명령의 정확한 레이어는 각 명령 데이터와 UI에 표시한다.

## 9. 비행과 돌진

기병의 지상 돌진과 비행 유닛의 급강하는 별도 행동 태그다.

- `[돌진]`: 지상 경로를 따라 수행하는 일반 돌진
- `[급강하]`: 비행 레이어에서 목표로 빠르게 접근하는 비행 돌진

창병의 기본 `대기병 전투`는 `[기병] [돌진]`을 저지한다.

- 비행 유닛이라는 이유만으로 창병에게 저지되지 않는다.
- `[기병] [비행]` 유닛이 지상 돌진을 사용한다면 일반 대기병 판정을 받을 수 있다.
- `[급강하]`는 `대공 저지` 능력이 있어야 취소하거나 약화할 수 있다.

따라서 일반 창병 한 종류가 지상 기병과 모든 비행 돌격을 동시에 완벽하게 막지 않는다.

## 10. 지상화와 착륙

`[지상화]`는 비행 유닛의 비행 레이어를 일정 시간 비활성화하는 특수 제어다.

지상화된 유닛은:

- `[지상]` 이동과 충돌 규칙을 사용한다.
- 바리케이드와 지상 유닛에 막힌다.
- 지상 전용 공격과 지면 상태이상의 대상이 된다.
- 비행 전용 이동·급강하 스킬을 사용할 수 없다.

지상화 자체는 기본적으로 추락 피해를 주지 않는다. 피해가 필요한 능력은 별도의 `추락 피해`를 명시한다.

보스·전설 비행 유닛은 지상화 지속시간 감소 또는 완전 지상화 대신 다음 약화만 받을 수 있다.

- 이동속도 감소
- 비행 고도 하락 상태
- 대공 피해 증가
- 급강하 취소

정확한 보스 저항 수치는 별도 조정한다.

## 11. 비행과 군중 제어

비행 유닛에게 적용되는 기본 규칙:

- 경직·기절: 공격이 비행을 유효 대상으로 하면 정상 적용
- 둔화: 공중 이동속도 감소
- 속박: 공중에서 이동 불가, 공격 가능
- 밀쳐내기: 공중 대상 가능 태그가 있는 효과만 적용
- 넘어짐: 비행 중 면역
- 지상 함정의 속박·넘어짐: 적용하지 않음
- 지상화: 별도 특수 제어로 적용

비행 유닛이 지상화되면 일반 지상 군중 제어 규칙을 사용한다.

## 12. 비행 타기팅과 전열 우회

비행 유닛은 지상 전열 충돌에 막히지 않으므로 후열·시설을 노리는 AI를 가질 수 있다.

그러나 모든 비행 유닛이 자동으로 본진을 우선 공격하지 않는다. 유닛 역할에 따라 타기팅 규칙을 명시한다.

예시:

- 비행 전투병: 가까운 공격 가능 유닛
- 비행 암살자: 원거리병·지원병·마법사
- 비행 공성병: 포탑·생산시설
- 비행 지휘관: 정해진 패턴 목표

웨이브 전조에는 다음을 표시한다.

- 비행 아이콘과 수량
- 공격 가능 레이어가 부족한 라인 경고
- 예상 우선 목표
- 대공 또는 지상화 대응 수단

## 13. 피해·치명타·후방 공통 규칙

초기 승인값:

- 기본 치명타 확률: 5%
- 기본 치명타 피해: 150%
- 후방 판정: 대상 정반대를 중심으로 총 120도
- 치명타 확률 상한: 100%

피해 계산 순서:

```text
기본 피해
→ 공격자 피해 증가·감소
→ 병종 상성·대상 태그 배율
→ 치명타
→ 방어력 또는 마법 저항
→ 공격 형태별 피해 경감
→ 전체 받는 피해 감소
→ 보호막
→ 체력
```

후방 판정은 지상·비행 레이어와 별개다. 공격자가 해당 대상을 실제로 타격할 수 있다면 적중 순간의 방향으로 후방 여부를 계산한다.

구조물에는 후방·기본 치명타·출혈을 적용하지 않는다.

## 14. 돌진과 창병 저지

일반 지상 기병 돌진:

- 시작 시 경로 고정
- 소형 지상 유닛 통과 또는 밀쳐내기 가능
- 대형 지상 유닛·건물·바리케이드에 충돌
- 창병 전방 저지 범위에 들어오면 충돌 피해 전 취소
- 창병별 저지 내부 쿨타임 5초

보스 지상 돌진 저지 초기값:

- 남은 거리 35% 감소
- 최종 돌진 피해 30% 감소
- 종료 뒤 짧은 경직

이 규칙은 `[급강하]`에 자동 적용되지 않는다.

## 15. 군중 제어와 중단

| 효과 | 기본 기능 |
|---|---|
| 경직 | 매우 짧은 행동 불가와 행동 중단 |
| 기절 | 지속시간 동안 이동·공격·스킬 불가 |
| 밀쳐내기 | 지정 방향 강제 이동 |
| 넘어짐 | 긴 행동 불가와 회복 동작 |
| 둔화 | 이동속도 감소, 행동 가능 |
| 속박 | 이동 불가, 공격·스킬 가능 |
| 지상화 | 비행 레이어를 일시적으로 지상으로 변경 |

초기 승인값:

- 둔화 상한: 60%
- 스킬 쿨다운 감소 상한: 40%
- 준비 중 중단된 스킬: 기본 쿨다운의 30% 적용

등급별 초기 제어 저항:

| 대상 | 경직·기절 지속시간 | 밀쳐내기·넘어짐 |
|---|---:|---|
| 일반 | 100% | 정상 적용 |
| 엘리트 | 70% | 거리 50% |
| 영웅·지휘관 | 50% | 거리 25% 또는 넘어짐 면역 |
| 전설 | 40% | 밀쳐내기·넘어짐 면역 |
| 보스 | 25% | 밀쳐내기·넘어짐 면역 |

## 16. 상태이상 중첩

출혈:

- 물리 지속 피해
- 같은 공격자의 출혈은 지속시간 갱신
- 서로 다른 공격자의 출혈은 최대 3개
- 구조물 제외

독:

- 초기 최대 5스택
- 스택 증가 시 전체 지속시간 갱신
- 보스는 스택 또는 피해 계수 감소 가능

화상:

- 중첩하지 않음
- 더 강한 화상 유지
- 더 긴 지속시간 유지

역병:

- 피해 중첩 없음
- 재적용 시 지속시간 갱신
- 치유 감소는 가장 강한 하나만 적용
- 지상·비행 적용 가능

## 17. 내부 쿨타임과 동시 판정

- 내부 쿨타임은 시뮬레이션 시간 기준
- 일시정지 중 진행되지 않음
- 공격속도는 내부 쿨타임을 감소시키지 않음
- 별도 스킬 쿨다운 감소만 적용

같은 틱 처리 순서:

```text
1. 시간 만료·쿨다운 갱신
2. 조건형 패시브·반응형 저지 수집
3. 중단·취소 적용
4. 유효 대상 레이어 확인과 적중 판정
5. 피해·치유·보호막 적용
6. 상태이상·지상화 적용
7. 강제 이동
8. 사망 판정
9. 점유 정리와 재타기팅
```

## 19. UI 계약

유닛 정보창:

- 공격 가능한 대상 레이어
- 대공 특화 여부
- 점령 가능 여부
- 지상화 저항
- 상태이상·군중 제어 예외

전투 중:

- 비행 유닛의 공중 그림자 또는 고도 표시
- 선택 시 비행 경로와 우선 목표
- 비행 웨이브 전조 아이콘
- 해당 라인의 대공 가능 유닛·포탑 부족 경고
- 지상 전용 공격이 비행 대상에게 사용할 수 없다는 표시
- 지상화 남은 시간과 착륙 상태 표시

## 20. 검증 계약

1. 비행 유닛은 지상 유닛과 바리케이드를 넘어 이동한다.
2. 비행 유닛도 현재 라인과 전장 경계를 벗어나지 않는다.
3. 지상 근접 공격은 비행 유닛을 목표로 선택하지 않는다.
4. 지상·비행 대상 원거리 공격은 비행 유닛을 정상 공격한다.
5. 지상 장판·함정·화살비는 비행 유닛에게 적용되지 않는다.
6. 역병처럼 양쪽 레이어를 지정한 효과는 비행 유닛에게 적용된다.
7. 비행 유닛은 기본적으로 접전지 점령에 기여하지 않는다.
8. 지상화된 비행 유닛은 지상 충돌·바리케이드·지상 공격의 대상이 된다.
9. 비행 중 넘어짐은 적용되지 않는다.
10. 일반 창병의 대기병 저지는 급강하를 자동으로 취소하지 않는다.
11. 대공 저지가 있으면 급강하를 취소하거나 약화할 수 있다.
12. 같은 좌표의 지상·비행 유닛은 별도 점유 레이어에서 공존한다.
13. 비행 유닛이 후열 우선 AI를 가져도 지정된 타기팅 규칙을 따른다.
14. 웨이브 전조와 실제 비행 수량·우선 목표가 일치한다.

## 21. 아직 미확정인 세부

- 첫 비행 아군·적 병종과 등장 스테이지
- 기본 궁병과 기본 포탑의 비행 대상 피해 보정
- 대공 전문 병종·포탑의 추가 피해량
- 공중 점유 간격과 최대 밀집 수
- 비행 유닛의 건물 통과 시 시각적 고도
- 지상화 기본 지속시간과 보스 저항
- 화살비·역병·강화지대의 최종 적용 레이어
- 비행 유닛의 식량·가격·Threat Budget 보정
- 점령 가능 비행 병종 포함 여부
- 비행 보스의 패턴과 대공 대응 수단

이 문서는 전투 키워드와 비행 레이어의 핵심 구조를 승인하지만 개별 병종·능력 수치를 구현 승인으로 간주하지 않는다. Godot 구현은 별도의 Codex Plan Mode 제안서와 사용자 승인을 거쳐야 한다.
