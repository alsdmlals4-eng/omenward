## 1. 한 문장 정의

> `율비`는 경계의 징조와 전장의 이상 반응을 감지하며, 최전선 지휘관에게 세계관·적 정보·전술 선택지를 짧게 전달하는 작은 감시 정령이다.

율비는 단순 장식이 아니다. 다음 역할을 담당한다.

1. 10~30초 학습을 돕는 짧은 튜토리얼 안내
2. 웨이브의 라인·병종·수량·도착 시간 보고
3. 보스·본진·자원 위험 경보
4. 룰렛·토큰·건물 시스템의 세계관식 번역
5. 경계의 율·축복·저주·과거 사건에 관한 암시
6. 룰렛 당첨·등급 공개·전선 역전의 보상 감정 증폭
7. 무거운 최전선 세계관과 플레이어 사이의 친근한 연결점

## 2. 단일 안내자 계약

프로토타입에서는 정찰관·부관을 별도 기능성 안내 NPC로 사용하지 않는다.

- 정찰관 초상·음성·보고창 없음
- 부관 조언 패널·음성 없음
- 필수 안내와 세계관 설명은 `율비 + HUD`로 통일
- 병사·장교는 배경 또는 캠페인 사건 인물로 등장할 수 있으나 시스템 설명을 분담하지 않음
- 율비가 플레이어의 결정을 대신하지는 않음

율비에게 역할이 집중되는 만큼 대사는 짧게 유지한다.

```text
율비: 핵심 감지·보고·안내·암시
HUD: 정확한 수치·지속시간·상태·선택 결과
플레이어: 최종 판단과 명령
```

## 3. 세계관 위치

### 확정 방향

- 율비는 `경계의 율`을 완전히 이해하지 못한다.
- 징조의 강도·방향·불길함을 감지하고 전술판 정보를 읽어 라인·병종·수량·시간을 보고한다.
- 미래를 예언하는 존재가 아니라 감지된 징조와 기록을 해석하는 존재다.
- 플레이어를 `지휘관`으로 부른다.
- 세계관의 비밀을 확정적으로 해설하는 만능 화자가 아니다.

### 권장 기원

요새의 오래된 경계종에 남은 울림이 작은 정령으로 분리되어 태어났다는 방향을 사용한다.

```text
경계종의 오래된 울림
→ 반복되는 공세와 징조에 반응
→ 작은 자아 형성
→ 전술판과 경계의 변화를 읽음
→ 지휘관 곁에서 위험 신호와 기록 전달
```

이 기원은 다음 장점이 있다.

- 이름·요정형 실루엣·경계종·웨이브 전조를 연결
- 경계의 율의 정체를 직접 설명하지 않음
- 요새가 바뀌어도 `경계종의 파편`, `휴대 종`, `전술판의 울림`으로 동행 가능
- 군사 보고 능력을 별도 정찰관 없이 자연스럽게 설명

정확한 탄생 사건과 지휘관과의 첫 만남은 캠페인 서사에서 확정한다.

## 4. 성격과 발화 모드

### 핵심 성격

- 영리하고 반응이 빠르다.
- 호기심이 많지만 위험을 가볍게 여기지 않는다.
- 플레이어의 실수를 비난하지 않는다.
- 정답을 대신 선택하기보다 위험과 선택지를 짧게 알려준다.
- 평소에는 명랑하지만 본진·민간 후방이 위험할 때는 즉시 진지해진다.

### 감정 비율

```text
친근함 40
기민함 25
신비로움 20
전장의 진지함 15
```

개그 전용 캐릭터로 사용하지 않는다. 농담은 전투가 끝났거나 긴장이 낮은 순간에만 제한적으로 사용한다.

### 발화 모드

| 모드 | 기능 | 예시 |
|---|---|---|
| 감지 | 새 징조·축복·저주 발견 | `지휘관, 상단 경계가 울려요.` |
| 보고 | 병종·수량·시간 전달 | `전사형 넷. 도달까지 30초예요.` |
| 안내 | 최초 시스템 조작 | `병영을 지으면 전사 증원이 늘어요.` |
| 조언 | 대응 선택지 요약 | `포탑이나 바리케이드로 시간을 벌 수 있어요.` |
| 암시 | 경계의 율과 과거 표현 | `징조는 틀리지 않아요. 선택이 달라질 뿐이에요.` |
| 반응 | 보상·역전·패배 감정 | `좋아요! 지휘관의 선택이 통했어요.` |

한 이벤트에서 감지·보고를 두 문장 이내로 합치고, 이어서 장황한 조언을 덧붙이지 않는다.

## 5. 최종 외형 계약

최신 요정형 시안을 최종 기준으로 사용한다.

### 핵심 실루엣

- 작고 둥근 요정형 비인간 캐릭터
- 큰 타원형 눈과 작은 입
- 부드럽게 아래로 늘어진 긴 귀·날개형 장식
- 반투명 요정 날개
- 밝은 청백색과 옅은 금색 파스텔 팔레트
- 몸 중앙의 단일 경계 문양
- 머리 위의 빛 고리·신호 기관
- 몸 아래 작은 경계종·방울
- 꽃·빛가루·이슬 같은 자연 정령 요소

고유 식별 요소:

```text
긴 귀형 요정 실루엣
+ 반투명 날개
+ 중앙 경계 문양
+ 빛 신호 기관
+ 아래 경계종
+ 전장 상태 반응
```

HUD 48~64px에서도 큰 눈, 긴 귀형 실루엣, 신호 기관과 중앙 문양이 구분되어야 한다.

### 독창성 경계

부드러운 파스텔 색감, 둥근 얼굴과 친근한 긴 귀형 실루엣은 참고할 수 있다. 그러나 특정 기존 캐릭터의 얼굴 비율, 귀 끝 모양, 의상·소품·색 배치와 대표 포즈를 그대로 복제하지 않는다.

## 6. 기본형과 일시 상태 반응

율비는 대부분의 시간에 하나의 청백색 기본형을 유지한다.

```text
기본형
→ 상태 감지
→ 짧은 색·문양·표정·사운드 반응
→ 정보 전달
→ 잔광
→ 기본형 복귀
```

- 위험·보스·축복·저주·룰렛 등급은 영구 변신이 아님
- 상태별 반응은 경고등처럼 약 0.5~2초만 표시
- 반응 뒤 0.2~0.4초 동안 기본색으로 복귀
- 지속 상태는 별도 HUD 아이콘·타이머·웨이브 카드가 담당
- 같은 경고 반복 시 전체 반응 대신 짧은 문양 점멸만 사용

우선순위:

```text
본진 치명 위험
> 보스·결전
> 웨이브 임박
> 필수 튜토리얼
> 축복·저주
> 룰렛 등급 반응
> 일반 감정 반응
```

## 8. 애니메이션 계약

### 기본 루프

- `idle_float`: 느린 상하 부유, 2.5~3.5초 주기
- `idle_blink`: 불규칙 눈 깜빡임
- `mark_breathe`: 중앙 문양 미세 발광
- 긴 귀형 장식과 날개는 몸보다 한 박자 늦게 부드럽게 움직임

### 반응

| 상황 | 애니메이션 |
|---|---|
| 튜토리얼 지시 | 대상 쪽으로 기울고 작은 빛 손으로 가리킴 |
| 웨이브 전조 | 신호 기관이 방향을 향하고 문양 주황 점등 |
| 본진 위험 | 부유 정지, 붉은 문양 점멸, 귀·날개 수축 |
| 보스 | 자주빛 파동과 진지한 표정 |
| 일반 당첨 | 한 번 위로 튀며 작은 빛 고리 |
| 엘리트 | 두 번 튀고 별빛 2회 |
| 영웅 | 한 바퀴 회전과 큰 빛 고리 |
| 전설 | 짧은 정적 → 문양 폭발 → 날개 개방 → 환호 |
| 일시정지 | 푸른 원형 파동과 생각 표정 |
| 실패·꽝 | 귀형 장식과 날개가 잠깐 처짐 |
| 방어 성공 | 전장을 보고 안도한 뒤 짧게 환호 |

전설 반응도 1.2~1.8초 이내로 제한한다.

## 9. UI 배치 계약

### 기본 위치

- 화면 오른쪽 가장자리 하단 1/3의 `율비 도크`
- 초상 기본 크기 48~64px
- 말풍선이 없을 때는 초상과 중앙 문양만 표시
- 최종 HUD에 따라 좌우 반전 가능

다음 영역을 가리지 않는다.

- 세 라인 전장
- 룰렛 핵심 결과
- 건설 노드
- 웨이브 타이머
- 전술 명령 버튼
- 본진 체력

### 말풍선

- 한 번에 최대 두 줄
- 한 문장 권장, 최대 두 문장
- 기본 노출 2.5~4초
- 필수 행동 안내는 완료까지 축소형 유지 가능
- 클릭을 가로채지 않음
- 전장 중요 위치와 겹치면 가장자리로 자동 이동
- 음성 없이도 같은 정보가 전달되도록 텍스트·아이콘·색과 결합

### 도움말 상태

```text
Hidden
→ IconOnly
→ HintBubble
→ UrgentAlert
→ RewardReaction
→ Cooldown
```

### 알림 우선순위

```text
본진 치명 위험
> 보스·결전 패턴
> 웨이브 임박
> 필수 튜토리얼 행동
> 자원·식량 문제
> 룰렛 보상
> 일반 팁
> 감정 장식 대사
```

낮은 우선순위 반응은 높은 경보가 발생하면 즉시 취소한다.

## 10. 대사 작성 계약

- 플레이어를 `지휘관`으로 부름
- 핵심 정보부터 말함
- 한 대사에 행동 요구 하나만 포함
- 숫자·라인·시간이 중요하면 생략하지 않음
- 플레이어의 결정을 대신하지 않음
- 실패를 비난하지 않음
- 경계의 율의 비밀을 확정적으로 설명하지 않음

길이:

- 경보: 8~18자 권장
- 튜토리얼: 15~35자 권장
- 감정 반응: 4~14자 권장
- 음성 한 줄: 일반적으로 2.5초 이내

좋은 예:

- `지휘관, 상단에 전사형 넷!`
- `도달까지 30초예요.`
- `병영을 지으면 전사 증원이 늘어요.`
- `포탑이나 바리케이드로 시간을 벌 수 있어요.`
- `잠시 멈추고 배치를 바꿔도 돼요.`
- `전설급 반응이에요!`
- `병력이 부족해요. 어느 라인을 지킬까요?`

피해야 할 예:

- 장황한 세계관 설명
- 세 개 이상의 행동을 동시에 지시
- HUD의 모든 숫자를 음성으로 낭독
- 플레이어를 조롱하거나 실수를 반복 언급
- 확정되지 않은 세계관 비밀을 사실처럼 말함
- 매번 같은 감탄사 사용

## 11. 보이스 방향

### 권장 음색

- 어린아이보다 작고 맑은 청년·소녀 사이의 중성적 음색
- 높은 톤이지만 날카롭거나 과도하게 애니메이션식이지 않음
- 귀여움보다 명료한 정보 전달 우선
- 보고 모드에서는 문장 끝을 짧게 정리
- 작은 종 울림과 겹쳐도 자음이 묻히지 않는 발음

연기 키워드:

```text
명랑함
+ 기민함
+ 약간의 신비로움
+ 실제 위험을 아는 진지함
```

상황별:

- 기본 안내: 밝고 빠르지만 재촉하지 않음
- 적 보고: 라인·수량·시간에 명확한 강세
- 위험 경보: 첫 단어를 강하게, 문장 끝을 짧게
- 룰렛 보상: 높아지는 음정과 빠른 호흡
- 전설: 놀람 30% + 환희 70%
- 패배 직전: 볼륨을 낮추고 안정적으로
- 암시 대사: 평소보다 느리고 작은 울림

## 12. 사운드 모티프

율비는 긴 테마곡보다 짧은 `두 음의 종 모티프`를 가진다.

- 맑은 유리종 또는 작은 금속종
- 서로 가까운 두 음
- 두 번째 음이 살짝 위로 올라감
- 전체 0.3~0.7초

| 상태 | 사운드 |
|---|---|
| 일반 알림 | 짧은 두 음 |
| 위험 | 낮은 첫 음 + 빠른 떨림 |
| 보스 | 낮은 공명 뒤 불협화음 한 음 |
| 축복 | 밝은 3음 확장 |
| 저주 | 두 번째 음이 아래로 꺾임 |
| 일반 당첨 | 가벼운 종 1회 |
| 엘리트 | 종 2회 + 반짝임 |
| 영웅 | 상승 3음 |
| 전설 | 정적 0.1초 → 큰 종 → 작은 잔향 |
| 일시정지 | 부드러운 원형 파동음 |

율비 알림음은 웨이브 경보·룰렛 효과음·UI 클릭음과 주파수 영역을 분리한다.

## 13. 발화 빈도와 피로 방지

- 같은 대사 재생 금지 기본 간격: 60초
- 같은 카테고리 발화 기본 간격: 15초
- 감정 장식 대사: 45초 이상
- 본진 치명 위험·보스 패턴은 제한 무시 가능
- 같은 경고 지속 시 음성 반복 없이 아이콘·점멸 유지
- 대사가 겹치면 우선순위가 낮은 음성을 취소
- 플레이어가 안내 행동을 빠르게 완료하면 남은 대사를 취소
- 옵션: `전체 음성`, `중요 알림만`, `음성 끄기`

첫 10분에는 안내 밀도가 높으므로 같은 화면에서 음성 대사 최대 2개, 연속 대사 사이 최소 0.6초를 적용한다.

## 14. 접근성 계약

- 율비 음성만으로 필수 정보를 전달하지 않음
- 모든 경보는 텍스트·아이콘·색·범위 표시 중 최소 두 가지와 결합
- 색각 이상을 고려해 위험도는 색뿐 아니라 문양 모양과 점멸 속도로 구분
- 말풍선과 자막은 UI 배율 적용
- 애니메이션 감소 옵션에서는 회전·도약·날개 확장을 축소하고 색·문양 점등만 유지
- 율비 표시를 최소화해도 안내와 경보는 일반 HUD로 유지

## 15. 제작 산출물

- 최종 기본형 회전도와 구조 분해도
- 긴 귀형 장식·날개 애니메이션 구조
- 표정 8종과 상태 반응 4종
- 기본형 ↔ 상태색 전환 팔레트
- 상태별 0.5~2초 반응 애니메이션
- 기본형 복귀 0.2~0.4초 블렌드
- HUD 초상 48px·64px·96px
- 일반·엘리트·영웅·전설 반응
- 웨이브·보스·본진 위험 경보
- 세계관 감지·보고·안내·암시 보이스 톤 샘플
- 두 음 종 모티프와 상태별 변형
- 첫 10분 대사 타임라인

## 16. 검증 기준

- 플레이어가 필수 정보를 받기 위해 여러 안내 NPC를 확인할 필요가 없음
- 율비의 한 문장과 HUD만으로 라인·병종·수량·시간을 이해 가능
- 율비가 세계관 비밀을 과도하게 설명하지 않음
- 대부분의 플레이 시간에 동일한 기본형 유지
- 상태 반응 뒤 기본형으로 복귀해도 HUD에 지속 상태가 남음
- 48px에서도 일반·위험·보스·축복·저주 순간 반응 구분
- 대사가 전장·룰렛·건설 조작을 가리지 않음
- 반복 발화가 피로를 만들지 않음
- 높은 우선순위 위험이 보상·장식 반응보다 먼저 전달됨
