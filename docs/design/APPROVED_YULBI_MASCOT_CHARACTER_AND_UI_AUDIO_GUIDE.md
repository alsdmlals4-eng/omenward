## 1. 한 문장 정의

> `율비`는 경계의 징조와 전장의 이상 반응을 감지하며, 최전선 지휘관에게 짧은 경고와 조언을 전달하는 작은 감시 정령이다.

율비는 단순 장식이 아니다. 다음 네 역할을 담당한다.

1. 10~30초 학습을 돕는 짧은 튜토리얼 안내
2. 웨이브·보스·자원 위험을 감정적으로 먼저 알리는 경보
3. 룰렛 당첨·등급 공개·전선 역전의 보상 감정 증폭
4. 무거운 최전선 세계관과 플레이어 사이의 친근한 연결점

## 2. 세계관 위치

### 확정 방향

- 율비는 `경계의 율`을 완전히 이해하지 못한다.
- 징조의 강도·방향·불길함을 감지하지만 미래를 정확히 예언하지는 못한다.
- 정찰관과 부관의 군사 보고를 대체하지 않고, 위험을 먼저 감지하거나 짧게 보조한다.
- 플레이어를 `지휘관`으로 부른다.
- 세계관의 비밀을 설명하는 만능 해설자가 아니다.

### 권장 기원

요새의 오래된 경계종에 남은 울림이 작은 정령으로 분리되어 태어났다는 방향을 추천한다.

```text
경계종의 오래된 울림
→ 반복되는 공세와 징조에 반응
→ 작은 자아 형성
→ 지휘관 곁에서 위험 신호를 전달
```

이 기원은 다음 장점이 있다.

- 이름·종형 실루엣·웨이브 전조를 자연스럽게 연결한다.
- 경계의 율의 정체를 직접 설명하지 않는다.
- 요새가 바뀌어도 `경계종의 파편`, `휴대 종`, `전술판의 울림` 등으로 동행 이유를 만들 수 있다.

정확한 탄생 사건과 지휘관과의 첫 만남은 캠페인 서사 작업에서 확정한다.

## 3. 성격과 감정 온도

### 핵심 성격

- 영리하고 반응이 빠르다.
- 호기심이 많지만 위험을 가볍게 여기지 않는다.
- 플레이어의 실수를 비난하지 않는다.
- 정답을 대신 선택하기보다 위험과 선택지를 짧게 알려준다.
- 평소에는 명랑하지만 본진·민간 후방이 위험할 때는 즉시 진지해진다.

### 감정 비율

```text
친근함 40
기민함 25
신비로움 20
전장의 진지함 15
```

개그 전용 캐릭터로 사용하지 않는다. 농담은 전투가 끝났거나 긴장이 낮은 순간에만 제한적으로 사용한다.

## 4. 외형 캐릭터 시트 계약

### 4.1 실루엣

- 전체 형태는 `둥근 방울 + 물방울` 사이의 종형 실루엣이다.
- 사람형 팔다리는 사용하지 않거나 매우 짧은 빛의 손 정도로만 표현한다.
- 몸 아래는 매끈하게 좁아지며 공중에 떠 있다.
- 머리 위에는 경계 신호를 받는 작은 불꽃형 안테나 또는 종의 고리 형태가 있다.
- 양옆에는 날개보다는 망토 조각·리본·음파 막 같은 작은 부유 장식을 둔다.
- 작은 크기에서도 `큰 눈`, `머리 위 신호 기관`, `몸 중앙 문양` 세 요소가 읽혀야 한다.

### 4.2 비율

- 몸통 높이 대비 얼굴 영역: 약 55~60%
- 눈 간격은 눈 하나 너비보다 약간 좁게 유지해 친근한 인상을 만든다.
- 머리 위 신호 기관은 전체 높이의 15%를 넘지 않는다.
- 측면에서도 종형 실루엣과 중앙 문양이 인식돼야 한다.
- HUD 48~64px 초상에서도 표정이 구분되어야 한다.

### 4.3 얼굴

- 큰 타원형 눈 두 개
- 작은 점·짧은 선 형태의 입
- 실제 눈썹 대신 눈 윗부분과 몸 문양의 각도로 감정을 표현
- 지나친 아기형 볼·혀·동물 코는 사용하지 않는다.
- 눈동자에는 경계 문양과 연결되는 작은 원형 하이라이트를 사용할 수 있다.

### 4.4 몸 중앙 문양

몸 중앙에는 `경계의 율`과 연결된 단일 문양이 있다.

기능:

- 평상시: 낮은 밝기의 호흡 발광
- 웨이브 감지: 위험 라인 방향으로 문양 일부 점등
- 보스: 문양 전체가 불규칙하게 진동
- 룰렛 고등급: 문양이 원형으로 확장
- 일시정지: 발광이 일정한 박자로 안정

문양은 설정 장식이면서 상태 표시 장치다. 의미가 다른 여러 문양을 몸에 과도하게 추가하지 않는다.

### 4.5 권장 색상

최종 색상은 원화 검토 대상이지만 초기 팔레트는 다음을 권장한다.

| 용도 | 권장 색 |
|---|---|
| 기본 몸체 | 밝은 청록·하늘빛 |
| 얼굴·빛 영역 | 따뜻한 백색 |
| 경계 문양 | 옅은 금색 |
| 일반 위험 | 주황빛 |
| 치명 위험·보스 | 붉은 자주빛 |
| 축복 반응 | 금색·연두빛 |
| 저주 반응 | 보랏빛·탁한 적색 |

기본 상태에서 아군 UI의 중요한 경고색과 혼동되지 않아야 한다. 위험 색은 율비 전체를 바꾸기보다 문양·안테나·초상 테두리에 집중한다.

### 4.6 크기감

- 세계 안에서는 사람 머리의 35~45% 정도 크기
- 기본적으로 지휘관의 어깨·전술판 근처에 떠 있는 크기
- 전장 유닛으로 오인될 정도로 크게 표시하지 않는다.
- 실제 전장 위에 나타날 경우 충돌·타기팅·점령 판정이 없는 비전투 연출 객체다.

## 6. 애니메이션 계약

### 기본 루프

- `idle_float`: 느린 상하 부유, 2.5~3.5초 주기
- `idle_blink`: 눈 깜빡임, 불규칙 간격
- `mark_breathe`: 중앙 문양 미세 발광

### 반응 애니메이션

| 상황 | 애니메이션 |
|---|---|
| 튜토리얼 대상 지시 | 대상 쪽으로 기울고 작은 빛 손으로 가리킴 |
| 웨이브 전조 | 안테나가 방향을 향하고 몸이 짧게 떨림 |
| 위험 심화 | 문양이 빠르게 점멸하고 부유 높이가 낮아짐 |
| 룰렛 일반 당첨 | 한 번 위로 튀며 짧은 빛 고리 |
| 엘리트 | 두 번 튀고 작은 별빛 |
| 영웅 | 한 바퀴 회전 후 큰 빛 고리 |
| 전설 | 실루엣 정지 → 문양 폭발 → 빠른 회전 → 환호 |
| 일시정지 | 몸이 안정되고 주변에 작은 원형 파동 |
| 실패·꽝 | 살짝 처지고 발광 감소, 0.6초 이내 복귀 |
| 방어 성공 | 전장 방향을 바라보고 안도한 뒤 환호 |
| 본진 위험 | 평소보다 움직임을 줄이고 눈·문양만 강하게 경고 |

고등급 연출도 플레이어 입력을 오래 막지 않는다. 전설 전용 전체 반응은 1.2~1.8초 이내를 기본 목표로 한다.

## 7. UI 배치 계약

### 7.1 기본 위치

율비는 화면 한가운데를 떠다니는 상시 캐릭터가 아니다.

권장 기본 배치:

- 화면 오른쪽 가장자리의 하단 1/3 구역
- 웨이브 전조·도움말 패널과 인접한 작은 `율비 도크`
- 초상 기본 크기 48~64px
- 말풍선이 없을 때는 초상과 상태 문양만 표시

최종 HUD 레이아웃에 따라 좌우 반전 가능하지만 다음 영역을 가리지 않는다.

- 전장 세 라인
- 룰렛 핵심 결과
- 건설 노드
- 웨이브 타이머
- 전술 명령 버튼
- 본진 체력

### 7.2 말풍선

- 한 번에 최대 두 줄
- 한 문장 권장, 최대 두 문장
- 기본 노출 2.5~4초
- 필수 행동 안내는 행동 완료까지 축소형으로 유지 가능
- 말풍선 자체가 클릭을 가로채지 않음
- 중요한 전장 위치 위에 겹치면 화면 가장자리로 자동 이동
- 같은 정보는 아이콘·색·애니메이션과 함께 제공하며 음성만으로 전달하지 않음

### 7.3 도움말 상태

```text
Hidden
→ IconOnly
→ HintBubble
→ UrgentAlert
→ RewardReaction
→ Cooldown
```

- `Hidden`: 컷신·집중 연출 또는 사용자 설정으로 숨김
- `IconOnly`: 기본 전투 상태
- `HintBubble`: 튜토리얼·새 기능 최초 노출
- `UrgentAlert`: 본진·웨이브·보스 위험
- `RewardReaction`: 룰렛·방어 성공
- `Cooldown`: 같은 카테고리의 반복 발화 제한

### 7.4 우선순위

```text
본진 치명 위험
> 보스·결전 패턴
> 웨이브 임박
> 튜토리얼 필수 행동
> 자원·식량 문제
> 룰렛 보상 반응
> 일반 팁
> 감정 장식 대사
```

낮은 우선순위 반응은 높은 우선순위 경보가 발생하면 즉시 취소한다.

## 8. 대사 작성 계약

### 기본 원칙

- 플레이어를 `지휘관`으로 부른다.
- 핵심 정보부터 말한다.
- 한 대사에 행동 요구를 하나만 넣는다.
- 숫자·라인·시간이 중요하면 생략하지 않는다.
- 플레이어의 결정을 대신하지 않는다.
- 실패를 비난하지 않는다.
- `경계의 율`의 비밀을 확정적으로 설명하지 않는다.

### 길이

- 경보: 8~18자 권장
- 튜토리얼: 15~35자 권장
- 감정 반응: 4~14자 권장
- 음성 한 줄: 일반적으로 2.5초 이내

### 좋은 예

- `지휘관, 상단에 전사형 여섯!`
- `병영을 지으면 전사 증원이 늘어요.`
- `잠시 멈추고 배치를 바꿔도 돼요.`
- `전설급 반응이에요!`
- `병력이 부족해요. 어느 라인을 지킬까요?`

### 피해야 할 예

- 장황한 세계관 설명
- 세 개 이상의 행동을 한 번에 지시
- 수치가 중요한데 `많이`, `조금`으로만 표현
- 플레이어를 조롱하거나 실수를 반복 언급
- 매번 같은 감탄사를 사용

## 9. 첫 10분 대사 세트

| 상황 | 율비 대사 |
|---|---|
| 첫 등장 | `지휘관, 경계가 울려요.` |
| 첫 전조 | `상단이 열립니다. 전사형 여섯, 30초.` |
| 일시정지 | `멈춘 상태에서도 명령은 내릴 수 있어요.` |
| 첫 병영 | `병영을 지으면 전사 증원이 늘어요.` |
| 토큰 반영 | `전술판에 전사 표식이 추가됐어요.` |
| 첫 회전 | `필요한 증원을 확보해 볼까요?` |
| 일반 당첨 | `검사 증원 확보! 상단에 보낼 수 있어요.` |
| 배치 | `상단을 선택하면 바로 전선으로 갑니다.` |
| 두 번째 위기 | `적이 더 옵니다. 시간을 벌어야 해요.` |
| 포탑 | `완공될 때까지 버티면 전선이 달라져요.` |
| 바리케이드 | `여기에 세우면 적을 잠깐 막을 수 있어요.` |
| 역전 성공 | `좋아요! 지휘관의 선택이 통했어요.` |
| 이동권 | `한 줄만 움직이면 더 좋은 결과가 보여요.` |
| 엘리트 | `엘리트 증원이에요. 첫 기술이 강화됐어요.` |
| Tier 2 예고 | `병영을 강화하면 새로운 전사 병종을 고를 수 있어요.` |

최종 대사는 화면 흐름과 함께 별도 테스트한다. 모든 문장을 반드시 음성 녹음할 필요는 없다.

## 10. 보이스 방향

### 권장 음색

- 어린아이보다는 `작고 맑은 청년·소녀 사이의 중성적 음색`
- 높은 톤이지만 날카롭거나 과도하게 애니메이션식이지 않음
- 말끝이 가볍게 떠오르되 경고에서는 빠르게 낮아짐
- 귀여움보다 명료한 전달을 우선
- 작은 종 울림과 겹쳐도 자음이 묻히지 않는 발음

### 연기 키워드

```text
명랑함
+ 기민함
+ 약간의 신비로움
+ 실제 위험을 아는 진지함
```

### 상황별 연기

- 기본 안내: 밝고 빠르지만 재촉하지 않음
- 위험 경보: 첫 단어를 강하게, 문장 끝을 짧게 끊음
- 룰렛 보상: 높아지는 음정과 빠른 호흡
- 전설: 놀람 30% + 환희 70%
- 패배 직전: 볼륨을 낮추고 안정적으로 말함
- 패배 후: 위로하되 지나치게 밝게 행동하지 않음

## 11. 사운드 모티프

율비는 긴 테마곡보다 짧은 `두 음의 종 모티프`를 가진다.

### 기본 모티프

- 맑은 유리종 또는 작은 금속종
- 서로 가까운 두 음
- 두 번째 음이 살짝 위로 올라가 호기심과 반응을 표현
- 전체 길이 0.3~0.7초

### 변형

| 상태 | 사운드 |
|---|---|
| 일반 알림 | 짧은 두 음 |
| 위험 | 낮은 첫 음 + 빠른 떨림 |
| 보스 | 낮은 공명 뒤 불협화음 한 음 |
| 축복 | 밝은 3음 확장 |
| 저주 | 두 번째 음이 아래로 꺾임 |
| 일반 당첨 | 가벼운 종 1회 |
| 엘리트 | 종 2회 + 짧은 반짝임 |
| 영웅 | 상승 3음 |
| 전설 | 정적 0.1초 → 큰 종 → 여러 작은 잔향 |
| 일시정지 | 부드러운 원형 파동음 |

율비 알림음은 웨이브 경보·룰렛 효과음·UI 클릭음과 주파수 영역을 분리한다.

## 12. 발화 빈도와 반복 피로 방지

- 같은 대사 재생 금지 기본 간격: 60초
- 같은 카테고리 발화 기본 간격: 15초
- 감정 장식 대사 기본 간격: 45초 이상
- 본진 치명 위험·보스 패턴은 제한을 무시할 수 있음
- 같은 경고가 지속되면 음성을 반복하지 않고 아이콘·점멸만 유지
- 정찰관·부관 음성과 동시에 말하지 않음
- 대사가 겹치면 우선순위가 낮은 음성을 취소
- 옵션에서 `전체 음성`, `중요 알림만`, `음성 끄기`를 제공하는 방향

## 13. 접근성 계약

- 율비 음성만으로 필수 정보를 전달하지 않는다.
- 모든 경보는 텍스트·아이콘·색·범위 표시 중 최소 두 가지와 결합한다.
- 색각 이상을 고려해 위험도는 색뿐 아니라 문양 모양과 점멸 속도로 구분한다.
- 말풍선 크기와 자막 크기는 UI 배율 설정의 영향을 받는다.
- 애니메이션 감소 옵션에서는 튀기·회전·화면 흔들림을 축소한다.
- 율비 표시를 최소화해도 튜토리얼과 경보 기능은 일반 UI로 유지한다.

## 15. 마케팅 활용

### 키비주얼

- 지휘관 또는 전술판 가까이에서 위험 라인을 바라보는 율비
- 뒤에는 세 라인 전장과 경계의 징조
- 귀여움만 강조하지 않고 `작은 안내자와 압도적인 괴물 군단`의 대비 사용

### 스팀 캡슐

- 작은 크기에서도 눈·문양·종형 실루엣이 보이도록 얼굴을 충분히 크게 배치
- 룰렛 또는 경계 문양과 함께 사용
- 메인 전투 유닛보다 앞에 크게 배치해 게임 장르를 오해하게 만들지 않음

### 커뮤니티 콘텐츠

- `율비의 전장 보고`
- `율비의 오늘의 징조`
- 업데이트 패치의 핵심 변경 요약
- 튜토리얼 팁 카드
- 이모트·스티커용 표정 세트

율비가 개발자 공지의 모든 내용을 말하는 메타 캐릭터가 되지 않도록 세계관형 게시물과 시스템 공지를 구분한다.

## 16. 제작 체크리스트

### 2D 아트

- 회전도 6방향
- 표정 8종 + 상태 4종
- HUD 초상 48·64·96px
- 말풍선용 반신 또는 얼굴 컷
- 전설 반응용 고해상도 컷인
- 스팀 캡슐용 고해상도 포즈

### 애니메이션

- 기본 부유·깜빡임·문양 호흡
- 대상 지시
- 일반·엘리트·영웅·전설 반응
- 일반·치명 위험 경고
- 축복·저주·보스 감지
- 생각·일시정지
- 걱정·시무룩·안도·승리

### 오디오

- 기본 음성 톤 샘플 3종
- 위험 경보 톤 샘플 3종
- 보상 반응 톤 샘플 3종
- 두 음 종 모티프와 상태 변형
- 임시 합성 음성 또는 플레이스홀더로 가독성 테스트

### UX 검증

- 첫 기능 안내를 10~30초 안에 이해하는가
- 말풍선이 전장·버튼을 가리지 않는가
- 음성 없이도 같은 정보를 이해하는가
- 20분 이상 플레이했을 때 반복 피로가 생기지 않는가
- 전설 반응이 보상을 강화하지만 흐름을 방해하지 않는가
- 정찰관·부관과 역할이 겹치지 않는가

## 17. 미확정 사항

- 권장 기원인 `경계종의 울림 정령` 최종 승인
- 최종 실루엣과 신호 기관 형태

- 정찰관·부관과 대사 분담

- 캠페인 중 율비의 성장·외형 변화 여부
- 마케팅에서 율비를 전면에 배치할 비율
