- 상태: **사제 Tier 2 전문화·치유/버프 Tier 3 분기·깃발병 기능 흡수 승인 / 정확한 수치·최종 이름은 PoC 조정 대상**
- 작성일: 2026-07-15
- 대체 문서: `APPROVED_FLAG_BEARER_COMMAND_SUPPORT_CLASS_V2.md`
- 연결 문서:
  - `docs/design/APPROVED_BARRACKS_TIER2_TIER3_INTEGRATED_TREE_V2.md`

  - `docs/design/APPROVED_MIRRORED_FACTION_UNITS_BUILDINGS_AND_ENEMY_RANKS_V1.md`

이 문서는 독립 깃발병 병종을 사제 계열에 통합하고, Tier 3에서 치유 전문과 버프·지휘 전문으로 분화시키는 규칙을 정의한다.

---

## 1. 핵심 정체성

```text
병종 표시명: 사제
base_unit_family = priest_support
combat_archetype_id = priest_line_support
roulette_token_family = priest
```

공통 태그:

```text
infantry
support
healer
buffer
ground
same_lane_support
standard_unit
```

핵심 역할:

- 같은 라인의 부상 아군을 회복한다.
- 주변 아군에게 약한 전투 격려를 제공한다.
- 직접 처치력보다 병력 유지와 전투 효율 상승에 가치가 있다.
- 전열 뒤에서 아군 군집을 따라간다.
- 전역 또는 다른 라인을 지원하지 않는다.
- 단독 전투력은 같은 Tier 전사보다 낮다.

---

## 2. 생산과 토큰

```text
Tier 1 기본 병영
- 검사 자동생산
- 전사 토큰

→ Tier 2 사제 전문화

Tier 2 사제 병영
- 일반 사제 자동생산
- 사제 토큰
```

고정 규칙:

- 별도 사원이나 지휘소를 기본 생산 건물로 요구하지 않는다.
- 업그레이드 중에는 검사 생산과 전사 토큰을 유지한다.
- 생산 진행률을 보존하고 완료 뒤 첫 완성분부터 사제를 생산한다.
- 진행 중 룰렛은 유지하고 다음 회전부터 사제 토큰을 적용한다.
- 기존 군기 토큰은 활성 토큰 목록에서 제거한다.

---

## 3. Tier 2 사제의 혼합 지원

Tier 2 사제는 치유와 버프를 모두 약하게 가진다.

### 기본 치유

가칭 `회복 기도`:

- 같은 라인·사거리 안에서 체력 비율이 가장 낮은 아군을 우선한다.
- 단일 대상 소량 회복.
- 과잉 회복을 보호막으로 변환하지 않는다.
- 보스·건물은 기본 치유 대상에서 제외한다.
- 치유 대상이 없으면 불필요하게 사용하지 않는다.

초기 범위 가설:

```text
healing_range = 220
healing_target_cap = 1
healing_cooldown = 8초
```

### 기본 격려

가칭 `전장의 성가`:

- 사제가 아군을 치유하면 주변 같은 라인 아군 일부에게 짧은 공격속도 또는 이동속도 증가를 제공한다.
- 초기 최대 대상 가설 4기.
- 동일 격려 효과는 중첩하지 않고 지속시간만 갱신한다.
- Tier 2에서는 전쟁사제의 전문 오라보다 약해야 한다.

---

## 4. 전투 위치와 AI

```text
선택 라인 유지
→ 가장 가까운 아군 전열 군집 탐색
→ 전열 뒤 약 120~200 world units 유지
→ 부상 아군이 치유 사거리 안에 있도록 재배치
→ 적 장거리 추격 금지
```

AI 우선순위:

1. 생존 위험이 높은 같은 라인 아군 치유.
2. 현재 교전 중인 아군 유지.
3. 영웅·전설·탱커·전쟁사제 같은 핵심 유닛 보호.
4. 적이 접근하면 후퇴하며 자기방어 공격.

- 다른 라인으로 자동 이동하지 않는다.
- 적을 추격해 전열 앞으로 뛰어나가지 않는다.
- 주변 아군이 없으면 중간요새 또는 랠리 지점으로 후퇴한다.

## 5. Tier 3 치유사제

```text
advanced_variant_t3_id = healing_priest
support_focus_id = healing_focus
```

역할:

- 직접 회복량과 회복 대상 수 강화.
- 짧은 재생 효과 추가.
- 약한 상태이상 지속시간 감소 또는 임시 보호막 제공.
- 버프 효과량은 전쟁사제보다 낮다.

초기 방향:

- 회복 기도 대상 1기 → 최대 2기.
- 낮은 체력 대상 추가 회복.
- 치유 후 3~5초 재생.
- 기절·속박을 전부 해제하는 만능 정화는 제공하지 않는다.
- 보스 패턴을 무시하는 무적·완전 면역을 제공하지 않는다.

치유 중첩:

- 여러 사제의 직접 치유는 가능하다.
- 동일 재생 효과는 가장 강한 하나만 적용한다.
- 동일 임시 보호막은 수치 중첩 없이 가장 강한 하나를 적용한다.

---

## 6. Tier 3 전쟁사제

```text
advanced_variant_t3_id = war_priest
support_focus_id = command_focus
```

전쟁사제는 기존 깃발병의 전장 보조 지휘관 기능을 흡수한다.

시각적 정체성:

- 높은 군기, 성물기, 전선 표식 또는 긴 지팡이를 사용한다.
- 일반 사제보다 깃발·천·문양 실루엣이 강조된다.
- 상시 거대한 발광 오라는 사용하지 않는다.

전투 역할:

- 같은 라인 아군의 공격속도·이동속도·진형 유지를 강화한다.
- 집결 명령과 전선 선언 같은 순간 지휘 능력을 사용한다.
- 직접 치유량은 치유사제보다 낮다.
- 지속 오라와 활성 명령을 조합한다.

초기 오라 가설:

```text
command_radius = 180
command_target_cap = 8
command_line_restriction = same_lane
buff_stack_rule = strongest_only
```

중첩 규칙:

- 동일 `command_aura`는 가장 강한 효과 하나만 적용한다.
- 동일 활성 명령은 수치가 중첩되지 않고 지속시간만 갱신한다.
- 여러 전쟁사제는 같은 군집 무한 증폭보다 여러 라인·분리 군집 지원에 유리해야 한다.
- 일반 지휘 오라가 보스에게 적용될 경우 효과량을 감소시킬 수 있다.

## 7. 등급별 스킬 성장

사제도 공통 룰렛 등급 계약을 따른다.

```text
일반: 1스킬 기본형
엘리트: 1스킬 강화
영웅: 강화된 1스킬 + 2스킬
전설: 강화된 1스킬 + 강화된 2스킬 + 3스킬
```

사제 계열의 고정 상위 등급 템플릿은 치유와 버프를 모두 다루는 상위 성직자 정체성을 가진다.

Tier 3 출처 수정자:

```text
healing_focus
→ 회복량·재생·보호 효과 강화

command_focus
→ 오라·집결·지휘 효과 강화
```

수정자는 고정 상위 등급 유닛의 이름·외형·기본 스킬을 교체하지 않고 효과 비중만 조정한다.

## 8. 기본 능력치 방향

`Tier 2 일반 전사 평균 = 100` 기준 초기 상대 지수:

| 항목 | 사제 방향 |
|---|---:|
| 체력 | 75 |
| 단독 DPS | 45 |
| 이동 | 95 |
| 식량 | 2 |
| 생산시간 | 135초 |

사제의 총 전력 비용은 본체 DPS가 아니라 다음을 포함해 계산한다.

```text
self_combat_cost
+ expected_healing_output
+ expected_supported_targets
+ expected_buff_uptime
= total_support_cost
```

## 9. 적군 대칭 지원 계열

적군에도 같은 `priest_support` 구조를 가진 지원형 베일종을 둔다.

가칭:

```text
치유형: 베일 봉합자
버프형: 베일 전령
```

공통 규칙:

- 같은 Tier·등급 아군 사제와 기본 지원 예산 ±10%에서 시작한다.
- 치유형은 부상 적을 회복하고 재생을 부여한다.
- 버프형은 오라·표식·전선 지휘를 제공한다.
- 베일의 징조에 `치유`, `지원`, `오라`, `우선 처치` 정보를 공개한다.
- 적 지원 유닛의 치유와 버프 대상 수를 Threat Budget에 포함한다.
- 보스 치유·버프는 효과량을 제한하거나 별도 공개 보스 수정자로 관리한다.

## 10. UI·아트 계약

### 일반 사제

- 기본 전략 줌 몸체 34~40px.
- 지팡이·성물·밝은 천 장식으로 식별한다.
- 치유 대상에게 짧은 선 또는 작은 표식을 표시한다.
- 상시 화면 전체 연결선은 사용하지 않는다.

### 치유사제

- 성물·등불·약병·빛나는 손 등의 회복 실루엣.
- 회복 효과는 짧고 명확하며 다른 전투 이펙트를 가리지 않는다.

### 전쟁사제

- 높은 군기 또는 성물기로 기존 깃발병의 가독성을 계승한다.
- 선택·마우스오버 시 오라 반경과 대상 수를 표시한다.
- 버프 대상에는 작은 군기·성가 아이콘만 표시한다.

## 12. 검증 계약

1. 깃발병은 독립 Tier 2 전문화로 표시되지 않는다.
2. 군기 토큰은 활성 토큰 목록에서 제거된다.
3. Tier 2 사제는 회복과 버프를 모두 약하게 제공한다.
4. 치유사제는 회복·재생·보호에 특화한다.
5. 전쟁사제는 기존 깃발병의 오라·군기·집결 역할을 흡수한다.
6. 두 Tier 3 분기는 같은 사제 토큰을 유지한다.
7. 모든 기본 지원 효과는 같은 라인으로 제한된다.
8. 동일 지휘 오라는 strongest-only 규칙을 사용한다.
9. 치유사제 여러 기가 동일 재생·보호막을 무한 중첩하지 않는다.
10. 사제 단독 전투력은 같은 Tier 전사보다 낮다.
11. 적군 지원형도 치유·버프 정보와 우선 처치 이유를 공개한다.
12. 전쟁사제의 높은 군기가 기본 전략 줌에서 식별된다.

## 13. 후속 미확정

- 사제·치유사제·전쟁사제의 최종 한국어·영문 이름.
- 회복량·쿨다운·대상 수·재생 수치.
- 버프 효과량·오라 반경·대상 수.
- 엘리트·영웅·전설 사제 이름과 스킬.
- 적군 대응 지원 유닛의 공식 이름과 외형.
- 사제 생산·식량·룰렛 가중치 최종값.

이 문서는 지원 계열 구조를 승인하지만 Godot 구현 승인을 뜻하지 않는다. 구현은 별도 Codex Plan Mode 제안서와 사용자 승인을 거친다.
