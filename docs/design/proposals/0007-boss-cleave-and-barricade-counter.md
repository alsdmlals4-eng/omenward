# 제안서 0007 — 보스 길 뚫기와 축 방향 범위 공격

- 상태: **핵심 방향 승인 / 세부 수치 조정 대기**
- 구현 상태: 승인 전 구현 금지
- 관련 문서:
  - `docs/design/APPROVED_BUILDING_SPECIALIZATION_AND_TACTICAL_COMMANDS.md`

## 1. 목적

바리케이드는 금화를 지불해 시간을 버는 강한 전술 수단이지만, 보스·지휘관형 적을 한 지점에 무기한 묶는 정답이 되어서는 안 된다.

이를 바리케이드 자체의 강한 사용 제한으로 해결하지 않고, 강한 적에게 다음 두 패턴을 부여해 해결한다.

1. 라인 진행 방향을 따라 길을 여는 **가로축 직선 공격**
2. 라인 폭을 크게 베어 밀집 병력을 공격하는 **세로축 크게 베기**

## 2. 좌표 계약

프로토타입 전장은 다음 좌표 의미를 사용한다.

```text
X축 / 가로축: 각 라인의 진행 방향, 적 본진 ↔ 플레이어 본진
Y축 / 세로축: 한 라인의 폭 방향
```

세로축 공격은 기본적으로 현재 라인의 폭만 공격한다. 인접한 다른 라인까지 동시에 공격하는 패턴은 최종 보스 같은 별도 능력으로만 검토한다.

## 3. 가로축 패턴 — 직선 돌파

### 역할

- 바리케이드와 전열을 부수며 이동 경로를 연다.
- 한 줄로 길게 모인 아군을 압박한다.
- 보스가 바리케이드 앞에서 일반 공격만 반복하는 현상을 막는다.

### 기본 흐름

```text
바리케이드 또는 전열 감지
→ 보스가 이동을 멈추고 직선 범위 예고
→ 시전 동작
→ 현재 라인의 전방으로 긴 직사각형 공격
→ 바리케이드·유닛 피해
→ 경로가 열리면 전진 재개
```

### 추천 계약

- 현재 라인 안에서만 사용한다.
- 가로축으로 긴 직사각형 범위를 사용한다.
- 바리케이드가 진행을 막고 있으면 우선 사용 후보가 된다.
- 바리케이드와 임시 구조물에 높은 피해 계수를 가진다.
- 일반 건물과 본진 피해는 별도 공성 계수로 제한한다.
- 플레이어 유닛에도 피해를 주지만 기본적으로 정상 체력 유닛을 일격에 삭제하지 않는다.
- 예고가 시작된 뒤 공격 범위는 목표를 추적하지 않고 고정한다.

바리케이드 즉시 파괴 여부와 구조물 피해 계수는 보스 등급별 데이터로 조정한다.

## 4. 세로축 패턴 — 크게 베기

### 역할

- 한 지점에 과도하게 밀집한 아군 병력을 공격한다.
- 바리케이드 뒤에 원거리·지원 병력을 모두 쌓는 운영에 대응한다.
- 다수 유닛을 상대하는 보스의 시각적 위압감과 전투 리듬을 만든다.

### 기본 흐름

```text
현재 라인의 밀집 병력 감지
→ 보스 전방의 세로 범위 예고
→ 크게 베기
→ 범위 안 유닛에 광역 피해·경직 또는 밀쳐내기
```

### 추천 계약

- Y축으로 넓고 X축으로 짧은 직사각형 또는 부채꼴을 사용한다.
- 현재 라인의 밀집도가 기준치를 넘을 때 사용 확률이 올라간다.
- 바리케이드 뒤의 아군도 범위 안이면 함께 맞을 수 있다.
- 건물과 본진에는 피해가 없거나 낮은 계수만 적용한다.
- 같은 패턴을 짧은 간격으로 연속 사용하지 않는다.
- 예고 범위는 시전 중 추적하지 않는다.

경직·밀쳐내기는 전투 충돌 규칙이 확정된 뒤 포함 여부를 결정한다.

## 5. 전조와 공정성

직접 유닛을 세밀하게 회피시키는 게임이 아니므로 보스 범위 공격은 반사신경 시험보다 사전 계획과 병력 분산을 요구해야 한다.

공통 원칙:

- 최초 등장 전에 패턴 아이콘과 역할을 공개한다.
- 사용 직전 명확한 바닥 범위, 자세 변화와 음향을 제공한다.
- 초기 시전 예고 가설은 1.5~2.0초다.
- 예고 시작 뒤 범위는 고정하고 플레이어 병력을 끝까지 추적하지 않는다.
- 정상 상태의 영웅·전설을 예고 없는 한 번의 공격으로 제거하지 않는다.
- 패턴 재사용 대기시간을 공개 또는 관찰 가능하게 만든다.
- 웨이브 전조 카드에 해당 보스가 `바리케이드 파괴`와 `밀집 병력 공격` 능력을 가졌음을 표시한다.

## 6. 바리케이드와의 상호작용

바리케이드는 여전히 유효하다.

```text
바리케이드 설치
→ 보스가 즉시 통과하지 못함
→ 직선 돌파 준비 시간 발생
→ 그동안 포탑 완공·증원·화살비·강화지대 사용 가능
→ 돌파 공격 뒤 보스 전진
```

따라서 바리케이드는 보스를 영구 봉쇄하지는 못하지만, 금화 비용에 맞는 대응 시간을 제공한다.

추천 우선순위:

1. 바리케이드가 경로를 막고 직선 돌파가 준비됨 → 직선 돌파
2. 밀집 아군이 기준치를 넘고 크게 베기가 준비됨 → 크게 베기
3. 그 외 → 기본 공격·이동·다른 보스 패턴

보스가 바리케이드를 감지하는 즉시 쿨다운을 무시하거나 예고 없이 파괴해서는 안 된다.

## 7. 전술 명령 연속 사용과의 관계

전술 명령은 전역 쿨다운을 사용하지 않는다. 금화가 충분하고 각 명령의 개별 쿨다운이 끝났다면 서로 다른 명령을 연속해서 사용할 수 있다.

보스 범위 공격은 이 자유를 직접 금지하지 않는다. 대신 다음과 같은 상호작용을 만든다.

- 바리케이드로 직선 돌파 시전을 유도한 뒤 화살비 사용
- 크게 베기 전 강화지대로 피해 완화
- 지원병이 섞인 보스 웨이브에 역병 사용
- 여러 명령을 연속 사용하면 큰 금화를 지불하므로 이후 건설·용병 구매가 약해짐

## 8. 데이터 계약

보스 패턴 데이터 최소 필드:

```text

trigger_tags         # barricade_blocked / unit_density 등
```

```text

boss_pattern_ui_tags
```

## 9. UI 계약

- 가로축 공격: 라인 방향으로 긴 붉은 직사각형 표시
- 세로축 공격: 라인 폭을 가로지르는 넓은 범위 표시
- 바리케이드 선택 시 해당 웨이브에 길 뚫기 보스가 있는지 경고
- 적 위협 카드에 `장애물 파괴`, `밀집 공격` 태그 표시
- 패턴에 맞은 뒤 결과 보고에 `보스 직선 돌파`, `보스 크게 베기` 원인 표시

## 10. 검증 시나리오

- 일반 적은 바리케이드에 막히지만 길 뚫기 보스는 예고 뒤 직선 돌파를 사용한다.
- 직선 돌파는 바리케이드에 높은 피해를 주고 경로를 다시 연다.
- 바리케이드가 없어도 가로축 범위 안 유닛은 공격받을 수 있다.
- 밀집 병력이 기준치를 넘으면 크게 베기 사용 후보가 된다.
- 크게 베기는 기본적으로 인접 라인의 유닛을 공격하지 않는다.
- 예고가 시작된 뒤 공격 범위가 유닛을 추적하지 않는다.
- 바리케이드 하나가 보스를 영구히 봉쇄하지 못한다.
- 바리케이드는 보스 패턴 준비 시간만큼 여전히 유의미한 시간을 번다.
- 같은 시드·StageManifest에서 패턴 목록과 초기 사용 규칙이 재현된다.

## 11. 남은 사용자 결정

- 직선 돌파의 바리케이드 즉시 파괴 여부 또는 피해 배율
- 크게 베기의 피해·경직·밀쳐내기 조합
- 패턴별 시전 예고와 개별 쿨다운
- 패턴을 가진 첫 보스의 등장 스테이지
- 보스 등급별 패턴 수와 우선순위
- 결전 웨이브 지휘관에게 두 패턴을 모두 줄지 여부

## 12. 승인 게이트

가로축 직선 공격으로 길을 열고 세로축 크게 베기로 밀집 병력을 공격하는 핵심 방향은 승인됐다. 정확한 피해, 범위, 시전시간과 쿨다운은 데이터·플레이테스트 조정 항목이며 Codex는 사용자 승인 전 구현하지 않는다.
