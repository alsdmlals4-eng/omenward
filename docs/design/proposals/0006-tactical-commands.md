# 제안서 0006 — 금화 소모형 일회성 전술 명령

- 상태: **핵심 사용 구조 승인 / 개별 효과 수치 조정 대기**
- 구현 상태: 승인 전 구현 금지
- 승인 원본: `docs/design/APPROVED_BUILDING_SPECIALIZATION_AND_TACTICAL_COMMANDS.md`
- 보스 대응: `docs/design/proposals/0007-boss-cleave-and-barricade-counter.md`

## 1. 목적

시장·용병·포탑 중심 빌드가 축적한 금화를 전투 중 즉각적인 대응력으로 전환한다.

전술 명령은 유닛 생산과 건설을 대체하는 무료 마법이 아니다. 사용할 때마다 금화를 지불하고 짧은 시간 동안 전선을 보조하는 선택지다.

## 2. 승인된 공통 흐름

```text
전술 명령 선택
→ 목표 라인·지점 지정
→ 비용·범위·예상 효과 확인
→ 실행 확정과 금화 차감
→ 짧은 시전 예고
→ 1회성 또는 제한시간 효과
→ 해당 명령의 개별 쿨다운
```

공통 계약:

- 해금된 기본 명령은 HUD에 항상 표시한다.
- 기본 명령은 상점 무작위 1회권으로 구매하지 않는다.
- 발동마다 금화를 직접 소비한다.
- 식량·건설 노드·룰렛 토큰을 사용하지 않는다.
- 전역 쿨다운을 사용하지 않는다.
- 일시정지 예약 상태와 예약 금액을 사용하지 않는다.
- 전술 명령은 게임이 진행 중일 때만 실행 확정할 수 있다.
- 일시정지 중에는 설명·범위 미리보기를 볼 수 있지만 실행·금화 차감은 하지 않는다.
- 금화와 각 명령의 개별 쿨다운 조건을 만족하면 서로 다른 명령을 연속 사용할 수 있다.
- 같은 효과가 무한 중첩되지 않도록 명령별 중첩 규칙을 둔다.
- 적 본진·생산시설을 직접 파괴하는 주 공격 수단으로 만들지 않는다.

## 3. 조작 구조

전술 명령은 고정 HUD 패널에서 사용한다.

- 명령 4개를 한 번에 표시
- 단축키 `1~4` 또는 클릭으로 선택
- 대상 위치 미리보기 뒤 좌클릭으로 실행
- 우클릭 또는 `Esc`로 취소
- 사용 후 잔액과 효과를 확정 전에 표시
- 일시정지 상태에서는 실행 확정 버튼 비활성화

전역 쿨다운이 없으므로 다음 상황을 허용한다.

```text
바리케이드 설치
→ 즉시 화살비 지정
→ 이어서 강화지대 사용
```

각 명령의 금화 비용과 개별 쿨다운은 모두 지불·준수해야 한다.

## 4. 바리케이드

### 역할

적의 전진을 잠시 막아 포탑 완공, 증원 도착 또는 후방 재정비 시간을 번다.

### 계약

- 각 라인의 지정된 전술 지점에만 설치한다.
- 자유 배치와 임의 길찾기 변경은 첫 프로토타입에서 제외한다.
- 아군은 통과하고 적만 차단한다.
- 라인당 동시에 하나만 활성화한다.
- 적의 공격 대상이며 체력 0 또는 지속시간 종료 시 사라진다.
- 공격 기능, 식량, 건설 노드와 룰렛 토큰이 없다.
- 보스·지휘관형 적은 예고된 길 뚫기 패턴으로 대응할 수 있다.

초기 수치 가설:

- 시전 지연 1.5초
- 지속시간 18초
- 체력: 해당 스테이지 Tier 1 포탑 체력의 약 70%
- 개별 쿨다운 30초
- 기본 비용 12골드

바리케이드가 강한 적을 영구 봉쇄하지 않도록 하는 규칙은 `0007`에서 관리한다.

## 5. 화살비

### 역할

한 라인의 밀집된 일반 병력을 빠르게 약화한다.

### 계약

- 원형 또는 짧은 라인 구간 지정
- 1.2초 경고 뒤 세 차례 피해
- 일반 유닛에 강하고 영웅·지휘관에는 감소된 계수
- 적 건물·본진·바리케이드 피해 없음
- 아군 피해 없음
- 개별 쿨다운 40초 초기 가설
- 기본 비용 18골드 초기 가설

화살비 하나만으로 정상 체력의 결전 웨이브를 삭제할 수 없어야 한다.

## 6. 역병

### 역할

적을 서서히 약화하고 회복·지원 중심 웨이브를 견제한다.

### 계약

- 지정 구역에 지속 피해 지대 생성
- 구역 안 적의 치유량 감소
- 건물·본진·바리케이드에는 적용하지 않음
- 동일 대상의 피해는 중첩하지 않고 지속시간만 갱신
- 지휘관형은 지속 피해 감소 계수 적용 가능
- 개별 쿨다운 50초 초기 가설
- 기본 비용 22골드 초기 가설

## 7. 강화지대

### 역할

특정 라인의 아군을 일시 강화해 접전지 방어 또는 공격 전환을 돕는다.

### 계약

- 지정 구역에 제한시간 강화지대 생성
- 유닛에만 적용하고 포탑·건물·바리케이드 제외
- 공격속도와 피해 감소 등 두 효과 이하로 제한
- 같은 강화지대는 중첩하지 않고 더 강하거나 오래 남은 효과로 갱신
- 개별 쿨다운 45초 초기 가설
- 기본 비용 24골드 초기 가설

## 8. 명령 간 역할

| 명령 | 핵심 목적 | 강한 상황 | 약한 상황 |
|---|---|---|---|
| 바리케이드 | 시간 확보 | 포탑 완공·증원 대기 | 길 뚫기 보스·원거리 적 |
| 화살비 | 즉시 광역 피해 | 밀집 일반 병력 | 지휘관·건물 |
| 역병 | 지속 약화·치유 억제 | 지원병·장기 교전 | 짧은 돌격전 |
| 강화지대 | 아군 전투력 상승 | 접전지·결전 방어 | 아군이 없는 구역 |

네 명령이 모두 단순 피해 기술이 되지 않도록 역할을 분리한다.

## 9. 비용과 개별 쿨다운

정확한 수치는 시장 수입·용병 가격과 함께 조정한다.

| 명령 | 기본 비용 | 개별 쿨다운 |
|---|---:|---:|
| 바리케이드 | 12 | 30초 |
| 화살비 | 18 | 40초 |
| 역병 | 22 | 50초 |
| 강화지대 | 24 | 45초 |

계약:

- 전역 쿨다운 없음
- 스테이지당 사용 횟수 하드 제한 없음
- 반복 사용 가격 상승 없음
- 서로 다른 명령 연속 사용 허용
- 같은 명령은 개별 쿨다운이 끝나야 재사용
- 금화 부족 시 버튼 비활성화와 부족량 표시
- 시장·아이템 할인은 별도 상한 적용 가능

금화가 많은 플레이어가 여러 명령을 연속 사용해 위기를 넘기는 것은 의도된 시장 빌드 보상이다. 그 대가로 건설·룰렛·용병에 사용할 금화가 줄어든다.

## 10. Command Power

후반 스테이지에서 전술 명령이 무의미하거나 초반을 삭제하지 않도록 StageManifest에 위력 스칼라를 둔다.

```text
command_power_level
command_damage_scalar
command_structure_hp_scalar
command_buff_scalar
command_cost_multiplier
```

- 적 현재 체력의 고정 비율로 직접 피해를 계산하지 않는다.
- 일반·엘리트·영웅·지휘관 대상별 계수를 사용한다.
- 같은 시드·난이도·제약은 같은 값을 만든다.
- 생성기는 특정 전술 명령을 필수 정답으로 요구하지 않는다.

## 11. 해금 순서 추천

| 구간 | 해금 |
|---|---|
| 튜토리얼 | 바리케이드 |
| 정규 스테이지 1 | 화살비 |
| 정규 스테이지 3 | 역병 |
| 정규 스테이지 4 | 강화지대 |

튜토리얼에서는 바리케이드로 적을 잠시 막아 포탑이 완공될 시간을 버는 장면만 짧게 소개한다.

## 12. 보스 대응 연결

바리케이드의 반복 사용을 전역 쿨다운으로 막지 않는다. 대신 보스·지휘관형 적이 다음 패턴을 가질 수 있다.

- 가로축 직선 돌파: 라인 진행 방향으로 바리케이드와 전열 공격
- 세로축 크게 베기: 바리케이드 뒤에 밀집한 다수 유닛 공격

두 패턴은 명확히 예고되고, 바리케이드가 패턴 준비 시간만큼 여전히 유의미한 지연을 제공해야 한다.

## 13. 제약 시스템 연결

제약 후보:

- 전술 명령 비용 증가
- 개별 쿨다운 증가
- 특정 명령 사용 불가
- Command Power 감소

전역 쿨다운 증가 제약은 기본 시스템에 전역 쿨다운이 없으므로 사용하지 않는다.

## 14. UI 계약

전술 명령 패널 표시:

- 해금 여부
- 기본 비용·할인·최종 비용
- 현재 금화와 사용 후 잔액
- 개별 쿨다운
- 대상 가능·불가능 영역
- 범위·시전 지연·지속시간
- 예상 피해·체력·버프
- 사용 불가 이유

표시하지 않는 항목:

- 전역 쿨다운
- 예약 금액
- PendingCommand 상태

## 15. 검증 시나리오

- 상점 재고와 무관하게 해금된 명령이 HUD에 표시된다.
- 금화가 충분하고 각 명령이 준비됐다면 서로 다른 명령을 연속 사용할 수 있다.
- 한 명령 사용이 다른 명령의 사용을 전역적으로 잠그지 않는다.
- 일시정지 중 명령 실행·금화 차감·예약 상태가 생성되지 않는다.
- 바리케이드는 아군을 막지 않고 적만 차단한다.
- 라인 하나에 바리케이드 두 개를 겹쳐 설치할 수 없다.
- 길 뚫기 보스는 예고 뒤 바리케이드 대응 패턴을 사용할 수 있다.
- 화살비와 역병은 건물·본진에 피해를 주지 않는다.
- 역병과 강화지대의 동일 효과가 무한 중첩되지 않는다.
- 같은 StageManifest와 입력은 같은 효과 결과를 만든다.

## 16. 남은 사용자 결정

- 명령별 정확한 비용과 개별 쿨다운
- 바리케이드 체력·지속시간·배치 지점
- 화살비 피해량과 대상 계수
- 역병 피해·치유 감소량
- 강화지대 강화량
- Command Power 스칼라
- 스테이지별 해금 순서

## 17. 승인 게이트

직접 금화 결제, 전역 쿨다운 없음, 일시정지 예약 없음, 서로 다른 명령의 연속 사용 허용은 승인된 구조다. 정확한 비용·효과·개별 쿨다운은 조정 중이며 Codex는 별도 Plan Mode 제안서와 사용자 승인 전 구현하지 않는다.
