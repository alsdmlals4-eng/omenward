# 제안서 0006 — 금화 소모형 일회성 전술 명령

- 상태: **핵심 방향 승인 / 세부 효과 조정 대기**
- 구현 상태: 승인 전 구현 금지
- 승인 원본: `docs/design/APPROVED_BUILDING_SPECIALIZATION_AND_TACTICAL_COMMANDS.md`

## 1. 목적

시장·용병·포탑 중심 빌드가 축적한 금화를 전투 중 즉각적인 대응력으로 전환할 수 있게 한다.

전술 명령은 유닛 생산과 포탑 건설을 대체하지 않는다. 짧은 시간 동안 전선을 보조하거나 위기 대응 기회를 만드는 금화 소비 수단이다.

## 2. 공통 흐름

```text
전술 명령 선택
→ 목표 라인·지점 지정
→ 비용·범위·예상 효과 확인
→ 금화 지불
→ 짧은 시전 예고
→ 1회성 또는 제한시간 효과 발생
→ 재사용 대기
```

공통 계약:

- 발동마다 금화를 소비한다.
- 식량과 건설 노드를 사용하지 않는다.
- 룰렛 토큰을 추가하지 않는다.
- 일시정지 중 목표를 예약할 수 있고 재개 시 실행한다.
- 효과가 적 본진과 생산시설을 직접 파괴하는 주 공격 수단이 되지 않게 한다.
- 같은 능력을 연속 사용해 효과가 무한 중첩되지 않도록 중첩 규칙을 둔다.
- 각 명령의 금화 비용과 재사용 대기시간은 데이터로 조정한다.

## 3. 추천 조작 구조

전술 명령은 본진 또는 고정 HUD의 `전술 명령 패널`에서 사용한다.

추천:

- 한 번에 4개 명령 표시
- 단축키 `1~4` 또는 클릭으로 선택
- 대상 위치 미리보기 후 확정
- 우클릭 또는 `Esc`로 취소
- 일시정지 중 예약 가능
- 명령 사용 뒤 짧은 전역 재사용 대기시간 적용

초기 전역 재사용 대기시간 가설은 10~15초다. 이는 금화가 많아도 여러 명령을 한 틱에 겹쳐 웨이브를 삭제하는 상황을 막기 위한 것이다.

## 4. 바리케이드 건설

### 역할

적의 전진을 잠시 막아 포탑 완공, 증원 도착 또는 후방 재정비 시간을 번다.

### 추천 규칙

- 각 라인의 미리 지정된 전술 지점에만 설치한다.
- 자유 배치와 길찾기 재계산은 첫 프로토타입에서 제외한다.
- 적 유닛의 이동을 막는 임시 구조물이다.
- 아군은 통과하거나 바리케이드 뒤에서 전투할 수 있다.
- 적의 공격 대상이 되며 체력이 0이 되면 즉시 사라진다.
- 지속시간이 끝나도 사라진다.
- 건설 노드, 룰렛 토큰과 식량을 사용하지 않는다.
- 바리케이드 자체 공격 기능은 없다.

초기 가설:

- 시전시간: 1~2초
- 지속시간: 12~20초
- 역할: 적 웨이브를 완전히 봉쇄하지 않고 짧은 지연 제공

## 5. 화살비

### 역할

한 라인의 밀집된 일반 병력을 빠르게 약화한다.

### 추천 규칙

- 원형 또는 짧은 라인 구간을 지정한다.
- 1초 안팎의 명확한 경고 표시 뒤 피해를 준다.
- 여러 차례의 작은 피해 또는 한 번의 큰 피해 중 성능 검증 후 선택한다.
- 일반 유닛에는 효과적이지만 지휘관·영웅형 적에는 감소된 피해를 준다.
- 적 건물과 본진에는 피해를 주지 않는다.
- 아군 피해는 첫 프로토타입에서 제외한다.

초기 역할은 `밀집 병력 정리`이며 단독으로 결전 웨이브를 삭제할 수 없어야 한다.

## 6. 역병

### 역할

적 병력을 서서히 약화하고 회복·지원 중심 웨이브를 견제한다.

### 추천 규칙

- 지정 구역에 일정 시간 역병 지대를 생성한다.
- 구역 안 적에게 지속 피해를 준다.
- 치유량 또는 회복 효과를 감소시킨다.
- 건물·본진·바리케이드에는 영향을 주지 않는다.
- 같은 대상에게 여러 역병을 중첩하면 피해가 쌓이지 않고 지속시간만 갱신하는 안을 추천한다.
- 지휘관형 적의 치유 감소는 적용하되 지속 피해는 감소시킬 수 있다.

화살비가 즉시 피해라면 역병은 장기 교전과 지원병 대응에 강한 역할로 구분한다.

## 7. 강화지대

### 역할

특정 라인에 있는 아군 병력을 일시적으로 강화해 접전지 방어 또는 공격 전환을 돕는다.

### 추천 규칙

- 지정 구역에 제한시간 동안 강화지대를 생성한다.
- 구역 안 아군에게 공격속도·방어·이동속도 중 일부를 제공한다.
- 구역을 벗어나면 짧은 유예 뒤 효과가 사라진다.
- 포탑과 건물에는 적용하지 않고 유닛만 강화한다.
- 같은 강화지대 효과는 중첩하지 않고 가장 강한 효과만 적용한다.

초기에는 공격·방어를 모두 조금 올리는 단순 효과보다 `공격속도 + 방어`처럼 두 효과 이하로 제한하는 것을 추천한다.

## 8. 명령 간 역할 구분

| 명령 | 핵심 목적 | 강한 상황 | 약한 상황 |
|---|---|---|---|
| 바리케이드 | 시간 확보 | 돌격·공성 접근 지연 | 원거리 화력, 침투 |
| 화살비 | 즉시 광역 피해 | 밀집 일반 병력 | 지휘관·건물 |
| 역병 | 지속 약화·치유 억제 | 지원병·장기 교전 | 짧은 돌격전 |
| 강화지대 | 아군 전투력 상승 | 접전지·결전 방어 | 해당 구역에 아군이 없음 |

네 명령이 모두 단순 피해 기술이 되지 않도록 역할을 분리한다.

## 9. 비용과 재사용 추천 구조

정확한 금화는 시장 수입과 용병 가격을 확정한 뒤 정한다.

상대 비용 가설:

```text
바리케이드: 낮음~중간
화살비: 중간
역병: 중간~높음
강화지대: 중간~높음
```

공통 추천:

- 각 명령별 개별 재사용 대기시간
- 하나 사용 후 10~15초 전역 재사용 대기시간
- 금화가 부족하면 버튼 비활성화와 부족량 표시
- 한 스테이지 사용 횟수의 하드 제한은 두지 않음
- 시장 중심 빌드의 정식 금화 소비처로 유지

재사용 대기시간은 금화 수익을 무효화하는 제한이 아니라 입력 폭발과 동일 웨이브 즉시 삭제를 방지하는 안전장치다.

## 10. 해금과 캠페인 도입

튜토리얼에서 네 능력을 모두 설명하지 않는다.

추천 도입:

- 튜토리얼: 바리케이드 또는 화살비 하나만 짧게 소개
- 정규 스테이지 1~2: 바리케이드·화살비
- 정규 스테이지 3: 역병
- 정규 스테이지 4 이후: 강화지대

스테이지 생성기는 해금되지 않은 명령을 필수 대응책으로 요구해서는 안 된다.

## 11. 제약 시스템 연결 후보

향후 제약 예시:

- 전술 명령 비용 증가
- 전역 재사용 대기시간 증가
- 특정 명령 사용 불가
- 스테이지당 최초 사용 비용 증가

정보를 숨기거나 사용 후 몰래 비용을 올리지 않고 시작 전에 공개한다.

## 12. UI 계약

전술 명령 패널은 다음을 표시한다.

- 금화 비용
- 현재 보유 금화와 사용 후 잔액
- 대상 가능 라인·지점
- 범위와 지속시간
- 예상 피해·강화·지연 효과
- 개별 재사용 대기시간
- 전역 재사용 대기시간
- 사용 불가 이유

전장에는 시전 위치, 발동까지 남은 시간과 효과 종료 시간을 표시한다.

## 13. 검증 시나리오

- 적이 접근하는 동안 바리케이드가 지정 지점에 생성된다.
- 바리케이드는 적을 지연하지만 영구 봉쇄하지 않는다.
- 화살비는 적 유닛에만 피해를 주고 적 건물에는 피해를 주지 않는다.
- 역병 두 개가 같은 대상에게 무한 피해 중첩을 만들지 않는다.
- 강화지대 두 개가 같은 유닛에게 중첩되지 않는다.
- 일시정지 중 예약한 명령은 금화를 중복 차감하지 않는다.
- 금화가 부족하면 명령을 확정할 수 없다.
- 같은 시드와 같은 명령 입력은 같은 결과를 만든다.
- 전역 재사용 대기 중 다른 명령을 즉시 연속 발동할 수 없다.

## 14. 남은 사용자 결정

1. 전술 명령을 항상 사용 가능하게 할지 상점에서 1회권을 구매하게 할지
2. 전역 재사용 대기시간 사용 여부와 초기값
3. 바리케이드가 아군도 막는지 적만 막는지
4. 화살비의 피해 방식과 보스 감소율
5. 역병의 지속 피해·치유 감소 비율
6. 강화지대의 강화 항목
7. 튜토리얼에서 소개할 첫 명령
8. 스테이지별 해금 순서

## 15. 승인 게이트

금화 소모형 일회성 전술 명령과 네 초기 후보는 승인된 방향이다. 정확한 비용·지속시간·재사용과 중첩 규칙은 조정 중이다. Codex는 별도 Plan Mode 구현 제안서와 사용자 승인 전에는 구현하지 않는다.
