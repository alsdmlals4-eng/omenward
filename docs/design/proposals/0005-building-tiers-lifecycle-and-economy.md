# 제안서 0005 — 건물 Tier, 생명주기와 경제 계약

- 상태: **사용자 조정안 대기**
- 구현 상태: 승인 전 구현 금지
- 관련 문서: `docs/GAME_DESIGN.md`, `docs/design/APPROVED_ECONOMY_BUILDS_AND_TERMINAL_ASSAULT.md`, `docs/DECISIONS_PENDING.md`

## 1. 목적

건설 노드를 선택한 순간부터 건물이 완공·업그레이드·파괴·철거되어 다시 빈 노드가 되기까지의 상태 전이를 고정한다.

Codex가 다음을 임의로 정하지 않게 하는 것이 목적이다.

- 건설과 업그레이드 중 시설이 작동하는지
- 적이 접근했을 때 진행도가 어떻게 되는지
- 건물 파괴가 자원·식량·생산·룰렛 토큰에 반영되는 시점
- 철거와 취소의 환불
- 수리 기능의 프로토타입 포함 여부
- Tier 1~3의 기능 차이
- 생산 완료 시 대기칸이 가득 찬 경우
- 시장·병영·포탑 사이의 투자 회수 구조

## 2. 추천 핵심 결정

1. 첫 프로토타입은 **고정형 3티어**를 사용하고 전문화 분기는 제외한다.
2. 건설·업그레이드 비용은 시작할 때 전액 지불한다.
3. 전방 노드에 적이 존재하면 새 건설을 시작할 수 없고, 진행 중 건설·업그레이드는 정지한다.
4. 업그레이드 중에는 이전 Tier 기능과 룰렛 토큰을 유지한다.
5. 적에게 파괴되면 15초 폐허 뒤 빈 노드로 돌아간다.
6. 수동 수리는 첫 프로토타입에서 제외하고 재건설을 기본 복구 방식으로 사용한다.
7. 건설 취소는 70%, 업그레이드 취소는 50%, 완공 건물 철거는 기본 건설비의 40%를 환불한다.
8. 성공적인 철거는 폐허를 남기지 않지만, 철거 중 파괴되면 폐허가 남는다.
9. 훈련시설의 완성 유닛은 공간 부족으로 사라지지 않고 시설 내부에 1개까지 대기한다.
10. 포탑은 프로토타입에서 전방 노드에만 건설하며 Tier 3에서만 중앙 접전지 가장자리에 제한적으로 영향을 준다.

## 3. 건물 상태 전이

```text
Empty
→ Constructing
→ ActiveTier1
→ UpgradingToTier2
→ ActiveTier2
→ UpgradingToTier3
→ ActiveTier3

Active 또는 Upgrading
→ Demolishing
→ Empty

Constructing / Active / Upgrading / Demolishing
→ Destroyed
→ Ruins
→ Empty
```

`UnderAttack`과 `ProgressPaused`는 별도 상태가 아니라 현재 상태에 붙는 플래그로 관리한다.

예시:

```text
state = Constructing
under_attack = true
progress_paused = true
```

## 4. 노드와 건설 가능 조건

### 4.1 노드 제한

- 한 노드에는 건물 하나만 존재할 수 있다.
- 후방 6개 노드: 농장, 시장, 훈련시설 건설 가능
- 라인별 전방 3개 노드: 농장, 시장, 훈련시설, 포탑 건설 가능
- 프로토타입에서는 후방 노드의 포탑 건설을 금지한다.
- 중앙 접전지에는 건설할 수 없다.
- 적은 노드를 점령하지 않고 건물만 파괴한다.

### 4.2 건설 시작 조건

다음을 모두 만족해야 한다.

- 노드가 `Empty`
- 필요한 금화를 보유
- 해당 노드에서 허용된 건물 종류
- 노드 위험 범위 안에 적 유닛이 없음
- 같은 노드에서 다른 명령이 진행 중이지 않음

여러 노드에서 동시에 건설·업그레이드하는 것은 허용한다. 별도 건설 일꾼이나 전역 건설 슬롯은 사용하지 않는다.

### 4.3 적 접근

- 적 유닛이 노드 위험 범위에 들어오면 새 건설·업그레이드를 시작할 수 없다.
- 이미 진행 중인 건설·업그레이드는 즉시 정지한다.
- 건물은 정지 중에도 공격받고 파괴될 수 있다.
- 적이 범위에서 사라진 뒤 2초 동안 다시 들어오지 않으면 진행을 재개한다.
- 후방 노드도 적이 본진 구역까지 침투하면 같은 규칙을 적용한다.

2초는 초기 데이터 가설이다.

## 5. 건설 계약

### 5.1 비용과 효과

- 건설 명령 확정 시 금화를 전액 지불한다.
- 건설 중에는 건물 효과, 생산, 룰렛 토큰, 식량 증가와 공격 기능이 없다.
- 건설 중 구조물은 목표가 될 수 있으며 최대 체력의 일부만 가진 상태로 시작해 진행도에 따라 체력이 증가한다.
- 완공 순간부터 효과와 룰렛 토큰을 제공한다.
- 완공된 건물은 다음 룰렛 회전의 스냅샷부터 반영한다.

### 5.2 초기 건설시간 가설

| 건물 | 건설시간 |
|---|---:|
| 포탑 | 4초 |
| 농장 | 6초 |
| 시장 | 8초 |
| 훈련시설 | 10초 |

신전·아카데미·도적 훈련소는 훈련시설 계열의 시간을 기본으로 사용한다.

### 5.3 건설 취소

- 플레이어가 직접 시작한 건설은 취소할 수 있다.
- 취소 시 지불 비용의 **70%**를 환불한다.
- 진행도와 피해량에 따른 추가 환불 계산은 하지 않는다.
- 취소한 노드는 즉시 `Empty`가 되며 폐허를 남기지 않는다.
- 적에게 파괴된 건설은 환불되지 않고 폐허가 남는다.

## 6. 업그레이드 계약

### 6.1 공통 규칙

- Tier 1 → 2, Tier 2 → 3 순서로만 상승한다.
- 업그레이드 명령 시 비용을 전액 지불한다.
- 업그레이드 중 건물은 **이전 Tier 기능을 계속 수행**한다.
- 시장 수입, 농장 식량, 훈련 생산, 포탑 공격과 룰렛 토큰을 유지한다.
- 새 Tier의 능력은 완료 순간 한 번에 적용한다.
- 업그레이드 중에도 피해를 받고 파괴될 수 있다.
- 적 접근 시 업그레이드 진행도만 정지하며 이전 Tier 기능은 유지한다.

### 6.2 비용·시간 곡선 초기 가설

| 단계 | 비용 | 시간 |
|---|---:|---:|
| Tier 1 건설 | 기본 건설비 | 기본 건설시간 |
| Tier 1 → 2 | 기본 건설비 × 1.5 | 기본 건설시간 × 0.75 |
| Tier 2 → 3 | 기본 건설비 × 2.25 | 기본 건설시간 × 1.0 |

소수 금화와 시간은 데이터 로딩 시 정수 또는 지정 단위로 반올림한다.

### 6.3 업그레이드 취소

- 업그레이드를 취소하면 건물은 즉시 이전 Tier의 정상 상태로 돌아간다.
- 현재 업그레이드 비용의 **50%**를 환불한다.
- 업그레이드 중 파괴되면 비용을 돌려받지 못한다.

## 7. Tier별 기능 추천

정확한 값은 초기 밸런스 가설이며 데이터에서 변경한다. 구조와 효과 종류를 먼저 고정한다.

### 7.1 농장

| Tier | 총 식량 증가량 | 추가 효과 |
|---|---:|---|
| 1 | +5 | 기본 보급 제공 |
| 2 | +8 | 내구도 증가 |
| 3 | +12 | 내구도 추가 증가 |

- 표의 값은 누적 추가량이다. Tier 2가 `+5+8`을 주는 것이 아니다.
- 농장은 룰렛 토큰을 제공하지 않는다.
- 농장 파괴로 현재 식량 사용량이 최대치를 넘더라도 출전 중 유닛을 제거하지 않는다.
- 식량 초과 상태에서는 새 유닛 출전만 막는다.

### 7.2 시장

Tier 1 시장 수입을 `1.0`으로 둔 정규화 가설:

| Tier | 금화 수입률 |
|---|---:|
| 1 | 1.0 |
| 2 | 1.6 |
| 3 | 2.4 |

- 시장 수입은 1초 단위로 정산한다.
- 여러 시장의 수입은 선형으로 합산하며 건물 수에 따른 감쇠는 사용하지 않는다.
- 시장 1동은 Tier와 관계없이 각 릴에 금화 토큰 1개만 제공한다.
- 시장 파괴 시 수입은 즉시 멈추고 다음 회전부터 토큰이 제거된다.

### 7.3 병종 훈련시설

초기 생산 가설:

| Tier | 기본 생산 |
|---|---|
| 1 | 60초마다 해당 병종 1성 병사 1명 |
| 2 | 45초마다 해당 병종 1성 병사 1명 |
| 3 | 35초마다 생산, 매 4번째 완성 유닛은 엘리트로 강화 |

- Tier 3 강화 주기 `4회`는 데이터 조정 항목이다.
- 훈련시설 1동은 Tier와 관계없이 각 릴에 대응 토큰 1개만 제공한다.
- 전방 시설은 해당 라인의 전방 거점에서 유닛을 출전시키거나 가까운 대기 지점으로 보낸다.
- 후방 시설은 본진 출발 지점을 사용한다.
- 전방 시설에 별도의 생산량·생산속도 보너스는 없다.

### 7.4 포탑

Tier 1을 `1.0`으로 둔 초기 비율:

| Tier | DPS | 최대 체력 | 사거리 역할 |
|---|---:|---:|---|
| 1 | 1.0 | 1.0 | 자기 전방 거점 접근로만 방어 |
| 2 | 1.45 | 1.35 | 거점 외곽 강화, 접전지 도달 불가 |
| 3 | 2.0 | 1.75 | 맵 조건에 따라 접전지 가장자리에 제한적 영향 |

- Tier 3도 중앙 접전지 전체를 덮어서는 안 된다.
- `MapTemplate` Validator가 모든 포탑 노드와 접전지 거리 계약을 검사한다.
- 포탑은 룰렛 토큰과 식량을 사용하지 않는다.
- 첫 프로토타입은 기본 단일 대상 원거리 포탑 1종으로 시작한다.
- 마법 광역 포탑은 후속 콘텐츠로 분리한다.

## 8. 생산 완료와 공간 부족

훈련시설은 생산 완료 유닛을 잃지 않는다.

```text
생산 타이머 완료
→ 대기칸 또는 지정 자동 출전 시도
→ 실패하면 시설 내부 Ready 슬롯에 1명 보관
→ Ready 슬롯이 비워질 때까지 다음 생산 타이머 정지
```

- 시설당 Ready 슬롯은 1개다.
- 대기칸이 가득 찼거나 식량이 부족하면 자동 출전이 실패할 수 있다.
- Ready 유닛은 플레이어가 대기칸 이동, 라인 출전 또는 판매로 정리한다.
- 시설이 파괴되면 아직 완료되지 않은 생산 진행도와 Ready 유닛은 소멸한다.
- 소멸 전 UI에서 위험 경고를 표시한다.

## 9. 파괴와 폐허

### 9.1 파괴 즉시 효과

건물 체력이 0이 되면:

- 생산·수입·공격·식량 효과 즉시 중단
- 업그레이드와 생산 진행도 소멸
- 시설 내부 Ready 유닛 소멸
- 다음 룰렛 회전부터 대응 토큰 제거
- 현재 진행 중인 룰렛 스냅샷은 변경하지 않음
- 노드는 `Ruins` 상태로 전환

### 9.2 폐허

- 기본 폐허 유지시간은 **15초**다.
- 폐허 동안 건설, 업그레이드, 철거와 수리를 할 수 없다.
- 폐허 타이머가 끝나면 자동으로 `Empty`가 된다.
- 적은 폐허 노드를 점령하지 않는다.
- 금화를 내고 폐허를 즉시 제거하는 기능은 프로토타입에서 제외한다.

## 10. 철거

완공된 건물을 다른 빌드로 교체하고 룰렛 토큰 구성을 바꾸기 위해 철거를 허용한다.

- 적이 노드 위험 범위 안에 있으면 철거를 시작할 수 없다.
- 철거시간 초기값은 5초다.
- 철거 시작 즉시 건물 효과, 공격, 생산과 룰렛 토큰을 비활성화한다.
- 철거는 시작 후 취소할 수 없다.
- 철거 중에도 적에게 공격받을 수 있다.
- 성공하면 기본 건설비의 **40%**를 환불하고 노드는 즉시 `Empty`가 된다.
- 업그레이드 비용은 환불하지 않는다.
- 철거 중 파괴되면 환불 없이 15초 폐허가 남는다.

철거는 자원 회수 수단보다 노드와 룰렛 확률을 재설계하는 수단으로 본다.

## 11. 수리 범위

첫 프로토타입에서는 수동 수리와 자동 체력 재생을 제외하는 것을 추천한다.

이유:

- 실시간 3라인 관리 중 수리 명령까지 추가하면 조작 부담이 커진다.
- 포탑 방어 빌드가 금화만으로 피해를 무한 복구해 전투가 늘어질 수 있다.
- 파괴, 폐허와 재건설의 의미가 약해진다.
- 수리 중단, 수리비, 피격 판정과 UI 상태가 추가된다.

대신 다음으로 완화한다.

- Tier 상승에 따른 내구도 증가
- 적 웨이브와 공성병의 사전 공개
- 전방 시설 보호를 위한 유닛·포탑 배치
- 파괴 후 15초 뒤 같은 노드에 재건설

후속 실험 후보:

- 전투가 없는 동안만 가능한 유료 정비
- 상점의 일회성 긴급 수리 아이템
- 스테이지 사이의 완전 복구

## 12. 경제 기본 비율

Tier 1 시장을 경제 기준 `1.0`으로 둔다.

- 플레이어 기본 수입: Tier 1 시장의 약 25~35%
- 중앙 접전지 하나: Tier 1 시장의 약 50~60%
- 시장: Tier에 따라 1.0 / 1.6 / 2.4
- 기본 수입은 모든 시장이 파괴되어도 최소 복구 가능성을 보장한다.
- 접전지 수입은 시장을 대체하지 않으며 접전 중에는 정지하는 방향을 유지한다.
- 금화는 음수가 될 수 없으며 대출·부채는 프로토타입에서 제외한다.

### 12.1 건설비 초기 가설

| 건물 | Tier 1 비용 |
|---|---:|
| 포탑 | 12 |
| 농장 | 15 |
| 시장 | 20 |
| 훈련시설 | 25 |

이 숫자는 구조적 우선순위를 표현하는 초기값이다.

```text
포탑 < 농장 < 시장 < 훈련시설
```

시장 특화의 고수익은 유지하되 노드 점유, 식량, 용병 소비와 결전 웨이브로 균형을 잡는다.

## 13. UI 계약

건설 노드와 건물 패널은 최소 다음을 보여준다.

- 현재 상태: 빈 노드, 건설 중, 활성, 업그레이드 중, 철거 중, 폐허
- 현재·최대 체력과 피격 경고
- 진행도와 정지 이유
- 현재 Tier와 다음 Tier 효과 비교
- 비용, 시간과 환불액
- 생산 타이머와 Ready 유닛
- 현재 룰렛 토큰 기여
- 건설 또는 철거 후 예상 토큰 구성·확률 변화
- 농장 파괴 시 예상 식량 초과량
- 포탑 현재 사거리와 다음 Tier 사거리 오버레이
- 폐허 남은 시간

## 14. 검증 시나리오

- 건설 중인 시장은 수입과 금화 토큰을 제공하지 않는다.
- 완공된 시장은 다음 회전부터 금화 토큰을 제공한다.
- 업그레이드 중인 시장은 이전 Tier 수입과 토큰을 유지한다.
- 적이 접근하면 진행도가 멈추고 2초 안전 후 재개한다.
- 건설 취소는 70%, 업그레이드 취소는 50%를 환불한다.
- 성공 철거는 기본 건설비 40%를 환불하고 폐허를 남기지 않는다.
- 적에게 파괴된 건물은 환불 없이 15초 폐허를 남긴다.
- 농장 파괴로 식량 초과가 되어도 출전 유닛은 사라지지 않는다.
- 대기칸이 가득 차면 훈련시설 Ready 슬롯에서 생산이 멈춘다.
- 시설 파괴 시 Ready 유닛과 생산 진행도는 제거된다.
- Tier 상승만으로 룰렛 토큰 수가 증가하지 않는다.
- Tier 2 포탑은 접전지에 닿지 않는다.
- Tier 3 포탑은 접전지 전체를 덮지 않는다.
- 수리 명령과 자동 체력 재생은 존재하지 않는다.

## 15. 사용자 조정이 필요한 핵심 항목

1. 후방 노드의 포탑 건설 금지
2. 업그레이드 중 이전 Tier 기능 유지
3. 건설·업그레이드 취소 환불 70% / 50%
4. 완공 건물 철거 환불: 기본 건설비의 40%, 업그레이드비 환불 없음
5. 폐허 기본 15초
6. 수동 수리와 자동 체력 재생 제외
7. 농장 식량 +5 / +8 / +12
8. 시장 수입 1.0 / 1.6 / 2.4
9. 훈련시설 60초 / 45초 / 35초, Tier 3 매 4번째 엘리트
10. 포탑 Tier 3에서만 접전지 가장자리 제한 지원
11. 시설당 완성 유닛 Ready 슬롯 1개
