# 제안서 0005 — 건물 Tier, 생명주기와 선택형 전문화

- 상태: **핵심 방향 부분 승인 / 세부 수치 조정 대기**
- 구현 상태: 승인 전 구현 금지
- 승인 원본: `docs/design/APPROVED_BUILDING_SPECIALIZATION_AND_TACTICAL_COMMANDS.md`
- 관련 문서: `docs/GAME_DESIGN.md`, `docs/DECISIONS_PENDING.md`

## 1. 목적

건설 노드를 선택한 순간부터 건물이 완공·전문화·파괴·철거되어 다시 빈 노드가 되기까지의 상태 전이와 예외 처리를 고정한다.

이번 사용자 조정으로 기존 추천안의 다음 두 항목은 폐기한다.

- 적 접근 시 건설·업그레이드 정지
- 완전 고정형 Tier 1~3 성장

대신 다음 방향을 사용한다.

- 적이 있어도 건설·업그레이드 진행
- Tier 1 공통 기능, Tier 2 전문화, Tier 3 전문화 심화
- 기본 병영은 Tier 2에서 기병·창병·궁병 중 하나로 전환
- 생산 강화, 토큰 증폭과 포탑 역할 분기를 허용

## 2. 현재 승인된 핵심

1. 적 유닛이 주변에 있어도 새 건설과 업그레이드를 시작할 수 있다.
2. 피격 중에도 건설·업그레이드 진행도는 멈추지 않는다.
3. 건설 중 구조물은 공격받아 완공 전에 파괴될 수 있다.
4. 건물은 3티어를 유지하되 Tier 2부터 선택형 전문화를 사용한다.
5. 토큰 증폭 전문화는 대응 토큰 1개를 랜덤으로 정해진 릴 하나에만 추가한다.
6. 기본 병영 Tier 1은 검사 생산·검사 토큰이다.
7. 기본 병영 Tier 2는 기병·창병·궁병 중 하나를 선택해 생산 유닛과 기본 토큰을 함께 교체한다.
8. 포탑은 제압·요새·장거리 방향을 가질 수 있다.
9. 업그레이드 중에는 이전 Tier 기능과 기존 토큰을 유지한다.
10. 전문화 효과는 업그레이드 완료 순간부터 적용한다.

## 3. 건물 상태 전이

```text
Empty
→ Constructing
→ ActiveTier1
→ UpgradingToTier2
→ ActiveTier2Specialized
→ UpgradingToTier3
→ ActiveTier3Mastered

Active 또는 Upgrading
→ Demolishing
→ Empty

Constructing / Active / Upgrading / Demolishing
→ Destroyed
→ Ruins
→ Empty
```

`UnderAttack`은 진행 정지 상태가 아니라 현재 상태에 붙는 표시다.

```text
state = Constructing
under_attack = true
progress_paused = false
```

## 4. 노드와 건설 가능 조건

### 4.1 기본 조건

- 한 노드에는 건물 하나만 존재할 수 있다.
- 후방 6개 노드와 라인별 전방 3개 노드를 사용한다.
- 중앙 접전지에는 건설하지 않는다.
- 여러 노드에서 동시에 건설·업그레이드할 수 있다.
- 별도 건설 일꾼과 전역 건설 슬롯은 사용하지 않는다.

### 4.2 적이 있는 상태의 건설

건설 시작 조건에서 `주변 적 없음`을 제거한다.

- 적이 노드 주변에 있어도 건설 명령 가능
- 적이 건설 예정 위치를 통과하거나 공격 중이어도 진행
- 건설 중 구조물은 즉시 공격 가능한 목표
- 완공 전에는 어떤 기능도 활성화되지 않음
- 체력이 0이 되면 건설 실패, 환불 없음, 폐허 생성
- 살아남아 완공되면 해당 틱부터 포탑 공격·생산·경제·식량 효과 활성화

### 4.3 건설 중 체력 추천 구조

아슬아슬한 완공은 허용하되 값싼 길막 악용은 막아야 한다.

추천 가설:

```text
건설 시작 현재 체력 = 완공 최대 체력의 20%
건설 진행에 따라 현재 체력과 허용 최대 체력이 선형 증가
완공 시 남은 체력 비율을 유지한 채 완공 최대 체력 적용
```

예를 들어 완공 최대 체력이 100이고 50% 진행 시 허용 최대 체력이 60이라면, 피해받지 않은 구조물은 체력 60을 가진다. 정확한 곡선은 데이터로 조정한다.

건설 중 구조물이 완성 건물과 같은 강한 길막 판정을 가져서는 안 된다. 충돌 크기와 적 통과 규칙은 전투 제안에서 확정한다.

## 5. 건설·업그레이드 비용과 취소

기존 초기 가설을 유지한다.

| 행동 | 추천 처리 |
|---|---|
| 건설 시작 | 비용 전액 선불 |
| 건설 취소 | 지불 비용 70% 환불 |
| 업그레이드 시작 | 비용 전액 선불 |
| 업그레이드 취소 | 해당 업그레이드비 50% 환불 |
| 적에 의한 파괴 | 환불 없음 |
| 완공 건물 철거 | 기본 건설비 40% 환불 |

환불률은 아직 사용자 최종 승인 대상이다.

## 6. 업그레이드 공통 계약

```text
Tier 1: 공통 기능
→ Tier 2: 전문화 선택
→ Tier 3: 선택한 전문화 심화 또는 건물 전용 교리 선택
```

- 업그레이드 중에는 이전 Tier 기능이 계속 작동한다.
- 시장 수입, 농장 식량, 훈련 생산, 포탑 공격과 기존 토큰을 유지한다.
- 업그레이드 중에도 공격받고 파괴될 수 있다.
- 적 피격은 업그레이드 진행을 멈추지 않는다.
- 완료 순간 새 전문화 효과를 적용한다.
- 전문화는 기본적으로 해당 건물이 파괴·철거될 때까지 변경할 수 없다.
- 전문화 변경은 철거 후 재건설을 기본 방식으로 한다.

## 7. 토큰 증폭 전문화

기본 토큰 제공 건물은 세 릴에 대응 토큰 1개씩을 제공한다.

`토큰 증폭` 전문화는 다음 효과를 추가한다.

```text
기본: Reel 1 +1 / Reel 2 +1 / Reel 3 +1
전문화: 위 기본 구성 + 랜덤으로 정해진 릴 하나에 +1
```

계약:

- 보너스 토큰은 한 릴에만 추가된다.
- 릴은 스테이지 시드와 건물 인스턴스를 사용해 결정한다.
- 결과는 건물 수명 동안 고정되고 공개된다.
- 매 회전마다 새로 추첨하지 않는다.
- 파괴·철거 시 다음 회전부터 제거한다.
- 전문화 선택 전에 정확히 어느 릴에 추가될지와 확률 변화를 보여준다.

Tier 3 토큰 교리는 보너스 토큰을 하나 더 제공할 수 있지만, 같은 릴 중첩 또는 다른 릴 우선 여부는 미확정이다.

## 8. 생산 유닛 강화 전문화

생산시설은 생산속도 외에 생산 유닛 자체를 강화할 수 있다.

추천 후보:

- 공격 훈련: 공격력 또는 공격속도 증가
- 생존 훈련: 체력 또는 방어 증가
- 기동 훈련: 이동속도 또는 전선 합류 성능 증가

계약:

- 효과는 해당 시설에서 전문화 완료 후 생산된 유닛에만 적용한다.
- 기존 유닛과 상점 용병에는 소급 적용하지 않는다.
- 생산 시 출처 건물과 강화 ID를 유닛 데이터에 기록한다.
- 생산 건물이 파괴돼도 이미 생산된 유닛의 강화는 유지한다.

## 9. 기본 병영 전문화

### 9.1 Tier 1 공통 병영

- 생산 병종: 검사
- 룰렛 토큰: 검사
- 역할: 초반 전열과 공통 시작점

### 9.2 Tier 2 병종 전환

다음 세 가지 중 하나를 선택한다.

| 전문화 | 생산 유닛 | 세 릴 기본 토큰 |
|---|---|---|
| 기병 병영 | 기병 | 기병 |
| 창병 병영 | 창병 | 창병 |
| 궁병 병영 | 궁병 | 궁병 |

업그레이드 완료 시:

- 다음 생산부터 선택 병종을 생산한다.
- 기존 검사 토큰 3개를 선택 병종 토큰 3개로 교체한다.
- 이미 생산된 검사는 그대로 유지한다.
- 현재 룰렛 스냅샷은 유지하고 다음 회전부터 반영한다.
- 생산 진행률은 보존하고 업그레이드 완료 뒤 처음 완성되는 유닛부터 새 병종을 적용한다.

### 9.3 Tier 3 교리 추천

선택 병종을 유지한 채 다음 중 하나를 선택한다.

1. **대량생산** — 생산 간격 감소
2. **정예훈련** — 생산 유닛 강화 또는 일정 주기마다 엘리트 생산
3. **토큰 증폭** — 선택 병종 토큰 1개를 고정된 랜덤 릴 하나에 추가

각 병종의 Tier 3 수치와 고유 효과는 다음 조정 단계에서 확정한다.

## 10. 포탑 전문화

Tier 1은 기본 단일 대상 원거리 포탑이다.

Tier 2에서 다음 중 하나를 선택한다.

| 방향 | 역할 |
|---|---|
| 제압형 | 작은 범위 피해 또는 추가 대상 공격 |
| 요새형 | 체력·방어·피격 저항 강화 |
| 장거리형 | 사거리 강화 |

Tier 3은 선택한 방향을 심화한다.

- 제압형: 범위 또는 최대 대상 수 증가
- 요새형: 내구도와 방어 성능 추가 증가
- 장거리형: 접전지 가장자리에 제한 지원

장거리형이 아닌 포탑은 접전지에 닿지 않는다. 장거리형 Tier 3도 접전지 전체를 덮지 않는다.

## 11. 농장과 시장 전문화 방향

정확한 목록은 미확정이지만 다음 카테고리를 사용한다.

### 농장 후보

- 보급량 증가
- 시설 내구도 증가
- 출전·재배치 관련 물류 보조

### 시장 후보

- 정기 수입 증가
- 금화 토큰 증폭
- 전술 명령 또는 상점 소비 효율 강화

시장 전문화가 금화 룰렛과 용병·전술 명령을 모두 과도하게 강화하지 않도록 한 건물에서 모든 경제 효과를 동시에 얻지 못하게 한다.

## 12. 생산 완료와 Ready 슬롯

기존 추천을 유지한다.

```text
생산 완료
→ 대기칸 또는 자동 출전 시도
→ 실패하면 시설 내부 Ready 슬롯 1개에 보관
→ 슬롯을 비울 때까지 다음 생산 정지
```

- Ready 유닛은 대기칸 이동, 즉시 출전 또는 판매 가능
- 시설 파괴 시 생산 진행도와 Ready 유닛 소멸
- 소멸 위험을 UI로 경고

Ready 슬롯 수는 아직 최종 승인되지 않았다.

## 13. 파괴·폐허·철거·수리

기존 추천안:

- 적에게 파괴되면 효과·생산·토큰 즉시 중단
- 기본 폐허 15초
- 성공 철거는 폐허 없음
- 철거 중 파괴되면 환불 없이 폐허 발생
- 첫 프로토타입에서 수동 수리와 자동 체력 재생 제외

이번 변경으로 건설·업그레이드 중 파괴 위험이 커지므로 폐허시간과 환불률은 함께 플레이테스트해야 한다.

## 14. UI 필수 정보

- 건설·업그레이드 남은 시간
- 피격 중에도 진행된다는 표시
- 건설 중 현재 체력과 완공 예상 체력
- Tier 2 전문화 3개 비교
- 선택 후 생산 유닛·토큰·확률 변화
- 토큰 증폭 대상 릴
- 병영 생산 병종 변경 시점
- 포탑 전문화별 사거리·범위·내구도 오버레이
- 현재 전문화와 변경 불가 안내

## 15. 검증 시나리오

- 적이 전방 노드 주변에 있어도 포탑 건설을 시작할 수 있다.
- 피격 중인 포탑 건설 진행도가 계속 증가한다.
- 포탑이 완공 전 파괴되면 공격하지 못하고 폐허가 된다.
- 포탑이 살아남아 완공되면 즉시 공격 가능 상태가 된다.
- 업그레이드 중 시장은 이전 수입과 토큰을 유지한다.
- 병영 Tier 2 완료 전에는 검사 생산·검사 토큰을 유지한다.
- 병영 Tier 2 완료 후 다음 회전에서 선택 병종 토큰으로 교체된다.
- 기존 검사 유닛은 병종 전환으로 바뀌지 않는다.
- 토큰 증폭 릴은 건물 수명 동안 바뀌지 않는다.
- 같은 시드와 건물 인스턴스는 같은 보너스 릴을 선택한다.
- 장거리형이 아닌 포탑은 접전지에 닿지 않는다.

## 16. 남은 사용자 결정

1. 건설 중 시작 체력과 체력 증가 곡선
2. 건설 중 구조물의 길막 여부
3. Tier 2 전문화의 비용을 동일하게 할지 효과별로 다르게 할지
4. Tier 3에서 같은 방향 고정 심화만 허용할지 세 교리 선택을 허용할지
5. 병영 Tier 3 교리 수치
6. 농장과 시장의 정확한 전문화 3종
7. 토큰 증폭 Tier 3의 추가 토큰 배치 규칙
8. Ready 슬롯, 환불, 폐허, 수리 기존 추천안
9. 후방 포탑 허용 여부

## 17. 승인 게이트

전투 중 건설 지속, 선택형 전문화, 병영 병종 전환과 토큰 교체는 승인된 방향이다. 나머지 수치와 세부 효과는 조정 중이다. Codex는 별도 Plan Mode 구현 제안서와 사용자 승인 전에는 Godot 코드, Scene, Resource, 데이터와 테스트를 만들지 않는다.
