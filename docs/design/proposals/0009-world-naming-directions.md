## 1. 명명 목표

고유명사는 다음 조건을 만족해야 한다.

- 최전선 방어와 군사적 긴장감이 느껴짐
- `경계의 율`, 징조, 축복·저주와 어울림
- 요정형 마스코트 율비와 함께 있어도 지나치게 음울하지 않음
- 첫 10분에 여러 이름을 들어도 혼동되지 않음
- 한국어로 발음하기 쉽고 영어 표기도 어렵지 않음
- 특정 기존 판타지 작품의 고유명사를 직접 연상시키지 않음

첫 10분에는 이름을 최대 세 개만 노출한다.

1. 요새명
2. 괴물 영역의 통칭
3. 경계 현상의 명칭 `경계의 율`

국가명과 인간 생활권의 세부 명칭은 튜토리얼 종료 뒤 노출할 수 있다.

## 2. 추천안 A — 빛·종·무명

최전선의 어두운 긴장과 율비의 밝은 이미지가 가장 자연스럽게 공존하는 방향이다.

| 대상 | 이름 | 영문 가안 | 의미·용도 |
|---|---|---|---|
| 국가 | 루메른 왕국 | Kingdom of Lumern | 빛을 연상하지만 지나치게 성스러운 국가는 아님 |
| 인간 생활권 | 등화권 | Lamplit Reach | 인간의 불빛이 유지되는 영역 |
| 최전선 요새 | 은종성채 | Silverbell Bastion | 오래된 경계종과 율비의 기원을 연결 |
| 경계 통로 | 삼문경계 | Three-Gate Boundary | 상·중·하 세 라인을 세계관에 번역 |
| 괴물 외부 영역 | 무명야 | The Nameless Wild | 인간이 이름 붙이지 못한 어두운 외부 영역 |
| 적 공식 분류 | 외경종 | Outer-Bound Beasts | 경계 바깥에서 넘어오는 생물 |
| 병사들의 통칭 | 너머것들 | The Beyondkin / Things Beyond | 현장감 있는 짧은 표현 |
| 방위 조직 | 경계군 | Boundary Host | 최전선 요새와 경계선을 지키는 군대 |
| 공세 공식명 | 월경 공세 | Boundary Breach | 웨이브의 세계관식 표현 |
| 전조 | 경계의 징조 | Boundary Omen | 현재 승인 용어 유지 |

### 장점

- 은종성채와 율비의 `경계종 울림` 기원이 직접 연결된다.
- 등화권 대 무명야의 대비가 직관적이다.
- 삼문경계가 세 라인을 자연스럽게 설명한다.
- `루메른`, `은종`, `무명야`의 발음과 이미지가 서로 다르게 기억된다.
- 귀여운 율비와 진지한 전장을 모두 수용한다.

### 첫 30초 예시

> 율비: 지휘관, 은종성채의 상단 경계가 울려요.

> 율비: 무명야 쪽에서 전사형 넷. 도달까지 30초예요.

### 암시 대사

> 은종은 무명야가 열리기 전에 먼저 울려요. 왜 그런지는… 저도 몰라요.

> 등화권의 불빛은 여기서 끝나요. 저 선을 넘기면 이름 없는 땅이에요.

## 3. 후보안 B — 군사·기록·번호

전쟁 기록과 방어선의 냉혹함을 강조하는 방향이다.

| 대상 | 이름 | 영문 가안 | 의미·용도 |
|---|---|---|---|
| 국가 | 발테른 왕국 | Kingdom of Valtern | 단단한 군사 국가 이미지 |
| 인간 생활권 | 내경권 | Inner Boundary | 경계 안쪽의 공식 행정 용어 |
| 최전선 요새 | 제7경계요새 | Seventh Boundary Fortress | 수많은 전선 중 하나라는 압박 |
| 경계 통로 | 삼중 관문 | Triple Gate | 세 라인 구조 |
| 괴물 외부 영역 | 외경 | The Outer Boundary | 차갑고 기능적인 통칭 |
| 적 공식 분류 | 월경체 | Breach Entities | 군사 보고용 분류 |
| 병사들의 통칭 | 바깥것 | Outsiders | 짧고 거친 현장 용어 |
| 방위 조직 | 경계수비군 | Boundary Defense Corps | 현실적인 군대 느낌 |

### 장점

- 플레이어의 지휘관 역할과 전시 분위기가 강하다.
- UI와 군사 보고 문구를 만들기 쉽다.
- 절차적 스테이지를 다른 번호 요새로 확장하기 쉽다.

### 단점

- 율비와 축복·저주의 신비로운 분위기가 약해질 수 있다.
- 고유명사가 아니라 기능 명칭처럼 느껴질 위험이 있다.

## 4. 후보안 C — 새벽·꿈·숲

요정과 신비로운 율을 가장 강하게 강조하는 동화적 다크 판타지 방향이다.

| 대상 | 이름 | 영문 가안 | 의미·용도 |
|---|---|---|---|
| 국가 | 아우렐리아 왕국 | Kingdom of Aurelia | 새벽빛과 황금빛 문명 |
| 인간 생활권 | 새벽뜰 | Dawnward | 인간이 지키는 밝은 영역 |
| 최전선 요새 | 마지막 종루 | Last Belfry | 종과 최후 방어선 강조 |
| 경계 통로 | 세 갈래 문 | Threefold Gate | 동화적 표현 |
| 괴물 외부 영역 | 잠들지 않는 숲 | The Sleepless Wildwood | 괴물과 신비가 섞인 영역 |
| 적 공식 분류 | 악몽종 | Nightmare Beasts | 저주·꿈 이미지 |
| 병사들의 통칭 | 꿈먹이 | Dream-Eaters | 강한 개성 |
| 방위 조직 | 새벽수호대 | Dawn Guard | 영웅적 조직 |

### 장점

- 율비의 요정형 디자인과 매우 잘 어울린다.
- 마케팅 이미지와 동화적 비주얼 정체성이 강하다.

### 단점

- 최전선 지휘관과 군사 전략의 무게가 약해질 수 있다.
- 괴물이 숲·꿈 계열로 제한되어 보일 위험이 있다.
- 현재의 건물·병영·포탑 중심 전투보다 마법 모험물처럼 느껴질 수 있다.

## 5. 최종 추천

**추천안 A — 빛·종·무명**을 우선한다.

추천 이유:

```text
은종성채
→ 율비의 경계종 기원
→ 첫 전조의 종소리
→ 지휘관이 지키는 구체적 장소

등화권
↔ 무명야
→ 인간 문명과 괴물 영역의 즉각적인 대비

삼문경계
→ 상·중·하 세 라인의 자연스러운 세계관 번역
```

A안은 게임의 세 핵심 톤을 동시에 만족한다.

1. 최전선 전쟁의 무게
2. 경계의 율이 주는 미스터리
3. 율비가 주는 밝고 친근한 이미지

## 6. A안 적용 시 첫 10분 명칭 노출

### 0:00

화면 지역명:

```text
은종성채
루메른 왕국 최외곽 방위선
```

율비:

> 지휘관, 은종성채의 경계가 울려요.

### 첫 웨이브

웨이브 카드:

```text
무명야 월경 공세
상단 / 전사형 4 / 30초
```

율비:

> 무명야 쪽에서 전사형 넷. 상단으로 와요.

### 첫 10분 종료

율비:

> 은종성채는 버텼어요. 하지만 무명야의 징조는 더 커지고 있어요.

국가명 `루메른`과 생활권 `등화권`은 종료 카드 또는 다음 스테이지 브리핑에서 처음 강조한다.

## 7. 추가 명명 규칙

### 인간 측

- 밝음·불빛·종·성벽·기록 이미지 사용
- 2~4음절 한국어 발음 우선
- 지나치게 성스럽거나 천사적인 이름은 제한

예시 어근:

```text
루메 / 벨 / 은종 / 등화 / 성채 / 경계 / 기록 / 새벽
```

### 괴물 측

- 정확히 이해되지 않음, 이름 없음, 바깥, 침식 이미지 사용
- 종족 이름은 외형 또는 전장 역할에서 파생
- 모든 괴물을 악몽·언데드 한 계열로 제한하지 않음

예시:

```text
무명 / 외경 / 너머 / 침식 / 공허 / 잔향 / 이형
```

### 스테이지

```text
[요새·지역명] + [율의 선언 또는 사건]
```

예시:

- 은종성채 — 첫 울림
- 회색관문 — 메마른 율
- 등불고개 — 붉은 달
- 폐종루 — 돌아오지 않은 공세
