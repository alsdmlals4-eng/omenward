# 세계관 고유명사 방향 제안

- 상태: **기존 한자어·번역풍 세트 보류 / 영문풍 통일안으로 재검토**
- 작성일: 2026-07-14
- 후속 제안서:
  - `docs/design/proposals/0010-english-world-names-and-game-title.md`

기존 `루메른 왕국 / 등화권 / 은종성채 / 삼문경계 / 무명야` 조합은 국가명만 영문 판타지풍이고 나머지는 한자어·번역풍이라 같은 문화권의 고유명사처럼 들리지 않는 문제가 있다.

따라서 이 문서의 A·B·C안은 참고 기록으로만 유지하며, 실제 선택은 후속 제안서 `0010-english-world-names-and-game-title.md`의 영문풍 통일안을 기준으로 진행한다.

## 기존 추천안 기록

| 대상 | 기존 이름 |
|---|---|
| 국가 | 루메른 왕국 |
| 인간 생활권 | 등화권 |
| 첫 최전선 요새 | 은종성채 |
| 세 라인 경계 | 삼문경계 |
| 괴물 외부 영역 | 무명야 |
| 적 공식 분류 | 외경종 |
| 병사 통칭 | 너머것들 |
| 방위 조직 | 경계군 |
| 적 공세 | 월경 공세 |

## 변경 방향

다음 요소는 유지한다.

- 국가 핵심 어근 `Lumern`
- 종·경계·세 라인·미지의 외부 영역이라는 의미 구조
- 율비의 경계종 기원과 첫 요새 연결
- 첫 10분에는 요새명·외부 영역명·경계의 율만 우선 노출

다음 요소는 변경한다.

- 한자어·고유어 중심 고유명사를 영문 판타지풍 고유명으로 통일
- 한국어판에서도 음차 표기를 기본으로 사용
- 게임 타이틀 변경안과 세계관 명칭을 함께 검토

후속 추천:

```text
Kingdom of Lumern
Silverbell Bastion
Threegate Front
The Veilwilds
Beyondborn
Frontier Wardens
```

게임명 최우선 후보:

```text
OMENWARD
```

세부 비교와 대체 후보는 후속 제안서에서 관리한다.
