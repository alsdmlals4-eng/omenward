# 영문풍 세계관 명칭과 게임 타이틀 변경안

- 상태: **제안 단계 / 사용자 선택 대기**

## 1. 변경 목표

기존 `루메른 왕국`은 영문 판타지풍인데 `등화권`, `은종성채`, `삼문경계`, `무명야`는 한자어·고유어 번역풍이라 한 세트로 들었을 때 결이 갈린다.

새 명명안은 다음을 목표로 한다.

- 모든 주요 고유명사가 같은 영문 판타지 세계에서 나온 것처럼 들림
- 한국어 표기는 음차를 기본으로 하고 필요할 때만 짧은 설명을 병기
- 첫 10분에 이름 세 개를 들어도 서로 혼동되지 않음
- 율비의 밝고 귀여운 이미지와 최전선 전쟁의 긴장감을 함께 수용
- 국가명·요새명·괴물 영역명이 로고와 마케팅 문구에 사용 가능

## 2. 국가명

### 최우선 추천 — `Lumern`

- 한국어: `루메른`
- 공식 표기: `Kingdom of Lumern`
- 짧은 표기: `Lumern`
- 형용사형: `Lumernian`

`루메른`은 현재 이름을 유지하면서도 영어 문장 안에 자연스럽게 들어간다.

```text
The Kingdom of Lumern
Lumernian Frontier Command
The Last Bastion of Lumern
```

`Lumeria`처럼 흔한 판타지 국가형 접미사를 붙이지 않고 `Lumern` 자체를 고유명으로 유지한다.

## 3. 추천 세계관 명칭 세트 A — `Lumern Frontier`

가장 추천하는 통일안이다.

| 대상 | 영문 이름 | 한국어 표기 | 용도 |
|---|---|---|---|
| 국가 | Kingdom of Lumern | 루메른 왕국 | 인간 문명의 중심 국가 |
| 인간 생활권 | Lamplight Reach | 램플라이트 리치 | 인간의 불빛이 유지되는 영역 |
| 첫 요새 | Silverbell Bastion | 실버벨 배스천 | 율비와 오래된 경계종의 기원 |
| 세 라인 전선 | Threegate Front | 쓰리게이트 프론트 | 상·중·하 세 통로의 전선 |
| 괴물 영역 | The Veilwilds | 베일와일즈 | 경계 너머 안개와 미지의 야생 |
| 적 공식 분류 | Beyondborn | 비욘드본 | 경계 너머에서 넘어온 생물 |
| 병사 통칭 | The Beyond | 더 비욘드 | 현장에서 쓰는 짧은 통칭 |
| 방위 조직 | Frontier Wardens | 프론티어 워든즈 | 요새와 경계를 지키는 군단 |
| 적 공세 | Breach Wave | 브리치 웨이브 | 웨이브의 세계관식 명칭 |
| 전조 | Boundary Omen | 바운더리 오멘 | 경계의 징조 영문식 표현 |
| 경계 법칙 | The Boundary Law | 바운더리 로 | `경계의 율` 공식 영문명 |

### 추천 이유

```text
Lumern
→ 국가 브랜드

Silverbell Bastion
→ 율비·종·첫 요새의 기억점

Threegate Front
→ 세 라인 전투를 즉시 이해

The Veilwilds
→ 괴물 종류를 숲·악몽 한 계열로 제한하지 않는 미지의 영역
```

각 이름의 첫 음절과 길이가 달라 첫 10분에도 구분하기 쉽다.

### 첫 30초 예시

> 율비: 지휘관, 실버벨 배스천의 경계가 울려요.

> 율비: 베일와일즈에서 비욘드본 넷. 상단 게이트로 와요.

웨이브 카드:

```text
BREACH WAVE
THREEGATE FRONT — UPPER GATE
Beyondborn ×4 / 30s
```

## 4. 대체 세트 B — 조금 더 군사적인 방향

| 대상 | 영문 이름 | 한국어 표기 |
|---|---|---|
| 국가 | Kingdom of Lumern | 루메른 왕국 |
| 인간 생활권 | Inner Reach | 이너 리치 |
| 첫 요새 | Bellwatch Keep | 벨워치 킵 |
| 세 라인 전선 | Trigate Line | 트라이게이트 라인 |
| 괴물 영역 | Outer Veil | 아우터 베일 |
| 적 분류 | Breachborn | 브리치본 |
| 방위 조직 | Lumern Border Corps | 루메른 보더 코어 |
| 적 공세 | Incursion | 인커전 |

장점:

- 군사 보고와 UI에 잘 맞는다.
- 절차적 스테이지를 `Bellwatch`, `Ashwatch`, `Dawnwatch`처럼 확장하기 쉽다.

단점:

- 율비의 요정·종·축복·저주 분위기가 세트 A보다 약하다.

| 대상 | 영문 이름 | 한국어 표기 |
|---|---|---|
| 국가 | Crown of Lumern | 루메른 크라운 |
| 인간 생활권 | Everlight Reach | 에버라이트 리치 |
| 첫 요새 | Silverchime Keep | 실버차임 킵 |
| 세 라인 전선 | Threefold Gate | 쓰리폴드 게이트 |
| 괴물 영역 | Hollowwild | 할로우와일드 |
| 적 분류 | Gloamborn | 글롬본 |
| 방위 조직 | Bellwardens | 벨워든즈 |
| 적 공세 | Omen Tide | 오멘 타이드 |

장점:

단점:

- 병영·포탑·전선 지휘의 군사성이 약해질 수 있다.

## 6. 게임 타이틀 변경 기준

타이틀은 다음 네 가지 중 최소 세 가지를 전달해야 한다.

1. 경계와 최전선 방어
2. 징조·운명·룰이라는 미스터리
3. 룰렛으로 전력을 얻는 핵심 시스템
4. 율비·종·요새의 독자적인 브랜드

`Roulettebound`는 룰렛 핵심은 즉시 전달하지만 카지노·슬롯 게임 인상이 강하고 세계관의 경계·지휘관 판타지가 약하다.

## 7. 게임명 후보

### 1순위 — `Omenward`

- 한국어: `오멘워드`
- 의미: 징조를 읽고 전선을 지키는 자들 / 징조에 맞서 세운 방벽
- 장점:
  - `Boundary Omen`과 `Frontier Wardens`를 한 단어로 압축
  - 웨이브 전조와 방어 게임성을 함께 전달
  - 어둡지만 과도하게 음울하지 않음
  - 확장 부제 사용이 쉬움

권장 전체 표기:

```text
OMENWARD
The Lumern Frontier
```

또는:

```text
OMENWARD: Silverbell Bastion
```

### 2순위 — `Bellward`

- 한국어: `벨워드`
- 의미: 경계종의 울림을 따라 요새를 지키는 존재
- 장점:
  - 율비와 실버벨 배스천을 강하게 브랜드화
  - 귀여운 마스코트와 다크 판타지의 균형이 좋음
  - 짧고 로고화하기 쉬움
- 단점:
  - 룰렛·징조 시스템이 제목만으로는 덜 보임

권장 부제:

```text
BELLWARD: Omen of the Frontier
```

### 3순위 — `Wheelward`

- 한국어: `휠워드`
- 의미: 운명의 바퀴와 방어를 결합
- 장점:
  - 룰렛 핵심 시스템을 은유적으로 포함
  - `Roulette`보다 카지노 인상이 약함
  - 독창적인 조어
- 단점:
  - 차량·바퀴 게임으로 오해할 가능성

### 4순위 — `Omenfront`

- 한국어: `오멘프론트`
- 의미: 징조가 나타나는 최전선
- 장점:
  - 전선과 웨이브 전조가 직관적
  - 전략 게임 제목처럼 들림
- 단점:
  - 마스코트와 룰렛의 개성이 약함

### 5순위 — `Threegate`

- 한국어: `쓰리게이트`
- 의미: 게임의 세 라인 경계
- 장점:
  - 짧고 지형·전투 구조가 명확
  - 스테이지·캠페인 확장성이 좋음
- 단점:
  - 운명·룰렛·징조가 제목에서 빠짐

### 6순위 — `Bastion of Fortune`

- 한국어: `배스천 오브 포춘`
- 의미: 행운을 전력으로 바꾸는 요새
- 장점:
  - 룰렛과 방어를 비교적 직접적으로 전달
- 단점:
  - 다소 일반적인 모바일 판타지 제목처럼 들릴 수 있음

## 8. 최종 추천 조합

### 브랜드 중심 추천

```text
게임명: OMENWARD
국가: Kingdom of Lumern
첫 요새: Silverbell Bastion
전선: Threegate Front
외부 영역: The Veilwilds
괴물: Beyondborn
방위군: Frontier Wardens
```

한국어 표기:

```text
오멘워드
루메른 왕국
실버벨 배스천
쓰리게이트 프론트
베일와일즈
비욘드본
프론티어 워든즈
```

이 조합은 `지휘관이 징조를 읽고 세 전선을 지킨다`는 게임 경험을 가장 선명하게 전달한다.

### 율비·마스코트 중심 추천

```text
게임명: BELLWARD
부제: Omen of the Lumern Frontier
```

이 조합은 종·율비·경계종의 브랜드를 강하게 만들지만, 전술 게임임을 보여주는 키비주얼과 부제가 더 중요하다.

## 9. 선택 뒤 갱신할 항목

1. 메인 게임명과 프로젝트 표기
2. 국가·생활권·요새·전선·괴물 영역 공식 이름
3. 첫 10분 율비 대사와 웨이브 카드
4. 게임 로고의 종·세 게이트·룰렛 문양 조합
5. 영문·한국어 스팀 상점 설명 한 문장
6. 적 병종 명명 규칙
7. 스테이지 제목 규칙

최종 선택 전에는 기존 프로젝트명 `roulettebound-prototype`과 설계 문서의 기능 용어를 유지한다.
