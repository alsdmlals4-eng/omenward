# 전투 키워드·상태이상·중단 공통 규칙 제안

- 상태: **추천안 / 사용자 승인 전 구현 금지**
- 작성일: 2026-07-14
- 연결 문서:
  - `docs/design/APPROVED_UNIT_GRADE_AND_ABILITY_GROWTH.md`
  - `docs/design/APPROVED_BUILDING_SPECIALIZATION_AND_TACTICAL_COMMANDS.md`
  - `docs/GAME_DESIGN.md`
  - `docs/DECISIONS_PENDING.md`

이 문서는 병종별 패시브와 스킬을 만들 때 공통으로 사용할 태그, 치명타, 후방, 돌진, 중단, 군중 제어, 상태이상과 피해 계산 규칙을 제안한다. 정확한 수치보다 **같은 용어가 언제나 같은 방식으로 작동하는 계약**을 먼저 고정하는 것이 목적이다.

---

## 1. 전투 능력 표기 원칙

모든 공격, 패시브, 스킬과 상태이상은 다음 세 요소를 분리해 정의한다.

1. **대상 태그**: 어떤 유닛 또는 구조물인가
2. **행동 태그**: 어떤 방식의 공격 또는 이동인가
3. **효과 태그**: 어떤 피해·제어·상태이상을 주는가

예시:

```text
창병 쓰러스트
대상 태그 조건: 없음
행동 태그: [스킬] [근접] [직선] [관통]
효과 태그: [물리 피해] [경직]

기병 돌진
사용자 태그: [기병]
행동 태그: [스킬] [돌진] [이동] [관통 이동]
효과 태그: [물리 피해] [밀쳐내기]
```

능력 설명에 없는 숨은 예외를 최소화한다. 보스 면역, 건물 제외, 중첩 불가 같은 예외는 반드시 데이터와 UI 설명에 표시한다.

## 2. 핵심 대상 태그

### 병종·역할 태그

초기 공통 태그:

- `[보병]`
- `[방패병]`
- `[기병]`
- `[원거리병]`
- `[지원병]`
- `[마법사]`
- `[암살자]`
- `[공성병]`

한 유닛은 여러 태그를 가질 수 있다.

예시:

```text
창병: [보병] [창병]
궁병: [보병] [원거리병]
기마궁수: [기병] [원거리병]
```

따라서 창병의 `[기병] 추가 피해`는 기마궁수에게도 적용된다.

### 등급·크기 태그

- `[일반]`
- `[엘리트]`
- `[영웅]`
- `[전설]`
- `[소형]`
- `[대형]`
- `[지휘관]`
- `[보스]`

등급과 크기는 별도 축이다. 영웅이 반드시 대형일 필요는 없다.

### 구조물 태그

- `[건물]`
- `[포탑]`
- `[생산시설]`
- `[경제시설]`
- `[본진]`
- `[임시구조물]`
- `[바리케이드]`

유닛 대상 효과는 기본적으로 구조물에 적용되지 않는다. 구조물에도 적용되는 경우 능력 설명에 명시한다.

## 3. 핵심 행동 태그

### 공격 거리

- `[근접]`: 근접 공격 거리에서 발생
- `[원거리]`: 원거리에서 발생
- `[투사체]`: 실제 투사체가 이동한 뒤 적중

`[원거리]`와 `[투사체]`는 같은 뜻이 아니다.

예시:

- 활 공격: `[원거리] [투사체]`
- 마법 광선: `[원거리]`, 투사체 아님
- 투척 도끼: `[원거리] [투사체]`

방패병의 원거리 피해 감소는 초기에는 `[원거리]` 공격에 적용하되 다음은 제외하는 것을 추천한다.

- `[공성]`
- `[전술 명령]`
- 지면에 남는 상태이상 피해
- 능력 설명에 `방패 무시`가 붙은 공격

### 공격 종류

- `[기본 공격]`
- `[스킬]`
- `[전술 명령]`
- `[지속 피해]`
- `[범위 공격]`
- `[직선]`
- `[부채꼴]`
- `[관통]`
- `[공성]`

공격 횟수 조건은 기본적으로 `[기본 공격]`만 센다. 스킬의 다단 공격은 별도 명시가 없으면 기본 공격 횟수에 포함하지 않는다.

### 이동·위치 행동

- `[돌진]`
- `[도약]`
- `[순간이동]`
- `[강제 이동]`
- `[후퇴]`
- `[후방 이동]`

`[돌진]`은 단순 이동속도 증가가 아니라 중단·저지 상호작용을 가지는 특수 이동 상태다.

## 4. 피해 유형

초기 피해 유형은 다음 세 가지로 제한하는 것을 추천한다.

- **물리 피해**: 방어력으로 감소
- **마법 피해**: 마법 저항으로 감소
- **고정 피해**: 방어력과 마법 저항을 무시

고정 피해는 첫 프로토타입에서 매우 제한적으로 사용한다. 고정 피해도 무적과 피해 무효화는 관통하지 않는다.

지속 피해는 물리·마법 중 하나를 반드시 가진다.

예시:

- 출혈: 물리 지속 피해
- 화상: 마법 지속 피해
- 역병: 마법 지속 피해

---

## 5. 피해 계산 순서

피해는 다음 순서로 계산하는 것을 추천한다.

```text
기본 피해
→ 공격자 피해 증가·감소
→ 병종 상성·대상 태그 배율
→ 치명타
→ 방어력 또는 마법 저항
→ 공격 형태별 피해 경감
→ 전체 받는 피해 감소
→ 보호막
→ 체력
```

예시:

```text
원거리 물리 피해 100
방패병 원거리 피해 50% 경감
강화지대 받는 피해 15% 감소

100 × 0.50 × 0.85 = 42.5
```

서로 다른 피해 감소 계열은 곱연산한다. 같은 이름의 효과는 중첩 규칙에 따라 가장 강한 하나만 적용하거나 정해진 상한까지 합산한다.

### 피해 최소값

방어력 계산 뒤 피해가 양수라면 최소 1의 피해를 주는 방향을 추천한다. 완전 피해 무효는 `면역`, `무적`, `보호막`처럼 명시된 효과만 사용한다.

## 6. 치명타 공통 규칙

초기 추천값:

- 기본 치명타 확률: **5%**
- 기본 치명타 피해: **기본 피해의 150%**
- 치명타 확률 상한: **100%**

치명타 확률 보너스는 기본적으로 합산한다.

예시:

```text
기본 치명타 5%
암살자 후방 보너스 +50%p
아이템 보너스 +10%p
최종 치명타 확률 65%
```

### 확정 치명타

`확정 치명타`는 최종 치명타 확률을 100%로 만든다. 치명타 확률이 100%를 넘었다고 치명타 피해가 추가로 증가하지 않는다.

궁병의 `3회 적중 후 4번째 공격 확정 치명타`는 다음처럼 판정한다.

- 성공한 기본 공격 적중만 횟수에 포함
- 스킬 공격과 지속 피해는 포함하지 않음
- 대상 변경 시 횟수 유지
- 전투에서 벗어난 뒤 6초가 지나면 횟수 초기화 추천
- 3회 적중 뒤 다음 **성공한 기본 공격 적중**이 확정 치명타가 되고 카운트 초기화
- 투사체가 목표를 잃어 적중하지 못하면 강화 횟수를 소비하지 않음

### 치명타 제외 대상

기본적으로 다음은 치명타가 발생하지 않는다.

- 지속 피해
- 전술 명령
- 건물·포탑·본진

스킬 설명에 `치명타 가능` 또는 `구조물 치명타 가능`이 있으면 예외로 한다.

---

## 7. 후방 판정

후방은 대상이 바라보는 방향을 기준으로 계산한다.

초기 추천:

- 대상 정반대 방향을 중심으로 **총 120도 후방 원뿔**
- 공격이 실제로 적중하는 순간 공격자의 위치로 판정
- 대상이 공격 준비 중이라면 해당 공격 방향을 적중까지 유지해 갑작스러운 회전 판정을 방지
- 구조물은 후방 판정 없음

```text
정면 240도: 일반 판정
후방 120도: 후방 공격 판정
```

암살자의 후방 공격은 후방에서 적중한 공격에 치명타 확률 +50%p를 준다.

### 후방 이동 스킬

대상 뒤로 이동하는 스킬은 다음을 확인한다.

- 목적지가 전장 범위 안인지
- 다른 유닛이나 구조물로 막히지 않았는지
- 해당 라인을 벗어나지 않는지
- 바리케이드와 건물을 통과하지 않는지

사용 가능한 위치가 없으면 스킬을 발동하지 않고 내부 쿨타임도 시작하지 않는다.

## 8. 돌진 공통 규칙

`[돌진]`은 다음 상태를 가진 이동형 스킬이다.

```text
목표와 최소 거리 확보
→ 짧은 준비 동작
→ 방향과 경로 고정
→ 돌진 이동
→ 충돌·저지·도착 판정
→ 종료 공격 또는 후속 효과
```

초기 추천 규칙:

- 일정 최소 거리 이상 떨어진 목표에만 사용
- 돌진 시작 시 경로를 고정하고 이동 중 목표를 급격히 추적하지 않음
- 소형 일반 유닛은 통과하거나 밀쳐낼 수 있음
- 대형 적, 바리케이드, 건물에는 막힘
- 바리케이드에 충돌하면 돌진을 종료하고 바리케이드에 피해 적용
- 돌진 중 다른 일반 행동을 하지 않음
- 돌진은 공격속도가 아니라 내부 쿨타임의 영향을 받음

### 창병의 돌진 저지

창병의 대기병 패시브 추천 판정:

- `[기병]`이 `[돌진]` 상태로 창병의 전방 저지 범위에 진입하면 발동
- 돌진을 즉시 종료
- 기병을 창병 앞의 유효 위치에 정지
- 돌진의 주 충돌 피해는 발생하지 않음
- 저지된 기병에게 짧은 경직 부여
- 창병 1명당 돌진 저지 내부 쿨타임 **5초** 추천

여러 창병이 같은 돌진을 동시에 저지하려 하면 가장 먼저 유효 판정을 얻은 창병 하나만 내부 쿨타임을 소비한다.

### 보스 돌진

보스의 돌진은 완전히 취소하지 않는 방향을 추천한다.

창병 저지 성공 시:

- 남은 돌진 거리 35% 감소
- 최종 돌진 피해 30% 감소
- 돌진 종료 뒤 짧은 경직 적용

정확한 수치는 플레이테스트 대상이다. 보스에게도 창병 배치의 가치가 있지만 단일 일반 창병이 보스 패턴을 완전히 봉쇄하지 않게 한다.

## 9. 행동 중단과 취소

`중단`은 현재 준비 중인 행동을 끝내고 효과 발생을 막는 판정이다.

### 중단 가능한 행동

기본적으로 다음은 중단될 수 있다.

- 기본 공격 준비 동작
- 일반 스킬 시전
- 돌진 준비와 돌진 이동
- 채널링 스킬

이미 피해와 효과가 발생한 뒤에는 중단으로 되돌리지 않는다.

### 중단 우선순위

같은 시뮬레이션 틱에 중단과 공격 적중이 겹치면 다음 순서를 추천한다.

```text
반응형 저지·방어 판정
→ 행동 중단·돌진 취소
→ 중단되지 않은 공격 적중
→ 피해·상태이상 적용
→ 강제 이동
→ 사망 판정
→ 재타기팅
```

따라서 창병 저지가 같은 틱의 기병 돌진 충돌보다 먼저 해결된다.

### 내부 쿨타임 시작 시점

- 스킬이 정상적으로 효과를 발생시키면 효과 발생 시점부터 시작
- 준비 중 중단되면 기본적으로 내부 쿨타임의 30%만 적용하는 것을 추천
- 발동 조건 불충족이나 유효 목표 없음으로 시작하지 못하면 쿨타임 없음

중단 시 일부 쿨타임을 적용해 같은 스킬을 매 틱 재시도하는 현상을 막는다.

## 10. 군중 제어 구분

### 경직

- 매우 짧은 행동 불가
- 이동과 공격 준비 중단
- 위치는 바뀌지 않음
- 일반적으로 0.2~0.8초 범위

### 기절

- 지속시간 동안 이동·공격·스킬 사용 불가
- 진행 중인 행동 중단
- 경직보다 강한 제어

### 밀쳐내기

- 지정 방향으로 강제 이동
- 이동 중 행동 중단
- 구조물과 대형 대상은 저항 또는 면역 가능

### 넘어짐

- 긴 행동 불가와 전용 회복 동작
- 소형·일반 대상 중심
- 첫 프로토타입에서는 사용 병종을 제한하는 것을 추천

### 둔화

- 이동속도 감소
- 행동 자체는 가능
- 최종 이동속도 감소 상한 **60%** 추천

### 속박

- 이동만 불가능
- 공격과 스킬 사용 가능
- 초기 프로토타입에 필요할 때만 추가

## 11. 군중 제어 저항

대상 등급별 추천:

| 대상 | 경직·기절 지속시간 | 밀쳐내기·넘어짐 |
|---|---:|---|
| 일반 | 100% | 정상 적용 |
| 엘리트 | 70% | 거리 50% |
| 영웅·지휘관 | 50% | 거리 25% 또는 넘어짐 면역 |
| 전설 | 40% | 밀쳐내기·넘어짐 면역 추천 |
| 보스 | 25% | 밀쳐내기·넘어짐 면역 |

보스는 일반 기절에 완전 면역으로 만들기보다, 매우 짧은 경직으로 변환하는 방향을 추천한다. 단, 보스 패턴의 핵심 시전은 `중단 불가` 태그를 가질 수 있다.

UI에는 `제어 저항`, `밀쳐내기 면역`, `중단 불가`를 명확히 표시한다.

## 12. 버프·디버프 공통 중첩 규칙

모든 효과는 다음 중 하나의 중첩 방식을 가진다.

### 중첩 불가·강한 효과 유지

같은 효과가 다시 적용되면:

- 더 강한 수치 유지
- 지속시간은 더 긴 쪽으로 갱신

방어 감소, 공격속도 증가, 받는 피해 감소처럼 여러 출처 중 가장 강한 것만 적용할 때 사용한다.

### 지속시간 갱신

수치는 중첩하지 않고 지속시간만 초기화한다.

역병의 피해와 치유 감소에 추천한다.

### 스택 누적

효과마다 최대 스택을 정한다. 새 스택이 추가될 때 전체 지속시간을 갱신하거나 스택별 시간을 따로 관리할 수 있다.

첫 프로토타입에서는 성능과 UI 단순화를 위해 **전체 지속시간 갱신 방식**을 추천한다.

### 출처별 독립

같은 효과라도 서로 다른 유닛이 적용한 경우 별도로 존재한다.

출혈처럼 여러 암살자의 공격 가치를 보존해야 할 때 사용한다.

## 13. 상태이상 초기 권장 규칙

### 출혈

- 물리 지속 피해
- 치명타 또는 베기 계열 스킬로 적용
- 같은 공격자에게서 온 출혈은 중첩하지 않고 지속시간 갱신
- 서로 다른 공격자의 출혈은 최대 3개까지 독립 적용 추천
- 건물·포탑·본진에는 적용하지 않음

### 독

- 마법 지속 피해 또는 별도 독 피해
- 스택형으로 설계 가능
- 초기 추천 최대 5스택
- 스택 증가 시 전체 지속시간 갱신
- 보스는 최대 스택 감소 또는 피해 계수 적용

독 병종이 확정되기 전까지 구현 보류 가능하다.

### 화상

- 마법 지속 피해
- 중첩하지 않음
- 더 강한 화상이 기존 화상을 교체
- 지속시간은 더 긴 쪽 유지
- 주변으로 자동 전염하지 않음

### 역병

- 마법 지속 피해
- 받는 치유량 감소
- 같은 역병 피해는 중첩하지 않고 지속시간만 갱신
- 치유 감소는 가장 강한 수치 하나만 적용
- 영웅·지휘관·보스는 지속 피해 계수 감소 가능

### 표식

- 피해 자체가 없는 디버프
- 특정 병종이나 스킬의 추가 조건으로 사용
- 같은 표식은 중첩하지 않고 지속시간 갱신

## 14. 치유와 치유 감소

치유는 다음 순서로 처리한다.

```text
기본 치유량
→ 시전자 치유량 증가·감소
→ 대상이 받는 치유량 증가·감소
→ 최대 체력 초과분 제거
```

여러 치유 감소 효과는 기본적으로 가장 강한 하나만 적용한다.

예시:

```text
역병 치유 감소 50%
다른 약화 치유 감소 30%
최종 치유 감소 50%
```

치유 감소를 합산해 100%가 되는 상황을 방지한다.

## 15. 내부 쿨타임 공통 규칙

- 내부 쿨타임은 시뮬레이션 시간 기준
- 일시정지 중 진행되지 않음
- 2배속에서는 게임 시간 기준으로 정상 진행
- 공격속도는 내부 쿨타임을 줄이지 않음
- 별도의 `스킬 쿨다운 감소` 효과만 내부 쿨타임에 적용
- 쿨다운 감소 상한 **40%** 추천
- 효과가 정상 발생한 순간 쿨다운 시작
- 중단된 스킬은 기본 쿨타임의 30% 적용 추천

공격 횟수 조건형 스킬은 내부 쿨타임과 별개다. 필요하다면 공격 횟수 조건과 최소 재발동 시간을 동시에 가질 수 있다.

- 위치가 없으면 발동·쿨다운 없음
