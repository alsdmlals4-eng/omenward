# 승인된 15웨이브 스테이지 시계와 초과 공세 1차안

- 상태: **정규 스테이지 60초 공세 주기·15웨이브 결전·20웨이브 절멸 구조 승인 / 세부 공세 예산·보스 능력치는 PoC 초기 가설**
- 작성일: 2026-07-15
- 적용 범위: 정규 스테이지 시간 구조, 공세 충돌 시점, 승리 조건, 15웨이브 보스, 16~19웨이브 초과 공세, 20웨이브 절멸 공세
- 연결 문서:
  - `docs/OMENWARD_GAME_DESIGN.md`
  - `docs/design/APPROVED_BATTLEFIELD_TOPOLOGY_AND_SCALE_V1.md`

이 문서는 기존의 `정규 스테이지 25~35분`, `약 35분 결전 공세` 초기 가설을 대체한다.

## 1. 한 판의 기본 길이

```text
정규 클리어 목표: 15웨이브
공세 충돌 간격: 활성 전투 시간 기준 60초
15웨이브 충돌: 15:00
표준 체감 플레이: 약 15분
초과전 최대 압박 시점: 20:00
```

`활성 전투 시간`은 일시정지를 제외한 전투 시계다.

- 일시정지 중에는 공세 시계가 멈춘다.
- 이동·공격·건설·생산·쿨다운도 함께 멈춘다.
- 플레이어가 계획 모드에서 사용한 현실 시간은 다음 공세까지의 60초에서 차감되지 않는다.
- 공세는 이전 공세가 완전히 정리될 때까지 기다리지 않는다.
- 이전 적이 남아 있어도 다음 공세는 정해진 시각에 중앙 접전지로 진입한다.

따라서 플레이어가 공세를 느리게 처리하면 적이 누적되고, 빠르게 처리하면 다음 준비 시간을 확보한다.

---

## 2. 공세 시계

정규 스테이지에서 웨이브 `N`의 목표 충돌 시점은 다음과 같다.

```text
wave_collision_time = N × 60초
```

| 웨이브 | 충돌 시점 |
|---:|---:|
| 1 | 1:00 |
| 5 | 5:00 |
| 10 | 10:00 |
| 15 | 15:00 |
| 16 | 16:00 |
| 20 | 20:00 |

`충돌`은 적 선두가 해당 라인의 중앙 접전지 주 교전 반경에 들어오는 순간이다.

적 생성 시각은 라인 길이와 이동속도에 따라 역산한다.

```text
spawn_time = collision_time - travel_time_to_engagement
```

일반 보행형은 충돌 약 10~12초 전에 적 중간요새에서 출격하는 기존 방향을 유지한다.

## 3. 베일의 징조 시간

### 일반 공세

```text
T-30: 라인·병종·수량 정확히 공개
T-15: 위험 라인과 주요 상성 강조
T-5: 구성 잠금·경계종과 벨루 최종 경고
T: 중앙 접전지 충돌
```

### 첫 공세

첫 공세는 준비 시간이 필요하므로 스테이지 시작과 동시에 전체 징조를 공개한다.

```text
0:00 첫 공세 전체 정보 공개
1:00 첫 공세 충돌
```

### 15웨이브와 20웨이브

- 15웨이브 보스의 존재와 주 라인은 `T-60`부터 예고한다.
- 정확한 호위 병력과 패턴은 `T-30`에 공개한다.
- 20웨이브 절멸 공세는 19웨이브 충돌 시점부터 전장 전체에 붉은 베일 경보를 표시한다.

## 4. 승리와 패배

### 4.1 정상 승리

```text
15웨이브 강력 보스 처치
→ 스테이지 승리
```

15웨이브 보스는 정규 스테이지의 표준 최종 목표다.

### 4.2 공격적 조기 승리

```text
15웨이브 이전 적 본진 파괴
→ 즉시 조기 승리
```

적 중간요새와 생산시설을 밀어붙이는 공격형 빌드의 보상이다. 조기 승리는 높은 위험을 감수한 정식 전략으로 허용한다.

### 4.3 일반 패배

- 아군 본진 체력 0
- 스테이지별 핵심 보호 목표 파괴
- 별도 공개된 패배 조건 달성

### 4.4 소프트 패배 시한

20:00에 즉시 패배 화면을 띄우지는 않는다.

대신 20웨이브에 절멸급 보스와 강력한 호위 병력을 보내, 그 시점까지 클리어하지 못한 플레이어가 빠르게 패배하도록 압박한다.

기적적인 역전은 규칙상 가능하지만 일반적인 빌드의 기대 결과는 패배다.

## 5. 1~15웨이브 구조

| 구간 | 역할 |
|---|---|
| 1~4 | 기본 병종·라인 판단·초반 빌드 확인 |
| 5 | 첫 엘리트 또는 특수 병종 압박 |
| 6~9 | 복수 라인·혼합 병종·건물 대응 |
| 10 | 중간 지휘관 또는 미니보스 |
| 11~14 | 상위 병종·공성·비행·엘리트 혼합 |
| 15 | 강력 보스와 호위 병력의 결전 공세 |

정규 스테이지마다 모든 병종을 강제로 사용하지 않는다. `StageManifest`가 스테이지 테마와 카운터 가능성을 검증해 공세 구성을 만든다.

### 권장 중간 이정표

```text
5웨이브: 초반 빌드 검증
10웨이브: 중간 위기와 빌드 전환
14웨이브: 최종 준비
15웨이브: 결전
```

## 6. 15웨이브 결전 공세

15웨이브는 다음 구성으로 만든다.

```text
주 라인: 스테이지 보스 1기 + 호위 병력
나머지 라인: 중형 압박 병력 또는 엘리트 지휘관
```

목표:

- 한 라인에 모든 병력을 몰아넣는 정답을 강요하지 않는다.
- 보스 라인을 집중 대응하면서도 다른 두 라인을 완전히 버릴 수 없게 한다.
- 포탑·바리케이드·전술 명령·상위 등급 병력이 모두 의미를 갖는다.
- 보스는 바리케이드 영구 봉쇄와 병력 과밀을 대응하는 예고된 패턴을 가진다.
- 보스 전투 목표 시간은 초기 30~60초다.

15웨이브 보스가 살아 있는 동안 16웨이브 시간이 되면 스테이지는 승리하지 않고 초과전으로 진입한다.

---

## 7. 16~19웨이브 초과 공세

초과 공세는 새로운 전략을 가르치는 구간이 아니라, 15웨이브를 마무리하지 못한 대가를 빠르게 누적시키는 구간이다.

공통:

- 15웨이브 보스가 살아 있는 상태로 다음 병력이 합류한다.
- 일반 병력보다 엘리트·상위 병종 비중을 크게 높인다.
- 공세 간격은 계속 60초를 유지한다.
- 금화·식량 보상을 과도하게 늘려 역으로 파밍 구간이 되지 않게 한다.
- 적 본진 조기 파괴 또는 15웨이브 보스 처치 시 즉시 승리한다.

초기 위협 예산 가설:

| 웨이브 | 기본 15웨이브 전 위협 대비 | 성격 |
|---:|---:|---|
| 16 | 1.25× | 각 라인 엘리트 추가 |
| 17 | 1.50× | 복수 엘리트·원거리 지원 |
| 18 | 1.80× | 공성·비행·지휘관 혼합 |
| 19 | 2.15× | 세 라인 동시 붕괴 압박 |

배율은 적 체력을 일괄 증가시키는 값이 아니라 `Threat Budget` 총량과 상위 병종 비중을 조정하는 기준이다.

## 8. 20웨이브 절멸 공세

20웨이브는 사실상의 패배 시한이다.

구성:

```text
절멸급 보스 1기
+ 세 라인 강화 엘리트 호위
+ 남아 있는 15웨이브 보스와 기존 병력
```

절멸급 보스 초기 방향:

- 15웨이브 보스보다 훨씬 높은 체력과 구조물 파괴력
- 바리케이드·전열을 빠르게 무너뜨리는 직선 돌파
- 밀집 병력을 공격하는 큰 범위 패턴
- 경직·밀쳐내기·속박 지속시간 대폭 감소
- 일정 시간마다 공격력·이동속도가 상승하는 전투 중 격노
- 아군 본진을 향해 계속 전진하며 장기 교착을 허용하지 않음

초기 수치 가설:

```text
15웨이브 보스 대비 체력: 약 2.5×
공격력: 약 1.75×
바리케이드·건물 피해: 약 3.0×
받는 군중제어 지속시간: 50%
15초마다 공격·이동 성능 증가
```

정확한 값은 보스 설계와 플레이테스트에서 조정한다.

## 9. 튜토리얼 적용

튜토리얼은 세계관과 시스템 습득을 위한 수동 설계 스테이지이므로, 첫 웨이브 전까지 온보딩 시간을 별도로 둘 수 있다.

다만 전투 공세가 시작된 뒤에는 같은 60초 충돌 간격을 사용한다.

```text
튜토리얼 웨이브 시계 시작
→ +1:00 제1공세
→ +2:00 제2공세
→ +3:00 제3공세
→ +4:00 제4공세
```

일시정지는 튜토리얼 웨이브 시계도 멈춘다.

이 규칙은 `APPROVED_TUTORIAL_FIRST_FOUR_WAVES_BALANCE_V1.md`의 절대 시각표보다 우선한다. 해당 문서의 공세 구성·능력치·학습 목적은 유지하고, 충돌 시점만 이 문서의 상대 60초 주기를 적용한다.

## 10. HUD 계약

항상 표시:

- 현재 웨이브 / 목표 15웨이브
- 다음 충돌까지 남은 활성 전투 시간
- 현재 공세와 다음 공세의 징조 상태
- 15웨이브 결전 보스 아이콘
- 15웨이브 이후 `초과 공세` 경고
- 20웨이브 절멸 공세 카운트다운

표현:

```text
1~14: WAVE 01 / 15
15: FINAL WAVE / 결전 공세
16~19: OVERTIME / 초과 공세
20: ANNIHILATION / 절멸 공세
```

한국어 UI에서는 영어를 강제하지 않고 `결전`, `초과`, `절멸`을 우선한다.

## 13. 검증 계약

1. 일시정지를 제외한 충돌 간격이 항상 60초다.
2. 이전 공세가 남아 있어도 다음 공세가 예정대로 진입한다.
3. 15웨이브 보스가 표준 승리 목표로 인식된다.
4. 공격형 빌드는 적 본진을 파괴해 15웨이브 이전 조기 승리할 수 있다.
5. 16~19웨이브는 파밍이 아니라 빠르게 누적되는 실패 압박으로 느껴진다.
6. 20웨이브 절멸 공세의 일반 승률은 매우 낮지만 0%로 강제하지 않는다.
7. 기본 난이도 정규 스테이지의 중앙 플레이타임은 활성 전투 시간 약 15분이다.
8. 보스 처치가 지나치게 길어 표준 플레이가 18분 이상으로 늘어나면 15웨이브 보스 체력과 패턴 시간을 먼저 조정한다.
9. 신규 UI·대사에서 기존 35분 결전 공세 문구를 사용하지 않는다.
