## 1. 결정 요약

베일은 세계를 둘러싼 단순 장벽이나 하나의 장소가 아니다. **현실 세계와 이질적인 법칙을 가진 외부 영역이 국소적으로 겹칠 때 발생하는 비의지적 경계 현상**이다.

```text
ONTOLOGY = NON_SENTIENT_BOUNDARY_OVERLAP
MATERIAL_EXPRESSION = ECOLOGICAL_GROWTH_LIKE_PATTERNS
VEIL_ITSELF_HAS_UNIFIED_WILL = FALSE
ORIGIN = PENDING
EXTERNAL_DOMAIN_STRUCTURE = PENDING
```

베일이 혈관·균사·결정·조직처럼 자라고 지형을 바꾸는 모습은 살아 있는 생명체의 의도가 아니라, 서로 맞지 않는 두 법칙 체계가 접촉하면서 만들어 내는 반복적 물질 패턴이다.

## 2. 존재론적 구분

### 2.1 현실 세계

루메른 왕국과 루미엔 영토가 속한 물리 세계다. 평상시에는 자체 인과·공간·물질 법칙이 안정적으로 유지된다.

### 2.2 외부 영역

현실과 다른 법칙을 가진 베일 너머의 영역이다. 하나인지 복수인지, 자연 발생인지 인공 구조인지, 세계와 어떤 역사적 관계인지 아직 확정하지 않는다.

### 2.3 베일

현실과 외부 영역 사이의 **접촉면과 겹침 과정**이다. 베일 자체는 영토·종족·신격이 아니며 통일된 욕망이나 계획을 갖지 않는다.

### 2.4 균열·침공로

겹침이 현실의 특정 지형에 고정되어 물질과 존재가 오갈 수 있게 된 상태다. 하나의 MapRun은 이런 고정 겹침 하나가 확대되는 실제 공세를 봉쇄하는 작전이다.

### 2.5 베일 상흔

겹침이 제거된 뒤에도 지형·생태·물질·기억에 남는 비가역 또는 장기 잔류 변화다. 베일런 황야는 장기간의 겹침과 봉쇄가 누적된 상흔 지역으로 해석할 수 있으나 정확한 지리·역사는 후속 Decision에서 확정한다.

## 3. 베일의 법칙

`베일의 법칙`은 편의적으로 무엇이든 가능하게 하는 마법이 아니라, 특정 겹침 안에서 반복적으로 관측되는 **유한하고 설명 가능한 변형 규칙 묶음**이다.

허용되는 범주 예시:

- 공간의 거리·방향·연결 관계 변형.
- 물질의 성장·결정화·융합·침식.
- 중력·빛·소리·시간 감각의 국소 변형.
- 특정 행동에 반응하는 전장 조건.
- 외부 존재가 현실에서 유지되기 위한 조건.

불변 조건:

- 한 공세의 핵심 법칙은 작전 도중 이유 없이 무작위로 바뀌지 않는다.
- 플레이어가 중요한 위협을 판단할 수 있도록 징조·브리핑·전장 반응으로 관측 가능해야 한다.
- 규칙을 알 수 없어서 실패하는 것이 아니라, 공개된 규칙에 어떻게 대응할지 판단하다 실패하도록 설계한다.
- 이후 콘텐츠가 필요하다는 이유로 기존 법칙과 충돌하는 예외를 무제한 추가하지 않는다.

## 4. 베일의 징조

징조는 외부 영역의 미래를 완전히 보는 예언이 아니다. 실제 겹침에 앞서 두 법칙 체계가 서로 공명하면서 현실에 남기는 **선행 관측 패턴**이다.

징조가 제공할 수 있는 것:

- 어느 전선에서 겹침이 강해지는가.
- 어떤 종류의 적·현상·치명 행동이 나타날 가능성이 높은가.
- 어떤 베일 법칙이 이번 공세의 중심인가.
- 위험 Stage에서 무엇이 달라지는가.

징조가 제공하지 않는 것:

- 전투의 확정 결과.
- 모든 적의 정확한 순서와 수치.
- 플레이어의 선택과 무관한 운명.
- 시간 루프의 기억이나 미래 시뮬레이션의 정답.

## 5. 생태적으로 보이는 물질 표현

베일은 의식이 없지만 장시간 지속될수록 생태계처럼 보이는 구조를 만든다.

권장 시각·물질 언어:

- 지형을 따라 퍼지는 균사·뿌리·혈관형 맥.
- 법칙이 고정된 장소의 결정·막·껍질·층리.
- 주변 물질을 흡수해 반복 형상을 만드는 성장 패턴.
- 현실 생태와 외부 법칙이 섞여 생긴 혼성 지형.
- 공세가 강해질수록 구조가 더 조밀하고 목적적으로 보이는 착시.

이 표현은 베일을 생명체나 신으로 승격하지 않는다. 성장 방향은 통일된 의지가 아니라 지형·에너지·균열 조건에 의해 결정된다.

## 6. 베일종과 의지의 분리

베일 자체에 의식이 없다는 결정은 베일종까지 무의식이라는 뜻이 아니다.

```text
VEIL = NON_SENTIENT_PHENOMENON
VEIL_SPECIES = MAY_HAVE_INDEPENDENT_AGENCY
BOUNDARY_BREAKER = ROLE_AND_PURPOSE_PENDING
```

베일종의 발생 방식, 지성의 범위, 사회·세력, 침공 목적, 경계파쇄자의 역할은 별도 Decision에서 확정한다. 베일종이 베일을 이용하거나 숭배하거나 생존 조건으로 필요로 할 수는 있지만, 이를 이번 존재론 승인으로 자동 확정하지 않는다.

## 7. 봉쇄와 승리

균열 봉쇄는 베일을 죽이거나 외부 영역을 제거하는 행위가 아니다.

```text
봉쇄
= 고정된 겹침을 불안정화
→ 현실과 외부 영역의 직접 연결을 끊음
→ 국소 법칙을 현실 쪽으로 되돌림
→ 잔류 상흔과 피해를 남김
```

Stage 20 승리는 해당 침공로를 실제로 닫은 결정적 지역 승리다. 세계 전체에서 베일 현상이 사라지지 않는다고 해서 그 승리가 무효화되지 않는다.

## 8. MapRun과 연결

```text
선행 공명과 징조
→ 균열 고정
→ 베일 법칙이 전장에 나타남
→ 베일종·경계파쇄자 공세
→ 4막·20 Stage 동안 겹침 확대
→ 봉쇄 또는 방어선 붕괴
```

- Stage 진행은 시간 반복이 아니라 겹침 강도와 적의 공세가 고조되는 과정이다.
- 위험 Stage는 새로운 규칙을 아무 이유 없이 추가하는 것이 아니라 이미 예고된 법칙이 임계 상태에 도달하는 구간이다.
- 전선별 위협 차이는 같은 겹침이 지형·시설·침공 축과 다르게 반응한 결과로 설명할 수 있다.
- 세 물리 릴·TokenSource가 베일 법칙을 어떻게 측정·편집하는지는 아직 확정하지 않는다.
