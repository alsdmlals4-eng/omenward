## 1. 결론

현재 병영 후보의 세 축을 동일한 방식으로 억지 선택하지 않는다.

```text
SPECIAL_COST_MULTIPLIER = DECISION_ELIGIBLE_ECONOMY_DIMENSION
SPECIAL_INTERVAL_MULTIPLIER = DECISION_ELIGIBLE_PRODUCTION_DIMENSION
SPECIAL_FUNCTIONAL_VALUE_INDEX = DEFERRED_UNTIL_PRODUCT_COMBAT_NUMERICS
FINAL_PARAMETER_VECTOR = NOT_SELECTED
```

비용·생산간격은 현행 MapRun 경제·생산 정본으로 관측할 수 있다. 반면 `special_functional_value_index`는 제품 HP/DPS/사거리/역할 계수/전술 출력이 없는 상태에서 실제 기능가치를 대표하지 못한다. 4/10에서 폐기한 `COMBAT_POWER_SCALAR` 또는 `SUPPORT_TU`를 다시 주입해 이 차원을 가짜로 식별하지 않는다.

## 2. 현행 정본에서 직접 가져오는 hard gate

현행 병영 정정 계약은 다음을 유지한다.

```text
SPECIAL_UNIT_FUNCTIONAL_POWER = STRONGER_THAN_GENERAL_UNIT
SPECIAL_AUTO_PRODUCTION_INTERVAL = LONGER_THAN_GENERAL_UNIT
```

따라서 생산간격 후보에는 다음 hard gate를 적용한다.

```text
SPECIAL_INTERVAL_CANON_GATE = STRICTLY_LONGER_THAN_RELEVANT_GENERAL_INTERVAL
RELEVANT_GENERAL_INTERVAL_MAX_SECONDS = 65
PASS_RULE = MIN_SPECIAL_INTERVAL_SECONDS > 65
```

현행 MapRun baseline:

```text
GENERAL: BASIC_INFANTRY=50 / SHIELD=65 / ARCHER=65
SPECIAL_BASE: ASSASSIN=75 / PRIEST=80 / MAGE=90 / FLYING_UNIT=100 / GIANT=110
VECTOR_INTERVAL_SCALE = special_interval_multiplier / 1.70
```

현재 후보 계산:

```text
INTERVAL_MULTIPLIER_1.45:
  ASSASSIN_MIN = 75 * 1.45 / 1.70 = 63.970588
  RESULT = HARD_CANON_FAIL

INTERVAL_MULTIPLIER_1.70:
  ASSASSIN_MIN = 75.000000
  RESULT = PASS

INTERVAL_MULTIPLIER_2.20:
  ASSASSIN_MIN = 97.058824
  RESULT = PASS
```

따라서 다음 벡터는 10k 이전에 제거한다.

```text
V01_CHEAP_FAST_LOW = EXCLUDED_CANON_INTERVAL_FAIL
V02_CHEAP_FAST_HIGH = EXCLUDED_CANON_INTERVAL_FAIL
V05_EXPENSIVE_FAST_LOW = EXCLUDED_CANON_INTERVAL_FAIL
V06_EXPENSIVE_FAST_HIGH = EXCLUDED_CANON_INTERVAL_FAIL
```

이 판정은 Monte Carlo 결과가 아니라 정본 생산간격과 후보 multiplier의 결정론적 계산이다.

## 3. Opportunity-cost observable

현재 승인된 MapRun baseline의 비교 형식을 그대로 사용한다.

```text
COMPARISON_FORM = VECTOR_GOLD_TIME_FOOD_NODE_NO_SINGLE_WEIGHTED_SCORE
GOLD_EQUIVALENT = investment_gold / 40
TIME_EQUIVALENT = first_unit_wait_active_combat_seconds / 50
FOOD_EQUIVALENT = unit_food_cost / 6
NODE_EQUIVALENT = occupied_optional_nodes / 2
SINGLE_WEIGHTED_SCORE = FORBIDDEN
```

Observable 정의:

```text
SPECIAL_BUILD_GOLD_EQUIVALENT
  = special_barracks_t1_cost_gold / general_barracks_t1_cost_gold

SPECIAL_FIRST_UNIT_WAIT_EQUIVALENT_BY_OUTCOME
  = selected_special_first_unit_wait_active_combat_seconds / 50

SPECIAL_FOOD_EQUIVALENT_BY_OUTCOME
  = selected_special_food_cost / 6

SPECIAL_NODE_EQUIVALENT
  = one_optional_special_barracks_node / 2
```

특수 T1 선정 가중치는 현재 5종 각각 20%이며 결과별 time/food observable을 보존한다. 평균 하나로 합쳐 특정 거인·비행병 같은 높은 기회비용을 숨기지 않는다.

## 4. 기존 5/10 decision screen 보존

아래는 hard screening으로 계속 선행한다.

```text
SPECIAL_TOKEN_SHARE_10_MIN <= 0.35
SPECIAL_TOKEN_SHARE_BURST_MAX <= 0.45
SECOND_SPECIAL_MARGINAL_VALUE_RATIO <= 0.80
REROLL_EXPECTED_VALUE_GAIN = 0.0
SECOND_SPECIAL_TOKEN_SOURCE = DEFERRED_UNTIL_3_NON_SPECIAL_ACTIVE_SOURCES
```

combat-dependent raw metrics는 계속 `DIAGNOSTIC_NON_IDENTIFIABLE`이다. 이 Decision은 그 값을 selection score로 승격하지 않는다.

## 5. Pareto와 baseline-preservation 규칙

정본이 단일 weighted score를 금지하므로 비용·시간·food·node를 임의 가중합하지 않는다.

```text
SELECTION_MODE = HARD_FILTER_THEN_PARETO
PARETO_DIRECTION_GOLD = LOWER_IS_LOWER_OPPORTUNITY_COST
PARETO_DIRECTION_TIME = LOWER_IS_LOWER_OPPORTUNITY_COST
FOOD_AND_NODE = OUTCOME_OR_STRUCTURE_TERMS_PRESERVED
POST_HOC_WEIGHT_TUNING = FORBIDDEN
```

hard interval filter 뒤 현재 2k grid의 경제·생산 축은 다음처럼 축약된다.

```text
V00_BASELINE:
  BUILD_COST = 60
  INTERVAL_MULTIPLIER = 1.70
  CANON_INTERVAL = PASS

V03/V04_CHEAP_SLOW:
  BUILD_COST = 50
  INTERVAL_MULTIPLIER = 2.20
  CANON_INTERVAL = PASS

V07/V08_EXPENSIVE_SLOW:
  BUILD_COST = 80
  INTERVAL_MULTIPLIER = 2.20
  CANON_INTERVAL = PASS
  PARETO = DOMINATED_BY_V03_V04_ON_GOLD_WITH_SAME_INTERVAL
```

`V00`과 `V03/V04`는 비용 대 생산시간 trade-off라 서로를 Pareto 지배하지 않는다. 이때 이전 승인 정본 보존 원칙을 사용한다.

```text
BASELINE_PRESERVATION_TIEBREAK = IF_CURRENT_APPROVED_BASELINE_IS_HARD_GATE_PASS_AND_PARETO_NONDOMINATED_KEEP_BASELINE
ECONOMY_PRODUCTION_ENVELOPE = V00_BASELINE_COST_INTERVAL_ONLY
SPECIAL_BARRACKS_COST_GOLD_FOR_NEXT_ROBUSTNESS = 60
SPECIAL_INTERVAL_MULTIPLIER_FOR_NEXT_ROBUSTNESS = 1.70
SPECIAL_FUNCTIONAL_VALUE_INDEX_FOR_SELECTION = NOT_SELECTED
```

이것은 최종 3D 파라미터 벡터 확정이 아니다. 비용·생산간격에 대해 새 증거 없이 기존 승인 baseline을 임의 변경하지 않는 보수적 simulation envelope 고정이다.

## 6. Functional-value 차원 보류

```text
SPECIAL_FUNCTIONAL_VALUE_INDEX = DEFERRED_UNTIL_PRODUCT_COMBAT_NUMERICS
COMBAT_POWER_SCALAR = FORBIDDEN
SUPPORT_TU_NUMERIC_INJECTION = FORBIDDEN
ROLE_BLIND_UNIT_EQUIVALENT = DIAGNOSTIC_ONLY
```

기능가치는 제품 전투 수치·역할 출력이 정본화된 뒤 별도 Gate에서 관측한다. 그 전까지 LOW/HIGH label은 final-selection 차원이 아니다.
