## 1. 교정 목적

이 문서는 사용자 이미지 검수로 확정된 인게임 HUD·룰렛 작업대·전장 시야·병종 이미지 사용 규칙을 소유한다. 기존 Decision 8·9의 내용 중 아래와 충돌하는 화면 배치와 시각 자산 규칙은 이 문서가 우선한다.

핵심 목표는 다음과 같다.

> 전장 전체를 계속 확인하면서, 낮고 가로로 긴 룰렛 작업대에서 이동·회전·결과 확인을 한 흐름으로 처리한다.

## 2. 전장 시야

### 평상시

- 기본 카메라는 기존 초기 시안보다 더 멀리서 본다.
- 아군 본진부터 적 본진까지 상·중·하 세 전선, 주요 거점과 건설 노드를 한 화면에서 읽을 수 있어야 한다.
- 평상시 하단 기능 바는 얇게 유지한다.

### 룰렛 작업대가 열린 상태

- 룰렛 패널은 화면 아래를 **세로로 낮고 가로로 길게** 사용한다.
- 패널을 열어도 전장 전체 구도가 위쪽 화면에 남아야 한다.
- 아군 본진, 적 본진 또는 특정 전선이 패널 때문에 잘리면 실패다.
- 필요하면 전장 카메라를 일시적으로 더 멀리 조정하되 세 전선의 판독 가능성은 유지한다.
- 정확한 픽셀·비율·카메라 수치는 Codex와 UI 제작 단계가 조정한다.

## 3. 건설 노드 시각 언어

건설 노드는 장식보다 상태 판독을 우선한다.

- 빈 노드: 밝은 원형 석판과 중앙 건설 문양.
- 설치 가능: 금색 외곽선과 약한 맥동.
- 선택: 예상 건물 실루엣과 설치 범위.
- 사용 중: 건물 바닥 문양으로 전환.
- 설치 불가: 잠금 또는 금지 아이콘.
- 점령권 상실: 적 문양과 오염된 외곽선.
- 색상만으로 상태를 구분하지 않고 형태·아이콘·맥동을 함께 사용한다.

## 4. 룰렛 작업대 전체 구성

룰렛 작업대는 좌·중·우 세 영역으로 구성한다.

```text
┌──────────────┬──────────────────────────────┬─────────────────────┐
│ 좌측         │ 중앙                         │ 우측                │
│ 이동권       │ 3×3 룰렛 보드                │ 회전 비용           │
│ 럭키 찬스    │ 세로 릴·가로 행 이동 화살표  │ [룰렛 돌리기]       │
│ 병종 Tier    │                              │ 결과 보상 Preview   │
│ 보상 등급    │                              │ [결과 확정]         │
│              │                              │ 벨루 초상·대사      │
└──────────────┴──────────────────────────────┴─────────────────────┘
```

### 좌측 — 조작 자원과 규칙

- 보관 이동권 `n/3`.
- 현재 SpinSession의 럭키 무료 이동 횟수.
- 병종 Tier 설명.
- 동일 심벌 완성선 수에 따른 보상 등급 설명.
- 최근 이동 기록은 표시하지 않는다.
- TokenSource 출처, Source ID와 내부 가중치는 표시하지 않는다.

보상 등급 설명은 다음 줄 수를 항상 확인할 수 있어야 한다.

```text
1줄 = 일반
2줄 = 엘리트
3~7줄 = 영웅
8줄 = 전설
9칸 동일 = 주기 변환
```

### 중앙 — 룰렛 조작

- 중앙 영역은 작업대에서 가장 넓게 사용한다.
- 하나의 3×3 노출 보드를 중심으로 표시한다.
- 보드 크기는 토큰을 즉시 판독할 수 있을 만큼 충분히 크되 전장 시야를 압박할 정도로 세로 확대하지 않는다.
- 빈 공간은 새 정보로 채우지 않고 룰렛 보드와 방향 화살표의 판독성에 사용한다.

### 우측 — 실행·결과·벨루

위에서 아래 순서를 사용한다.

```text
회전 비용
[룰렛 돌리기]
결과 보상 Preview
[결과 확정]
벨루 초상·짧은 대사
```

- 룰렛 안에는 전술스킬 목록이나 마석 UI를 중복 표시하지 않는다.
- 벨루는 별도 목록이 아니라 현재 룰렛 결과나 전황을 설명하는 우측 하단 안내자다.

## 5. 룰렛 보드와 이동 화살표

```text
      ▲     ▲     ▲

◀  [토큰] [토큰] [토큰]  ▶
◀  [토큰] [토큰] [토큰]  ▶
◀  [토큰] [토큰] [토큰]  ▶

      ▼     ▼     ▼
```

- 위·아래 화살표는 각 세로 릴을 직접 가리킨다.
- 왼쪽·오른쪽 화살표는 각 가로 행을 직접 가리킨다.
- 화살표 위치만 보고 어느 릴 또는 행이 어느 방향으로 움직이는지 알 수 있어야 한다.
- 선택된 릴 또는 행만 강조한다.
- 이동 후 위치를 실행 전에 미리 보여준다.
- 세로 이동은 해당 릴만 한 칸 회전한다.
- 가로 이동은 해당 행의 세 토큰을 순환 이동한다.

## 6. 병종 토큰과 결과 보상의 이미지 규칙

### 병종 토큰

- 최종 게임의 병종 토큰은 말·방패·활·지팡이 같은 별도 추상 기호만으로 대체하지 않는다.
- **게임에서 실제 사용하는 해당 병종 이미지**를 토큰 크기에 맞춰 축소·크롭하여 사용한다.
- 토큰에서도 병종의 얼굴, 대표 무기 또는 실루엣 중 최소 하나가 즉시 인식돼야 한다.
- 병종 Tier가 달라도 같은 계열임을 알아볼 수 있도록 핵심 실루엣과 대표 무기를 유지한다.
- 작은 크기에서 읽히지 않는 세부 장식은 제거하거나 단순화할 수 있다.

### 결과 보상 Preview

- 결과 보상 카드는 게임에서 실제 사용하는 병종 이미지를 더 크게 표시한다.
- 같은 병종의 룰렛 토큰과 결과 보상 카드가 서로 다른 캐릭터처럼 보이면 안 된다.
- 보상 카드에는 병종 이미지와 함께 이름, 보상 등급, Tier, 핵심 역할을 표시한다.
- 확정 뒤 보관·판매·배치 단계에서도 같은 병종 이미지를 유지한다.

### 비병종 토큰

- 금화, 공백 X, 특수 주기 토큰 등 병종이 아닌 토큰은 전용 상징 아이콘을 사용한다.
- 병종 이미지와 비병종 상징은 형태만으로도 구분돼야 한다.

### 자산 일관성

```text
룰렛 병종 토큰
→ 결과 보상 카드
→ 보관함 카드
→ 전선 배치 카드
→ 실제 전장 병종
```

위 다섯 위치는 동일한 병종 정체성과 아트 계보를 공유한다.

## 7. 룰렛 돌리기·결과 Preview·확정

### 회전 전

- 회전 비용과 `룰렛 돌리기` 버튼을 우측 상단에 표시한다.
- 회전 전에는 결과 보상 Preview를 비어 있거나 대기 상태로 표시한다.
- 결과 확정 버튼은 비활성화한다.

### 회전 완료

- 결과 보상 Preview를 세로 카드 형태로 표시한다.
- 실제 병종 이미지, 병종명, Tier, 보상 등급과 핵심 역할을 보여준다.
- 완성된 줄 수와 해당 보상 등급의 관계를 함께 확인할 수 있어야 한다.
- `결과 확정` 버튼을 활성화한다.

### 결과 확정

- 확정 시 immutable PendingReward를 생성한다.
- 결과 보상 카드는 이후 보관·판매·배치 선택으로 이어진다.
- `룰렛 돌리기`는 시작 행동, `결과 확정`은 결과 수령 행동으로 시각적 위계를 분리한다.

## 8. 하단 기능 바

평상시 기능 순서는 유지한다.

```text
[룰렛] [보관함] [건설] [전술스킬] [벨루]
```

- 벨루는 우측 하단 초상과 짧은 말풍선으로 전황을 설명한다.
- 룰렛 작업대 안에는 전술스킬을 중복 노출하지 않는다.
- 상점 버튼은 없으며 상인은 Stage 종료 정비시간에만 방문한다.

## 9. 이미지 생성 상태

- 사용자의 직접 지시에 따라 추가 이미지 생성을 중단한다.
- 대화 중 생성한 이미지는 레이아웃·분위기 참고용이며 기획 정본이나 최종 게임 자산이 아니다.
- 실제 제작 자산은 본 문서의 규칙과 프로젝트 병종 아트 원본을 기준으로 제작한다.
