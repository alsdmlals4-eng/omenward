# 건물·전문화 제안서 검토 질문

책임 제안서: `docs/design/proposals/0005-building-tiers-lifecycle-and-economy.md`

이미 승인된 방향:

- 적이 있어도 건설·업그레이드 진행
- 건설 중 구조물은 공격받아 완공 전에 파괴 가능
- Tier 1 공통 → Tier 2 전문화 → Tier 3 심화·교리
- 토큰 증폭은 랜덤으로 정해진 릴 하나에 토큰 1개 추가
- 병영 Tier 1 검사 → Tier 2 기병·창병·궁병 중 하나 선택
- 병영 전문화 시 생산 병종과 기본 토큰 교체
- 포탑 제압형·요새형·장거리형 방향

사용자 조정이 필요한 항목:

1. 건설 중 구조물의 시작 체력과 진행도별 체력 증가 곡선
2. 건설 중 구조물이 적의 이동을 막는 정도
3. 후방 안전 노드의 포탑 건설 허용 여부
4. Tier 2 전문화 비용을 모두 같게 할지 효과별로 다르게 할지
5. Tier 3에서 같은 방향만 고정 심화할지 별도 교리 선택을 허용할지
6. 병영 Tier 3 대량생산·정예훈련·토큰 증폭의 정확한 효과
7. 농장과 시장의 전문화 선택지
8. 토큰 증폭 Tier 3에서 추가 토큰을 같은 릴에 쌓을지 다른 릴에 배치할지
9. 건설 취소 70%, 업그레이드 취소 50%, 철거 환불 40%
10. 폐허 15초, 수리 제외와 Ready 슬롯 1개 기존안

승인 전에는 Godot 구현으로 옮기지 않는다.
