# 건물·경제 제안서 검토 질문

책임 제안서: `docs/design/proposals/0005-building-tiers-lifecycle-and-economy.md`

사용자 조정이 필요한 항목:

1. 후방 안전 노드에서는 포탑 건설을 금지한다.
2. 업그레이드 중에는 이전 Tier 기능과 룰렛 토큰을 유지한다.
3. 건설 취소는 70%, 업그레이드 취소는 50% 환불한다.
4. 완공 건물 철거는 기본 건설비의 40%만 환불하며 업그레이드비는 환불하지 않는다.
5. 적에게 파괴된 노드는 15초 동안 폐허가 된다.
6. 첫 프로토타입에서는 수동 수리와 자동 체력 재생을 제외한다.
7. 농장 식량은 Tier별 총 +5 / +8 / +12를 기본값으로 한다.
8. 시장 수입률은 Tier별 1.0 / 1.6 / 2.4를 기본값으로 한다.
9. 훈련시설은 60초 / 45초 / 35초 생산이며 Tier 3에서 매 4번째 유닛을 엘리트로 만든다.
10. 포탑은 Tier 2까지 접전지에 닿지 않고 Tier 3에서 가장자리에만 제한적으로 영향을 준다.
11. 훈련시설은 완성 유닛을 내부 Ready 슬롯 1개에 보존하며 슬롯이 차면 생산을 멈춘다.
12. Tier 1 비용은 포탑 12 / 농장 15 / 시장 20 / 훈련시설 25를 초기값으로 한다.

승인 전에는 `GAME_DESIGN.md`의 확정 계약이나 Godot 구현으로 옮기지 않는다.
