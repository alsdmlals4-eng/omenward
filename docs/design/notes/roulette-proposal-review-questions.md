# 룰렛 제안서 검토 질문

책임 제안서: `docs/design/proposals/0004-roulette-resolution-bench-and-lucky-chance.md`

사용자 조정이 필요한 항목:

1. 기준 줄은 회전 전에 선택·고정한다.
2. 혼합 심벌은 종류별로 모두 보상한다.
3. 별 단계와 병사·엘리트·영웅 품질을 별도 축으로 유지한다.
4. 결과 보관함을 두고 미정리 중 다음 회전만 막는다.
5. 대기칸 초기값은 8칸, 수동 합성은 프로토타입에서 제외한다.
6. 금화 환급은 회전 비용의 20% / 45% / 75%로 시작한다.
7. 럭키 찬스는 12%에서 시작해 실패당 +8%p, 6회 실패 후 다음 회전에 확정한다.
8. 자연 럭키 찬스와 이동권을 합쳐 회전당 한 번만 이동한다.
9. 럭키 찬스 결정 시간 제한은 두지 않는다.

승인 전에는 `GAME_DESIGN.md`의 확정 규칙이나 Godot 구현으로 옮기지 않는다.
