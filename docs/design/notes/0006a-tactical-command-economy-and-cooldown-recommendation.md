# 세부 추천 0006-A — 전술 명령 경제·사용·쿨다운

- 상태: **사용자 조정안 대기**
- 구현 상태: 승인 전 구현 금지
- 상위 제안서: `docs/design/proposals/0006-tactical-commands.md`
- 관련 Issue: #9

## 1. 추천 결론

1. 해금된 전술 명령은 HUD에 항상 표시하고 **사용할 때마다 금화를 직접 지불**한다.
2. 기본 전술 명령 자체를 상점의 무작위 1회권으로 판매하지 않는다.
3. 한 스테이지 사용 횟수 하드 제한과 연속 사용 비용 증가를 두지 않는다.
4. 명령별 개별 쿨다운과 **12초 전역 쿨다운**을 함께 사용한다.
5. 일시정지 중에는 전술 명령 하나만 예약할 수 있다.
6. 예약 시 금화를 차감하지 않고 `예약 금액`으로 묶어 다른 지출에 사용할 수 없게 한다.
7. 게임 재개와 명령 실행 시 실제 금화를 차감하고 쿨다운을 시작한다.
8. 대상이 무효가 되면 예약을 취소하고 금화·쿨다운을 소비하지 않는다.
9. 전술 명령의 공격력·체력은 `StageManifest.command_power_level`에 따라 스케일하며 적 현재 체력 비율을 직접 기준으로 하지 않는다.

## 2. 직접 금화 결제 방식

전술 명령은 `한 번 발동할 때 한 번 효과가 나는 능력`이라는 의미의 1회성이다. 사용권을 미리 사서 인벤토리에 보관하는 소비 아이템 방식은 기본 시스템에서 제외한다.

```text
캠페인에서 명령 해금
→ 스테이지 HUD에 고정 등록
→ 전투 중 목표 지정
→ 금화 지불
→ 효과 발동
→ 쿨다운 뒤 다시 사용 가능
```

추천 이유:

- 필요한 순간 사용할 수 있어 위기 대응이 상점 운에 좌우되지 않는다.
- 시장 중심 빌드가 금화 수입을 전술 능력으로 전환하는 계획을 세울 수 있다.
- 상점 재고·새로고침과 전술 명령 접근성을 분리해 시스템을 이해하기 쉽다.
- 명령이 필요한 스테이지에서 구매권이 나오지 않는 불공정 상황을 피한다.

상점은 후속으로 다음만 판매할 수 있다.

- 전술 명령 비용 할인 아이템
- 쿨다운 감소 아이템
- 범위·지속시간을 바꾸는 런 한정 강화
- 기본 네 명령과 다른 희귀 전술 명령

## 3. 일시정지 예약

일시정지 중 전술 명령을 선택하고 목표를 확정하면 `PendingCommand` 하나를 만든다.

```text
command_id
target_lane
target_point
reserved_gold
preview_payload
```

규칙:

- 동시에 예약 가능한 전술 명령은 1개다.
- 예약 금액은 HUD의 사용 가능 금화에서 제외한다.
- 재개 전 취소하면 전액 예약 해제한다.
- 재개 시 목표가 유효하면 금화를 실제 차감하고 시전을 시작한다.
- 재개 시 목표가 무효라면 자동 취소하고 금화와 쿨다운을 소비하지 않는다.
- 건설·상점·룰렛 예약 금액과 합산해 보유 금화를 초과할 수 없다.

여러 명령을 일시정지 중 겹쳐 예약해 재개 직후 웨이브를 삭제하는 방식은 허용하지 않는다.

## 4. 쿨다운 구조

### 전역 쿨다운

- 한 명령이 정상 실행되면 모든 전술 명령에 **12초** 전역 쿨다운을 적용한다.
- 시전 지연이 있는 명령은 명령 확정 시점부터 전역 쿨다운을 시작한다.
- 대상 무효로 실행이 취소되면 전역 쿨다운도 시작하지 않는다.

### 개별 쿨다운 초기값

| 명령 | 개별 쿨다운 |
|---|---:|
| 바리케이드 | 30초 |
| 화살비 | 40초 |
| 역병 | 50초 |
| 강화지대 | 45초 |

- 개별 쿨다운과 전역 쿨다운이 모두 끝나야 다시 사용할 수 있다.
- 시장 특화와 아이템으로 쿨다운을 줄일 경우 전역 쿨다운 최소값은 6초로 제한한다.
- 같은 명령의 스테이지당 사용 횟수 상한은 두지 않는다.
- 사용 횟수에 따른 가격 상승은 기본 규칙에 넣지 않는다.

## 5. 비용 초기값

기존 Tier 1 건설비 가설과 비교하기 위한 초기값이다.

| 명령 | 기본 금화 비용 | 상대 역할 |
|---|---:|---|
| 바리케이드 | 12 | 값싼 긴급 지연 |
| 화살비 | 18 | 일반 병력 즉시 약화 |
| 역병 | 22 | 지원·회복 웨이브 대응 |
| 강화지대 | 24 | 아군 병력의 공격·방어 전환 |

최종 비용:

```text
기본 비용
× DifficultyProfile.command_cost_multiplier
× Constraint.command_cost_multiplier
× 시장·아이템 할인
```

- 최종 비용은 정수로 반올림한다.
- 할인 합계는 건물 전문화 추천 기준 최대 24%를 기본 상한으로 둔다.
- 금화 부족 시 부족량을 표시한다.

## 6. Command Power

화살비·역병 피해와 바리케이드 체력이 후반 스테이지에서 무의미해지거나 초반을 삭제하지 않도록 `StageManifest`가 전술 명령 위력 단계를 제공한다.

```text
command_power_level
command_damage_scalar
command_structure_hp_scalar
command_buff_scalar
```

- 피해를 적 현재 체력의 고정 비율로 계산하지 않는다.
- 일반·엘리트·영웅·지휘관 대상별 계수를 사용한다.
- 같은 시드·난이도·제약은 같은 Command Power 값을 만든다.
- 스테이지 생성기는 특정 전술 명령을 필수로 요구하지 않는다.

## 7. 바리케이드 추천안

역할은 적을 죽이는 것이 아니라 포탑 완공과 증원 도착까지 시간을 버는 것이다.

- 자신의 전방 거점과 중앙 접전지 사이에 마련된 지정 전술 지점에만 설치한다.
- 적 진영 전방 거점 너머에는 설치할 수 없다.
- 아군 유닛은 통과하고 적 유닛만 하드 차단한다.
- 라인당 동시에 하나만 활성화할 수 있다.
- 활성 바리케이드가 있는 라인에는 새 바리케이드를 사용할 수 없다.
- 공격 기능, 룰렛 토큰, 식량과 건설 노드를 사용하지 않는다.
- 시전 지연 1.5초
- 지속시간 18초 또는 체력 0까지
- 기본 체력은 해당 스테이지 Tier 1 포탑 체력의 약 70%
- 공성병은 바리케이드에 추가 피해를 줄 수 있다.

바리케이드는 일반 건물과 달리 이동 차단을 가진 유일한 플레이어 구조물이다.

## 8. 화살비 추천안

- 목표 구역을 지정한 뒤 1.2초 경고를 표시한다.
- 1.2초 동안 세 차례 피해를 주어 유닛이 범위를 벗어날 대응 여지를 둔다.
- 같은 스테이지 일반 병사에게 총 최대 체력의 약 60%에 해당하는 기준 피해를 목표로 한다.
- 엘리트 대상 피해 계수 0.65
- 영웅·지휘관 대상 피해 계수 0.30
- 적 건물·본진·바리케이드 피해 0
- 아군 피해 없음

정확한 피해량은 Command Power와 유닛 방어 계산을 거친다. 화살비 하나만으로 정상 체력의 결전 웨이브를 삭제할 수 없어야 한다.

## 9. 역병 추천안

- 지정 구역 지속시간 10초
- 구역 안 적에게 1초마다 지속 피해
- 일반 병사 기준 전체 지속시간 동안 최대 체력 약 35% 상당의 기준 피해
- 받는 치유량 50% 감소
- 영웅·지휘관은 지속 피해 계수 0.50, 치유 감소는 동일 적용
- 동일 대상에게 다시 적용하면 피해를 중첩하지 않고 지속시간만 갱신
- 건물·본진·바리케이드에는 적용하지 않음

화살비보다 즉시 피해가 낮고 지원병·장기 교전 대응에 강하도록 역할을 분리한다.

## 10. 강화지대 추천안

- 지속시간 12초
- 구역 안 아군 유닛 공격속도 +20%
- 구역 안 아군 유닛이 받는 피해 -15%
- 구역을 벗어나면 1초 유예 뒤 효과 종료
- 포탑·건물·바리케이드에는 적용하지 않음
- 동일 강화지대는 중첩하지 않고 남은 시간이 긴 효과로 갱신
- 다른 출처의 병종 버프와는 곱연산이 아닌 별도 데이터 규칙으로 계산하되 총 공격속도 상한을 둔다.

강화지대는 병력이 없는 라인에서는 가치가 없으므로 공격 병력과 함께 사용해야 한다.

## 11. 해금 순서 추천

튜토리얼은 긴 설명을 피하고 전술 명령 하나만 소개한다.

| 구간 | 해금 |
|---|---|
| 튜토리얼 | 바리케이드 |
| 정규 스테이지 1 | 화살비 |
| 정규 스테이지 3 | 역병 |
| 정규 스테이지 4 | 강화지대 |

튜토리얼에서는 적이 다가오는 동안 바리케이드를 사용해 포탑이 완공될 시간을 버는 짧은 장면으로 건설 시스템과 함께 소개한다.

## 12. UI 계약

전술 명령 패널은 다음을 표시한다.

- 해금 여부와 잠긴 이유
- 기본 비용, 할인과 최종 비용
- 현재 금화, 예약 금액과 사용 후 잔액
- 개별·전역 쿨다운
- 대상 가능 지역과 불가능 지역
- 효과 범위, 시전 지연과 지속시간
- Command Power가 반영된 예상 피해·체력·버프
- 현재 라인에 활성 바리케이드·역병·강화지대 존재 여부

일시정지 예약 중에는 `예약됨` 상태와 취소 키를 강조한다.

## 13. 검증 시나리오

- 상점 재고와 무관하게 해금된 명령이 HUD에 표시된다.
- 금화가 충분하면 같은 스테이지에서 여러 번 사용할 수 있다.
- 전역 쿨다운 중 다른 명령을 사용할 수 없다.
- 일시정지 중 두 번째 명령을 예약할 수 없다.
- 예약 금액 때문에 다른 구매가 보유 금화를 초과하지 않는다.
- 무효 대상 취소는 금화와 쿨다운을 소비하지 않는다.
- 바리케이드는 아군을 막지 않고 적만 차단한다.
- 라인 하나에 바리케이드 두 개를 겹쳐 설치할 수 없다.
- 화살비와 역병은 건물·본진에 피해를 주지 않는다.
- 역병과 강화지대의 동일 효과가 무한 중첩되지 않는다.
- 같은 StageManifest와 입력은 같은 효과 결과를 만든다.

## 14. 사용자 조정 항목

1. 상점 1회권이 아닌 항상 사용 가능한 직접 금화 결제
2. 전역 쿨다운 12초와 개별 쿨다운 30/40/50/45초
3. 일시정지 중 PendingCommand 1개 제한
4. 기본 비용 12/18/22/24
5. 바리케이드 아군 통과·적 차단, 라인당 1개
6. 화살비 세 차례 피해와 대상 계수
7. 역병 10초·치유 감소 50%·비중첩
8. 강화지대 공격속도 20%·피해 감소 15%
9. 튜토리얼 바리케이드 소개와 해금 순서

승인된 항목만 상위 승인 문서와 구현 계약으로 이동한다.
