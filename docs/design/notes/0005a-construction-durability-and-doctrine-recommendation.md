# 세부 추천 0005-A — 건설 내구도·충돌과 Tier 교리

- 상태: **사용자 조정안 대기**
- 구현 상태: 승인 전 구현 금지
- 상위 제안서: `docs/design/proposals/0005-building-tiers-lifecycle-and-economy.md`
- 관련 Issue: #8

## 1. 추천 결론

1. 건설 시작 체력은 완공 최대 체력의 **25%**로 둔다.
2. 건설 진행으로 추가되는 구조 체력은 현재 체력에도 같은 양만큼 더하며, 받은 피해는 절대값으로 보존한다.
3. 일반 건물과 건설 중 구조물은 라인 이동을 하드 차단하지 않는다. 적의 이동을 직접 막는 기능은 전술 명령 `바리케이드`만 담당한다.
4. 같은 시뮬레이션 틱에서는 `건설 진행·완공 → 기능 활성화 → 공격 피해` 순서로 처리한다.
5. Tier 2 전문화 비용은 건물별로 동일하게 두고 효과 강도로 균형을 맞춘다.
6. 포탑·시장·농장은 Tier 2 방향을 Tier 3에서 고정 심화한다.
7. 병영은 Tier 2에서 병종을 고르고 Tier 3에서 `대량생산 / 정예훈련 / 토큰 증폭` 교리를 추가 선택한다.
8. 전문화는 철거·파괴 전까지 변경할 수 없다.

## 2. 건설 체력 계산

건설 진행률을 `p` (`0.0~1.0`), 완공 최대 체력을 `H`라고 한다.

```text
건설 중 허용 최대 체력 = H × (0.25 + 0.75 × p)
```

건설 시작 시:

```text
현재 체력 = 허용 최대 체력 = H × 0.25
누적 피해 = 0
```

진행도가 올라가 허용 최대 체력이 증가할 때 현재 체력에도 증가분을 더한다.

```text
현재 체력 = 새 허용 최대 체력 - 지금까지 받은 누적 피해
```

예시:

```text
완공 체력 H = 100
건설 시작 체력 = 25
건설 도중 총 18 피해를 받음
완공 시 현재 체력 = 100 - 18 = 82
```

추천 이유:

- 초반에 받은 피해가 완공과 함께 사라지지 않는다.
- 공사가 진행될수록 새 구조물이 추가되어 버티는 시간이 자연스럽게 늘어난다.
- 체력 비율을 보존하는 방식보다 초반 작은 피해가 과도하게 확대되지 않는다.
- 완공 직전 포탑이 살아남는 장면을 만들 수 있다.

### 파괴와 완공

- 현재 체력이 0이 되는 순간 건설 실패로 처리한다.
- 실패하면 기능을 활성화하지 않고 환불 없이 폐허로 전환한다.
- 완공 시 별도 무적시간과 무료 완전 회복을 제공하지 않는다.
- 완공 뒤에도 건설 중부터 공격하던 적은 타깃을 유지한다.

## 3. 같은 틱의 처리 순서

동일한 고정 시뮬레이션 틱에서 완공과 적 공격이 겹칠 때 다음 순서를 사용한다.

```text
1. 건설·업그레이드 시간 진행
2. 100% 도달 시 상태 전환
3. 새 기능·전문화·최대 체력 적용
4. 공격과 피해 판정
5. 파괴·사망 판정
```

따라서 포탑이 해당 틱에 완공되면 공격 기능과 완공 체력을 얻은 뒤 적의 공격을 받는다. UI의 남은 건설시간과 실제 결과가 일치하도록 고정 틱 단위로 표시한다.

## 4. 업그레이드 중 체력

업그레이드는 기존 건물이 작동하는 상태에서 진행한다.

- 업그레이드 진행 중에는 현재 Tier의 최대 체력과 기능을 유지한다.
- 업그레이드 진행 자체가 체력을 회복시키지 않는다.
- 업그레이드 완료로 최대 체력이 증가하면 증가한 최대 체력만큼 현재 체력에도 더한다.
- 기존에 받은 피해의 절대값은 유지한다.

예시:

```text
Tier 1 최대 체력 100 / 현재 체력 60
Tier 2 최대 체력 150으로 업그레이드 완료
→ 현재 체력 110 / 최대 체력 150
```

요새형처럼 피해 감소를 얻는 전문화는 완료 이후의 공격부터 적용한다.

## 5. 충돌과 길막

일반 건물은 건설 중이거나 완공됐는지와 관계없이 라인의 내비게이션을 하드 차단하지 않는 것을 추천한다.

- 건설 노드는 기본 이동 회랑 바깥에 배치한다.
- 건물은 공격 가능한 타깃이지만 길을 막는 벽으로 사용하지 않는다.
- 적 AI는 우선순위에 따라 멈춰 건물·포탑을 공격할 수 있다.
- 건물 설치로 내비게이션 경로를 매번 재계산하지 않는다.
- 공사 현장을 반복 설치해 적을 가두는 플레이를 허용하지 않는다.
- 적의 전진을 실제로 차단하는 기능은 지정 지점의 `바리케이드`만 가진다.

`MapTemplate` Validator는 모든 일반 건설 노드가 라인 이동 회랑을 침범하지 않는지 검사한다.

## 6. 전문화 비용과 변경

- 같은 건물의 동일 Tier 전문화는 **같은 금화 비용과 같은 업그레이드시간**을 사용한다.
- 비싼 선택지가 더 강하다는 오해를 만들지 않고 효과 자체를 비교하게 한다.
- 선택 전에 전문화 결과, 토큰 변화와 전투 효과를 모두 공개한다.
- 선택 완료 후 재전문화는 불가능하다.
- 다른 방향이 필요하면 철거 후 다시 건설한다.

정확한 공통 비용 배율은 기존 가설인 Tier 2 `기본비 ×1.5`, Tier 3 `기본비 ×2.25`부터 테스트한다.

## 7. 병영 Tier 3 교리

Tier 2에서 기병·창병·궁병 중 병종을 결정하고, Tier 3에서 다음 교리 중 하나를 선택한다.

### 7.1 대량생산

- 생산 간격 **25% 감소** 초기 가설
- 생산 유닛의 등급과 전투 능력은 기본값 유지
- Ready 슬롯이 차면 다른 병영과 동일하게 생산 정지

### 7.2 정예훈련

전문화 완료 후 생산되는 유닛에 시설 출처 기반 영구 버프를 준다.

초기 가설:

```text
최대 체력 +15%
공격 피해 +10%
```

- 병사·엘리트·영웅 등급 자체는 변경하지 않는다.
- 식량 비용은 증가하지 않는다.
- 이미 생산된 유닛과 용병에는 적용하지 않는다.
- 생산 병영이 파괴돼도 이미 받은 훈련 버프는 유지한다.

### 7.3 토큰 증폭

- 선택 병종 토큰 1개를 결정론적으로 선택된 릴 하나에 추가한다.
- 어떤 릴이 강화되는지는 교리 선택 전에 공개한다.
- 병영 하나가 제공하는 보너스 토큰은 Tier 3에서 최대 1개다.

## 8. 시장 전문화 추천

### 금고시장

- 해당 시장의 정기 수입에 집중한다.
- Tier 2: Tier 1 기준 수입 `×1.5`
- Tier 3: Tier 1 기준 수입 `×2.2`
- 추가 금화 토큰이나 상점 할인은 제공하지 않는다.

### 군수시장

- 해당 시장의 수입은 Tier 1 기본값을 유지한다.
- 용병과 전술 명령 금화 비용을 할인한다.
- Tier 2: 시장 하나당 8%, Tier 3: 시장 하나당 12%
- 여러 군수시장의 할인은 합산하되 전역 상한은 **24%**다.

### 행운시장

- 해당 시장의 수입은 Tier 1 기본값을 유지한다.
- Tier 2: 금화 토큰 1개를 결정된 릴 하나에 추가한다.
- Tier 3: 첫 릴과 다른 릴 하나에 금화 토큰 1개를 추가한다.
- 한 시장이 같은 릴에 보너스 토큰 두 개를 몰아주지 않는다.

## 9. 농장 전문화 추천

### 대농장

- 최대 식량에 집중한다.
- 초기 총 식량 가설: Tier 1 `+5`, Tier 2 `+8`, Tier 3 `+12`

### 보급소

- 식량 증가는 Tier 1 기본값 `+5`를 유지한다.
- 새로 출전한 아군 유닛은 첫 교전 또는 아군 전방 거점 도달 전까지 `행군`을 얻는다.
- Tier 2 이동속도 +20%, Tier 3 +30% 초기 가설
- 전투가 시작되면 즉시 효과가 끝나 전투 능력치를 직접 올리지 않는다.

### 비축창고

- 식량 증가는 Tier 1 기본값 `+5`를 유지한다.
- 파괴되어도 식량 기여가 즉시 사라지지 않고 비상 비축 시간 뒤 제거된다.
- Tier 2 12초, Tier 3 20초 초기 가설
- 비축 시간 동안 새 농장을 완공하면 식량 초과를 피할 수 있다.
- 건물이 파괴됐으므로 룰렛 토큰·기타 기능은 즉시 제거한다.

## 10. 포탑 전문화 추천

Tier 2에서 선택한 방향을 Tier 3에서 고정 심화한다. Tier 3에서 다른 포탑 방향으로 갈아탈 수 없다.

### 제압형

- Tier 2: 주 대상 주변 최대 2명에게 본 피해의 35%
- Tier 3: 주변 최대 4명에게 본 피해의 50%
- 건물·본진에는 범위 피해가 전달되지 않는다.

### 요새형

- Tier 2: 최대 체력 +60%, 공격속도 -10%
- Tier 3: 최대 체력 +120%, 받는 피해 -15%, 공격속도 -15%
- 공격력을 높이지 않고 시간을 버는 역할로 제한한다.

### 장거리형

- Tier 2: 사거리 +25%, 공격속도 -10%, 접전지 도달 불가
- Tier 3: 사거리 +50%, 공격속도 -15%, 접전지 가장자리 제한 지원
- 접전지 전체나 적 전방 거점까지 덮지 못한다.

## 11. 검증 시나리오

- 체력 25%로 시작한 포탑이 피해를 받으면서도 공사를 계속한다.
- 누적 피해가 완공 시 사라지지 않는다.
- 완공과 공격이 같은 틱이면 완공 상태 적용 후 피해를 받는다.
- 일반 건설물을 반복 설치해 적 이동을 막을 수 없다.
- 바리케이드 외 일반 건물은 내비게이션 하드 차단을 만들지 않는다.
- 같은 Tier의 전문화 선택 비용은 동일하다.
- 병영 Tier 3 교리 세 가지가 동시에 적용되지 않는다.
- 정예훈련은 기존 유닛과 용병을 소급 강화하지 않는다.
- 행운시장 Tier 3의 두 보너스 토큰은 서로 다른 릴에 배치된다.
- 군수시장 할인 합계는 24%를 넘지 않는다.
- 장거리형 Tier 2는 접전지에 닿지 않고 Tier 3만 가장자리를 지원한다.

## 12. 사용자 조정 항목

1. 건설 시작 체력 25%
2. 누적 피해 절대값 보존 방식
3. 동일 틱에서 완공을 공격보다 먼저 처리
4. 일반 건물 하드 길막 없음, 바리케이드만 길막
5. 같은 Tier 전문화 동일 비용
6. 병영 교리 수치 25% / 체력 15%·공격 10% / 토큰 1개
7. 시장의 금고·군수·행운 전문화
8. 농장의 대농장·보급소·비축창고 전문화
9. 포탑 전문화 초기 수치
