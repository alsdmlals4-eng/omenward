# 승인된 룰렛 핵심 규칙

- 갱신일: 2026-07-24
- 상태: `V2_SPEC_APPROVED / V2_IMPLEMENTATION_NOT_STARTED`
- 기존 구현: `LEGACY_C1_ROULETTE_CORE_REMOTE_PROVEN / MIGRATION_REQUIRED`
- 승인 근거: 2026-07-24 사용자 확정
- 상위 책임: `docs/PROJECT_CORE.md`
- 통합 관계: `docs/design/APPROVED_CORE_V2_INTEGRATED_SPEC.md`

이 문서는 룰렛의 물리 릴, 토큰 공급, 회전, 이동, snapshot, 판정, 럭키, 전설 주기와 결과 확정 계약을 소유한다.

## 1. 용어와 상태

- **릴 / Reel**: 길이 3 이상의 원형 `TokenInstance` 배열.
- **토큰 인스턴스 / TokenInstance**: 고유 ID, 심벌, 출처 건물, 보상 판정 데이터를 가진 개별 토큰.
- **cursor / start_index**: 릴에서 현재 노출 3칸의 첫 인덱스.
- **정지 보드**: 세 릴에서 노출된 3×3 토큰.
- **SpinSnapshot**: 회전 정지 시점의 릴, cursor, 보드, 비용, 출처 후보와 보상 데이터를 깊은 복사한 불변 객체.
- **SpinSession**: 정지 후 이동·예측·확정까지의 단일 거래.
- **live 릴 상태**: 다음 회전에 사용할 맵런의 현재 릴 배열.

## 2. 물리 구조

화면에는 항상 3×3 토큰 9개가 보인다. 내부에는 왼쪽, 중앙, 오른쪽 세 원형 릴이 있다.

- 각 릴의 길이는 3 이상이다.
- 마지막 토큰 다음에는 첫 토큰이 연결된다.
- 각 릴은 독립적으로 같은 확률의 정지 시작 인덱스를 선택한다.
- 선택한 시작 인덱스부터 연속된 3개 토큰을 wrap하여 노출한다.
- 동일 릴 상태와 RNG stream은 동일한 정지 보드를 만든다.

## 3. 초기 상태와 X

맵런 시작 시 각 릴은 X 세 개로 시작한다.

```text
왼쪽  [X, X, X]
중앙  [X, X, X]
오른쪽[X, X, X]
```

X는 보상을 만들지 않는 빈 토큰이다. X 세 개도 당첨이 아니다.

## 4. TokenSource 건물

모든 건물이 자동으로 토큰을 공급하지 않는다. `TokenSource` 계약을 가진 건물만 토큰을 공급한다.

TokenSource 건물 한 동은 같은 심벌·출처의 토큰을 각 릴에 하나씩, 총 세 개 제공한다.

### 4.1 토큰 추가

각 릴마다 다음 순서를 적용한다.

1. 배열 인덱스 0부터 검색한다.
2. 가장 낮은 안정 배열 인덱스의 X를 찾으면 그 위치를 새 토큰으로 교체한다.
3. X가 없을 때만 배열 끝에 새 토큰을 append한다.
4. 현재 cursor와 노출 위치는 X 선택에 영향을 주지 않는다.
5. 새 토큰은 고유 `token_instance_id`와 `source_building_instance_id`를 가진다.

### 4.2 허용 심벌

코어 심벌은 다음으로 제한한다.

- 병종 계열 심벌.
- 금화 심벌.
- X.

전술 아이템 룰렛 심벌은 별도 사용자 승인 전 추가하지 않는다. 이동 아이템은 미션, 이벤트, 특수 적, 전술 건물과 업적형 조건에서 획득한다.

### 4.3 건물 파괴·비활성화

- 파괴·비활성화된 건물의 `source_building_instance_id`를 가진 토큰을 live 릴에서 모두 제거한다.
- 토큰이 가로 이동으로 다른 릴에 옮겨졌어도 출처 ID로 제거한다.
- 제거 후 릴 길이가 3보다 작으면 X를 추가해 길이 3을 보장한다.
- 이미 생성된 `SpinSnapshot`은 수정하지 않는다.
- 파괴 효과는 다음 회전부터 반영한다.

## 5. 회전

회전을 시작하기 전에 다음을 검증한다.

- 미확정 SpinSession이 없음.
- 처리하지 않은 결과 대기 병력이 없음.
- 보관함이 완전히 차 새 병력 결과를 받을 수 없는 상태가 아님.
- 무료 회전권 또는 지불 가능한 금화가 있음.

검증 실패 시 회전권과 금화를 소비하지 않는다.

회전 시:

1. 실제 비용 또는 무료 회전권을 확정한다.
2. 세 릴이 독립적으로 균등한 시작 인덱스를 선택한다.
3. 3×3 자연 정지 보드를 만든다.
4. immutable `SpinSnapshot`을 생성한다.
5. 자연 결과를 판정한다.
6. 자연 중앙줄 꽝이면 럭키를 판정한다.
7. 플레이어가 이동·예측·확정을 처리한다.

## 6. SpinSnapshot

SpinSnapshot은 다음 데이터를 깊은 복사로 보존한다.

- 세 릴의 전체 토큰 순서.
- 각 릴 cursor/start index.
- 노출 3×3 보드.
- 각 `token_instance_id`.
- `symbol_id`.
- `source_building_instance_id`.
- 판정용 reward payload.
- 실제 회전 비용.
- 정지 시점의 동일 심벌 출처 후보와 가중치.
- 자연 결과와 럭키 판정 결과.

건물이 파괴되거나 live 릴이 이후 변경되어도 snapshot은 변하지 않는다. 확정 보상은 live 건물이나 live 릴을 다시 조회하지 않고 snapshot과 SpinSession 최종 보드만 사용한다.

## 7. 이동 공통 규칙

이동 기회는 다음 중 하나를 소비한다.

- 보유 이동 아이템 1개.
- 현재 회전에 발생한 럭키 무료 이동 1회.

공통 규칙:

- 한 회전의 이동 횟수 상한은 없다.
- 이동은 실행 즉시 소비·확정한다.
- 실행 취소, 전체 초기화, 이전 상태 복원이 없다.
- 이동 전 preview는 복제 상태에서 계산하며 live 상태를 변경하지 않는다.
- 이동 뒤 보상 예측을 즉시 다시 계산한다.

## 8. 세로 이동

세로 이동은 선택한 한 릴의 전체 원형 배열을 위 또는 아래로 한 칸 회전한다.

- 릴의 cursor가 한 칸 변한다.
- 숨은 인접 토큰이 새로 노출된다.
- 배열 순서와 릴 소속은 변하지 않는다.
- 다른 릴은 변하지 않는다.

## 9. 가로 이동

가로 이동은 선택한 노출 행의 세 `TokenInstance`를 왼쪽 또는 오른쪽으로 원형 순환 교환한다.

- 배열에 insert 또는 remove를 수행하지 않는다.
- 세 릴의 길이는 변하지 않는다.
- 세 릴의 cursor/start index는 변하지 않는다.
- 선택 행에 대응하는 각 릴의 현재 노출 인덱스 값만 교환한다.
- 토큰 ID, 심벌, 출처 건물과 reward payload가 함께 이동한다.
- 변경된 live 릴 배열은 이후 회전에도 유지된다.

오른쪽 이동:

```text
오른쪽 릴 토큰 → 왼쪽 릴의 선택 행 인덱스
왼쪽 릴 토큰   → 중앙 릴의 선택 행 인덱스
중앙 릴 토큰   → 오른쪽 릴의 선택 행 인덱스
```

왼쪽 이동은 반대 방향이다.

## 10. 기본 판정 줄

- 기본 판정 줄은 중앙 가로줄이다.
- 중앙줄 세 칸이 동일한 비-X 심벌일 때만 보상을 판정한다.
- 중앙줄이 실패하면 다른 일곱 줄은 무시한다.
- 중앙줄이 성공하면 그 심벌을 판정 심벌로 고정한다.

## 11. 완성선과 등급

검사 대상은 가로 3줄, 세로 3줄, 대각선 2줄이다.

- 판정 심벌과 같은 심벌로 완성된 줄만 센다.
- 중앙 판정 줄도 한 줄로 포함한다.
- 겹치는 줄도 각각 센다.

| 동일 심벌 완성선 | 유닛 결과 |
|---:|---|
| 1줄 | 일반 |
| 2줄 | 엘리트 |
| 3~7줄 | 영웅 |
| 8줄·9칸 전체 동일 | 전설 또는 주기 변환 |

등급은 최종 확정 시점의 보드로 결정한다.

## 12. 계열 심벌과 출처 결정

같은 기본 병종 계열은 Tier와 세부 병종이 달라도 같은 심벌을 공유한다.

보상 결정 순서:

1. 최종 보드와 판정 심벌·등급을 확정한다.
2. SpinSnapshot 전체 세 릴에서 판정 심벌과 같은 토큰 출처를 후보로 수집한다.
3. snapshot에 저장된 가중치로 세부 출처를 결정한다.
4. 일반 등급은 선택 출처의 실제 병종을 생성한다.
5. 상위 등급은 승인된 계열 템플릿을 사용한다.
6. 선택 출처 Tier가 패시브 단계에 영향을 주는 기존 계약은 별도 데이터 마이그레이션에서 보존한다.

확정 전에 출처 건물이 파괴되어도 snapshot 후보와 reward payload를 사용하므로 보상은 정상 지급된다.

## 13. 금화 판정

중앙줄이 금화 3개면 같은 방식으로 금화 완성선을 센다.

| 금화 완성선 | 보상 |
|---:|---:|
| 1줄 | 실제 회전 비용의 75% |
| 2줄 | 실제 회전 비용의 200% |
| 3줄 이상 | 실제 회전 비용의 500% |

- 할인 후 실제 지불액을 기준으로 한다.
- 무료 회전은 경제 시뮬레이션에서 승인한 기준 회전가를 사용한다.
- 금화에는 유닛 등급과 전설 주기를 적용하지 않는다.
- 지급액 반올림은 `floor`를 기본 계약으로 유지한다.

## 14. 전설 위험 주기

전설 유닛은 5스테이지 위험 주기마다 병종 공용 1회다.

```text
1~5 / 6~10 / 11~15 / 16~20 / 21~25 ...
```

- 전설 결과 확정 시 해당 주기의 한도를 소비한다.
- 보관, 배치, 판매, 사망으로 한도가 복구되지 않는다.
- 이미 한도를 사용한 주기에 다시 9칸 동일 유닛 심벌을 확정하면 같은 계열 영웅 2기로 변환한다.
- UI는 현재 주기와 `0/1` 또는 `1/1`을 항상 표시한다.
- 금화 결과는 전설 한도와 무관하다.

## 15. 럭키

럭키는 자연 정지 보드의 중앙줄이 당첨되지 않은 경우에만 판정한다. 다른 줄의 완성 여부는 자연 꽝 판정에 영향을 주지 않는다.

실패 보정:

| 럭키 판정 전 유효 실패 | 성공 확률 |
|---:|---:|
| 0 | 15% |
| 1 | 25% |
| 2 | 35% |
| 3 | 45% |
| 4 | 55% |
| 5 | 100% |

- 확률과 실패 횟수는 플레이어에게 숨긴다.
- 성공 시 현재 회전에만 무료 이동 1회를 준다.
- 무료 이동은 일반 이동 아이템과 같은 기능이다.
- 사용하지 않은 무료 이동은 확정 시 소멸하며 이월·판매할 수 없다.
- 럭키 발생 즉시 실패 카운터는 0으로 초기화한다.

### 15.1 truth table

| 자연 정지 | 럭키 | 최종 확정 | 실패 카운터 |
|---|---|---|---|
| 당첨 | 판정 없음 | 당첨 | 0 |
| 당첨 | 판정 없음 | 아이템 조작 후 꽝 | 0 유지 |
| 꽝 | 성공 | 당첨 | 0 |
| 꽝 | 성공 | 무료 이동 미사용 또는 최종 꽝 | 0 |
| 꽝 | 실패 | 아이템 조작 후 당첨 | 0 |
| 꽝 | 실패 | 최종 꽝 | +1 |

럭키 상태는 맵런 동안 유지하고 런 종료 시 초기화한다. 영구 성장으로 확률·보정표를 변경하지 않는다.

## 16. 예측과 확정

각 이동 뒤 다음을 예측한다.

- 판정 심벌.
- 완성선 수.
- 등급과 유닛 수.
- 출처 후보와 최종 출처 결정 규칙.
- 전설 변환 여부.
- 필요한 보관 슬롯.
- 금화 지급액.

`[확정]` 시:

1. 최종 보드를 한 번 평가한다.
2. 보상을 한 번 생성한다.
3. 금화는 즉시 지급하고 유닛은 결과 대기 또는 보관 처리로 넘긴다.
4. 현재 럭키 무료 이동을 소멸시킨다.
5. SpinSession을 닫고 반복 확정을 거부한다.
6. 변경된 live 릴 배열은 유지한다.

확정은 idempotent하다. 같은 SpinSession에서 두 번째 확정은 아무 보상도 만들지 않는다.

## 17. 결과 수령 경계

- 미확정 결과가 있으면 새 회전을 차단한다.
- 유닛 결과는 공간 부족으로 사라지지 않는다.
- 보관함과 결과 대기 세부는 `APPROVED_CORE_V2_INTEGRATED_SPEC.md`와 맵런 책임 문서를 따른다.
- 금화 결과는 결과 대기 슬롯을 사용하지 않는다.

## 18. 기존 규칙 강등

다음 규칙은 V2 현재 정본이 아니다.

```text
스테이지당 전설 1회
기본 럭키 12%·실패당 +8%p
럭키 확률과 남은 실패 횟수 공개
여러 이동 되돌리기·전체 초기화
최종 확정 시 이동권 소비
독립 9칸 가중 추첨
전술 아이템 룰렛 심벌
```

기존 C1 구현 증거는 보존하지만 위 항목은 `LEGACY_IMPLEMENTED / MIGRATION_REQUIRED`로만 기록한다.

## 19. 검증 계약

- 각 릴 길이 3 이상과 토큰 ID 유일성.
- 길이 3·4·N에서 wrap 노출.
- 최저 안정 index X 교체와 X 부재 append.
- 가로 이동 뒤 길이·cursor 불변과 토큰 ID 이동.
- 이동된 토큰의 출처 건물 파괴 제거.
- 멈춤 뒤 건물 파괴 후 동일 보상.
- 중앙줄 실패 시 다른 줄 무시.
- 1/2/3~7/8 등급.
- 금화 75/200/500%.
- 럭키 truth table 전체.
- 위험 주기 전설 1회와 영웅 2기 변환.
- 반복 확정 무보상.
- 같은 상태·입력·시드의 동일 결과.

## Legacy C1 보존 증거

- C1 중앙 판정·완성선·등급·보상·보관 REMOTE_PROVEN
- 검증된 legacy resolver는 V2 migration에서 보존 seam으로만 사용한다.
