# 승인된 룰렛 핵심 규칙

- 상태: **핵심 구조·등급 생성 경로 승인됨 / 세부 밸런스 일부 미확정**
- 승인일: 2026-07-14
- 관련 제안서: `docs/design/proposals/0004-roulette-resolution-bench-and-lucky-chance.md`
- 경제 빌드 계약: `docs/design/APPROVED_ECONOMY_BUILDS_AND_TERMINAL_ASSAULT.md`
- 유닛 능력 성장 계약: `docs/design/APPROVED_UNIT_GRADE_AND_ABILITY_GROWTH.md`

## 1. 기본 판정 줄

- 기본 판정 줄은 3×3 보드의 **가운데 가로줄 1개**로 고정한다.
- 플레이어는 기본 상태에서 상단·하단 줄을 임의로 선택할 수 없다.
- 특정 아이템 효과가 있을 때만 판정 줄을 변경하거나 선택할 수 있다.
- 줄 변경 아이템의 정확한 지속시간, 소비 여부와 상·하단 선택 방식은 별도 아이템 제안에서 확정한다.
- 판정 줄은 회전 비용을 지불한 시점에 고정되며, 회전 도중에는 아이템을 새로 장착하거나 해제해 바꾸지 못한다.

## 2. 기본 보상 조건

판정 줄의 세 칸이 **동일한 비-X 심벌**일 때만 보상이 발생한다.

```text
[검사, 검사, 검사] → 검사 보상 판정 시작
[검사, 검사, 기병] → 보상 없음
[검사, 기병, 궁병] → 보상 없음
[검사, 검사, X] → 보상 없음
[X, X, X] → 보상 없음
```

- 같은 심벌 1개 또는 2개만으로는 보상을 지급하지 않는다.
- 혼합 심벌을 종류별로 나눠 지급하지 않는다.
- 판정 줄이 3개 일치하면 해당 심벌을 `판정 심벌`로 고정하고 전체 8개 줄을 검사한다.

## 3. 완성 줄 계산

검사 대상은 다음 8개 줄이다.

- 가로 3줄
- 세로 3줄
- 대각선 2줄

규칙:

- 판정 심벌과 같은 심벌로 세 칸이 완성된 줄만 센다.
- 판정 줄도 완성 줄 1개에 포함한다.
- 서로 겹치는 줄은 각각 센다.
- 다른 심벌의 완성 줄은 무시한다.
- 판정 줄이 3개 일치하지 않았다면 다른 곳의 완성 줄도 보상으로 인정하지 않는다.

## 4. 유닛 등급 생성

| 판정 심벌 완성 줄 수 | 보상 |
|---:|---|
| 1줄 | 해당 병종 **일반 병사 1명** |
| 2줄 | 해당 병종 **엘리트 1명** |
| 3~7줄 | 해당 병종 **영웅 1명** |
| 8줄, 즉 9칸 전체 동일 | 해당 병종 **전설 1명** |

유닛 등급은 룰렛 최종 보상 판정 시점에 직접 생성한다.

- 일반 유닛 합성으로 엘리트·영웅·전설을 만드는 시스템은 사용하지 않는다.
- 처치 경험치나 전투 시간으로 유닛 등급이 상승하지 않는다.
- 건물 Tier나 생산시설 업그레이드가 이미 생성된 유닛의 등급을 바꾸지 않는다.
- 병영 자동 생산은 기본적으로 일반 등급 유닛을 만든다.
- 병영 `정예훈련`은 등급 상승이 아니라 해당 시설에서 새로 생산되는 유닛의 능력치를 강화한다.
- 상점에서 상위 등급 용병을 직접 판매하는 구조는 현재 승인 범위에서 제외한다.
- 등급별 핵심 패시브·스킬 성장 규칙은 `APPROVED_UNIT_GRADE_AND_ABILITY_GROWTH.md`에서 관리한다.

### 4.1 2줄 예시

기본 중앙줄을 판정 줄로 사용한 예시:

```text
검사 / 기병 / 궁병
검사 / 검사 / 검사
검사 / 금화 / 마법사
```

- 중앙 가로줄: 검사 완성
- 왼쪽 세로줄: 검사 완성
- 총 2줄이므로 **엘리트 검사 1명**

### 4.2 3줄 예시

```text
검사 / 검사 / 기병
검사 / 검사 / 검사
검사 / 검사 / 궁병
```

- 중앙 가로줄
- 왼쪽 세로줄
- 가운데 세로줄
- 총 3줄이므로 **영웅 검사 1명**

### 4.3 전설 제한

- 9칸 전체가 같은 유닛 심벌일 때 전설 등급 조건을 충족한다.
- 전설 소환은 **한 스테이지/한 판 전체에서 병종과 관계없이 1회만** 가능하다.
- 이미 전설을 소환한 뒤 다시 9칸 동일 유닛 심벌이 나오면 해당 병종의 **영웅 2명**으로 변환한다.
- 전설 사용 여부는 룰렛 UI에 항상 표시한다.
- 금화 심벌은 전설 등급을 만들지 않는다.

## 5. 금화 심벌

금화도 판정 줄이 `[금화, 금화, 금화]`일 때만 지급한다. 이후 전체 보드에서 금화 완성 줄 수를 센다.

| 금화 완성 줄 수 | 환급 비율 |
|---:|---:|
| 1줄 | 실제 지불한 회전 비용의 **75%** |
| 2줄 | 실제 지불한 회전 비용의 **200%** |
| 3줄 이상 | 실제 지불한 회전 비용의 **500%** |

```text
금화 보상 = floor(실제 지불한 회전 비용 × 환급 비율)
```

- 할인 후 실제 지불액을 기준으로 한다.
- 금화 9칸 전체 동일도 `3줄 이상`으로 처리해 500% 상한을 적용한다.
- 금화에는 병사·엘리트·영웅·전설 등급을 적용하지 않는다.
- 시장 다수 건설로 금화 보드를 높은 확률 또는 확정 상태로 만드는 전략을 허용한다.
- 금화와 별개의 회전 충전, 웨이브당 보상 횟수 제한과 연속 보상 감쇠를 기본 규칙에 넣지 않는다.
- 시장 특화의 대가는 병영 부족, 건설 노드 점유, 식량 부족, 포탑·용병·상점 소비와 결전 웨이브 압박으로 설계한다.
- 시장+포탑+용병은 정식 빌드로 인정하며 세부 계약은 `APPROVED_ECONOMY_BUILDS_AND_TERMINAL_ASSAULT.md`에서 관리한다.

## 6. 럭키 찬스

기본 구조:

```text
기본 확률: 12%
자연 실패 1회당: +8%p
6회 연속 자연 실패 후 다음 회전: 100% 확정
자연 발생 시: 현재 기본 확률로 초기화
```

- 현재 확률과 확정까지 남은 실패 횟수는 UI에 공개한다.
- `행운` 아이템은 럭키 찬스의 **초기 기본 확률**을 올린다.
- 자연 발생 뒤 초기화되는 값도 아이템 보정이 적용된 기본 확률이다.
- 실패당 +8%p와 6회 실패 뒤 확정 구조는 유지한다.
- 행운 아이템 1개당 증가량, 중첩 상한과 희귀도는 별도 아이템 제안에서 확정한다.

## 7. 행·열 이동과 이동권

- 자연 럭키 찬스가 발생하면 무료 이동 1회를 얻는다.
- 이동권은 자연 럭키 찬스 발생 여부와 관계없이 사용할 수 있다.
- 자연 럭키 찬스 무료 이동과 이동권은 같은 회전에 함께 사용할 수 있다.
- 회전당 이동 횟수 상한은 없다.
- 실제 상한은 보유 이동권 수로만 제한한다.
- 이동권 1장은 행 또는 열의 1칸 순환 이동 1회를 제공한다.

허용 이동:

- 가로줄 하나를 왼쪽 또는 오른쪽으로 1칸 순환
- 세로줄 하나를 위 또는 아래로 1칸 순환

### 7.1 이동 계획과 소비

- 여러 이동을 연속으로 계획하고 최종 보상 변화를 미리 볼 수 있다.
- 자연 럭키 찬스가 있으면 첫 이동 1회는 무료 이동 크레딧을 사용한다.
- 그 이후 이동 1회마다 이동권 1장을 예약한다.
- 최종 판을 확정할 때만 예약한 이동권을 실제 소비한다.
- 확정 전 되돌리기나 전체 초기화로 예약 이동권 수를 줄일 수 있다.
- 최종 확정 뒤에는 되돌릴 수 없고 보상은 한 번만 계산한다.

## 8. 유지되는 결과 보관 원칙

이번 승인으로 대기칸 세부 수치는 확정하지 않았지만 다음 원칙은 유지한다.

- 룰렛 유닛 보상은 공간 부족으로 사라지지 않는다.
- 보상 정리 전에는 다음 룰렛 회전만 차단한다.
- 전투·건설·카메라·기존 유닛 배치는 계속 진행한다.
- 금화 보상은 즉시 지급한다.
- 현재 구조에서는 한 회전당 유닛 보상 묶음이 최대 1개다.

## 9. 아직 미확정인 항목

- 판정 줄 변경 아이템의 정확한 효과와 지속시간
- 행운 아이템 1개당 확률 증가량과 중첩 상한
- 대기칸 기본 용량과 결과 보관함의 최종 UI
- 이동권 보유 상한과 상점 가격
- 시장·포탑·용병 빌드와 병영 빌드의 정확한 효율 관계
- 결전 웨이브의 정확한 출격 시간과 Threat Budget
- 등급별 정확한 능력치 배율
- 병종별 엘리트·영웅·전설 추가 핵심 능력과 기존 능력 강화량
- 상점 용병의 등급 표기와 일반 등급 고정 여부

## 10. 검증 계약

- 기본 상태에서는 중앙 가로줄만 판정한다.
- 혼합 줄과 2개 일치는 보상을 만들지 않는다.
- 중앙줄 3개 일치가 있을 때만 해당 심벌의 전체 완성 줄을 센다.
- 1/2/3~7/8줄은 일반/엘리트/영웅/전설을 만든다.
- 2줄 예시는 엘리트, 3줄 예시는 영웅을 만든다.
- 유닛 9칸 동일은 첫 1회 전설, 이후 영웅 2명을 만든다.
- 수동 합성·처치 경험치·건물 Tier로 유닛 등급이 바뀌지 않는다.
- 병영 정예훈련 버프는 등급 변화로 기록하지 않는다.
- 금화 1/2/3줄 이상은 각각 75%/200%/500%를 지급한다.
- 시장 특화 상태에서도 별도 회전 충전 없이 금화가 있는 한 회전할 수 있다.
- 자연 럭키 찬스와 여러 이동권을 같은 회전에 사용할 수 있다.
- 이동권은 최종 확정 시에만 소비된다.
- 같은 최종 판에서 보상은 한 번만 지급된다.
