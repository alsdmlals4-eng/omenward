## 2. 기본 병영

```text
Tier 1 기본 병영
- 일반 검사 자동생산
- 전사 토큰 제공

Tier 2 전문화
- 방패병 / 전사 토큰
- 대검전사 / 전사 토큰
- 암살자 / 암살자 토큰
- 창병 / 창병 토큰
- 궁병 / 궁병 토큰
- 기병 / 기병 토큰
```

기본 병영 규칙:

- 자동생산과 룰렛 토큰을 모두 제공한다.
- 한 병영은 Tier 2 전문화 하나만 선택한다.
- 서로 다른 병영은 다른 전문화를 선택할 수 있다.
- 업그레이드 중에는 이전 생산과 토큰을 유지한다.
- 생산 진행률을 보존한다.
- 완료 뒤 첫 완성분부터 새 병종을 자동생산한다.
- 토큰 변경은 다음 룰렛 회전부터 적용한다.
- 자동생산은 항상 일반 등급이다.

사제는 기본 병영 전문화에서 제거한다.

## 3. 특수병단

건물 표시명은 **특수병단**을 사용한다. 공식 영문명과 세계관 세부 명칭은 후속 조정한다.

```text
Tier 1 특수병단
- 유닛 자동생산 없음
- 룰렛 토큰 없음
- 전투·경제·식량 효과 없음
- Tier 2 전문화를 위한 준비 시설

Tier 2 전문화
- 사제단 / 사제 토큰
- 마도단 / 마법사 토큰
- 거인단 / 거인 토큰
- 비행단 / 비행 토큰
```

Tier 1 고정 규칙:

- 완공만으로는 토큰을 추가하지 않는다.
- 자동생산 유닛이 없다.
- 수입·식량·방어·오라 효과가 없다.
- 완공 뒤 즉시 Tier 2 전문화 선택이 가능하다.
- 준비 단계라는 사실과 Tier 2 총비용·시간을 건설 전에 공개한다.

Tier 2 고정 규칙:

- 전문화 완료 순간부터 선택한 특수 토큰을 각 릴에 기본 1개씩 제공한다.
- 진행 중인 룰렛은 유지하고 다음 회전부터 토큰을 적용한다.
- 특수병단은 기본적으로 유닛을 자동생산하지 않는다.
- 일반·엘리트·영웅·전설 특수 유닛은 룰렛 결과로 획득한다.
- 한 특수병단은 전문화 하나만 선택한다.
- 여러 특수병단을 지어 서로 다른 특수 계열을 열 수 있다.
- 건물이 파괴되면 다음 회전부터 해당 토큰이 제거된다.

이 구조는 강한 특수 유닛이 시간 경과만으로 누적되는 것을 막고, 특수병단 투자와 룰렛 성공을 직접 연결한다.

## 4. 룰렛 등급 계약

특수병종도 공통 등급 판정을 사용한다.

| 완성 줄 | 결과 |
|---:|---|
| 1줄 | 일반 특수 유닛 |
| 2줄 | 고정 엘리트 특수 유닛 |
| 3~7줄 | 고정 영웅 특수 유닛 |
| 8줄·9칸 동일 | 고정 전설 특수 유닛 |

- 플레이어 신화급은 생성하지 않는다.
- 특수병단 Tier 2 출처는 Tier 2 패시브 성장 단계를 적용한다.
- 특수병단 Tier 3은 아직 승인하지 않는다.
- 상위 등급 유닛은 계열별 고정 템플릿을 사용한다.

고정 특수 계열:

```text
priest_support
mage
large_giant
flying_unit
```

## 5. 기본 병영과 특수병단의 전략 차이

```text
기본 병영
- 즉시 전력과 장기 생산량
- 일반 병종 자동생산
- 비교적 낮은 투자 위험
- 상성 대응의 기본 골격

특수병단
- 생산량보다 룰렛 기대값
- 강한 특수 유닛 토큰 해금
- 높은 선행 투자
- 토큰 풀 복잡도와 실패 위험 증가
```

기본 병영 여러 채는 안정적인 병력량을 만든다. 특수병단 투자는 현재 병력 생산을 포기하고 강한 특수 결과를 룰렛 풀에 추가하는 선택이다.

## 6. 상성 순환

```text
거인·기병·대형 돌진
→ 창병이 대응

비행병
→ 궁병·대공궁병이 대응

사제·마법사·지휘 지원
→ 암살자가 대응

밀집 일반병
→ 대검전사·마법사가 대응

중장갑·구조물
→ 대검전사 파쇄·거인이 대응

거인
→ 창병 대형 보너스·마법 피해·방어 파쇄·지속 피해가 대응
```

특수병종은 기본 병종의 상위호환이 아니라, 기본 병종이 명확하게 대응할 수 있는 고위험·고영향 전력이어야 한다.

## 7. 건물 상태 전이

기본 병영:

```text
Tier 1 Active
→ Tier 2 Upgrading
→ Tier 2 Specialized
→ Tier 3 Upgrading
→ Tier 3 Advanced
```

특수병단:

```text
Tier 1 Preparation
→ Tier 2 Upgrading
→ Tier 2 Specialized
```

- 특수병단 Tier 1은 `Preparation` 상태지만 정상 건물로 공격받고 파괴될 수 있다.
- 건설·업그레이드는 적이 있어도 계속 진행된다.
- Tier 2 완공 전 파괴되면 토큰을 한 번도 제공하지 못한다.
- 특수병단 Tier 3은 병종별 역할 검증 뒤 별도 승인한다.

## 9. 검증 계약

1. 기본 병영 Tier 2 선택지는 6종만 표시한다.
2. 사제는 기본 병영에서 생산하거나 토큰을 제공하지 않는다.
3. 특수병단 Tier 1은 토큰·자동생산·전투·경제 효과가 없다.
4. 특수병단 Tier 2 완료 전 특수 토큰이 룰렛에 나타나지 않는다.
5. 특수병단 Tier 2는 선택 계열 토큰만 제공한다.
6. 특수병단은 기본적으로 유닛을 자동생산하지 않는다.
7. 사제·마법사·거인·비행병은 룰렛으로만 생성한다.
8. 거인과 비행병은 기본 병영 일반 생산량을 대체하지 않는다.
9. 특수병종에도 일반·엘리트·영웅·전설 등급 계약을 적용한다.
10. 강한 특수병종은 기본 병종의 명확한 카운터를 가진다.
11. 건설 전 Tier 1+Tier 2 총 투자와 토큰 활성 시점을 공개한다.
12. Godot 구현은 별도 Plan Mode 승인 전 시작하지 않는다.

## 10. 후속 조정 대상

- 특수병단 Tier 1·Tier 2 비용과 건설시간.
- 특수 토큰이 릴당 1개인지 별도 가중치를 사용할지 최종값.
- 특수병단 Tier 3 도입 여부와 분기.
- 사제·마법사·비행병 능력 계보.
- 거인 절대 능력치와 공격 범위.
- 계열별 엘리트·영웅·전설 고정 유닛.
- 캠페인 해금 순서와 첫 등장 스테이지.
