# 승인된 한 판 구조와 프로토타입 분량

- 승인일: 2026-07-14
- 상태: 구현 계약으로 사용 가능
- 관련 제안서: `docs/design/proposals/0001-match-structure-and-start-conditions.md`
- 결전 계약: `docs/design/APPROVED_ECONOMY_BUILDS_AND_TERMINAL_ASSAULT.md`

## 제품 범위

- 첫 공개 프로토타입은 **싱글플레이 PvE**를 우선한다.
- 우선 플랫폼은 Windows PC, 입력은 마우스와 키보드다.
- 첫 공개 프로토타입의 목표 총 플레이 분량은 **약 3시간**이다.
- 3시간은 한 번의 전투 시간이 아니라 여러 스테이지로 구성된 프로토타입 캠페인의 총 분량이다.

## 개별 전투 길이

- 정규 스테이지 한 판의 목표 시간은 평균 25~35분이다.
- 핵심 시스템 수직 슬라이스는 10~15분 안에 검증할 수 있게 만든다.
- 첫 공개 프로토타입은 6개 안팎의 스테이지를 기본 가설로 삼고, 튜토리얼·결과·재도전 시간을 포함해 총 165~195분 범위를 목표로 한다.
- 실제 스테이지 수와 각 스테이지 길이는 절차적 스테이지 생성기 제안서에서 조정한다.

## 시작 상태

- 플레이어 본진만 존재한다.
- 후방 노드 6개와 라인별 전방 노드 3개는 비어 있다.
- 시장, 농장, 훈련소, 포탑은 미건설 상태로 시작한다.
- 룰렛의 실제 토큰은 0개이며 각 릴은 X 토큰 3개로 채워진다.
- 실제 토큰이 하나도 없을 때는 룰렛 회전을 차단하고 이유를 표시한다.
- 시작 금화는 `Tier 1 경제시설 1개 + 기본 훈련소 1개 + 룰렛 약 2회`가 가능한 예산을 목표로 하며 정확한 값은 데이터로 조정한다.

## 첫 웨이브와 접전지

- 첫 웨이브의 라인, 병종, 정확한 수량은 게임 시작과 동시에 공개한다.
- 첫 웨이브는 게임 시작 60초 뒤 출격한다.
- 첫 웨이브는 한 라인 중심이며 특수 능력, 공성, 후방 침투를 사용하지 않는다.
- 중앙 접전지는 첫 웨이브 출격과 함께 활성화한다.
- 두 번째 웨이브부터 기본 30초 전조 규칙을 적용한다.

## 게임 속도

- 일시정지, 1배속, 2배속을 제공한다.
- 일시정지 중 정보 확인, 건설·업그레이드 예약, 유닛 출전 예약과 룰렛 조작을 허용한다.
- 웨이브 출격 10초 전, 본진·시설 피격, 새 접전 발생, 식량·대기칸 문제 발생 시 2배속을 자동으로 1배속으로 되돌린다.
- 3배속 이상은 MVP에서 제외한다.

## 승패와 장기전

- 적 본진 파괴 시 승리한다.
- 플레이어 본진 파괴 시 패배한다.
- 같은 시뮬레이션 틱에 양쪽 본진이 파괴되면 상호 파괴로 기록한다.
- 강제 시간패는 사용하지 않는다.
- 정규 스테이지에는 적 본진을 파괴하지 못한 경우 출격하는 **결전 웨이브 타이머**를 둔다.
- 기본 초기값은 35분이며 스테이지 목표 시간과 난이도에 따라 데이터로 조정한다.
- 결전 웨이브는 시작 전에 시점이 공개되고 HUD에 남은 시간을 항상 표시한다.
- 출격 5분 전부터 결전 경보를 제공하며 T-30·T-15·T-5 전조와 정확한 병력 정보를 유지한다.
- 결전 웨이브는 세 라인, 공성·지원·지휘관형 병력을 포함하는 초강력 실제 전투다.
- T-10 구성 확정 전 적 생산시설을 파괴하면 해당 병종의 결전 증원량을 줄일 수 있다.
- 결전 웨이브를 막아도 적 본진이 남아 있다면 짧은 간격의 강화 웨이브가 반복될 수 있다.
- 구체적인 출격 시간, 반복 간격과 강화량은 `APPROVED_ECONOMY_BUILDS_AND_TERMINAL_ASSAULT.md`와 스테이지 데이터에서 관리한다.

## 허용되는 경제 전략

- 시장을 다수 건설해 금화 룰렛과 정기 수입에 집중하는 빌드를 허용한다.
- 시장+포탑+상점 용병 조합은 정식 전략이다.
- 금화와 별개의 시간 기반 룰렛 충전은 기본 규칙에 넣지 않는다.
- 시장 특화는 병영 부족, 노드 점유, 식량, 용병 비용과 결전 웨이브를 감당해야 한다.
- 방어 경제를 공격 병력과 적 시설 파괴로 전환할 시점을 판단하는 것이 전략의 핵심이다.

## 결과와 재도전

결과 화면은 다음을 표시한다.

- 승리, 패배, 상호 파괴 또는 포기
- 플레이 시간과 도달 웨이브
- 결전 웨이브 도달·방어 여부
- 건설·파괴된 시설
- 가장 많이 사용한 토큰과 주력 병종
- 구매한 용병과 상점 소비
- 라인별 접전지 점령 시간
- 승리 기여 또는 패배 원인 2~3개

재도전은 다음 두 방식을 제공하는 방향으로 설계한다.

- 같은 스테이지 시드로 재도전
- 새로운 시드로 재생성 후 재도전

## 데이터 조정 항목

다음 값은 구조를 유지한 채 데이터로 조정한다.

- 시작 금화와 기본 수입
- 건설시간과 첫 웨이브 정확한 수량
- 정규 웨이브 간격
- 결전 웨이브 출격 시간·Threat Budget·반복 간격
- 적 건물 파괴에 따른 결전 증원 감소량
- 스테이지별 목표 시간
