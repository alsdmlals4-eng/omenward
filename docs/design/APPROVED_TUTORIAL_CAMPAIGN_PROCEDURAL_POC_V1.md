# 승인된 튜토리얼·3시간 캠페인·절차 생성 PoC V1

- 상태: **캠페인 구조·해금 순서·생성 계약 승인 / 스테이지 이름·세부 수치는 첫 PoC 가설**
- 작성일: 2026-07-16
- 적용 범위: 수동 튜토리얼, 약 3시간 캠페인, 정규 스테이지 생성, 난이도·제약

## 1. 캠페인 전체 길이

```text
튜토리얼 1개
+ 정규 스테이지 9개
= 총 10개 스테이지
```

- 튜토리얼 10~15분.
- 정규 스테이지 각 15분 전후.
- 준비·결과·대사·재도전을 포함해 첫 완료 약 2시간 40분~3시간 20분을 목표로 한다.
- 첫 캠페인 부제는 `오멘워드: 실베른 성채` 가안을 유지한다.

## 2. 해금 순서

| 스테이지 | 신규 핵심 요소 |
|---:|---|
| 0 튜토리얼 | 방패병·대검전사·암살자 선택 체험 |
| 1 | 창병, 돌진·대형 태그 |
| 2 | 궁병, 비행 예고와 대공 |
| 3 | 사제단, 치유·버프·특수병단 준비 할인 |
| 4 | 기병, 라인 돌파·후열 압박 |
| 5 | 마도단, 마법 피해·광역·제어 |
| 6 | 비행단, 지상/비행 레이어 |
| 7 | 거인단, 대형·공성·높은 식량 |
| 8 | 모든 건물 Tier 3·베일의 축복/저주 |
| 9 결전 | 전체 병종·15 전설 보스·초과 공세 가능 |

- 한 스테이지에서 새 핵심 개념은 최대 2개다.
- 신규 병종은 첫 등장 전 벨루가 한 문장, 한 행동, 즉시 결과로 설명한다.

## 3. 튜토리얼 수정안

### 도입
- 괴이현상·베일의 법칙·실베른 성채·벨루를 30초 안에 소개.
- 저승역 설정은 사용하지 않고 현재 오멘워드 세계관을 따른다.

### 고정 흐름
1. 기본 병영 무료 또는 강제 건설.
2. 첫 룰렛 중앙 1줄 일반 검사.
3. 상단 제1공세 방어.
4. 포탑 또는 바리케이드로 첫 역전.
5. 두 번째 회전에서 상단 행 왼쪽 이동으로 엘리트 전사.
6. 제4공세 전 방패병·대검전사·암살자 중 하나를 선택.

### 선택별 대응
- 방패병: 원거리 혼합 공세 대응.
- 대검전사: 밀집 근접 공세 대응.
- 암살자: 원거리·지원 후열 대응.

- 특수병단·시장·Tier 3·비행은 첫 10분에 열지 않는다.
- 튜토리얼 경제는 정규 160금화와 분리하고 무료 회전·강제 비용을 TutorialManifest로 기록한다.

## 4. 스테이지 학습 구조

각 정규 스테이지는 다음 리듬을 사용한다.

```text
0~3분: 익숙한 병종으로 기반 구축
3~6분: 신규 위협 1차 소개
6~10분: 신규 위협과 기존 위협 결합
10분: 영웅 이정표
11~14분: 완성 빌드 검증
15분: 전설 보스 또는 스테이지 결전
```

## 6. WavePatternCard

웨이브는 수동 정의된 카드 조합으로 만든다.

카드 유형:
- 단일 라인 집중.
- 두 라인 압박.
- 세 라인 분산.
- 전후열 조합.
- 돌진·대형.
- 비행 습격.
- 지원 보호.
- 공성 전진.
- 암살 침투.

Validator는 같은 웨이브에 복잡한 특수 카드가 3개 이상 겹치지 못하게 한다.

- 난이도는 숨은 명중·회피나 플레이어 조작 불가 확률을 변경하지 않는다.
- 룰렛 기본 확률은 난이도로 직접 낮추지 않는다.

## 8. 베일의 축복·저주·선언 초안

### 축복
- `풍요의 울림`: 시작 식량 +6, 시장 수입 -1.
- `성벽의 기억`: 포탑·바리케이드 HP +20%, 유닛 이동 -5%.
- `전사의 맹세`: 전사 토큰 +1, 특수 토큰 가중치 -1.

### 저주
- `갈라진 보급로`: 기본 수입 -15%, 중앙 통제 수입 +50%.
- `검은 비상`: 비행 Threat +25%, 대공 피해 +15%.
- `무거운 베일`: 이동속도 -10%, 적 돌진 재사용 +20%.

### 선언
- `적 본진 조기 파괴`: 조기 승리 보너스, W13 이후 적 건물 강화.
- `시장 없는 승리`: 시장 건설 금지, 시작 금화 +30.
- `전설 없는 승리`: 전설 결과를 영웅 2기로 변환, 캠페인 보상 증가.

모든 수정자는 시작 전에 공개하고 상충 조합은 Validator가 차단한다.

## 9. 안전 스테이지 대체

다음 조건이면 생성 결과를 폐기하고 수동 안전 Manifest를 사용한다.

- 첫 대공 해금 전 비행 핵심 위협 등장.
- 한 라인 Threat가 전체의 75% 초과.
- W1~4에 영웅·전설 등장.
- W10 전 특수병종 세 종류가 한 웨이브에 동시 등장.
- 적 건물 파괴 없이 W15 예상 Threat가 목표 범위 20% 초과.
- 시작 자원으로 방어 가능한 건설 조합이 하나도 없음.

## 10. 캠페인 서사 비트

- 초반: 베일의 징조는 법칙처럼 보이지만 누군가 조정하는 흔적 발견.
- 중반: 적 생산시설과 인간의 전력 표식이 유사한 구조임을 암시.
- 후반: 벨루가 실베른 성채의 오래된 방어 기록과 연결됨을 공개.
- 결전: 15웨이브 전설 보스 처치 뒤 베일의 법칙 배후를 다음 캠페인 훅으로 남김.
- 벨루의 기억 완전 회복은 첫 캠페인에서 확정하지 않고 일부 파편만 회복한다.

## 11. 검증 기준

- 신규 시스템 기본 사용을 30초 안에 수행한다.
- 각 신규 병종은 해금 스테이지에서 명확한 카운터 대상이 등장한다.
- 절차 생성 결과가 수동 튜토리얼을 대체하지 않는다.
- 동일 시드·버전은 동일 Manifest를 생성한다.
- 생성 실패는 플레이어에게 노출하지 않고 검증된 안전 스테이지로 교체한다.
- 한 캠페인에서 10병종 모두 최소 한 번은 명확한 효용을 보여준다.
