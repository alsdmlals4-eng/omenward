# OMENWARD 사람용 통합 블루프린트

이 문서는 2026-09-11 사용자 최종 검토를 위한 편집 원본이다. 예시 십보강호 PDF는 구성만 참고했다. 최종 구현 승인, 전투 밸런스 검증, 모든 자산의 납품 완료는 아직 아니다. 수치 표의 책임 입력은 OMENWARD_BLUEPRINT_BUILD_INPUT_20260911.json이며 본문과 PDF가 같은 입력을 읽는다. 이전 20260910 Blueprint는 설계 검토 이력과 근거로 보존한다. 충돌 시 이 검토판의 명시 보완 규칙을 적용하되 사용자 승인 전 runtime은 바꾸지 않는다.

## 읽는 순서와 승인 경계

화면 아틀라스에서 원하는 화면을 찾고, 게임 경험과 상세 SWOT를 읽은 뒤 진행·룰렛·군수·전투를 확인한다. 병종 도감과 건물·공세 데이터는 실제 입력값 후보다. 마지막 구현 지도로 데이터가 어디에 연결되는지 확인한다.

표시: 사용자 확정은 단일 전선, 다섯 순차 맵, 맵마다 10+α 시간제 라운드와 복수 웨이브, 재정비, 생존/본진 점령 두 승리조건, 6+보유 점령지 슬롯이다. 권장 구현 초깃값은 첫 실험을 실행할 만큼 구체적인 숫자이며 재미·공정성 PASS가 아니다.

신규 자산은 후보 상태다. 배경과 불투명 아이콘의 PNG는 포함하지만 전체 병종의 투명 모션·다섯 배경·방어탑·분리 소품은 아직 모두 준비되지 않았다. 따라서 이 파일은 검토판이며 ‘승인 즉시 모든 콘텐츠 구현에 필요한 자산이 완비됐다’고 표시하지 않는다. 구현은 사용자 최종 승인 후 별도 패킷으로 진행한다.

## 핵심 경험과 세계관

플레이어는 징조수호관이다. 베일은 인간 진영의 단순 적색 변형이 아니라 현실을 침식하는 적대 현상이며, 갑각·가시·포자·균열을 가진 군단으로 압박한다. 아군은 질서 있는 군수와 서로 보완하는 병종으로 맞선다.

핵심 재미는 예고를 읽어 대비했다는 만족, 현재 부족한 역할을 찾는 조합, 생존에서 진격으로 전환하는 판단, 살아남은 군단을 다음 라운드로 이어가는 성장이다. 큰 당첨만이 결과의 가치가 되어서는 안 된다.

독창성 가설은 예고된 공세 순서 → 건물 공급 → 룰렛 조정 → 남아 있는 전장 → 다음 준비의 연결이다. 슬롯·자동전투 각각은 선행 사례가 있다. 세계 최초나 법적 독점성은 주장하지 않는다. 플레이어가 이 연결을 설명하지 못하면 정보 전달과 선택 구조부터 수정한다.

## SWOT S · 강점을 강화하는 계획

S1. 단일 전선은 시선을 집중시키고 병종의 기여를 관찰할 수 있는 제약이다. 강화: 화면 중앙을 전투에 할당하고 탭을 바꿔도 공세·시간·위치는 유지한다. 비용: 세부 통계는 펼침으로 이동. 확인: 준비한 병종과 전투 사건을 연결해 설명할 수 있는가.

S2. 두 승리조건은 방어와 진격에 다른 목적을 준다. 강화: 남은 라운드와 본진 점령 가능성을 함께 제시한다. 비용: 조기 점령의 시간 이득과 생존 경제의 균형 검토. 확인: 같은 편성이 모든 상황에서 우월하지 않은가.

S3. 건물과 토큰의 연결은 영구 군수 투자와 즉시 동원의 차이를 만든다. 강화: 건설 전후 실제 공급 병종/가중치를 나란히 표시한다. 비용: 확률 모델과 표시 일치 검사. 확인: 건물 선택이 왜 결과 분포를 바꾸는지 설명 가능한가.

S4. 동화풍 군단은 역할 실루엣과 세계관을 함께 전달할 수 있다. 강화: 장식보다 무기/기관/자세를 먼저 읽히게 한다. 비용: 실제 축소·겹침·모션 검수. 실패 시 장식과 병력 밀도를 줄이지 전체 화풍을 평면화하지 않는다.

## SWOT W · 약점을 개선하는 계획

W1. 현재 main은 세 전선·건설 노드·단일 표적 처리이고 새 기획과 다르다. 개선: 라운드 상태와 단일전선 책임부터 교체하고 역할 효과를 명시 데이터로 연결한다. 우선순위 P0. 완료 증거: 준비/전투/재정비/결과 경계와 비용 1회 적용 테스트.

W2. 동결 상태가 많아 저장·재개가 복잡하다. 개선: 시간/RNG/투사체/상태효과/점령/생산 잔여를 한 versioned snapshot으로 직렬화한다. P0. 확인: 같은 저장에서 재개해 최종 로그 해시가 같은가. 실패 시 새 기능을 줄이고 저장 기반을 우선한다.

W3. 병종 수에 비해 실제 스킬 처리와 이미지 상태군이 부족하다. 개선: 방패/궁병/마법사/사제 네 역할로 수직 검증 후 확장. P1. 확인: 치료와 범위 태그가 실제 판정에 도달하고 상태군이 모두 있는가.

W4. 군수·룰렛·전투·재정비의 설명량이 많다. 개선: 한 화면의 주요 행동 하나, 결과 확정 단계 통합, 잠금 이유와 비용 선표시. P1. 확인: 초반 라운드에서 다음 행동을 묻지 않고 진행하는가. 설명문을 늘리는 것만으로 해결하지 않는다.

## SWOT O · 기회를 검증하는 계획

O1. 당첨보다 준비의 인과를 강조하면 유사 슬롯 게임과 다른 지휘 경험을 만들 수 있다. 실험: 공급 원인 표시 on/off와 플레이어 자유 설명 비교. 채택 기준은 영향 설명과 선택 변화이며 시장 수요를 입증하는 지표는 아니다.

O2. 적 전선이 남아 있는 재정비는 다음 수를 읽는 장면이 될 수 있다. 실험: 잔존 위협과 다음 공세의 관계를 설명할 수 있는지 확인. 반례: 매번 죽기 직전 화면만 반복해 답답하면 공세 간격·증원 도착을 교정한다.

O3. 보유 군단의 누적은 캐릭터 애착을 만들 수 있다. 강화: 병종별 생존과 기여를 보여 준다. 초기에는 개체별 장비·랜덤 특성·이름 생성까지 추가하지 않는다. 애착이 약하면 기록 UI 개선을 먼저 시험한다.

O4. 다섯 맵은 공통 규칙 안에서 공세 순서를 바꾸는 학습 곡선이 될 수 있다. 강화: 역할 압박과 타이밍 변주. 검증: 배경만 달라지고 구매 순서가 같다면 맵 공세를 재설계한다.

## SWOT T · 위험과 중단 기준

T1. 고의 지연 수입: 이길 수 있어도 기다리는 편이 이득. 대응: 남은 기본 보급 정산을 시험하고 미래 점령 수입까지 지급하지 않는다. 임의 경제 점수로 해결됐다고 주장하지 않는다. 즉시/지연 승리의 최종 자산을 실제 비교한다.

T2. 눈덩이 효과: 점령으로 탑·골드·슬롯을 함께 얻어 한 번의 패배가 누적. 대응: 보너스 규모 분리 실험, 기본 6슬롯의 대응력, 점령 상실 후 회복 시나리오. 회복 불가면 수치·공세를 줄이며 사용자 슬롯 규칙을 몰래 바꾸지 않는다.

T3. 정답 편성: 모든 공세에 같은 순서. 대응: 전열/밀집/돌파/지원의 시간 순서를 바꾸고 최소 두 대응을 비교한다. 플레이어 편성을 읽는 비공개 하드카운터 생성 금지.

T4. 제작 폭증: 병종×진영×등급×상태. 대응: 등급마다 신규 원화를 의무화하지 않고 기본 4역할 상태군 검증 후 확장. 투명도·피벗이 실패하면 해당 자산을 준비 완료로 표시하지 않는다.

T5. 사용자 시간과 권리: 긴 원정·불명확한 AI provenance. 대응: 재정비 저장/중단 재개, 출처 해시·참조 독립성 기록. Android 실기기·권리·출시 검수는 별도 게이트다.

## 한 원정의 흐름

메인 → 새 원정 또는 이어하기 → 해금된 맵 선택 → 첫 준비 → 룰렛/내정 → 라운드 시작 → 여러 웨이브 → 시간 종료 → 재정비 → 다음 라운드.

전투 중 적 본진 점령이면 즉시 맵 결과. 마지막 라운드까지 본진을 유지해도 맵 결과. 패배는 현재 맵 진입 snapshot으로 재도전하거나 메인으로 돌아간다. 앞선 완료 맵 기록은 유지한다. 최종 맵 클리어 뒤에는 원정 결과로 가며 여섯 번째 맵을 자동 생성하지 않는다.

동시 판정: 종료 시각까지의 사건 처리 → 아군 본진 함락 → 적 본진 점령 → 마지막 라운드 생존 → 일반 재정비. 양측 본진 동시 함락은 패배. 종료 시각과 같은 신규 웨이브 출현은 금지한다.

## 시간·전장·재정비

권장 초깃값은 라운드 60초, 공세 5/22/40초. 라운드 종료 시 적을 삭제하거나 전멸까지 연장하지 않고 상태를 동결한다. 잔존 체력/위치/투사체/상태효과/공격 시간/생산/점령을 보존한다.

재정비는 사용자 시작까지 무제한이다. 골드·생산·치료 쿨다운이 기다린 시간만큼 증가하지 않는다. 건설/업그레이드/동원/유료 치료는 준비 중 명령으로 처리한다. 탭 클릭은 전투 시계에 영향을 주지 않는다.

1배/2배 재생을 지원하는 명세다. simulation은 30Hz 고정 step, 배속은 step 수만 늘린다. pause는 저장 상태를 바꾸지 않는다. 모든 시간 수치는 초 단위 정수 tick으로 직렬화해 경계의 부동소수 오차를 피한다.

## 전선과 점령의 명세

지도 논리 좌표는 0~100. 아군 진입 5, 적 진입 95, 아군 본진 0, 적 본진 100. 중간 점령지는 25/50/75 세 곳으로 시작한다. 이는 초깃값이며 경로는 한 개다. 현재 맵의 방어탑은 50 지점 한 개로 시작해 라인당 한 개 원칙을 보존한다. 다른 두 점령지는 탑이 없는 군수 거점이다.

점령 반경 3, 지상 병력만 기여. 적 지상 병력이 같은 반경에 있으면 진행 정지. 독점 점령 시간은 8초, 점령력 합산은 최대 2배. 공격측 부재 시 초당 0.1 감소, 중립화 후 새 소유권 적용. 반복 재점령에 일회성 골드 보상은 없다.

적 본진은 방어 HP를 0으로 만든 뒤 같은 점령 절차로 마무리한다. 아군 본진은 HP 0이면 함락한다. 두 규칙의 비대칭은 UI에 명시한다. 방어탑 소유 변경 시 기존 투사체는 발사 당시 소유자를 유지하고 다음 공격부터 새 소유자다.

## 군수와 건물 공급

모든 건물은 내정 목록에만 존재한다. 슬롯은 6+보유 점령지, 상단부터 해금. 잠기면 건물과 레벨은 남고 자동생산·다음 룰렛 공급은 중단한다. 출전 병력/확정 결과는 소급 삭제하지 않는다.

최신 사용자 교정: 일반병종과 특수병종은 별도다. 일반병 병영 T1은 방패병을 공급하며 T2에서 방패/대검/창/궁/기병 중 하나로 특화한다. 특수병 병영은 별도 건설 계열이며 T2에서 마법사/사제/암살자/비행병/거인 중 하나로 특화한다. v2의 일반병영→마법학당/성소, 창병→기병, 마법사→거인 경로는 폐기한다. 기본 일반병영 40G, 특수병영 75G와 전문화 추가 비용은 실험 초깃값이다. 두 계열 모두 동일한 6+점령지 슬롯 예산을 사용하고 서로의 병영으로 전환되지 않는다.

시설당 현재 전문 병종 토큰 1개를 각 릴에 제공한다. 특화는 공급 병종과 기본 역할을 바꾸며 토큰 개수를 늘리지 않는다. T3는 선택한 T2 병종의 심화형 하나로 이어지며 새 병종으로 재분기하지 않는다. T3 추가 비용은 해당 T2 전문화 가격의 1.25배 올림, 생산 간격은 T2와 같고 다음 생산부터 T3 심화 스킬을 가진다. 기존 출전/대기 병력은 소급 승급하지 않는다. T2는 첫 맵 2라운드 준비, T3는 첫 맵 6라운드 준비부터 허용하는 초기안을 시험한다.

특수병영 T1 권장 복원안: 건설 거래 성공 시 특수병 5종을 동일 확률로 한 번 추첨하고 생산·토큰 공급 병종을 즉시 공개한다. T1 동안 60초 간격으로 같은 병종을 생산하며 저장/탭 이동/재정비로 재추첨하지 않는다. T2는 추첨 결과와 무관하게 특수병 5종 중 선택한다. 8월 6일 문서는 T1 토큰 공급 없음, 8월 20일 문서는 공급 있음으로 서로 다르다. 최신 사용자 지시는 계열 분리만 확정하므로 이번에는 후자의 공급 있음 안을 RECOMMENDED로 채택하고 승인된 과거 수치를 통째로 복원하지 않는다. 일반병만으로 첫 맵을 진행할 수 있어야 하며 특수병 추첨은 필수 대응을 독점하지 않는다.

특화 명령은 준비 단계에서만 가능하고, 활성 슬롯·부모 경로·골드·미확정 룰렛 없음 조건을 검사한다. 골드 차감과 건물/풀 변경은 한 거래로 처리한다. 생산 진행도는 초기화하고 이미 생산된 병력과 확정 대기열은 이전 병종을 유지한다. 해당 원정에서 분기 되돌리기/옆 분기 전환은 없으며 다른 병영을 특화해 혼합 편성한다. UI 확인창에서 사라지는 공급과 새 공급을 함께 표시한다.

군수소는 토큰/자동생산 없이 동시 출전 한도 +6. 점령 상실로 한도가 내려가도 살아 있는 병력을 삭제하지 않는다. 초기 자유 재정렬은 없다. 철거는 준비 중 환급 없이 가능하고 해당 생산·공급만 중단한다. 철거 버튼은 영향과 무환급을 확인받는다.

## 룰렛의 구체 처리

3릴 각 3칸, 총 3×3. 각 릴의 풀은 활성 시설의 병종 토큰 + 기본 방패 토큰 2개 + 빈칸 2개다. 궁병은 사격장 특화 이후에만 공급한다. 각 셀은 독립 복원 추출, 모든 토큰 인스턴스는 같은 가중치. 시설 중복은 그 병종 확률을 높이며 세 릴을 전선에 대응시키지 않는다. 기본 방패 공급은 슬롯 상실 시에도 남는다.

각 준비에서 기본 무료 회전 1회, 추가 회전 20G. 기본 회전은 이월/판매되지 않는다. 회전당 행 또는 열을 한 칸 순환 이동하는 조작 3회. 같은 이동을 되돌려도 사용 횟수는 반환하지 않는다. 확정 전 결과 병력은 미리 볼 수 있으나 확정 전에는 지급하지 않는다.

지급: 빈칸을 제외한 각 병종이 3칸당 해당 병종 1명을 만든다(기본 최대 3명). 같은 병종으로 완성된 가로/세로/대각선이 있으면 보너스는 전체 회전에서 최대 1명이다. 여러 병종의 완성 줄이 있으면 확정 전 그중 한 병종을 선택한다. 총 최대 4명, 최대 출전비용 20으로 대기열 24보다 작다. 이 규칙은 기존 resolver와 다른 신규 권장안이다. 회전 전 현재 풀에서 가능한 최대 지급비용만큼 공간을 예약하고 확정 후 실제 비용 외 예약은 해제한다. 공간 부족 시 결제나 RNG 소비 없이 거절한다.

무료 회전도 대기열 부족이면 잠금 이유를 표시하고 기존 대기열로 출전할 수 있다. 불리한 결과에도 기본 시작 병력과 자동생산 경로가 남아야 하며 임의 당첨 조작은 금지한다. 공급 preview는 확정된 풀을 사용하고 UI가 RNG를 재실행하지 않는다.

## 경제·치료·초기 편성

시작 120G, 동시 출전 한도 18, 대기열 24(병종별 출전비용 합). 시작 병력 방패 4, 무료 기본 동원 1회, 완성 건물 없음. 궁병을 시작 병력에 넣어 특화 해금을 우회하던 이전 초깃값은 교정한다. 첫 라운드는 지상 적만 사용하고 기본 편성 생존 가능성을 별도 시험한다. UI는 현재 편성과 공세를 먼저 보여 주고 특정 건설 정답을 강요하지 않는다.

라운드 기본 보급 15G를 전투 중 20초마다 5G 지급. 점령지 수입은 각 지급 시점의 보유 수에 따라 15초마다 1G/거점. 재정비에서는 시계 정지. 출전비용은 동시 용량이지 소모 식량이 아니며 사망/제거 시 1회 반환한다.

치료가격 = ceil(충원 기준가 × 복구 HP/최대 HP × 0.6). 최대 HP까지 회복하며 실제 복구량이 0이면 비용 0. 치료 대상별 가격을 보여 주고 선택 결제한다. 사제 치료는 전투 중 스킬이고 내정 치료와 다른 경로다.

조기 점령하면 남은 기본 보급만 정산하여 전체 기본 보급 총액을 맞춘다. 미래 점령 수입/미생산 병력은 지급하지 않는다. 이 규칙만으로 지연 파밍이 제거됐다고 주장하지 않는다. 즉시 승리와 마지막까지 지연한 승리를 같은 seed로 비교한다.

## 맵 계승·저장·재시도

현재 원정의 완료한 맵에서 실제 확보한 군수 거점만 보유 이력으로 남긴다. 생존 승리가 해당 맵의 모든 점령지를 자동 획득시키지 않는다. global point id로 중복을 방지한다. 이전 맵 거점 수입/슬롯은 원정 동안 유지하고 적에게 다시 잃는 비공개 사건은 없다.

골드·시설/레벨·병력 체력·대기열을 다음 맵으로 계승한다. 병력은 진입 지점으로 이동하고 투사체와 소멸한 타깃 참조는 제거한다. 본진은 새 맵의 기준 HP 1000으로 시작. 자동 완전회복 없음. 재도전은 맵 진입 직전 snapshot 전체로 복원하며 그 맵에서 얻은 보상은 되돌린다.

save_version, ruleset_version, run_id, map_id, round_index, phase, tick, RNG state, wave cursor, gold, buildings, owned_point_ids, units, queue, projectiles, timers, claimed_reward_ids를 저장한다. 임시파일 기록→검증→원자 교체, 직전 정상본 유지. 손상 세이브를 덮어쓰지 않는다. 기존 세이브는 구형 실행 경로로 보존하고 새 규칙은 새 원정에만 적용한다.

## 화면별 입력 계약과 접근성

메인: 새 원정/이어하기/설정. 이어하기 불가 사유를 표시. 맵 선택: 다섯 구간, 잠금/완료/현재 상태와 총 라운드. 준비: 내정·룰렛·전선 탭, 공통 상단 리본과 다음 공세 유지. 전투: 관리 읽기 전용, pause/배속/전술만 활성. 결과: 승리 방식·실제 손실·보상과 다음 맵/재도전.

논리 해상도 1280×720을 신규 UI 검증 기준으로 권장한다. 현행 960×540 코드와 차이가 있어 승인 후 실제 대응 검증이 필요하다. PC 우선, Android 출시 대상은 유지하되 기기검증 미실행. 텍스트 최소 18px, 핵심 버튼 최소 높이 44px, 색+아이콘+문구 병용, 키보드 초점과 Esc 복귀 제공.

동작 감소 옵션은 화면 흔들림/섬광을 낮추지만 타격·위협 정보는 유지. 음량은 음악/효과 분리. pause 메뉴에서 설정을 바꾸어도 RNG/비용/공세 재실행 없음. 실제 장치 접근성 승인은 별도다.

## 자산 납품 계약과 아틀라스

화면 아틀라스는 화면을 찾는 지도이며 texture atlas는 이미지 좌표표다. 둘 다 포함한다. 신규 배경은 불투명 단일 레이어, UI 아이콘은 불투명 4×4 시트로 사용한다. UI 문구·수치는 이미지에 넣지 않는다. 고정 navy 타일은 사각 카드에 사용할 수 있지만 자유 배치 투명 소품이 아니다.

캐릭터는 좌우 2방향·idle/move/attack/hit/death 상태, 방어병 guard·사제 cast를 추가한다. frame cell 512×512, pivot (256,448), 본체 표시 높이 80px부터 시험. attack은 windup/contact/recovery와 simulation event id 연결. 정확한 프레임 수는 일관성 검수 후 정하되 4프레임 idle·6 move·6 attack·2 hit·5 death를 최초 제작 예산으로 둔다.

Aseprite는 원화 생성기가 아니라 프레임/시간/PNG+JSON 패키징 도구다. 이미지 모델로 생성한 포즈의 크기·무기·발 기준을 검사한 뒤 패키징한다. 현재 새 4병종 시트는 RGB 체크무늬여서 투명 sprite 계약 실패. 배경 제거를 완료했다고 주장하지 않는다.

완료 기준: 실제 alpha, 경계 누출 없음, 동일 발 기준, 무기 끝 잘림 없음, 준비→타격→회복 연속성, 1배/2배/정지 재개 확인. Godot SpriteFrames/AtlasTexture는 이 검사 뒤 연결한다. 자산 manifest는 원본 해시/도구/프롬프트/상태/consumer를 기록한다.

## 구현 작업 순서와 테스트

P0 데이터/진행: 새 ruleset을 기존 저장과 분리하고 MapDefinition/RoundDefinition/WaveDefinition을 읽는다. 준비→전투→재정비/결과, tick 경계·동시 본진 판정을 테스트한다.

P1 군수/동원: 슬롯/소유권/생산/풀 snapshot/조작/지급/한도 반환을 연결한다. 부족 골드·빈 결과·포화·중복 클릭·반복 로드를 실패 fixture로 둔다. 공개 지급 규칙과 코드 resolver의 일치가 필요하다.

P2 전투 역할: target domain·단일/범위/치료·가드·돌격·공성을 연결한다. 가까운 적만 공격하는 현재 경로를 데이터 기반 효과로 교체한다. 각 효과는 준비 취소/사망/투사체/정지 재개 회귀를 통과해야 한다.

P3 화면/자산: 실제 Control 노드와 데이터에 연결한다. 생성 화면을 runtime 촬영으로 부르지 않는다. 1280×720과 작은 창/터치 배치 검사, 자산 state coverage 검사.

P4 전 맵: 53라운드/159웨이브 데이터 유효성, 세 운영 편성, 불리한 룰렛, 즉시/지연 승리, 반복 저장. 자동 테스트와 실제 플레이 이해·재미를 분리한다. 종료 조건은 코드·데이터·자산·실행 증거와 사용자 승인 모두다.

공세 데이터 전개: 전체 cycle에서 각 라운드의 세 연속 항목을 사용하고 다음 라운드는 시작 위치를 1칸 이동한다. 각 병종 수는 ceil(기본 수 × 맵 pressure × (1 + 0.03 × (라운드-1)))이다. 같은 웨이브 병력은 0.4초 간격으로 데이터 순서대로 출현한다. 이는 확정 밸런스가 아닌 재현 가능한 초기 fixture다. 적은 아군 해금 제한을 공유하지 않지만 위협 예고와 유효 대응을 제공해야 한다.

## 티어·등급·영웅을 구분하는 계약

일반/특수는 병종 계열, 아군/베일은 진영, T1/T2/T3는 생산 시설의 발전 단계, 일반/숙련/정예는 개체 등급이다. UI에서 ‘일반병종’과 ‘일반 등급’을 같은 필드로 표시하지 않는다. 병종 수는 일반 5+특수 5=10이며 영웅은 별도다. 이전 8병종안에서 빠진 암살자·비행병을 복원한다. 이 분류는 과거 10병종 문서를 비교해 제안했으며 과거 전투 수치/3전선/시대 진행은 계승하지 않는다.

건물 T2는 역할 선택, T3는 같은 역할 심화다. 병사 등급은 일반 → 숙련 → 정예의 동일 병종 성장 축을 권장한다. 영웅은 별도 고유 인물이며 일반 병사의 최상위 등급 이름으로 사용하지 않는 안이다. 현행 코드의 rank_id=hero와 혼용하지 않도록 신규 ruleset에서 명시적으로 매핑한다. 등급 체계 변경은 사용자 확정이 아닌 권장안이다. 티어·등급 배수 중첩으로 전투력이 폭증하는 구조는 채택하지 않는다.

## 제작 도구와 구현 준비도

신규 도감·건물·영웅·배경·아이콘은 이미지 모델 생성이며 Aseprite 미사용이다. 기존 방패병 베기 V2만 이미지 모델 포즈를 Aseprite 5프레임으로 구성하고 180/70/100/130/220ms, PNG+JSON으로 내보낸 시험이다. Aseprite 사용과 그림 완성도·투명화·Godot 구현은 별도 항목이다. 최신 누락 병종 도감도 정적 이미지 후보로 먼저 제공하며 모션 완료로 표시하지 않는다.

현재 착수 가능한 준비 작업: 문서/데이터 교정, 비용·트리·직렬화 계약 테스트, 후보 원화 제작. 최종 승인 후 첫 구현 패킷은 1맵/2라운드와 일반병영 T1→T2, 별도 특수병영, 저장 재개를 연결하는 수직 검증이다. 전체 5맵·10병종 구현을 한 번에 시작하지 않는다. 완성 원화 전에도 논리 테스트는 가능하지만 실제 소비처 연결과 인간 가독성 검증을 대신하지는 못한다.

권장 등급 획득: 살아서 완료한 라운드 2회에 숙련, 5회에 정예. 맵 재도전은 진입 snapshot으로 생존 횟수도 복구한다. 처치 막타·재정비 대기·저장 반복으로 등급 경험을 얻지 않는다. 각 등급의 스킬은 누적되며 병종 기본 HP/공격에 일괄 배수를 적용하지 않는다. 자동생산과 룰렛은 일반 등급으로 지급한다. 기존 등급 RNG는 새 규칙에 자동 이식하지 않는다.

공통 효과 계약: 동일 명칭 보호막은 가장 큰 잔여량으로 갱신하고 합산하지 않는다. 둔화는 가장 강한 값만 적용하며 이동속도 최저 50%. 동일 경직 종료 후 1초간 경직 면역. 추가타는 자신의 추가타 조건을 재귀 발동하지 않는다. 사망한 시전자에게 예정된 미발사 효과는 취소한다. 최대 대상 초과 시 거리→instance_id 순으로 선택한다. 베일도 대응 역할 스킬을 쓰되 수치 동등성은 초기 시험값이며 종족별 고유화는 후속 검토다.

## 영웅 편성 · 권장안

세 영웅 후보 중 원정 시작에 1명을 선택한다. 아우렐은 전열 보호, 리라는 후열 요격, 세렌은 회복 지원이다. 영웅은 룰렛 당첨으로 나오거나 일반 병사를 합성해 만드는 개체가 아니다. 지휘관과 영웅의 세계관 관계·이름은 검토 후보이며 이번 사용자 지시는 영웅 추가 자체를 승인한 것이다.

영웅은 별도 1칸으로 편성하며 일반 병력 용량을 쓰지 않는다. 자동 이동/기본 행동과 고유 능동기 1개, 패시브 1개로 시작한다. 처음부터 기술을 모두 갖고 있어 반복 성장 의무를 추가하지 않는다. 기술은 전투 중 유효 대상 선택→확정 때만 재사용시간을 소비한다. pause/재정비 중에는 시간과 쿨다운이 멈춘다. 맵 변경 시 체력은 계승하고 재사용시간은 초기화한다.

쓰러지면 해당 라운드에서 제외되고 다음 재정비에 최대 HP 50%로 돌아온다. 이때 라운드별 복귀 id로 중복 생성을 방지한다. 본진 함락을 영웅 부활로 취소하지 않는다. 회복 무한 농사를 막기 위해 동일 재정비에서 추가 사망/복귀는 없다. 세 영웅의 출전 가치와 회복형 정답화는 아직 실험하지 않았다.

## 실무 조사와 증거의 한계

기존 12개 게임 공식 설명 비교를 적용한다. 그 게임을 직접 플레이하여 통계를 수집한 결과는 아니다. Into the Breach의 예고, Commander Quest의 편성 시너지, Thronefall의 준비/공세, The King is Watching의 군수 투자, Balatro의 작은 규칙 조합을 참고한다. 카지노 표현·분기 지도·3전선·전멸제 종료는 복제하지 않는다.

Godot 공식 AtlasTexture 문서에서 region과 filter_clip을 확인했고, SpriteFrames/AnimatedSprite2D의 시트 재생 경로를 확인했다. GDC 지표 발표 URL은 이번 재조회에서 실패했으므로 새로 확인한 실무 근거로 세지 않는다. 과거 발표 개요를 전 강연 시청·인터뷰로 부풀리지 않는다.

현재 main은 9ea3245b 기준 확인했으며 미병합 PR257의 단일전선 구현은 읽기 전용 비교다. Base adapter 9.4.3을 검증했고 더 오래된 버전 안내 문서와의 차이는 자동 업그레이드 이유가 아니다. GitHub main·검토 분기·로컬 미커밋 결과를 구별한다.

## 최종 승인 전 남은 게이트

문서·데이터 표는 사용자 검토에 제공한다. 원화/모션 전부 완비, 모든 신규 효과 구현 가능성 실증, 실제 화면 가독성, 권리 확인은 남아 있다. 신규 배경과 UI 아이콘의 납품 후보를 전체 아틀라스 완성으로 부르지 않는다.

다섯 맵 배경 중 현재 신규 후보는 한 개다. 아군 8종·베일 8종·건물 8종·영웅 3명은 불투명 도감/목록용 원화 후보를 추가했다. 이는 실제 UI 소비처를 가진 후보지만 전투 sprite가 아니다. 분리 소품·방어탑·군수소 이미지·공격/이동/피격/사망 상태군은 제작/검증 필요다. 실패한 RGB 체크무늬 병종 시트는 제품 자산에서 제외한다. 이 부족 목록이 해결되기 전 전체 구현 준비 완료로 올리지 않는다.

다음 안전 작업은 납품 자산의 alpha/좌표 계약 복구와 나머지 필수 상태군 제작, 룰렛 최댓값/경제 fixture 계산, 문서-데이터 일치 검수다. 사용자가 최종 승인하기 전 제품 코드를 수정하거나 기존 자산을 교체하지 않는다.
