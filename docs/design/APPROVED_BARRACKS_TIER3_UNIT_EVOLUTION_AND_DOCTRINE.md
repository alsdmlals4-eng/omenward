# 승인된 병영 Tier 3 병종 진화와 운영 교리 규칙

- 상태: **핵심 구조 승인됨 / 병종별 수치와 최종 진화 목록 조정 대기**
- 승인일: 2026-07-14
- 연결 문서:
  - `docs/design/APPROVED_BUILDING_SPECIALIZATION_AND_TACTICAL_COMMANDS.md`
  - `docs/design/APPROVED_UNIT_GRADE_AND_ABILITY_GROWTH.md`
  - `docs/design/APPROVED_ROULETTE_CORE_RULES.md`
  - `docs/design/APPROVED_COMBAT_KEYWORDS_STATUS_EFFECTS_AND_FLIGHT.md`

이 문서는 기본 병영의 Tier 3 규칙을 확장한다. 기존 문서의 `Tier 3 교리 후보 중 하나만 선택` 문구보다 이 문서가 우선한다.

## 1. 기본 병영 성장 구조

```text
Tier 1: 검사 생산
→ Tier 2: 기병·창병·궁병 중 병종 선택
→ Tier 3: 병종 진화 1개 + 운영 교리 1개 선택
```

Tier 3은 병종 진화와 운영 교리를 서로 대체하는 선택지로 취급하지 않는다. 플레이어는 Tier 3 업그레이드를 시작하기 전에 다음 두 슬롯을 각각 하나씩 선택한다.

1. **병종 진화 슬롯**: 생산 병종과 룰렛 토큰의 세부 병종 결정
2. **운영 교리 슬롯**: 생산속도·생산 유닛 강화·토큰 확률 중 운영 방식 결정

같은 Tier 2 병종이라도 두 선택의 조합에 따라 서로 다른 건물 빌드가 만들어진다.

예시:

```text
기병 병영
→ 중기병 + 대량생산
→ 중기병 + 정예훈련
→ 중기병 + 토큰 증폭
→ 충격기병 + 대량생산
→ 충격기병 + 정예훈련
→ 충격기병 + 토큰 증폭
```

## 2. Tier 3 선택과 비용

- 병종 진화와 운영 교리는 Tier 3 업그레이드 화면에서 함께 선택한다.
- 두 선택이 모두 완료돼야 업그레이드를 시작할 수 있다.
- 같은 Tier 2 병종에서 가능한 모든 Tier 3 조합은 기본적으로 동일한 업그레이드 비용과 시간을 사용한다.
- 특정 조합만 숨은 추가 비용이나 추가 시간을 사용하지 않는다.
- 선택 결과는 업그레이드 시작 전에 생산 유닛, 토큰, 능력, 생산속도와 확률 변화로 미리 표시한다.
- 업그레이드 시작 뒤 선택을 바꾸려면 취소 규칙을 적용하거나 건물을 철거 후 재건설한다.
- Tier 3 완공 뒤에는 해당 건물이 파괴·철거될 때까지 병종 진화와 교리를 유지한다.

## 3. 완공 전후 전환 시점

Tier 3 업그레이드 중에는 Tier 2 상태를 유지한다.

- 기존 Tier 2 병종을 계속 생산한다.
- 기존 Tier 2 병종 토큰을 유지한다.
- 진행 중인 생산 진행률을 보존한다.
- 진행 중인 룰렛 스냅샷은 변경하지 않는다.

Tier 3 완공 순간:

- 이후 생산 유닛을 선택한 진화 병종으로 변경한다.
- 세 릴의 Tier 2 병종 토큰을 선택한 진화 병종 토큰으로 교체한다.
- 진행 중이던 생산은 진행률을 유지하며, 완공 뒤 처음 완성되는 유닛부터 진화 병종으로 생성한다.
- 현재 회전 중인 룰렛은 유지하고 다음 회전부터 진화 병종 토큰을 사용한다.
- 이미 생산됐거나 출전한 Tier 2 유닛은 진화 병종으로 바뀌지 않는다.
- 운영 교리 효과도 완공 순간부터 적용한다.

## 4. 병종 진화와 유닛 등급은 별도 축이다

병종 진화는 유닛의 **종류와 역할**을 바꾸며, 일반·엘리트·영웅·전설은 유닛의 **등급**을 나타낸다.

따라서 다음 유닛이 모두 존재할 수 있다.

```text
일반 중기병
엘리트 중기병
영웅 중기병
전설 중기병

일반 대공궁병
엘리트 대공궁병
영웅 대공궁병
전설 대공궁병
```

계약:

- 병영 자동 생산은 선택한 진화 병종의 **일반 등급**을 생산한다.
- 룰렛 토큰은 정확한 진화 병종을 결정한다.
- 룰렛의 완성 줄 수는 해당 진화 병종의 일반·엘리트·영웅·전설 등급을 결정한다.
- Tier 3 진화 자체는 엘리트 등급을 부여하지 않는다.
- `정예훈련` 교리도 등급을 바꾸지 않는다.
- 생산시설 버프와 유닛 등급 강화는 데이터에서 분리한다.

## 5. 진화 병종의 능력 구성

진화 병종도 일반 등급 기준으로 핵심 패시브 1개와 핵심 스킬 1개를 가진다.

병종 진화는 기본 Tier 2 병종의 역할을 다음 방법으로 변형한다.

- 기본 핵심 패시브의 일부 효과 교체 또는 강화
- 기본 핵심 스킬의 피해·범위·대상·이동 방식 변형
- 능력치 분배와 대상 우선순위 변경
- 새로운 병종·행동 태그 추가
- 비행·대공 등 전투 레이어 대응 추가

병종 진화만으로 핵심 능력 슬롯을 하나 더 추가하지 않는다. 진화 병종의 일반 등급은 여전히 핵심 능력 2개를 가지며, 엘리트·영웅·전설 등급 상승으로 3·4·5개가 된다.

예시:

```text
기병
- 핵심 패시브: 기동전
- 핵심 스킬: 돌진

중기병
- 변형 패시브: 중장기동
- 변형 스킬: 중장돌진

충격기병
- 변형 패시브: 돌격대형
- 변형 스킬: 충격돌진
```

## 6. 기병 Tier 3 진화

### 중기병

역할: 전열 돌파 후 전선 유지, 원거리 압박을 견디는 중장갑 기병.

추천 방향:

- 체력·방어력 증가
- 원거리 물리 공격에 대한 일부 경감
- 일반 기병보다 이동속도와 돌진 준비속도 감소
- 돌진 관통 거리 또는 후열 도달 능력 감소
- 돌진 종료 뒤 짧은 방어 강화 또는 경직 저항
- `[지상] [기병] [중장갑]` 태그

중기병은 충격기병보다 최초 돌파 피해가 낮지만, 돌진 후 전선에서 오래 버티는 방향으로 설계한다.

### 충격기병

역할: 긴 돌진과 높은 순간 피해로 전열을 뚫고 후열을 붕괴시키는 공격형 기병.

추천 방향:

- 돌진 거리·속도·최초 충돌 피해 증가
- 돌진 경로의 소형 적에게 피해 또는 강한 밀쳐내기
- 후열 대상 우선순위 강화
- 기본 체력·방어력은 중기병보다 낮음
- 돌진이 저지되거나 바리케이드에 막히면 위험한 후딜레이 발생 가능
- `[지상] [기병] [돌진 특화]` 태그

충격기병은 돌진 성공 시 강하지만 창병·바리케이드·대형 적에게 저지됐을 때 손실 위험이 큰 병종으로 설계한다.

## 7. 궁병 Tier 3 진화

### 석궁병

역할: 느리지만 강한 단발 공격으로 중장갑·대형 지상 유닛을 처리하는 원거리 병종.

추천 방향:

- 공격속도 감소
- 기본 공격 피해와 방어력 관통 증가
- 긴 재장전 동작
- 확정 치명타 공격의 치명타 피해 또는 관통 효과 강화
- 소형 다수보다 중장갑·대형 단일 대상에 효율적
- `[지상] [원거리병] [중장갑 대응]` 태그

### 대공궁병

역할: 비행 유닛을 우선 공격하고 급강하를 견제하는 대공 전문 원거리 병종.

추천 방향:

- `target_layers = ground_and_air`
- `[대공]` 태그 보유
- 비행 대상 우선 타기팅
- 비행 대상 추가 피해 또는 대공 사거리 증가
- 등급 또는 추가 스킬에 따라 `[급강하]` 둔화·저지·지상화 가능
- 지상 대상 피해나 공격속도는 범용 궁병보다 낮게 조정 가능
- `[지상] [원거리병] [대공]` 태그

대공궁병은 비행 유닛을 공격할 수 있는 단순 궁병과 달리, 비행 카운터에 특화된 병종이다.

### 연사궁병

역할: 빠른 연속 공격으로 소형 적과 낮은 방어력 대상을 압박하는 지속 화력 병종.

추천 방향:

- 공격속도 증가
- 공격 1회당 피해와 방어 관통 감소
- 궁병의 공격 횟수 기반 확정 치명타를 더 빠르게 준비
- 대상 변경과 소형 적 연속 처리에 유리
- 중장갑 대상과 강한 피해 경감 대상에는 효율 감소
- `[지상] [원거리병] [연사]` 태그

## 8. 창병 Tier 3 진화 후보

창병의 최종 진화 목록은 후속 승인 대상으로 두되, 기본 방향은 다음 두 가지를 우선 검토한다.

### 장창병

역할: 기병과 지상 돌진을 가장 안정적으로 봉쇄하는 방진형 창병.

추천 방향:

- 돌진 저지 범위 증가
- 돌진 저지 내부 쿨타임 감소 또는 저지 후 주변 창병 보조
- 쓰러스트 사거리 증가
- 이동속도와 방향 전환 능력 감소
- 비행 급강하는 기본적으로 저지하지 못함

### 할버드병

역할: 대형·중장갑 보병을 상대하고 전방 다수를 베는 공격형 창병.

추천 방향:

- `[대형]` 또는 `[중장갑]` 대상 추가 피해
- 쓰러스트 대신 또는 쓰러스트와 연결되는 넓은 전방 베기
- 장창병보다 돌진 저지 성능 감소
- 기병뿐 아니라 중장갑 전열을 상대하는 범용성 확보

정확한 창병 진화 수와 명칭은 병종별 능력표 작업에서 확정한다.

## 9. Tier 3 운영 교리

병종 진화와 별도로 다음 중 하나를 선택한다.

### 대량생산

- 생산 간격 감소
- 생산되는 병종과 등급은 바꾸지 않음
- 정확한 감소율은 플레이테스트 대상

### 정예훈련

- 해당 건물에서 새로 생산되는 일반 등급 진화 병종에게 영구 능력치 버프
- 이미 생산된 유닛에는 소급 적용하지 않음
- 엘리트 등급을 생성하지 않음
- 룰렛으로 생성된 유닛에는 적용하지 않음
- 정확한 체력·피해·방어 보정은 플레이테스트 대상

### 토큰 증폭

- 선택한 진화 병종 토큰 1개를 결정된 릴 하나에 추가
- 추가 릴은 건물 수명 동안 고정되고 공개
- 매 회전마다 재추첨하지 않음
- 파괴·철거 시 다음 회전부터 제거

## 10. 조합 밸런스 원칙

- 진화 병종은 기본 병종의 완전한 상위호환이 아니라 역할 특화와 약점을 함께 가진다.
- 모든 진화 병종이 지상·비행·중장갑·다수전에 동시에 강하지 않게 한다.
- 운영 교리가 병종 진화의 약점을 완전히 제거하지 않게 한다.
- 대량생산은 수량, 정예훈련은 생산 유닛 품질, 토큰 증폭은 룰렛 확률을 강화한다.
- 자동 생산 일반 유닛과 룰렛 상위 등급 유닛의 가치를 모두 유지한다.
- 특정 진화 하나가 모든 스테이지에서 정답이 되지 않도록 웨이브 전조와 적 조합이 선택 가치를 바꾸게 한다.

## 11. UI 계약

Tier 3 선택 화면은 두 영역으로 나눈다.

### 병종 진화 비교

- 생산 유닛 이름·외형
- 병종·이동·전투 태그
- 핵심 패시브와 핵심 스킬 변화
- 능력치 증가·감소
- 유효 대상 레이어와 대공 여부
- 강점·약점과 추천 상대
- 기존 토큰에서 새 토큰으로의 교체

### 운영 교리 비교

- 생산 간격 변화
- 생산 유닛 버프
- 보너스 토큰 릴과 확률 변화

최종 확인 화면에는 `선택한 진화 병종 + 선택한 운영 교리` 조합과 전체 효과를 함께 표시한다.

## 13. 검증 계약

- Tier 3 업그레이드는 병종 진화와 운영 교리를 각각 하나씩 요구한다.
- 같은 Tier 2 병종의 모든 조합은 승인된 동일 비용·시간 규칙을 따른다.
- 업그레이드 중에는 Tier 2 생산 병종과 토큰이 유지된다.
- 완공 뒤 첫 생산부터 진화 병종이 생성된다.
- 진행 중인 룰렛은 유지되고 다음 회전부터 진화 병종 토큰이 적용된다.
- 기존 Tier 2 유닛은 진화 병종으로 소급 변경되지 않는다.
- 자동 생산은 일반 등급 진화 병종을 만든다.
- 룰렛은 진화 병종 토큰과 완성 줄 수를 조합해 정확한 병종·등급을 만든다.
- 정예훈련은 유닛 등급을 바꾸지 않는다.
- 토큰 증폭은 진화 병종 토큰에 적용된다.
- 대공궁병은 비행 유닛을 유효 대상으로 삼고 우선 타기팅한다.
- 병종 진화는 일반 등급의 핵심 능력 수를 2개보다 늘리지 않는다.

## 14. 아직 미확정인 세부

- 중기병·충격기병의 정확한 능력치와 스킬 변형
- 석궁병·대공궁병·연사궁병의 정확한 능력치와 스킬 변형
- 창병 Tier 3 최종 진화 목록과 개수
- 진화 병종별 생산시간·식량 사용량 차이 여부
- 진화 병종 토큰의 기본 릴 가중치
- 대공궁병의 비행 추가 피해와 급강하 저지 방식
- 모든 조합의 정확한 업그레이드 비용과 시간
- 대량생산·정예훈련·토큰 증폭의 최종 수치
- 진화 병종의 룰렛·생산 애니메이션과 UI 정보 밀도
