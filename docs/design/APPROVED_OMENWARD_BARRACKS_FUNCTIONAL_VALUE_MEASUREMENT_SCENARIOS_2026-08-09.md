## 1. 결론

기능가치 비교에 필요한 동일 입력 deterministic fixture와 역할별 output vector를 사전등록한다.

```text
FIXTURE_POLICY = DETERMINISTIC_SAME_INPUT
FUNCTIONAL_VALUE_COMPARISON = ROLE_SPECIFIC_VECTOR_NO_SINGLE_WEIGHTED_SCORE
POST_HOC_WEIGHT_TUNING = FORBIDDEN
MONTE_CARLO_ROLE_VALUE = NOT_AUTHORIZED_BEFORE_ROLE_OUTPUT_RUNTIME_EXISTS
BLOCKED_RUNTIME_OUTPUT = NEVER_SYNTHESIZE_AS_ZERO
FINAL_FUNCTIONAL_VALUE_INDEX = NOT_SELECTED
FINAL_PARAMETER_VECTOR = NOT_SELECTED
FINAL_PRODUCT_NUMERICS = NOT_APPROVED
PRODUCT_IMPLEMENTATION = NOT_AUTHORIZED
```

현재 runtime이 만들지 않는 역할 출력에는 값을 추정하거나 `0`을 넣지 않고 `BLOCKED_RUNTIME_OUTPUT`를 기록한다.

## 2. Output availability classes

```text
MEASURABLE_CURRENT_RUNTIME
PARTIAL_RUNTIME_OUTPUT
BLOCKED_RUNTIME_OUTPUT
DIAGNOSTIC_ONLY
```

- `MEASURABLE_CURRENT_RUNTIME`: 현재 runtime/event로 직접 관측 가능.
- `PARTIAL_RUNTIME_OUTPUT`: 일부 행동은 있으나 승인 역할 전체를 대표하지 못함.
- `BLOCKED_RUNTIME_OUTPUT`: 행동 또는 instrumentation이 없어 값 생성 금지.
- `DIAGNOSTIC_ONLY`: 관찰은 가능하지만 functional-value 판정 기준으로 단독 사용 금지.

## 9. Decision rules

1. 역할을 정의하는 primary output이 하나라도 `BLOCKED_RUNTIME_OUTPUT`이면 final functional-value index를 선택하지 않는다.
2. base attack/HP/resource 값은 입력 설명에 쓸 수 있지만 누락된 역할 output을 대신하지 않는다.
3. PoC 수치는 후속 구현 테스트의 hypothesis/reference로만 쓸 수 있으며 별도 numeric approval 전 final target이 아니다.
4. 비교는 hard role relationship + role-specific vector/Pareto 방식으로만 수행한다.
5. missing instrumentation/behavior는 `0` 관측값이 아니라 blocker다.
