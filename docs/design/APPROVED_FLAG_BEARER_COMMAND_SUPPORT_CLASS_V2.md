## 1. 생산 구조 고정

깃발병은 별도 지휘소에서 생산하지 않는다. **Tier 1 기본 병영의 Tier 2 전문화 분기**다.

```text
Tier 1 기본 병영
- 일반 검사 자동생산
- 전사 토큰 제공

→ Tier 2 깃발병 전문화 선택

Tier 2 깃발병 병영
- 일반 깃발병 자동생산
- 군기 토큰 제공
- 같은 라인의 병력을 강화하는 지휘 지원 병영
```

고정 규칙:

- 한 병영은 방패병·대검병·광전사·깃발병 전문화를 동시에 가질 수 없다.
- 서로 다른 병영을 각각 다른 Tier 2 방향으로 전문화할 수 있다.
- 별도 `지휘소` 건물 후보는 폐기한다.
- 업그레이드 중에는 기존 Tier 1 검사 생산 기능과 전사 토큰을 유지한다.
- 업그레이드 완료 순간부터 자동생산 결과와 토큰 구성을 깃발병 계열로 전환한다.
- 업그레이드 전 이미 생산된 검사와 배치된 유닛은 변하지 않는다.
- 생산 진행률은 보존하며 완료 뒤 처음 완성되는 유닛부터 일반 깃발병이 된다.
- 진행 중인 룰렛은 바꾸지 않고 다음 회전부터 군기 토큰을 반영한다.

## 2. 토큰과 등급 경계

깃발병은 병영에서 생산되지만 전사와 역할·상위 등급 템플릿이 다르므로 **독립 군기 토큰 계열**을 사용한다.

```text
T1 기본 병영: 전사 토큰
T2 깃발병 전문화 완료: 군기 토큰으로 교체
```

이유:

- 전투병을 기대한 전사 토큰 결과에 지원병이 섞이는 것을 막는다.
- 엘리트·영웅·전설 깃발병을 별도 고정 템플릿으로 유지한다.
- 룰렛 화면에서 전사 화력 계열과 지휘 지원 계열의 기대 결과를 명확히 구분한다.

등급 결과:

| 완성 줄 | 깃발병 결과 |
|---:|---|
| 1줄 | 선택된 Tier 2 깃발병 병영 출처의 일반 깃발병 |
| 2줄 | 고정 엘리트 깃발병 |
| 3~7줄 | 고정 영웅 깃발병 |
| 8줄·9칸 동일 | 고정 전설 깃발병 |

- 일반 결과는 실제 출처 병영과 생산 강화 원장을 보존한다.
- 엘리트·영웅·전설은 `banner_commander` 계열 고정 템플릿이다.
- 플레이어는 신화급 깃발병을 획득하지 않는다.

---

## 3. Tier 성장 시작점

깃발병은 Tier 2에서 처음 해금되므로 플레이어가 획득하는 기본 깃발병은 처음부터 **Tier 2 패시브 구조**를 가진다.

```text
Tier 2 깃발병
- 패시브 1 `군기 규율` 강화형
- 패시브 2 `진형 유지` 생성

Tier 3 깃발병
- 패시브 1 추가 강화
- 패시브 2 강화
- 패시브 3 `승세 고양` 생성
```

Tier 1 깃발병은 일반 플레이어 생산·룰렛 후보로 존재하지 않는다. 데이터상 공통 원형이 필요할 경우 내부 기준 프로필로만 둘 수 있다.

초기 수치 가설:

- Tier 2 군기 규율: 같은 라인 오라 내 공격속도 +8%.
- Tier 2 진형 유지: 경직 지속시간·밀쳐내기 거리 20% 감소.
- Tier 3 군기 규율: +10%.
- Tier 3 진형 유지: 30% 감소.
- Tier 3 승세 고양: 주변 적 처치 시 이동속도 +12%, 3초, 내부 쿨다운 6초.

정확한 값은 PoC 플레이테스트 대상이다.

## 4. 핵심 전장 역할

```text
병종 표시명: 깃발병
base_unit_family = banner_commander
combat_archetype_id = banner_line_support
태그: infantry / support / commander / banner / buff_aura / ground / standard_unit
```

- 직접 처치력보다 주변 병력의 전투 효율을 높인다.
- 같은 라인의 전열 뒤 약 100~160 world units를 유지한다.
- 다른 라인에는 영향을 주지 않는다.
- 적을 장거리 추격하지 않고 아군 군집과 진형을 우선한다.
- 단독 전투력은 같은 Tier 전사보다 낮아야 한다.
- 벨루와 달리 실제 전투 유닛이며 안내·보고 역할을 맡지 않는다.

초기 능력치 방향:

| 항목 | 같은 Tier 전사 대비 |
|---|---:|
| 체력 | 75~85% |
| 단독 DPS | 50~65% |
| 이동속도 | 95~100% |
| 식량 | 초기 2 제안 |
| 총 전력 비용 | 일반 전사 약 1.3~1.8기 가설 |

총 전력 비용은 본체뿐 아니라 실제 지원 대상 수와 오라 가동률을 포함한다.

## 5. 오라와 중첩 규칙

초기 범위 가설:

```text
command_radius = 180
command_target_cap = 8
command_line_restriction = same_lane
buff_stack_rule = strongest_only
range_exit_grace = 0.5초
```

- 동일 `aura_category`는 가장 강한 효과 하나만 적용한다.
- Tier·등급이 다른 동일 오라가 겹쳐도 수치가 합산되지 않는다.
- 동일 활성 지휘 스킬은 중첩되지 않고 지속시간만 갱신한다.
- 여러 깃발병은 한 군집 무한 증폭보다 여러 라인·분리 군집 지원에 유리해야 한다.
- 기본 지속 오라는 깃발병 자신에게 적용하지 않는다.

## 6. 등급별 스킬 축

```text
일반: 집결 명령
엘리트: 강화 집결 명령
영웅: 강화 집결 명령 + 불굴의 군기
전설: 영웅 효과 + 강화 불굴의 군기 + 전선 선언
```

### 집결 명령

- 일반: 5초 동안 공격속도 +10%, 이동속도 +15%, 쿨다운 14초 초기 가설.
- 엘리트: 6초, 공격속도 +14%, 이동속도 +20%, 최대 대상 10기 초기 가설.
- 같은 효과는 수치 중첩 없이 지속시간만 갱신한다.

### 불굴의 군기

- 영웅에서 생성.
- 같은 라인 아군에게 최대 체력 10% 임시 보호막.
- 5초 동안 경직·밀쳐내기·둔화 지속시간 30% 감소.
- 쿨다운 24초 초기 가설.
- 기절·속박 전체 해제나 보스 패턴 면역은 제공하지 않는다.

전설 강화 초기 가설:

- 보호막 14%.
- 상태이상 지속시간 감소 40%.
- 반경 240.

### 전선 선언

- 전설에서 생성.
- 현재 위치에 8초 동안 반경 260의 고정 지휘 구역 생성.
- 같은 라인 아군 공격 피해 +15%, 받는 피해 -12% 초기 가설.
- 전조 뒤 위치가 고정되며 깃발병을 따라 움직이지 않는다.
- 전역·전체 라인 효과가 아니며 다른 전선 선언과 중첩하지 않는다.

## 7. 적군 대칭 지휘관형

적군에도 같은 `banner_commander` 계열을 사용할 수 있다.

```text
가칭: 베일 표식자
획득: 적 생산 건물·StageManifest·공세 시간표
```

- 같은 Tier·등급 아군 깃발병과 기본 전투 예산 ±10%에서 시작한다.
- 깃발 대신 균열 표식·뼈 기둥·살아 있는 막 등 비인간적 지휘 장치를 사용한다.
- 베일의 징조에 `지원·지휘·오라`, 반경, 대상 수와 주요 버프를 공개한다.
- 일반 지휘 오라가 보스에게 적용될 경우 초기 효과 50% 가설을 사용한다.

## 8. UI·아트 계약

- 몸체는 일반 보병 크기 34~40px 범위를 사용한다.
- 깃발 포함 전체 높이는 기본 전략 줌에서 약 50~60px를 목표로 한다.
- 엘리트·영웅·전설은 깃발 형태·장식·천 길이와 자세로 구분한다.
- 선택·마우스오버 시 오라 범위와 현재 대상 수 `6/8`을 표시한다.
- 버프 대상에는 작은 군기 아이콘만 표시한다.
- 상시 거대한 발광 오라와 전장 전체 연결선을 사용하지 않는다.

## 10. 검증 계약

1. 깃발병은 기본 병영의 Tier 2 전문화로만 해금된다.
2. 별도 지휘소 건물은 생성하지 않는다.
3. 업그레이드 중 생산·토큰은 Tier 1 상태를 유지한다.
4. 완료 뒤 생산 진행률을 보존한 채 일반 깃발병 자동생산으로 전환한다.
5. 진행 중 룰렛은 유지하고 다음 회전부터 군기 토큰으로 교체한다.
6. 일반 깃발병은 Tier 2 패시브 구조에서 시작한다.
7. 동일 지휘 오라는 중첩되지 않는다.
8. 같은 라인만 강화하며 전역·전체 라인 효과를 사용하지 않는다.
9. 깃발병 단독 전투력은 같은 Tier 전사보다 낮다.
10. 엘리트·영웅·전설 깃발병은 군기 토큰의 고정 상위 등급 템플릿이다.
11. 첫 10분 튜토리얼에는 기본적으로 등장시키지 않는다.
