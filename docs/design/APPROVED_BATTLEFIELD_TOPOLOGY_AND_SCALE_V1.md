# 승인된 전장 구조·점령·성문·암살자 우회로 기준

- 상태: **구조·초기값 승인 / C2 전투 목적 구현 후보·원격 검증 진행 / 플레이테스트 조정 가능**
- 최초 작성일: 2026-07-15
- 최신 갱신일: 2026-07-22
- 적용 범위: 기본 전장, 튜토리얼 전장, 카메라, 길, 성문, 중간거점, 중앙 접전지, 건설 노드, 암살자 이동, 전장 UI
- 책임 원본: 이 문서가 전장 구조와 세부 초기값의 최신 기준이다.

과거 버전은 별도 활성 문서로 복제하지 않고 Git 이력에서 보존한다.

## 1. 전장 정체성

오멘워드의 기본 전장은 **한 화면에서 전체 전황을 읽는 좌우 대칭형 3라인 점령·건설·공성 전장**이다.

```text
중앙 접전지 장악
→ 중간거점 점령과 건설권·생산권 확보
→ 암살자 우회 침투로 후열 교란
→ 라인별 성문 돌파와 본진 공성
```

- 좌측 아군 구조를 기준으로 우측 적군 구조는 기능상 대칭이다.
- 상단·중단·하단은 각각 독립된 라인이다.
- 일반 병력은 배치된 라인을 임의로 변경하지 않는다.
- 전장 전체가 기본 전략 화면에 들어오므로 별도 미니맵을 사용하지 않는다.

---

## 2. 고정 전장 토폴로지

각 라인은 아래 순서를 독립적으로 가진다.

```text
아군 본진
→ 아군 라인 성문
→ 아군 중간거점
→ 중앙 접전지
→ 적 중간거점
→ 적 라인 성문
→ 적 본진
```

### 연결 금지

- 상·중·하 사이에 일반 횡단로를 두지 않는다.
- 중앙 접전지는 해당 라인의 앞뒤 도로에만 연결한다.
- 중간거점끼리 세로로 연결하지 않는다.
- 건물·바리케이드·전술 명령은 새로운 라인 연결로를 만들지 않는다.
- 암살자 우회로도 출발한 라인의 적 후열로만 이어진다.

### 대칭 기준

- 성문, 중간거점, 건설 노드, 접전지, 우회로 출발·도착 지점은 기능상 대칭이다.
- 장식과 지형 테마는 비대칭으로 꾸밀 수 있다.
- 실제 이동 거리와 유효 전투 공간은 진영별 승률 편차가 나지 않게 보정한다.

## 3. 본진과 라인별 성문

### 3.1 기본 역할

- 각 본진 입구에 상·중·하 라인별 성문을 하나씩 둔다.
- 한 라인의 성문이 무너져도 다른 라인의 성문은 유지된다.
- 아군은 통과하고 적은 파괴 전까지 차단된다.
- 중간거점 점령 여부와 무관하게 실제로 도달한 적은 성문을 공격할 수 있다.
- 성문은 공격 시설이 아니라 최종 진입 차단 구조물이다.

### 3.2 수직 슬라이스 초기값

```text
max_hp = 5000
armor = 80
magic_resistance = 80
normal_structure_damage_multiplier = 0.40
siege_structure_damage_multiplier = 2.00
fixed_structure_damage_multiplier = 0.50
collapse_duration = 2.0초
```

- 군중제어, 밀치기, 이동 방해, 비율 피해에 면역이다.
- HP가 0이 되면 2초 붕괴 연출 후 통로가 열린다.
- 폐허는 이동을 막지 않는다.
- 수직 슬라이스에서는 자동 수리와 재건을 사용하지 않는다.
- 성문 세 개의 HP와 파괴 상태는 서로 독립적이다.

### 3.3 초기 바리케이드

- 성문 또는 중간거점 전방에 둘 수 있다.
- 적 진군을 지연하지만 도로를 영구 완전 봉쇄하지 않는다.
- 배치 여부와 수량은 스테이지 데이터에서 정한다.

## 4. 중간거점

각 라인에는 양 진영이 하나씩 보유한 중간거점이 존재한다.

- 점령 가능한 전략 목표다.
- 해당 라인의 건설권과 기본 자원 생산을 제공한다.
- 전선 유지와 성문 방어를 위한 전진 기지다.
- 암살자 우회로의 출발·도착 기준점이다.

### 4.1 건설 노드

각 중간거점은 총 3개의 노드를 가진다.

```text
             중앙 접전지 방향

      [전방 노드 A]  [전방 노드 B]

              [중간거점]

              [후방 노드]

                 본진 방향
```

- 전방 2개: 방어탑, 공격 지원, 전선 강화 시설에 적합하다.
- 후방 1개: 자원, 회복, 지원 시설에 적합하다.
- 노드와 최대 크기 건물은 주 이동로를 침범하지 않는다.

### 4.2 점령 상태

```text
OWNED
→ CONTESTED_OR_CAPTURING
→ NEUTRAL
→ STABILIZING
→ OWNED_BY_NEW_FACTION
```

- 한 진영만 유효 점령 병력을 보유할 때 진행된다.
- 양 진영이 함께 있으면 교착되어 게이지가 정지한다.
- 적 소유 거점은 중립화 후 새 진영 점령의 두 단계로 넘어간다.

### 4.3 수직 슬라이스 초기값

```text
neutralize_seconds_at_power_1 = 10.0
capture_seconds_at_power_1 = 10.0
max_effective_capture_power = 2.0
minimum_full_takeover_seconds = 10.0
progress_hold_after_exit = 3.0초
progress_revert_rate = 10% / 초
stabilization_seconds = 5.0
owned_income = 금화 +2 / 30초
```

#### 점령력

| 병종군 | 점령력 |
|---|---:|
| 방패·수호형 | 1.25 |
| 일반 근접·기병 | 1.00 |
| 원거리·지원·거인 | 0.50 |
| 암살자·비행·순수 공성 병기 | 0.00 |

- 합산 유효 점령력은 최대 2.0으로 제한한다.
- 점령 병력이 모두 사라지면 3초 동안 진행도를 유지한다.
- 3초 뒤 이전 안정 상태를 향해 초당 10%씩 되돌아간다.

### 4.4 생산·건설·기존 건물 처리

- 점령 시도가 시작되면 신규 건설과 업그레이드를 잠근다.
- 점령 시도, 교착, 중립 상태에서는 거점 기본 생산을 정지한다.
- 중립화가 완료되면 기존 건물 기능이 정지한다.
- 점령 완료 시 기존 건물은 환불 없이 폐허가 된다.
- 적 건물의 즉시 소유권 전환은 사용하지 않는다.
- 점령 완료 후 5초 안정화가 끝나면 새 소유자가 노드를 사용한다.
- 기본 생산도 안정화 완료 후 시작한다.

이 방식은 점령 직후 기존 건물까지 즉시 획득하는 과도한 눈덩이를 막고, 건설권과 경제권을 빼앗았다는 결과는 명확히 유지한다.

## 5. 중앙 접전지

- 각 라인의 주력 병력이 충돌하는 독립 점령 구역이다.
- 건설 노드를 두지 않는다.
- 다른 라인이나 우회로와 연결하지 않는다.
- 점령 보상은 라인 전선 보너스와 접전지 수입이다.
- 정확한 수입과 전선 보너스는 경제 책임 문서에서 관리한다.

| 구분 | 중앙 접전지 | 중간거점 |
|---|---|---|
| 핵심 목적 | 정면 전선 주도권 | 건설권·생산권·전진 기지 |
| 건설 | 불가 | 전방 2·후방 1 |
| 점령 보상 | 라인 보너스·접전지 수입 | 건설권·거점 기본 생산 |
| 전투 빈도 | 상시 높음 | 공방 단계에서 높음 |

## 6. 암살자 우회로

### 6.1 역할

암살자는 적 후방에 직접 생성되지 않는다.

```text
아군 중간거점보다 조금 앞선 진입점
→ 안개 속 우회 이동
→ 적 중간거점 후방 도착 구역
→ 원거리·지원·후방 시설 공격
```

### 6.2 수직 슬라이스 초기값

```text
entry_windup = 1.0초
travel_duration = 9.0초
defender_warning_before_arrival = 2.5초
arrival_recovery = 0.6초
exit_offset_from_enemy_outpost = 본진 방향 120 units
exit_zone_size = 160 × 120 units
blocked_fallback_radius = 80 units
capture_power = 0
```

### 6.3 이동 규칙

- 암살자는 아군 측 배치 지점에 배치한 뒤 우회로에 진입한다.
- 진입 확정 후 취소하거나 후퇴할 수 없다.
- 우회 중 다른 라인으로 이동하지 않는다.
- 우회 중 공격, 피격, 버프, 디버프, 점령 판정을 받지 않는다.
- 구현상 전장 밖 이동 상태로 취급한다.
- 막힌 도착점은 반경 80 units 안의 가장 가까운 유효 지점으로 보정한다.
- 출현 후 0.6초 준비를 거쳐 공격을 시작한다.
- 우회 종료 후에는 같은 라인에서 일반 유닛처럼 계속 전투한다.
- 암살자는 우회 전후 모두 점령력 0이다.

### 6.4 안개와 경고

- 평상시에는 경로 선, 출입구, 도착점을 모두 숨긴다.
- 암살자를 선택하면 배치 가능한 우회로 윤곽만 보인다.
- 라인을 지정하면 출발점, 이동 방향, 도착 구역을 표시한다.
- 배치 확정 후 해당 암살자의 경로만 필요한 동안 표시한다.
- 수비 측에는 도착 2.5초 전 도착 구역의 안개 파동 경고를 표시한다.
- 침투 종료 또는 선택 해제 후 다시 안개로 가린다.
- 탐지 전용 건물과 경고 시간 증폭은 수직 슬라이스 범위에서 제외한다.

### 6.5 공격 우선순위

```text
지원병·원거리 병력
→ 후방 자원·지원 시설
→ 공성 병력
→ 가장 가까운 일반 전투 병력
```

정면 전열과 장시간 맞붙는 범용 근접 병종으로 바꾸지 않는다.

```text
PoC 플레이 영역: 2880 × 1280 world units
일반 보행속도 기준: 60 world units/sec
Tier 1 포탑 사거리 기준: 270 world units

중간거점 전방: 240~300 world units
성문 전방: 260~320 world units
```

- 최소 두 개 이상의 병력 이동 열을 유지한다.
- 근접 전열 뒤에 원거리·지원 유닛 공간을 확보한다.
- 대형 건물도 도로 중앙을 막지 않는다.
- 바리케이드는 지연 효과만 제공한다.

## 8. 카메라와 전장 UI

- 기본 전략 줌에서 양측 본진과 세 라인 전체가 보인다.
- 별도 미니맵은 사용하지 않는다.
- 성문 HP, 중간거점 소유권·점령 게이지, 노드 상태, 중앙 접전지 상태를 실제 전장 위에 표시한다.
- 암살자를 선택했을 때만 우회로 안개를 부분적으로 걷는다.
- 우회로 표시가 성문·거점·접전지 핵심 정보를 가리지 않게 한다.
- 라인 경고 클릭은 해당 라인을 화면 중심에 두되 강제 확대하지 않는다.

## 9. 수직 슬라이스 검증 기준

1. 기본 화면에서 3초 안에 가장 위험한 라인을 찾는다.
2. 상·중·하 접전지가 연결된 길로 오인되지 않는다.
3. 성문 세 개의 상태가 독립적으로 보인다.
4. 전방 2·후방 1 노드가 도로를 막지 않는다.
5. 중간거점 점령 시 생산·건설 잠금과 소유권 변화가 명확하다.
6. 점령 완료 후 기존 건물이 폐허화되고 5초 뒤 새 건설이 가능하다.
7. 성문 공성에서 일반 병력보다 공성 태그가 분명히 효율적이다.
8. 암살자 선택 전에는 우회로가 보이지 않는다.
9. 암살자 선택·배치 중 출발 라인과 도착 후열을 이해한다.
10. 수비 측은 도착 2.5초 전 경고를 보고 대응할 수 있다.
11. 미니맵 없이 전황을 파악할 수 있다.

## 10. 조정 가능한 값

다음은 구조 변경이 아니라 플레이테스트 조정 대상이다.

- 점령 10+10초와 점령력 배율.
- 거점 금화 +2/30초와 안정화 5초.
- 성문 HP·방어·피해 배율.
- 암살자 이동 9초·경고 2.5초·도착 영역.
- 도로 폭과 라인별 이동 거리.

구조, 라인 연결 금지, 성문 3개, 중간거점 노드 배치, 건설권·생산권 이전, 암살자 직접 후방 배치 금지, 우회로 안개 표시, 미니맵 미사용 원칙은 사용자 승인 없이 변경하지 않는다.

## C2 구현 상태

C2 구현 후보는 중앙 접전지 3개, 양측 중간거점 6개, 성문 6개, 본진 2개와 같은 라인 목적 순서를 실제 전투 상태로 연결한다. 점령·교착·건설 revision·성문 붕괴·자연 승패 자동 회귀가 존재한다.

- 본진 독립 수치는 아직 승인하지 않았다. 미지정 시 성문 프로필을 기술 fallback으로 재사용한다.
- 중앙 접전지의 별도 점령 시간도 미승인이다. 승인 중간거점 상태기를 재사용한다.
- 정규화 목적 좌표는 시뮬레이션 좌표이며 이 문서의 시각 scale을 변경하지 않는다.
- 사람 플레이·가독성·밸런스 검증 전에는 최종값으로 승격하지 않는다.
