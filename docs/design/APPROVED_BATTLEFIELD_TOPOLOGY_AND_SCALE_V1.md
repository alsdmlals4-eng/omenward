- 상태: **전장 연결 구조 승인 / 수치·거리·카메라 비율은 PoC 초기 가설**
- 작성일: 2026-07-15
- 적용 범위: 실베른 성채 튜토리얼, 정규 스테이지 기본 맵, 카메라, 유닛 이동, 건설 노드, 포탑 사거리, 전술 스킬 범위
- 연결 문서:
  - `docs/design/APPROVED_BELLU_SINGLE_GUIDE_AND_FIRST_10_MINUTE_FLOW.md`
  - `docs/OMENWARD_GAME_DESIGN.md`
  - `docs/design/APPROVED_OMENWARD_WORLD_AND_NAMING.md`

이 문서는 오멘워드의 기본 전장 구조와 화면 스케일을 정의한다. 연결 구조는 임의로 변경하지 않으며, 수치는 첫 수직 슬라이스 플레이테스트 뒤 조정할 수 있다.

## 1. 전장 설계 목표

플레이어는 기본 전략 줌에서 다음 정보를 3초 안에 파악할 수 있어야 한다.

1. 상·중·하 중 어느 라인이 위험한가
2. 아군과 적군이 각 라인의 어느 구간에서 충돌하고 있는가
3. 어느 건설 노드가 비어 있으며 어떤 건물이 전선을 지원하는가
4. 룰렛·용병·전술 명령 중 지금 사용할 수 있는 수단은 무엇인가
5. 본진과 중간요새가 어느 정도 위험한가

전장은 유닛 감상보다 전체 지휘 판단을 우선한다. 기본 화면에서 맵 전체와 양측 본진이 넉넉하게 보여야 하며, 확대하면 병종과 기술 연출을 확인할 수 있어야 한다.

## 2. 고정 전장 토폴로지

### 2.1 전체 루트

모든 기본 스테이지는 아래 연결 순서를 사용한다.

```text
아군 본진
→ 아군 본진 접전지
→ 상·중·하 라인 분기
→ 각 라인의 아군 중간요새
→ 각 라인의 중앙 접전지
→ 각 라인의 적 중간요새
→ 상·중·하 라인 수렴
→ 적 본진 접전지
→ 적 본진
```

### 2.2 라인 방향

```text
상단: 아군 본진 접전지에서 위쪽으로 분기해 진행
중단: 아군 본진 접전지에서 적 본진 접전지까지 직진
하단: 아군 본진 접전지에서 아래쪽으로 분기해 진행
```

### 2.3 연결 금지 규칙

- 상단·중단·하단 사이에 횡단로를 두지 않는다.
- 중간요새 사이를 세로로 연결하지 않는다.
- 중앙 접전지 사이를 세로로 연결하지 않는다.
- 일반 유닛은 배치된 라인에서 다른 라인으로 이동하지 않는다.
- 건물과 전술 명령은 새 이동 경로를 만들지 않는다.
- 순간이동·공중 강습 같은 특수 콘텐츠가 추가되더라도 라인 변경은 예외 능력으로 명시한다.

### 2.4 평면 구조

```text
                         ┌─ 상단 아군 중간요새 ─ 상단 중앙 접전지 ─ 상단 적 중간요새 ─┐
아군 본진 ─ 아군 본진 접전지 ├─ 중단 아군 중간요새 ─ 중단 중앙 접전지 ─ 중단 적 중간요새 ─┤ 적 본진 접전지 ─ 적 본진
                         └─ 하단 아군 중간요새 ─ 하단 중앙 접전지 ─ 하단 적 중간요새 ─┘
```

도식의 분기선은 실제 횡단로가 아니다. 세 라인은 본진 접전지에서만 분기하고 반대편 본진 접전지에서만 다시 수렴한다.

## 3. 기준 좌표와 맵 크기

### 3.1 설계 좌표계

PoC 기준 플레이 가능 영역을 다음 크기로 둔다.

```text
가로: 2,880 world units
세로: 1,280 world units
```

장식용 외곽 버퍼는 좌우 120, 상하 80 world units를 추가할 수 있다.

### 3.2 주요 지점 중심 좌표

| 지점 | X | Y |
|---|---:|---:|
| 아군 본진 | 120 | 640 |
| 아군 본진 접전지 | 360 | 640 |
| 상단 아군 중간요새 | 800 | 320 |
| 중단 아군 중간요새 | 800 | 640 |
| 하단 아군 중간요새 | 800 | 960 |
| 상단 중앙 접전지 | 1,440 | 320 |
| 중단 중앙 접전지 | 1,440 | 640 |
| 하단 중앙 접전지 | 1,440 | 960 |
| 상단 적 중간요새 | 2,080 | 320 |
| 중단 적 중간요새 | 2,080 | 640 |
| 하단 적 중간요새 | 2,080 | 960 |
| 적 본진 접전지 | 2,520 | 640 |
| 적 본진 | 2,760 | 640 |

좌표는 구현용 확정 좌표가 아니라 레벨 블록아웃 기준이다. 지형 테마에 따라 곡선과 세부 위치를 조정할 수 있지만, 중단의 직선성과 라인 비연결 규칙은 유지한다.

## 4. 구간 길이와 이동 시간

### 4.1 구간 기준 거리

| 구간 | 중단 | 상·하단 | 기능 |
|---|---:|---:|---|
| 본진 → 본진 접전지 | 240 | 동일 | 최종 방어 구간 |
| 본진 접전지 → 아군 중간요새 | 440 | 약 540 | 라인 분기 구간 |
| 아군 중간요새 → 중앙 접전지 | 640 | 640 | 주 전투 준비 구간 |
| 중앙 접전지 → 적 중간요새 | 640 | 640 | 역공 구간 |
| 적 중간요새 → 적 본진 접전지 | 440 | 약 540 | 라인 수렴 구간 |
| 적 본진 접전지 → 적 본진 | 240 | 동일 | 최종 공격 구간 |

전체 이동 거리:

```text
중단: 약 2,640 world units
상·하단: 약 2,840 world units
```

상·하단은 중단보다 약 7~8% 길다. 이 차이는 화면상 위·아래 분기를 자연스럽게 보이기 위한 초기 허용치다. 실제 승률 차이가 커지면 상·하단 중간요새의 랠리 위치나 이동 보정으로 3% 이내까지 줄인다.

### 4.2 기준 이동속도

초기 보행형 일반 유닛 기준:

```text
기본 이동속도: 60 world units / sec
```

예상 시간:

| 이동 | 예상 시간 |
|---|---:|
| 본진 → 본진 접전지 | 약 4초 |
| 본진 접전지 → 중단 아군 중간요새 | 약 7.3초 |
| 본진 접전지 → 상·하단 아군 중간요새 | 약 9초 |
| 중간요새 → 중앙 접전지 | 약 10.7초 |
| 중단 전체 횡단 | 약 44초 |
| 상·하단 전체 횡단 | 약 47초 |

기병·러너형은 75~90, 중장갑·브루트형은 42~50을 초기 범위로 사용한다.

### 4.3 첫 30초 징조와 이동의 관계

`베일의 징조 30초`는 **적 선두가 중앙 접전지 전투 반경에 진입할 때까지 남은 시간**을 의미하는 방향을 우선한다.

초기 구성:

```text
징조 공개
→ 약 18초 동안 적 편성·출격 준비
→ 적 중간요새에서 출발
→ 약 10~12초 이동
→ 중앙 접전지 진입
```

이 방식은 플레이어가 건설·룰렛·배치할 준비 시간과 실제로 접근하는 적을 보는 긴장감을 함께 제공한다.

## 5. 길과 전투 공간

### 5.1 일반 도로 폭

```text
기본 도로 폭: 160~180 world units
```

목표:

- 일반 보병 4~6명이 전열을 구성할 수 있음
- 근접 유닛이 한 점에 완전히 겹치지 않음
- 원거리 유닛이 후방에 설 공간이 있음
- 길이 넓어 보여도 다른 라인으로 이탈할 수는 없음

### 5.2 중간요새 전방 폭

```text
요새 전방 전투 폭: 220~260 world units
```

요새 문 앞에서 수비 병력과 공격 병력이 자연스럽게 전열을 만들 수 있게 일반 도로보다 넓힌다.

### 5.3 중앙 접전지

```text
점령 판정 반경: 120 world units
주 교전 반경: 220 world units
시각적 원형 지름: 약 240~260 world units
```

- 점령 판정은 작은 중심 원에서 계산한다.
- 전투 연출과 부대 밀집은 더 넓은 주 교전 반경에서 일어난다.
- 비행 유닛은 기본적으로 점령 수치에 기여하지 않는다.

### 5.4 본진 접전지

```text
전투 반경: 160 world units
```

본진 접전지는 세 라인의 분기·수렴 허브다. 중앙 접전지처럼 지속 금화를 주는 점령지는 아니며, 돌파될 경우 본진 위험 단계가 시작되는 방어 구역이다.

## 6. 건설 노드

### 6.1 총량

```text
후방 노드: 6개
상단 노드: 3개
중단 노드: 3개
하단 노드: 3개
총 15개
```

### 6.2 후방 노드 6개

아군 본진과 아군 본진 접전지 주변의 안전 지역에 둔다.

추천 배치:

- 본진 상부 2개
- 본진 하부 2개
- 본진 접전지 후방 상·하 각 1개

경제·증원 중심 시설을 배치하기 쉽지만 중앙 접전지에 대한 직접 영향은 낮다.

### 6.3 라인별 노드 3개

각 라인은 다음 세 역할의 노드를 가진다.

| 노드 | 위치 | 위험·효율 |
|---|---|---|
| 후방 노드 | 아군 중간요새 뒤 약 160~200 | 안전, 중앙 영향 낮음 |
| 측면 노드 | 중간요새 옆 약 110~150 | 중간 위험, 요새 방어 유리 |
| 전방 노드 | 중앙 접전지에서 아군 쪽 약 220~260 | 위험, 포탑·전술 지원 효율 높음 |

세 노드는 도로를 막지 않고 도로 중심에서 최소 100 world units 이상 떨어뜨린다.

### 6.4 노드와 건물 크기

초기 블록아웃 기준:

| 대상 | 점유 크기 |
|---|---:|
| 건설 노드 표시 지름 | 112~128 |
| 포탑·소형 시설 | 80~96 |
| 병영·시장·농장 | 112~144 |
| Tier 3 대형 건물 | 최대 160 |
| 중간요새 | 180~220 |
| 본진 | 280~340 |

건물 Tier가 올라가도 도로 또는 다른 노드를 침범하지 않는다. 외형 증가는 수직 실루엣과 주변 소품으로 우선 표현한다.

### 6.5 노드 표시 규칙

```text
평상시: 기초석·말뚝·정리된 흙으로 약하게 표시
마우스오버: 얇은 원형 외곽선과 + 아이콘
선택: 건물 미리보기·가격·영향 범위 표시
건설 중: 기초 → 골조 → 기능부 완성
```

평상시 흰 원이 화면 전체에 상시 노출되는 방식은 사용하지 않는다.

## 7. 포탑과 전술 범위

### 7.1 기본 포탑 사거리

```text
Tier 1 기본 사거리: 270 world units
Tier 2 권장 범위: 300~330
Tier 3 권장 상한: 350~380
```

기본 포탑 한 기가 중간요새와 중앙 접전지 사이의 전체 640 units를 단독으로 덮지 못해야 한다. 전방 노드 포탑은 중앙 접전지 일부를 지원하지만 반대편 요새까지 공격하지 못한다.

### 7.2 기본 공격 거리 참고

| 유형 | 초기 범위 |
|---|---:|
| 근접 | 28~42 |
| 창·장병기 | 48~64 |
| 일반 원거리 | 180~220 |
| 장거리 특화 | 240~280 |

### 7.3 전술 명령 범위

| 명령 | 초기 공간 값 |
|---|---|
| 바리케이드 | 도로 폭의 75~85%, 폭 130~150 / 깊이 32~40 |
| 화살비 | 반경 140 |
| 역병 | 반경 120 |
| 강화지대 | 반경 160 |

전술 범위 표시는 픽셀 이펙트와 분리된 얇은 외곽선·점선·바닥 음영으로 표시한다.

## 8. 유닛과 건물 화면 크기

### 8.1 기본 전략 줌의 목표 화면 높이

1920×1080 출력 기준:

| 대상 | 목표 화면 높이 |
|---|---:|
| 일반 보병 | 34~40 px |
| 엘리트 | 40~46 px |
| 영웅 | 46~54 px |
| 전설 | 54~62 px |
| 기병·대형 일반병 | 46~58 px |
| 보스 | 80~120 px 이상 |
| 일반 건물 | 64~96 px |
| 중간요새 | 100~130 px |
| 본진 | 150~180 px |

### 8.2 등급별 크기 비율

```text
일반: 1.00
엘리트: 1.12~1.18
영웅: 1.28~1.35
전설: 1.42~1.50
```

등급은 크기만으로 표현하지 않는다.

- 엘리트: 무기·견갑·자세 차이
- 영웅: 고유 무기·망토·고유 실루엣
- 전설: 완전히 독립적인 실루엣과 기술 순간 발광
- 지속 오라는 최소화하고 선택·기술 발동 순간에만 강조

### 8.3 픽셀 제작 기준

권장 내부 논리 해상도:

```text
960×540 → 1920×1080 정수 2배 확대
```

권장 원본 스프라이트 높이:

| 대상 | 논리 픽셀 |
|---|---:|
| 일반 | 17~20 px |
| 엘리트 | 20~23 px |
| 영웅 | 23~27 px |
| 전설 | 27~31 px |

카메라 확대 상태에서는 정수 또는 픽셀 스냅 규칙을 적용해 흐림을 방지한다.

## 9. 카메라와 화면 구도

### 9.1 HUD 안전 영역

1920×1080 기준 초기 배치:

```text
상단 상태바: 64~72 px
하단 조작 UI: 220~240 px
실제 전장 표시 영역: 약 1920×768~796 px
```

하단:

- 좌측 하단: 3×3 룰렛
- 중앙 좌측: 건설
- 중앙: 용병·대기 병력
- 중앙 우측: 전술 명령
- 우측 하단: 벨루와 최대 두 줄 대사

### 9.2 카메라 단계

| 단계 | 배율 개념 | 용도 |
|---|---:|---|
| 전체 조망 | 0.85× | 장식 외곽까지 포함한 전장 전체 확인 |
| 기본 전략 | 1.00× | 양측 본진과 세 라인 전체가 넉넉하게 보이는 기본 상태 |
| 전술 확대 | 1.25× | 한두 라인의 병종·건물 상태 확인 |
| 교전 확대 | 1.55× | 접전지 기술·상태이상·영웅 연출 확인 |

`1.00×`는 구현 엔진의 실제 Camera2D zoom 값이 아니라 플레이어가 느끼는 기준 배율이다.

### 9.3 카메라 조작

- 마우스 휠 확대·축소
- 커서 위치를 기준으로 확대
- 가운데 버튼 드래그 또는 WASD 이동
- 화면 가장자리 이동은 설정에서 켜고 끌 수 있음
- 스페이스 또는 지정 키로 전체 전략 줌 복귀
- 라인 경고 클릭 시 해당 라인을 화면 중심에 두되 강제 줌은 하지 않음
- 영웅 기술 때문에 자동 카메라가 이동하지 않음

### 9.4 기본 시야 계약

게임 시작과 일반 플레이의 기본 카메라에서는 다음이 모두 화면에 보여야 한다.

- 아군 본진과 적 본진
- 아군·적 본진 접전지
- 상·중·하 양측 중간요새 6개
- 중앙 접전지 3개
- 전방 건설 노드 상태
- 각 라인의 가장 앞선 아군·적군 위치

건물 이름과 유닛 체력바는 줌 단계와 선택 상태에 따라 축약한다.

## 10. 첫 10분과 거리 검증

### 10.1 첫 배치

첫 검사는 상단 아군 중간요새 전방 랠리 지점에 배치한다.

```text
랠리 지점 → 상단 중앙 접전지: 약 520~600 units
검사 이동 시간: 약 8.5~10초
```

기존 첫 10분 계약의 `배치 뒤 10초 안 첫 교전`을 만족해야 한다.

### 10.2 포탑 역전

두 번째 공세의 전방 포탑은 상단 중앙 접전지 아군 측 약 230 units 위치의 전방 노드에 둔다.

- 적 선두가 사거리 가장자리에 들어오기 1~2초 전에 완공
- 완공 직후 첫 발사가 선두에게 명중
- 포탑이 없으면 일부 적이 본진 방향으로 통과
- 포탑 또는 바리케이드를 사용하면 안정적으로 저지

### 10.3 합격 기준

- 기본 전략 줌에서 위험 라인을 3초 안에 찾는 비율 90% 이상
- 상·중·하 라인이 연결되어 있다고 오해하는 플레이어 5% 미만
- 일반/엘리트/영웅 크기를 실루엣만으로 구분하는 비율 80% 이상
- 첫 병력 배치 후 첫 접촉 8~12초
- 징조 30초 동안 최소 한 번의 건설·룰렛·배치 결정을 완료 가능
- 기본 포탑 한 기가 한 라인의 전체 주요 구간을 덮지 않음
- 기본 전략 줌에서 건물·병력이 너무 작다고 응답하는 비율 20% 미만

## 11. 플레이테스트 조정 순서

전장이 너무 넓거나 느릴 때 맵 전체를 즉시 축소하지 않는다.

조정 우선순위:

```text
1. 랠리 지점 위치
2. 일반 이동속도 ±10%
3. 전투 사이 대기 시간
4. 중간요새↔접전지 거리 ±8%
5. 전체 맵 크기
```

전장이 너무 좁거나 혼잡할 때:

```text
1. 도로 폭과 교전 반경 확대
2. 충돌 반경·대형 유닛 밀도 조정
3. 웨이브 출격 간격 조정
4. 유닛 화면 크기 축소
```

카메라가 너무 멀게 느껴질 때는 먼저 유닛·건물 화면 크기를 5~10% 키우고, 전체 맵이 잘리는 방식으로 기본 줌을 바꾸지 않는다.

## 12. 확정과 미확정 경계

### 확정

- 중단은 본진에서 적 본진 방향으로 직진한다.
- 상단은 위로, 하단은 아래로 분기한다.
- 세 라인 사이 횡단로와 요새 간 연결로는 없다.
- 라인은 본진 접전지에서만 분기·수렴한다.
- 기본 전략 줌에서 맵 전체와 양측 본진이 보인다.
- 확대·축소와 카메라 이동을 지원한다.
- 룰렛은 좌측 하단 3×3 고정 패널을 사용한다.
- 벨루는 우측 하단 대사 도크를 사용한다.
- 엘리트·영웅·전설은 일반보다 점진적으로 크게 표현한다.
