# 승인된 전장 구조·점령·암살자 우회로 기준

- 상태: **3라인 대칭 구조·라인별 성문·중간거점 점령·암살자 우회로 표시 규칙 승인 / 세부 수치는 PoC 가설**
- 최초 작성일: 2026-07-15
- 최신 갱신일: 2026-07-16
- 적용 범위: 기본 전장, 튜토리얼 전장, 카메라, 길, 성문, 중간거점, 중앙 접전지, 건설 노드, 암살자 이동, 전장 UI
- 책임 원본: 이 문서가 전장 구조와 암살자 우회로의 최신 기준이다.

이 문서는 기존 전장 토폴로지 초안을 현재 승인된 구조로 교체한다. 과거 내용은 별도 활성 문서로 복제하지 않고 Git 이력에서만 보존한다.

## 1. 전장 정체성

오멘워드의 기본 전장은 **한 화면에서 전체 전황을 읽는 좌우 대칭형 3라인 점령·건설·공성 전장**이다.

핵심 전술은 다음 네 축으로 구성한다.

```text
중앙 접전지 장악
→ 중간거점 점령과 건설권·생산권 확보
→ 암살자 우회 침투로 후열 교란
→ 라인별 성문 돌파와 본진 공성
```

- 좌측 아군 구조를 기준으로 우측 적군 구조는 대칭이다.
- 상단·중단·하단은 각각 독립된 라인이다.
- 일반 병력은 배치된 라인을 임의로 변경하지 않는다.
- 전장 전체가 기본 전략 화면에 들어오므로 별도 미니맵을 사용하지 않는다.

---

## 2. 고정 전장 토폴로지

### 2.1 라인별 기본 진행 순서

각 라인은 아래 순서를 독립적으로 가진다.

```text
아군 본진
→ 아군 라인 성문
→ 아군 중간거점
→ 중앙 접전지
→ 적 중간거점
→ 적 라인 성문
→ 적 본진
```

상단·중단·하단의 지형 곡률과 장식은 달라질 수 있지만 기능 순서는 같다.

### 2.2 좌우 대칭

- 아군 본진과 적 본진은 좌우 반전 구조다.
- 라인별 성문, 중간거점, 건설 노드, 중앙 접전지, 우회로 출발·도착 위치도 기능상 대칭이다.
- 장식물과 지형 테마는 비대칭으로 꾸밀 수 있으나 이동 거리와 유효 전투 공간은 승률 편차가 생기지 않게 맞춘다.

### 2.3 연결 금지 규칙

- 상단·중단·하단 사이에 일반 횡단로를 두지 않는다.
- 중앙 접전지는 해당 라인의 앞뒤 도로에만 연결한다.
- 한 접전지에서 다른 라인이나 다른 접전지로 빠지는 길을 만들지 않는다.
- 중간거점 사이를 세로로 연결하지 않는다.
- 건물, 바리케이드, 전술 명령은 새로운 라인 연결로를 만들지 않는다.
- 암살자 우회로도 같은 라인의 적 후열로만 이어지며 다른 라인으로 갈 수 없다.

## 3. 본진과 라인별 성문

### 3.1 본진

본진은 최종 방어 구역이자 병력 배치의 출발점이다.

- 본진 핵심 목표물이 파괴되면 해당 전투에서 패배한다.
- 상단·중단·하단 출구는 서로 구분되어야 한다.
- 본진 건물과 배치 공간이 도로를 막지 않게 충분한 여유 공간을 둔다.

### 3.2 라인별 성문

상단·중단·하단의 본진 진입부에 각각 하나의 성문을 둔다.

- 한 라인의 성문이 무너져도 다른 라인의 성문은 유지된다.
- 적 병력은 해당 라인의 성문을 파괴하거나 무력화해야 본진 내부로 진입할 수 있다.
- 성문은 아군 병력의 정상 출격을 방해하지 않는다.
- 공성 병력과 거인은 성문 파괴의 핵심 수단이다.
- 성문 앞은 전열이 형성될 수 있도록 일반 도로보다 넓은 전투 공간을 확보한다.

### 3.3 초기 바리케이드

- 초기 바리케이드는 성문 전방 또는 중간거점 전방의 방어 준비 지점에 둘 수 있다.
- 도로 전체를 영구 봉쇄하지 않고 적 진군을 지연하는 구조물로 사용한다.
- 초기 배치 여부와 수량은 스테이지 규칙으로 정한다.

## 4. 중간거점

각 라인에는 아군과 적군이 하나씩 보유한 중간거점이 존재한다.

중간거점은 단순 통과 지점이 아니라 다음 기능을 가진다.

- 점령 가능 전략 목표
- 해당 라인의 건설권 제공
- 기본 자원 생산 제공
- 전선 유지와 성문 방어를 위한 전진 기지
- 암살자 침투의 출발·도착 기준점

### 4.1 건설 노드 배치

각 중간거점에는 총 3개의 건설 노드가 있다.

```text
             중앙 접전지 방향

      [전방 노드 A]  [전방 노드 B]

              [중간거점]

              [후방 노드]

                 본진 방향
```

- 전방 노드 2개: 방어탑, 공격 지원 시설, 바리케이드 지원, 전선 강화 시설에 적합하다.
- 후방 노드 1개: 자원, 회복, 지원, 탐지 계열 시설에 적합하다.
- 노드는 도로 바깥에 배치하며 최대 크기 건물도 주 이동로를 침범하지 않는다.
- 건물이 완공되거나 Tier가 올라가도 병력 통행 폭을 줄이지 않는다.

### 4.2 점령 상태

중간거점은 다음 상태를 가진다.

| 상태 | 의미 |
|---|---|
| 아군 점령 | 아군이 건설권과 거점 기본 생산을 보유 |
| 점령 진행 | 적이 점령 게이지를 진행 중 |
| 교착 | 양 진영 병력이 함께 있어 점령이 정지 또는 상쇄 |
| 적군 점령 | 건설권과 거점 기본 생산이 적에게 이전 |

### 4.3 점령 결과

중간거점을 빼앗기면 다음이 즉시 발생한다.

- 해당 거점의 신규 건설권 상실
- 해당 거점의 기본 자원 생산 상실
- 점령 진영이 건설권과 기본 생산을 획득
- 해당 라인의 방어와 증원 유지력이 약화
- 적이 해당 라인의 성문 방향으로 전선을 밀기 쉬워짐

기존 건물의 파괴·정지·소유권 전환 방식은 PoC 구현 전에 별도 수치 규칙으로 확정한다. 확정 전에는 임의로 적 건물로 즉시 전환하지 않는다.

### 4.4 점령 판정 원칙

- 점령 범위 안에 한 진영만 유효 병력을 보유할 때 게이지가 진행된다.
- 양 진영 병력이 함께 있으면 교착 상태가 된다.
- 비행 유닛과 암살자의 점령 기여 여부는 병종 데이터에서 명시한다.
- 정확한 점령 시간과 병력 가중치는 플레이테스트 항목이다.

## 5. 중앙 접전지

각 라인의 중앙 접전지는 양 진영의 주력 병력이 정면 충돌하는 독립 점령 구역이다.

- 건설 노드를 두지 않는다.
- 다른 라인과 연결하지 않는다.
- 우회로의 출입구로 사용하지 않는다.
- 접전지 점령은 해당 라인의 전선 보너스와 자원 보상을 제공한다.
- 정확한 보상 수치와 주기는 경제 문서에서 관리한다.

중간거점과 중앙 접전지의 차이는 다음과 같다.

| 구분 | 중앙 접전지 | 중간거점 |
|---|---|---|
| 핵심 목적 | 정면 전선 주도권 | 건설권·생산권·전진 기지 |
| 건설 | 불가 | 전방 2·후방 1 노드 |
| 점령 보상 | 라인 보너스와 점령 수입 | 건설권과 거점 기본 생산 이전 |
| 전투 빈도 | 상시 높음 | 공격·방어 단계에서 높음 |

## 6. 암살자 우회로

### 6.1 역할

우회로는 암살자가 적 후방에 직접 생성되지 않고 실제 침투 시간을 거쳐 적 후열을 공격하게 만드는 특수 이동 경로다.

```text
아군 중간거점보다 조금 앞선 지점
→ 안개 속 우회로 이동
→ 적 중간거점 또는 주 교전선의 후방 진입
→ 적 원거리·지원·후방 시설 공격
```

### 6.2 이용 규칙

- 기본 이용 병종은 암살자다.
- 다른 병종이 사용하려면 별도의 승인된 특수 능력이 필요하다.
- 암살자는 아군 측 배치 지점에 배치한 뒤 우회로로 진입한다.
- 적 후방에 즉시 소환하거나 직접 배치하지 않는다.
- 출발한 라인의 적 후열로만 이동한다.
- 우회 중 다른 라인으로 변경할 수 없다.
- 우회 중 중앙 접전지나 중간거점을 점령하지 않는다.

### 6.3 안개와 표시 규칙

우회로는 평상시에 지형 안개·전장의 연무로 가린다.

- 평상시: 경로 선, 출입구, 도착점 모두 표시하지 않는다.
- 암살자 선택: 배치 가능한 라인의 우회로 윤곽만 임시로 드러낸다.
- 라인 지정: 예상 출발점, 이동 방향, 도착 구역을 표시한다.
- 배치 확정 후: 해당 암살자의 이동 경로를 필요한 동안만 보여준다.
- 침투 종료 또는 선택 해제 후: 경로를 다시 안개로 가린다.
- 일반 유닛 선택 중에는 우회로가 나타나지 않는다.

우회로는 상시 지도 정보가 아니라 **암살자 배치 순간에만 열리는 전술 정보**로 취급한다.

### 6.4 공격 우선순위

암살자는 기본적으로 다음 대상을 우선한다.

```text
지원병·원거리 병력
→ 후방 자원·지원 시설
→ 공성 병력
→ 주변의 일반 전투 병력
```

정확한 타깃 우선순위는 병종 AI 데이터에서 조정할 수 있으나, 정면 전열과 장시간 싸우는 병종으로 바꾸지 않는다.

## 7. 병종 역할과 전술 흐름

| 병종군 | 전장 역할 |
|---|---|
| 방패병·수호형 | 접전지와 거점에서 버티며 점령을 유지 |
| 근접 공격형 | 적 전열과 거점 수비 병력을 제거 |
| 원거리형 | 전열 뒤에서 지속 화력과 건물 견제 |
| 지원형 | 회복·강화·약화로 장기 교전 유지 |
| 공성형·거인 | 바리케이드·중간거점 시설·성문 파괴 |
| 암살자 | 안개 우회로를 통해 같은 라인의 적 후열 침투 |
| 정찰·탐지형 | 향후 승인 시 후열 경계와 침투 대응 담당 |

### 전투 단계

```text
1. 중간거점 건설 노드 구성
2. 중앙 접전지 선점 경쟁
3. 정면 전선과 암살자 침투 동시 운영
4. 적 중간거점 점령
5. 라인별 성문 공성
6. 열린 라인을 통한 본진 공격
```

전략의 핵심은 세 라인에 병력·건물·자원을 동일하게 나누는 것이 아니라, 방어 라인·경제 라인·돌파 라인·침투 라인을 상황에 따라 바꾸는 데 있다.

## 8. 길과 건물 공간

### 8.1 도로 폭 PoC 가설

```text
일반 주 도로: 200~240 world units
중간거점 전방: 240~300 world units
성문 전방: 260~320 world units
```

- 최소 두 개 이상의 병력 이동 열을 유지한다.
- 근접 전열 뒤에 원거리와 지원 유닛이 설 공간을 확보한다.
- 건설 노드는 도로 가장자리 바깥에 둔다.
- 대형 건물도 도로 중앙을 막을 수 없다.
- 바리케이드는 지연 효과를 주되 영구적인 완전 봉쇄가 되지 않는다.

### 8.2 기존 스케일 가설

- PoC 플레이 가능 영역: 2,880×1,280 world units.
- 일반 보행형 이동속도 기준: 60 world units/sec.
- Tier 1 포탑 사거리 기준: 270 world units.

이 수치는 블록아웃과 플레이테스트에서 조정 가능하지만 3라인 전체 조망, 성문별 독립 방어, 중간거점과 접전지의 분리 가독성을 훼손하지 않는다.

## 9. 카메라와 전장 UI

### 9.1 미니맵 미사용

전장이 기본 전략 줌에서 한눈에 보이므로 별도 미니맵을 두지 않는다.

미니맵 대신 실제 전장 위에서 다음 정보를 직접 표시한다.

- 라인별 성문 상태
- 중간거점 소유권과 점령 게이지
- 전방 2·후방 1 건설 노드 상태
- 중앙 접전지 점령 상태
- 가장 앞선 아군·적군 위치
- 공격받는 라인과 본진 경고

### 9.2 우회로 UI

- 암살자를 선택했을 때만 해당 라인의 안개가 부분적으로 걷힌다.
- 예상 침투 방향과 도착 구역은 얇은 경로와 영역 표시로 보여준다.
- 일반 화면에는 우회로 아이콘이나 상시 선을 남기지 않는다.
- 우회로 표시가 중앙 접전지, 건설 노드, 성문 상태를 가리지 않게 한다.

### 9.3 카메라 원칙

- 기본 전략 줌에서 양측 본진과 세 라인 전체가 보인다.
- 확대는 병종, 건물, 기술 연출 확인용이다.
- 라인 경고를 클릭하면 해당 라인을 중심에 두되 강제로 확대하지 않는다.
- 자동 연출이 플레이어의 전장 시야를 장시간 빼앗지 않는다.

## 10. 검증 기준

PoC 블록아웃은 다음 조건을 만족해야 한다.

1. 기본 화면에서 3초 안에 가장 위험한 라인을 찾을 수 있다.
2. 상·중·하 접전지가 서로 연결된 길로 오인되지 않는다.
3. 각 본진 입구에 성문이 세 개임을 즉시 구분할 수 있다.
4. 각 중간거점의 전방 2·후방 1 노드가 도로를 막지 않는다.
5. 중간거점 점령 시 건설권과 생산권 변화가 명확히 보인다.
6. 암살자를 선택하지 않았을 때 우회로가 보이지 않는다.
7. 암살자 선택·배치 중에는 출발 라인과 도착 후열을 이해할 수 있다.
8. 대형 건물과 병력이 겹쳐도 최소 두 이동 열이 유지된다.
9. 미니맵 없이도 성문·거점·접전지·전선 상태를 파악할 수 있다.

## 11. 구현 전 미확정 수치

다음은 구조가 아니라 플레이테스트와 Plan Mode에서 확정할 값이다.

- 중간거점 점령 시간과 병력별 점령 가중치
- 중간거점 기본 자원 생산량과 생산 주기
- 점령 시 기존 건물의 정지·파괴·회수 규칙
- 암살자 우회 이동 시간과 도착 범위
- 적 암살자 탐지·경고 수단
- 성문 HP·방어·재건 가능 여부
- 라인별 실제 이동 거리 보정

이 수치가 미확정이어도 본 문서의 구조, 연결 금지, 라인별 성문, 중간거점 노드 배치, 점령권 이전, 우회로 안개 표시 원칙은 변경하지 않는다.
