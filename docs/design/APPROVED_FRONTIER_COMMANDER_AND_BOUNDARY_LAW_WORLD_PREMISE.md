# 레거시 경로 — 오멘워드 세계관 계약으로 이동

기존 `경계의 율` 세계관 전제는 아래 공식 문서로 교체됐다.

- `docs/design/APPROVED_OMENWARD_WORLD_AND_NAMING.md`
- `docs/OMENWARD_GAME_DESIGN.md`
- `docs/design/APPROVED_BELLU_MASCOT_AND_GUIDE_CONTRACT.md`

유지되는 핵심 전제:

- 플레이어는 괴물 군단을 막는 최전선 지휘관이다.
- 괴물은 정체불명의 규칙에 따라 웨이브 단위로 넘어온다.
- 공세 전에는 정확한 징조가 나타난다.
- 세계관의 원인은 암시하지만 게임 효과와 수치는 HUD에 공개한다.

공식 명칭:

```text
경계의 율 → 베일의 법칙
율비 → 벨루
은종성채 → 실베른 성채
무명야 → 베일런 황야
```

이 경로는 과거 링크 호환용이며 신규 기획의 책임 문서로 사용하지 않는다.
