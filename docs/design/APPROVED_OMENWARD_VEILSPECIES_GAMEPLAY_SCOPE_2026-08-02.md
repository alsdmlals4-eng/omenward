## 1. 결정 요약

베일종은 사용자에게 상세한 문명·정치·우주론으로 설명하지 않는다. 제품에서는 **균열을 통해 현실로 넘어온 여러 종류의 이계 생물종** 정도로 이해할 수 있으면 충분하다.

```text
INTERNAL_UMBRELLA = 베일종 / VEIL_SPECIES
PLAYER_FACING_EXPLANATION = 균열에서 넘어온 이계 생물종
UNIFIED_RACE_OR_EMPIRE = NOT_REQUIRED
DETAILED_DIPLOMACY_OR_POLITICS = OUT_OF_CURRENT_SCOPE
BOUNDARY_BREAKER = BREACH_STABILIZING_BOSS_ORGANISM
```

이 결정은 세계관 서사를 확장하기 위한 것이 아니라 적 유닛·공세·보스 콘텐츠를 일관되게 제작하기 위한 최소 내부 규칙이다.

## 2. 내부 해석

- 베일종은 하나의 종족이나 단일 제국이 아니라, 이질적인 외부 법칙 환경에 적응한 다양한 생물의 현실 측 통칭이다.
- 모든 개체가 같은 지성·사회·명령 체계를 공유한다고 가정하지 않는다.
- 공세의 조직성은 군체 행동, 포식·번식 본능, 환경 반응, 우두머리 신호, 균열을 중심으로 한 생태적 집결로 설명할 수 있다.
- 일부 개체가 고등 지성을 가질 가능성은 닫지 않지만 현재 제품은 이를 설명하거나 외교 콘텐츠로 확장하지 않는다.
- 베일 자체는 여전히 비의지적 경계 현상이며 베일종의 행동 주체와 분리한다.

## 3. 사용자에게 보이는 정보

사용자에게 필요한 정보는 다음 세 가지다.

1. 어디에서 왔는가: 균열 너머의 이계.
2. 무엇을 하는가: 전선을 침식하고 균열을 확장한다.
3. 전투에서 어떻게 대응해야 하는가: 각 개체의 관측 가능한 행동과 약점.

허용되는 표현:

- 이계 생물
- 균열 생물
- 베일 생물
- 경계파쇄자
- 군집·돌격·원거리·방호·교란·공성 등 전투 역할

필수적이지 않은 표현:

- 이계 제국의 역사
- 종족별 정치 체계
- 왕조·신앙·외교 관계
- 다중우주 구조 강의
- 비적대 베일종과의 협상

## 4. 경계파쇄자

경계파쇄자는 단순히 체력이 높은 대형 적이 아니다.

```text
PRIMARY_FUNCTION = 균열 고정·확장
BATTLE_ROLE = 보스급 공성·환경 변형 생물
DEFEAT_RESULT = 해당 공세의 균열 안정성 붕괴와 봉쇄 가능 상태
```

- Stage 15·20 같은 위험 구간에서 전선·건물·공세 규칙을 바꾸는 핵심 위협으로 사용한다.
- 종류마다 균열을 확장하는 방식과 대응 규칙이 달라야 한다.
- 경계파쇄자를 처치하면 해당 침공로를 봉쇄할 수 있지만 베일 현상 전체가 사라지는 것은 아니다.
- 고대 병기·제국 장군·신의 화신 같은 설명은 현재 범위에서 요구하지 않는다.

## 5. 적 콘텐츠 제작 분류

다음은 정확한 최종 적 명단이 아니라 콘텐츠 설계용 역할 분류다.

| 역할 | 전투 압박 | 설계 목적 |
|---|---|---|
| 군집형 | 다수·점유·소모 | 광역 대응과 라인 유지 시험 |
| 돌격형 | 빠른 전선 돌파 | 초기 대응·배치 타이밍 시험 |
| 원거리형 | 후열·건물 압박 | 보호 우선순위와 전선 구성 시험 |
| 방호형 | 피해 흡수·진형 보호 | 화력 집중과 역할 조합 시험 |
| 교란형 | 릴·건물·전선 규칙에 명시적 방해 | 원인 가독성과 대응 판단 시험 |
| 공성형 | 거점·성문·건물 파괴 | 장기 방어와 건설 선택 시험 |
| 경계파쇄자 | 균열 고정·공세 규칙 변화 | 위험 Stage와 최종 봉쇄 시험 |

각 적은 외형보다 먼저 다음을 가져야 한다.

```text
OBSERVABLE_BEHAVIOR
CLEAR_THREAT_TARGET
COUNTERPLAY
CAUSE_OF_FAILURE
```

## 6. 서사 전달 원칙

- 장문의 도감 설명 없이 전조·애니메이션·목표 선택·결과 로그로 행동을 보여준다.
- 적 이름과 짧은 한 줄 설명은 전투 기능을 우선한다.
- 벨루는 종족 역사보다 현재 관측된 행동·위험·대응 근거를 설명한다.
- 설정을 모르는 사용자가 전투 판단에서 손해를 보지 않아야 한다.
- 세계관 비밀을 알아야만 적의 약점을 이해하는 구조를 금지한다.

## 7. 적대적 검토

### 해결한 위험

- 세계관이 게임보다 커지는 문제: 사용자 노출을 최소화하고 내부 제작 규칙으로 제한.
- 모든 적을 단일 제국 병사로 만드는 문제: 다양한 이계 생물의 통칭으로 확정.
- 비의지적 베일과 조직적 공세의 충돌: 생태적 집결·우두머리 신호·균열 반응으로 분리.
- 보스가 단순 체력 덩어리가 되는 문제: 균열 고정·확장 기능을 필수화.

### 남은 게임 설계 과제

- 각 Act의 적 역할 조합과 신규 도입 순서.
- 일반 적·위험 적·경계파쇄자 정확 명단.
- 교란형이 플레이어 통제감을 훼손하지 않는 한계.
- 경계파쇄자별 전조·규칙·대응·보상.
- 동일 역할 적 사이의 시각·행동 차별화.
