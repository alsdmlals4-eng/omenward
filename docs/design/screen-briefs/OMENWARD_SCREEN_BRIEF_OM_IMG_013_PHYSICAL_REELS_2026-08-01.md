# OM-IMG-013 — 세 물리 릴 설계 화면 브리프

- Decision ID: `OMW-DEC-20260801-VISUAL-SCREEN-BOARD-V2`
- 화면 ID: `OM-IMG-013`
- 상태: `TEXT_BRIEF_CURRENT / IMAGE_NOT_GENERATED`
- 역할: `PHYSICAL_REEL_ENGINEERING / SPIN_SESSION`
- 기초 화면 우선순위: `FOUNDATION_1`

## 1. 플레이어 질문

> 현재 세 릴은 어떤 TokenInstance로 구성됐고, 이동권을 어디에 써야 가능한 결과를 바꿀 수 있으며, 지금 확정하면 무엇을 얻게 되는가?

## 2. 핵심 구도

- 화면 중앙: 왼쪽·중앙·오른쪽 세 물리 릴.
- 세 릴의 노출 구간이 정렬돼 3×3 보드를 만든다.
- 각 릴 위·아래에는 숨은 토큰이 이어지는 원형 구조를 암시한다.
- 좌측: TokenSource 건물·출처 목록.
- 우측: 현재 SpinSession, 이동권, 결과 preview, 확정 영역.
- 하단: 세로 이동·가로 이동·회전·확정 조작.

## 3. 물리 릴 표현

각 릴은 독립된 실제 `TokenInstance` 배열이다.

```text
왼쪽 릴  [숨김] [노출1] [노출2] [노출3] [숨김]
중앙 릴  [숨김] [노출1] [노출2] [노출3] [숨김]
오른쪽 릴[숨김] [노출1] [노출2] [노출3] [숨김]
```

- 원형 테두리·회전 방향·cursor 표식으로 wrap을 표현한다.
- 독립 원판 세 개를 옆에 둔 슬롯머신처럼 만들지 않는다.
- 각 노출 칸은 토큰 심벌·출처 표식·선택 상태를 함께 가진다.
- X는 빈 슬롯·미완성 구조로 읽히며 보상 심벌처럼 화려하게 표현하지 않는다.

## 4. TokenSource 인과

- 금고·병영 출처만 릴 토큰 공급자로 표시한다.
- 한 TokenSource가 세 릴에 하나씩 연결됨을 얇은 출처 선 또는 동일 source badge로 표현한다.
- 파괴·BLOCKED source는 출처 토큰 비활성/제거 상태로 표시한다.
- 토큰의 현재 위치가 바뀌어도 source 추적 표식은 유지한다.
- 건물 하나와 릴 하나가 1:1 대응하는 표현은 금지한다.

## 5. 이동 조작

### 세로 이동

- 선택 릴의 cursor만 위·아래로 한 칸 wrap 이동.
- 다른 릴과 배열 순서는 변경되지 않음.
- 각 릴 양옆에 독립 이동 버튼 또는 명확한 키 포커스.

### 가로 이동

- 선택한 노출 행의 세 TokenInstance를 좌/우 순환 교환.
- 토큰 심벌·source·reward payload가 함께 이동함을 한 덩어리 animation/preview로 표현.
- 실행 후 다음 회전에도 유지됨을 `영구 이동` 또는 잠금 표식으로 알림.

### 비가역성

```text
preview: 취소 가능
실행: 이동권 즉시 소비
실행 후: undo/reset 없음
```

## 6. 회전·Snapshot·확정

- `회전`은 live 릴을 정지시켜 3×3 결과를 만든다.
- 정지 뒤 `SpinSnapshot` 상태를 별도 프레임·잠금·타임스탬프 아이콘으로 표시한다.
- 이동 preview와 snapshot 결과를 혼동하지 않는다.
- `확정`은 보상을 한 번만 생성한다.
- PendingReward 또는 공간 부족 상태에서는 새 회전을 비활성화하고 이유를 표시한다.

## 7. 정보 위계

```text
1. 현재 3×3 노출 결과와 중앙 판정선
2. 현재 선택한 이동·예상 변화
3. 남은 이동권·회전 가능 여부
4. TokenSource 출처와 장기 릴 구조
5. 분석용 후보 결과
```

## 8. 허용 문구 예시

```text
세로 이동
가로 이동
영구 이동 — 실행 후 되돌릴 수 없음
회전
결과 확정
보상 처리 필요
출처: [건물]
```

비용·수량은 `[ ]` 또는 기호 placeholder를 사용한다.

## 9. 접근성

- 토큰 종류는 색+실루엣+문자/아이콘으로 구분.
- source 연결은 색상만 쓰지 않고 badge·선 패턴을 사용.
- 중앙 판정선은 굵기·프레임·라벨로 명확히 표시.
- preview와 live 상태는 점선/실선·투명도·잠금 아이콘을 병행.
- 키보드 포커스가 어느 릴·행·조작에 있는지 항상 보임.

## 10. 금지

- 세 개의 독립 원판이 각자 결과를 뽑는 표현.
- 3×3 칸을 물리 릴과 무관한 카드 격자로만 표현.
- 모든 토큰의 확률 숫자를 기본 화면에 상시 노출.
- TokenSource 출처가 없는 임의 병종 토큰.
- 이동 뒤 전체 초기화 버튼.
- 이동권 소비 전후가 구분되지 않는 UI.
- 좋은 결과만 과도하게 금빛으로 강조하는 도박 연출.

## 11. 검수

- 세 물리 배열과 3×3 노출 보드가 동시에 이해되는가.
- 세로 이동과 가로 이동의 대상·결과가 다르게 읽히는가.
- 가로 이동이 TokenInstance 전체를 옮긴다는 점이 보이는가.
- TokenSource가 세 릴에 공급한다는 인과가 읽히는가.
- snapshot과 최종 확정이 분리되는가.
- 일반 슬롯머신·가챠 화면으로 보이지 않는가.

```text
FOUNDATION_SCREEN: YES
GENERATE_FIRST: YES
IMAGE_GENERATION: BLOCKED_PENDING_VISUAL_REFERENCE_GATE
RUNTIME_VALIDATION: NOT_RUN
```
