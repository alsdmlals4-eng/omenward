# OM-IMG-016 — Stage 15 경계파쇄자 화면 브리프

- Decision ID: `OMW-DEC-20260801-VISUAL-SCREEN-BOARD-V2`
- 화면 ID: `OM-IMG-016`
- 상태: `TEXT_BRIEF_CURRENT / IMAGE_NOT_GENERATED`
- 역할: `DANGER_STAGE / BOUNDARY_BREAKER_BOSS`
- 선행 화면: `OM-IMG-015 STANDARD_BATTLE`

## 1. 플레이어 질문

> 경계파쇄자가 어느 라인의 어떤 건물을 언제 파괴하려 하며, 동시에 유지해야 할 두 번째 위협은 무엇인가?

## 2. 기본 원칙

- 일반 전투 화면의 전장·카메라·HUD를 그대로 사용한다.
- 보스 전용 화면이 별도 장르처럼 보이지 않는다.
- 새 토폴로지·새 노드 종류·새 전투 조작을 발명하지 않는다.
- 보스 위협과 보조 공세, 최대 두 축만 전면에 노출한다.

## 3. 경계파쇄자 표현

- 선택된 한 라인에 거대한 공성 실루엣으로 등장한다.
- 일반 유닛보다 크지만 다른 두 라인을 가리지 않는다.
- 비대칭 갑각·균열·가시·공허 구멍의 적 언어를 사용한다.
- 치명적 행동 대상 건물과 이동/돌진 경로를 명확히 연결한다.
- 내부 발광은 약점·충전·Phase 정보를 전달하는 범위에서 제한한다.

## 4. 공개 전조

필수:

- 현재 목표 라인.
- 목표 건물 또는 목표 구역.
- 행동 준비·충전·재사용 대기 상태.
- 충돌 경로와 위험 범위.
- Phase 또는 contact point 상태가 승인 계약에 존재하는 범위.

표현:

- 바닥 경로·목표 프레임·카운트다운·방향 아이콘을 병행.
- 붉은 색만으로 위험을 알리지 않는다.
- 숨겨진 즉사나 화면 밖 돌진을 만들지 않는다.

## 5. 두 위협 축

```text
축 A: 경계파쇄자와 목표 건물
축 B: 보조 공세 또는 다른 라인의 붕괴 위험
```

- 축 A는 화면의 주 위험이다.
- 축 B는 compact threat strip 또는 해당 라인의 강한 전조로 표시한다.
- 세 번째·네 번째 위협을 같은 강도로 병렬 노출하지 않는다.

## 6. HUD 변화

일반 전투 HUD에 다음만 추가한다.

- 보스명 `경계파쇄자`.
- 현재 Phase placeholder.
- 목표 건물.
- 치명적 행동 준비 상태.
- 다음 행동까지 시간 또는 진행 표식.

정확한 HP·피해·간격·Phase 수치는 미확정이다.

## 7. 벨루

- 최초 목표 지정·Phase 변화·본진 직결 위험을 짧게 경고한다.
- 보스 대처 정답을 자동 선택하지 않는다.
- 대사는 전조를 중복 설명하지 않고 플레이어가 놓칠 수 있는 의미만 보완한다.

## 8. 금지

- 일반 전장을 지우고 보스 단독 컷신으로 교체.
- 다른 두 라인의 상태 은폐.
- 거대한 보스 HP 바만 강조한 액션 RPG 구도.
- 확정되지 않은 약점 부위·스킬·Phase 발명.
- 건물과 무관한 임의 즉사 패턴.
- 전조 없이 시설이 파괴되는 연출.
- 기본 전투보다 더 복잡한 UI layer 추가.

## 9. 검수

- OM-IMG-015와 같은 게임·같은 전장으로 보이는가.
- 보스 목표 건물과 경로가 2초 안에 읽히는가.
- 다른 두 라인의 상태가 유지되는가.
- 보스 위협과 보조 위협이 두 축으로 정리되는가.
- exact value를 발명하지 않았는가.
- 전조가 색 외 형태·방향·텍스트로 전달되는가.
