# OM-IMG-012 — Stage 준비·공세·건설 화면 브리프

- Decision ID: `OMW-DEC-20260801-VISUAL-SCREEN-BOARD-V2`
- 화면 ID: `OM-IMG-012`
- 상태: `TEXT_BRIEF_CURRENT / IMAGE_NOT_GENERATED`
- 역할: `STAGE_PREPARATION / ASSAULT_FORECAST / CONSTRUCTION`

## 1. 플레이어 질문

> 다음 공세는 어느 라인에 언제 무엇이 오며, 제한된 골드와 노드로 어디에 무엇을 건설할 것인가?

## 2. 핵심 구도

- 전장 전체가 화면 중앙의 주 정보면이다.
- 아군 본진부터 적 본진까지 상·중·하 세 라인을 동시에 표시한다.
- 좌측 또는 하단: 5개 건물 가족 선택 패널.
- 상단: Act·Stage·골드·식량·무료 회전·공세 시작 조건.
- 우측: 공개 공세 요약과 현재 선택 노드 상세.
- 위험 Stage에서는 주력 라인·보조 라인·구간별 출격·치명적 행동을 준비 단계에서 공개한다.

## 3. 전장 불변 조건

- 아군 본진 6노드, 적 본진 6노드.
- 중간 거점 6곳, 각 3노드.
- 중앙 접전지 3곳, 노드 0개.
- 전체 30노드가 대칭 관계로 해석 가능해야 한다.
- 현재 소유·건설 가능·적 소유·접전지를 색만이 아니라 테두리·아이콘·패턴으로 구분한다.
- 접전지에는 빈 노드 자리나 건설 버튼을 그리지 않는다.

## 4. 건물 패널

```text
금고
농장
타워
병영
지휘소
```

각 항목은 다음만 표시한다.

- 역할 아이콘.
- 건설 가능 여부.
- 비용·시간 placeholder.
- TokenSource 여부.
- 현재 선택 노드와의 호환성.

정확한 비용·시간·HP·환급률은 미정이다.

## 5. 공세 정보 위계

```text
1. 즉시 위험: 주력 라인·치명적 행동
2. 현재 선택: 건설 노드와 건물
3. 비교 정보: 보조 공세·기존 건물·자원 영향
4. 분석 정보: 다음 Stage·미션·장기 효과
```

## 6. 상호작용

- 노드 hover/focus → 소유권·점유 건물·건설 가능 목록.
- 건물 선택 → preview만 표시.
- 확정 전 취소 가능.
- target invalid·골드 부족·건설 중 충돌은 원인을 텍스트로 표시.
- 중앙 접전지 클릭 시 `건설 불가 지역`을 명확히 표시하고 자원을 소비하지 않는다.

## 7. 벨루

- 놓치기 쉬운 공개 위험이나 건물→TokenSource 영향을 짧게 설명한다.
- 특정 건물을 정답으로 지목하지 않는다.
- 반복 안내는 접을 수 있고 입력을 차단하지 않는다.

## 8. 금지

- 미니맵으로 실제 전장을 대체.
- 각 라인을 별도 카드로만 표현해 공간 관계를 제거.
- 접전지에 건설 노드 추가.
- 병영·금고 외 건물을 TokenSource처럼 표현.
- 확정되지 않은 비용·수입·HP 숫자.
- 장비 인벤토리나 영웅 편성 패널.

## 9. 검수

- 세 라인과 본진·중간 거점·접전지의 순서가 한눈에 읽히는가.
- 6/3/0 구조가 시각적으로 모순되지 않는가.
- 공세 정보가 건설 UI보다 먼저 위험으로 읽히는가.
- 5개 건물 가족과 TokenSource 여부가 구분되는가.
- 720p에서도 노드 상태와 주력 라인을 식별할 수 있는가.
