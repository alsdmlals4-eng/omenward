# OM-IMG-015 — 일반 세 라인 전투 화면 브리프

- Decision ID: `OMW-DEC-20260801-VISUAL-SCREEN-BOARD-V2`
- 화면 ID: `OM-IMG-015`
- 상태: `TEXT_BRIEF_CURRENT / IMAGE_NOT_GENERATED`
- 역할: `CORE_BATTLE / THREE_LANE_AUTO_COMBAT`
- 기초 화면 우선순위: `FOUNDATION_2`

## 1. 플레이어 질문

> 지금 무너질 가능성이 가장 높은 곳은 어디이며, 세 라인의 전선·거점·건물·다음 공세는 어떤 상태인가?

## 2. 핵심 구도

- 아군 본진은 왼쪽, 적 본진은 오른쪽.
- 상·중·하 세 라인이 화면 안에 동시에 보인다.
- 각 라인은 `아군 본진 → 아군 중간 거점 → 중앙 접전지 → 적 중간 거점 → 적 본진` 공간 관계를 공유한다.
- 카메라는 전장 전체를 읽는 고정 또는 제한적 전술 시점이다.
- 전투를 세 개의 별도 창·카드·분할 카메라로 나누지 않는다.

## 3. 전장 요소

필수:

- 양 진영 본진과 본진 HP.
- 라인별 중간 거점 두 곳.
- 라인별 중앙 접전지 한 곳.
- 거점 소유권·점령 진행·contested 상태.
- 배치 병력의 라인 고정.
- 타워·지휘소 등 전선 건물의 읽을 수 있는 실루엣.
- 접전지에는 건설 노드나 건물이 없음.

건설 노드 30개 전체를 전투 중 항상 밝게 표시하지 않는다. 기본 상태에서는 건물과 점유 노드만 읽히고, 전술 overlay에서 노드가 드러난다.

## 4. HUD

### 상단

- 현재 Act·Stage.
- 전투 진행 또는 다음 주요 사건까지 남은 시간.
- 골드·식량·무료 회전은 작은 상태 표시.
- 일시정지·속도·설정.

### 라인 HUD

각 라인에 다음 정보를 compact하게 붙인다.

- 현재 위험 등급.
- 아군·적 병력 밀도.
- 점령 상태.
- 현재 주력 공세.
- 다음 공세 전조.

### 현재/다음 위협

- 화면 우측 또는 상단 우측에 주력 위협 한 건과 다음 위협 한 건.
- 라인·출격 시각·치명적 행동을 짧게 표시.
- 모든 적 정보를 긴 리스트로 노출하지 않는다.

## 5. 전투 판독

- 아군과 적의 실루엣·진행 방향·공격 효과를 색 외 형태로 구분.
- 라인 경계는 지형·건축·바닥 패턴으로 읽힌다.
- 점령 진행은 원형 또는 선형 게이지로 표시하되 유닛 수에 따른 속도 보너스를 암시하지 않는다.
- contested는 정지 아이콘·양측 표식·진행 정지 animation으로 표현한다.
- 유닛 수·Tier·병종에 무관한 고정시간 점령을 전제로 한다.

## 6. 플레이어 개입

전투는 자동 진행이 핵심이다. 화면은 다음을 지원한다.

- 라인·유닛·건물 선택과 상세 확인.
- 전술 overlay 표시.
- 속도 조절·일시정지.
- 현재/다음 공세 확인.

확정되지 않은 실시간 능력 버튼·영웅 스킬 hotbar·수동 이동 명령을 추가하지 않는다.

## 7. 벨루

- 본진 붕괴 위험·중요 건물 파괴·위험 행동 전조를 짧게 알린다.
- 전투 화면 중앙을 가리지 않는다.
- 반복 경고는 cooldown·중복 억제를 전제로 한다.

## 8. 정보 위계

```text
1. 즉시 붕괴 위험과 치명적 전조
2. 세 라인의 현재 전선·점령 상태
3. 다음 공세
4. 건물·유닛 상세
5. 장기 경제·분석 정보
```

## 9. 금지

- 한 라인만 크게 보여 주고 다른 라인을 미니맵으로 축소.
- 각 라인을 별도 전투 카드로 표현.
- 영웅 초상화·스킬 hotbar 중심 HUD.
- 접전지 건설 노드.
- `capture_power` 수치와 다수 병력 속도 보너스 표현.
- 과도한 VFX로 전선과 점령 상태를 가림.
- generic MOBA 또는 타워디펜스 HUD 복제.

## 10. 검수

- 하나의 전장과 세 라인이 동시에 읽히는가.
- 본진·중간 거점·접전지의 순서가 일관적인가.
- 가장 위험한 라인을 2초 안에 찾을 수 있는가.
- 현재/다음 공세가 전장과 연결되는가.
- 접전지 0노드가 지켜지는가.
- 일반 RPG 전투·MOBA·단일 라인 타워디펜스로 오인되지 않는가.
