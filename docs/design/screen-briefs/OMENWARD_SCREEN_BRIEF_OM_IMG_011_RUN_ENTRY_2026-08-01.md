## 1. 플레이어 질문

> 이 게임은 어떤 판타지와 구조를 가진 게임이며, 지금 이어서 할 런이 있는가?

## 2. 목표 인상

- 어두운 경계 요새와 세 전선의 긴장.
- 원형 릴·종·방패·배너 문양을 배경 구조에 통합.
- 영웅 한 명이나 파티가 아니라 **지휘와 방어 체계**가 주인공인 화면.
- 메뉴를 읽기 전에 오멘워드의 세 라인·징조·방어 판타지가 느껴져야 한다.

## 3. 권장 구도

- 전체 16:9 배경: 멀리 이어지는 세 전선과 아군 요새.
- 좌측 또는 중앙 좌측: `OMENWARD` 로고와 세로 메뉴.
- 우측 하단: 작은 이어하기 상태 카드.
- 벨루는 화면 모서리에 작은 비모달 실루엣·반응으로만 배치.
- 세 물리 릴은 실제 조작 UI가 아니라 문양·기계 장치의 배경 모티프로만 암시한다.

## 4. 필수 요소

- 제품명 `OMENWARD`.
- `이어하기`, `새 런`, `설정`, `종료`.
- 이어하기가 있을 때: 현재 Act·Stage·마지막 checkpoint 정도의 짧은 요약.
- 이어하기가 없을 때: 해당 버튼 비활성 또는 숨김.
- PC 키보드·마우스 포커스 상태.

## 5. 정보 위계

```text
1. 제품명과 세계 분위기
2. 이어하기 또는 새 런
3. 현재 런 요약
4. 설정·종료
```

## 6. 허용 문구 예시

```text
이어하기
새 런
설정
종료
Act [ ] · Stage [ ]
마지막 준비 checkpoint
```

정확한 Stage 숫자는 샘플 이미지에서 임의로 고정하지 않는다.

## 7. 벨루

- 첫 실행에서 한 문장 환영 안내 가능.
- 이어하기 선택을 강요하거나 특정 메뉴를 자동 선택하지 않는다.
- 최종 외형·픽셀 크기는 사용자 제공 시각자료 이관 뒤 확정한다.

## 8. 금지

- 전면 영웅 초상화·파티 진형.
- 능력치·장비·레벨 카드.
- 모바일 가챠 로비.
- 여러 재화 바와 상점 버튼.
- 확정되지 않은 영구재화명.
- 배경을 가리는 대형 기술 설명.

## 9. 검수

- 한눈에 PC 전술 전략 게임으로 보이는가.
- 세 전선의 존재가 과장 없이 암시되는가.
- 메뉴가 배경보다 읽히지만 화면을 지배하지 않는가.
- 일반 RPG·로그라이크 캐릭터 선택 화면으로 오인되지 않는가.
- 벨루가 보조자로만 보이는가.
