# 승인된 벤치마킹 반영 사항

- 승인일: 2026-07-14
- 상태: 게임 기획 확정 사항
- 근거 제안서: `docs/benchmarks/0001-core-game-benchmark-proposal.md`

이 문서는 벤치마킹 제안서에서 사용자가 승인한 결론을 기록한다. 이후 Codex 제안서와 구현은 이 결정을 임의로 변경하지 않는다.

## 1. 수직 슬라이스 필수 UX

다음 6개를 첫 플레이 가능한 수직 슬라이스의 필수 UX로 채택한다.

1. **건설 전 룰렛 확률 미리보기**
   - 건설 또는 철거로 토큰 풀이 어떻게 변하는지 실행 전에 보여준다.
   - 예: `검사 25% → 40%`, `X 25% → 0%`.
2. **룰렛 토큰 장부**
   - 토큰 종류별 개수, 각 릴의 구성, 등장 확률과 X 토큰 수를 확인할 수 있다.
3. **적 웨이브 3단계 전조**
   - T-30: 라인, 병종, 정확한 수량.
   - T-15: 집결 위치와 이동 경로.
   - T-5: 카운트다운과 위험 라인 강조.
4. **상성·사거리·타기팅 오버레이**
   - 선택한 유닛과 포탑의 공격 범위, 우선 목표와 주요 상성을 확인할 수 있다.
5. **웨이브 종료 후 라인별 원인 보고**
   - 병력 손실, 상성 열세, 증원 지연, 시설 파괴 등 주요 원인을 짧게 보여준다.
6. **건설 선택 비교 UI**
   - 같은 노드에 지을 수 있는 건물의 즉시 효과, 장기 효과, 토큰 변화와 위험을 비교한다.

## 2. 건물 티어

- MVP는 **고정형 3티어 성장**을 사용한다.
- Tier 1은 기본 기능, Tier 2는 효율 개선, Tier 3은 고정된 핵심 강화로 구성한다.
- 선택형 두 갈래 전문화는 수직 슬라이스와 기본 밸런스가 검증된 뒤 실험한다.
- 건물 티어는 룰렛 토큰 수를 늘리지 않는다.

## 3. 적 웨이브 정보

- 기본·일반 난이도에서는 공격 라인, 병종과 **정확한 수량**을 공개한다.
- 정보 은폐나 수량 범위 표시는 고난도 변형으로만 검토한다.
- 치명적인 특수 공격과 후방 침투는 반드시 사전 경고한다.

## 4. 럭키 찬스

- 럭키 찬스는 **기본 발생 확률 + 실패 누적 보정** 구조를 채택한다.
- 연속 실패할수록 다음 회전의 발생 확률이 올라가며, 성공하면 누적 보정이 초기화된다.
- 정확한 기본 확률, 증가량과 확정 상한은 밸런스 데이터로 결정한다.
- 목표는 운을 제거하는 것이 아니라 장기간 아무 조작 기회도 얻지 못하는 좌절을 방지하는 것이다.

## 5. 전방 생산시설 보상

- 전방 생산시설에 별도의 생산량·생산속도 보너스를 주지 않는다.
- 전방 생산시설의 기본 보상은 **짧은 전선 합류 거리**다.
- 위험한 위치, 시설 파괴와 토큰 손실을 감수하는 대신 빠르게 전투에 개입할 수 있다.
- 추후 보상이 부족하다고 확인될 때만 작은 전방 특성 보너스를 별도 제안서로 검토한다.

## 6. 적용 경계

다음 요소는 초기 범위에서 제외한다.

- 무작위 개별 유닛 능력치와 각인
- 수십 개 병종과 복합 친화도
- 대규모 영구 성장 트리
- 직접 조작하는 영웅 액션 전투
- 복잡한 흡수·진화 계보
- PvP 랭크와 시즌 시스템

핵심 차별점은 다음 연결을 유지하는 것이다.

```text
건물 구성
→ 룰렛 토큰과 확률 변화
→ 예고된 적 웨이브에 맞는 유닛 획득
→ 3라인 배치와 접전지·시설 공방
→ 결과 원인 확인과 다음 건설 결정
```
