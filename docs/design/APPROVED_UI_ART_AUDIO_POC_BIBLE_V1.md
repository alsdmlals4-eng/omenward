# 승인된 UI·아트·오디오 PoC 바이블 V1

- 상태: **가독성·형태 언어·HUD·오디오 구조 승인 / 최종 시안·팔레트·프레임 수는 PoC 가설**
- 작성일: 2026-07-16
- 최신 갱신일: 2026-07-16
- 적용 범위: 1920×1080 HUD, 전장, 아군·적군 10병종, 등급, 건물, 벨루, VFX, 오디오

## 1. 화면 기준

- 기준 출력: 1920×1080, 16:9.
- 내부 픽셀 기준 후보: 960×540을 2배 정수 확대.
- 전략 기본 줌에서 양측 본진과 세 라인 전체를 확인한다.
- 전장이 한눈에 보이므로 별도 미니맵을 사용하지 않는다.
- 일반 유닛 화면 높이 34~40px, 특수 유닛 42~56px, 거인 72~96px.
- 색상만으로 병종·등급·진영을 구분하지 않는다.

## 2. HUD 배치

```text
상단 좌측: 금화·식량·수입 타이머
상단 중앙: 웨이브 시계·베일의 징조·보스 체력
상단 우측: 일시정지·속도·설정
좌측 하단: 3×3 룰렛·이동권·럭키 찬스
하단 중앙: 건설·용병·대기 결과·전술 명령
우측 하단: 벨루·최대 두 줄 대사
```

- 전장 가시영역은 중앙 세로 60% 이상을 유지한다.
- 룰렛 회전 중에도 웨이브 경고와 본진 위험을 가리지 않는다.
- 전설 연출은 1.2초 이내이며 자동으로 전투 화면에 복귀한다.
- 미니맵 대신 실제 전장 위의 성문·중간거점·중앙 접전지 상태 표시를 사용한다.

## 3. 정보 우선순위

### 항상 표시

- 현재 금화·식량.
- 다음 공세 충돌까지 시간.
- 각 라인 중앙 접전지 점령 상태.
- 각 라인 중간거점의 소유권과 점령 진행.
- 라인별 성문 상태와 본진 HP.
- 선택 건물 생산·업그레이드 진행.

### 조건부 표시

- T-30 징조: 라인·핵심 태그.
- T-15: 정확한 병종·수량·카운터 아이콘.
- T-5: 주력 라인 강조·벨루 짧은 경고.
- 식량 부족: 완성 대기 유닛과 필요한 식량.
- 특수병단: 현재 할인·다음 할인 시간·원가/실제 비용.
- 암살자 선택: 해당 라인의 안개 속 우회로와 예상 도착 구역.

## 4. 전장 정보와 우회로 UX

### 4.1 실제 전장 표시

- 성문 내구도와 공격받는 상태는 성문 위에 직접 표시한다.
- 중간거점은 소유 진영, 점령 게이지, 전방 2·후방 1 노드 상태를 실제 위치에서 표시한다.
- 중앙 접전지는 점령 테두리와 교착 상태를 실제 바닥에 표시한다.
- 화면 구석의 축소 지도에 같은 정보를 중복하지 않는다.

### 4.2 암살자 우회로

- 평상시에는 우회로의 선·출입구·도착점을 모두 안개와 연무로 가린다.
- 암살자를 선택하면 배치 가능한 라인의 우회로 윤곽만 임시로 드러낸다.
- 라인을 지정하면 출발점, 이동 방향, 예상 도착 구역을 표시한다.
- 배치 확정 뒤에는 해당 암살자의 침투에 필요한 동안만 경로를 보여준다.
- 침투 종료 또는 선택 해제 뒤에는 다시 안개로 가린다.
- 일반 유닛 선택 중에는 우회로가 보이지 않는다.
- 우회로 표시는 성문·거점·접전지의 핵심 정보를 가리지 않는다.

## 5. 룰렛 UX

- 각 심벌은 실루엣 아이콘 + 작은 계열 문양을 함께 사용한다.
- 현재 판정줄은 얇은 금속 프레임으로 표시한다.
- 이동 전 예상 완성 줄을 실시간 미리보기한다.
- 등급 결과는 프레임 형태와 음향 길이로 구분한다.
- 결과 보관함 3칸은 룰렛 오른쪽에 세로 배치한다.
- 금화 부족·이동권 부족은 버튼 비활성화와 정확한 부족량을 표시한다.

## 6. 진영 형태 언어

### 루메른·실베른

- 수직선·아치·방패·종·천 배너.
- 정돈된 판금, 청백빛 경계 문양, 따뜻한 금속 포인트.
- 무기와 장비가 병종 역할을 크게 드러낸다.

### 베일런·베일종

- 비대칭 균열·갑각·가시·공허 구멍.
- 내부에서 새는 빛과 검은 외곽.
- 인간 장비의 직접 복제보다 기능을 생물 구조로 변환한다.

### 금지

- 아군과 적군이 색상 변경만으로 구분되는 디자인.
- 작은 전략 줌에서 무기 실루엣이 몸에 묻히는 디자인.
- 상시 발광이 등급·스킬 전조를 가리는 디자인.

## 7. 아군 10병종 실루엣

| 병종 | 식별 요소 |
|---|---|
| 방패병 | 몸 높이의 큰 직사각·연꼴 방패, 낮은 자세 |
| 대검전사 | 몸보다 긴 넓은 검, 넓은 어깨와 회전 준비 |
| 암살자 | 낮은 전방 자세, 쌍단검·짧은 망토 |
| 창병 | 가로 화면에서 가장 긴 수평 무기 |
| 궁병 | 활의 큰 곡선, 뒤쪽 화살통 |
| 기병 | 탈것 포함 긴 전후 실루엣, 높은 창 |
| 사제 | 지팡이·성물·천 장식, 전열 뒤 직립 자세 |
| 마법사 | 큰 소매·원형 촉매·떠 있는 룬 조각 |
| 비행병 | 명확한 날개·상하 운동·지상 그림자 |
| 거인 | 일반의 약 2배 키, 큰 팔·무기, 느린 키포즈 |

## 8. 적군 10병종 실루엣

- 아군 대응 역할을 읽을 수 있도록 무기 길이·몸 크기·자세는 대응한다.
- 방패는 갑각판, 창은 가시 돌출, 궁은 침 발사기관처럼 변환한다.
- 지원형은 주변 개체와 연결되는 표식기관을 가진다.
- 비행형은 날개와 지상 그림자가 항상 보인다.
- 거인은 화면 가장자리에서도 대형임을 확인할 수 있는 상체 흔들림을 사용한다.

## 9. 등급 시각 언어

| 등급 | 월드 표현 | UI 표현 |
|---|---|---|
| 일반 | 기본 실루엣 | 무테 또는 얇은 프레임 |
| 엘리트 | 어깨·무기 부속 1개, 작은 문양 | 이중 모서리 프레임 |
| 영웅 | 실루엣 부속 2개, 짧은 비전투 잔광 | 초상 배지·스킬 2칸 |
| 전설 | 고유 부속·짧은 출격 연출·바닥 문양 | 움직이는 프레임·스킬 3칸 |
| 적 신화 | 페이즈별 실루엣 변화·균열 코어 | 전용 보스 프레임 |

- 등급을 단순 크기 증가로만 표현하지 않는다.
- 전설도 일반 거인의 크기 체계를 침범하지 않는다.

## 10. 건물 아트 계약

- 모든 건물은 `건설 중 / 활성 / 업그레이드 중 / 파손 / 폐허` 상태를 가진다.
- 기본 병영 T2는 입구 장비와 지붕 부속으로 6전문화를 구분한다.
- 특수병단 T1은 비어 있는 4개 준비 단상을 보여주고, 준비도에 따라 불빛과 깃발이 채워진다.
- T2 사제단·마도단·비행단·거인단은 지붕 실루엣과 출입구 크기가 확연히 다르다.
- 시장은 수입 타이머, 농장은 식량 수용량, 포탑은 사거리·대공 여부를 선택 시 시각화한다.
- 중간거점 건설 노드는 전방 2·후방 1 배치를 유지하며 평상시 강한 원형 UI를 상시 노출하지 않는다.

## 11. VFX 전조 계약

- 위험 전조는 실제 판정보다 같거나 크게 표시하지 않고 정확히 일치시킨다.
- 일반 스킬 전조 0.25~0.6초, 영웅 0.6~1.0초, 전설·보스 1.0~1.5초.
- 적 위험 범위는 외곽선, 아군 강화 범위는 내부 문양으로 구분한다.
- 비행 고도는 그림자와 얇은 수직 연결선으로 표시한다.
- 지속 피해 지역은 바닥 가독성을 위해 최대 불투명도 45%를 목표로 한다.
- 우회로 안개 해제 연출은 전투 위험 범위와 혼동되지 않는 흐린 연무와 얇은 경로선으로 표현한다.

## 12. 벨루

- 기본 청백색 요정형 시안을 유지한다.
- 오른쪽 하단 48~64px 도크.
- 상태 반응은 0.5~2초 뒤 기본형으로 복귀한다.
- 표정 초안 8종: 기본, 경고, 기쁨, 당황, 집중, 슬픔, 분노, 신비.
- 공식 영문 철자는 작업상 `Bellu`를 사용하고 최종 로컬라이징에서 재검증한다.

## 13. 오디오

### 음악

- 기본 전투: 낮은 현악·타악·종의 반복 모티프.
- T-30부터 층을 추가하고 T-5에 짧은 경계종.
- 5·10·15웨이브마다 리듬과 화성 밀도 증가.
- 15 보스는 기존 테마를 왜곡해 연속성을 유지한다.

### 효과음

- 룰렛 일반/엘리트/영웅/전설은 1/2/3/4단계 음정 상승.
- 벨루는 맑은 두 음 종 모티프.
- 방패·대검·창·궁·마법·비행·거인은 재질과 저역 비중으로 구분.
- 거인 공격은 준비음과 충돌음을 분리해 회피 가능성을 높인다.
- 암살자 우회로 선택과 침투 완료는 짧고 낮은 음향으로 구분하되 상시 반복하지 않는다.

### 음성

- 벨루는 맑고 중성적인 짧은 발화.
- 반복 대사는 동일 문장을 60초 안에 재생하지 않는다.
- 숫자 정보는 음성보다 HUD를 우선한다.

## 14. 아트 제작 예산

### 일반 병종

- 대기 4~6프레임.
- 이동 6~8프레임.
- 기본 공격 6~10프레임.
- 피격 2~3프레임.
- 사망 6~10프레임.

### 특수·보스

- 핵심 스킬당 8~16프레임.
- 보스 패턴당 전조·공격·회복 키포즈를 분리한다.
- 방향은 좌/우 미러링을 기본으로 하되 비대칭 무기·문양이 깨지지 않게 한다.

## 15. 검증 기준

- 색을 제거한 흑백 실루엣 테스트에서 10병종 중 8종 이상을 구분한다.
- 0.85배 전략 줌에서 비행·대형·지원·대공 위협을 1초 안에 찾는다.
- 미니맵 없이 세 라인의 성문·중간거점·중앙 접전지 상태를 3초 안에 파악한다.
- 암살자를 선택하지 않았을 때 우회로가 보이지 않는다.
- 암살자 선택·배치 중에는 출발 라인과 도착 후열을 즉시 이해할 수 있다.
- 웨이브 경고가 룰렛·건설 패널에 가려지지 않는다.
- 상시 VFX가 전투 유닛 실루엣의 20% 이상을 지속적으로 가리지 않는다.
- 스킬 전조와 실제 판정 오차는 4 world units 이하를 목표로 한다.
