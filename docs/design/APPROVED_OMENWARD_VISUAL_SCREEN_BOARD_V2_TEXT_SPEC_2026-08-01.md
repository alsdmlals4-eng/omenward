## 3. OM-IMG-011 메인·작전 허브

### 3.1 목적

플레이어가 다음 행동을 즉시 구분해야 한다.

1. 현재 작전을 이어갈 것인가.
2. 새 MapRun을 시작할 것인가.
3. 정산된 영구재화로 조직의 장기 준비를 확장할 것인가.

### 3.2 위계

```text
1순위: 이어하기 / 새 작전 / 현재 작전 상태
2순위: 정산 영구재화·현재 Readiness·최근 작전 기록
3순위: 보조 콘텐츠 — 주점 / 병영 / 연구
4순위: 도감 / 기록 / 설정
```

- 런 진입 CTA가 화면의 가장 강한 행동이다.
- 주점·병영·연구는 동일한 2차 시설군으로 배치한다.
- 각 시설은 현재 개방 가능한 노드 수, 새 기록, 활성 선택 상태만 간결하게 표시한다.
- 메인 화면을 상점·가챠·영웅 파티 편성 화면처럼 만들지 않는다.
- 벨루는 현재 위험·다음 작전·새로 열린 시설 정보를 짧게 설명하지만 자동 구매·편성하지 않는다.

### 3.3 주점 화면

- 영웅 이상 전문 인재의 영구 명부와 공개 노드 영입 조건을 표시한다.
- 후보·비용·선행 조건을 구매 전에 공개한다.
- 랜덤 뽑기·확률 상자·유료 재굴림·중복 합성 연출을 사용하지 않는다.
- 영입은 영구, MapRun 출전은 제한이라는 차이를 명확히 표시한다.
- 정확 영웅 수·등급·출전 상한·능력은 pending이다.

### 3.4 허브 병영 화면

- 병사 훈련·병종·전문화·교리 노드를 표시한다.
- `허브 병영 = Profile 훈련`, `전장 병영 = MapRun TokenSource 건물`임을 문맥·아이콘·라벨로 구분한다.
- sidegrade 장단점과 새로 공급 가능한 토큰을 표시한다.
- 무한 레벨·일괄 공격력 상승을 중심 UI로 두지 않는다.

### 3.5 연구 화면

- 베일 법칙·징조·봉쇄 기록, 대체 건물·TokenSource·미션·분석 편의 노드를 표시한다.
- 릴 확률을 숨겨 조작하거나 전체 생산량을 영구 증폭하는 연구를 표시하지 않는다.
- 정보 해금과 전투력 해금의 성격을 아이콘·분류·설명으로 분리한다.

### 3.6 영구 노드 공통 UX

- 노드 비용·선행 조건·해금 결과·잔액을 동시에 확인할 수 있어야 한다.
- 잠금 상태는 자물쇠 색 하나가 아니라 연결선·아이콘·텍스트로 표시한다.
- 구매 전 확인과 구매 뒤 영수증·변경 결과를 제공한다.
- 영구재화와 paid Retry가 같은 소비 잔액을 사용한다는 기회비용을 숨기지 않는다.
- 노드 수·가격·환불·초기화 규칙은 정확값 승인 전 마스킹한다.

## 4. OM-IMG-012 Stage 준비·공세·건설

- 상·중·하 세 라인과 공개 공세 정보가 한 화면에서 읽힌다.
- 진영당 본진 6노드, 중간 거점 6곳×3노드, 중앙 접전지 0노드, 전체 30노드를 유지한다.
- 건설·수리·업그레이드 preview와 실제 확정을 구분한다.
- 오멘워드 현장 지휘관의 활성 작전 권한 범위를 브리핑 문맥에 반영한다.
- 지방 행정·왕실·조직 관계를 기술 보고서처럼 과도하게 노출하지 않는다.

## 5. OM-IMG-013 세 물리 릴 설계

- 왼쪽·중앙·오른쪽 세 원형 TokenInstance 배열을 표현한다.
- 각 릴의 연속 3칸이 3×3 노출 보드를 만든다.
- TokenSource 출처, cursor, 숨은 연속성, preview, live 상태, SpinSnapshot, 최종 확정을 구분한다.
- 가로 이동은 세 릴 사이 TokenInstance 순환 교환이며 이후 회전에도 유지된다.
- 독립 9칸 랜덤 추첨이나 서로 무관한 원판 3개로 표현하지 않는다.

## 6. OM-IMG-014 PendingReward 처리

- 정지 결과와 출처를 보존한다.
- 보관·판매·한 라인 배치의 기회비용을 비교한다.
- 배치 뒤 라인 변경·회수·판매 불가를 확정 전에 명확히 경고한다.
- 영웅 출전·병영 훈련 등 Profile 선택이 결과에 영향을 주었다면 별도 원인 태그로 표시하되 결과를 자동 결정한 것처럼 보이지 않는다.

## 7. OM-IMG-015 일반 세 라인 전투

- 한 전장 안의 상·중·하 세 라인이 동시에 읽힌다.
- 현재 전투, 다음 공개 위협, 본진·거점·건물 상태가 우선이다.
- 캐릭터 능력 핫바나 영웅 한 명 중심 액션 RPG 구도를 금지한다.
- 영웅이 출전해도 세 전선 지휘와 일반 병력 구조를 시각적으로 대체하지 않는다.

## 8. OM-IMG-016 경계파쇄자 위험 전투

- Stage 5·10·15·20의 위험은 사전 징조와 브리핑에서 예고된 법칙이 임계 상태에 도달한 것으로 표현한다.
- 위협 축과 실시간 조작을 과도하게 늘리지 않는다.
- 베일 자체를 하나의 악신 얼굴로 형상화하지 않는다.
- 경계파쇄자·베일종의 정확 목적은 후속 세계관 Decision 전 임의 확정하지 않는다.

## 9. OM-IMG-017 정산·인과 복기

```text
건물·훈련·연구·영웅 선택
→ TokenSource와 릴 구조
→ SpinSnapshot
→ 보관·판매·전선 커밋
→ 전투·영토·피해
→ 정산 영구재화·기록·상흔
```

- 구조·잔여 RNG·출처·커밋·전투 결과를 분리한다.
- Profile 보정과 영웅 기여를 표시하되 실패 원인을 숨기지 않는다.
- 승리한 균열 봉쇄와 남은 피해·상흔을 함께 기록한다.

## 10. OM-IMG-018 패배·제품 유료 Retry

- 기본 선택은 런 종료·정산이다.
- Stage 5 이후 허용되는 paid Retry는 동일 공세의 비상 재투입이며 시간 되감기가 아니다.
- 사용 영구재화, 남은 잔액, 보조 노드 구매 기회비용을 명확히 보여 준다.
- 현실 화폐·프리미엄 결제를 연상시키는 상점 표현을 금지한다.

### 아군·오멘워드

- 수직선·아치·방패·종·천 배너.

- 왕실 인가 조직이지만 왕실 궁정의 호화로움보다 현장 전문성과 기록성을 우선한다.

- 생태적으로 보이지만 하나의 통일된 얼굴·신격·의지를 암시하지 않는다.

## 12. 금지되는 일반 RPG·수집형 표현

- 메인 화면을 채우는 영웅 파티 초상화 행렬.
- 랜덤 뽑기·확률 게이지·중복 합성·유료 재굴림.
- 장비 슬롯·무기/방어구 인벤토리 격자 중심 화면.
