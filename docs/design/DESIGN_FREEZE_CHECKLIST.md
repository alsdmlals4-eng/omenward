# 프리프로덕션 디자인 프리즈 체크리스트

## 목적

Codex가 게임 규칙을 임의로 해석하지 않도록 구현 전에 핵심 계약을 확정한다. 모든 수치를 완벽히 고정하는 것이 목적은 아니다.

- **구현 전에 잠글 것:** 규칙, 상태 전이, 책임, 입력, UI 정보, 실패 처리, 데이터 계약, MVP 경계.
- **데이터로 조정할 것:** 비용, 시간, 확률, 체력, 피해량, 거리, 수입량, 웨이브 수량.
- **프로토타입으로 검증할 것:** 손맛, 속도감, 가독성, 피로도, 실제 재미, 성능 한계.

## 프리즈 단계

- `미논의`: 아직 방향이 없다.
- `제안 필요`: 선택지와 추천안이 필요하다.
- `승인 대기`: 제안서가 준비됐다.
- `확정`: Codex가 구현 계약으로 사용한다.
- `플레이테스트 조정`: 구조는 확정됐지만 수치는 데이터로 조정한다.

- [ ] 룰렛 회전 비용과 연속 회전 비용 구조
- [ ] 금화 토큰 보상 상한과 무한 경제 방지 규칙

- [ ] 럭키 찬스 기본 확률, 실패 누적, 확정 상한과 초기화
- [ ] 행·열 이동 후 최종 보상 판정 시점

- [ ] 기본 포탑은 접전지에 닿지 않는다.

- [ ] 정확한 웨이브 정보와 실제 출격 구성이 일치한다.
- [ ] 대기칸 가득 참과 식량 부족이 데이터 손실 없이 처리된다.
- [ ] 한 라인 몰빵과 세 라인 분산 전략 모두 장단점이 있다.

- [ ] 플레이어가 웨이브 패배 원인을 UI에서 설명할 수 있다.
