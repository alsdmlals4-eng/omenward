# 프리프로덕션 디자인 프리즈 체크리스트

- 갱신일: 2026-07-16
- 현재 상태: **제품·전장·공용 병종·경제·웨이브·아트·연출 구조 승인 / 기술 Plan Mode·수치 검증 남음**
- 최초 인수인계: `docs/HANDOFF_CONTEXT.md`

이 체크리스트는 모든 수치를 완벽히 고정하기 위한 문서가 아니다. Codex가 제품 구조와 데이터 책임을 임의로 해석하지 않도록 **구현 전에 잠글 구조**, **PoC에서 조정할 수치**, **실제 플레이로 검증할 경험**을 구분한다.

## 상태 정의

- `[x] 승인`: 구조·책임·불변 조건 확정.
- `[~] PoC 조정`: 첫 구현값이 있으나 측정 후 조정 가능.
- `[ ] 구현 전 결정`: Issue #1 또는 #32 Plan Mode에서 선택.
- `[>] 장기 확장`: 수직 슬라이스 이후 별도 승인.

- [x] 일시정지 중 건설·룰렛·배치·전술 계획 가능, active combat time 정지.
- [~] 정규 전투 약 15분과 약 3시간 첫 캠페인.
- [ ] 재시작·포기·결과 화면의 정확한 입력 흐름.

책임: GDD, `APPROVED_15_WAVE_STAGE_CLOCK_AND_OVERTIME_V2.md`, 캠페인 문서.
