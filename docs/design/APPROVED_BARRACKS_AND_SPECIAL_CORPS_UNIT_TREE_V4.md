## 2. 기본 병영

```text
Tier 1 기본 병영
- 일반 검사 자동생산
- 전사 토큰 제공

Tier 2 전문화
- 방패병 / 전사 토큰
- 대검전사 / 전사 토큰
- 암살자 / 암살자 토큰
- 창병 / 창병 토큰
- 궁병 / 궁병 토큰
- 기병 / 기병 토큰
```

기본 병영 규칙:

- 자동생산과 룰렛 토큰을 함께 제공한다.
- 한 병영은 Tier 2 전문화 하나만 선택한다.
- 서로 다른 병영은 다른 전문화를 선택할 수 있다.
- 업그레이드 중에는 이전 생산과 토큰을 유지한다.
- 생산 진행률은 보존한다.
- 완료 뒤 첫 완성분부터 새 병종을 자동생산한다.
- 토큰 변경은 다음 룰렛 회전부터 적용한다.
- 자동생산은 항상 일반 등급이다.

사제는 기본 병영 전문화에 포함하지 않는다.

## 3. 특수병단 전체 구조

건물 표시명은 **특수병단**을 사용한다.

```text
Tier 1 특수병단
- 토큰 없음
- 유닛 자동생산 없음
- Tier 2 준비도 축적
- 준비 시간에 따라 Tier 2 업그레이드 비용 감소

Tier 2 전문화
- 사제단 / 사제 토큰 / 일반 사제 장기 자동생산
- 마도단 / 마법사 토큰 / 일반 마법사 장기 자동생산
- 거인단 / 거인 토큰 / 일반 거인 초장기 자동생산
- 비행단 / 비행 토큰 / 일반 비행병 장기 자동생산
```

한 특수병단은 Tier 2 전문화 하나만 선택한다. 여러 특수병단을 지어 서로 다른 특수 계열을 열 수 있다.

## 4. Tier 1 준비 시설과 업그레이드 할인

Tier 1은 전투 유닛이나 토큰을 직접 제공하지 않지만, 건물을 유지하는 동안 Tier 2 전문화 비용을 낮추는 **준비 시설**이다.

### 준비도 축적

```text
preparation_progress_seconds += active_combat_time
```

- 완공 순간 준비도 0초에서 시작한다.
- 활성 전투 시간만 축적한다.
- 일시정지 중에는 준비도가 증가하지 않는다.
- 건설 중에는 준비도를 축적하지 않는다.
- 업그레이드 시작 순간 준비도와 할인율을 고정한다.

### 비용 할인 공식

초기 PoC 가설:

```text
30초  → Tier 2 금화 비용 -10%
60초  → Tier 2 금화 비용 -20%
90초  → Tier 2 금화 비용 -30%
120초 → Tier 2 금화 비용 -40%
```

공식:

```text
preparation_step = floor(preparation_progress_seconds / 30)
preparation_step = clamp(preparation_step, 0, 4)
tier2_gold_discount = preparation_step × 10%
tier2_gold_cost_multiplier = 1.0 - tier2_gold_discount
```

고정 규칙:

- 최대 할인은 40%다.
- 할인은 **금화 비용에만** 적용하는 초기안을 사용한다.
- 업그레이드 시간은 준비도로 감소하지 않는다.
- 서로 다른 특수병단의 준비도와 할인은 공유하지 않는다.
- 건물이 파괴되면 해당 건물의 준비도는 사라진다.
- 철거·취소 뒤 다시 건설하면 준비도 0초부터 시작한다.
- 전문화 종류를 고르기 전에도 준비도는 축적된다.
- 120초 이후에는 추가 할인이 발생하지 않는다.

### 전략적 선택

```text
즉시 Tier 2 업그레이드
→ 비용이 높지만 특수 토큰과 생산을 빨리 확보

Tier 1 유지 후 업그레이드
→ 전력 도입은 늦지만 최대 40% 저렴하게 전문화
```

Tier 1은 아무 효과가 없는 건물이 아니라 미래 특수 전력의 비용을 낮추는 선행 투자다.

## 5. Tier 1 UI 계약

특수병단 선택 패널에 다음을 표시한다.

- 현재 준비 시간.
- 현재 Tier 2 할인율.
- 다음 할인 단계까지 남은 활성 전투 시간.
- 각 전문화의 원래 비용과 현재 할인 적용 비용.
- 최대 할인율 40%.
- 즉시 업그레이드와 대기 업그레이드의 차이.

표시 예시:

```text
특수병단 준비도 64초
현재 할인 20%
다음 할인까지 26초

거인단 원가 100 → 현재 80 금화
```

할인은 숨은 수치로 처리하지 않는다.

## 6. Tier 2 토큰 활성

Tier 2 전문화 완료 순간:

- 다음 룰렛 회전부터 선택 계열 토큰을 반영한다.
- 진행 중인 룰렛 스냅샷은 바꾸지 않는다.
- 각 릴에 선택 계열 토큰 1개를 제공하는 것을 초기값으로 사용한다.
- 건물이 파괴되면 다음 회전부터 해당 토큰을 제거한다.

특수병종도 공통 룰렛 등급을 사용한다.

| 완성 줄 | 결과 |
|---:|---|
| 1줄 | 일반 특수 유닛 |
| 2줄 | 고정 엘리트 특수 유닛 |
| 3~7줄 | 고정 영웅 특수 유닛 |
| 8줄·9칸 동일 | 고정 전설 특수 유닛 |

- 플레이어 신화급은 생성하지 않는다.
- 상위 등급은 계열별 고정 템플릿을 사용한다.
- 자동생산은 일반 등급만 생성한다.

---

## 7. Tier 2 특수병종 자동생산

Tier 2 특수병단은 선택한 병종의 일반 등급 유닛을 자동생산한다.

초기 생산시간 가설:

| 전문화 | 자동생산 결과 | 생산시간 |
|---|---|---:|
| 사제단 | 일반 사제 | 180초 |
| 마도단 | 일반 마법사 | 195초 |
| 비행단 | 일반 비행병 | 210초 |
| 거인단 | 일반 거인 | 270초 |

공통 규칙:

- 생산은 Tier 2 전문화 완료 순간 0%에서 시작한다.
- 첫 생산도 동일한 전체 시간을 사용한다.
- 활성 전투 시간에만 생산 진행도가 증가한다.
- 일시정지 중에는 생산이 멈춘다.
- 생산 완료 시 식량 여유가 없으면 완성 대기 상태로 머문다.
- 식량이 확보되는 즉시 일반 특수 유닛을 출격 대기열에 넣는다.
- 건물이 파괴되면 현재 생산 진행도는 사라진다.
- 생산된 특수 유닛은 건물 파괴 후에도 유지된다.
- 여러 특수병단은 각각 독립적으로 생산한다.
- 자동생산에는 엘리트·영웅·전설 결과가 나오지 않는다.

### 룰렛과 자동생산의 관계

```text
룰렛
- 즉시 획득
- 엘리트·영웅·전설 가능
- 확률과 토큰 조작이 핵심

자동생산
- 매우 느림
- 일반 등급만 획득
- 장기 투자에 대한 확정 보상
```

룰렛이 특수 전력의 주된 획득 수단이고, 자동생산은 실패가 누적돼도 일정 시간 뒤 최소 한 기를 보장하는 안전장치다.

---

## 8. 예상 생산 횟수

활성 전투 시간 15분 스테이지에서 Tier 2 완료 시각에 따른 대략적 생산 횟수다.

| Tier 2 완료 시각 | 사제 | 마법사 | 비행병 | 거인 |
|---:|---:|---:|---:|---:|
| 4:00 | 3기 | 3기 | 3기 | 2기 |
| 6:00 | 3기 | 2기 | 2기 | 2기 |
| 8:00 | 2기 | 2기 | 2기 | 1기 |
| 10:00 | 1기 | 1기 | 1기 | 1기 |

이는 이론적 최대치이며 식량 부족·건물 파괴·일시정지와 스테이지 조기 종료에 따라 감소할 수 있다.

생산량이 지나치면 다음 순서로 조정한다.

1. 생산시간 +15초.
2. 첫 생산 추가 지연 +15초.
3. 특수병단 Tier 2 비용 증가.
4. 마지막으로 식량 비용 조정.

## 9. 기본 병영과 특수병단의 전략 차이

```text
기본 병영
- 즉시 전력과 높은 장기 생산량
- 비교적 짧은 생산 간격
- 낮은 투자 위험
- 상성 대응의 기본 골격

특수병단
- 준비 시간으로 비용 절감 가능
- 강력한 특수 토큰 추가
- 느리지만 확정적인 일반 특수 유닛 생산
- 높은 선행 투자와 식량 부담
- 잘못된 전문화의 전환 손실이 큼
```

기본 병영은 병력 수와 안정성을 제공한다. 특수병단은 초기 전력을 포기하고 중후반의 강한 룰렛 결과와 장기 자동생산을 확보하는 선택이다.

## 10. 상성 순환

```text
거인·기병·대형 돌진
→ 창병

비행병
→ 궁병·대공궁병

→ 암살자

밀집 일반병
→ 대검전사·마법사

중장갑·구조물
→ 대검전사 파쇄·거인

```

특수병종은 기본 병종의 상위호환이 아니라 기본 병종으로 명확히 대응 가능한 고영향 전력이어야 한다.

## 11. 건물 상태 전이

기본 병영:

```text
Tier 1 Active
→ Tier 2 Upgrading
→ Tier 2 Specialized
→ Tier 3 Upgrading
→ Tier 3 Advanced
```

특수병단:

```text
Tier 1 Preparation
→ Tier 2 Upgrading
→ Tier 2 Specialized + Auto Producing
```

- 특수병단 Tier 1도 정상 건물로 공격받고 파괴될 수 있다.
- 건설·업그레이드는 적이 있어도 계속 진행된다.
- Tier 2 업그레이드 시작 시 할인율을 고정한다.
- Tier 2 업그레이드 중에는 토큰·자동생산을 제공하지 않는다.
- Tier 2 완공 전 파괴되면 토큰과 특수 유닛을 한 번도 제공하지 못할 수 있다.
- 특수병단 Tier 3은 병종별 역할 검증 뒤 별도 승인한다.

## 13. 검증 계약

1. 기본 병영 Tier 2 선택지는 6종만 표시한다.
2. 특수병단 Tier 2 선택지는 사제·마법사·거인·비행병 4종만 표시한다.
3. Tier 1 특수병단은 토큰과 유닛을 제공하지 않는다.
4. Tier 1은 활성 전투 시간 30초마다 Tier 2 금화 비용을 10%씩 낮춘다.
5. Tier 1 최대 할인은 120초의 40%다.
6. 일시정지 중에는 준비도가 증가하지 않는다.
7. 건물 파괴·철거 시 준비도가 사라진다.
8. Tier 2 업그레이드 시작 시 현재 할인율을 고정한다.
9. Tier 2 완료 전 특수 토큰이 룰렛에 나타나지 않는다.
10. Tier 2 완료 후 다음 회전부터 선택 특수 토큰이 나타난다.
11. Tier 2 특수병단은 선택한 일반 특수병종을 자동생산한다.
12. 특수 자동생산은 기본 병영보다 명확히 느리다.
13. 자동생산은 일반 등급만 생성한다.
14. 룰렛은 특수병종의 엘리트·영웅·전설을 생성할 수 있다.
15. 식량이 부족하면 생산 완료 결과를 대기시키고 진행도를 초기화하지 않는다.
16. 건물 파괴 시 생산 진행도와 다음 룰렛 토큰을 제거한다.
17. 이미 생산된 유닛과 이미 확정된 룰렛 결과는 유지한다.
18. 특수병종은 기본 병종의 상위호환이 아니며 명확한 기본 병종 카운터를 가진다.

## 14. 후속 조정 대상

- Tier 1과 Tier 2의 절대 금화 비용·건설시간·업그레이드 시간.

- 특수병단 Tier 3 도입 여부.
