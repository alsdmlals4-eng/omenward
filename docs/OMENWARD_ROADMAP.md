## Phase P — 프리프로덕션 디자인 프리즈

완료:

- 오멘워드 공식명과 세계관 명칭.
- 벨루 단일 안내자.
- 좌우 대칭 독립 3라인과 라인별 성문.
- 중간거점 점령, 전방 2·후방 1 노드, 건설권·생산권 이전.
- 독립 중앙 접전지.
- 암살자 같은 라인 안개 우회로.
- 전장 전체 조망과 미니맵 미사용.
- 60초 공세 시계와 5·10·15·20 이정표.
- 플레이어 10병종과 적군 대응 10병종.
- 기본 병영·특수병단·룰렛·경제·건물·전술·용병 구조.
- 튜토리얼 1 + 정규 9의 약 3시간 캠페인 초안.
- UI·아트·오디오·성능·데이터·테스트 계약.
- 중간거점·성문·암살자 우회로의 수직 슬라이스 초기값.

승인된 초기값:

```text
중간거점: 중립화 10초 + 점령 10초, 최대 점령력 2.0
거점 생산: 금화 +2 / 30초, 안정화 5초
성문: HP 5000, 방어·마저 80, 일반 40%, 공성 200%
암살자: 진입 1초, 이동 9초, 도착 경고 2.5초, 출현 준비 0.6초
```

남은 프리프로덕션 검증:

- 룰렛 최소 100,000시드 확률 시뮬레이션.
- 기본·시장·접전지·중간거점 경제 시간축 검증.
- 전투·생산·웨이브 표 계산.
- 최종 고유명·아트 시안·아이콘·오디오.
- 정확한 Godot stable 버전과 구현 구조.

## Phase 0 — Godot 기술 기반

책임: Issue #1, Goal 0001.

- 정확한 Godot stable 버전.
- 프로젝트·Scene·Script·Resource·Test 폴더 구조.
- 2D 픽셀 카메라와 해상도·stretch 정책.
- 결정론적 난수·Manifest·입력 로그.
- real_time / active_combat_time / ui_planning_time 분리.
- UnitProfile·BuildingProfile·RankProfile·StageManifest 골격.
- BattlefieldProfile 또는 동등한 전장 데이터 구조.
- headless 테스트 러너와 데이터 검증기.

완료 기준:

- 빈 스테이지 headless 로드.
- 동일 시드 결과 재현.
- 일시정지 중 active_combat_time 정지.
- 잘못된 데이터 참조 시작 전 검출.
- 라인 연결 금지와 우회로 병종 제약 데이터 검증.

## Phase 1 — 트리븐 3라인 그레이박스

- 양측 본진과 상·중·하 성문.
- 양측 라인별 중간거점과 중앙 접전지.
- 독립 이동 그래프와 일반 횡단 금지.
- 주 도로와 성문·거점 전방의 넓은 전투 공간.
- 기본 전략 화면 전체 조망, 미니맵 없음.
- 검사·소형 베일종 더미 이동·교전.
- 성문 독립 상태와 접전지 점령 디버그 오버레이.

## Phase 2 — 중간거점·건설·경제

- 전방 2·후방 1 건설 노드.
- 도로 침범 검증.
- 중립화→점령→안정화 상태 머신.
- 생산·건설권 이전.
- 점령 시도 중 생산·건설·업그레이드 정지.
- 중립화 시 건물 비활성, 점령 완료 시 폐허화.
- 거점 +2/30초 생산.
- 최소 전방 방어 건물과 후방 경제 건물.

## Phase 3 — 룰렛·등급·배치

- 최소 3×3 릴과 건물 기반 토큰 가중치.
- X·금화·이동권.
- 결과 보관함과 라인 배치.
- 일반·엘리트·영웅·전설 경계.
- 100,000시드 분포·금화 기대값 검증.

## Phase 4 — 기본 병영·암살자

- 방패병·대검전사·암살자·창병·궁병·기병.
- 최소 수직 슬라이스에서는 전열·후열·공성·암살자 대표만 우선 구현.
- 암살자 선택 시 우회로 표시.
- 진입 1초→이동 9초→2.5초 경고→0.6초 출현 준비.
- 직접 후방 생성 금지, 우회 중 점령·피격 없음.

## Phase 5 — 성문 공성·특수병단

- 성문 HP 5,000, 방어·마저 80.
- 일반 구조물 피해 40%, 공성 200%, 고정 피해 50%.
- 2초 붕괴와 통로 개방.
- 수직 슬라이스에서는 수리·재건 없음.
- 사제·마법사·비행병·거인 확장.
