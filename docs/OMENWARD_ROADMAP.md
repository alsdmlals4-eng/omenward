## 2. 프로젝트 전체 완료 정의

오멘워드의 완료는 기능 수가 아니라 다음 경험과 품질을 만족하는 상태다.

- 플레이어가 다음 공세를 읽고 건물·룰렛·배치로 대응한다.
- 세 라인의 성문·중간거점·접전지 상태를 미니맵 없이 파악한다.
- 공용 10병종 데이터가 아군·적군 이미지 세트에서 동일하게 동작한다.
- 암살자 우회와 거점·성문 공방이 빌드 선택을 바꾼다.
- 첫 10분 안에 핵심 루프를 두 번 체험한다.
- 1~15웨이브와 선택적 16~20 초과전이 안정적으로 진행된다.
- 약 3시간 캠페인이 병종·Tier·위협을 단계적으로 소개한다.
- 실제 화면 크기에서 병종·진영·등급·공격 전조를 읽을 수 있다.
- 결정론적 데이터와 테스트로 주요 결과를 재현한다.
- 적군 전용 병종 데이터 복제 없이 콘텐츠를 확장한다.

## 9. P2 — 10~15분 핵심 수직 슬라이스

### 검증할 핵심 루프

```text
징조 확인
→ 건설
→ 룰렛
→ 배치
→ 3라인 교전
→ 거점 점령
→ 암살자 우회 또는 성문 공성
→ 승리 결과
```

### 대표 병종

- 전열: 방패병 또는 검사형.
- 원거리: 궁병.
- 침투: 암살자.
- 지원: 사제.
- 공성: 거인 또는 공성 더미.

각 공용 아키타입은 allied/veil Visual Profile로 최소 한 번씩 생성한다.

### 핵심 완료 기준

- 일반 유닛이 다른 라인으로 이탈하지 않는다.
- 미니맵 없이 주요 전황을 읽는다.
- 건물이 도로를 막지 않는다.
- 거점 점령 전후 건설권·생산권이 전환된다.
- 성문 3개가 라인별 독립 상태로 작동한다.
- 공성 역할이 성문에 유의미하게 강하다.
- 암살자 우회가 선택 전 숨겨지고 경고 후 적 후열에 도착한다.
- 같은 아키타입의 양 진영 전투 결과가 동일하다.
- 공격 판정과 시각 이벤트 오차가 승인 범위 안이다.
- 목표 객체 수에서 성능 기준을 측정한다.
