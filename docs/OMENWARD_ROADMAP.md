## 2. 프로젝트 전체 완료 정의

오멘워드의 개발 완료는 기능 목록이 아니라 다음 플레이 경험과 품질을 만족하는 상태다.

- 플레이어가 다음 공세를 읽고 건물·룰렛·배치로 대응한다.
- 세 라인의 성문·중간거점·접전지 상태를 미니맵 없이 파악한다.
- 공용 10병종 데이터가 아군·적군 이미지 세트에서 동일하게 동작한다.
- 암살자 우회와 거점·성문 공방이 빌드 선택을 바꾼다.
- 첫 10분에 핵심 루프를 두 번 체험한다.
- 1~15웨이브와 선택적 16~20 초과전이 안정적으로 진행된다.
- 약 3시간 캠페인이 병종·Tier·위협을 단계적으로 소개한다.
- 실제 화면 크기에서 병종·진영·등급·공격 전조를 읽을 수 있다.
- 결정론적 데이터와 테스트로 주요 결과를 재현한다.

## 3. Phase P — 프리프로덕션 디자인 기준

### 완료된 구조

- 오멘워드 공식명, 세계관, 벨루 단일 안내자.
- 건물 기반 3×3 룰렛과 첫 10분 핵심 루프.
- 좌우 대칭 독립 3라인과 라인별 성문.
- 중간거점 점령, 전방 2·후방 1 노드, 건설권·생산권 이전.
- 독립 중앙 접전지.
- 암살자 같은 라인 안개 우회로.
- 전장 전체 조망과 미니맵 미사용.
- 공용 UnitArchetype 10개와 Tier·등급 능력 계보.
- 아군·적군 전투 데이터 공유, 진영별 이미지 세트 분리.
- 기본 병영·특수병단·경제·건물·전술·용병 구조.
- 60초 공세 시계와 W5·W10·W15·W20 이정표.
- 튜토리얼 1 + 정규 9의 약 3시간 캠페인 초안.
- UI·아트·애니메이션·오디오·성능·테스트 계약.
- 중간거점·성문·암살자 우회로 초기값.

### 승인된 초기값

```text
중간거점: 중립화 10초 + 점령 10초, 최대 점령력 2.0
거점 생산: 금화 +2 / 30초, 안정화 5초
성문: HP 5000, 방어·마저 80, 일반 40%, 공성 200%
암살자: 진입 1초, 이동 9초, 경고 2.5초, 출현 준비 0.6초
```

### 남은 검증

- 룰렛 최소 100,000시드 확률·금화 EV.
- 기본·시장·접전지·중간거점 경제 시간축.
- 전투·생산·웨이브 표 계산.
- 실제 병종 키포즈와 40px 축소 모션.
- 정확한 Godot stable 버전과 기술 구조.

프리프로덕션은 새로운 대형 시스템을 추가하는 단계가 아니라 구현 가능한 책임 경계와 첫 수치를 검증하는 단계로 전환됐다.

## 7. Phase 1 — 3라인 그레이박스와 공용 유닛 인스턴스

### 범위

- 양측 본진과 상·중·하 성문.
- 양측 중간거점과 중앙 접전지.
- 독립 라인 이동 그래프.
- 기본 전략 화면 전체 조망, 미니맵 없음.
- UnitArchetype 참조 기반 UnitInstance.
- 같은 아키타입의 아군·적군 이미지 세트 생성.
- 전열·원거리 더미 이동과 기본 공격.

### 완료 기준

- 일반 유닛이 다른 라인으로 이탈하지 않는다.
- 양 진영 같은 아키타입의 수치·쿨다운·판정이 동일하다.
- 팀과 이미지가 달라도 별도 병종 코드가 없다.
- 0.85배 전략 줌에서 아군·적군과 역할을 구분한다.

## 8. Phase 2 — 중간거점·건설·경제

### 범위

- 전방 2·후방 1 건설 노드.
- 건물·최대 점유 영역의 도로 침범 검증.
- 중립화→점령→안정화 상태 머신.
- 생산·건설권 이전.
- 점령 시도 중 생산·건설·업그레이드 정지.
- 중립화 시 기존 건물 비활성.
- 점령 완료 시 기존 건물 폐허화.
- 거점 +2/30초 생산.
- 최소 전방 방어 건물 1종과 후방 경제 건물 1종.

### 완료 기준

- 승인된 시간과 점령력으로 상태가 전환된다.
- 소유권과 생산권이 일치한다.
- 폐허와 건물이 이동로를 막지 않는다.
- 동일 시드에서 점령·수입 결과가 재현된다.

## 9. Phase 3 — 최소 룰렛·등급·배치

### 범위

- 최소 3×3 릴.
- 완공 건물 기반 토큰 가중치.
- X·금화·이동권.
- 결과 보관함과 라인 배치.
- 일반·엘리트 우선 구현, 영웅·전설 인터페이스 고려.
- 100,000시드 분포·금화 EV 테스트 골격.

### 완료 기준

- 같은 시드에서 룰렛 결과가 재현된다.
- 건물 생성·파괴 뒤 토큰 풀이 다음 회전에 반영된다.
- 공용 아키타입 결과가 아군 UnitInstance로 생성된다.
- 상위 등급은 자동생산으로 생성되지 않는다.

## 10. Phase 4 — 암살자 우회와 대표 애니메이션

### 범위

- 암살자 선택 시 경로·도착 구역 표시.
- 진입 1초→이동 9초→경고 2.5초→출현 준비 0.6초.
- 직접 후방 생성 금지.
- 우회 중 전투·점령·피격 없음.
- 대표 아키타입의 deploy, idle, move, attack, hit, death, victory.
- 아군·적군 이미지 시트의 동일 상태·프레임·이벤트 검증.

### 완료 기준

- 선택 전 우회로가 보이지 않는다.
- 선택·배치 중 출발 라인과 도착 구역을 이해한다.
- 수비 측이 경고 뒤 대응할 수 있다.
- 우회가 순간이동으로 오인되지 않는다.
- 공격 판정과 접촉·발사 이벤트 오차가 한 프레임 이내다.
- 적군 전용 애니메이션 상태 머신이 없다.

## 11. Phase 5 — 성문 공성·지원·대형 역할

### 범위

- 성문 HP 5,000, 방어·마저 80.
- 일반 구조물 피해 40%, 공성 200%, 고정 피해 50%.
- 2초 붕괴와 통로 개방.
- 사제 또는 지원 더미.
- 거인 또는 공성 더미와 structure_attack.
- 성문 피격 단계와 붕괴 연출.
- 수직 슬라이스에서 수리·재건 없음.

### 완료 기준

- 세 성문 상태가 독립적이다.
- 공성 역할이 일반 병력보다 유의미하게 빠르게 성문을 파괴한다.
- 성문 붕괴가 2초 안에 균열→문짝 이탈→통로 개방으로 읽힌다.
- 성문 연출이 다른 라인의 전황을 가리지 않는다.

## 12. Phase 6 — 베일의 징조·첫 공세·승리

### 범위

- T-30/T-15/T-5 정보 공개.
- 공용 아키타입 기반 최소 적 웨이브.
- 첫 네 공세와 튜토리얼 학습 곡선.
- 적 생산시설 파괴의 예약 공세 감소.
- 스테이지 승리 판정과 2.5~4초 승리 시퀀스.
- 벨루 반응과 결과 UI 더미.

### 완료 기준

- 웨이브 파일에 적군 전용 스탯·스킬 복사본이 없다.
- 플레이어가 다음 위협 라인과 태그를 이해한다.
- 웨이브 정리 연출이 다음 공세를 막지 않는다.
- 승리 연출이 4초 이내 결과 UI로 연결된다.

Phase 1~6을 합친 결과가 10~15분 핵심 수직 슬라이스다.

## 13. Phase 7 — 1~15웨이브 확장

- W1~15 Threat와 라인 편성.
- 공용 10병종의 Tier·등급 조합.
- W5 엘리트, W10 영웅.
- W15 전설 보스 패키지.
- 생산시설 파괴와 호위 감소.
- 성문·거점 상태가 웨이브에 미치는 영향 계측.

완료 기준:

- 일반 적군 데이터 복제 없이 모든 웨이브 구성.
- W5·W10·W15의 위험 증가를 사전에 읽을 수 있음.
- 건강한 빌드가 다음 충돌 전 현재 Threat의 70% 이상 제거하는 첫 목표 검증.
