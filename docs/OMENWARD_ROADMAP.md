# 오멘워드 개발 로드맵

모든 구현 단계는 이전 단계의 관찰 가능한 완료 기준을 통과한 뒤 진행한다. 실제 코드 작업은 각 단계마다 Codex Plan Mode 제안서와 사용자 승인을 거친다.

## Phase P — 프리프로덕션 디자인 프리즈

- 오멘워드 공식명과 루메른·실베른·트리븐·베일런 명칭 계약
- 베일의 법칙과 베일의 징조 세계관 계약
- 벨루 단일 안내자·최종 시안·일시 상태 반응 계약
- Dopamine Driven Design과 시스템당 10~30초 습득 계약
- 첫 10분 결정론적 룰렛·초기 4공세·Tier 2 체험 계약
- 60초 공세 시계와 약 15분 정규 스테이지 계약
- 5 엘리트·10 영웅·15 전설 보스·20 신화 최종보스 이정표
- 15웨이브 표준 승리·적 본진 조기 승리·20웨이브 소프트 패배 구조
- 아군·적군 공통 병종·Tier·등급·태그·건물 데이터 구조
- 같은 병종·Tier·등급의 기본 전투 예산 대칭 계약
- 약 3시간 캠페인 범위
- 절차 생성기, StageManifest, DifficultyProfile, Threat Budget, Validator
- 건설 생명주기, Tier 전문화, 병영 세부 병종과 공유 토큰
- 룰렛 등급, 럭키 찬스, 이동권, 결과 보관함
- 패시브·스킬 성장, 전투 키워드, 비행·대공
- 전술 명령과 보스 패턴

완료 기준:

- Codex가 핵심 규칙과 상태 전이를 임의 해석할 필요가 없다.
- 벨루·베일의 법칙·실베른 성채 공식 용어가 모든 활성 문서에서 일치한다.
- 플레이어 4등급과 적군 전용 신화급의 경계가 명확하다.
- 아군·적군의 동일 병종·Tier·등급 비교 기준이 데이터로 표현된다.
- 비용·시간·확률·능력치는 데이터 조정 대상으로 분리된다.
- 기존 25~35분·35분 결전 공세 문구가 활성 계약에 남지 않는다.

## Phase 0 — Godot 기술 기반

- 정확한 Godot stable 버전
- GDScript 최소 프로젝트
- Scene·Script·Data·Resource·Test 구조
- 2D 픽셀 카메라와 아트 파이프라인
- 기준 해상도와 stretch 정책
- headless 파싱·실행 검증
- 결정론적 난수와 시간 서비스
- 활성 전투 시간과 현실 시간·일시정지 시간 분리
- 공통 UnitProfile·BuildingProfile·RankProfile 데이터 골격

## Phase 1 — 트리븐 3라인 전장

- 실베른 성채 본진과 적 본진
- 상·중·하 라인과 중앙 접전지
- 검사·베일 전사 더미 유닛 이동·교전
- 동일 병종·동Tier 기준 능력치 비교 디버그 표시
- 기본 승패와 디버그 오버레이
- 전장 거리·사거리 기준 검증

## Phase 2 — 건설·경제·전문화

- 후방 6노드와 라인별 전방 3노드
- 농장, 시장, 병영, 포탑
- 대응되는 적 생산 건물·방어 건물 더미
- 같은 기능 계열·Tier 건물의 HP·사거리·생산 주기 비교
- 금화·식량·생산 타이머
- Constructing→Active→Upgrading→Ruins 상태
- 적이 있어도 건설 진행, 건설 중 피격·파괴
- Tier 2 병종 전문화와 Tier 3 세부 병종·교리
- 공유 토큰과 출처 병영 원장
- Ready 슬롯과 식량 초과 처리

## Phase 3 — 룰렛·등급·배치

- 건물 기반 릴별 토큰 풀과 X
- 중앙 가로줄 판정
- 1/2/3~7/8줄 일반·엘리트·영웅·전설
- 금화 75%/200%/500%
- 전설 1회와 이후 영웅 2명
- 럭키 찬스와 이동권
- 결과 보관함과 라인 배치
- 병영 출처 후보 가중치 추첨
- 플레이어 등급표에서 신화급 생성 차단 검증

## Phase 4 — 전투·상성·능력

- 검사·방패병·대검병·광전사·기병·창병·궁병·암살자
- 대응되는 베일종 병종 계열
- 병영 Tier별 패시브 생성·강화
- 일반·엘리트·영웅·전설 1·2·3스킬 구조
- 적군 전용 신화 특성과 페이즈 인터페이스
- 물리·마법·고정 피해
- 치명타·후방·돌진·경직·밀쳐내기·상태이상
- 비행·대공·급강하·지상화
- 타기팅·충돌·접전지 점령
- 동일 병종·Tier·등급 전투 예산 ±10% 초기 검증

## Phase 5 — 베일의 징조·공세·등급 이정표·보스

- 적 건물 기반 경계 공세
- 활성 전투 시간 기준 60초 충돌 시계
- 웨이브별 생성 시점과 중앙 접전지 충돌 시점 분리
- T-30/T-15/T-5 징조와 정확한 구성 공개
- 이전 공세 잔존 시 다음 공세 누적
- 적 시설 파괴가 현재·다음 공세에 미치는 영향
- 5웨이브 엘리트 공세
- 10웨이브 영웅 공세
- 15웨이브 전설 보스 결전과 30~60초 목표 전투
- 16~19웨이브 엘리트·영웅 초과 공세
- 20웨이브 신화 최종보스 절멸 공세
- 적 본진 파괴 조기 승리
- 보스 직선 돌파·크게 베기
- 신화 다중 페이즈와 전투 중 격노
- 창병 돌진 저지와 보스 저항

## Phase 6 — 절차적 스테이지 생성기

- 튜토리얼 생성 대상 제외
- 결정론적 시드와 생성 규칙 버전
- StageArchetype·MapTemplate·EnemyBuild·WavePatternCard
- DifficultyProfile과 Threat Budget
- StageManifest와 Validator
- `wave_interval_seconds=60`, `elite_milestone_wave=5`, `hero_milestone_wave=10`
- `legendary_boss_wave=15`, `mythic_boss_wave=20`
- `wave_rank_compositions`와 공세별 등급 비중
- 아군·적군 공통 전투 예산 검증기
- 베일의 축복·저주·선언 필드
- 실패 시 검증된 안전 스테이지 대체
- 다수 시드 headless 검증

## Phase 7 — 상점·전술 명령·특수 적

- 상점 재고·새로고침·용병
- 바리케이드·화살비·역병·강화지대
- 전역 쿨다운 없이 명령별 개별 쿨다운
- 일시정지 중 정상 확정과 시간 정지
- 공성·돌격·지원·침투·지휘관형 베일종
- 비행 적과 대공 대응

## Phase 8 — 실베른 성채 튜토리얼

- 벨루 단일 안내
- 첫 30초 세계관·징조
- 첫 병영·토큰·룰렛·배치
- 포탑 또는 바리케이드 역전
- 이동권으로 엘리트 생성
- 방패병·대검병·광전사 선택
- 튜토리얼 공세 시계 시작 뒤 60초 간격 충돌
- 10분 안에 핵심 루프 두 번
- 실패 복구와 계측

## Phase 9 — 제약 시스템

- 베일의 축복·저주·선언 데이터
- 위험도 점수와 충돌 규칙
- 시작 전 공개와 Validator 재실행
- 공세 등급·전술 명령·보스 패턴 제약
- 기록·점수·메달 보상

## Phase 10 — 약 3시간 프로토타입 캠페인

- 실베른 성채 튜토리얼
- 활성 전투 시간 약 15분의 여러 정규 스테이지와 안전 시드
- 스테이지별 엘리트·영웅·전설·신화 적 디자인
- 루메른 영토와 베일런 황야의 시각 변형
- 병종·전술 명령·특수 베일종 순차 해금
- 쉬움·보통·어려움 프로필
- 시장·병영·혼합 빌드 플레이테스트
- 조기 승리·15웨이브 표준 승리·초과전 기록
- 벨루 대사·애니메이션·오디오
- 로고·키비주얼·스토어 소개
