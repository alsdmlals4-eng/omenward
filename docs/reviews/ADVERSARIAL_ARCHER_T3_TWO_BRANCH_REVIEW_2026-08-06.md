## 2. 채택 근거

### 2.1 T3 선택 목적이 선명해진다

- 석궁병은 낮은 연사와 높은 단발·관통을 교환한다.
- 연사궁병은 낮은 단발과 높은 공격 빈도·군집 대응을 교환한다.
- 대공궁병은 부모 궁병이 이미 가진 비행 대응을 다시 전문화해 선택 목적이 겹칠 위험이 있었다.

### 2.2 기본 대공을 T3에 잠그지 않는다

비행 압력이 등장할 때 T3 대공궁병을 먼저 확보해야만 한다면 건설·룰렛 선택이 사실상 강제된다. T2 궁병이 기본 대공 역할을 맡고 T3는 화력 방식 선택에 집중하는 편이 더 유연하다.

### 2.3 로스터 역할 중복을 줄인다

비행병도 FLYING 압력 대응 경로다. 별도의 대공궁병을 유지하면 궁병·대공궁병·비행병 사이에서 역할 경계가 흐려질 수 있다.

## 3. 주요 위험

### 위험 A — T2 궁병이 모든 공중전을 해결

T2 궁병의 기본 대공 성능이 너무 높으면 비행병과 전술 대응의 가치가 약화된다.

```text
MITIGATION
= 궁병은 지속 원거리 억제
= 비행병은 공중 우세·후방 급습
= 전술·건물은 시간·지역 단위 대응
```

정확한 피해 배율과 표적 전환은 시뮬레이션으로 분리한다.

### 위험 B — 석궁병이 지상·공중 모두 최적

높은 단발과 관통이 비행 적에게도 그대로 최고 효율을 내면 연사궁병과 비행병을 침범할 수 있다.

```text
STOP_SHIP
= 석궁병이 동일 비용·시간 기준으로 중장갑·고가치 지상·비행 모두 최상위
```

### 위험 C — 연사궁병이 군집·비행을 동시에 독점

높은 공격 빈도가 작은 비행 적과 지상 군집을 모두 가장 잘 처리하면 선택 기회비용이 사라진다.

```text
STOP_SHIP
= 연사궁병이 경장갑 군집·비행 군집·단일 지속 피해 모두 최상위
```

### 위험 D — 기존 문서가 대공궁병을 재도입

기존 승인 문서 세 곳에 대공궁병 문구가 남아 있어 구형 문서를 단독 참조하면 회귀할 수 있다.

```text
MITIGATION
= 최신 정정 문서에 정확한 대체 범위 명시
= 회귀 방지 계약에서 대공궁병 구현 입력 금지
= Google Sheet 상태 열에 폐기·GitHub 동기화 기록
```
