## 2. 결론

영웅 이상 등급 전체를 전역 1명으로 제한하고, 해금 영웅이 2스킬을 고유 스킬로 교체하는 방향은 핵심 재미와 **조건부 적합**하다.

적합한 이유:

- 영웅·전설을 단순 누적 전력으로 쌓지 않고 세 전선 중 어디에 최고 전력을 커밋할지 판단하게 한다.
- 해금 영웅의 고유 2스킬은 영웅 등급 당첨과 메타 해금의 체감 보상을 강화한다.
- 추가 스킬 슬롯이 아니라 기존 슬롯 교체이므로 전설 키트와의 계층을 보존하기 쉽다.
- 공통 자동 cooldown 프레임은 수동 액션 게임으로 변질되지 않게 한다.

조건:

- 슬롯 충돌로 영웅·전설 당첨이 무가치하게 느껴지지 않아야 한다.
- 해금 영웅 고유 2스킬이 표준 전설 전체 키트를 넘지 않아야 한다.
- 고등급 한 명의 장기 생존이 이후 룰렛 기대를 지나치게 억압하지 않아야 한다.

## 3. 발견 사항

### OMW-AUD-153 — 기존 제한 대상 충돌

- 기존 문서 일부는 `이름 지정 해금 영웅만 전역 최대 1명`으로 정의했다.
- 최신 사용자 결정은 표준·해금 여부와 관계없이 `[영웅]·[전설]` 전체를 합쳐 1명이다.
- 판정: `VALID_CONFLICT / LATEST_USER_DECISION_PREVAILS`.
- 보완: 새 책임 원본으로 라우팅하고 기존 named-only 규칙은 refined history로 남긴다.

### OMW-AUD-154 — 추가 스킬 구조가 등급 계층을 파괴

- 기존 해금 영웅 문서는 표준 영웅 키트에 고유 스킬을 추가하는 것으로 읽혔다.
- 이는 `강화 1스킬 + 표준 2스킬 + 고유 스킬`이 되어 사실상 3스킬 유닛이 된다.
- 표준 전설의 3스킬 구조를 침범한다.
- 판정: `VALID_CONFLICT / REPLACE_NOT_ADD`.
- 보완: 해금 영웅은 표준 2스킬을 고유 2스킬로 교체한다.

### OMW-AUD-155 — 전설 잭팟이 슬롯 충돌로 좌절

- 표준 영웅이 살아 있는 중 전설이 당첨돼도 즉시 배치할 수 없다.
- 한 Stage 1회 전설 보상의 감정적 고점이 약해질 수 있다.
- 판정: `VALID_RISK`.
- 보완: 결과는 정상 생성하며 보관·판매를 허용하고, UI에서 전역 슬롯 충돌과 보관 선택을 즉시 설명한다.
- 검증: 전설 판매 가치·보관함 압력·후속 배치 가능성 사람 QA.

### OMW-AUD-156 — 영웅 결과 빈도와 슬롯 압력

- 영웅은 3~7 완성선이라 전설보다 훨씬 넓은 결과 범위를 가진다.
- 영웅 슬롯이 장기간 차 있으면 고등급 토큰이 보관함에 누적되거나 판매 보상으로 전락할 수 있다.
- 판정: `VALID_RISK / SIMULATION_REQUIRED`.
- 보완: 영웅 결과 발생률·평균 생존 Stage·보관함 점유·판매 비율을 함께 측정한다.

### OMW-AUD-157 — 해금 영웅의 표준 영웅 완전 대체

- 같은 토큰과 같은 슬롯을 사용하고 해금 영웅이 더 강하면 해금 후 표준 영웅은 합리적 선택이 아니다.
- 판정: `EXPECTED_VERTICAL_PROGRESSION`, 결함으로 보지 않는다.
- 보완: 해금 전에도 기본 진행 가능해야 하며, 해금은 명확한 수직 보상으로 표시한다.
- 과거의 `다른 이름 지정 영웅 활성 중 표준 영웅 사용` 논리는 새 전역 고등급 슬롯에서는 더 이상 성립하지 않는다.

### OMW-AUD-158 — 고유 2스킬이 전설보다 강해지는 역전

- 전장 사건형 고유 스킬의 임팩트를 지나치게 높이면 표준 전설의 강화 2스킬+3스킬보다 실전 가치가 커질 수 있다.
- 판정: `VALID_RISK`.
- 보완: 전열 유지·피해·지원·제어·목표 제거의 총 전투 가치를 비교하는 `표준 영웅 < 해금 영웅 < 표준 전설` 매트릭스를 필수화한다.

### OMW-AUD-159 — 영웅 이상 단일 슬롯이 3전선 재미를 축소

- 최고 등급 유닛을 한 전선에만 쓸 수 있어 다른 두 전선이 상대적으로 평범해질 수 있다.
- 판정: `PARTIAL_RISK`.
- 보완: 게임의 주력은 일반·엘리트 병력, 건물, 타워, 지휘소, 룰렛 설계이며 고등급은 한 전선의 역전 카드로 제한한다.
- 성공 기준: 고등급 없이도 두 전선을 운영하고, 고등급 배치 전선 선택이 명확한 기회비용을 만든다.

### OMW-AUD-160 — 수동 교체가 비가역 커밋을 훼손

- 더 높은 등급을 얻었을 때 기존 영웅을 퇴각시켜 전설로 바꾸게 하면 비가역 배치와 장기 책임이 사라진다.
- 판정: `VALID_ATTACK / FORBIDDEN`.
- 보완: 자동 삭제·수동 퇴각·수동 교체·판매·재보관을 금지한다.

### OMW-AUD-161 — 미래 해금 전설의 범위 폭증

- 해금 전설을 바로 설계하면 현재 5명 영웅 작업과 함께 로스터·자산·획득·스킬·밸런스 범위가 배가된다.
- 판정: `VALID_SCOPE_RISK`.
- 보완: 현재는 `3스킬을 고유 스킬로 교체`하는 슬롯 방향만 예약하며 구현·자산·정확 로스터는 NOT_NOW다.

### OMW-AUD-162 — cooldown 완료 즉시 낭비 발동

- 공통 cooldown이 완료되자마자 약한 상황에 자동 발동하면 예측과 배치의 보상이 아니라 자동 낭비로 느껴진다.
- 판정: `VALID_RISK`.
- 보완: `READY_WAITING_FOR_VALID_CONDITION` 상태를 두고 유효 조건이 충족될 때까지 준비 상태를 보존한다.

## 4. 개선된 권장 구조

```text
룰렛에서 [영웅] 또는 [전설] 결과 획득
→ 전역 고등급 슬롯 상태 확인
→ 슬롯이 비어 있으면 표준/해금 후보 중 합법 선택
→ 한 전선에 비가역 배치
→ 자동 고유/표준 스킬로 전선 국면 변화
→ 생존 중 다른 고등급 결과는 보관·판매
→ 사망·완전 제거 후 슬롯 해제
```

해금 영웅:

```text
강화 1스킬 + 고유 2스킬
```

표준 전설:

```text
강화 1스킬 + 강화 표준 2스킬 + 표준 3스킬
```

향후 해금 전설:

```text
강화 1스킬 + 강화 표준 2스킬 + 고유 3스킬
```
