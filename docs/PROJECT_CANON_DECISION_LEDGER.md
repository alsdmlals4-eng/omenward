## 운영 원칙

- 현재 권위는 `DOCUMENTATION_MAP.md`와 `DOCUMENT_LIFECYCLE_REGISTRY.md`로 라우팅한다.
- Google Sheet는 같은 Decision ID와 exact PR HEAD로 동기화한다.
- 승인된 시뮬레이션 계약과 입력 manifest는 분석 입력일 뿐 제품 수치·제품 구현 권위를 갖지 않는다.
- 최신 물리 릴 정본이 legacy 가중치 보드보다 우선한다.
- 출처·단위·버전·SHA 또는 필수 입력이 누락되면 simulation sweep를 실행하지 않는다.
