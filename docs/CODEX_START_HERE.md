# Codex 시작 안내

Codex는 구현 전에 다음 순서로 문서를 읽는다.

1. `AGENTS.md`
2. `docs/BASE_RULES_VERSION.md`
3. `docs/GAME_DESIGN.md`
4. 현재 GitHub Issue 또는 `docs/goals/` Goal
5. `docs/DECISIONS_PENDING.md`
6. 관련 실제 파일과 테스트

첫 작업은 `docs/goals/0001-engine-selection-and-bootstrap.md`다. 이 작업은 엔진 비교와 추천까지만 수행하며, 사용자 승인 전 엔진 프로젝트를 생성하지 않는다.

구현 작업은 별도 `codex/issue-<번호>-<설명>` 브랜치와 Pull Request로 제출한다.
