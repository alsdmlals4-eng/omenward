# 다음 단계

엔진은 Godot, 기본 언어는 GDScript로 확정됐다. 핵심 게임 벤치마킹 적용안도 사용자 승인을 받아 `docs/design/APPROVED_BENCHMARK_DECISIONS.md`에 기록됐다.

현재 다음 작업은 코딩이 아니라 **프리프로덕션 디자인 프리즈**다.

## 검토 순서

`docs/design/DESIGN_FREEZE_CHECKLIST.md`를 기준으로 다음 묶음을 순차적으로 제안·승인한다.

1. 한 판 구조와 제품 범위
2. 전장·카메라와 플레이어 입력
3. 룰렛 보상·대기칸·럭키 찬스
4. 건물 Tier·파괴·폐허·경제
5. 유닛 상태·타기팅·상성·접전지
6. 적 건물·웨이브 생성과 전조
7. UI 정보 구조·접근성·튜토리얼
8. Godot 데이터·상태 소유·성능·테스트 계약

각 묶음은 선택지, 추천안, 포함·제외 범위와 검증 시나리오를 가진 제안서 형식으로 검토한다.

## 코딩 시작 조건

- 게임 규칙과 상태 전이가 구현자가 해석할 필요 없이 정리돼 있다.
- MVP 필수 UI와 오류·경계 처리가 확정돼 있다.
- Godot 버전, 데이터 경계, 상태 소유와 성능 목표가 확정돼 있다.
- 핵심 검증 시나리오가 작성돼 있다.
- 사용자가 Codex Plan Mode 구현 제안서를 명시적으로 승인했다.

비용, 생산시간, 확률, 체력, 공격력과 거리 같은 밸런스 수치는 초기값과 허용 범위를 데이터로 두고 플레이테스트로 조정할 수 있다.

Godot Phase 0 Issue #1은 계속 제안서 전용 상태로 유지하며, 사용자 승인 전에는 `project.godot`, Scene, 스크립트 또는 테스트를 생성하지 않는다.
