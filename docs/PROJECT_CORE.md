## 2. 핵심 플레이어 인과

```text
징조 관측
→ Stage 1: 지휘 거점·전진기지 방어·잠긴 건설 패드의 역할 이해
→ Stage 2 이후: 건설 / TokenSource / 미래 병력 분포 설계
→ 3×3 징조륜 결과
→ 제한된 행·열 조작
→ 병력 획득
→ 세 전선 중 하나에 비가역 커밋
→ 자동전투 + 제한된 수동 전술
→ 인과 Review
→ 다음 설계
```

핵심은 순수 운이 아니라 **읽을 수 있는 미래를 플레이어가 불완전하게 조율하고 그 결과의 책임을 이해하는 것**이다.
