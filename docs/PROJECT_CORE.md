## 5. Run shell

```text
PREPARE -> COMMIT -> BATTLE -> REVIEW
```

- 공간적 세 전선과 Forecast는 Focus 전환 사이에도 유지한다.
- PREPARE: 건설 / 동원 분포 / 징조륜.
- COMMIT: 획득 병력 / 전선 선택 / 비가역 배치.
- BATTLE: 자동전투 / 핵심 위험 / 마력 전술.
- REVIEW: Forecast → 준비 → 배치 → 사건 → 대응 → 결과.
- Debug raw ledger/target/cause 정보는 player-facing 상시 HUD에서 분리한다.
