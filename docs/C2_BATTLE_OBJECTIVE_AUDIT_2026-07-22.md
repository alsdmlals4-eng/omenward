## 2. 승인 인과

```text
3라인 교전
→ 중앙 접전지 통제
→ 중간거점 점령
→ 건설권·기본 생산권 전환
→ 라인별 성문 공성
→ 본진 종료 조건
→ 전장 상태 기반 승리·패배
→ 실제 소유 수 기반 시간 경제
```

## 3. 확인된 계약 차이

1. `BattleSimulator`는 적 유닛이 없으면 유닛을 `idle`로 두며 전선 목표로 전진시키지 않는다.
2. 정상 전투 흐름에서 유닛 점령력이 `OutpostState.begin_capture()`로 전달되지 않는다.
3. `OutpostState`는 승인 점령력 1.25·0.5를 현재 정규화 과정에서 0으로 만든다.
4. `GateState`는 승인 성문 수치를 보유하지만 전투 유닛의 구조물 공격과 연결되지 않는다.
5. 본진 상태와 전장 상태 기반 승리·패배 연결이 없다.
6. `StageRun`은 중앙 접전지 아군 통제 수를 경제에 `0`으로 전달한다.
7. 기존 외부 `stage_victory`·`stage_defeat` 명령이 정상 목적 루프를 대신한다.

## 4. 승인 초기값

- 성문: HP 5000, armor 80, magic resistance 80, 일반 구조물 피해 0.40, 공성 피해 2.00, 붕괴 2초.
- 중간거점: 중립화 10초 + 점령 10초, 유효 점령력 상한 2.0, 이탈 유지 3초, 복귀 10%/초, 안정화 5초.
- 점령력: 방패·수호 1.25, 일반 근접·기병 1.0, 원거리·지원·거인 0.5, 암살자·비행·순수 공성 0.
- 중앙 접전지: 60초마다 아군 통제 1곳당 4금화.
- 중간거점: 안정 소유 시 30초마다 2금화.

## 5. 보호 범위

- C1 룰렛 판정·보상·보관·결정론을 변경하지 않는다.
- C1U 이동권·럭키·고정 상위 등급 템플릿을 임의 확정하지 않는다.
- 코어 UX 6종·신규 병종·보스·캠페인·최종 아트를 섞지 않는다.
- 승인 문서 또는 기존 데이터에 없는 밸런스 수치를 숨은 최종값으로 추가하지 않는다.
- 각 라인의 상태와 성문은 독립적으로 유지한다.
- 암살자는 우회 전후 점령력 0을 유지한다.

## 6. 완료 게이트

- 유닛이 같은 라인에서 교전 뒤 목적 객체로 전진한다.
- 교착 시 점령이 정지하고 한 진영만 남으면 승인 점령력으로 진행된다.
- 점령 상태가 건설·생산 revision과 경제 소유 수에 반영된다.
- 성문은 라인별로 독립 공격·붕괴한다.
- 본진 종료 조건이 외부 디버그 명령 없이 승리·패배를 만든다.
- 접전지·중간거점 소유 수가 서로 다른 경제 주기로 반영된다.
- 같은 입력·seed·고정 틱이 같은 목적 상태와 로그를 만든다.
- Godot 4.7.1 import·전체 headless·runtime smoke·Python·문서·Skill 검증이 통과한다.
- 활성 문서에 C1 진행 중, PR #49 병합 대기, 과거 Work Order·Goal·Proposal 직접 참조가 남지 않는다.

이 문서는 감사가 끝날 때 실제 파일·테스트·검증 run과 최종 상태로 갱신한다.
