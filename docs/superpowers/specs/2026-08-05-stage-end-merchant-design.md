## 1. 설계 목적

Stage 종료 상인은 상시 상점이 아니다.

```text
Stage 결과 정산·checkpoint
→ 정비시간
→ 상인 재고 공개
→ 골드 사용 결정
→ 미션·선택지·건설·연구 정리
→ 다음 Stage 시작 확정
```

상인의 목적은 다음 세 가지다.

1. 골드를 건설·업그레이드·수리·룰렛 회전·연구와 경쟁시키는 명확한 기회비용을 만든다.
2. 이동권·수리·연구 진행처럼 기존 시스템을 제한적으로 보정한다.
3. 다음 Stage 압력에 대비할 선택지를 제공하되, 병종·건물·전술 연구를 우회하는 정답 상점이 되지 않는다.

## 2. 방문 시점

- Stage 1~19 종료 후 정비시간에 방문한다.
- Stage 20 종료 후에는 상인이 등장하지 않고 MapRun 최종 정산으로 이동한다.
- 상인은 평상시 HUD에 상시 버튼으로 존재하지 않는다.
- 상인 화면을 닫고 다음 Stage 시작을 확정하면 해당 방문 재고는 소멸한다.
- 전투 중 상인 재진입·구매·재고 갱신은 금지한다.

## 3. 재고 구조 — 권장 4칸

```text
TOTAL_SLOTS = 4
SLOT_A = GUARANTEED_MOVE_TICKET
SLOT_B = RECOVERY_SERVICE
SLOT_C = DEVELOPMENT_SERVICE
SLOT_D = VARIABLE_OPPORTUNITY
```

모든 상품은 방문별 유한 재고 1개를 기본 문법으로 사용한다. 정확한 수량은 `PENDING_SIMULATION`이지만 무한 반복 구매는 금지한다.

### 3.1 A — 보관형 이동권

- 매 방문 최소 1개를 보장한다.
- 구매하면 룰렛 보관 이동권에 즉시 추가한다.
- 기존 보유 상한 3개를 초과할 수 없다.
- 상한 도달 시 구매 불가 이유를 표시한다.
- 럭키 무료 이동과는 별도다.

### 3.2 B — 복구 서비스

후보:

- 손상 건물 수리 서비스.
- 보호 목표 또는 핵심 건물의 다음 Stage 한정 임시 보강.

권장 기본은 `수리 서비스`다.

- 구매 시 손상된 건물 하나를 선택해 즉시 수리한다.
- 수리할 대상이 없으면 이 슬롯은 다른 유효 상품으로 대체한다.
- 완전 무상 복구·파괴 건물 즉시 부활·영구 방어력 증가는 제공하지 않는다.
- 정확한 회복량과 일반 수리 대비 가격 차이는 `PENDING_SIMULATION`이다.

### 3.3 C — 성장 보조 서비스

후보:

- 현재 진행 중 전술 연구 시간 단축.
- 다음 건물 업그레이드 비용 할인.
- 다음 룰렛 회전 비용 할인.

권장 기본은 `연구 가속`이다.

- 진행 중 연구가 있으면 남은 연구 시간을 줄인다.
- 진행 중 연구가 없으면 선택 가능한 연구 하나에 시작 진행도를 부여하거나 다른 유효 상품으로 대체한다.
- 전술스킬을 직접 해금하지 않는다.
- 마력탑 Tier 요구를 우회하지 않는다.
- 연구 완료를 무조건 보장하지 않는다.
- 정확한 시간 단축량은 `PENDING_SIMULATION`이다.

### 3.4 D — 가변 기회 슬롯

다음 후보군에서 현재 상태에 유효한 하나를 제시한다.

- 추가 보관형 이동권.
- 추가 수리 서비스.
- 연구 가속.
- 다음 룰렛 1회 비용 할인.
- 다음 건물 건설 또는 업그레이드 1회 비용 할인.

금지 상품:

- 병종 직접 판매.
- T3 병종 직접 지급.
- 전술스킬 직접 해금.
- 마력 직접 판매.
- 병력 한도 영구 증가.
- 건물 분기 재선택권.
- Stage 정보 구매.
- Hero·Legendary 직접 판매.

## 4. 재고 생성 원칙

```text
재고 생성
→ 현재 MapRun 상태 검증
→ 무효 상품 제거
→ 슬롯별 후보 선정
→ 전체 재고와 가격 동시 공개
```

- 구매 전 모든 슬롯·가격·효과·대상 조건을 공개한다.
- 구매 결과로 다른 슬롯 가격이나 내용이 숨겨서 변하지 않는다.
- 상인 재고 수동 새로고침은 기본적으로 금지한다.
- 무료·유료 무한 reroll은 금지한다.
- 같은 서비스가 여러 슬롯에 동시에 등장할 수 있으나, 한 방문에서 동일 상품이 재고 대부분을 차지하지 않도록 중복 상한을 둔다.
- 사용 불가능한 상품은 생성하지 않는다.
- 다음 Stage 압력에 대한 명시적 대응 상품을 보장하지 않는다.
- Danger·Boss 직전이라고 필수 카운터를 상점에 숨겨 두지 않는다.

## 5. 골드 기회비용

상인 구매는 다음과 같은 골드 사용과 경쟁한다.

```text
건설
업그레이드
수리
룰렛 회전
전술 연구
상인 구매
```

상인 가격 원칙:

- 상품 가격은 무료가 아니다.
- 상인에서 모든 유효 상품을 매번 사는 전략이 기본 정답이 되어서는 안 된다.
- 반대로 이동권 하나조차 거의 살 수 없는 장식 상점이어서도 안 된다.
- 가격은 Stage 번호만으로 기계적으로 상승하지 않고 상품 가치·현재 경제·Act 구간을 함께 고려한다.
- 금고 투자로 상인 재고 전체를 무조건 매입하는 스노우볼은 시뮬레이션 Stop-ship 항목이다.
- 정확 가격·할인율·재고 수량은 `PENDING_SIMULATION`이다.

## 6. 구매·거래 규칙

- 구매 통화는 골드 하나다.
- 판매·매입·흥정·대출·외상은 6/10 범위에서 도입하지 않는다.
- 구매 후 즉시 적용되는 서비스는 되돌릴 수 없다.
- 비용 할인 상품은 구매 시 명시된 한 번의 행동에만 적용한다.
- 할인 중첩은 금지한다.
- 다음 Stage가 시작되면 사용하지 않은 1회성 할인 권리는 소멸한다.
- 구매 확인 화면은 `상품 / 대상 / 즉시 효과 / 소멸 조건 / 구매 후 골드`를 표시한다.
- 중복 클릭·화면 전환·checkpoint 저장으로 같은 상품을 두 번 구매할 수 없어야 한다.

## 7. Stage 진행과 재고 등급

```text
Act 1 = 기본 정비 중심
Act 2 = 연구·구조 조정 선택 증가
Act 3 = Danger 대응 준비 가치 증가
Act 4 = Boss 직전 기회비용 강화
```

이는 상품의 역할 폭을 조절하는 기준이며 정확 등장률·가격 배율은 아니다.

- 초반 상인은 이동권·수리처럼 이해하기 쉬운 상품을 우선한다.
- 후반 상인은 연구 가속·고가 할인처럼 미래 선택을 바꾸는 상품 비중을 늘릴 수 있다.
- Boss 직전 상인은 강한 상품을 자동 보장하지 않는다.
- 최종 Stage 직전에도 단일 필수 구매가 생성되어서는 안 된다.

## 8. 핵심 시스템과의 경계

### 룰렛

- 이동권과 회전 할인만 지원한다.
- 릴 토큰을 직접 편집하거나 특정 병종 당첨을 보장하지 않는다.
- 보상 등급·완성선 규칙을 변경하지 않는다.

### 건물

- 수리와 1회 비용 할인만 지원한다.
- 건물 Tier·분기를 직접 변경하지 않는다.
- MapRun 영구 분기 선택을 되돌리지 않는다.

### 전술·마력탑

- 연구 시간을 보조할 수 있으나 전술을 직접 해금하지 않는다.
- 마력탑 Tier 요구와 동시 연구 1개 규칙을 우회하지 않는다.
- 마력은 판매하지 않는다.

### 병종

- 병종·승급·T3를 직접 판매하지 않는다.
- 병종 획득은 룰렛·보상 계보를 유지한다.

## 10. 실패·예외 처리

- 골드 부족: 구매 불가, 부족량 표시.
- 이동권 상한: 구매 불가, 상한 표시.
- 수리 대상 없음: 수리 상품 생성 금지 또는 대체.
- 진행 연구 없음: 직접 해금 대신 유효한 연구 보조 규칙 적용 또는 대체.
- 할인 대상 없음: 할인 상품 생성 금지 또는 대체.
- 구매 중 저장·종료: checkpoint 기준 멱등 처리.
- 구매 직후 크래시: 골드 차감과 상품 적용이 하나의 거래로 복구되어야 한다.
- Stage 20 종료: 상인 생성 금지.

정확한 상태머신·트랜잭션·저장 순서는 Codex 구현 계획이 소유한다.

## 12. 적대적 검토 대상

후속 적대적 검토는 최소 다음을 공격한다.

1. 이동권 매 방문 보장이 사실상 세금이 되는가.
2. 연구 가속이 마력탑 Tier·연구 시간을 무의미하게 만드는가.
3. 금고 경제가 상인 전체 구매 스노우볼을 만드는가.
4. 수리 서비스가 일반 수리를 대체하거나 중복하는가.
5. 할인 상품 저장·중첩·checkpoint 복제 악용.
6. 상인 재고가 다음 Stage의 숨은 필수 카운터가 되는가.
7. 직접 병종·전술 판매가 다시 유입되는가.
8. 19회 방문이 반복적이고 느린가.
9. 초반 골드 부족으로 상인이 장식이 되는가.
10. 마지막 Stage 예외가 최종 정산과 충돌하는가.
