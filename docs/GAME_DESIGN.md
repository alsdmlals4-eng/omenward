# Roulettebound 게임 기획서

- 문서 버전: v0.8
- 상태: 프리프로덕션 / 핵심 시스템 사양 정리
- 장르: 실시간 3라인 전략 오토배틀 + 건물 기반 룰렛 빌드
- 기본 모드: 플레이어 대 비대칭 웨이브 AI

## 1. 한 문장 소개

플레이어가 건물을 지어 3×3 룰렛의 토큰과 확률을 직접 설계하고, 획득한 병력을 상·중·하 전선에 배치해 접전지와 생산 거점을 지키며 적 본진을 무너뜨리는 실시간 전략 오토배틀 게임.

## 2. 목표 플레이어 경험

- 운을 그대로 받아들이는 것이 아니라 건설 조합으로 확률을 설계한다.
- 세 라인의 전투, 접전지, 전방 시설을 동시에 관찰하고 제한된 자원을 배분한다.
- 적 웨이브의 전조를 읽고 병종 상성, 포탑, 룰렛, 대기 유닛으로 대응한다.
- 안전한 후방 경제와 위험하지만 강력한 전방 투자의 선택을 반복한다.
- 상대 시설을 파괴해 현재 전선뿐 아니라 미래 생산과 룰렛/웨이브 구성까지 약화한다.

## 3. 핵심 플레이 루프

```text
금화·식량 확보
→ 건설 노드에 시설 건설 또는 티어 상승
→ 건물 구성에 따라 룰렛 토큰 풀 변화
→ 룰렛 회전 및 유닛/금화 획득
→ 대기칸에서 유닛과 아이템 정리
→ 상·중·하 라인 배치
→ 실시간 접전·점령·시설 방어
→ 적 웨이브 전조 확인 및 대응
→ 적 전방 시설과 본진 압박
→ 반복
```

전투는 멈추지 않는다. 플레이어는 실시간 전투 중 룰렛, 건설, 업그레이드, 구매, 배치를 수행한다.

## 4. 승패 기본안

- 승리: 적 본진의 핵심 건물 체력을 0으로 만든다.
- 패배: 플레이어 본진의 핵심 건물 체력이 0이 된다.
- 세션 길이와 제한 시간은 테스트 후 결정한다.

## 5. 전장 구조

### 5.1 세 개의 독립 라인

- 상단
- 중단
- 하단

각 라인의 기본 흐름:

```text
플레이어 본진
→ 플레이어 전방 건설 거점
→ 중앙 접전지
→ 적 전방 건설 거점
→ 적 본진
```

### 5.2 맵 크기와 거리 원칙

- 본진과 전방 건설 거점 사이에 병력이 이동하고 요격할 수 있는 충분한 거리를 둔다.
- 전방 거점과 중앙 접전지 사이에도 독립된 전투 구간을 둔다.
- 기본 포탑은 전방 거점에서 중앙 접전지를 공격할 수 없다.
- 포탑이 여러 차례의 사거리 업그레이드를 완료한 뒤에만 접전지 가장자리 또는 내부에 영향을 줄 수 있다.
- 사거리 업그레이드는 경제와 공격 성능을 포기하는 명시적인 투자여야 한다.

### 5.3 건설 노드

플레이어 한쪽 기준 총 15개:

| 구역 | 노드 수 | 특징 |
|---|---:|---|
| 본진 후방 | 6 | 안전하지만 공간이 제한됨 |
| 상단 전방 거점 | 3 | 시설과 포탑 건설 가능, 공격받을 수 있음 |
| 중단 전방 거점 | 3 | 시설과 포탑 건설 가능, 공격받을 수 있음 |
| 하단 전방 거점 | 3 | 시설과 포탑 건설 가능, 공격받을 수 있음 |

전방 노드에서는 생산시설과 포탑이 같은 공간을 경쟁한다.

- 생산시설: 장기 경제·생산 이득, 파괴 위험
- 포탑: 해당 라인 방어 강화, 경제 공간 포기
- 전방 훈련시설: 병력이 전선에 더 빠르게 합류

시설이 파괴된 노드는 일정 시간 폐허 상태가 된 뒤 다시 사용할 수 있다. 구체 시간은 밸런스 테스트 항목이다.

## 6. 중앙 접전지

각 라인 중앙에 점령 지점 1개, 총 3개를 배치한다.

### 6.1 점령 규칙 기본안

- 한 진영의 유닛만 범위 안에 일정 시간 존재하면 점령한다.
- 양측 유닛이 함께 있으면 접전 상태가 되어 진행이 멈춘다.
- 적 점령지를 빼앗을 때는 `중립화 → 재점령` 단계를 거친다.
- 유닛 수에 따른 점령속도 보정은 초기 MVP에서 제외한다.
- 중앙 접전지에는 건물을 지을 수 없다.

### 6.2 보상

- 점령한 접전지마다 초당 추가 금화를 얻는다.
- 여러 라인을 점령하면 수입이 누적된다.
- 접전 중에는 해당 접전지의 추가 수입이 일시 정지되는 안을 기본으로 한다.
- 접전지 1개의 수입은 시장 1티어보다 낮게 유지해 시장 건설을 대체하지 않도록 한다.

목적은 한 라인 몰아치기만 반복하지 않고 세 전선을 모두 관리하게 만드는 것이다.

## 7. 자원

### 7.1 금화

사용처:

- 룰렛 회전
- 상점 새로고침
- 스킬북과 장비 구매
- 건물 건설
- 건물 티어 상승
- 럭키 찬스 이동권 구매

획득처:

- 기본 수입
- 시장
- 룰렛 금화 토큰
- 중앙 접전지
- 기타 전투 보상은 추후 검토

### 7.2 식량 / 보급 한도

식량은 현재 출전 가능한 병력의 최대 한도를 나타낸다.

- 농장 건설 및 티어 상승으로 최대 식량 증가
- 유닛마다 보급 비용이 다름
- 전방 농장 파괴로 최대치가 내려가도 이미 출전한 유닛은 즉시 제거하지 않음
- 한도를 초과한 상태에서는 새로운 병력을 출전할 수 없음

## 8. 건물 시스템

### 8.1 공통 규칙

- 빈 건설 노드에 금화를 지불해 건설한다.
- 완공 전에는 생산 효과와 룰렛 토큰을 제공하지 않는다.
- 건물은 티어를 높일 수 있다.
- 티어 상승은 생산량, 생산 간격, 유닛 품질, 내구도 또는 전투 능력을 강화한다.
- **룰렛 토큰 수는 티어가 아니라 완공된 건물 개수로 계산한다.**
- 건물 1동은 대응 토큰을 각 세로 릴에 1개씩 추가한다.
- 파괴 또는 철거된 건물의 토큰은 다음 회전부터 제거된다.

### 8.2 시설 목록

| 건물 | 기본 효과 | 룰렛 토큰 | 티어 상승 예시 |
|---|---|---|---|
| 농장 | 최대 식량 증가 | 없음 | 식량 증가량 상승, 보급 관련 보너스 |
| 시장 | 지속 금화 생산 | 금화 | 생산량 증가, 생산 간격 감소 |
| 검사 훈련소 | 일정 시간마다 기본 검사 생산 | 검사 | 생산시간 감소, 생산량/품질 증가 |
| 기병 훈련소 | 일정 시간마다 기본 기병 생산 | 기병 | 생산시간 감소, 생산량/품질 증가 |
| 창병 훈련소 | 일정 시간마다 기본 창병 생산 | 창병 | 생산시간 감소, 생산량/품질 증가 |
| 궁병 훈련소 | 일정 시간마다 기본 궁병 생산 | 궁병 | 생산시간 감소, 생산량/품질 증가 |
| 신전 | 일정 시간마다 사제 생산 | 사제 | 생산시간 감소, 회복 관련 품질 증가 |
| 아카데미 | 일정 시간마다 마법사 생산 | 마법사 | 생산시간 감소, 마법 품질 증가 |
| 도적 훈련소 | 일정 시간마다 도적 생산 | 도적 | 생산시간 감소, 침투 품질 증가 |
| 포탑 | 고정 위치 자동 공격 | 없음 | 공격력, 공속, 내구도, 단계적 사거리 증가 |

### 8.3 병종 시설 자동 생산

- 일정 시간마다 1단계 기본 병종을 생산한다.
- 자동 출전 라인을 지정하거나 대기칸에 보관할 수 있다.
- 전방 시설은 해당 라인에서 또는 가까운 지점에서 생산해 합류 시간을 줄인다.
- 후방 시설은 안전하지만 병력의 이동 시간이 길다.

### 8.4 포탑

- 지정 노드에 고정 배치된다.
- 범위 안의 적을 자동 공격한다.
- 기본 역할은 라인을 영구 봉쇄하는 것이 아니라 증원 시간을 버는 것이다.
- 초기 포탑은 중앙 접전지까지 닿지 않는다.
- 사거리 티어를 여러 번 올린 고급 포탑만 접전지를 지원할 수 있다.
- 포탑은 식량을 차지하지 않지만 노드와 금화를 소모한다.
- 초기 MVP는 기본 원거리 포탑 1종으로 시작한다.

## 9. 건물 티어 설계 원칙

초기 목표는 3티어 구조다. 정확한 수치는 플레이테스트 후 정한다.

| 티어 | 설계 의도 |
|---|---|
| Tier 1 | 건물의 기본 기능과 룰렛 토큰 1개/릴 제공 |
| Tier 2 | 생산량 증가 또는 생산시간 감소, 내구도 개선 |
| Tier 3 | 핵심 성능 강화 또는 전문화 선택 |

제약:

- 티어 상승만으로 룰렛 토큰 수가 늘어나지 않는다.
- 고티어 1동과 저티어 여러 동 사이에 `노드 효율 대 룰렛 확률` 선택이 생겨야 한다.
- 포탑 사거리 강화는 초반 티어 한 번으로 접전지에 닿아서는 안 된다.
- 적 건물도 티어에 따라 웨이브 생산량, 생산속도, 유닛 품질이 강화된다.

## 10. 룰렛 시스템

### 10.1 기본 구조

- 3개의 세로 릴
- 각 릴에서 3개 심벌을 표시해 3×3 판 생성
- 플레이어가 판정할 가로 기준 줄 하나를 선택
- 세 릴은 현재 토큰 풀을 기준으로 독립적으로 회전

### 10.2 건물 기반 토큰 풀

완공된 건물 1개마다 각 릴에 대응 토큰 1개를 추가한다.

예시: 시장 2개, 검사 훈련소 2개, 기병 훈련소 1개

```text
각 릴: 금화 / 금화 / 검사 / 검사 / 기병
등장 비율: 금화 40%, 검사 40%, 기병 20%
```

자신의 건설 조합으로 확률을 조정하며, 보이는 적 건물로 상대의 미래 생산 성향을 추측할 수 있다.

### 10.3 X 토큰

각 릴의 실제 토큰이 3개 미만이면 부족한 수만큼 임시 X 토큰을 넣는다.

```text
릴당 X 수 = max(0, 3 - 실제 토큰 수)
```

| 실제 토큰/릴 | X 토큰/릴 |
|---:|---:|
| 0 | 3 |
| 1 | 2 |
| 2 | 1 |
| 3 이상 | 0 |

X는 아무런 보상도 제공하지 않는다. 실제 토큰이 증가하면 X부터 자동 제거된다.

### 10.4 기준 줄 보상

선택한 가로줄에서 같은 심벌 수를 센다.

- 1개: 해당 종류 1성 보상
- 2개: 해당 종류 2성 보상
- 3개: 해당 종류 3성 보상 및 추가 빙고 판정 활성화
- 서로 다른 심벌은 각각 1개 보상으로 처리하는 안을 기본으로 하며 경제 밸런스 검증 필요

금화 심벌은 별 단계에 따라 금화 보상량이 증가한다.

### 10.5 추가 빙고와 병력 품질

기준 줄에서 같은 심벌 3개가 완성된 경우에만 전체 판의 가로·세로·대각선을 추가 검사한다.

현재 기본안:

| 동일 심벌 완성 줄 수 | 병력 품질 |
|---:|---|
| 1줄 | 병사 |
| 2줄 | 엘리트 |
| 3줄 | 영웅 |

전설·신화 등급의 정확한 조건은 미확정이다.

### 10.6 럭키 찬스

회전 후 확률적으로 또는 구매한 이동권으로 다음 중 하나를 수행한다.

- 특정 행을 좌우로 1칸 순환 이동
- 특정 열을 상하로 1칸 순환 이동

목적은 단순 재굴림이 아니라 플레이어가 빙고 패턴을 직접 완성할 기회를 주는 것이다.

## 11. 유닛 획득과 배치

### 11.1 대기칸

룰렛과 훈련시설로 얻은 유닛은 기본적으로 대기칸에 저장할 수 있다.

- 유닛 확인
- 출전 라인 지정
- 스킬북·장비 적용
- 판매 또는 정리
- 자동 출전 여부 설정

대기칸은 제한된 용량을 가진다.

### 11.2 라인 배치

- 일반 유닛은 상·중·하 중 선택한 라인으로 출전한다.
- 한 번 출전하면 기본적으로 자동 이동·공격한다.
- 도적/암살자는 조건을 만족하면 적 후방 배치 또는 침투가 가능하다.
- 유닛 직접 조작보다 배치, 구성, 출전 타이밍에 집중한다.

## 12. 병종과 상성

| 병종 | 역할 | 강점 | 약점 |
|---|---|---|---|
| 검사/전사 | 전면 탱커·근접 | 궁병 압박, 안정적 전선 | 기병 |
| 기병 | 돌진·기동·돌파 | 검사와 궁병 압박 | 창병 |
| 창병 | 대기병·진형 유지 | 기병 저지 | 궁병 |
| 궁병 | 후방 원거리 | 창병과 느린 보병 압박 | 검사, 기병, 도적 |
| 사제 | 회복·지원 | 전선 유지력 | 도적, 낮은 단독 전투력 |
| 마법사 | 강한 범위 화력 | 밀집 병력 | 도적, 낮은 체력 |
| 도적/암살자 | 단일딜·후방 침투 | 궁병·사제·마법사 제거 | 전면전과 광역 피해 |

핵심 상성 기본안:

```text
기병 > 검사
창병 > 기병
궁병 > 창병
검사 > 궁병
기병 > 궁병
도적 > 마법사·사제·궁병
전면 근접 병력 > 도적
마법사 > 밀집 병력
```

## 13. 등급 밸런스 목표

수치보다 다음 관찰 가능한 관계를 우선한다.

1. 엘리트 검사는 상성상 유리한 병사 기병과 1대1에서 조금 밀린다.
2. 엘리트 검사 1명은 같은 병종 병사 2명보다 강하다.
3. 영웅 1명은 같은 조건의 엘리트 2명보다 강하다.
4. 상성상 유리한 엘리트는 불리한 영웅을 1대1에서 이길 수 있다.

초기 프로토타입의 상대 전투력 가설:

- 병사 1.0
- 엘리트 2.1
- 영웅 4.3
- 상성은 주는 피해와 받는 피해를 함께 조정

정확한 배율은 자동 시뮬레이션과 플레이테스트로 결정한다.

## 14. 스킬북과 장비

- 상점에서 금화로 구매한다.
- 해당 게임/런 동안만 유지된다.
- 초기 구현은 개별 유닛보다 병종 전체 적용을 우선 검토한다.
- 영웅도 동일한 스킬·장비 시스템의 영향을 받는다.

예시:

- 방패벽
- 대기병진
- 관통 화살
- 연속 돌진
- 범위 치유
- 연쇄 번개
- 그림자 도약

장비는 체력, 방어, 사거리, 공격속도, 마력, 이동속도 등 수치를 보완한다.

## 15. 적 AI와 웨이브

### 15.1 비대칭 운영

적은 플레이어처럼 룰렛을 돌리지 않는다.

- 적 건물과 티어가 일정 시간마다 웨이브 병력을 생산
- 적 본진은 모든 외부 건물이 파괴돼도 최소 기본 병력을 제공
- 전방 적 시설은 해당 라인을 강화하고 가까운 지점에서 병력을 출현시킬 수 있음

### 15.2 30초 전조

웨이브 출격 약 30초 전에 다음 정보를 공개한다.

- 공격 예정 라인
- 병종
- 예상 또는 정확한 수량
- 특수 웨이브 여부
- 후방 침투 위치와 목표가 있으면 별도 경고

전조 단계 기본안:

| 시점 | 표시 |
|---|---|
| T-30 | 병종, 수량, 공격 라인 공개 |
| T-15 | 적 집결 실루엣과 라인 경고 강화 |
| T-5 | 경고음, 카운트다운, 화면 강조 |
| T-0 | 웨이브 출격 |

웨이브 구성은 출격 직전 특정 시점에 확정한다. T-10초 확정안을 우선 검토한다.

- 확정 전 적 건물 파괴: 현재 웨이브 감소 가능
- 확정 후 적 건물 파괴: 다음 웨이브부터 적용

### 15.3 특수 웨이브 후보

- 한 라인 기병 돌격
- 세 라인 분산 공격
- 시설 우선 공성 병력
- 후방 도적 침투
- 적 영웅 출현

모든 치명적인 특수 공격은 대응 가능한 전조를 제공한다.

## 16. UI 정보 구조

전투 중 항상 이해할 수 있어야 하는 정보:

- 플레이어·적 본진 체력
- 금화, 초당 수입, 식량 사용량/최대치
- 상·중·하 접전지 소유와 점령 진행도
- 다음 적 웨이브 카운트다운과 라인별 구성
- 3×3 룰렛, 선택 기준 줄, 현재 토큰 비율
- 대기 유닛과 출전 가능 여부
- 건설 노드 상태, 건물 티어, 생산 타이머
- 선택 포탑의 현재 사거리와 다음 사거리 업그레이드 결과

룰렛 확률은 최소한 자기 진영에는 숫자로 공개한다. 적은 건물 관찰로 추정하도록 하되 정확한 공개 수준은 난이도 설계에서 결정한다.

## 17. 중반 플레이 예시

1. 후방 노드 6개가 대부분 농장, 시장, 훈련소로 찬다.
2. 상단은 포탑 2개와 전방 병영으로 방어형 구성을 만든다.
3. 중단은 시장과 훈련소를 전진 배치해 높은 위험을 감수한다.
4. 하단은 접전지를 확보했지만 적 기병 웨이브가 30초 뒤 도착할 예정이라고 표시된다.
5. 플레이어는 창병 훈련소를 추가해 룰렛 창병 확률을 높이고, 대기 중인 창병을 하단에 배치한다.
6. 포탑을 업그레이드할지 시장 티어를 올려 다음 룰렛 자금을 마련할지 선택한다.
7. 적 전방 훈련소를 파괴하면 향후 웨이브에서 해당 병종 수가 줄어든다.

## 20. 주요 위험

- 룰렛 금화 토큰이 회전 비용보다 높은 기대값을 만들어 무한 경제가 발생할 수 있음
- 같은 건물 3개로 특정 토큰을 확정하는 특화 빌드가 지나치게 강할 수 있음
- 접전지 수입이 우세한 플레이어의 스노우볼을 과도하게 키울 수 있음
- 전방 농장 파괴에 따른 식량 초과 상태가 이해하기 어렵거나 지나치게 치명적일 수 있음
- 포탑 사거리 업그레이드가 접전지를 일방적으로 봉쇄할 수 있음
- 세 라인, 웨이브 전조, 룰렛, 건설 UI가 동시에 표시돼 정보 과부하가 생길 수 있음
- 유닛 수가 많아질 때 경로 탐색과 타기팅 비용이 급증할 수 있음
