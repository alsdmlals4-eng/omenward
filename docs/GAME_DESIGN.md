# Roulettebound 게임 기획서

- 문서 버전: **v0.11**
- 상태: 프리프로덕션 / 구현 전 디자인 프리즈 진행 중
- 장르: 실시간 3라인 전략 오토배틀 + 건물 기반 3×3 룰렛 빌드
- 기본 모드: 싱글플레이 PvE 비대칭 웨이브 전투
- 우선 플랫폼: Windows PC / 마우스·키보드
- 구현 엔진: Godot / GDScript

세부 책임 문서가 이 문서보다 더 최근인 경우 `docs/design/APPROVED_*.md`가 우선한다. 미확정 수치는 `docs/DECISIONS_PENDING.md`에서 관리한다.

## 1. 한 문장 소개

플레이어는 인류 최전선의 지휘관이 되어 건물로 룰렛 확률과 증원 체계를 설계하고, 정체불명의 규칙에 따라 경계를 넘어오는 괴물 군단을 세 전선에서 막아낸다.

## 2. 핵심 재미

> 건물을 지어 룰렛 확률을 바꾸고, 당첨된 병력으로 예고된 위기를 뒤집는다.

```text
경계의 징조 확인
→ 필요한 건물·병종·전술 선택
→ 룰렛 토큰과 확률 변화
→ 룰렛 회전과 병력 획득
→ 필요한 라인에 배치
→ 상성과 전술로 전선 역전
→ 다음 Tier·등급·병종 목표
```

핵심 감정은 긴장, 판단, 기대, 당첨 쾌감, 통제감, 역전과 성장 기대의 순서로 연결한다.

## 3. 세계관 전제

### 3.1 플레이어

플레이어는 직접 전투하는 영웅보다 전체 전선을 책임지는 지휘관이다.

- 건설과 업그레이드
- 병력 획득과 출전 라인 결정
- 적 웨이브 분석
- 전술 명령 사용
- 공격·방어 우선순위 결정

괴물 군단이 최종 방어선을 넘으면 후방 생활권이 공격받는다.

### 3.2 경계의 율

괴물은 계속 밀려오는 것이 아니라 정체불명의 `경계의 율`에 따라 웨이브 단위로 경계를 넘는다.

- 공세 전에는 라인·병종·수량을 예측할 수 있는 징조가 나타난다.
- 전장 조건에 따라 축복과 저주가 내려올 수 있다.
- 인간과 괴물 모두 율의 전체 원리를 알지 못한다.
- 누가 율을 만들었는지와 최종 목적은 초반에 설명하지 않는다.
- 스테이지 제약과 수정자는 세계관에서 율의 축복·저주·선언으로 표현할 수 있다.

세계관은 긴 설명문보다 경계종, 전조 카드, 정찰관 보고와 짧은 전장 기록으로 암시한다.

### 3.3 룰렛과 토큰

룰렛과 토큰은 반드시 물리적인 마법 소환 장치로 설명하지 않는다.

- 플레이어 UI: 룰렛, 토큰, 릴, 완성 줄
- 세계관 표현: 전술판, 전력 표식, 증원 경로
- 병영 건설은 해당 병종의 모집·훈련·보급 경로를 확보하는 행위다.
- 게임은 복잡한 증원 가능성을 토큰과 확률로 압축해 보여준다.
- 병사들은 자신이 룰렛에서 마법처럼 소환되었다고 인식하지 않는다.

## 4. Dopamine Driven Design

게임은 시스템이 많아도 표면적으로 단순하고 즉각적으로 보상적이어야 한다.

모든 기능은 다음 순서로 검수한다.

```text
의도
→ 플레이어 경험·감정
→ 행동
→ 규칙
→ 보상·피드백
→ 다음 목표
```

### 4.1 시스템당 최초 습득 시간

- 새 시스템의 기본 사용법은 10~30초 안에 습득시키는 것을 목표로 한다.
- 한 문장 설명, 한 번의 직접 행동, 즉시 결과 확인으로 구성한다.
- 첫 노출에서 전체 예외와 고급 활용을 설명하지 않는다.
- 활용과 숙련은 이후 웨이브에서 반복적으로 익히게 한다.
- 첫 10분의 시스템 수보다 동시에 요구하는 새 개념의 수를 제한한다.

## 5. 첫 10분 구조

첫 10분은 느린 기능 설명이 아니라 짧은 학습과 즉시 보상을 연속으로 제공한다.

| 시간 | 경험 | 신규 학습 |
|---|---|---|
| 0:00~0:30 | 경계종과 첫 웨이브 징조 | 지휘관 역할·방어 목표 |
| 0:30~0:50 | 시간 정지 | 일시정지 계획 모드 |
| 0:50~1:20 | 병영 건설 | 건설 |
| 1:20~1:40 | 전사 토큰이 릴로 이동 | 건물·토큰 연결 |
| 1:40~2:10 | 첫 보장 룰렛 | 룰렛·한 줄 보상 |
| 2:10~2:35 | 위험 라인에 검사 배치 | 라인 배치 |
| 2:35~3:30 | 첫 교전과 횡베기 | 자동전투·스킬 피드백 |
| 3:30~3:55 | 두 번째 징조 판독 | 웨이브 전조 |
| 3:55~4:25 | 포탑 또는 바리케이드 | 전장 대응 수단 |
| 4:25~5:30 | 첫 전선 역전 | 선택 결과 체감 |
| 5:30~6:25 | 두 번째 건설·룰렛 조작 | 빌드 선택·통제 가능한 행운 |
| 6:25~6:50 | 첫 엘리트 | 등급과 스킬 강화 |
| 6:50~8:20 | 두 번째 종합 웨이브 | 핵심 루프 자율 연결 |
| 8:20~8:50 | Tier 2 병종 예고 | 다음 성장 목표 |
| 8:50~10:00 | 미니 위기와 방어 성공 | 핵심 루프 마무리 |

초기 PoC 목표:

- 첫 룰렛 2분 10초 이내
- 첫 교전 3분 30초 이내
- 선택에 의한 첫 역전 5분 30초 이내
- 시스템별 최초 습득 10~30초
- 첫 10분 안에 핵심 루프 약 2회 경험

## 6. 목표 플레이어 경험

- 운을 그대로 받아들이지 않고 건물 구성·전문화·이동권으로 확률을 설계한다.
- 적 웨이브의 라인·병종·수량을 읽고 상성, 포탑, 유닛, 전술 명령으로 대응한다.
- 일시정지 계획 모드로 빠른 손보다 판단과 준비를 우선한다.
- 시장·병영·포탑·용병 중심 등 서로 다른 빌드가 승리 경로를 갖는다.
- 적이 접근하는 동안 포탑이 간발의 차이로 완공되는 역전 장면을 만든다.
- 높은 등급 유닛은 강화·신규 스킬로 전투 장면을 바꾼다.
- 방어만 반복하지 않고 축적한 경제력을 공격으로 전환한다.

## 7. 핵심 플레이 루프

```text
금화·식량 확보
→ 건물 건설 또는 전문화 업그레이드
→ 생산 체계와 룰렛 토큰·확률 변화
→ 룰렛 회전 및 유닛·금화 획득
→ 룰렛 완성 줄로 유닛 병종·등급 결정
→ 상점 용병·아이템 구매 또는 전술 명령 사용
→ 대기 유닛을 상·중·하 라인에 배치
→ 접전지·시설 방어와 적 생산시설 공격
→ 웨이브 결과와 패배 원인 확인
→ 다음 건설·전문화 결정
→ 적 본진 파괴까지 반복
```

전투는 기본적으로 계속 진행된다. 플레이어는 언제든 일시정지해 시간 흐름만 멈추고 룰렛, 건설, 전술 명령, 유닛 배치와 상점 조작을 정상적으로 확정할 수 있다.

## 8. 프로토타입 제품 구조

- 첫 공개 프로토타입 목표 분량: 약 3시간
- 정규 스테이지 평균: 25~35분
- 핵심 수직 슬라이스: 10~15분
- 튜토리얼: 10~15분짜리 수동 설계 스테이지 1개

튜토리얼은 절차적으로 생성하지 않는다. 이후 정규 스테이지는 난이도 증가, 맵 변형과 특수 적 순차 등장으로 구성하며 결정론적 시드와 `StageManifest`를 사용한다.

튜토리얼 완료 후 공개형 플레이어 선택 제약을 해금한다. 기본 난이도와 제약은 별도 축이며 불가능한 조합은 시작 전에 차단하고 이유를 표시한다.

## 9. 승패와 장기전

- 적 본진 체력 0: 승리
- 플레이어 본진 체력 0: 패배
- 같은 시뮬레이션 틱에 양쪽 본진 파괴: 상호 파괴
- 시간 초과 즉시 패배는 사용하지 않음

일정 시간 안에 적 본진을 파괴하지 못하면 공개된 결전 웨이브가 출격한다.

초기 가설:

```text
T-5:00  결전 경보
T-1:00  최종 구성 강조
T-0:30  라인·병종·정확한 수량 공개
T-0:10  구성 확정
T=35:00 결전 웨이브 출격
```

결전 전에 적 생산시설을 파괴하면 대응 병종 증원량이 감소한다. 결전을 방어해도 적 본진이 남으면 강화 웨이브가 반복될 수 있다.

## 10. 게임 속도와 일시정지

- 일시정지
- 1배속
- 2배속

일시정지는 전투 시간의 흐름만 멈추는 계획 모드다.

일시정지 중 허용:

- 카메라와 정보 확인
- 룰렛 회전·행열 이동·결과 확정
- 결과 보관함 정리와 유닛 출전
- 유닛 배치·이동 명령
- 건설·업그레이드·철거·전문화
- 전술 명령 사용과 목표 지정
- 상점 새로고침과 구매

비용과 자원은 즉시 확정되지만 이동·공격·건설·생산·시전·지속시간·쿨다운·웨이브 타이머는 진행되지 않는다.

## 11. 전장 구조

- 상단·중단·하단 세 라인
- 플레이어 본진과 적 본진
- 양측 전방 거점
- 라인별 중앙 접전지
- 충분한 이동 구간

플레이어 한쪽 기준 건설 노드:

| 구역 | 수 | 특징 |
|---|---:|---|
| 본진 후방 | 6 | 안전한 경제·생산 공간 |
| 상단 전방 | 3 | 시설·포탑 가능, 공격 위험 |
| 중단 전방 | 3 | 시설·포탑 가능, 공격 위험 |
| 하단 전방 | 3 | 시설·포탑 가능, 공격 위험 |

전방 생산시설은 추가 생산 보너스 없이 전선 합류 거리가 짧다는 이점만 가진다.

## 12. 자원과 접전지

금화 사용처:

- 룰렛
- 건설·업그레이드
- 상점·용병·아이템
- 전술 명령

식량:

- 출전 중인 유닛이 사용
- 대기칸·결과 보관함 유닛은 미사용
- 농장 파괴로 초과 상태가 되어도 기존 출전 유닛을 제거하지 않음
- 초과 상태에서는 새 출전만 차단

각 라인의 접전지는 점령한 진영에 금화 수입을 제공한다. 양측이 함께 있으면 접전 상태로 진행과 수입을 멈춘다.

## 13. 건물 생명주기와 전문화

```text
Empty
→ Constructing
→ Active Tier 1
→ Tier 2 전문화
→ Tier 3 상위 세부 병종·심화·교리
→ Destroyed / Ruins / Empty
```

- 적이 있어도 건설·업그레이드 시작과 진행 가능
- 건설 중 공격받아 완공 전에 파괴될 수 있음
- 완공 전에는 생산·수입·토큰·포탑 공격 기능 없음
- 완료 순간 기능과 토큰 적용
- Tier 1 공통 기능, Tier 2 전문화, Tier 3 심화 구조

## 14. 병영과 공유 토큰

### 전사 계열

- Tier 1 검사
- Tier 2 방패병·대검병·광전사
- 향후 Tier 3 전사 세부 병종
- 모두 전사 토큰 공유

### 기병 계열

- Tier 2 기병
- Tier 3 중기병·충격기병
- 모두 기병 토큰 공유

### 궁병 계열

- Tier 2 궁병
- Tier 3 석궁병·대공궁병·연사궁병
- 모두 궁병 토큰 공유

### 창병 계열

- Tier 2 창병
- Tier 3 세부 병종 후속 확정
- 모두 창병 토큰 공유

같은 계열 병영 한 동은 각 릴에 공유 토큰 1개를 제공한다. 토큰 외형은 같지만 내부 원장은 출처 병영·Tier·실제 병종·패시브 단계를 보존한다.

높은 Tier 후보는 낮은 Tier 후보보다 높은 확률을 가진다. 초기 추천 가중치는 Tier 1/2/3 = 1/2/3이다.

## 15. 병영 Tier와 패시브 성장

| 출처 Tier | 핵심 패시브 구성 |
|---|---|
| Tier 1 | 패시브 1 기본형 |
| Tier 2 | 패시브 1 강화 + 패시브 2 생성 |
| Tier 3 | 패시브 1 추가 강화 + 패시브 2 강화 + 패시브 3 생성 |

이 규칙은 일반·엘리트·영웅·전설 모두에 적용한다. 출처 병영이 파괴되어도 이미 생성된 유닛의 패시브와 강화 단계는 유지한다.

## 16. 룰렛 등급과 스킬 성장

| 동일 심벌 완성 줄 | 등급 | 스킬 성장 |
|---:|---|---|
| 1줄 | 일반 | 1스킬 기본형 |
| 2줄 | 엘리트 | 1스킬 강화 |
| 3~7줄 | 영웅 | 강화된 1스킬 + 2스킬 생성 |
| 8줄·9칸 동일 | 전설 | 영웅 효과 + 2스킬 강화 + 3스킬 생성 |

- 수동 합성·처치 경험치·건물 Tier로 등급 상승 없음
- 병영 자동 생산은 항상 일반 등급
- 전설은 스테이지당 1회
- 이후 9칸 동일은 해당 계열 영웅 2명
- 일반은 선택된 출처의 실제 세부 병종
- 엘리트·영웅·전설은 계열별 고정 유닛

## 17. 룰렛 규칙

- 세로 릴 3개, 3×3 보드
- 기본 판정 줄은 중앙 가로줄
- 판정 줄 세 칸이 동일한 비-X 심벌일 때만 보상
- 판정 심벌의 가로·세로·대각선 완성 줄 수로 등급 결정
- 실제 토큰이 릴당 3개 미만이면 X 토큰으로 보충
- 건물 완공·파괴·전문화는 다음 회전부터 반영

금화 완성 줄:

| 줄 | 보상 |
|---:|---:|
| 1 | 실제 회전 비용의 75% |
| 2 | 200% |
| 3 이상 | 500% |

럭키 찬스:

- 기본 12%
- 실패당 +8%p
- 6회 실패 뒤 다음 회전 확정
- 자연 럭키 찬스와 이동권 동시 사용 가능
- 회전당 이동 횟수 상한 없음

전조:

- T-15: 집결 위치·경로
- T-5: 위험 라인과 카운트다운

보스 바리케이드 대응:

- 세로축 크게 베기: 바리케이드 뒤 밀집 병력 공격
- 두 패턴 모두 명확한 전조와 고정 범위 사용

## 22. UI 원칙

- 자주 확인하는 정보를 가장 잘 보이는 위치에 둔다.
- 같은 기능은 같은 위치·색·상호작용으로 처리한다.
- 새 기능의 첫 설명은 10~30초 안에 완료한다.
- 한 번에 강조하는 새 행동은 하나다.
- 설명 카드는 행동을 완료하면 자동 종료한다.
- 고급 수치와 예외는 상세 패널에 두되 중요한 비용·판정은 숨기지 않는다.
- 룰렛 당첨, 건설 완공, 유닛 등장, 상성 발동과 전선 역전에 시각·음향·수치 피드백을 함께 제공한다.

## 24. 주요 위험

- 룰렛 결과의 병종 출처 확률이 이해하기 어려울 수 있음
- Tier·등급·패시브·스킬 정보가 한 화면에 과밀해질 수 있음
- 10~30초 학습을 위해 설명을 줄이다 중요한 판정이 불명확해질 수 있음
- 첫 10분 시스템 전환이 지나치게 빨라질 수 있음
- 룰렛이 단순 슬롯 게임으로 오해받을 수 있음
- 경계의 율이 모든 게임 규칙을 억지로 설명하는 설정이 될 수 있음
- 높은 등급이 병종 상성과 건설 전략을 무시할 수 있음
- 시장·포탑·용병·전술 조합이 병영 빌드를 압도할 수 있음
- 비행과 대공이 특정 병종을 필수화할 수 있음
- 다수 유닛의 타기팅·경로·능력 검사 성능 문제
