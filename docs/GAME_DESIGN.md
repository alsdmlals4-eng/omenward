# Roulettebound 게임 기획서

- 문서 버전: **v0.9**
- 상태: 프리프로덕션 / 구현 전 디자인 프리즈 진행 중
- 장르: 실시간 3라인 전략 오토배틀 + 건물 기반 3×3 룰렛 빌드
- 기본 모드: 싱글플레이 PvE 비대칭 웨이브 전투
- 우선 플랫폼: Windows PC / 마우스·키보드
- 구현 엔진: Godot / GDScript

세부 책임 문서가 이 문서보다 더 최근인 경우 `docs/design/APPROVED_*.md`가 우선한다. 미확정 수치는 `docs/DECISIONS_PENDING.md`에서 관리한다.

## 1. 한 문장 소개

플레이어가 제한된 건설 노드에 시설을 짓고 전문화해 룰렛 토큰과 생산 체계를 설계하며, 획득한 병력과 금화 소모형 전술 명령을 상·중·하 전선에 배분해 예고된 적 웨이브를 막고 적 본진을 파괴하는 실시간 전략 오토배틀 게임.

## 2. 목표 플레이어 경험

- 운을 그대로 받아들이지 않고 건물 구성·전문화·이동권으로 확률을 설계한다.
- 세 라인의 전투와 접전지, 건설·업그레이드, 룰렛과 상점을 실시간으로 관리한다.
- 적 웨이브의 라인·병종·수량을 읽고 상성, 포탑, 유닛, 전술 명령으로 대응한다.
- 안전한 후방 경제와 위험한 전방 생산·방어 사이에서 노드 기회비용을 계산한다.
- 시장·병영·포탑·용병 중심 등 서로 다른 빌드가 실제 승리 경로를 갖는다.
- 적이 접근하는 동안 포탑이 간발의 차이로 완공되는 등 실시간 역전 장면을 만든다.
- 방어만 반복하지 않고 결전 웨이브 전에 축적한 경제력을 공격으로 전환한다.

## 3. 핵심 플레이 루프

```text
금화·식량 확보
→ 건물 건설 또는 전문화 업그레이드
→ 생산 체계와 룰렛 토큰·확률 변화
→ 룰렛 회전 및 유닛·금화 획득
→ 상점 용병·아이템 구매 또는 전술 명령 사용
→ 대기 유닛을 상·중·하 라인에 배치
→ 접전지·시설 방어와 적 생산시설 공격
→ 웨이브 결과와 패배 원인 확인
→ 다음 건설·전문화 결정
→ 적 본진 파괴까지 반복
```

전투는 기본적으로 계속 진행된다. 플레이어는 일시정지를 사용해 정보를 확인하고 명령을 예약할 수 있다.

## 4. 프로토타입 제품 구조

### 4.1 총 분량

- 첫 공개 프로토타입 목표 분량: 약 3시간
- 정규 스테이지 평균: 25~35분
- 핵심 수직 슬라이스: 10~15분
- 튜토리얼: 10~15분짜리 수동 설계 스테이지 1개

### 4.2 캠페인

- 튜토리얼은 절차적으로 생성하지 않는다.
- 이후 정규 스테이지는 난이도 증가, 맵 변형, 특수 적 순차 등장으로 구성한다.
- 정규 스테이지는 결정론적 시드와 `StageManifest`로 생성한다.
- 같은 시드·난이도·제약·생성기 버전은 같은 결과를 만든다.
- 생성 결과는 Validator를 통과해야 하며 실패 시 검증된 안전 스테이지를 사용한다.

### 4.3 제약 시스템

- 튜토리얼 완료 후 해금한다.
- 기본 난이도와 별개의 플레이어 선택형 추가 난이도다.
- 효과와 보상은 스테이지 시작 전에 공개한다.
- 불가능한 조합은 몰래 수정하지 않고 선택 단계에서 차단하고 이유를 표시한다.
- 보상은 점수·메달·기록을 우선하며 영구 전투력 보상은 초기 범위에서 제외한다.

## 5. 승패와 장기전

- 적 본진 체력 0: 승리
- 플레이어 본진 체력 0: 패배
- 같은 시뮬레이션 틱에 양쪽 본진 파괴: 상호 파괴
- 시간 초과 즉시 패배는 사용하지 않는다.

일정 시간 안에 적 본진을 파괴하지 못하면 공개된 `결전 웨이브`가 출격한다.

초기 가설:

```text
T-5:00  결전 경보
T-1:00  최종 구성 강조
T-0:30  라인·병종·정확한 수량 공개
T-0:10  구성 확정
T=35:00 결전 웨이브 출격
```

- 결전 웨이브는 세 라인, 공성·지원·지휘관형 적을 포함한다.
- T-10 전에 적 생산시설을 파괴하면 해당 병종 증원량이 감소한다.
- 결전을 막아도 적 본진이 남으면 2~3분 간격의 강화 웨이브가 반복될 수 있다.
- 결전은 강하지만 검증된 빌드로 방어 가능해야 한다.

## 6. 게임 속도

- 일시정지
- 1배속
- 2배속

일시정지 중 허용:

- 카메라 이동과 정보 확인
- 건설·업그레이드·철거 예약
- 유닛 출전 예약
- 룰렛·이동 계획
- 전술 명령 목표 예약

웨이브 출격 10초 전, 본진·시설 피격, 새 접전 발생, 식량·대기칸 문제 발생 시 2배속을 자동으로 1배속으로 되돌리는 방향을 유지한다.

## 7. 전장 구조

### 7.1 세 라인

- 상단
- 중단
- 하단

기본 거리 구조:

```text
플레이어 본진
→ 플레이어 전방 거점
→ 이동 구간
→ 중앙 접전지
→ 이동 구간
→ 적 전방 거점
→ 적 본진
```

### 7.2 건설 노드

플레이어 한쪽 기준 총 15개:

| 구역 | 노드 수 | 특징 |
|---|---:|---|
| 본진 후방 | 6 | 안전하지만 제한된 경제·생산 공간 |
| 상단 전방 | 3 | 시설·포탑 건설 가능, 공격 위험 |
| 중단 전방 | 3 | 시설·포탑 건설 가능, 공격 위험 |
| 하단 전방 | 3 | 시설·포탑 건설 가능, 공격 위험 |

- 한 노드에는 건물 하나만 존재한다.
- 중앙 접전지에는 건설하지 않는다.
- 전방 생산시설은 생산량 보너스 없이 전선 합류 거리가 짧다는 이점만 가진다.
- 후방 포탑 허용 여부는 미확정이다.

## 8. 중앙 접전지

각 라인에 중립 접전지 1개를 둔다.

기본 규칙:

- 한 진영만 범위 안에 있으면 점령 진행
- 양측이 함께 있으면 접전 상태로 진행 정지
- 적 소유 지점은 중립화 뒤 재점령
- 유닛 수에 따른 점령속도 보정은 초기 범위에서 제외
- 접전 중 해당 지점 수입 정지 방향
- 접전지 1개의 수입은 Tier 1 시장보다 낮게 유지
- 세 지점 독점 추가 보너스는 두지 않는 방향

## 9. 자원

### 9.1 금화

사용처:

- 룰렛 회전
- 건물 건설·업그레이드
- 상점 새로고침
- 용병·스킬북·장비·이동권·행운 아이템 구매
- 금화 소모형 전술 명령

획득처:

- 기본 수입
- 시장
- 룰렛 금화 보상
- 중앙 접전지

금화는 음수가 되지 않으며 대출·부채는 초기 범위에서 제외한다.

### 9.2 식량

- 출전 중인 유닛이 식량을 사용한다.
- 대기칸과 결과 보관함의 유닛은 식량을 사용하지 않는다.
- 농장 건설·전문화로 최대 식량을 늘린다.
- 농장 파괴로 최대치가 감소해도 이미 출전한 유닛은 제거하지 않는다.
- 한도 초과 상태에서는 새 유닛 출전만 막는다.
- 포탑과 전술 명령은 식량을 사용하지 않는다.

## 10. 건물 공통 생명주기

```text
Empty
→ Constructing
→ ActiveTier1
→ UpgradingToTier2
→ ActiveTier2Specialized
→ UpgradingToTier3
→ ActiveTier3Mastered

Active 또는 Upgrading
→ Demolishing
→ Empty

Constructing / Active / Upgrading / Demolishing
→ Destroyed
→ Ruins
→ Empty
```

### 10.1 전투 중 건설

적이 노드 주변에 있거나 건설 중 구조물을 공격해도 건설·업그레이드 진행은 멈추지 않는다.

- 적 존재는 건설·업그레이드 시작을 차단하지 않는다.
- 건설 중 구조물은 공격 가능한 목표다.
- 건설 중에는 수입·식량·생산·토큰·공격 기능이 없다.
- 완공되는 틱부터 정상 기능을 활성화한다.
- 완공 전에 체력 0이 되면 실패하고 환불 없이 폐허가 된다.
- 건설 중 시작 체력, 진행도별 체력과 길막 규칙은 미확정이다.

### 10.2 업그레이드 중 기능

- 비용은 시작 시 선불이다.
- 이전 Tier 기능과 기존 룰렛 토큰은 계속 유지한다.
- 피격 중에도 업그레이드 진행은 계속된다.
- 완료 순간 전문화 효과와 새 토큰 구성을 적용한다.
- 현재 진행 중인 룰렛 스냅샷은 바꾸지 않고 다음 회전부터 반영한다.

### 10.3 파괴·폐허·철거

초기 제안값:

- 적에게 파괴: 환불 없음
- 폐허: 15초
- 건설 취소: 비용 70% 환불
- 업그레이드 취소: 업그레이드비 50% 환불
- 완공 건물 철거: 5초, 기본 건설비 40% 환불
- 성공 철거: 폐허 없음
- 철거 중 파괴: 환불 없음, 폐허 발생
- 수동 수리와 자동 체력 재생: 초기 제외 제안

수치는 아직 최종 승인 대상이다.

## 11. 건물 Tier와 전문화

기존 완전 고정형 성장은 폐기하고 다음 구조를 사용한다.

```text
Tier 1: 공통 기본 기능
→ Tier 2: 역할·병종 전문화 선택
→ Tier 3: 선택 방향 심화 또는 전용 교리 선택
```

- 전문화는 해당 건물이 파괴·철거될 때까지 유지한다.
- 기본적으로 전문화를 되돌리려면 철거 후 재건설한다.
- 전문화 선택 전에 비용·시간·기능·토큰·확률 변화를 표시한다.

### 11.1 토큰 증폭

기본 토큰 제공 건물은 세 릴에 대응 토큰 1개씩을 제공한다.

토큰 증폭 전문화:

- 대응 토큰 1개를 세 릴 중 정확히 한 릴에만 추가한다.
- 릴은 스테이지 시드와 건물 인스턴스로 결정론적으로 선택한다.
- 선택 릴은 건물 수명 동안 고정되고 공개된다.
- 매 회전마다 다시 추첨하지 않는다.
- 파괴·철거 시 다음 회전부터 제거한다.

### 11.2 생산 유닛 강화

- 전문화 완료 뒤 해당 시설에서 생산되는 유닛에만 강화 적용
- 기존 유닛과 상점 용병에는 소급 적용하지 않음
- 생산 시 출처 건물과 강화 ID 기록
- 생산시설 파괴 뒤에도 이미 생산된 유닛의 강화 유지

## 12. 시설 목록

### 12.1 농장

- 최대 식량 증가
- 룰렛 토큰 없음
- 전문화 후보: 보급량, 내구도, 물류 보조
- 정확한 Tier별 식량과 전문화는 미확정

### 12.2 시장

- 지속 금화 수입
- 세 릴에 금화 토큰 1개씩 제공
- 시장 다수 건설과 고배율 금화 룰렛은 정식 전략
- 전문화 후보: 정기 수입, 금화 토큰 증폭, 상점·전술 소비 효율
- 시장 수입은 건물 수에 따른 자동 감쇠를 사용하지 않는다.

### 12.3 기본 병영

#### Tier 1

- 검사 생산
- 세 릴에 검사 토큰 1개씩 제공

#### Tier 2 병종 전문화

다음 중 하나를 선택한다.

| 선택 | 이후 생산 | 세 릴 기본 토큰 |
|---|---|---|
| 기병 | 기병 | 기병 |
| 창병 | 창병 | 창병 |
| 궁병 | 궁병 | 궁병 |

완료 시:

- 다음 생산부터 선택 병종 적용
- 검사 토큰을 선택 병종 토큰으로 교체
- 기존 검사 유닛은 변경하지 않음
- 생산 진행률은 보존하고 완료 뒤 첫 생산부터 새 병종 적용

#### Tier 3 교리 후보

- 대량생산: 생산 간격 감소
- 정예훈련: 생산 버프 또는 일정 주기 엘리트
- 토큰 증폭: 선택 병종 토큰을 한 릴에 추가

### 12.4 고급 생산시설

후속 또는 정규 스테이지 해금:

- 신전: 사제
- 아카데미: 마법사
- 도적 훈련시설: 도적·암살자

정확한 해금, 전문화와 토큰 계약은 별도 조정한다.

### 12.5 포탑

Tier 1은 단일 대상 원거리 포탑이다.

Tier 2 전문화 후보:

| 방향 | 기능 |
|---|---|
| 제압형 | 작은 범위 피해 또는 추가 대상 공격 |
| 요새형 | 체력·방어·피격 저항 강화 |
| 장거리형 | 사거리 강화 |

Tier 3은 선택 방향을 심화한다.

- 장거리형이 아닌 포탑은 접전지에 닿지 않는다.
- 장거리형 Tier 3만 접전지 가장자리에 제한적으로 영향을 줄 수 있다.
- 어떤 포탑도 접전지 전체를 영구 봉쇄해서는 안 된다.
- 포탑은 노드와 금화를 사용하지만 식량과 룰렛 토큰을 사용하지 않는다.

## 13. 훈련시설 생산과 Ready 슬롯

```text
생산 타이머 완료
→ 대기칸 또는 자동 출전 시도
→ 실패하면 시설 내부 Ready 슬롯에 보관
→ 슬롯이 비워질 때까지 다음 생산 정지
```

- Ready 슬롯 기본 제안: 시설당 1개
- Ready 유닛은 대기칸 이동, 즉시 출전 또는 판매 가능
- 시설 파괴 시 생산 진행도와 Ready 유닛 소멸
- 위험 상태를 UI로 경고

## 14. 건물 기반 룰렛

### 14.1 기본 구조

- 세로 릴 3개
- 각 릴에 3개 심벌을 표시해 3×3 보드 생성
- 기본 판정 줄은 가운데 가로줄
- 상·하단 판정은 아이템 효과로만 허용
- 세 릴은 현재 스냅샷 토큰 풀을 기준으로 독립적으로 회전

### 14.2 토큰 풀

완공된 토큰 제공 건물 1동은 각 릴에 대응 토큰 1개를 추가한다.

실제 토큰이 릴당 3개 미만이면 X 토큰으로 채운다.

```text
릴당 X 수 = max(0, 3 - 실제 토큰 수)
```

- X는 보상을 제공하지 않는다.
- 건물 완공·파괴·전문화는 다음 회전부터 반영한다.
- Tier 자체는 기본 토큰 수를 늘리지 않지만 토큰 증폭 전문화는 한 릴 보너스를 제공할 수 있다.
- 자신의 릴별 토큰 수와 확률은 숫자로 공개한다.

## 15. 룰렛 결과 판정

### 15.1 기본 보상 조건

판정 줄 세 칸이 동일한 비-X 심벌일 때만 보상한다.

```text
검사 / 검사 / 검사 → 검사 보상
검사 / 검사 / 기병 → 보상 없음
검사 / 기병 / 궁병 → 보상 없음
검사 / 검사 / X    → 보상 없음
```

### 15.2 완성 줄과 등급

판정 줄이 완성되면 같은 심벌로 구성된 가로 3·세로 3·대각선 2줄을 검사한다.

| 동일 심벌 완성 줄 | 유닛 보상 |
|---:|---|
| 1줄 | 1성 병사 1명 |
| 2줄 | 엘리트 1명 |
| 3~7줄 | 영웅 1명 |
| 8줄·9칸 전체 동일 | 전설 1명 |

- 전설은 한 스테이지에서 병종과 관계없이 1회만 소환한다.
- 전설 소환 뒤 다시 9칸 동일이 나오면 해당 병종 영웅 2명으로 변환한다.

### 15.3 금화

판정 줄이 금화 3개일 때 전체 금화 완성 줄 수를 센다.

| 금화 완성 줄 | 보상 |
|---:|---:|
| 1줄 | 실제 회전 비용의 75% |
| 2줄 | 실제 회전 비용의 200% |
| 3줄 이상 | 실제 회전 비용의 500% |

- 별도 회전 충전, 당첨 횟수 제한과 연속 감쇠는 사용하지 않는다.
- 시장 특화의 고수익은 병영 부족, 노드 점유, 식량, 용병·전술 소비와 결전 웨이브로 균형을 잡는다.

## 16. 럭키 찬스와 이동권

```text
기본 확률: 12%
실패 1회당: +8%p
6회 연속 실패 뒤 다음 회전: 100%
성공 뒤: 현재 기본 확률로 초기화
```

- 현재 확률과 확정까지 남은 횟수를 공개한다.
- 행운 아이템은 초기 기본 확률을 높인다.
- 자연 럭키 찬스는 무료 행·열 이동 1회를 제공한다.
- 이동권은 자연 발생 여부와 관계없이 함께 사용할 수 있다.
- 회전당 이동 횟수 상한은 없고 보유 이동권 수로 제한한다.
- 여러 이동을 계획하고 되돌리기·전체 초기화 후 최종 확정한다.
- 이동권은 최종 확정 시에만 소비한다.

## 17. 결과 보관함과 대기칸

- 룰렛 유닛 보상은 공간 부족으로 사라지지 않는다.
- 보상은 결과 보관함에 생성한다.
- 대기칸 이동, 즉시 출전 또는 판매로 정리한다.
- 보관함이 남아 있으면 다음 룰렛 회전만 차단한다.
- 전투·건설·카메라·기존 유닛 배치는 계속된다.
- 대기칸 기본 용량과 수동 합성 여부는 미확정이다.

## 18. 상점과 용병

- 용병은 상점에서 금화로 구매한다.
- 용병 구매는 룰렛 토큰을 추가하지 않는다.
- 일반 유닛과 동일하게 출전 시 식량을 사용한다.
- 즉시 확보할 수 있지만 장기 금화 효율은 병영 생산보다 낮게 조정하는 방향이다.
- 시장+포탑+용병은 정식 전략이다.
- 용병 병종·등급·가격·재고·갱신은 별도 확정한다.

## 19. 금화 소모형 전술 명령

전투 중 금화를 지불하고 짧은 전장 보조 효과를 사용한다.

초기 후보:

| 명령 | 역할 |
|---|---|
| 바리케이드 | 지정 지점에서 적 전진 지연 |
| 화살비 | 밀집 일반 병력에 즉시 광역 피해 |
| 역병 | 지속 피해와 치유 감소 |
| 강화지대 | 일정 구역 아군 유닛 강화 |

공통 원칙:

- 발동마다 금화 소비
- 식량·건설 노드·룰렛 토큰 미사용
- 일시정지 중 목표 예약 가능
- 범위·지속시간·예상 효과·비용 사전 표시
- 적 본진·생산시설을 직접 파괴하는 주 공격 수단이 아님
- 같은 효과의 무한 중첩 금지
- 개별 쿨다운과 짧은 전역 쿨다운을 검토

세부안은 `docs/design/proposals/0006-tactical-commands.md`에서 관리한다.

## 20. 병종과 상성

| 병종 | 역할 | 강점 | 약점 |
|---|---|---|---|
| 검사 | 전열·근접 | 궁병 압박, 안정적 전선 | 기병 |
| 기병 | 돌진·기동 | 검사·궁병 압박 | 창병 |
| 창병 | 대기병 | 기병 저지 | 궁병 |
| 궁병 | 후방 원거리 | 창병·느린 보병 | 검사·기병·도적 |
| 사제 | 회복·지원 | 전선 유지 | 도적, 낮은 단독 전투력 |
| 마법사 | 범위 화력 | 밀집 병력 | 도적, 낮은 체력 |
| 도적 | 후방 침투·단일딜 | 궁병·사제·마법사 | 전면전·광역 피해 |

기본 상성:

```text
기병 > 검사
창병 > 기병
궁병 > 창병
검사 > 궁병
기병 > 궁병
도적 > 궁병·사제·마법사
전면 근접 병력 > 도적
마법사 > 밀집 병력
```

## 21. 등급 밸런스 목표

- 엘리트 검사는 상성상 유리한 병사 기병에게 1대1에서 조금 밀린다.
- 엘리트 검사 1명은 병사 검사 2명보다 강하다.
- 영웅 1명은 엘리트 2명보다 강하다.
- 상성상 유리한 엘리트는 불리한 영웅을 이길 수 있다.

초기 상대 전투력 가설:

- 병사 1.0
- 엘리트 2.1
- 영웅 4.3
- 전설 수치 미확정
- 상성 유리 시 주는 피해 ×1.5, 받는 피해 ×0.65 초기 가설

## 22. 자동전투 기본 방향

- 유닛은 지정 라인에서 자동 이동·공격한다.
- 일반 유닛은 기본적으로 라인을 변경하지 않는다.
- 직접 조작보다 병종 구성, 출전 라인과 타이밍에 집중한다.
- 적 우선순위 기본안: 적 유닛 → 포탑 → 생산·경제시설 → 본진 방향 진행
- 도적·공성병 등은 역할에 따른 우선순위 예외를 가진다.
- 충돌, 라인 폭, 타깃 변경, 적 통과와 밀집 처리 규칙은 다음 디자인 프리즈 항목이다.

## 23. 적 AI와 웨이브

적은 플레이어처럼 룰렛을 돌리지 않는다.

- 적 건물 종류·Tier가 웨이브 구성을 강화한다.
- 적 본진은 외부 건물이 모두 파괴돼도 최소 병력을 제공한다.
- 전방 시설은 해당 라인 출격 위치를 전진시킬 수 있다.
- 기본 구현은 실제 적 생산 시뮬레이션보다 데이터 기반 웨이브 계산을 우선 검토한다.

### 23.1 전조

| 시점 | 정보 |
|---|---|
| T-30 | 라인·병종·정확한 수량 |
| T-15 | 집결 위치·경로 |
| T-5 | 카운트다운·위험 라인 강조 |
| T-0 | 출격 |

- T-10을 웨이브 구성 확정 시점 기본안으로 둔다.
- 확정 전 적 시설 파괴는 현재 웨이브를 줄일 수 있다.
- 확정 후 파괴는 다음 웨이브부터 적용한다.
- 치명적인 공성·침투·특수 공격은 반드시 사전 경고한다.

### 23.2 특수 적 후보

- 공성병: 포탑·시설 우선 공격
- 돌격병: 빠른 전열 돌파
- 지원병: 주변 적 회복·강화
- 침투병: 후방 경제·생산시설 공격
- 지휘관형: 고유 패턴과 강한 전조

## 25. 튜토리얼

10~15분 단일 고정 스테이지에서 기능의 연결만 짧게 소개한다.

추천 흐름:

```text
카메라·속도
→ 첫 시장·병영 건설
→ 토큰 변화와 룰렛
→ 유닛 배치
→ 웨이브 전조와 상성
→ 적 접근 중 포탑 완공
→ 병영 Tier 2 전문화
→ 접전지
→ 바리케이드 또는 화살비 1회
→ 짧은 종합 웨이브
```

- 설명은 1~2문장
- 기능마다 필수 행동 1회
- 실수 시 즉시 패배보다 보충 자원과 짧은 안내
- 안내 건너뛰기와 다시 보기 제공
- 특수 적과 나머지 전술 명령은 정규 스테이지에서 도입

## 29. 주요 위험

- 건설 중 구조물을 반복 배치해 적을 부당하게 막는 악용
- 한 릴 토큰 증폭과 이동권 다중 사용이 룰렛을 지나치게 결정적으로 만드는 문제
- 시장 수익·금화 룰렛·용병·전술 명령 조합이 다른 빌드를 압도하는 문제
- 포탑 장거리·제압 전문화가 접전지를 영구 봉쇄하는 문제
- 병영 전문화 전환 시점과 생산 진행률이 이해하기 어려운 문제

- 세 라인, 전조, 룰렛, 건설, 전문화 UI의 정보 과부하
- 다수 유닛의 경로 탐색과 타기팅 성능
