## 1. 한 문장 소개

플레이어는 루메른 왕국 트리븐 전선의 지휘관이 되어 건물로 룰렛 확률과 증원 체계를 설계하고, 베일의 법칙에 따라 베일런 황야에서 넘어오는 공세를 세 전선에서 막아낸다.

## 2. 핵심 재미

> **다음 공세를 미리 읽고 건물과 룰렛 확률을 설계한 뒤, 당첨된 병력과 전술로 무너지는 전선을 간발의 차이로 뒤집는다.**

핵심 감정:

- 예고된 위험을 읽는 긴장.
- 제한된 자원으로 빌드를 선택하는 고민.
- 룰렛 결과를 조작해 원하는 병력을 얻는 기대.
- 적절한 라인 배치와 건설이 즉시 전황을 바꾸는 만족.
- 거점과 성문을 밀고 당기는 전선 변화.

## 3. 핵심 루프

```text
베일의 징조 확인
→ 건물·토큰·전술 선택
→ 3×3 룰렛 회전·조작
→ 병력 획득·대기
→ 상·중·하 라인 배치
→ 자동 교전과 전술 개입
→ 접전지·중간거점 공방
→ 암살자 우회 또는 성문 공성
→ 다음 공세 준비
```

- 첫 10분 안에 건설→룰렛→배치→역전 루프를 두 번 체험한다.
- 새 시스템은 한 문장 설명, 한 번의 행동, 즉시 결과로 10~30초 안에 기본 사용법을 익힌다.
- 정보는 설명 메뉴보다 실제 전장, 벨루, 베일의 징조와 조작 미리보기로 전달한다.

## 3.1 현재 구현 경계

프로젝트 코어와 실제 구현 상태는 다음 문서를 따른다.

- `docs/PROJECT_CORE.md`
- `docs/CURRENT_IMPLEMENTATION_STATUS.md`

현재 판정:

```text
TECHNICAL_BASELINE_IMPLEMENTED
+ CORE_VERTICAL_SLICE_PARTIAL
+ CORE_LOOP_NOT_PROVEN
+ HUMAN_QA_NOT_RUN
```

이 기획서의 전체 설계와 승인된 초기값이 모두 현재 실행 코드로 완결됐다는 뜻이 아니다. 실제 구현 여부는 상태 문서와 코드·데이터·테스트를 대조한다.

## 4. 세계관

| 대상 | 공식 명칭 |
|---|---|
| 국가 | 루메른 왕국 |
| 인간 생활권 | 루미엔 영토 |
| 전선 | 트리븐 전선 |
| 첫 요새 | 실베른 성채 |
| 괴물 영역 | 베일런 황야 |
| 세계 규칙 | 베일의 법칙 |
| 괴물 분류 | 베일종 |
| 안내자 | 벨루 |

룰렛은 UI 용어다. 세계관에서는 전술판, 전력 표식, 증원 경로로 가볍게 번역한다. 병사는 자신이 룰렛에서 생성됐다고 인식하지 않는다.

## 5. 벨루

벨루는 실베른 성채 경계종의 울림에서 태어난 작은 감시 정령이다.

- 세계관 설명, 적 보고, 튜토리얼, 전술 요약, 감정 반응을 담당한다.
- 우측 하단 48~64px 도크와 최대 두 줄 대사를 사용한다.
- 위험·보스·축복·저주·등급 반응은 0.5~2초 뒤 기본형으로 복귀한다.
- 정확한 숫자와 지속 상태는 HUD가 표시한다.
- 이미 배운 설명은 짧은 재방문 문구로 축소한다.

## 6. 전장 구조

전장은 좌우 대칭의 독립된 상·중·하 3라인으로 구성한다.

```text
아군 본진
→ 라인별 아군 성문
→ 아군 중간거점
→ 중앙 접전지
→ 적 중간거점
→ 라인별 적 성문
→ 적 본진
```

### 불변 조건

- 상·중·하 라인은 일반 도로로 서로 연결하지 않는다.
- 중앙 접전지는 해당 라인의 앞뒤 길에만 연결하고 건설할 수 없다.
- 기본 유닛은 배치된 라인을 변경하지 않는다.
- 각 본진 진입부에는 라인별 성문 3개가 있다.
- 각 중간거점에는 전방 건설 노드 2개와 후방 건설 노드 1개가 있다.
- 중간거점 점령 시 건설권과 기본 생산권이 점령 진영으로 이전된다.
- 암살자는 적 후방에 직접 배치하지 않고 같은 라인의 안개 우회로로 침투한다.
- 전장이 기본 전략 줌에서 한눈에 보이므로 별도 미니맵을 사용하지 않는다.
- 건설 노드와 최대 크기 건물은 주 도로를 막지 않는다.

### 중간거점 PoC 초기값

```text
중립화 10초 + 점령 10초 at 점령력 1.0
최대 유효 점령력 2.0
진행 유지 3초
복귀 속도 초당 10%
점령 완료 후 안정화 5초
소유 수입 금화 +2 / 30초
```

- 방패·수호형 점령력 1.25.
- 일반 근접·기병 1.0.
- 원거리·지원·거인 0.5.
- 암살자·비행·순수 공성 병기 0.
- 점령 시도 중 생산·신규 건설·업그레이드 정지.
- 중립화 시 기존 건물 비활성.
- 점령 완료 시 기존 건물은 환불 없이 폐허화.
- 5초 안정화 후 새 소유자의 노드와 생산 활성.

### 성문 PoC 초기값

```text
HP 5000
방어 80
마법저항 80
일반 구조물 피해 40%
공성 태그 피해 200%
고정 피해 50%
붕괴 2초
```

- 같은 진영은 통과하고 적은 파괴 전까지 차단된다.
- 군중제어·밀쳐내기·비율 피해에 면역이다.
- 폐허는 이동을 막지 않는다.
- 수직 슬라이스에서는 수리·재건하지 않는다.
- 세 라인의 성문 상태는 독립적이다.

### 암살자 우회 PoC 초기값

```text
진입 준비 1초
우회 이동 9초
도착 2.5초 전 수비 측 경고
출현 준비 0.6초
적 중간거점에서 본진 방향 120 units
도착 영역 160 × 120 units
막힘 보정 반경 80 units
점령력 0
```

- 진입 확정 후 취소·후퇴할 수 없다.
- 우회 중 전투·점령·피격·버프 판정이 없다.
- 경로는 암살자 선택·배치 중에만 보인다.
- 탐지 전용 건물은 수직 슬라이스 범위에서 제외한다.

### 스케일 첫 가설

- PoC 맵 2,880×1,280 world units.
- 일반 이동속도 기준 60.
- 기본 포탑 사거리 270.
- 주 도로 폭 200~240.
- 중간거점·성문 전방 240~320 world units.

## 7. 공용 10병종 데이터 구조

### 핵심 결정

오멘워드에는 전투 데이터 기준 **10개의 공용 병종 아키타입만 존재한다.**

```text
공용 UnitArchetype 10개
+
아군 이미지 세트
+
적군 이미지 세트
+
owner_team_id
+
출격 방식
```

별도 아군 10개 + 적군 10개의 스탯·스킬·애니메이션 데이터 세트를 만들지 않는다.

### 공유하는 데이터

- HP, 공격력, 방어, 마법저항.
- 이동속도, 사거리, 공격 주기.
- 역할 태그와 타기팅.
- 스킬·패시브.
- Tier·등급 적용.
- 점령력과 구조물 피해.
- 이동·공격·피격·사망 애니메이션 상태.
- 공격 판정·투사체 생성 이벤트 타이밍.

### 진영별로 달라지는 것

- 소유 팀과 적대 관계.
- 아군 배치·룰렛 생산 또는 적 웨이브 출격.
- 스프라이트·초상화·아이콘·팔레트.
- 세계관 표시명과 설명.

첫 PoC에서는 진영별 VFX·오디오 복제도 하지 않는다. 가독성 검증에서 필요성이 확인될 때만 표현 override를 검토한다.

### 런타임 조합

```text
UnitArchetypeProfile
+ TierProfile
+ RankProfile
+ owner_team_id
+ visual_faction_id
= UnitInstance
```

- `owner_team_id`는 공격 대상, 점령, 승패를 결정한다.
- `visual_faction_id`는 이미지를 결정하며 능력치를 바꾸지 않는다.
- 적 웨이브는 같은 `archetype_id`에 enemy 팀과 veil 이미지 세트를 지정한다.
- 별도 `EnemyUnitProfile`을 만들지 않는다.

책임 원본: `docs/design/APPROVED_SHARED_UNIT_ARCHETYPE_AND_FACTION_VISUAL_DATA_V1.md`

## 8. 공용 10병종

### 기본 병영 6종

1. **방패병** — 범용 전열·원거리 대응.
2. **대검전사** — 정면 범위·파쇄·격노.
3. **암살자** — 같은 라인의 안개 우회로를 통해 적 후열·후방 시설 침투.
4. **창병** — 돌진·대형 저지.
5. **궁병** — 지속 원거리·대공.
6. **기병** — 기동·돌진·후열 압박.

### 특수병단 4종

1. **사제** — 치유·버프.
2. **마법사** — 광역 마법·제어.
3. **비행병** — 지상 전열 우회·후열 압박.
4. **거인** — 높은 범위 공격·체력·방어·공성.

각 계열은 일반·엘리트·영웅·전설 고정 능력 계보를 가진다. 플레이어 신화급은 없다.

### 적군 표시 예시

| 공용 아키타입 | 아군 표시 | 적군 이미지·표시 후보 |
|---|---|---|
| 방패병 | 방패병 | 베일 갑각수 |
| 대검전사 | 대검전사 | 균열도살자 |
| 암살자 | 암살자 | 그림자갈퀴 |
| 창병 | 창병 | 가시창병 |
| 궁병 | 궁병 | 침사수 |
| 기병 | 기병 | 균열기수 |
| 사제 | 사제 | 베일 표식자 |
| 마법사 | 마법사 | 공허주술사 |
| 비행병 | 비행병 | 베일익수 |
| 거인 | 거인 | 파성거체 |

적군 표시명은 로컬라이징 별칭이며 새로운 전투 데이터가 아니다.

## 9. 병종 애니메이션·전투 연출

### 공통 상태

```text
deploy
idle
move
attack_basic
skill_1
hit_light
death
victory
```

역할별 추가:

- 점령 가능 병종: `capture`.
- 암살자: `bypass_enter`, `bypass_exit`.
- 기병: `charge`, `turn_recover`.
- 비행병: 상승, 순항, 급강하, 공중 회복.
- 거인: `structure_attack`, `heavy_stagger`.
- 사제·마법사: 필요한 경우 지속 시전.

### 공격 계약

```text
준비 Anticipation
→ 판정 Active
→ 회복 Recovery
```

- 무기 접촉·투사체 발사와 실제 판정은 한 애니메이션 프레임 이내로 맞춘다.
- 이동은 코드가 위치를 소유하며 루트 모션으로 전투 위치를 결정하지 않는다.
- 가벼운 연속 피격은 큰 경직 대신 짧은 플래시·미세 반동을 사용한다.
- 대검·기병·거인은 준비와 회복으로 무게를 표현한다.

### 공용 모션·진영 이미지

10개 아키타입마다 상태·프레임·이벤트 타이밍 계약을 하나만 만든다.

- 아군 이미지 시트와 적군 이미지 시트는 같은 상태 목록, 프레임 수, 배열, 피벗, 이벤트 프레임을 사용한다.
- 적군 10병종의 모션을 별도 기획하거나 별도 상태 머신으로 제작하지 않는다.
- 이미지 실루엣과 소재는 진영별로 다르지만 판정과 타이밍은 같다.

### 승리 단계

- 개별 처치: 승리 모션 없음.
- 웨이브 정리: 0.4~0.8초 무기 정리·호흡.
- 중간거점 점령: 참여 유닛 0.6~1.0초 확인 동작.
- 성문 파괴: 0.5초 이내 짧은 반응.
- 스테이지 승리: 2.5~4.0초 병종별 승리→벨루→결과 UI.

## 10. 정규 스테이지와 공세 시계

- 활성 전투 시간 약 15분.
- `wave_collision_time = wave_index × 60초`.
- 이전 공세가 남아 있어도 다음 공세가 진입한다.
- 일반 징조 T-30/T-15/T-5.
- W15 보스는 T-60부터 예고한다.

| 웨이브 | 이정표 |
|---:|---|
| 1~4 | 일반 중심 |
| 5 | 엘리트 핵심 유닛 |
| 10 | 영웅 핵심 유닛 |
| 15 | 전설 보스, 표준 승리 |
| 16~19 | 초과 공세 |
| 20 | 적군 전용 신화 보스 패키지 |

- 적 본진을 W15 이전에 파괴하면 조기 승리.
- W20 진입은 즉시 패배가 아니라 사실상 절멸 공세.

## 11. 적 웨이브

일반 적 웨이브는 공용 10병종을 다음 값으로 조합한다.

```text
archetype_id
+ Tier
+ Rank
+ count
+ lane_id
+ spawn_time
+ owner_team_id = enemy
+ visual_faction_id = veil
```

- W1~15 Threat 첫 곡선 6→85.
- W16~20 Threat 첫 곡선 100→250.
- 난이도는 수량, Tier, 등급, 라인, 출격 시간으로 만든다.
- 일반 적군 전용 숨은 능력치·스킬·AI 데이터는 사용하지 않는다.
- 적 생산시설 파괴는 아직 출격하지 않은 현재·다음 공세의 해당 아키타입을 감소시킨다.

### 보스

W15 전설과 W20 신화 보스는 다음 구조를 사용한다.

```text
공용 base_archetype_id
+ BossBehaviorPackage
+ BossPhaseProfile
+ 전용 Visual Set
```

- W15: 직선 돌파, 대단절, 진군.
- W20: 끝나지 않는 진군과 2페이즈.
- 보스 패키지는 일반 병종 데이터를 복제하지 않는다.

책임 원본: `docs/design/APPROVED_SHARED_ARCHETYPE_WAVE_1_20_POC_V1.md`

## 12. 건물과 생산

### 기본 병영

```text
Tier 1
검사 자동생산 + 전사 토큰

Tier 2
방패병 / 대검전사 / 암살자 / 창병 / 궁병 / 기병

Tier 3
상위 세부 병종 1개 + 운영 교리 1개
```

- 방패병·대검전사는 전사 토큰을 공유한다.
- 암살자·창병·궁병·기병은 독립 토큰을 사용한다.
- 자동생산은 일반 등급만 생성한다.

### 특수병단

```text
Tier 1
금화 40 / 건설 25초
토큰·생산 없음
30초마다 Tier 2 비용 -10%
150초에 최대 -50%

Tier 2
사제단 / 마도단 / 비행단 / 거인단
토큰 활성 + 일반 자동생산
```

| 특수병종 | 생산시간 | 식량 |
|---|---:|---:|
| 사제 | 180초 | 3 |
| 마법사 | 210초 | 3 |
| 비행병 | 240초 | 4 |
| 거인 | 300초 | 6 |

건물 Tier는 생산량, 속도, 품질과 전투 성능을 강화하지만 룰렛 토큰 수는 **완공된 건물 개수**로 계산한다.

## 13. 자원과 경제

```text
시작 금화 160
시작 식량 12
기본 수입 20초마다 +5
중앙 접전지 60초마다 소유 지점당 +4
중간거점 30초마다 소유 지점당 +2
기본 룰렛 20
```

- 중간거점 점령 시 생산과 건설권이 점령 진영으로 이전된다.
- 점령 시도·교착·중립 상태에서는 거점 생산이 정지한다.
- 점령 완료 뒤 5초 안정화 후 새 소유자의 생산이 시작된다.
- 적 처치·웨이브 클리어 고정 금화는 없다.
- 시장 50, 농장 35, 포탑 35, 기본 병영 40, 특수병단 40 첫 기준.
- 시장은 20초마다 +4, 다중 시장 비용은 증가한다.
- 일시정지 중 모든 시간 기반 수입·생산·공세 시계가 정지한다.

## 14. 룰렛

- 3×3 결정론적 보드.
- 중앙 가로줄의 동일 비-X 심벌 3개가 보상 판정의 선행 조건.
- 선행 조건이 성립한 심벌만 전체 가로·세로·대각선 8개 완성선을 계산.
- 결과는 보드 9칸이 아니라 최종 보상 1개를 기본으로 생성.

| 완성 줄 | 등급 |
|---:|---|
| 1 | 일반 |
| 2 | 엘리트 |
| 3~7 | 영웅 |
| 8·9칸 동일 | 전설 |

- 전설은 스테이지당 1회, 이후 9칸 동일은 영웅 2기.
- 상위 등급은 룰렛으로만 생성.
- 럭키 기본 12%, 실패당 +8%p, 6회 실패 뒤 확정.
- 결과 보관함 기본 3칸.
- 금화 1/2/3줄 이상은 15/40/100 지급.
- 금화 장기 평균 지급 목표는 회전비의 30% 이하.
- 기본 병영은 전사 토큰을 제공하고 농장·포탑은 유닛 토큰을 제공하지 않는다.
- 생성 유닛은 StageRun 보관함에 들어가며 보관 중에는 다음 룰렛 회전만 차단한다.
- 이동권 보상량·럭키 최종 해석·고정 상위 등급 템플릿은 미확정 경계를 유지한다.

## 15. Tier와 등급

```text
Tier
→ 생산시설 성장·전문화·패시브

등급
→ 일반·엘리트·영웅·전설 스킬 생성·강화
```

| Tier | 패시브 |
|---|---|
| T1 | 패시브 1 기본 |
| T2 | 패시브 1 강화 + 패시브 2 |
| T3 | 패시브 1·2 강화 + 패시브 3 |

| 등급 | 스킬 |
|---|---|
| 일반 | 스킬 1 |
| 엘리트 | 강화 스킬 1 |
| 영웅 | 강화 스킬 1 + 스킬 2 |
| 전설 | 강화 스킬 1·2 + 스킬 3 |

같은 아키타입·Tier·등급은 진영과 무관하게 같은 전투 데이터를 사용한다.

## 20. UI·아트·오디오

### 화면

- 기준 출력 1920×1080.
- 내부 960×540 정수 확대 후보.
- 기본 전략 줌에서 양측 본진과 세 라인 전체 확인.
- 별도 미니맵 없음.
- 실제 전장 위 성문·중간거점·접전지 상태 표시.
- 룰렛 좌하단, 건설·용병·전술 하단, 벨루 우하단.

### 아트

- 클린 전술 픽셀.
- 미니어처 치비 약 2.5~3등신.
- 고해상도 픽셀의 재질·조명 완성도.
- 병종은 무기·자세·몸통·이동 리듬으로 식별.
- 색상만으로 병종·진영·등급을 구분하지 않는다.
- 상위 등급은 실루엣 부속, 무기, 문양, 짧은 VFX로 표현.

### 진영 이미지

- 공용 아키타입과 모션 계약에 아군·적군 이미지 세트를 연결한다.
- 아군: 수직선·아치·방패·종·천 배너.
- 적군 이미지: 비대칭 균열·갑각·가시·공허 구조.
- 이미지는 다르지만 상태, 프레임 수, 피벗, 공격 이벤트 타이밍은 같다.

### 오디오

- 기본 전투는 낮은 현악·타악·종 모티프.
- W5·W10·W15에서 밀도 증가.
- 룰렛 등급별 음정 단계 상승.
- 벨루는 맑은 두 음 종 모티프.
- 숫자 정보는 음성보다 HUD 우선.
