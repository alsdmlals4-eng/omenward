# 오멘워드 게임 기획서

- 공식명: **오멘워드 / OMENWARD**
- 문서 버전: **v0.12**
- 상태: 프리프로덕션 / 구현 전 디자인 프리즈 진행 중
- 장르: 실시간 3라인 전략 오토배틀 + 건물 기반 3×3 룰렛 빌드
- 기본 모드: 싱글플레이 PvE 비대칭 웨이브 전투
- 우선 플랫폼: Windows PC / 마우스·키보드
- 구현 엔진: Godot / GDScript

세부 규칙은 `docs/design/APPROVED_*.md`가 우선한다. 미확정 수치는 `docs/DECISIONS_PENDING.md`에서 관리한다.

## 1. 한 문장 소개

플레이어는 루메른 왕국 트리븐 전선의 지휘관이 되어 건물로 룰렛 확률과 증원 체계를 설계하고, 베일의 법칙에 따라 베일런 황야에서 넘어오는 괴물 군단을 세 전선에서 막아낸다.

## 2. 핵심 재미

> 건물을 지어 룰렛 확률을 바꾸고, 당첨된 병력으로 예고된 위기를 뒤집는다.

```text
베일의 징조 확인
→ 필요한 건물·병종·전술 선택
→ 룰렛 토큰과 확률 변화
→ 룰렛 회전과 병력 획득
→ 필요한 라인에 배치
→ 상성과 전술로 전선 역전
→ 다음 Tier·등급·병종 목표
```

핵심 감정은 긴장, 판단, 기대, 당첨 쾌감, 통제감, 역전과 성장 기대의 순서로 연결한다.

## 3. 세계관

### 3.1 공식 명칭

| 대상 | 명칭 |
|---|---|
| 국가 | 루메른 왕국 |
| 인간 생활권 | 루미엔 영토 |
| 첫 요새 | 실베른 성채 |
| 세 라인 전선 | 트리븐 전선 |
| 괴물 영역 | 베일런 황야 |
| 경계 현상 | 베일 |
| 세계 규칙 | 베일의 법칙 |
| 괴물 공식 분류 | 베일종 |
| 방위 조직 | 루메른 경계군 |
| 플레이어 부대 | 실베른 수비대 |
| 마스코트·안내자 | 벨루 |

### 3.2 플레이어

플레이어는 직접 전투하는 영웅보다 전체 전선을 책임지는 지휘관이다.

- 건설과 업그레이드
- 병력 획득과 출전 라인 결정
- 적 공세 분석
- 전술 명령 사용
- 공격·방어 우선순위 결정
- 베일런 측 적 시설과 본진 반격

괴물 군단이 최종 방어선을 넘으면 루미엔 영토가 공격받는다.

### 3.3 베일의 법칙

괴물은 계속 밀려오는 것이 아니라 정체불명의 베일의 법칙에 따라 경계 공세 단위로 넘어온다.

- 공세 전에는 라인·병종·수량을 예측할 수 있는 징조가 나타난다.
- 전장 조건에 따라 축복·저주가 나타날 수 있다.
- 인간과 괴물 모두 법칙의 전체 원리를 알지 못한다.
- 누가 만들었는지와 목적은 초반에 설명하지 않는다.
- 스테이지 제약과 수정자는 베일의 축복·저주·선언으로 표현할 수 있다.
- 세계관 원인은 암시하지만 게임 효과와 수치는 HUD에 정확히 공개한다.

### 3.4 룰렛과 토큰

룰렛과 토큰은 반드시 물리적인 소환 장치로 설명하지 않는다.

- 플레이어 UI: 룰렛, 토큰, 릴, 완성 줄
- 세계관 표현: 전술판, 전력 표식, 증원 경로
- 병영 건설은 모집·훈련·보급 경로를 확보하는 행위
- 게임은 복잡한 증원 가능성을 토큰과 확률로 압축해 표시
- 병사는 자신이 룰렛에서 마법처럼 소환되었다고 인식하지 않음

## 4. 벨루

벨루는 실베른 성채의 오래된 경계종 울림에서 태어난 작은 감시 정령이다.

담당:

- 세계관 설명
- 라인·병종·수량·시간 보고
- 튜토리얼 안내
- 전술 선택지 요약
- 베일의 법칙 암시
- 룰렛·역전 감정 반응

정찰관과 부관은 별도 기능성 안내 NPC로 두지 않는다. 정확한 숫자와 지속 상태는 HUD, 짧은 감지와 보고는 벨루가 담당한다.

벨루는 경고등처럼 0.5~2초 상태색과 문양을 보여준 뒤 기본 청백색 외형으로 돌아간다. 지속 상태는 HUD 아이콘과 타이머로 표시한다.

## 5. Dopamine Driven Design

게임은 시스템이 많아도 표면적으로 단순하고 즉각적으로 보상적이어야 한다.

모든 기능은 다음 순서로 검수한다.

```text
의도
→ 플레이어 경험·감정
→ 행동
→ 규칙
→ 보상·피드백
→ 다음 목표
```

- 새 시스템의 기본 사용법은 10~30초 안에 습득시키는 것을 목표로 한다.
- 한 문장 설명, 한 번의 직접 행동, 즉시 결과 확인으로 구성한다.
- 첫 노출에서 전체 예외와 고급 활용을 설명하지 않는다.
- 활용과 숙련은 이후 공세에서 반복적으로 익힌다.
- 시스템 수보다 동시에 요구하는 새 개념 수를 제한한다.

## 6. 첫 10분

| 시간 | 경험 |
|---|---|
| 0:00~0:15 | 실베른 성채·지휘관 역할·첫 베일의 징조 |
| 0:15~0:35 | 일시정지 계획 모드 |
| 0:35~1:05 | 첫 병영·전사 토큰 |
| 1:05~1:45 | 고정 1줄 룰렛·일반 검사 |
| 1:45~2:15 | 상단 배치 |
| 2:15~3:10 | 첫 공세·횡베기 |
| 3:10~5:15 | 포탑 또는 바리케이드·첫 역전 |
| 5:15~5:45 | 이동권으로 1줄→2줄·엘리트 |
| 5:45~7:20 | 엘리트 강화·두 번째 핵심 루프 |
| 7:20~8:10 | Tier 2 전사 병종 선택 |
| 8:10~9:20 | 선택 병종 즉시 체험 |
| 9:20~10:00 | 베일런 적 시설과 다음 성장 예고 |

목표:

- 첫 룰렛 1분 45초 이내
- 첫 교전 3분 10초 이내
- 첫 선택 역전 5분 15초 이내
- 첫 엘리트 5분 45초 이내
- Tier 2 선택 8분 10초 이내
- 핵심 루프 두 번 10분 이내

## 7. 전장 구조

- 상단·중단·하단 3라인
- 각 라인 중앙에 접전지 1개
- 플레이어 후방 노드 6개
- 라인별 전방 노드 3개
- 중앙 접전지에는 건설 불가
- 전방 시설은 생산량 보너스 없이 전선 합류 거리만 짧음

기본 거리:

```text
실베른 성채 본진
→ 플레이어 전방 거점
→ 이동 구간
→ 중앙 접전지
→ 이동 구간
→ 적 전방 거점
→ 적 본진
```

## 8. 자원

### 금화

사용처:

- 룰렛 회전
- 건설·업그레이드
- 상점과 용병
- 이동권·행운·장비
- 전술 명령

획득처:

- 기본 수입
- 시장
- 금화 룰렛
- 접전지

### 식량

- 출전 중 유닛만 사용
- 대기칸과 결과 보관함은 미사용
- 농장으로 최대치 증가
- 농장 파괴 뒤 한도 초과 시 기존 유닛 유지, 신규 출전만 차단
- 포탑과 전술 명령은 식량 미사용

## 9. 일시정지 계획 모드

일시정지는 전투 시간만 멈춘다.

허용:

- 룰렛과 결과 확정
- 유닛 생산·배치·이동 명령
- 건설·업그레이드·철거
- 전술 명령 사용과 목표 지정
- 전문화와 상점 구매
- 공세 정보 확인

자원은 즉시 차감·확정된다. 이동·공격·생산·건설·시전·지속시간·쿨다운·공세 타이머는 재개 전까지 진행되지 않는다.

## 10. 건물 성장

```text
Tier 1: 공통 기본 기능
→ Tier 2: 병종·역할 전문화
→ Tier 3: 상위 세부 병종 + 운영 교리
```

- 적이 있어도 건설·업그레이드 진행
- 건설 중 공격받고 완공 전에 파괴 가능
- 건설 시작 체력 초기 제안 25%
- 누적 피해 절대값 보존
- 일반 건물은 이동을 하드 차단하지 않음
- 바리케이드만 적 이동 차단

### 병영

Tier 1:

- 검사 생산
- 전사 토큰 제공

Tier 2 전사:

- 방패병
- 대검병
- 광전사

Tier 2 다른 계열:

- 기병
- 창병
- 궁병

Tier 3 예시:

- 기병 → 중기병·충격기병
- 궁병 → 석궁병·대공궁병·연사궁병
- 상위 세부 병종 1개와 대량생산·정예훈련·토큰 증폭 교리 중 1개 선택

같은 계열은 Tier가 달라도 같은 토큰을 공유한다. 토큰 내부 원장은 출처 병영·Tier·세부 병종을 보존한다.

## 11. 룰렛

- 3×3 보드
- 기본 판정줄은 중앙 가로줄
- 판정줄 3칸이 같은 비-X 심벌일 때만 보상
- 같은 심벌의 전체 8개 줄 완성 수를 계산

| 완성 줄 | 유닛 등급 |
|---:|---|
| 1줄 | 일반 |
| 2줄 | 엘리트 |
| 3~7줄 | 영웅 |
| 8줄·9칸 동일 | 전설 |

- 전설은 스테이지당 1회
- 이후 9칸 동일은 해당 계열 영웅 2명
- 합성·처치 경험치·건물 Tier로 등급 상승 없음
- 병영 자동 생산은 일반 등급
- 상위 등급은 룰렛으로만 생성

금화:

| 금화 완성 줄 | 지급 |
|---:|---:|
| 1줄 | 실제 회전비 75% |
| 2줄 | 200% |
| 3줄 이상 | 500% |

## 12. 럭키 찬스와 이동권

- 시작 확률 12%
- 자연 실패마다 +8%p
- 6회 실패 뒤 다음 회전 확정
- 성공 뒤 보정된 기본 확률로 초기화
- 자연 럭키 찬스는 무료 이동 1회 제공
- 이동권과 같은 회전에 함께 사용 가능
- 회전당 이동 횟수 상한 없음
- 최종 확정 시에만 이동권 소비

## 13. 병종 성장

유닛 성장은 두 축으로 분리한다.

```text
병영 Tier
→ 실제 일반 병종
→ 핵심 패시브 생성·강화

룰렛 등급
→ 일반·엘리트·영웅·전설
→ 핵심 스킬 생성·강화
```

패시브:

| 출처 Tier | 성장 |
|---|---|
| T1 | 패시브 1 기본형 |
| T2 | 패시브 1 강화 + 패시브 2 생성 |
| T3 | 패시브 1 추가 강화 + 패시브 2 강화 + 패시브 3 생성 |

스킬:

| 등급 | 성장 |
|---|---|
| 일반 | 1스킬 기본형 |
| 엘리트 | 1스킬 강화 |
| 영웅 | 강화된 1스킬 + 2스킬 생성 |
| 전설 | 영웅 효과 + 2스킬 강화 + 3스킬 생성 |

일반은 출처 병영의 실제 세부 병종을 생성한다. 엘리트·영웅·전설은 계열별 고정 유닛이며 Tier 3 세부 병종과 무관하다.

## 14. 전투 키워드

- 대상 태그: 보병, 기병, 원거리병, 공성병, 보스, 건물, 바리케이드
- 행동 태그: 근접, 원거리, 투사체, 돌진, 급강하, 관통, 범위, 기본 공격, 스킬
- 효과 태그: 물리, 마법, 고정 피해, 경직, 기절, 밀쳐내기, 넘어짐, 둔화, 속박, 출혈, 독, 화상, 역병

초기값:

- 기본 치명타 확률 5%
- 치명타 피해 150%
- 후방 판정 총 120도
- 창병 돌진 저지 내부 쿨타임 5초
- 둔화 상한 60%
- 스킬 쿨다운 감소 상한 40%

## 15. 비행

- 모든 유닛은 지상 또는 비행 레이어 보유
- 비행은 지상 유닛·바리케이드·지상 함정을 우회
- 라인과 전장 경계는 유지
- 기본적으로 접전지 점령에 기여하지 않음
- 공격은 `ground`, `air`, `ground_and_air` 대상 레이어 명시
- 대공은 비행 카운터 특화 태그
- 일반 창병 돌진 저지는 급강하를 막지 못하며 대공 저지 필요
- 지상화 상태에서는 바리케이드·지상 공격·지면 상태이상 적용

## 16. 전술 명령

- 바리케이드
- 화살비
- 역병
- 강화지대

공통:

- HUD에서 직접 사용
- 발동마다 금화 지불
- 전역 쿨다운 없음
- 명령별 개별 쿨다운
- 준비된 서로 다른 명령 연속 사용 가능
- 사용 횟수 제한과 반복 가격 상승 없음
- 일시정지 중 사용·목표 확정 가능, 시간 진행은 정지

## 17. 적 공세

적은 플레이어처럼 룰렛을 돌리지 않는다.

- 적 건물과 시간표에 따라 공세 유닛 생산
- 약 30초 전에 베일의 징조 표시
- 라인·병종·정확한 수량 공개
- T-10에 구성 확정하는 초기 방향
- 확정 전 적 시설 파괴는 현재 공세 감소 가능
- 확정 후 파괴는 다음 공세부터 반영

적 본진을 일정 시간 안에 파괴하지 못하면 공개된 결전 공세가 출격한다. 초기 가설은 약 35분이다.
