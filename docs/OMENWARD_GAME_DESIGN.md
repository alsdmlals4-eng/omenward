# 오멘워드 게임 기획서

- 공식명: **오멘워드 / OMENWARD**
- 문서 버전: **v0.18**
- 상태: 프리프로덕션 구조 완료 / 전장 초기값 승인 / 수직 슬라이스 준비 / 구현 전
- 장르: 실시간 3라인 전략 오토배틀 + 건물 기반 3×3 룰렛 빌드
- 플랫폼: Windows PC / 마우스·키보드
- 엔진: Godot + GDScript

세부 규칙은 `docs/design/APPROVED_*.md`가 우선한다. 전체 최신 인덱스는 `docs/design/APPROVED_PREPRODUCTION_POC_BASELINE_V1.md`다.

## 1. 한 문장 소개

플레이어는 루메른 왕국 트리븐 전선의 지휘관이 되어 건물로 룰렛 확률과 증원 체계를 설계하고, 베일의 법칙에 따라 베일런 황야에서 넘어오는 괴물 군단을 세 전선에서 막아낸다.

## 2. 핵심 루프

```text
베일의 징조 확인
→ 건물·토큰·전술 선택
→ 룰렛 회전·조작
→ 병력 획득·배치
→ 상성으로 전선 역전
→ Tier·등급·병종 목표 갱신
```

- 첫 10분 안에 건설→룰렛→배치→역전 루프를 두 번 체험한다.
- 새 시스템은 한 문장 설명, 한 번 행동, 즉시 결과로 10~30초 안에 기본 사용법을 익힌다.

## 3. 세계관

| 대상 | 공식 명칭 |
|---|---|
| 국가 | 루메른 왕국 |
| 인간 생활권 | 루미엔 영토 |
| 전선 | 트리븐 전선 |
| 첫 요새 | 실베른 성채 |
| 괴물 영역 | 베일런 황야 |
| 세계 규칙 | 베일의 법칙 |
| 괴물 분류 | 베일종 |
| 안내자 | 벨루 |

룰렛은 UI 용어이며 세계관에서는 전술판·전력 표식·증원 경로로 가볍게 번역한다. 병사는 자신이 룰렛에서 생성됐다고 인식하지 않는다.

## 4. 벨루

벨루는 실베른 성채 경계종의 울림에서 태어난 작은 감시 정령이다.

- 세계관 설명, 적 보고, 튜토리얼, 전술 요약, 감정 반응 담당.
- 우측 하단 48~64px 도크, 최대 두 줄 대사.
- 위험·보스·축복·저주·등급 반응은 0.5~2초 뒤 기본형으로 복귀.
- 정확한 숫자와 지속 상태는 HUD가 표시한다.

## 5. 전장

전장은 좌우 대칭의 독립된 상·중·하 3라인으로 구성한다.

```text
아군 본진
→ 라인별 아군 성문
→ 아군 중간거점
→ 중앙 접전지
→ 적 중간거점
→ 라인별 적 성문
→ 적 본진
```

- 상·중·하 라인은 일반 도로로 서로 연결하지 않는다.
- 중앙 접전지는 해당 라인의 앞뒤 길에만 연결하고 건설할 수 없다.
- 기본 유닛은 배치된 라인을 변경하지 않는다.
- 각 본진 진입부에는 라인별 성문 3개가 있다.
- 각 중간거점에는 전방 건설 노드 2개와 후방 노드 1개가 있다.
- 중간거점 점령 시 건설권과 기본 생산권이 점령 진영으로 이전된다.
- 암살자는 적 후방에 직접 배치하지 않고 같은 라인의 안개 우회로로 침투한다.
- 전장이 기본 전략 줌에서 한눈에 보이므로 별도 미니맵을 사용하지 않는다.
- 건설 노드는 도로 바깥에 두고 대형 건물도 통행을 막지 않는다.

### 중간거점 첫 PoC 값

```text
중립화 10초 + 점령 10초 at 점령력 1.0
최대 유효 점령력 2.0
진행 유지 3초
복귀 초당 10%
점령 완료 후 안정화 5초
소유 수입 금화 +2 / 30초
```

- 방패·수호형 1.25, 일반 근접·기병 1.0, 원거리·지원·거인 0.5.
- 암살자·비행·순수 공성 병기는 점령력 0.
- 점령 시도 중 생산·신규 건설·업그레이드 정지.
- 중립화 시 기존 건물 비활성.
- 점령 완료 시 기존 건물은 환불 없이 폐허화.
- 5초 안정화 뒤 새 소유자의 노드와 생산 활성.

### 성문 첫 PoC 값

```text
HP 5000
방어 80
마법저항 80
일반 구조물 피해 40%
공성 태그 피해 200%
고정 피해 50%
붕괴 2초
```

- 아군은 통과하고 적은 파괴 전까지 차단된다.
- 군중제어·밀치기·비율 피해에 면역이다.
- 폐허는 이동을 막지 않는다.
- 수직 슬라이스에서는 수리·재건하지 않는다.

### 암살자 우회로 첫 PoC 값

```text
진입 준비 1초
우회 이동 9초
도착 2.5초 전 수비 측 경고
출현 준비 0.6초
적 중간거점에서 본진 방향 120 units
도착 영역 160 × 120 units
막힘 보정 반경 80 units
점령력 0
```

- 진입 확정 후 취소·후퇴할 수 없다.
- 우회 중 전투·점령·피격·버프 판정이 없다.
- 경로는 암살자 선택·배치 중에만 보인다.
- 탐지 전용 건물은 수직 슬라이스 범위에서 제외한다.

### 스케일 첫 가설

- PoC 맵 2,880×1,280 world units.
- 일반 이동속도 기준 60, 포탑 사거리 270.
- 주 도로 폭 200~240, 중간거점·성문 전방 240~320 world units.

세부 전장 규칙은 `docs/design/APPROVED_BATTLEFIELD_TOPOLOGY_AND_SCALE_V1.md`를 따른다.

## 6. 정규 스테이지

- 활성 전투 시간 약 15분.
- `wave_collision_time = wave_index × 60초`.
- 이전 공세가 남아 있어도 다음 공세 진입.
- 일반 징조 T-30/T-15/T-5.
- 15웨이브 보스 T-60 예고.

| 웨이브 | 이정표 |
|---:|---|
| 1~4 | 일반 중심 |
| 5 | 엘리트 핵심 유닛 |
| 10 | 영웅 핵심 유닛 |
| 15 | 전설 보스, 표준 승리 |
| 16~19 | 초과 공세 |
| 20 | 적군 전용 신화 보스 |

- 적 본진을 15웨이브 이전에 파괴하면 조기 승리.
- 20:00 즉시 패배가 아니라 사실상 절멸 공세.

## 7. 플레이어 10병종

### 기본 병영 6종

1. 방패병 — 범용 전열·원거리 대응.
2. 대검전사 — 정면 범위·파쇄·격노.
3. 암살자 — 같은 라인의 안개 우회로를 통해 적 후열·후방 시설 침투.
4. 창병 — 돌진·대형 저지.
5. 궁병 — 지속 원거리·대공.
6. 기병 — 기동·돌진·후열 압박.

### 특수병단 4종

1. 사제 — 치유·버프.
2. 마법사 — 광역 마법·제어.
3. 비행병 — 지상 전열 우회·후열 압박.
4. 거인 — 높은 범위 공격·체력·방어·공성.

각 계열은 일반·엘리트·영웅·전설 고정 능력 계보를 가진다. 플레이어 신화급은 없다.

## 8. 건물과 생산

### 기본 병영

```text
Tier 1
검사 자동생산 + 전사 토큰

Tier 2
방패병 / 대검전사 / 암살자 / 창병 / 궁병 / 기병

Tier 3
상위 세부 병종 1개 + 운영 교리 1개
```

- 방패병·대검전사는 전사 토큰 공유.
- 암살자·창병·궁병·기병은 독립 토큰.
- 자동생산은 일반 등급만 생성.

### 특수병단

```text
Tier 1
금화 40 / 건설 25초
토큰·생산 없음
30초마다 Tier 2 비용 -10%
150초에 최대 -50%

Tier 2
사제단 / 마도단 / 비행단 / 거인단
토큰 활성 + 일반 자동생산
```

| 특수병종 | 생산시간 | 식량 |
|---|---:|---:|
| 사제 | 180초 | 3 |
| 마법사 | 210초 | 3 |
| 비행병 | 240초 | 4 |
| 거인 | 300초 | 6 |

## 9. 자원과 경제

```text
시작 금화 160
시작 식량 12
기본 수입 20초마다 +5
중앙 접전지 60초마다 한 곳당 +4
소유 중간거점 30초마다 한 곳당 +2
기본 룰렛 20
```

- 중간거점 점령 시 생산과 건설권이 점령 진영으로 이전된다.
- 점령 시도·교착·중립 상태에서는 거점 생산이 정지한다.
- 점령 완료 뒤 5초 안정화 후 새 소유자의 생산이 시작된다.
- 적 처치·웨이브 클리어 고정 금화 없음.
- 시장 50, 농장 35, 포탑 35, 기본 병영 40, 특수병단 40.
- 시장은 20초마다 +4, 다중 시장 비용 증가.
- 일시정지 중 모든 시간 기반 수입·생산·공세 시계 정지.

## 10. 룰렛

- 3×3 보드.
- 중앙 가로줄 기본 판정.
- 같은 비-X 심벌 3개가 완성된 줄만 보상.

| 완성 줄 | 등급 |
|---:|---|
| 1 | 일반 |
| 2 | 엘리트 |
| 3~7 | 영웅 |
| 8·9칸 동일 | 전설 |

- 전설은 스테이지당 1회, 이후 9칸 동일은 영웅 2기.
- 상위 등급은 룰렛으로만 생성.
- 럭키 12%, 실패당 +8%p, 6회 실패 뒤 확정.
- 결과 보관함 기본 3칸.
- 금화 1/2/3줄 이상은 15/40/100 지급.
- 금화 장기 평균 지급 목표는 회전비의 30% 이하.

## 11. Tier와 등급

```text
Tier
→ 생산시설 성장·패시브 생성·강화

등급
→ 일반·엘리트·영웅·전설 스킬 생성·강화
```

| Tier | 패시브 |
|---|---|
| T1 | 패시브 1 기본 |
| T2 | 패시브 1 강화 + 패시브 2 |
| T3 | 패시브 1·2 강화 + 패시브 3 |

| 등급 | 스킬 |
|---|---|
| 일반 | 스킬 1 |
| 엘리트 | 강화 스킬 1 |
| 영웅 | 강화 스킬 1 + 스킬 2 |
| 전설 | 강화 스킬 1·2 + 스킬 3 |

## 12. 공통 전투

- 물리·마법·고정 피해.
- 방어·마법저항 공식과 75% 감소 상한 첫 가설.
- 기본 치명타 5%, 150% 피해.
- 후방 120도, 기본 +25%.
- 지상·비행·대공·대형 태그.
- 보스 상태이상 감소와 연속 제어 면역.
- 범위 공격 대상 상한과 외곽 감쇠.
- 전조와 실제 판정 일치.

## 13. 적군과 웨이브

아군 10병종에는 기능상 대응하는 적군 10병종이 존재한다. 같은 병종·Tier·등급의 기본 전투 예산은 ±10%에서 시작하며 AI·스킬·외형·편성으로 차별화한다.

- W1~15 Threat 첫 곡선 6→85.
- W16~20 Threat 첫 곡선 100→250.
- 적 생산시설 파괴는 아직 출격하지 않은 현재·다음 공세를 약화.
- 15 전설 보스는 직선 돌파·대단절·진군 패턴.
- 20 신화 보스는 끝나지 않는 진군과 2페이즈.

## 15. 튜토리얼·캠페인

```text
튜토리얼 1개
+ 정규 9개
= 총 10스테이지, 약 3시간
```

해금 초안:

```text
방패·대검·암살
→ 창병
→ 궁병
→ 사제
→ 기병
→ 마법사
```

튜토리얼은 첫 룰렛 일반 검사, 포탑/바리케이드 역전, 이동권 엘리트, 방패·대검·암살 중 Tier 2 선택을 포함한다.

## 16. 절차 생성

정규 스테이지는 결정론적 StageManifest를 사용한다.

- MapTemplate, WavePatternCard, EnemyBuild, DifficultyProfile, Threat Budget.
- 베일의 축복·저주·선언.
- Validator가 해금 이전 위협, 과도한 라인 집중, 성능 상한을 검사.
- 실패 시 수동 안전 Manifest로 대체.
- 튜토리얼은 절차 생성 대상이 아니다.

## 17. UI·아트·오디오

- 1920×1080, 내부 960×540 정수 확대 후보.
- 기본 전략 줌에서 양측 본진과 세 라인 전체를 확인한다.
- 별도 미니맵을 두지 않고 실제 전장 위의 성문·거점·접전지 상태 표시를 사용한다.
- 암살자 우회로는 평상시 안개로 가리고 암살자 선택·배치 중에만 표시한다.
- 룰렛 좌하단, 건설·용병·전술 하단, 벨루 우하단.
- 아군은 수직선·아치·방패·종·천 배너.
- 적군은 비대칭 균열·갑각·가시·공허 구조.
- 10병종은 무기·자세·크기 실루엣으로 구분.
- 등급은 부속·문양·프레임·짧은 VFX로 구분.
- 벨루는 맑은 두 음 종 모티프.

## 18. 성능·데이터·검증

정상 목표:

- 지상 유닛 120, 비행 24, 투사체 160, VFX 80.
- 하드 안전 상한 지상 180, 비행 40, 투사체 260, VFX 140.
