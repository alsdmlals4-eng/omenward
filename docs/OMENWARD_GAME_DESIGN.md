# 오멘워드 게임 기획서

- 공식명: **오멘워드 / OMENWARD**
- 문서 버전: **v0.13**
- 상태: 프리프로덕션 / 구현 전 디자인 프리즈 진행 중
- 장르: 실시간 3라인 전략 오토배틀 + 건물 기반 3×3 룰렛 빌드
- 기본 모드: 싱글플레이 PvE 비대칭 웨이브 전투
- 우선 플랫폼: Windows PC / 마우스·키보드
- 구현 엔진: Godot / GDScript

세부 규칙은 `docs/design/APPROVED_*.md`가 우선한다. 미확정 수치는 `docs/DECISIONS_PENDING.md`에서 관리한다.

## 1. 한 문장 소개

플레이어는 루메른 왕국 트리븐 전선의 지휘관이 되어 건물로 룰렛 확률과 증원 체계를 설계하고, 베일의 법칙에 따라 베일런 황야에서 넘어오는 괴물 군단을 세 전선에서 막아낸다.

## 2. 핵심 재미

> 건물을 지어 룰렛 확률을 바꾸고, 당첨된 병력으로 예고된 위기를 뒤집는다.

```text
베일의 징조 확인
→ 필요한 건물·병종·전술 선택
→ 룰렛 토큰과 확률 변화
→ 룰렛 회전과 병력 획득
→ 필요한 라인에 배치
→ 상성과 전술로 전선 역전
→ 다음 Tier·등급·병종 목표
```

핵심 감정은 긴장, 판단, 기대, 당첨 쾌감, 통제감, 역전과 성장 기대의 순서로 연결한다.

## 3. 세계관과 명칭

| 대상 | 명칭 |
|---|---|
| 국가 | 루메른 왕국 |
| 인간 생활권 | 루미엔 영토 |
| 첫 요새 | 실베른 성채 |
| 세 라인 전선 | 트리븐 전선 |
| 괴물 영역 | 베일런 황야 |
| 경계 현상 | 베일 |
| 세계 규칙 | 베일의 법칙 |
| 괴물 공식 분류 | 베일종 |
| 방위 조직 | 루메른 경계군 |
| 플레이어 부대 | 실베른 수비대 |
| 마스코트·안내자 | 벨루 |

플레이어는 직접 전투하는 영웅이 아니라 건설·증원·라인 배치·공세 분석·전술 명령과 반격을 지휘하는 최전선 지휘관이다.

괴물은 계속 밀려오는 것이 아니라 베일의 법칙에 따라 공세 단위로 넘어온다. 공세 전에는 라인·병종·수량을 읽을 수 있는 베일의 징조가 나타난다. 법칙의 기원과 목적은 초반에 설명하지 않지만 게임 효과와 수치는 HUD에 정확히 공개한다.

룰렛과 토큰은 반드시 물리적인 마법 소환 장치로 설명하지 않는다.

- 플레이어 UI: 룰렛, 토큰, 릴, 완성 줄
- 세계관 표현: 전술판, 전력 표식, 증원 경로
- 병영 건설: 모집·훈련·보급 경로 확보
- 병사는 자신이 룰렛에서 생성됐다고 인식하지 않음

## 4. 벨루

벨루는 실베른 성채의 오래된 경계종 울림에서 태어난 작은 감시 정령이다.

담당:

- 세계관 설명
- 라인·병종·수량·시간 보고
- 튜토리얼 안내
- 전술 선택지 요약
- 베일의 법칙 암시
- 룰렛·역전·보스 감정 반응

정찰관과 부관은 별도 기능성 안내 NPC로 사용하지 않는다. 정확한 숫자와 지속 상태는 HUD, 짧은 감지와 보고는 벨루가 담당한다.

벨루는 위험·보스·축복·저주·룰렛 등급에 0.5~2초 동안 경고등처럼 반응한 뒤 기본 청백색 외형으로 돌아간다.

## 5. Dopamine Driven Design

- 새 시스템의 기본 사용법은 10~30초 안에 습득시킨다.
- 한 문장 설명, 한 번의 직접 행동, 즉시 결과로 구성한다.
- 첫 노출에서 전체 예외와 고급 활용을 설명하지 않는다.
- 활용과 숙련은 이후 공세에서 반복적으로 익힌다.
- 시스템 수보다 동시에 요구하는 새 개념 수를 제한한다.

## 6. 첫 10분 튜토리얼

튜토리얼은 수동 설계 스테이지이며 첫 공세 전까지 온보딩 시간을 별도로 둘 수 있다. 튜토리얼 공세 시계가 시작된 뒤에는 60초 간격으로 충돌한다.

```text
+1:00 제1공세 — 일반 검사·횡베기
+2:00 제2공세 — 포탑 또는 바리케이드 역전
+3:00 제3공세 — 룰렛 이동권과 엘리트
+4:00 제4공세 — Tier 2 병종과 세 라인 판단
```

일시정지는 튜토리얼 공세 시계도 멈춘다.

핵심 경험:

- 첫 병영과 전사 토큰
- 고정 1줄 룰렛과 일반 검사
- 포탑 또는 바리케이드로 첫 역전
- 행 이동으로 1줄을 2줄 엘리트로 개선
- 방패병·대검병·광전사 중 하나 선택
- 10분 안에 건설→룰렛→배치→방어 루프를 두 번 이상 체험

초기 전투 수치는 `APPROVED_TUTORIAL_FIRST_FOUR_WAVES_BALANCE_V1.md`에서 관리한다.

## 7. 전장 구조와 화면

고정 루트:

```text
아군 본진
→ 아군 본진 접전지
→ 상·중·하 분기
→ 각 라인의 아군 중간요새
→ 각 라인의 중앙 접전지
→ 각 라인의 적 중간요새
→ 상·중·하 수렴
→ 적 본진 접전지
→ 적 본진
```

- 상단은 위로 분기
- 중단은 직진
- 하단은 아래로 분기
- 라인 사이 횡단로 없음
- 기본 유닛 라인 변경 없음
- 중앙 접전지에는 건설 불가
- 후방 노드 6개, 라인별 노드 3개

PoC 스케일 초기값:

```text
맵: 2,880 × 1,280 world units
일반 보행속도: 60
중앙 접전지 점령 반경: 120
Tier 1 포탑 사거리: 270
```

카메라는 기본 전략 줌에서 양측 본진과 세 라인 전체를 보여주며 0.85×~1.55× 확대·축소를 지원한다.

1920×1080 기본 줌 목표:

| 대상 | 화면 높이 |
|---|---:|
| 일반 병사 | 34~40px |
| 엘리트 | 40~46px |
| 영웅 | 46~54px |
| 전설 | 54~62px |
| 중간요새 | 100~130px |
| 본진 | 150~180px |

하단 UI:

```text
좌측 하단: 3×3 룰렛
중앙 좌측: 건설
중앙: 용병·대기 병력
중앙 우측: 전술 명령
우측 하단: 벨루와 최대 두 줄 대사
```

## 8. 정규 스테이지와 공세 시계

정규 스테이지의 표준 활성 전투 시간은 약 15분이다.

```text
wave_collision_time = wave_index × 60초
```

- 1웨이브 충돌: 1:00
- 5웨이브 충돌: 5:00
- 10웨이브 충돌: 10:00
- 15웨이브 충돌: 15:00
- 20웨이브 충돌: 20:00

`충돌`은 적 선두가 중앙 접전지 주 교전 반경에 들어오는 순간이다. 적은 이동시간을 역산해 적 중간요새에서 먼저 출격한다.

- 일시정지는 공세 시계를 멈춘다.
- 이전 공세가 남아 있어도 다음 공세는 예정대로 진입한다.
- 첫 공세는 0:00에 전체 정보를 공개한다.
- 일반 공세는 T-30/T-15/T-5 단계로 경고한다.
- 15웨이브 보스는 T-60부터 예고한다.

### 1~15웨이브 역할

| 구간 | 역할 |
|---|---|
| 1~4 | 초반 빌드·기본 병종·라인 판단 |
| 5 | 첫 엘리트 또는 특수 병종 |
| 6~9 | 복수 라인·혼합 병종·건물 대응 |
| 10 | 지휘관 또는 미니보스 |
| 11~14 | 상위 병종·공성·비행·엘리트 |
| 15 | 강력 보스와 호위 병력의 결전 |

## 9. 승리·초과전·절멸 공세

### 표준 승리

```text
15웨이브 강력 보스 처치
→ 스테이지 승리
```

### 공격적 조기 승리

```text
15웨이브 이전 적 본진 파괴
→ 즉시 승리
```

### 일반 패배

- 아군 본진 체력 0
- 핵심 보호 목표 파괴
- 스테이지별 공개 패배 조건 달성

### 16~19웨이브 초과 공세

15웨이브 보스가 살아 있으면 매 60초마다 강화 엘리트·상위 병종이 계속 합류한다. 초과 공세는 파밍 구간이 아니라 빠르게 누적되는 실패 압박이어야 한다.

초기 Threat Budget 가설:

| 웨이브 | 배율 |
|---:|---:|
| 16 | 1.25× |
| 17 | 1.50× |
| 18 | 1.80× |
| 19 | 2.15× |

### 20웨이브 절멸 공세

20:00에 즉시 패배를 강제하지 않는다. 대신 절멸급 보스와 세 라인 강화 호위가 합류해 일반적인 빌드가 빠르게 붕괴하도록 한다.

절멸급 보스 초기 방향:

- 15웨이브 보스 대비 체력 약 2.5×
- 공격력 약 1.75×
- 건물·바리케이드 피해 약 3.0×
- 군중제어 지속시간 50%
- 15초마다 공격·이동 성능 상승
- 직선 돌파와 밀집 공격으로 장기 교착 방지

기적적인 역전은 가능하지만 일반 승률은 매우 낮아야 한다.

## 10. 자원과 일시정지

### 금화 사용처

- 룰렛 회전
- 건설·업그레이드
- 상점과 용병
- 이동권·행운·장비
- 전술 명령

### 금화 획득처

- 기본 수입
- 시장
- 금화 룰렛
- 접전지

### 식량

- 출전 유닛만 사용
- 대기칸과 결과 보관함은 미사용
- 농장으로 최대치 증가
- 한도 초과 시 기존 유닛 유지, 신규 출전 차단
- 포탑과 전술 명령은 식량 미사용

일시정지는 전투 시간만 멈추는 계획 모드다. 룰렛, 건설, 전술 명령, 생산, 배치, 이동과 상점은 정상 확정되며 이동·공격·건설·생산·쿨다운·공세 시계는 재개 전까지 멈춘다.

## 11. 건물 성장

```text
Tier 1: 공통 기본 기능
→ Tier 2: 병종·역할 전문화
→ Tier 3: 상위 세부 병종 + 운영 교리
```

- 적이 있어도 건설·업그레이드 진행
- 건설 중 피격·파괴 가능
- 건설 시작 체력 초기값 25%
- 일반 건물은 이동을 하드 차단하지 않음
- 바리케이드만 적 이동 차단

병영:

- Tier 1 검사·전사 토큰
- Tier 2 전사: 방패병·대검병·광전사
- 다른 계열: 기병·창병·궁병
- Tier 3: 상위 세부 병종 1개와 대량생산·정예훈련·토큰 증폭 교리 중 1개

같은 계열은 Tier가 달라도 같은 토큰을 공유하며 내부 원장은 출처 병영·Tier·세부 병종을 보존한다.

## 12. 룰렛

- 3×3 보드
- 기본 판정줄 중앙 가로줄
- 판정줄 3칸이 같은 비-X 심벌일 때 보상
- 같은 심벌의 전체 8개 줄 완성 수 계산

| 완성 줄 | 유닛 등급 |
|---:|---|
| 1줄 | 일반 |
| 2줄 | 엘리트 |
| 3~7줄 | 영웅 |
| 8줄·9칸 동일 | 전설 |

- 전설은 스테이지당 1회
- 이후 9칸 동일은 해당 계열 영웅 2명
- 합성·처치 경험치·건물 Tier로 등급 상승 없음
- 병영 자동생산은 일반 등급
- 상위 등급은 룰렛으로만 생성

금화 완성 줄:

| 완성 줄 | 지급 |
|---:|---:|
| 1줄 | 실제 회전비 75% |
| 2줄 | 200% |
| 3줄 이상 | 500% |

럭키 찬스:

- 시작 확률 12%
- 자연 실패마다 +8%p
- 6회 실패 뒤 다음 회전 확정
- 성공 뒤 초기화
- 무료 이동 1회 제공
- 이동권과 같은 회전에 병용 가능
- 확정 시에만 이동권 소비

## 13. 병종과 등급 성장

```text
병영 Tier
→ 실제 일반 병종
→ 핵심 패시브 생성·강화

룰렛 등급
→ 일반·엘리트·영웅·전설
→ 핵심 스킬 생성·강화
```

패시브:

| 출처 Tier | 성장 |
|---|---|
| T1 | 패시브 1 기본형 |
| T2 | 패시브 1 강화 + 패시브 2 생성 |
| T3 | 패시브 1 추가 강화 + 패시브 2 강화 + 패시브 3 생성 |

스킬:

| 등급 | 성장 |
|---|---|
| 일반 | 1스킬 기본형 |
| 엘리트 | 1스킬 강화 |
| 영웅 | 강화된 1스킬 + 2스킬 생성 |
| 전설 | 영웅 효과 + 2스킬 강화 + 3스킬 생성 |

일반은 출처 병영의 실제 병종을 생성한다. 엘리트·영웅·전설은 계열별 고정 유닛이며 Tier 3 세부 병종과 무관하다.

## 14. 전투·비행·전술 명령

초기 공통값:

- 기본 치명타 5%
- 치명타 피해 150%
- 후방 판정 총 120도
- 창병 돌진 저지 내부 쿨타임 5초
- 둔화 상한 60%
- 스킬 쿨다운 감소 상한 40%

비행:

- 지상 유닛·바리케이드·지상 함정 우회
- 라인과 전장 경계 유지
- 기본적으로 접전지 점령에 기여하지 않음
- 공격별 대상 레이어 명시
- 대공은 비행 카운터 특화

전술 명령:

- 바리케이드
- 화살비
- 역병
- 강화지대

공통:

- HUD에서 직접 사용
- 발동마다 금화 지불
- 전역 쿨다운 없음
- 명령별 개별 쿨다운
- 서로 다른 명령 연속 사용 가능
- 사용 횟수 제한과 반복 가격 상승 없음
- 일시정지 중 선택·목표·확정 가능, 시간 진행은 정지

보스는 바리케이드와 밀집 병력을 대응하는 직선 돌파·크게 베기 패턴을 가지며, 모든 강한 패턴은 범위·동작·음향으로 명확히 예고한다.

## 15. 데이터와 절차 생성

정규 스테이지만 결정론적 시드와 다음 구조로 생성한다.

- StageManifest
- DifficultyProfile
- Threat Budget
- WavePatternCard
- Validator
- 베일의 축복·저주·선언
