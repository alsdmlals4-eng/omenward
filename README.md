```text
징조 관측
→ 건설 / 확률 설계
→ 3×3 룰렛 / 행·열 조작
→ 병력 획득
→ PREPARE -> COMMIT -> BATTLE -> REVIEW
→ 비가역 전선 커밋
→ 자동전투 + 제한된 전술
→ 인과 복기
```
