## 1. 화면 기준

- 기준 출력: 1920×1080, 16:9.
- 내부 픽셀 기준 후보: 960×540을 2배 정수 확대.
- 축소 검증: 1280×720.
- 기본 전략 줌에서 양측 본진과 세 라인 전체를 확인한다.
- 전장이 한눈에 보이므로 미니맵을 사용하지 않는다.
- 일반 유닛 34~40px, 특수 인간형 42~56px, 거인 72~96px 첫 기준.
- 색상만으로 병종·등급·진영을 구분하지 않는다.

## 2. HUD 배치

```text
상단 좌측: 금화·식량·수입 타이머
상단 중앙: 공세 시계·베일의 징조·보스 체력
상단 우측: 일시정지·속도·설정
좌측 하단: 3×3 룰렛·이동권·럭키 찬스
하단 중앙: 건설·용병·대기 결과·전술 명령
우측 하단: 벨루·최대 두 줄 대사
```

- 중앙 전장 가시영역을 최대한 보존한다.
- 룰렛·건설 조작 중에도 웨이브 경고와 본진 위험을 가리지 않는다.
- 전설 룰렛 결과 연출은 1.2초 이내에 전투 화면으로 복귀한다.
- 목표 상태는 축소 지도에 복제하지 않고 실제 월드 위치에 표시한다.

## 3. 정보 우선순위

### 항상 표시

- 현재 금화·식량.
- 다음 공세 충돌까지 시간.
- 각 라인의 중앙 접전지 소유 상태.
- 각 중간거점 소유권과 점령 진행.
- 라인별 성문과 본진 HP.
- 선택 건물의 건설·생산·업그레이드 진행.

### 조건부 표시

- T-30: 라인과 핵심 위협 태그.
- T-15: 정확한 공용 병종 역할·수량·카운터 아이콘.
- T-5: 주력 라인 강조와 벨루 경고.
- 식량 부족: 완성 대기 유닛과 필요한 식량.
- 특수병단: 현재 할인, 다음 할인 시간, 원가와 실제 비용.
- 암살자 선택: 사용 가능한 우회로와 예상 도착 구역.
- 공성 공격: 해당 성문 위험과 구조물 피해 태그.

## 4. 전장 월드 정보

### 성문

- 내구도, 파손 단계와 공격받는 상태를 성문 위에 직접 표시한다.
- 각 라인의 성문 상태는 독립적으로 표시한다.
- 일반 피격과 공성 피격의 파손 피드백을 구분한다.

### 중간거점

- 소유 팀, 점령 게이지와 교착 상태를 실제 위치에 표시한다.
- 전방 2·후방 1 노드의 사용 가능·비활성·폐허 상태를 표시한다.
- 중립화 시 거점 문양과 건물 기능 표시를 끈다.
- 점령 뒤 5초 안정화는 거점 자체의 빛과 게이지로 표시한다.

### 중앙 접전지

- 점령 테두리와 교착 상태를 바닥에 표시한다.
- 건설 가능한 영역처럼 보이는 강한 노드 UI를 사용하지 않는다.

### 암살자 우회로

- 평상시에는 경로, 출입구와 도착점을 안개로 가린다.
- 암살자를 선택하면 사용 가능한 라인의 윤곽만 나타난다.
- 라인을 지정하면 출발점, 방향과 예상 도착 구역을 표시한다.
- 배치 확정 뒤 선택자에게만 필요한 진행 정보를 보여준다.
- 수비 측은 도착 2.5초 전 정확한 좌표가 아닌 도착 영역 경고를 받는다.
- 위험 공격의 붉은 전조와 혼동되지 않는 회색·청회색 연무를 사용한다.
- 선택 해제·침투 종료 뒤 다시 가린다.

## 5. 룰렛 UX

- 각 심벌은 실루엣 아이콘과 작은 계열 문양을 함께 사용한다.
- 현재 판정줄은 얇은 금속 프레임으로 표시한다.
- 이동권 사용 전 예상 완성 줄을 실시간 미리보기한다.
- 등급 결과는 프레임 형태, 길이와 음향 단계로 구분한다.
- 결과 보관함 3칸은 룰렛 옆에 명확히 배치한다.
- 금화·이동권 부족은 비활성 버튼과 정확한 부족량으로 표시한다.
- 결과 유닛은 공용 `archetype_id`와 Rank를 나타내며 진영별 별도 병종 ID를 사용하지 않는다.

## 6. 공용 10병종과 진영 이미지

전투·애니메이션 규칙은 공용 10병종 하나를 사용한다.

```text
UnitArchetypeProfile
+ AnimationContract
+ FactionVisualProfile
```

- 아군·적군은 같은 능력·상태·프레임·판정 이벤트를 사용한다.
- 아군용과 적군용 이미지만 별도로 제작한다.
- 초상화·아이콘·팔레트·표시명은 Visual Set이 소유한다.
- 일반 적군 전용 스탯·스킬·애니메이션 데이터를 만들지 않는다.

## 7. 진영 형태 언어

### 루메른·실베른 Visual Set

- 수직선, 아치, 방패, 종, 천 배너.
- 정돈된 판금, 남색·상아색 천, 따뜻한 금속 포인트.
- 인간형 무기와 장비가 공용 병종 역할을 직접 드러낸다.

### 베일런·베일종 Visual Set

- 비대칭 균열, 갑각, 가시, 공허 구멍.
- 검은 외곽과 내부에서 새는 제한된 발광.
- 공용 병종 기능을 생물 구조로 번역한다.
- 공용 AnimationContract의 프레임 수·피벗·접촉 이벤트를 지켜야 한다.

### 금지

- 아군과 적군이 색상만 다름.
- 별도 적군 애니메이션 타이밍과 상태 머신 제작.
- 작은 전략 줌에서 무기·기관 실루엣이 몸에 묻힘.
- 상시 발광이 등급과 스킬 전조를 가림.

| 방패병 | 몸 높이의 방어면, 낮은 중심 | 큰 방패 | 넓은 갑각판 |
| 대검전사 | 몸보다 긴 넓은 공격 구조 | 대검 | 절단 골격·균열 칼날 |
| 암살자 | 낮은 자세, 양손 짧은 무기 | 쌍단검·짧은 망토 | 긴 갈퀴·낮은 갑각 |
| 창병 | 가장 긴 수평 무기 | 장창 | 전방 가시창 |
| 궁병 | 원거리 발사 구조와 탄약 표시 | 활·화살통 | 침 발사기관·탄낭 |
| 기병 | 탈것 포함 긴 전후 실루엣 | 기수·말·창 | 변이 야수·돌진 기관 |

| 거인 | 일반의 약 2배, 큰 팔·무기 | 중량 갑주·망치 | 거대 갑각 팔·공성 구조 |

적군 이미지는 별도 병종이 아니라 동일 역할의 FactionVisualProfile이다.

## 9. 등급 시각 언어

| 등급 | 월드 표현 | UI 표현 |
|---|---|---|
| 일반 | 기본 역할 실루엣 | 무테 또는 얇은 프레임 |
| 엘리트 | 장비·기관 부속 1개 | 이중 모서리 프레임 |
| 영웅 | 실루엣 부속 2개, 짧은 잔광 | 초상 배지·스킬 2칸 |
| 전설 | 고유 부속·출격·승리 키포즈 | 움직이는 프레임·스킬 3칸 |
| 신화 보스 | 페이즈별 코어·실루엣 변화 | 전용 보스 프레임 |

- 등급은 단순 크기·색상 변경만으로 표현하지 않는다.
- 전설도 거인 아키타입의 크기 의미를 침범하지 않는다.
- 같은 RankProfile이 양 진영 이미지에 동일하게 적용된다.

## 10. 건물 아트 계약

- 상태: `건설 예정 / 건설 중 / 활성 / 업그레이드 / 비활성 / 파손 / 폐허`.
- 기본 병영 T2는 지붕, 입구와 외부 장비로 6전문화를 구분한다.
- 특수병단 T1은 비어 있는 준비 단상과 할인 축적 상태를 보여준다.
- 사제단·마도단·비행단·거인단은 지붕과 출입구 크기가 확연히 다르다.
- 시장은 수입, 농장은 식량 저장, 포탑은 사거리·대공 역할을 선택 시 시각화한다.
- 중간거점 노드는 전방 2·후방 1 배치를 유지한다.
- 비활성 건물은 폭발보다 기능이 꺼졌다는 표시를 사용한다.

## 11. 애니메이션과 전투 피드백

- 공용 병종마다 AnimationContract 하나를 사용한다.
- 아군·적군 이미지 시트는 같은 상태, 프레임 수, 배열, 피벗과 이벤트 프레임을 사용한다.
- 일반 인간형 첫 가설: 대기 4~6, 이동 6~8, 공격 6~10, 스킬 8~14, 사망 6~10, 승리 8~14프레임.
- 공격은 준비→판정→회복을 구분한다.
- 판정과 접촉·발사 이벤트 오차는 한 프레임 이내다.
- 가벼운 피격은 플래시·미세 반동으로 처리한다.
- 스테이지 승리는 2.5~4초 뒤 결과 UI로 연결한다.

## 12. VFX 전조 계약

- 위험 전조와 실제 판정 범위를 일치시킨다.
- 일반 0.25~0.6초, 영웅 0.6~1.0초, 전설·보스 1.0~1.5초 첫 기준.
- 적 위험은 외곽선, 아군 강화는 내부 문양으로 구분한다.
- 비행 고도는 지상 그림자와 얇은 수직 연결선으로 표시한다.
- 지속 장판 최대 불투명도 목표 45%.
- 일반 공격마다 큰 화면 흔들림과 히트 스톱을 사용하지 않는다.
- 성문 붕괴·거인·보스만 제한된 화면 반응을 사용한다.

## 13. 벨루

- 청백색 감시 정령형 시안을 유지한다.
- 우측 하단 48~64px 도크.
- 상태 반응은 0.5~2초 뒤 기본형으로 복귀한다.
- 표정 초안: 기본, 경고, 기쁨, 당황, 집중, 슬픔, 분노, 신비.
- 숫자는 HUD가 책임지고 벨루는 의미와 선택을 설명한다.
- 작업 영문 표기는 `Bellu`, 최종 로컬라이징에서 재검증한다.

## 14. 오디오

### 음악

- 기본 전투: 낮은 현악, 타악과 종의 반복 모티프.
- T-30부터 층을 추가하고 T-5에 짧은 경계종.
- W5·W10·W15·W20에서 밀도와 왜곡 증가.

### 효과음

- 룰렛 일반·엘리트·영웅·전설은 1·2·3·4단계 음정 상승.
- 벨루는 맑은 두 음 종 모티프.
- 방패·대검·창·궁·마법·비행·거인은 공용 아키타입별 재질·저역 차이를 사용한다.
- 아군·적군 이미지가 다르다는 이유로 별도 효과음을 대량 복제하지 않는다.
- 실제 가독성 검증에서 필요할 때만 진영별 짧은 음색 override를 승인한다.
- 거인·공성 공격은 준비음과 충돌음을 분리한다.
- 암살자 진입·도착은 짧고 낮은 신호로 구분한다.

### 음성

- 벨루는 맑고 중성적인 짧은 발화.
- 동일 문장은 60초 안에 반복하지 않는다.
- 숫자 정보는 HUD를 우선한다.

## 15. 제작·검증 순서

```text
공용 병종 역할 키포즈
→ 공용 AnimationContract
→ 아군 Visual Set
→ 동일 프레임 레이아웃의 적군 Visual Set
→ HUD·배경 위 축소 테스트
→ VFX·오디오 동기화
→ 최대 객체 수 혼전 검증
```

- 20개의 독립 병종을 제작하지 않는다.
- 대표 아키타입 3~5종의 양 진영 이미지 호환을 먼저 검증한다.

## 16. 검증 기준

- 미니맵 없이 3초 안에 세 라인의 성문·거점·접전지 상태를 파악한다.
- 전략 줌 0.85배에서 1초 안에 대표 병종 역할과 진영을 구분한다.
- 흑백에서도 양 진영과 역할의 주요 차이가 남는다.
- 모든 공용 아키타입에 아군·적군 Visual Set이 존재한다.
- 양 Visual Set의 상태·프레임·피벗·이벤트 프레임이 일치한다.
- `visual_faction_id` 변경이 전투 결과를 바꾸지 않는다.
- 암살자 선택 전 우회로가 보이지 않고 선택 중 도착 구역을 이해한다.
- 성문 붕괴, 점령과 승리 연출이 승인된 시간 안에 완료된다.
- 1280×720에서도 모션·VFX·HUD가 핵심 목표를 가리지 않는다.
- 동시 VFX 정상 목표 80개에서 위험 전조가 묻히지 않는다.
