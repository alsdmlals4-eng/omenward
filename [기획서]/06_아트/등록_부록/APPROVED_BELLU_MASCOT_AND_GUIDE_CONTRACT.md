# 승인된 마스코트 `벨루` 캐릭터·안내·UI·오디오 계약

- 상태: **캐릭터·역할·최종 시안·일시 상태 표현 승인됨**
- 승인일: 2026-07-15
- 적용 범위: 튜토리얼, HUD, 베일의 징조, 룰렛 결과, 전투 경보, 세계관 설명, 마케팅
- 세계관 명칭: `../../02_게임_디자인/등록_부록/APPROVED_OMENWARD_WORLD_AND_NAMING.md`

이 문서는 기존 `율비` 명칭을 사용하는 마스코트 문서보다 우선한다.

## 1. 한 문장 정의

> `벨루`는 실베른 성채의 오래된 경계종 울림에서 태어나, 베일의 징조와 전장의 이상 반응을 감지해 최전선 지휘관에게 적 정보와 선택지를 짧게 알려주는 작은 감시 정령이다.

## 2. 이름

공식 이름:

```text
벨루
```

이름은 종을 연상시키는 부드러운 `벨`과 루메른 문화권의 어감을 가진 `루`가 합쳐진 인상이다. 게임 안에서 어원을 직접 설명하지는 않는다.

기존 `율비` 명칭은 사용하지 않는다.

## 3. 단일 안내자 역할

프로토타입과 첫 캠페인에서 벨루가 다음 기능을 모두 담당한다.

1. 세계관 기본 설명
2. 적 라인·병종·수량·도착 시간 보고
3. 최초 시스템 조작 안내
4. 위험과 가능한 대응 선택지 요약
5. 룰렛·토큰·건물의 세계관식 번역
6. 베일의 법칙과 과거 사건 암시
7. 룰렛 등급·방어 성공·패배 반응

정찰관과 부관은 기능성 안내 NPC로 두지 않는다.

```text
벨루: 감지·보고·안내·조언·암시·반응
HUD: 정확한 숫자·시간·지속 상태·선택 결과
플레이어: 최종 판단과 명령
```

한 이벤트에서 최대 두 문장만 사용하고, 같은 정보가 반복되면 음성 대신 문양 점멸과 아이콘을 우선한다.

## 4. 성격과 말투

- 영리하고 반응이 빠르다.
- 친근하지만 위험을 가볍게 여기지 않는다.
- 플레이어의 실수를 비난하지 않는다.
- 정답을 대신 고르지 않고 위험과 선택지를 알려준다.
- 평소에는 명랑하지만 본진과 민간 후방이 위험하면 즉시 진지해진다.

발화 모드:

| 모드 | 목적 | 예시 |
|---|---|---|
| 감지 | 새 징조·보스·축복·저주 발견 | `지휘관, 상단의 베일이 울려요.` |
| 보고 | 라인·병종·수량·시간 전달 | `전사형 넷. 도달까지 30초예요.` |
| 안내 | 새 시스템 최초 조작 | `병영을 지으면 전사 증원이 늘어요.` |
| 조언 | 위험과 대응 선택지 요약 | `포탑이나 바리케이드로 시간을 벌 수 있어요.` |
| 암시 | 베일의 법칙과 과거 표현 | `징조는 틀리지 않아요. 선택이 달라질 뿐이에요.` |
| 반응 | 당첨·역전·패배 감정 | `좋아요! 지휘관의 선택이 통했어요.` |

## 5. 최종 외형

최신 승인된 요정형 시안을 사용한다.

- 작고 둥근 비인간 요정형 실루엣
- 큰 타원형 눈과 작은 입
- 아래로 부드럽게 늘어진 긴 귀·날개형 장식
- 반투명 요정 날개
- 청백색과 옅은 금색 파스텔 팔레트
- 몸 중앙의 단일 베일 문양
- 머리 위 빛 신호 기관
- 몸 아래 작은 경계종·방울
- 꽃·빛가루·이슬 같은 자연 정령 요소

고유 식별 요소:

```text
긴 귀형 요정 실루엣
+ 반투명 날개
+ 중앙 베일 문양
+ 빛 신호 기관
+ 작은 경계종
+ 전장 상태 반응
```

특정 기존 마스코트의 얼굴 비율, 귀 모양, 대표 색 배치와 포즈를 그대로 복제하지 않는다.

## 6. 일시 상태 반응

벨루는 대부분의 시간에 청백색 기본형을 유지한다.

```text
기본형
→ 상태 감지
→ 짧은 색·문양·표정·사운드 반응
→ 정보 전달
→ 잔광
→ 기본형 복귀
```

- 위험·보스·축복·저주·룰렛 등급은 영구 변신이 아니다.
- 반응은 경고등처럼 약 0.5~2초만 나타난다.
- 종료 뒤 0.2~0.4초 동안 기본형으로 복귀한다.
- 지속 효과와 남은 시간은 HUD 아이콘·타이머·웨이브 카드가 담당한다.
- 반복 경고는 전체 변색 대신 문양만 짧게 점멸한다.

우선순위:

```text
본진 치명 위험
> 보스·결전
> 웨이브 임박
> 필수 튜토리얼
> 축복·저주
> 룰렛 등급 반응
> 세계관 기억 반응
> 일반 감정 반응
```

## 7. 표정과 반응

필수 표정 8종:

1. 기본·대기
2. 기쁨
3. 대흥분·전설
4. 놀람
5. 경고
6. 걱정
7. 시무룩
8. 생각·일시정지

추가 반응:

- 축복 감지
- 저주 감지
- 보스·결전 감지
- 승리 후 안도

등급 반응:

```text
일반: 한 번 튀며 작은 빛 고리
엘리트: 두 번 튀며 별빛
영웅: 한 바퀴 회전과 큰 빛 고리
전설: 짧은 정지 → 문양 폭발 → 빠른 회전 → 환호
```

전설 반응도 약 1.2~1.8초 안에 끝내 전투 흐름을 방해하지 않는다.

## 8. HUD 계약

- 기본 위치: 화면 오른쪽 가장자리 하단 1/3
- 기본 초상 크기: 48~64px
- 말풍선: 최대 두 줄
- 기본 노출: 2.5~4초
- 클릭과 드래그 입력을 가로채지 않음
- 전장·룰렛 결과·건설 노드·웨이브 타이머를 가리지 않음
- 음성 없이도 텍스트·아이콘·색으로 같은 필수 정보를 전달
- 애니메이션 감소 옵션에서는 큰 움직임 없이 색·문양 점등만 사용

## 9. 보이스·사운드

- 맑고 작은 중성적 음색
- 어린아이 연기보다 기민한 작은 정령의 인상
- 일반 대사 2.5초 이내
- 보고 대사는 라인·수량·시간에 명확한 강세
- 플레이어가 요구 행동을 끝내면 남은 안내 음성을 취소할 수 있음
- 같은 대사 60초, 같은 알림 카테고리 15초 반복 제한

고유 사운드:

- 두 음의 작은 종 모티프
- 일반 알림: 밝은 두 음
- 위험: 낮은 첫 음과 짧은 떨림
- 보스: 낮은 공명과 약한 불협화음
- 축복: 밝은 3음
- 저주: 아래로 꺾이는 두 번째 음
- 전설: 짧은 정적 뒤 큰 종과 작은 잔향

## 10. 첫 30초 대사

> 벨루: 지휘관, 실베른 성채의 베일이 울려요.

> 벨루: 베일런 쪽에서 전사형 넷. 상단으로 와요.

> 벨루: 잠깐 멈춰도 괜찮아요. 명령은 계속 내릴 수 있어요.

## 11. 제작 산출물

- 정면·측면·후면·3/4 회전도
- 귀형 장식과 날개 구조 분해도
- 48px·64px·96px 축소 테스트
- 표정 8종과 추가 상태 반응
- 기본형 ↔ 상태색 팔레트
- 0.5~2초 상태 반응 애니메이션
- 0.2~0.4초 복귀 블렌드
- 발화 모드별 보이스 샘플
- 두 음 종 모티프

## 12. 검증 계약

- 모든 필수 안내는 벨루와 HUD만으로 이해할 수 있다.
- `율비`, `경계의 율` 명칭이 신규 UI·대사에 노출되지 않는다.
- 상태 반응 뒤 기본형으로 돌아와도 지속 상태가 끝난 것으로 오해되지 않는다.
- 벨루가 전장 조작이나 중요 정보를 가리지 않는다.
- 반복 발화로 전투 피로를 만들지 않는다.
