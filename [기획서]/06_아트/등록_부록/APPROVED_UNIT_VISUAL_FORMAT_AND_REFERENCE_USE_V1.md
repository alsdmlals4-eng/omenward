## 1. 최신 사용자 결정

병종 이미지의 실제 제작 형식은 **전장 UI 시안 안에서 전투 중인 소형 고해상도 픽셀 유닛 형식**으로 확정한다.

```text
실제 전장 삽입형 월드 스프라이트
+ 작은 크기의 역할 판독
+ 무기·자세 중심 실루엣
+ 제한된 고해상도 픽셀 디테일
```

과거의 `10병종 × 일반·엘리트·영웅·전설` 도감표는 병종과 등급 전개 관계를 비교하는 자료로만 남긴다. 도감표의 큰 전신 캐릭터 비율과 렌더링 방식은 실제 월드 스프라이트 제작 형식이 아니다.

## 2. 실제 전장 병종 이미지 형식

### 화면 역할

- 유닛 이미지는 캐릭터 일러스트가 아니라 전투 정보를 전달하는 월드 오브젝트다.
- 기본 전략 화면에서 세 라인과 다수 유닛을 동시에 볼 때 1초 안에 병종 역할과 진영을 읽어야 한다.
- 얼굴 표정이나 미세 장식보다 무기 길이, 자세, 몸통 덩어리, 이동 리듬과 공격 방향이 우선한다.

### 비율과 크기

- 인간형은 약 2.5~3등신의 전술 미니어처 비율을 기본으로 한다.
- 기본 화면 높이는 일반 인간형 34~40px 범위를 첫 제작 기준으로 사용한다.
- 상위 등급은 단순 확대보다 실루엣 부속, 무기 변화, 제한된 색·빛과 자세 차이로 위계를 표현한다.
- 거인은 인간형과 명확히 다른 크기군을 유지한다.

### 형태

- 머리, 몸통, 주 무기와 역할 부속을 큰 덩어리로 먼저 설계한다.
- 방패병의 방어면, 창병의 긴 수평축, 궁병의 활, 기병의 전후 길이처럼 한눈에 역할을 말하는 형태를 유지한다.
- 기본 외곽선은 어두운 중성색 1px를 기준으로 하며 밝고 어두운 전장 양쪽에서 읽히는 선택적 림을 허용한다.
- 3/4 측면 또는 전투 방향을 읽기 쉬운 각도를 사용하되 모든 병종이 같은 정면 도감 포즈로 서 있지 않게 한다.

### 디테일

- 픽셀 크기를 한 시트 안에서 혼용하지 않는다.
- 자동 안티앨리어싱과 생성형 이미지의 매끈한 명암을 최종 자산에 그대로 남기지 않는다.
- 재질은 2~4단 명암과 제한된 하이라이트로 표현한다.
- 일반 등급에서 장식과 발광을 절제하고 영웅·전설에서만 기능적인 장식과 순간 VFX를 확장한다.

## 3. 공용 병종과 진영 이미지

오멘워드는 전투 데이터 기준 공용 병종 10개를 사용한다.

```text
UnitArchetypeProfile
+ AnimationContract
+ FactionVisualProfile
```

- 아군과 적군은 같은 상태 목록, 프레임 수, 피벗, 공격 이벤트 시점과 실제 판정 계약을 공유한다.
- 양 진영 이미지는 팔레트만 바꾸지 않고 소재, 외곽 형태, 장비 또는 생물 기관으로 구분한다.
- 적군 이미지 때문에 별도 병종 데이터, Scene, 스킬, 애니메이션 타이밍을 만들지 않는다.
- 체형 차이로 공용 프레임 계약을 지키기 어렵다면 데이터 계약을 복제하지 않고 이미지 구조를 먼저 조정한다.

## 4. 등급별 시각 위계

도감표에서 유지할 핵심은 `같은 병종의 등급 상승을 한눈에 비교한다`는 구조다.

### 일반

- 역할에 필요한 최소 실루엣과 장비.
- 기능과 무관한 망토, 왕관, 후광, 대형 보석 금지.

### 엘리트

- 방어구 또는 무기 한 영역을 강화한다.
- 팔레트 대비와 재질 표현을 한 단계 높인다.
- 기본 실루엣과 공격 방향은 유지한다.

### 영웅

- 병종 역할을 과장하는 기능 부속과 자세 변화를 추가한다.
- 짧은 스킬 VFX와 명확한 계급 포인트를 허용한다.
- 다른 병종으로 오인될 정도의 무기 교체는 금지한다.

### 전설

- 화면에서 즉시 읽히는 대표 실루엣과 제한된 고급 조명·후광·배너를 사용할 수 있다.
- 상시 과도한 발광으로 전투 가독성을 해치지 않는다.
- 일반 인간형 전설이 거인의 크기 의미를 침범하지 않는다.

## 5. 참고 이미지 해석

### 승인 기준 이미지

`../증거/VISUAL_REFERENCE_INDEX.md`의 `VR-001`을 병종 월드 스프라이트 형식과 실제 게임 삽입 밀도의 우선 참고로 사용한다.

참고 대상:

- 전장 속 유닛의 크기와 디테일 균형.
- 병종을 무기·자세·덩어리로 구분하는 방식.
- 아군과 적군의 색·소재·실루엣 구분.
- 전장, 전투, HUD와 하단 조작 패널이 함께 보이는 화면 밀도.

비권위 요소:

- 임시 UI 문구와 수치.
- 이미지 안의 전장 경로, 거점 수와 건물 위치.
- 좌하단 전장 요약 UI.
- 이미지에 보이는 병종 편성·비용·웨이브 수치.

### 과거 도감표

`VR-002`는 다음에만 사용한다.

- 공용 10병종 목록 확인.
- 일반·엘리트·영웅·전설의 상대적 위계 비교.
- 같은 병종 안에서 무기와 자세가 단계적으로 강화되는 방향.

도감표의 전신 비율, 캐릭터 일러스트 밀도, 등급별 정확한 장식과 외형은 복제하지 않는다.

## 6. 제작 파이프라인

```text
실제 전장 축소 크기에서 실루엣 키포즈
→ 일반 등급 idle·move·attack 테스트
→ 같은 공용 계약의 아군·적군 Visual Set
→ 5기 이상 중첩 전투 가독성 테스트
→ 엘리트·영웅·전설 시각 위계 확장
→ UI 초상·도감용 확대 자산 분리 제작
```

도감·카드·초상화가 필요해도 월드 스프라이트를 무리하게 확대해 대신하지 않는다. 반대로 도감용 전신 원화를 축소해 월드 스프라이트로 사용하지 않는다. 같은 디자인 언어를 공유하되 용도별 자산을 분리한다.

## 7. 수직 슬라이스 우선 검증

대표 병종으로 다음을 먼저 확인한다.

- 방패병: 방어면과 낮은 중심.
- 궁병: 활과 발사 방향.
- 암살자: 낮은 이동 자세와 후열 출현.
- 사제: 지원 병종의 직립 실루엣.
- 거인 또는 공성 더미: 인간형과 다른 크기·충돌감.

완료 기준:

- 1920×1080과 1280×720에서 다섯 역할을 색상 없이도 구분한다.
- 같은 병종 5기가 겹쳐도 공격 방향을 읽을 수 있다.
- 아군과 적군 이미지가 다른 진영으로 보이지만 같은 애니메이션 이벤트에 정확히 맞는다.
- 일반·엘리트·영웅·전설이 같은 병종으로 보이면서 위계가 구분된다.
- 도감표 형식이 월드 스프라이트 제작 기준으로 다시 유입되지 않는다.

## 8. 변경 규칙

사용자 승인 필요:

- 월드 스프라이트를 큰 전신 캐릭터 또는 카드 일러스트 형식으로 변경.
- 인간형 기본 비율과 화면 크기군의 대규모 변경.
- 공용 병종 계약을 깨고 진영별 프레임 수·피벗·공격 타이밍을 분리.
- VR-001 대신 다른 이미지를 최우선 병종 형식 기준으로 교체.

PoC 조정 가능:

- 정확한 픽셀 캔버스와 프레임 수.
- 외곽선 색, 팔레트 수와 재질 명암 단계.
- 등급별 장식량과 순간 VFX 강도.
- 전략 줌에서의 실제 표시 높이.
