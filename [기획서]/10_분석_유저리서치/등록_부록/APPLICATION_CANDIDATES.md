# 벤치마킹 적용 후보

이 문서는 빠른 검토용 요약이다. 책임 원본은 `0001-core-game-benchmark-proposal.md`다.

## A — 수직 슬라이스 필수 후보

- 건설 전 룰렛 확률 변화 미리보기
- 현재 토큰 장부와 X 토큰 표시
- T-30/T-15/T-5 적 웨이브 전조
- 상성·사거리·타기팅 오버레이
- 웨이브 종료 후 라인별 패배·승리 원인 요약
- 노드 건설 메뉴의 경제·생산·방어 비교

## B — 이후 실험 후보

- 럭키 찬스 실패 누적 보정
- 건물 티어 2갈래 선택형 업그레이드
- 전방 생산시설 생산 보너스
- 토큰 집중 또는 일시 비활성화 수단
- 런 종료 빌드 요약과 재도전 프리셋

## C — 초기 제외 후보

- 수십 개 병종과 복합 친화도
- 랜덤 유닛 능력치·각인
- 대형 메타 성장 트리
- 직접 조작 영웅 전투
- PvP 랭크·시즌
- 흡수·진화 계보

모든 항목은 사용자 승인 전 확정 기획이 아니다.
