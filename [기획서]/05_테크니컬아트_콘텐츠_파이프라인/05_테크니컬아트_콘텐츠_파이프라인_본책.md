# OMENWARD 테크니컬 아트·콘텐츠 파이프라인 본책

## 목표

공용 아키타입의 양 진영 Visual Set이 프레임·피벗·이벤트 계약을 공유하고, 자산 출처·승인·교체 필요 상태가 추적된다.

## 배경과 의도

진영 차이는 전투 규칙이 아닌 이미지·초상화·아이콘·팔레트·표시명으로 표현한다.

## 범위

병종 비주얼 형식, AnimationContract, 성능·데이터 준비 PoC, 이미지 인덱스를 등록 부록으로 승계한다.

## 규칙과 제약

- 아군·적군 시트는 같은 상태 목록·프레임 수·배열·피벗·판정 이벤트를 사용한다.
- 생성 이미지는 최종 텍스처가 아니며, 실제 자산은 권리·픽셀·관절·무기·광원·축소 가독성 검수를 거친다.

## 현재 상태와 다음 작업

대표 아키타입 3~5종의 양 진영 호환을 먼저 실제 게임 크기에서 검증한다.

## 검증과 완료 기준

Visual Set 호환 표, import 결과, 40px 축소·혼합 배치 검수와 Asset Manifest 해시를 확인한다.
