## 1. 설계 목표

첫 네 공세는 다음 학습을 순서대로 검증한다.

```text
1공세: 일반 검사 한 명의 배치·자동전투·횡베기
2공세: 두 라인 판단·포탑 또는 바리케이드에 의한 역전
3공세: 룰렛 조작으로 얻은 엘리트의 확실한 전투력 상승
4공세: Tier 2 전사 선택과 세 라인 종합 판단
```

핵심 감정 곡선:

```text
간신히 승리
→ 병력만으로는 부족함
→ 지휘관의 선택으로 역전
→ 엘리트의 강함 체감
→ 전문 병종으로 더 복잡한 공세 해결
```

## 2. 공통 전투 규칙

### 2.1 결정론

- 튜토리얼은 고정 시드와 고정 출격 순서를 사용한다.
- 기본 치명타 5%는 유지하되 고정 RNG 결과로 재현 가능해야 한다.
- 동일 입력이면 각 공세의 결과가 같은 시뮬레이션 틱에 재현되어야 한다.
- 플레이어 조작 차이는 배치 위치, 건설·전술 선택과 사용 시점에서 발생한다.

### 2.2 기준 시간

- `공세 충돌 시점`은 적 선두가 중앙 접전지 주 교전 반경에 들어오는 순간이다.
- 베일의 징조는 기본적으로 충돌 30초 전에 표시한다.
- 적 출격은 충돌 약 10~12초 전에 적 중간요새에서 시작한다.
- 출격 전 18~20초 동안 플레이어는 편성·건설·룰렛·배치를 준비한다.

### 2.3 초기 피해 모델

첫 네 공세는 복잡한 방어력 공식을 검증하는 구간이 아니다.

```text
기본 물리 피해 = 공격력
방어력·관통 = 0을 기준으로 시작
치명타 = 고정 시드의 5% 규칙
```

방패병의 원거리 피해 감소처럼 학습에 필요한 고유 패시브만 별도 계수로 적용한다.

## 5. 병영 자동생산 보장

첫 룰렛 외에도 병영이 일반 병력을 자동생산한다는 사실을 자연스럽게 보여준다.

### 5.1 Tier 1 병영 생산

```text
기준 생산 간격: 105초
첫 생산도 같은 간격 사용
생산 진행은 일시정지 중 멈춤
```

튜토리얼 목표 타임라인에서 병영이 약 1:05에 가동되면 예상 완료는 다음과 같다.

| 완료 시점 | 결과 |
|---|---|
| 약 2:50 | 일반 검사 B |
| 약 4:35 | 일반 검사 C |
| 약 6:20 | 일반 검사 D |
| 약 8:05 | Tier 2 선택 완료 시 선택 병종 |

Tier 2 업그레이드 중 생산 진행률은 유지한다. 업그레이드가 약 8:00 전에 끝나면 8:05에 완성되는 병력부터 방패병·대검병·광전사 중 선택 병종으로 생성한다.

생산 일정이 공세 구성과 어긋날 경우 튜토리얼은 몰래 병력을 생성하지 않고, 생산 진행바와 완료 시점을 조정해 플레이어에게 원인을 공개한다.

### 6.2 건설 프로필

| 항목 | 초기값 |
|---|---:|
| 건설 시간 | 22초 |
| 건설 시작 체력 | 완공 최대 체력의 25% |
| 건설 중 체력 증가 | 진행도에 따라 선형 증가 |
| 기능 활성화 | 완공 틱부터 즉시 공격 |

두 번째 공세 튜토리얼에서는 충돌 약 23초 전에 포탑·바리케이드 선택을 강조하고 자동 일시정지한다. 포탑을 즉시 선택하면 적 선두가 검사의 전열에 닿기 약 0.5~2.5초 전에 완공되는 것을 목표로 한다.

플레이어가 선택을 이해하는 데 사용한 현실 시간은 일시정지 때문에 전투 시간에서 차감되지 않는다.

### 6.3 성공 연출

```text
적이 사거리 진입
→ 건설 골조 90% 이상
→ 완공 점등
→ 첫 포탄 즉시 발사
→ `포탑 완공` 원인 태그
```

포탑 한 기는 상단 6기를 혼자 제거하지 못하고, 검사와 함께 싸워야 한다.

## 7. 바리케이드 기준

기존 전술 명령 계약을 따른다.

| 항목 | 초기값 |
|---|---:|
| 비용 | 12골드 |
| 시전 지연 | 1.5초 |
| 최대 체력 | 350 |
| 지속시간 | 18초 |
| 개별 쿨다운 | 30초 |
| 동시 활성 | 라인당 1개 |

상단 소형 근접 6기가 집중 공격하면 약 8~11초를 버티는 것을 목표로 한다.

바리케이드 뒤에 있는 검사는 차단된 적을 공격할 수 있다. 바리케이드는 공격하지 않으며, 포탑 완공이나 병력 합류를 위한 시간을 제공한다.

성공 원인 태그:

```text
바리케이드 지연 +8.4초
```

실제 수치는 전투 결과에 따라 표시하되, 단순히 `방어 성공`만 보여주지 않는다.

## 8. 첫 4공세 구성

## 8.1 제1공세 — 일반 검사 체험

```text
라인: 상단
소형 근접 베일종: 4기
출격 간격: 0.65초
징조: 충돌 30초 전
목표 교전 시간: 8~11초
```

사용 가능 병력:

- 룰렛으로 얻은 일반 검사 A 1기

의도한 결과:

- 검사가 횡베기를 최소 1회 사용한다.
- 적 4기를 모두 처치한다.
- 검사 잔여 체력 30~60%.
- 본진·중간요새 피해 없음.

실패 판정:

- 검사가 횡베기 전에 사망함.
- 적 2기 이상이 검사를 통과함.
- 전투가 15초 이상 지속됨.

---

## 8.2 제2공세 — 두 라인과 첫 역전

```text
상단: 소형 근접 6기 / 0.45초 간격
중단: 소형 근접 3기 / 0.70초 간격
중단 출격 시작: 상단보다 1.0초 늦음
징조: 충돌 30초 전
```

보장 병력:

- 일반 검사 A: 제1공세 생존자
- 일반 검사 B: 병영 첫 자동생산

권장 배치:

- 잔여 체력이 낮은 검사 A → 중단 3기
- 새 검사 B → 상단 6기

상단은 다음 중 하나를 사용해야 안정적으로 막을 수 있다.

### 선택 A — 포탑

- 상단 전방 노드에 Tier 1 포탑 건설.
- 충돌 직전 완공.
- 포탑과 검사 B가 함께 상단 6기 제거.

목표 결과:

- 상단 검사 잔여 체력 35~60%.
- 포탑 잔여 체력 60% 이상.
- 상단 교전 7~11초.

### 선택 B — 바리케이드

- 상단 지정 전술 지점에 설치.
- 적을 8~11초 지연.
- 검사 B가 차단된 적을 공격.

목표 결과:

- 상단 검사 잔여 체력 65% 이상.
- 바리케이드 파괴 또는 잔여 체력 25% 이하.
- 상단 교전 11~16초.

중단 목표:

- 검사 A가 생존하되 잔여 체력 10~40%.
- 중단은 추가 전술 없이 방어 가능.

선택 수단 없이 상단 검사 한 명만 배치하면 5~6번째 적이 검사를 돌파하거나 검사가 사망해야 한다.

---

## 8.3 제3공세 — 엘리트 강화 체험

```text
상단: 소형 근접 4기 / 0.60초 간격
중단: 소형 근접 6기 / 0.45초 간격
징조: 충돌 30초 전
```

보장 병력:

- 생존 일반 검사들
- 병영 자동생산 검사 C
- 두 번째 룰렛의 엘리트 전사 1기

권장 배치:

- 엘리트 전사 → 중단 6기
- 일반 검사 → 상단 4기

목표 결과:

- 엘리트가 강화 횡베기를 최소 1회 사용해 4기 이상을 동시에 타격.
- 엘리트 잔여 체력 45~70%.
- 중단 교전 6~10초.
- 상단 일반 검사는 지원 병력에 따라 20~60% 체력으로 생존.
- 플레이어가 엘리트의 크기·참격 범위·처치 속도를 일반과 구분할 수 있음.

검증 질문:

> 수치 표시를 보지 않아도 어떤 유닛이 엘리트인지 알 수 있었는가?

목표 긍정 응답은 90% 이상이다.

## 8.4 제4공세 — Tier 2 전사와 세 라인

```text
상단: 소형 근접 3기 / 0.70초 간격
중단: 소형 근접 6기 + 소형 원거리 2기
하단: 소형 근접 3기 / 0.70초 간격
원거리 출격: 중단 근접 선두보다 2.0초·2.8초 늦음
징조: 충돌 30초 전
```

보장 병력:

- 생존 일반 검사
- 병영 자동생산 검사 D
- 엘리트 전사
- 8:05 전후 완성되는 선택 Tier 2 전사

권장 배치:

- 선택 Tier 2 전사 + 일반 검사 1기 → 중단
- 엘리트 또는 일반 검사 → 상단·하단 분담

### 방패병 체험

- 중단 전열을 오래 유지한다.
- 원거리 피해 감소 아이콘이 최소 2회 표시된다.
- 세 선택 중 처치 시간은 가장 느려도 잔여 체력은 가장 높다.

### 대검병 체험

- 근접 5기 이상이 모였을 때 대회전 베기를 사용한다.
- 세 선택 중 중단 근접 병력 처치 시간이 가장 빠르다.
- 원거리 적에게 접근하는 동안 체력 손실이 눈에 보인다.

### 광전사 체험

- 체력 50% 이하에서 광전 본능이 발동한다.
- 공격속도 변화와 흡혈 회복이 전투 중 보인다.
- 전투 종료 체력은 방패병보다 낮지만 발동 직후 회복 상승 구간이 있어야 한다.

공통 목표:

- 선택 병종이 스킬·패시브를 최소 한 번 보여준다.
- 세 선택 모두 중단을 12~20초 안에 방어할 수 있다.
- 본진 피해 없음.
- 상·하단 중 한 곳을 완전히 방치하면 적이 중간요새를 위협한다.
- 세 라인을 한눈에 확인하고 병력을 분배해야 한다.

## 10. 자원 안전 계약

정확한 시작 금화와 건물 비용은 별도 경제 표에서 확정한다. 다만 두 번째 공세 시작 시 다음 조건을 반드시 만족해야 한다.

```text
병영·필수 룰렛 비용을 지불한 뒤에도
포탑 건설 또는 바리케이드 사용 중 하나는 항상 가능
```

플레이어가 선택 이전에 불필요한 소비를 했더라도 튜토리얼은 다음 방식 중 하나로 선택지를 보존한다.

1. 사용 전 경고와 되돌리기 제공.
2. 선택 단계 진입 전 최소 금화 보정.
3. 튜토리얼 전용 포탑 건설 할인.

원인 없이 무료 건물·전술을 생성하지 않는다. 보정이 발생하면 `실베른 비상 보급`으로 명확히 표시한다.

## 11. 조정 순서

공세가 너무 쉽거나 어려울 때 다음 순서로 조정한다.

```text
출격 간격 ±0.10초
→ 적 공격력 ±1
→ 적 체력 ±5
→ 아군 스킬 피해 ±5
→ 포탑 공격 간격 ±0.10초
→ 바리케이드 체력 ±35
→ 마지막에 아군 최대 체력 조정
```

유닛 수를 먼저 바꾸면 화면 밀도와 학습 의도가 함께 바뀌므로 후순위로 둔다.

## 13. 합격 기준

### 제1공세

- 일반 검사 단독 승률 95~100%.
- 잔여 체력 중앙값 30~60%.
- 횡베기 관찰률 95% 이상.

### 제2공세

- 포탑 또는 바리케이드 선택 시 양 라인 방어 성공률 90% 이상.
- 둘 다 사용하지 않은 상단 단독 방어 성공률 20% 이하.
- `내 선택이 역전을 만들었다` 응답 80% 이상.

### 제3공세

- 엘리트가 일반보다 강하다고 느낀 응답 90% 이상.
- 강화 횡베기 4기 이상 동시 타격률 80% 이상.

### 제4공세

- 세 Tier 2 선택 모두 방어 성공률 80~95%.
- 선택 병종의 고유 장점을 설명할 수 있는 비율 75% 이상.
- 세 라인 중 위험 라인을 3초 안에 찾는 비율 90% 이상.

### 전체

- 첫 네 공세 중 본진 피해를 입은 플레이어 15% 이하.
- 한 번의 실수는 실패 복구로 계속 진행 가능.
- 수치가 튜토리얼의 고정 정답을 숨기지 않고 선택 이유를 명확히 보여줌.
