# OMENWARD 작업 시작

## 목적

오멘워드는 건물 구성과 룰렛 확률 변화, 공용 10병종 획득, 독립 3라인 배치, 거점·성문 공방을 연결하는 싱글플레이 PvE 전략 오토배틀이다.

## 10분 콜드 스타트 순서

1. 이 문서와 `ACTIVE_CONTEXT.md`에서 현재 단계·다음 작업·금지 범위를 확인한다.
2. `DOCUMENTATION_MAP.md`에서 질문의 책임 본책과 1:1 분야 스킬을 고른다.
3. `DESIGN_DOCUMENT_REGISTRY.json`과 `SKILL_REGISTRY.json`에서 현행 원본·경로·발행 상태를 확인한다.
4. 실제 코드·Scene·데이터·테스트와 `DEVELOPMENT_GATES.md`의 검증 경로를 대조한다.

## 현재 상태

- 기준 Base: `d2457e75a856260d309203e20262f2a2142d2dd6` (Base PR #18의 Linux·Windows 발행 검증 통과 커밋).
- 현재 프로젝트 기준: Issue #41 정본 worktree의 수직 슬라이스 기준선과 Base PR #18(`d2457e7`). 원격 `main`의 `4cb0ae4`는 마이그레이션 보존 기준으로만 유지한다.
- 게임 코드·Scene·데이터·저장 형식은 이 문서 구조 작업에서 변경하지 않는다. `project.godot`은 Godot 4.7 feature 메타데이터만 예외로 하며 표시 계약은 회귀 테스트로 보호한다.
- 기존 승인 문서는 등록 부록으로 보존한다. 충돌을 해결할 수 없는 내용은 삭제하지 않고 `[확인 필요]`로 남긴다.
