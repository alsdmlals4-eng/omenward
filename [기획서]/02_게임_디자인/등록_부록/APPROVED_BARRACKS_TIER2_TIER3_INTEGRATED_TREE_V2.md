## 1. 전체 성장 구조

```text
Tier 1 기본 병영
└─ 검사 / 전사 토큰

Tier 2 전문화
├─ 방패병 / 전사 토큰
├─ 대검전사 / 전사 토큰
├─ 사제 / 사제 토큰
├─ 암살자 / 암살자 토큰
├─ 창병 / 창병 토큰
├─ 궁병 / 궁병 토큰
└─ 기병 / 기병 토큰

Tier 3
└─ 선택한 Tier 2 계열의 상위 세부 병종 1개
   + 공통 운영 교리 1개
```

`대검전사`, `치유사제`, `전쟁사제` 등의 명칭은 1차 작업명이다. 역할 구조가 우선이며 최종 세계관 명칭은 후속 승인한다.

핵심 원칙:

- 한 병영은 Tier 2 전문화 하나만 선택한다.
- 서로 다른 병영은 서로 다른 전문화를 선택할 수 있다.
- Tier 3에서는 상위 세부 병종 하나와 운영 교리 하나를 함께 선택한다.
- 자동생산은 모든 Tier에서 일반 등급만 생산한다.
- 엘리트·영웅·전설은 룰렛 결과로만 획득한다.
- 업그레이드 중에는 이전 Tier 생산과 토큰을 유지한다.
- 생산 진행률은 보존하며 완료 뒤 첫 완성분부터 새 병종을 생산한다.
- 진행 중인 룰렛은 유지하고 다음 회전부터 새 토큰을 반영한다.

## 2. 대검병·광전사 통합

기존의 독립 `대검병`과 `광전사` Tier 2 전문화는 폐기하고 **대검전사** 하나로 합친다.

```text
base_unit_family = warrior
specialization_t2_id = greatblade_warrior
roulette_token_family = warrior
```

Tier 2 대검전사의 기본 역할:

- 느리지만 넓은 전방 베기.
- 중장갑과 방어형 적에게 유효한 약한 파쇄.
- 체력이 낮아질수록 공격속도 또는 피해가 소폭 증가하는 격노.
- 제한적인 흡혈 또는 처치 회복.
- 파쇄·격노·흡혈 중 어느 하나도 Tier 3 수준으로 강하지 않다.

이 통합으로 공격형 근접 전문화의 선택 목적을 단순화한다.

```text
방패병 = 버티기
대검전사 = 공격하기
```

### Tier 3 분기

#### 파쇄검병

- 중장갑·방패·구조물 대응.
- 파쇄 중첩과 높은 단발 피해.
- 광폭전사보다 안정적이지만 공격속도 고점은 낮다.

#### 광폭전사

- 저체력 격노·처치 연쇄·흡혈 강화.
- 경장갑 군집과 긴 난전에 강하다.
- 생존 안정성과 구조물 파괴는 파쇄검병보다 낮다.

즉, Tier 2에서 두 역할을 체험하고 Tier 3에서 원하는 공격 방식을 전문화한다.

## 3. 사제·깃발병 통합

독립 Tier 2 `깃발병` 전문화와 `군기 토큰`은 폐기한다. 지원 계열은 **사제**로 통합한다.

```text
base_unit_family = priest_support
specialization_t2_id = priest_support
roulette_token_family = priest
```

Tier 2 사제는 회복과 격려를 모두 약하게 가진 혼합 지원형이다.

- 같은 라인의 부상 아군을 소량 회복한다.
- 주변 아군에게 짧고 약한 전투 격려를 제공한다.
- 전열 뒤에서 아군 군집을 따라간다.
- 단독 전투력은 같은 Tier 전사보다 낮다.
- 전역·다른 라인 지원은 하지 않는다.

### Tier 3 분기

#### 치유사제

- 직접 회복량·회복 대상 수·재생 효과 강화.
- 약한 상태이상 완화 또는 보호막 제공.
- 공격력·공격속도 버프는 전쟁사제보다 낮다.

#### 전쟁사제

- 기존 깃발병의 오라·군기·집결·전선 지휘 역할을 흡수한다.
- 높은 군기나 성물을 들고 전장 보조 지휘관으로 식별한다.
- 공격속도·이동속도·피해·진형 유지 버프를 강화한다.
- 직접 회복량과 지속 회복 능력은 치유사제보다 낮다.
- 동일 지휘 오라는 `strongest_only` 규칙을 유지한다.

따라서 깃발병의 전투 기능과 시각적 정체성은 사라지지 않고 전쟁사제의 전문 역할로 이동한다.

## 4. 암살자 Tier 2 추가

암살자는 용병 전용 후보에서 제외하고 기본 병영 Tier 2 정식 전문화로 추가한다.

```text
base_unit_family = assassin
specialization_t2_id = assassin
roulette_token_family = assassin
```

Tier 2 암살자의 역할:

- 같은 라인 후열의 궁병·사제·지휘관형 적 우선 공격.
- 후방 공격과 첫 타격에 높은 피해.
- 낮은 체력과 낮은 정면 지속 교전 능력.
- 다른 라인으로 순간이동하지 않는다.
- 전열을 완전히 무시하는 무제한 텔레포트는 사용하지 않는다.
- 은신 또는 침투는 명확한 탐지·해제 조건을 가진다.

### Tier 3 분기

#### 그림자암살자

- 짧은 은신·접근·후방 폭발 피해.
- 궁병·사제·영웅 같은 핵심 후열 단일 제거.
- 공격 뒤 장기 교전 능력은 낮다.

#### 맹독암살자

- 독·출혈·회복 감소를 이용한 지속 피해.
- 높은 체력의 엘리트·영웅·보스 보조 대응.
- 첫 타격 폭발력은 그림자암살자보다 낮다.
- 보스 대상 상태이상은 효과량 또는 지속시간이 감소할 수 있다.

## 8. Tier 3 운영 교리

Tier 3 병영은 세부 병종과 별도로 다음 교리 하나를 선택한다.

### 대량생산

- 자동생산 간격 감소.
- 초기 가설: 생산시간 -20%.
- 등급과 룰렛 상위 등급 확률은 바꾸지 않는다.

### 정예훈련

- 해당 병영에서 새로 생산되는 일반 유닛만 강화한다.
- 초기 전투병 가설: 최대 체력 +8%, 피해 +8%.
- 사제 초기 가설: 최대 체력 +8%, 회복·버프 효과량 +5%.
- 이미 생산된 유닛·룰렛 유닛·용병에는 적용하지 않는다.
- 엘리트 등급을 생성하지 않는다.

### 토큰 증폭

- 선택 계열 토큰 하나를 결정론적으로 정해진 릴 하나에 추가한다.
- 적용 릴은 선택 전에 공개한다.
- 건물 파괴·철거 뒤 다음 회전부터 제거한다.

## 10. 상위 등급 경계

고정 상위 등급 계열:

```text
warrior
priest_support
assassin
spearman
archer
cavalry
```

- 일반은 선택된 출처 병영의 실제 세부 병종을 생성한다.
- 엘리트·영웅·전설은 토큰 계열별 고정 템플릿을 생성한다.
- Tier 3 세부 병종은 고정 상위 등급의 이름·외형·기본 스킬 정체성을 교체하지 않는다.
- 선택된 출처 Tier와 지원 초점은 패시브 강화와 계수 수정에 적용할 수 있다.
- 자동생산은 항상 일반 등급이다.
- 플레이어 신화급은 존재하지 않는다.

사제 계열 상위 등급은 공통 사제 템플릿을 사용하되, Tier 3 출처가 치유사제인지 전쟁사제인지에 따라 `healing_focus` 또는 `command_focus` 수정자를 적용할 수 있다. 이는 고정 템플릿의 정체성을 바꾸지 않고 지원 비중만 조정한다.

## 11. 기본 병영 제외 병종

첫 프로토타입에서 기본 병영 Tier 2 트리에 포함하지 않는 병종:

- 공성병.
- 비행병.

암살자는 더 이상 제외 병종이 아니다. 공성병과 비행병은 용병·특수 생산시설·캠페인 해금 경로로 분리한다.

## 12. 튜토리얼 경계

첫 10분 Tier 2 전투 선택은 다음 세 방향을 우선 사용한다.

```text
방패병 = 생존
대검전사 = 정면 공격
암살자 = 후열 제거
```

사제·창병·궁병·기병은 튜토리얼의 기본 시스템 밀도를 높이지 않도록 이후 정규 스테이지에서 순차 해금한다.

암살자 선택 시 제4공세에 원거리 또는 지원형 적을 명확히 배치해 후열 제거 효과가 즉시 보이도록 한다. 정확한 튜토리얼 편성은 첫 네 공세 책임 문서의 후속 버전에서 조정한다.

## 14. 검증 계약

1. 대검병과 광전사는 독립 Tier 2 선택지로 표시되지 않는다.
2. 대검전사 하나가 광역·파쇄·격노의 기본 체험을 제공한다.
3. Tier 3 파쇄검병과 광폭전사는 명확히 다른 전투 역할을 가진다.
4. 깃발병은 독립 Tier 2 유닛·토큰으로 표시되지 않는다.
5. 사제는 Tier 2에서 약한 회복과 약한 버프를 모두 제공한다.
6. 치유사제는 회복 전문, 전쟁사제는 버프·군기 지휘 전문으로 구분된다.
7. 전쟁사제는 기존 깃발병의 같은 라인·중첩 제한을 유지한다.
8. 암살자는 기본 병영 Tier 2 선택지와 독립 토큰을 가진다.
9. 암살자는 다른 라인으로 순간이동하지 않는다.
10. 후열 우선 공격은 명확한 탐지·경로·해제 규칙을 가진다.
11. 공성병과 비행병은 기본 병영 트리에 포함되지 않는다.
12. 자동생산은 항상 일반 등급이다.
13. Tier 3은 상위 병종 하나와 운영 교리 하나를 함께 선택한다.
14. 15분 스테이지에서 방어·공격·지원·침투·대기병·원거리·기동 선택이 모두 의미가 있어야 한다.

- 암살자 은신·후방·독·회복 감소 수치.
- 절대 HP·공격력·공격속도·사거리.

- 계열별 엘리트·영웅·전설 고정 유닛.
