# 승인된 오멘워드 세계관·명칭 계약

- 상태: **공식 명칭 승인됨**
- 승인일: 2026-07-15
- 적용 범위: 게임명, 세계관, 튜토리얼, HUD, 웨이브 카드, 대사, 마케팅, 이후 모든 기획 문서

이 문서는 기존 `Roulettebound`, `경계의 율`, `율비`, `은종성채`, `무명야` 등 임시·이전 명칭보다 우선한다.

## 1. 게임 공식 명칭

```text
오멘워드
```

영문 표기:

```text
OMENWARD
```

첫 캠페인 또는 프로토타입 부제:

```text
오멘워드: 실베른 성채
OMENWARD: Silvern Citadel
```

핵심 의미:

- 공세 전 나타나는 징조를 읽는다.
- 최전선의 방벽과 병력을 지휘한다.
- 확률을 설계해 예고된 위기를 뒤집는다.

태그라인:

```text
확률을 설계하고, 최전선을 지켜라.
Build the odds. Hold the frontier.
```

저장소명과 내부 코드명 `roulettebound-prototype`은 구현 마이그레이션 계획이 승인될 때까지 유지한다.

## 2. 명명 원칙

세계관 이름은 다음 형식을 사용한다.

```text
영어권 판타지처럼 들리는 한글 고유명사
+ 역할을 즉시 이해할 수 있는 한국어 보통명사
```

권장 예:

- 루메른 왕국
- 실베른 성채
- 트리븐 전선
- 베일런 황야

피하는 방향:

- `실버벨 배스천`처럼 영어 일반명사를 모두 음차
- `은종성채`처럼 번역투 고유명사만 사용
- 같은 문화권에서 음차형과 한자풍 고유명사를 불규칙하게 혼합

## 3. 공식 세계관 명칭

| 대상 | 공식 명칭 | 역할 |
|---|---|---|
| 국가 | **루메른 왕국** | 인간 문명의 중심 국가 |
| 인간 생활권 | **루미엔 영토** | 루메른이 통치하며 불빛과 질서를 유지하는 영역 |
| 첫 최전선 요새 | **실베른 성채** | 오래된 경계종과 벨루의 기원이 있는 성채 |
| 세 라인 전선 | **트리븐 전선** | 상·중·하 세 통로가 만나는 방위선 |
| 괴물 외부 영역 | **베일런 황야** | 베일 너머의 광대한 미지 영역 |
| 방위 조직 | **루메른 경계군** | 최전선과 성채를 지키는 군단 |
| 첫 캠페인 부대 | **실베른 수비대** | 플레이어가 지휘하는 현지 부대 |
| 적 현장 통칭 | **너머의 괴물** | 초반에 사용하는 직관적 표현 |
| 적 공식 분류 | **베일종** | 군사·학술 문서의 생물 분류 |
| 적 웨이브 | **경계 공세** | 웨이브의 세계관 표현 |
| 웨이브 전조 | **베일의 징조** | 다음 공세를 미리 드러내는 현상 |

관계:

```text
루메른 왕국
└─ 루미엔 영토
   └─ 트리븐 전선
      └─ 실베른 성채
         ↔ 베일
            ↔ 베일런 황야
```

## 4. 베일과 베일의 법칙

기존 `경계의 율` 공식 명칭을 다음으로 교체한다.

```text
베일의 법칙
```

`베일`은 루미엔 영토와 베일런 황야 사이에 존재하는 보이지 않는 경계 현상이다.

베일의 법칙:

- 괴물이 넘어올 수 있는 시간·통로·규모를 제한한다.
- 공세 전에 관측 가능한 징조를 남긴다.
- 전장 조건에 따라 축복·저주·특수 규칙이 나타난다.
- 인간과 괴물 모두 전체 원리를 이해하지 못한다.
- 누가 만들었는지와 목적은 초반에 설명하지 않는다.
- 세계관 원인은 암시하되 실제 효과와 수치는 HUD에 정확히 공개한다.

현장 대사에서는 매번 정식 명칭을 반복하지 않는다.

- `이번 징조는 평소와 달라요.`
- `베일이 정한 순서가 바뀌었어요.`
- `이번 공세의 법칙이 달라졌어요.`

## 5. 플레이어 역할

플레이어는 실베른 성채에 부임한 최전선 지휘관이다.

- 세 라인의 위험을 읽는다.
- 건물과 룰렛 확률을 설계한다.
- 병력과 포탑을 배치한다.
- 전술 명령으로 위기를 지연하거나 역전한다.
- 괴물이 루미엔 영토로 넘어가지 못하게 한다.
- 방어에 성공한 뒤 베일런 측 적 시설과 본진을 공격한다.

## 6. 첫 30초 공식 표현

지역 카드:

```text
실베른 성채
루메른 왕국 트리븐 전선
```

벨루:

> 지휘관, 실베른 성채의 베일이 울려요.

> 베일런 쪽에서 전사형 넷. 상단으로 와요.

웨이브 카드:

```text
베일의 징조
상단 / 전사형 4 / 30초
```

첫 방어 성공:

> 첫 공세를 막았어요. 하지만 베일런의 징조가 더 커지고 있어요.

세계관 암시:

> 베일은 열리기 전에 반드시 울려요. 누가 정한 법칙인지는… 저도 몰라요.

## 7. 로고·마케팅 키워드

```text
세 갈래 전선
+ 3×3 룰렛 문양
+ 경계종의 빛 고리
+ 베일의 균열
+ 작은 감시 정령 벨루
```

게임명만 보고 슬롯 게임으로 오해하지 않도록 소개 문구와 영상 초반에 `건설 → 확률 변화 → 증원 → 전선 역전`을 바로 보여준다.
