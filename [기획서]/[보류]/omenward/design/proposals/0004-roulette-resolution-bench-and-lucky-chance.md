# 제안서 0004 — 룰렛 결과 판정, 대기칸 부족과 럭키 찬스

- 상태: **핵심 규칙 사용자 승인 / 세부 안전장치와 수치 검토 중**
- 구현 상태: 별도 Codex Plan Mode 승인 전 구현 금지
- 책임 원본: `docs/design/APPROVED_ROULETTE_CORE_RULES.md`
- 관련 문서: `docs/GAME_DESIGN.md`, `docs/DECISIONS_PENDING.md`, `docs/design/DESIGN_FREEZE_CHECKLIST.md`

## 1. 목적

룰렛 회전 시작부터 보상 정리까지의 상태 전이와 예외 처리를 고정한다.

이번 사용자 조정으로 기존 제안의 다음 부분은 폐기한다.

- 회전 전 상·중·하 기준 줄 자유 선택
- 같은 심벌 1개 또는 2개 보상
- 혼합 심벌 종류별 동시 보상
- 같은 심벌 수에 따른 1성·2성·3성 보상
- 금화 최대 환급률 100% 미만 계약
- 자연 럭키 찬스와 이동권 중 하나만 사용
- 회전당 이동 1회 제한

## 2. 승인된 핵심 결정

1. 기본 판정 줄은 **가운데 가로줄**로 고정한다.
2. 판정 줄 변경은 아이템 효과로만 가능하다.
3. 판정 줄의 세 심벌이 완전히 같아야 보상이 발생한다.
4. 판정 심벌의 전체 완성 줄 수가 유닛 등급 또는 금화 배율을 결정한다.
5. 유닛 9칸 전체 동일은 전설이며 한 판당 한 번만 소환한다.
6. 두 번째 이후 9칸 동일 유닛 결과는 같은 병종 영웅 2명으로 변환한다.
7. 금화는 1줄 75%, 2줄 200%, 3줄 이상 500%를 지급한다.
8. 럭키 찬스는 12% 시작, 실패당 +8%p, 6회 실패 뒤 다음 회전 확정 구조를 유지한다.
9. `행운` 아이템이 럭키 찬스 초기 확률을 높인다.
10. 자연 럭키 찬스와 이동권을 같은 회전에 함께 사용할 수 있다.
11. 회전당 이동 횟수 상한을 두지 않는다.

## 3. 룰렛 상태 전이

```text
Idle
→ CostPaidAndSnapshotLocked
→ Spinning
→ BoardRevealed
→ NaturalLuckyRoll
→ ManipulationPhase 또는 ResultLock
→ ResultLock
→ LineResolution
→ RewardResolution
→ RewardsPending 또는 Idle
→ Idle
```

### 3.1 회전 시작 조건

다음을 모두 만족해야 한다.

- 현재 릴에 실제 토큰이 1개 이상 존재한다.
- 회전 비용을 지불할 수 있다.
- 이전 회전의 결과 보관함이 비어 있다.
- 다른 회전이나 보드 조작이 진행 중이지 않다.

실제 토큰이 0개라 각 릴이 `[X, X, X]`인 상태에서는 회전 버튼을 비활성화한다.

### 3.2 판정 줄 고정

- 기본 판정 줄 인덱스는 중앙 가로줄이다.
- 아이템 효과가 없다면 플레이어에게 줄 선택 UI를 표시하지 않는다.
- 줄 변경 아이템이 적용된 경우에만 상단·하단 또는 선택 가능 상태를 제공한다.
- 비용을 지불한 순간 현재 판정 줄과 아이템 효과를 스냅샷으로 고정한다.
- 회전 도중 아이템 장착·해제로 판정 줄을 바꾸지 못한다.

정확한 줄 변경 아이템의 소비 여부와 지속시간은 아이템 설계에서 확정한다.

## 4. 판 생성 규칙

### 4.1 회전 스냅샷

비용 지불 순간 다음을 고정한다.

- 완공된 토큰 제공 건물 목록
- 릴별 실제 토큰 구성
- 부족분 X 토큰
- 실제 지불한 회전 비용
- 난수 시드와 회전 번호
- 현재 판정 줄
- 줄 변경 아이템 효과
- 행운 아이템으로 보정된 럭키 찬스 기본 확률

회전 도중 건물이 완공·파괴·철거돼도 현재 판에는 영향을 주지 않는다.

### 4.2 릴별 추출

각 세로 릴은 같은 구성의 독립 풀을 사용한다.

1. 완공 건물 기준 실제 토큰을 구성한다.
2. 실제 토큰이 3개 미만이면 X를 채운다.
3. 릴별로 독립 셔플한다.
4. 셔플된 풀에서 앞의 3개를 비복원 추출해 위·중간·아래 칸에 표시한다.

## 5. 기본 보상 조건

판정 줄의 세 칸이 동일한 비-X 심벌일 때만 보상 판정을 시작한다.

```text
[검사, 검사, 검사] → 검사 보상 판정
[검사, 검사, 기병] → 보상 없음
[검사, 기병, 궁병] → 보상 없음
[검사, 검사, X] → 보상 없음
[X, X, X] → 보상 없음
```

- 같은 심벌 1개 또는 2개는 보상을 주지 않는다.
- 혼합 심벌을 각각 보상하지 않는다.
- 세 칸이 같으면 해당 심벌을 `판정 심벌`로 고정한다.
- 판정 줄이 완성되지 않았다면 보드 다른 곳의 완성 줄은 무시한다.

## 6. 완성 줄 계산

전체 8개 줄을 검사한다.

```text
가로 3줄
+ 세로 3줄
+ 대각선 2줄
= 총 8줄
```

- 판정 심벌과 같은 심벌 3개로 완성된 줄만 센다.
- 판정 줄도 1줄로 센다.
- 교차하거나 겹치는 줄은 각각 센다.
- 다른 심벌의 완성 줄은 무시한다.

## 7. 유닛 보상

| 완성 줄 수 | 최종 보상 |
|---:|---|
| 1줄 | 해당 병종 1성 병사 1명 |
| 2줄 | 해당 병종 엘리트 1명 |
| 3~7줄 | 해당 병종 영웅 1명 |
| 8줄 | 해당 병종 전설 1명 |

### 7.1 2줄 예시

```text
검사 / 기병 / 궁병
검사 / 검사 / 검사  ← 기본 판정 줄
검사 / 금화 / 마법사
```

중앙 가로줄과 왼쪽 세로줄이 완성돼 **엘리트 검사 1명**을 지급한다.

### 7.2 3줄 예시

```text
검사 / 검사 / 기병
검사 / 검사 / 검사  ← 기본 판정 줄
검사 / 검사 / 궁병
```

중앙 가로줄, 왼쪽 세로줄, 가운데 세로줄이 완성돼 **영웅 검사 1명**을 지급한다.

### 7.3 전설

- 유닛 심벌이 9칸 전체를 채우면 8개 줄이 모두 완성된다.
- 한 스테이지/한 판에서 전설은 병종과 관계없이 한 번만 소환할 수 있다.
- 이미 전설을 소환했다면 이후 9칸 동일 유닛 결과는 해당 병종 영웅 2명으로 바꾼다.
- 전설 사용 여부는 룰렛 패널과 결과 화면에 표시한다.
- 전설의 정확한 능력치와 고유 스킬은 후속 유닛 설계에서 결정한다.

### 7.4 합성

수동·자동 유닛 합성은 아직 승인되지 않았다. 첫 프로토타입 제외를 추천하되 별도 결정으로 유지한다.

## 8. 금화 보상

판정 줄이 `[금화, 금화, 금화]`일 때 전체 보드의 금화 완성 줄 수를 센다.

| 금화 완성 줄 수 | 환급 비율 |
|---:|---:|
| 1줄 | 실제 지불 비용의 75% |
| 2줄 | 실제 지불 비용의 200% |
| 3줄 이상 | 실제 지불 비용의 500% |

```text
금화 보상 = floor(실제 지불한 회전 비용 × 환급 비율)
```

- 할인 후 실제 지불액을 기준으로 한다.
- 금화는 즉시 지급한다.
- 9칸 전체 금화도 3줄 이상 구간으로 처리해 500% 상한을 적용한다.
- 금화에는 유닛 등급을 적용하지 않는다.

### 8.1 필수 안전장치 검토

이 배율을 그대로 적용하면 시장 3개만 존재하는 구성에서 9칸 금화가 결정론적으로 발생할 수 있고, 매 회전 500% 환급으로 즉시 무한 경제가 가능하다.

사용자 배율을 유지하면서 구현하려면 다음 중 하나를 구현 전에 확정해야 한다.

1. 룰렛 회전에 금화와 별개의 시간 충전 자원을 요구한다.
2. 금화 고배율 보상에 재사용 대기시간 또는 웨이브당 지급 횟수 제한을 둔다.
3. 금화 보상 기준액과 실제 회전 비용을 분리하고 연속 회전 비용을 상승시킨다.
4. 동일 금화 토큰의 연속 지급에 감쇠를 적용한다.

현재 추천은 **시간 기반 회전 충전 1개 + 금화 비용** 방식이다. 금화가 많아도 충전 속도보다 빠르게 무한 회전할 수 없고, 룰렛 템포도 제어할 수 있다. 최종 선택은 미확정이다.

## 9. 결과 보관함과 대기칸

혼합 보상을 제거했으므로 한 회전당 유닛 보상 묶음은 최대 1개다.

- 유닛 보상은 공간 부족으로 사라지지 않고 결과 보관함에 생성한다.
- 금화 보상은 보관함을 사용하지 않고 즉시 지급한다.
- 결과 보관함이 남아 있으면 다음 룰렛 회전만 차단한다.
- 전투, 건설, 카메라, 기존 유닛 배치는 계속 진행한다.
- 보상은 대기칸 이동, 즉시 출전 또는 판매로 정리한다.
- 판매는 항상 가능하게 해 소프트락을 막는다.

대기칸 8칸 기본안은 아직 추천값이며 사용자 최종 승인을 받지 않았다.

## 10. 럭키 찬스

### 10.1 확률

```text
기본 확률: 12%
자연 실패 1회당: +8%p
6회 연속 자연 실패 후 다음 회전: 100%
자연 발생 시: 현재 기본 확률로 초기화
```

예시:

```text
12% → 20% → 28% → 36% → 44% → 52% → 100%
```

- 현재 확률과 확정까지 남은 실패 횟수를 UI에 공개한다.
- 자연 발생을 사용하지 않고 넘겨도 성공으로 보고 누적을 초기화한다.
- 이동권 사용 여부는 자연 발생 판정 결과를 바꾸지 않는다.

### 10.2 행운 아이템

`행운` 아이템은 럭키 찬스의 초기 기본 확률을 올린다.

```text
적용 기본 확률 = 12% + 행운 아이템 보너스 합계
현재 자연 확률 = 적용 기본 확률 + 실패 횟수 × 8%p
```

- 자연 발생 후에는 12%가 아니라 아이템 보정이 적용된 기본 확률로 돌아간다.
- 6회 실패 뒤 다음 회전 확정 구조는 유지한다.
- 아이템당 증가량, 중첩 상한과 희귀도는 미확정이다.

## 11. 다중 행·열 이동

### 11.1 이동 자원

- 자연 럭키 찬스 성공은 무료 이동 크레딧 1회를 제공한다.
- 이동권 1장은 추가 이동 1회를 제공한다.
- 이동권은 자연 럭키 찬스 발생 여부와 관계없이 사용할 수 있다.
- 무료 이동과 이동권을 같은 회전에 함께 사용할 수 있다.
- 회전당 이동 횟수 제한은 없다.
- 실제 이동 가능 횟수는 무료 크레딧과 보유 이동권 수로만 제한된다.

### 11.2 허용 이동

- 가로줄 하나를 왼쪽으로 1칸 순환
- 가로줄 하나를 오른쪽으로 1칸 순환
- 세로줄 하나를 위로 1칸 순환
- 세로줄 하나를 아래로 1칸 순환

여러 행·열 이동을 순서대로 조합할 수 있다.

### 11.3 계획·미리보기·소비

- 이동을 적용할 때마다 현재 보드, 완성 줄 수와 예상 보상을 갱신한다.
- 자연 럭키 찬스가 있다면 첫 이동은 무료 크레딧을 우선 사용한다.
- 추가 이동마다 이동권 1장을 예약한다.
- 이동권은 최종 판을 확정할 때만 실제 소비한다.
- 확정 전 `한 단계 되돌리기`와 `원본으로 초기화`를 제공한다.
- 되돌린 이동에 예약된 이동권은 소비하지 않는다.
- 최종 확정 뒤에는 되돌릴 수 없고 보상을 한 번만 계산한다.
- 별도 결정 시간 제한은 두지 않는다. 전투는 계속되며 일시정지를 사용할 수 있다.

## 12. 전체 회전 예시

```text
1. 기본 중앙 판정 줄과 적용 아이템 스냅샷
2. 회전 비용 지불
3. 완공 건물과 토큰 풀 스냅샷
4. 세 릴 독립 셔플·3개 추출
5. 3×3 판 공개
6. 자연 럭키 찬스 판정
7. 무료 이동과 이동권으로 0회 이상 행·열 순환
8. 최종 판 확정 및 이동권 소비
9. 판정 줄 3개 동일 여부 확인
10. 동일하면 판정 심벌의 전체 완성 줄 계산
11. 유닛 등급 또는 금화 배율 결정
12. 금화 즉시 지급 또는 유닛 결과 보관함 생성
13. 보관함 정리 후 다음 회전 가능
```

## 13. UI 필수 정보

룰렛 패널:

- 현재 판정 줄과 줄 변경 아이템 효과
- 현재 회전 비용
- 현재 토큰 수와 칸당 확률
- X 토큰 수
- 자연 럭키 찬스 현재 확률
- 확정까지 남은 실패 횟수
- 행운 아이템 총 보너스
- 무료 이동 크레딧 수
- 보유·예약 이동권 수
- 현재 완성 줄 수와 예상 보상
- 전설 소환 가능 여부
- 결과 보관함 상태와 회전 불가 이유

## 14. 검증 시나리오

- 아이템이 없으면 중앙 가로줄만 판정한다.
- 중앙줄 `[검사, 검사, 기병]`은 보상이 없다.
- 중앙줄 `[검사, 검사, 검사]`와 다른 검사 완성 줄이 없으면 1성 병사 검사를 지급한다.
- 승인된 2줄 예시는 엘리트 검사를 지급한다.
- 승인된 3줄 예시는 영웅 검사를 지급한다.
- 첫 9칸 동일 유닛 결과는 전설을 지급한다.
- 같은 판에서 전설을 이미 소환한 뒤 9칸 동일 결과는 영웅 2명을 지급한다.
- 금화 1줄·2줄·3줄 이상은 75%·200%·500%를 지급한다.
- 자연 럭키 찬스와 여러 이동권을 같은 회전에 사용할 수 있다.
- 이동권은 최종 확정 전에는 소비되지 않는다.
- 여러 이동을 되돌린 뒤 예상 보상과 예약 이동권 수가 정확히 복구된다.
- 최종 판 보상은 정확히 한 번만 지급된다.
- 대기칸이 가득 차도 유닛 보상이 사라지지 않는다.

## 15. 남은 사용자 결정

1. 판정 줄 변경 아이템의 형태, 지속시간과 소비 여부
2. 대기칸 초기 용량과 수동 합성 제외 여부
3. 행운 아이템 1개당 확률 증가량과 중첩 상한
4. 이동권 보유 상한과 상점 가격
5. 전설 유닛의 전투력과 영웅 대비 관계
6. 200%·500% 금화 배율을 유지하기 위한 무한 회전 안전장치
