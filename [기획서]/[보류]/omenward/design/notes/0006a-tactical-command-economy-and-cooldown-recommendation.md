# 세부 추천 0006-A — 전술 명령 경제·연속 사용·개별 쿨다운

- 상태: **사용 구조 승인 / 효과 수치 조정 대기**
- 구현 상태: 승인 전 구현 금지
- 상위 제안서: `docs/design/proposals/0006-tactical-commands.md`
- 보스 대응 제안서: `docs/design/proposals/0007-boss-cleave-and-barricade-counter.md`
- 관련 Issue: #9

## 1. 승인된 결론

1. 해금된 전술 명령은 HUD에 항상 표시하고 사용할 때마다 금화를 직접 지불한다.
2. 기본 명령을 상점 무작위 1회권으로 판매하지 않는다.
3. 스테이지 사용 횟수 제한과 반복 사용 가격 상승을 두지 않는다.
4. **전역 쿨다운을 사용하지 않는다.**
5. **일시정지 예약과 예약 금액을 사용하지 않는다.**
6. 일시정지 중에는 정보·범위 미리보기만 가능하고 실행 확정은 게임 진행 중에만 가능하다.
7. 명령별 개별 쿨다운은 유지한다.
8. 금화와 개별 쿨다운 조건을 만족하면 서로 다른 명령을 연속 사용할 수 있다.
9. 전술 명령 위력은 `StageManifest.command_power_level` 계열 값으로 스케일한다.
10. 바리케이드의 보스 길막 문제는 보스 패턴으로 대응한다.

## 2. 직접 금화 결제

```text
명령 해금
→ HUD 고정 등록
→ 전투 중 목표 지정
→ 비용과 사용 후 잔액 확인
→ 실행 확정과 즉시 금화 차감
→ 시전·효과
→ 해당 명령 개별 쿨다운
```

상점은 후속으로 다음 강화만 제공할 수 있다.

- 전술 명령 비용 할인
- 개별 쿨다운 감소
- 범위·지속시간·위력 변경
- 기본 네 명령과 다른 희귀 명령

## 3. 일시정지 처리

`PendingCommand`, `reserved_gold`와 예약 큐를 만들지 않는다.

일시정지 중:

- 명령 설명 확인 가능
- 범위와 대상 가능 영역 미리보기 가능
- 실행 확정 불가
- 금화 차감 없음
- 쿨다운 시작 없음

게임 재개 후 플레이어가 다시 실행을 확정한다.

이 방식은 예약 자원과 재개 시 유효성 재검사 같은 별도 상태를 제거한다.

## 4. 연속 사용

전역 쿨다운이 없으므로 다음 사용을 허용한다.

```text
바리케이드
→ 화살비
→ 강화지대
```

조건:

- 각 명령의 개별 쿨다운이 끝나 있음
- 각 사용 시점에 충분한 금화 보유
- 목표 지역이 유효함
- 같은 효과의 중첩 규칙 충족

연속 사용의 비용은 전술 명령을 막는 별도 시간 잠금이 아니라 실제 금화 지출로 만든다.

## 5. 개별 쿨다운·비용 초기값

| 명령 | 기본 비용 | 개별 쿨다운 |
|---|---:|---:|
| 바리케이드 | 12 | 30초 |
| 화살비 | 18 | 40초 |
| 역병 | 22 | 50초 |
| 강화지대 | 24 | 45초 |

이 수치는 최종 확정값이 아니라 시장 수입과 용병 가격을 비교하기 위한 초기값이다.

최종 비용:

```text
기본 비용
× DifficultyProfile.command_cost_multiplier
× Constraint.command_cost_multiplier
× 시장·아이템 할인
```

전역 쿨다운과 최소 전역 쿨다운 필드는 사용하지 않는다.

## 6. Command Power

```text
command_power_level
command_damage_scalar
command_structure_hp_scalar
command_buff_scalar
command_cost_multiplier
```

- 적 현재 체력 비율을 직접 피해 공식으로 사용하지 않는다.
- 일반·엘리트·영웅·지휘관 대상별 계수를 둔다.
- 같은 시드·난이도·제약은 같은 값을 만든다.
- 특정 명령이 없으면 클리어 불가능한 스테이지를 생성하지 않는다.

## 7. 바리케이드 추천안

- 지정 전술 지점에만 설치
- 아군 통과, 적 차단
- 라인당 동시에 1개
- 시전 지연 1.5초
- 지속시간 18초 또는 체력 0까지
- 체력: 해당 스테이지 Tier 1 포탑의 약 70%
- 공격·식량·건설 노드·룰렛 토큰 없음
- 개별 쿨다운 30초 초기값

바리케이드는 일반 웨이브와 돌격을 지연하지만 보스를 영구 봉쇄하지 않는다.

보스 대응:

- 가로축 직선 돌파로 바리케이드와 전열 공격
- 세로축 크게 베기로 바리케이드 뒤 밀집 병력 공격
- 두 패턴 모두 명확한 시전 예고 사용

## 8. 화살비 추천안

- 목표 구역 지정 뒤 1.2초 경고
- 세 차례 피해
- 일반 병사 기준 총 체력 약 60% 상당의 기준 피해 목표
- 엘리트 계수 0.65
- 영웅·지휘관 계수 0.30
- 건물·본진·바리케이드 피해 없음
- 아군 피해 없음
- 개별 쿨다운 40초 초기값

## 9. 역병 추천안

- 지속시간 10초
- 구역 안 적에게 1초마다 지속 피해
- 일반 병사 기준 전체 지속시간 동안 최대 체력 약 35% 상당의 기준 피해 목표
- 받는 치유량 50% 감소
- 영웅·지휘관 지속 피해 계수 0.50
- 동일 대상 피해 비중첩, 지속시간만 갱신
- 건물·본진·바리케이드 제외
- 개별 쿨다운 50초 초기값

## 10. 강화지대 추천안

- 지속시간 12초
- 아군 공격속도 +20%
- 받는 피해 -15%
- 구역 이탈 1초 뒤 효과 종료
- 포탑·건물·바리케이드 제외
- 동일 효과 비중첩
- 개별 쿨다운 45초 초기값

## 11. 해금 순서 추천

| 구간 | 해금 |
|---|---|
| 튜토리얼 | 바리케이드 |
| 정규 스테이지 1 | 화살비 |
| 정규 스테이지 3 | 역병 |
| 정규 스테이지 4 | 강화지대 |

튜토리얼에서는 바리케이드로 포탑 완공 시간을 버는 장면만 짧게 소개한다.

## 12. UI 계약

표시:

- 기본 비용·할인·최종 비용
- 현재 금화와 사용 후 잔액
- 개별 쿨다운
- 대상 가능·불가능 영역
- 범위·시전 지연·지속시간
- Command Power 반영 예상 효과
- 라인별 활성 바리케이드·역병·강화지대

제거:

- 전역 쿨다운 표시
- 예약 금액
- 예약됨 상태
- 일시정지 예약 취소 UI

## 13. 검증 시나리오

- 금화가 충분하면 서로 다른 준비된 명령을 연속 사용할 수 있다.
- 한 명령 사용이 다른 명령의 버튼을 전역 쿨다운으로 잠그지 않는다.
- 같은 명령은 개별 쿨다운 중 재사용할 수 없다.
- 일시정지 중 명령 실행·금화 차감·예약 객체가 발생하지 않는다.
- 바리케이드는 아군을 막지 않고 적만 차단한다.
- 라인당 활성 바리케이드는 하나다.
- 길 뚫기 보스는 예고된 패턴으로 바리케이드를 공격할 수 있다.
- 화살비와 역병은 건물·본진에 피해를 주지 않는다.
- 역병·강화지대의 동일 효과는 무한 중첩되지 않는다.
- 같은 StageManifest와 입력은 같은 결과를 만든다.

## 14. 남은 사용자 조정 항목

1. 개별 쿨다운 30/40/50/45초
2. 기본 비용 12/18/22/24
3. 바리케이드 체력·지속시간·배치 지점
4. 화살비 피해와 대상 계수
5. 역병 피해와 치유 감소량
6. 강화지대 강화량
7. Command Power 스칼라
8. 해금 순서

전역 쿨다운과 일시정지 예약은 더 이상 미확정 항목이 아니다.
