- spec-first 작업과 Plan Mode 승인 게이트.

- 애니메이션·전투 연출·판정 동기화 방법.
- 조사·벤치마킹·근거 관리 방법.
- 실무 스킬 매트릭스와 프로젝트 사례 기록 형식.
- 범용 GDD·계획서·연출·Work Order 템플릿과 품질 기준.

## 프로젝트 우선순위

일상 작업은 다음 순서를 사용한다.

```text
오멘워드 최신 사용자 지시
→ AGENTS.md
→ HANDOFF_CONTEXT.md
→ DOCUMENTATION_MAP.md
→ 현재 Work Order
→ 프로젝트 승인 책임 문서
→ 현재 Issue·Goal
→ 실제 파일과 테스트
→ 사전 기술 추천 또는 Codex 제출 제안서
→ 이 문서가 고정한 Base 커밋
→ Base 최신 공용 지식과 외부 참고
```

Base 원격 변경을 자동 적용하지 않는다. 동기화가 필요할 때 프로젝트 책임 문서와 충돌을 검토하고 별도 문서 커밋으로 갱신한다.
