# Issue #26: [Approved Unit][Support] 특수병단 사제 치유·전쟁 지휘·180초 자동생산

## Issue body
## 현재 상태

**사제를 특수병단에서 획득 / 최대 50% 준비 할인 / 사제단 비용·시간 / 사제 토큰·180초 일반 자동생산 / 치유·버프 역할 유지 / 정확한 수치·상위 분화 시점은 후속 조정 / 구현 금지**

## 책임 문서

- `docs/design/APPROVED_BARRACKS_AND_SPECIAL_CORPS_UNIT_TREE_V5.md`
- `docs/design/APPROVED_SPECIAL_CORPS_BUILDING_AND_GIANT_CLASS_V3.md`
- `docs/design/APPROVED_PRIEST_HEAL_AND_COMMAND_SUPPORT_CLASS_V1.md`

사제 능력 문서는 유지하되 생산 위치와 획득·경제 규칙은 V5 구조가 우선한다.

## 획득과 경제

```text
Tier 1 특수병단
금화 40 / 건설 25초

→ 준비도 축적
30초마다 -10%
150초에 -50% 최대

→ Tier 2 사제단
원가 60 / 최대 할인 30 / 업그레이드 30초

→ 사제 토큰 활성
→ 일반 사제 180초 자동생산
```

- 즉시 총금화 100.
- 최대 할인 총금화 70.
- 첫 사제도 전체 180초 생산시간 사용.
- 자동생산은 일반 등급만 생성.
- 룰렛은 일반·엘리트·영웅·전설 사제를 생성.
- 초기 식량 3.
- 플레이어 신화급 사제 없음.

## 역할

- 같은 라인의 부상 아군 치유.
- 약한 전투 격려.
- 전열 뒤 추종.
- 전역·다른 라인 지원 금지.
- 단독 전투력은 일반 전투병보다 낮음.

치유사제·전쟁사제 방향은 능력 계보로 유지하되, 특수병단 Tier 3 도입 여부와 함께 정확한 적용 방식을 다시 확정한다.

## 자동생산 경계

- 활성 전투 시간에만 진행.
- 일시정지 중 중단.
- 식량 부족 시 한 기 완성 대기, 다음 생산 중단.
- 사제단 파괴 시 진행 중 생산과 건물 안 완성 대기 사제 소멸.
- 이미 인도된 사제와 확정 룰렛 결과는 유지.
- 다음 룰렛부터 사제 토큰 제거.

## 남은 작업

1. 사제 일반·엘리트·영웅·전설 고정 능력
2. 회복·재생·보호막 수치
3. 버프·오라·지휘 수치
4. 특수병단 Tier 3에서 치유/지휘 분화를 적용할지 결정
5. 적군 대응 사제 병종
6. 식량 3·180초 생산 간격 실전 검증

별도 Plan Mode 승인 전에는 PriestProfile·HealingProfile·AuraProfile·ProductionQueue 구현을 시작하지 않는다.
