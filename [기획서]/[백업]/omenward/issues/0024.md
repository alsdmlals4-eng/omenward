## 종료 상태

현재 규칙:

- UnitArchetypeProfile은 정확히 10개다.
- 같은 archetype·Tier·Rank는 진영과 무관하게 같은 전투 결과를 낸다.
- 아군·적군 차이는 owner team, 출격 방식과 FactionVisualProfile이다.
- 별도 EnemyUnitProfile과 진영별 스탯·스킬·AnimationContract 복사본은 만들지 않는다.
- W20 신화는 일반 적군 Rank가 아니라 공용 base archetype 위의 보스 패키지다.

이전 대칭 데이터 초안은 GitHub 변경 이력에서 확인한다.
