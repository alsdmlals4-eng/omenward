# Issue #5: [Backlog Proposal][Constraints] 플레이어 선택형 추가 난이도 규칙

## Issue body
## 현재 상태

**백로그 제안 / 세부 계약 미승인 / 구현 금지**

이 Issue는 현재 PoC 필수 범위가 아니다. 수직 슬라이스와 기본 캠페인 구조를 검증한 뒤 별도 사용자 승인으로 재개한다.

## 목표

튜토리얼을 완료한 플레이어가 정규 스테이지 시작 전에 공개형 제약을 선택해 추가 난이도와 재도전 가치를 만드는 구조를 검토한다.

## 현재 책임 문서

- `docs/design/APPROVED_TUTORIAL_CAMPAIGN_PROCEDURAL_POC_V1.md`
- `docs/design/APPROVED_PREPRODUCTION_POC_BASELINE_V1.md`
- `docs/DECISIONS_PENDING.md`
- `docs/OMENWARD_ROADMAP.md`
- `docs/design/proposals/0003-constraint-system.md`

## 유지할 원칙

- 튜토리얼에서는 제약 사용 불가.
- 기본 난이도와 제약은 별도 축.
- 효과와 보상은 전투 시작 전에 공개.
- 전투 도중 숨은 동적 난이도 금지.
- 같은 시드·난이도·제약·생성기 버전은 같은 StageManifest 생성.
- 3라인·성문·중간거점·접전지·암살자 우회로의 기본 토폴로지를 훼손하지 않음.
- 불공정 조합은 자동 보정하지 않고 선택을 차단하며 이유 표시.
- 영구 전투력 보상은 사용하지 않음.

## 재개 조건

1. Goal 0001 Phase 0 승인·구현 완료.
2. Goal 0002 수직 슬라이스 플레이테스트 완료.
3. 기본 DifficultyProfile과 StageManifest 검증 완료.
4. 사용자가 제약 시스템을 PoC 이후 범위로 승인.

재개 전에는 Godot 코드·데이터·Scene·테스트를 만들지 않는다.
